## 제목

⚙️ [기능추가][커뮤니티] 모집글 채팅 기능 구현

## 본문

## 📝 현재 문제점

- 게시글 상세의 채팅 참여하기 버튼이 준비 중 안내만 띄우고 아무 동작도 하지 않음
- 백엔드가 게시글 단위 채팅방을 열었으나 앱은 참여·대화·나가기 어느 쪽도 붙어 있지 않음
- 내가 참여 중인 채팅방을 모아 볼 수 있는 화면이 없음

## 🛠️ 해결 방안 / 제안 기능

- 모집글 단위 채팅방 신설 — 상세에서 참여하고 방에 들어가 실시간으로 대화
- 내 채팅방 목록 화면 신설 — 참여 중인 방과 마지막 메시지 확인
- 채팅방 나가기

## ⚙️ 작업 내용

- 채팅방 참여·나가기·이전 대화 조회·내 채팅방 목록 서버 연동
- 채팅방 화면 신설 — 실시간 수신·전송, 위로 올려 이전 대화 이어 보기
- 보낸 메시지를 먼저 그린 뒤 서버 응답으로 확정 — 같은 메시지가 두 번 그려지지 않도록 앱에서 식별 키 생성
- 참여·나가기 알림 문구는 앱에서 조립 — 닉네임을 바꾸면 지난 대화의 이름도 따라 바뀜
- 채팅방 목록 화면 신설 — 마지막 메시지와 시각 표기, 대화가 없는 방은 맨 뒤
- 나가기 성공 후 해당 방 구독 해제
- 게시글 상세의 채팅 참여하기 버튼을 실제 참여·입장으로 연결
- 마감·종료된 글은 새 참여만 막고 이미 있는 대화는 그대로 유지
- 화면 문구와 실패 안내 다국어 처리 (ko/en/ja)

## 📌 참고

- 소켓은 앱당 하나만 쓴다 — 게임용과 커뮤니티용을 따로 열지 않는다. 서버가 연결마다 주기적 확인을 스레드 하나로 처리해서 연결이 늘면 부하가 그대로 늘어난다
- 목록 화면에서 방마다 구독하지 않는다. 지금 보고 있는 방만 구독한다
- 나가기 후 구독을 끊지 않으면 나간 방의 메시지가 계속 들어온다 — 서버는 구독 시점에만 자격을 확인한다
- 작성자는 방의 멤버로 자동 등록되고 나갈 수 없다
- 참여할 수 있는 방은 100개까지다. 자리가 필요하면 직접 나가야 하며 서버가 오래된 방을 지우지 않는다
- 읽음 처리와 안 읽은 개수는 서버에서 만들지 않기로 확정됐다 — 필요하면 앱에서 자체 처리한다
- 이전 대화에 표시되는 보낸 사람 이름은 조회 시점의 현재 닉네임이다. 탈퇴한 사용자만 탈퇴 당시 닉네임이 남는다
- 채팅 신고와 목록의 새 메시지 배지는 서버 후속 작업이라 이번 범위 밖이다
- 게임 화면들이 각자 소켓을 여는 부분을 하나로 합치는 정리는 게임 쪽 영향 범위가 커서 별도 이슈로 분리한다. 커뮤니티 채팅은 게임 밖에서만 쓰여 동시 연결 수를 늘리지 않는다
- 서버 스웨거 2.21.0 기준
