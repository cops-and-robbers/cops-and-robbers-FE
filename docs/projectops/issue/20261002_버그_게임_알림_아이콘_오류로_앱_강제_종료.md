# ❗ [버그][Android][알림] 게임 알림 아이콘 오류로 앱 강제 종료

## 🗒️ 설명

Android 게임 진행 알림(id=1001)을 표시할 때 아이콘 로딩 실패로 앱이 강제 종료된다. `ic_stat_notification.xml`의 벡터 경로를 모양 변경 없이 축약해 정상적으로 패키징되게 해야 한다.

원인은 `pathData`의 ASCII 문자열 34,747바이트가 AAPT UTF-8 문자열 한도 32,767바이트를 초과한 것이다. 빌드된 APK에는 경로 대신 `STRING_TOO_LARGE`가 들어가며, SystemUI의 벡터 파서가 실패하고 포그라운드 서비스 알림 오류로 앱 프로세스가 종료된다.

<br>

## 🔄 재현 방법

1. 수정 전 APK를 Android에서 실행하고 게임에 진입한다.
2. `GameSessionForegroundService`가 게임 알림(id=1001)을 게시한다.
3. `BadForegroundServiceNotificationException`과 함께 앱이 종료된다.

<br>

## 📸 참고 자료

<details>
<summary>실제 크래시와 SystemUI 내부 원인</summary>

```text
android.app.RemoteServiceException$BadForegroundServiceNotificationException:
Bad notification(tag=null, id=1001) posted from package com.elipair.copsandrobbers
Couldn't create icon StatusBarIcon(icon=Icon(typ=RESOURCE pkg=com.elipair.copsandrobbers id=0x7f070081) visible user=0 )

Caused by: android.content.res.Resources$NotFoundException:
File res/drawable/ic_stat_notification.xml from drawable resource ID #0x7f070081
Caused by: java.lang.IllegalArgumentException:
R is not a valid verb. Failure occurred at position 2 of path: STRING_TOO_LARGE
```

`aapt2 dump xmltree`로 수정 전 APK의 `android:pathData="STRING_TOO_LARGE"`를 확인했다.

</details>

| 위치 | 역할 |
|---|---|
| `android/app/src/main/res/drawable/ic_stat_notification.xml` | 한도를 넘은 원본 벡터 경로 |
| `GameSessionNotification.kt:53` | 게임 알림의 small icon 지정 |
| `GameSessionForegroundService.kt:43` | 같은 알림을 `startForeground`에 전달 |
| `AndroidManifest.xml:151` / `local_notifications_service.dart:29` | 같은 아이콘을 FCM·로컬 알림에서도 사용 |

<br>

## ✅ 예상 동작

아이콘의 모양을 유지하면서 게임 알림이 정상 표시되고, 해당 아이콘 로딩 오류로 게임 중 앱이 종료되지 않는다.
