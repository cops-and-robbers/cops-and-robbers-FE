# 🚀 [기능개선][인게임] 수감 화면 전면 철창 오버레이 적용

## 📝 현재 문제점

체포되면 `google_map_view.dart:441`에서 지도 JSON 스타일을 `MapStyles.dark` → `MapStyles.arrested`로 통째로 바꾼다. 화면 전체 색이 회흑색으로 갈려 "다른 지도로 갈아탄" 인상을 주고, 9/9 회의에서 정한 "감옥 바깥만 어둡게"라는 의도와도 다르게 배경 전체가 균일하게 어두워진다. 수감 상태가 한눈에 읽히지도 않는다.

<br>

## 🛠️ 해결 방안 / 제안 기능

지도 스타일은 도둑모드 그대로 두고, 그 위에 **전면 철창 오버레이**만 덮는다.

| 대상 | 변경 내용 |
| --- | --- |
| 지도 스타일 | 수감 중 `MapStyles.arrested` 교체 제거, 도둑모드(`MapStyles.dark`) 유지. 고아가 된 `arrested` 상수 삭제 |
| 철창 오버레이 | 앱바 아래부터 화면 바닥까지 끊김 없는 세로 창살(폭 8dp·간격 50dp) + 상하 가로 레일 + 상하 암부. 암부는 위아래에만 두어 감옥·내 위치가 있는 중앙은 밝게 |
| 터치·레이어 | `IgnorePointer`로 지도 조작 유지, 액션 버튼·전체 화면 패널(참가자·채팅) 아래에 배치 |
| 감옥 강조 | 노란 채움·맥동 경계는 변경 없음. 창살이 감옥 원을 가로지르는 것은 의도된 표현 |
| 채팅 버튼 아이콘 | `SvgIconButton`의 srcIn 틴트에서 줄이 사라지는 `speechBubble` 대신, 줄을 구멍으로 판 `icon_comment.svg`(`AppIcons.comment`)로 교체 |

> [!IMPORTANT]
> 오버레이는 게임 상태를 받지 않는 순수 비주얼 위젯으로 격리한다. 디자이너 시안(PNG/SVG 프레임)이 나오면 그 위젯의 `CustomPaint`만 `Image.asset`으로 갈아끼우고 호출부·지도·게임 로직은 건드리지 않는다.

<br>

## ⚙️ 작업 내용

- `lib/features/game/presentation/widgets/jail_bars_overlay.dart` 신규 — `IgnorePointer → SafeArea → Padding(top: kToolbarHeight) → RepaintBoundary → CustomPaint`
- `google_map_view.dart` `style:` 분기 단순화, `map_styles.dart`의 `arrested` 삭제
- `game_page.dart` 스택에 `index 0b`로 수감 중에만 오버레이 배치 (if/else 자식 개수 고정 컨벤션 유지)
- `app_colors.dart`에 암부 그라데이션용 `blackAlpha60`·`blackAlpha0` 추가 (`withValues` 금지 규칙)
- `game_page_auto_escape_test.dart` — 기존 스타일 단언 `arrested → dark`, 창살 배치·탈옥 시 제거 테스트 추가
- `game_page.dart:2540` 채팅 버튼 `AppIcons.speechBubble → AppIcons.comment`, `icon_comment.svg`를 단일 path(줄은 구멍) 버전으로 교체

## 📌 참고

- 9/9 회의에서는 "전체 철창 오버레이는 버튼이 안 눌린다고 오해할 수 있다"는 반론으로 기각됐던 안이다. 버튼을 창살 위 레이어에 두는 것으로 완화했으나 실사용에서 확인해야 한다.
- 창살 폭·간격·레일·암부 높이는 위젯 `build`의 상수 4개라 실기기 확인 후 바로 조정 가능하다.
- 앱바 높이를 `kToolbarHeight`로 가정하는 곳이 `game_page.dart` 4곳에 이어 이 위젯까지 5곳이 된다. `AppTopBar`에 `toolbarHeight`/`bottom`이 생기면 함께 고쳐야 한다 — 공용 상수로 모으는 정리는 이 이슈 범위 밖.
- 관련: #568 (수감 중 지도 조작·감옥 강조 — 이번 변경은 그 위에서 지도 표현만 바꾼다)
