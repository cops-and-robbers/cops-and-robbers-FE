# ⚙️ [기능추가][게임][알림] 잠금 화면 게임 현황 표시

## 🔥 구현 기능

| 항목 | Android | iOS |
|---|---|---|
| 기능 | Live Updates (Android 16+) | Live Activity (iOS 16.1+) |
| 노출 위치 | 상단바 칩 · 잠금 화면 · 알림창 최상단 | 잠금 화면 · 다이내믹 아일랜드 |
| 표시 내용 | 게임 남은 시간 · 남은 도둑 수 · 다음 위치 공개(경찰 대기 중엔 경찰 출발) | 같음 |
| 하위 버전 | 15 이하: 지금과 같은 일반 알림 | 15.x: 표시 없음 (지금과 같음) |
| 시작 / 종료 | 기존 `BackgroundService` start/stop 그대로 — GAME_START·재진입 가드에서 시작, GAME_OVER·게임 화면 이탈에서 종료 | 같음 |

<br>

## 📝 현재 문제점

게임 중 화면을 끄거나 다른 앱을 쓰면 남은 시간·남은 도둑 수·다음 위치 공개를 보려고 앱을 다시 열어야 한다.
Android는 게임 진행 FGS 알림(`GameSessionForegroundService.kt:113`)이 이미 떠 있지만 고정 문구뿐이고, iOS는 표시가 없다(`BackgroundServiceIos`는 no-op).

<br>

## 🛠️ 해결 방안

시간은 **서버가 아니라 인게임에서 계산**한다 — `GameTimerText`(`game_page.dart:2700`)와 같은 값(게임 시작 시각 · 제한 시간 · 경찰 대기 시간 · 공개 간격)으로 종료 시각과 다음 공개 시각을 구해 넘기고, 초 단위 카운트다운은 OS가 그린다. 서버 푸시로 갱신하지 않는다.

| 항목 | 갱신 방식 |
|---|---|
| 게임 남은 시간 | 시작 시 종료 시각 1회 전달 → OS 카운트다운 |
| 다음 위치 공개 | 게임 설정으로 계산, 공개 시각이 지나면 앱이 다음 시각으로 갱신 (위치 공개 이벤트 수신 시각에 의존하지 않음) |
| 남은 도둑 수 | 체포·탈옥·중도 퇴장 이벤트마다 앱이 갱신 |

| 영역 | 변경 |
|---|---|
| Dart | `BackgroundService`가 시작 시 종료 시각·공개 일정을, 도둑 수 변경 시 갱신값을 네이티브로 전달. iOS 구현도 no-op 대신 같은 채널 호출 |
| Android | `POST_PROMOTED_NOTIFICATIONS` 권한, `setRequestPromotedOngoing(true)`, 상단바 칩·카운트다운은 게임 남은 시간(`setWhen`·`setUsesChronometer`·`setChronometerCountDown`), 본문은 `도둑 N명 남음 · HH:mm 위치 공개`, 아이콘을 모노크롬 `ic_stat_notification`으로 |
| iOS 앱 | `NSSupportsLiveActivities`, AppDelegate에서 ActivityKit 시작/갱신/종료, 앱 재실행 시 남은 Activity 정리 |
| iOS 확장 기능 | Widget Extension 타깃 `LiveActivity`(`com.elipair.copsandrobbers.LiveActivity`) — 잠금 화면 + 다이내믹 아일랜드 뷰 (작은 화면엔 남은 시간만) |
| CI | TestFlight 워크플로에서 서명 파일 2개 설치, 타깃별 서명 파일 지정, `ExportOptions.plist`에 확장 기능 항목 추가 |

> [!IMPORTANT]
> 백그라운드 유지 구성(FGS + PARTIAL_WAKE_LOCK, #466)과 wakelock 3중 해제 경로는 건드리지 않는다. Android는 알림 **내용만** 바꾼다.

> [!TIP]
> 포털 App ID·서명 파일과 GitHub Secrets(`APPLE_LIVEACTIVITY_PROVISIONING_PROFILE_BASE64`, `IOS_LIVEACTIVITY_PROVISIONING_PROFILE_NAME`)는 2026-09-30 준비 완료.
