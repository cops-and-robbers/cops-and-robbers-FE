## 제목

🚀 [기능개선][Flutter] 사용자 액션 API 호출 전 네트워크 상태 사전 검증 적용

## 본문

## 📝 현재 문제점

- 사용자가 버튼/토글 등을 조작할 때 네트워크가 끊겨 있어도 API 요청을 그대로 시도함
- 요청 실패 후 롤백되는 방식이라 불필요한 API 호출과 대기 시간이 발생함
- 오프라인 상태임을 사용자에게 즉시 알려주지 못함

## 🛠️ 해결 방안 / 제안 기능

- 사용자 액션으로 API를 호출하는 모든 지점에서 호출 직전 네트워크 연결 여부를 확인함
- 연결이 없으면 API를 보내지 않고 즉시 안내 메시지를 표시함
- 이미 앱에 ConnectivityService가 구현되어 있으므로 이를 재사용함

## ⚙️ 작업 내용

- 사용자 액션이 트리거하는 API 호출 지점 전체 파악 (닉네임 변경, 버그 제보, 약관 동의 변경, 회원 탈퇴 등)
- 각 호출부에 네트워크 사전 검증 로직 추가
- 오프라인 시 표시할 안내 메시지 문구 통일
