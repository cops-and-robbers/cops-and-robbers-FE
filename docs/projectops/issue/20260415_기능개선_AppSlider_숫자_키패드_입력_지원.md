## 제목

🚀 [기능개선][AppSlider] 슬라이더 값 영역 탭 시 숫자 키패드 입력 지원 및 위치 공유 간격 최소값 0 허용

## 본문

## 📝 현재 문제점

- `AppSlider`는 값 조정이 드래그 방식으로만 가능해서, 정확한 숫자를 입력하고 싶을 때 세밀한 조작이 어렵다.
- 특히 divisions가 크거나 범위가 넓은 경우(예: 반경 100~1000m, 최대 인원 5~50명) 원하는 값을 드래그로 정확히 맞추기 번거롭다.
- 위치 공유 간격 슬라이더의 최소값이 0이 아니어서, "위치 공유 사용 안 함(0분)"을 선택할 수 없다.

## 🛠️ 해결 방안 / 제안 기능

- `AppSlider`의 값 표시 영역(`_buildValueDisplay`)을 탭하면 숫자 키패드가 올라와 직접 입력할 수 있도록 개선한다.
- 입력 UX는 기존 `InfoRadiusChip`의 편집 모드 패턴을 참고하여 동일한 사용자 경험을 제공한다.
  - 값 영역 탭 → `TextField`로 전환 → 숫자 키패드 노출
  - 입력값은 슬라이더의 `min`~`max` 범위로 자동 클램핑
  - 포커스 해제 또는 제출 시 편집 종료
  - 디바운스로 과도한 콜백 호출 방지
- 드래그 방식은 그대로 유지하여 기존 사용성을 해치지 않는다(드래그 + 탭 입력 병행).
- 위치 공유 간격 슬라이더의 최소값을 5분에서 0분으로 변경한다.
  - 0분 = 위치 공유 비활성화 의미로 사용

## ⚙️ 작업 내용

- `AppSlider`에 편집 모드(`editable`) 옵션 추가 및 값 영역 탭 핸들러 구현
- 편집 모드 시 `TextField` 기반 숫자 입력 UI 구성 (키패드, 클램핑, 디바운스, 포커스 처리)
- 기존 `displayValue` / `displayPrefix` / `displaySuffix` / `valueFormatter` 조합과 호환되도록 편집 모드 레이아웃 처리
- 위치 공유 간격 슬라이더 사용처의 `min` 값 0으로 변경 및 관련 검증 로직 점검
- 위치 공유 간격 0분(비활성화) 처리 관련 상위 로직 영향도 확인
