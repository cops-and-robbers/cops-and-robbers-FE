# ❗ [버그][Flutter][UI] 숫자 키패드 아래 세이프 에어리어가 흰색으로 비어 보임

## 🗒️ 설명

숫자 키패드가 있는 화면에서 키패드 아래(홈 인디케이터 영역)에 흰색 띠가 보인다.

- 키패드 화면들은 `SafeArea`가 하단 인셋만큼 body를 위로 밀어올리는데, 비워진 자리에 Scaffold 배경색이 노출된다.
- 방 생성 기본 정보 화면은 Scaffold가 `white`, 키패드 배경이 `background`(연회색)라 키패드 아래에만 흰 띠가 도드라진다.
- 대기실 설정 수정(다크)도 같은 구조다 - `black900` 위에 `black800` 키패드라 덜 튀지만 동일한 결함이다.

## 🔄 재현 방법

1. 홈에서 **게임 생성하기** → 구역 설정 완료 → **기본 정보를 설정해요** 단계 진입
2. 하단 숫자 키패드 아래, 홈 인디케이터 주변에 키패드와 색이 다른 흰 띠 확인
3. (동일) 대기실 → 설정 수정 화면에서도 키패드 아래 톤이 끊김

## ✅ 예상 동작

- 키패드 배경색이 화면 맨 아래(세이프 에어리어 포함)까지 이어져야 한다
- 홈 인디케이터가 키패드 배경 위에 자연스럽게 놓여야 한다
- 제스처 바가 없는 기기(하단 인셋 0)에서는 지금과 동일해야 한다

## ⚙️ 환경 정보

- iOS·Android 공통 (하단 세이프 에어리어가 있는 기기)
- iOS 실기기에서 제보, 에뮬레이터 Android API 36.1(제스처 내비게이션)에서 재현·검증
