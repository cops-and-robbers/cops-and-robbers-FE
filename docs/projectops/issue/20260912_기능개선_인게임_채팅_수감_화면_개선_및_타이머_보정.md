# 🚀 [기능개선][인게임] 인게임 채팅·수감 화면 개선 및 타이머 보정

## 📝 현재 문제점

인게임 채팅이 하단 시트를 사용하고, 체포 시 잠금 오버레이가 지도를 가린다. 채팅과 지도를 전환하는 흐름 및 수감 중 지도 확인 경험을 개선한다. 타이머는 전달 값이 바뀔 때 즉시 보정하고 60분 이상도 총 분으로 표시한다.

<br>

## 🛠️ 해결 방안 / 제안 기능

| 대상 | 변경 내용 |
| --- | --- |
| 인게임 채팅 | 버튼으로 여는 패널, 팀/전체 탭, 미읽음 배지, 지도 보기 버튼, 채널별 입력·스크롤 유지 |
| 채팅 UI | 공용 입력창 재사용, 내 말풍선 색상 구분, 빈 화면 캐릭터와 안내, 한·영·일 문구 |
| 수감 화면 | 지도 조작 유지, 버튼으로 안내창 표시·닫기, 수감 지도 스타일과 감옥 경계 강조 |
| 타이머 | 전달 값 변경 즉시 재계산, 60분 이상 표시 수정, 수신 시각 기준 남은 시간 생성자 |

## 📌 참고

현재 main의 미커밋 변경 21개를 추적하는 이슈다. 구현 완료나 테스트 통과를 의미하지 않는다.

- 주요 파일: `chat_overlay.dart`, `game_page.dart`, `arrest_lock_overlay.dart`, `google_map_view.dart`, `game_timer_text.dart`
- 공용 입력창: `lib/core/widgets/chat/community_message_input.dart`
- 관련 테스트: `chat_message_bubble_test.dart`, `game_page_auto_escape_test.dart`, `game_timer_text_test.dart`
- `GameTimerText.remaining`은 추가되었지만 실제 게임 화면은 기존 생성자를 사용한다. 서버 남은 시간 연동 완료로 간주하지 않는다.
- 확인한 검증은 `git diff --check`이며, Flutter 테스트와 실기기 검증은 아직 실행하지 않았다.
