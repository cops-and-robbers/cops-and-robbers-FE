📝 현재 문제점
---

- 작업 문서가 두 곳에 나뉘어 쌓이고 있다.
  - 이슈 문서: 예전 `docs/issues/`(140개), 지금 `docs/projectops/issue/`(17개)
  - 구현 보고서: 예전 `docs/report/`(204개), 지금 `docs/projectops/report/`(10개)
- projectops 스킬은 `docs/projectops/` 아래에 쓰는데, `CLAUDE.md`·`AGENTS.md`와 `.claude/commands`, `.agents/skills`의 이슈·보고서 명령은 아직 예전 경로를 안내한다. 같은 종류의 문서를 찾으려면 매번 두 곳을 봐야 한다.
- `AppIcons`에 상수만 남고 앱 어디에서도 쓰지 않는 아이콘 10개가 번들에 들어간다.
  - `icon_arrow.svg`, `icon_exit.svg`, `icon_map.svg`
  - `blog.svg`, `discord.svg`, `github.svg`, `instagram.svg`, `linkedin.svg`, `website.svg`, `youtube.svg` (SNS 바로가기는 `*_black` 글리프만 쓴다)

🛠️ 해결 방안 / 제안 기능
---

- 이슈·보고서 문서를 `docs/projectops/` 한 곳으로 모은다.
  - `docs/issues/` → `docs/projectops/issue/`
  - `docs/report/` → `docs/projectops/report/`
  - git 이력이 이어지도록 이동으로 처리하고, 파일 이름과 내용은 바꾸지 않는다.
- 예전 경로를 안내하는 문서를 새 경로로 고친다: `CLAUDE.md`, `AGENTS.md`, `.claude/commands`(issue·Issue-Branch·report·rp 등), `.agents/skills`(issue·report).
- 쓰지 않는 아이콘 10개와 그 `AppIcons` 상수를 지운다.
- `docs/pr/`, `docs/release-note/`, `docs/superpowers/` 등 나머지 폴더는 이번 범위에서 제외한다.

⚙️ 작업 내용
---

- 두 폴더 이동, 겹치는 파일 이름이 있는지 확인
- 경로 안내 문서 갱신, 예전 경로가 남았는지 전체 검색
- 아이콘 삭제 전 경로를 조립해 쓰는 곳(`_theme`, 언어별 로고 등)까지 다시 확인
- `flutter analyze`, `flutter test` 통과 확인
