## 제목

❗ [버그][게임][체포] 앱 재시작 시 체포 상태인데 ArrestLockOverlay가 표시되지 않음

## 본문

## 🗒️ 설명

- 도둑이 체포된 상태(JAILED)에서 앱을 강제 종료하거나 백그라운드에서 완전히 꺼졌다 다시 켰을 때, `ArrestLockOverlay`가 표시되어야 하지만 표시되지 않음
- 현재 내 참가자의 상태가 체포 상태라면 `game_page.dart`에서 `ArrestLockOverlay`가 다시 노출되어야 정상
- 오버레이가 없으면 체포된 도둑이 지도/AppBar/우측 버튼을 그대로 사용할 수 있어 게임 규칙이 깨짐

## 🔄 재현 방법

1. 게임 진행 중 도둑이 경찰에게 체포되어 `ArrestLockOverlay`가 노출된 상태가 됨
2. 앱을 강제 종료(스와이프로 완전 종료)함
3. 앱을 다시 실행하여 게임 화면(`game_page.dart`)으로 진입함
4. 내 상태는 여전히 체포(JAILED) 상태인데도 화면에 `ArrestLockOverlay`가 나타나지 않음

## 📸 참고 자료

- 관련 위젯: `lib/features/game/presentation/widgets/arrest_lock_overlay.dart`
- 관련 페이지: `lib/features/game/presentation/pages/game_page.dart`

## ✅ 예상 동작

- 앱 재시작 후 게임 화면 진입 시, 서버 상태 또는 로컬에 저장된 게임 상태를 기준으로 내 참가자의 체포 여부를 확인
- 내 상태가 체포(JAILED)라면 `ArrestLockOverlay`가 다시 표시되어야 함
- 탈옥 버튼/채팅 등 체포 상태에서 허용된 인터랙션만 가능해야 함
