## 제목

⚙️ [기능추가][게임][공유] 게임 종료 후 내 기록(이동 경로·거리) 공유 카드

## 본문

## 📝 현재 문제점

- 게임이 끝나면 팀 전체 통계(체포 수, 남은 도둑, 진행 시간)만 보여주고, 내가 게임 중 얼마나 움직였는지 등 개인 기록을 볼 수 없다.
- 게임 경험을 다른 사람과 공유하거나 남길 수 있는 수단이 없다.
- 백엔드에 위치/경로를 저장하지 않으므로 지금은 게임이 끝나면 내 활동 기록이 그대로 사라진다.

## 🛠️ 해결 방안 / 제안 기능

- 러닝앱 요약 화면처럼, 게임 종료 시 내 개인 기록을 보여주는 별도 다이얼로그를 추가한다.
- 보여줄 내용: 내가 이동한 거리(대표 숫자), 내가 움직인 경로, 플레이 시간, 승/패 결과, 게임 종료 날짜·시간.
- 역할별 카운트: 경찰이면 내가 잡은 도둑 수, 도둑이면 내가 탈옥한 횟수.
- 우리 앱 캐릭터(승리/패배)를 넣어 귀엽게 구성한다.
- 이동 경로는 실제 지도 타일 대신 우리 브랜드 톤의 스타일라이즈드 경로로 그린다.
- 이 기록 카드를 이미지로 공유하기(공유 시트) / 저장하기(갤러리)를 할 수 있다.
- 모든 개인 기록은 휘발성(인메모리)으로, 다음 게임 시작 시 초기화된다.

## ⚙️ 작업 내용

- 게임 중 내 이동 경로와 거리를 휘발성으로 누적
- 역할별 개인 카운트(경찰 체포 / 도둑 탈옥) 집계
- 기존 결과 다이얼로그에 내 기록 보기 진입 버튼 추가 (기존 홈으로/한 번 더 버튼은 유지)
- 내 기록 다이얼로그 화면 구성 (거리·경로·플레이 시간·승패·날짜 + 캐릭터)
- 공유하기 / 저장하기 동작 및 사진 권한 안내 문구 다국어 처리
