# 본문

## 📝 현재 문제점

- 백엔드 `api-docs.json` v2.5.0 업데이트로 버그 제보 API가 추가되었으나 프론트에 미연동
- 관련 엔드포인트
  - `POST /api/bugs` — 버그 내용 제보
- 사용자가 앱 내에서 버그를 제보할 수 있는 동선이 없음

## 🛠️ 해결 방안 / 제안 기능

- 마이페이지 또는 설정 화면에 "버그 제보" 진입 동선 추가
- 버그 제보 화면에서 사용자가 버그 내용을 작성하여 전송
- 디자인 시안 확인 후 입력 필드(제목/내용/스크린샷 등) 정의
