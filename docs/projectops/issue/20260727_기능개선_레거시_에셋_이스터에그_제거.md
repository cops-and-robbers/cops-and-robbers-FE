# 🚀 [기능개선][Flutter][에셋] 미사용 레거시 에셋 및 클래식 스킨 이스터에그 제거

## 📝 현재 문제점

- 캐릭터 디자인 교체(#376) 때 백업해 둔 구 캐릭터 자산이 assets/characters 아래 classic 폴더로 남아 있고, 홈 화면 캐릭터를 5번 탭하면 이 구 캐릭터로 바뀌는 이스터에그로 노출되고 있다. 더 이상 유지할 이유가 없다
- 이스터에그 때문에 캐릭터를 그리는 화면 여섯 곳이 전역 스킨 상태를 구독하고 있다. 스킨이 실질적으로 하나뿐인데도 화면마다 스킨 분기가 남아 있는 셈이다
- assets 루트에 splash.png, app_icon.png, app_icon_1024.png 세 개의 레거시 이미지가 남아 있다. 이 중 두 개는 참조가 완전히 끊기지 않아 파일만 지우면 앱 아이콘 생성과 개발용 위젯 화면이 깨진다
- classic 캐릭터 자산과 레거시 이미지가 앱 번들 용량을 불필요하게 차지한다

## 🛠️ 해결 방안 / 제안 기능

- 홈 화면 캐릭터 탭 이스터에그와 클래식 스킨을 화면, 문구, 자산 전 계층에서 제거한다
- 스킨이 하나만 남으므로 캐릭터 자산 경로를 만들 때 쓰이던 스킨 구분 인자를 걷어낸다
- 다만 자산 폴더 규칙(팀/스킨/상태)은 그대로 남긴다. 나중에 옷장 같은 스킨 시스템을 붙일 때 실제로 재사용되는 부분이기 때문이다
- 레거시 이미지 세 개는 남은 참조를 먼저 정리한 뒤 삭제한다. 개발용 위젯 화면의 아바타는 실제 게임에서 쓰는 것과 같은 형태로 맞추고, 앱 아이콘 생성 설정은 현재 실제로 쓰이는 로케일별 아이콘을 가리키도록 바꾼다
- 사용자 관점 변화는 홈 캐릭터를 여러 번 탭해도 아무 일이 일어나지 않는다는 점 하나뿐이다. 스킨 상태는 원래 앱을 껐다 켜면 기본값으로 돌아가는 임시 상태였으므로 기존 사용자 데이터에 영향이 없다

## ⚙️ 작업 내용

- 홈 화면 캐릭터 탭 카운터와 스킨 전환 페이드 연출 제거
- 전역 캐릭터 스킨 상태 제거 및 이를 구독하던 화면 여섯 곳 정리 (홈, 로비 참가자 카드, 체포 오버레이, 게임 결과, 내 기록, 홈 캐릭터 영역)
- 캐릭터 자산 경로 생성 함수에서 스킨 구분 인자 제거 및 확장 지점 안내 주석 추가
- 클래식 스킨 전용 환영 문구를 한국어·영어·일본어에서 제거
- classic 캐릭터 자산 폴더 네 곳 삭제 및 자산 등록 목록 정리
- 레거시 이미지 splash.png, app_icon.png, app_icon_1024.png 삭제
- 개발용 위젯 화면의 아바타 다이얼로그를 실제 게임 화면과 동일한 형태로 교체
- 앱 아이콘 생성 설정에서 삭제 대상 이미지 참조 정리 및 사용되지 않는 안드로이드 적응형 아이콘 항목 제거
- 정보 구조 문서의 이미지 표기 갱신
