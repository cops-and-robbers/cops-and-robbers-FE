## 제목

❗ [버그][게임][팝업] 재연결 팝업이 닫힐 때 플레이그라운드 이탈 팝업도 함께 사라짐

## 본문

## 🗒️ 설명

- 게임스크린에서 플레이그라운드 영역을 벗어나면 `app_popup` 으로 "플레이그라운드를 벗어났어요!" 안내 팝업이 표시됨
- 이 상태에서 웹소켓 연결이 끊어지면 재연결 팝업이 추가로 표시됨
- 이후 웹소켓이 다시 연결되는 등의 이유로 재연결 팝업이 닫힐 때, 이탈 안내 팝업까지 함께 닫혀버려 사용자가 여전히 구역을 벗어났는지 확인할 수 없게 됨

## 🔄 재현 방법

1. 게임 진행 중인 화면(게임스크린)에 진입
2. 플레이그라운드 영역 밖으로 이동하여 "플레이그라운드를 벗어났어요!" 팝업이 뜨는 것을 확인
3. 이탈 팝업이 떠 있는 상태에서 네트워크를 잠시 끊어 웹소켓 재연결 팝업이 뜨도록 유도
4. 네트워크를 복구하거나 재연결 조건이 해제되어 재연결 팝업이 닫히는 순간을 관찰
5. 여전히 플레이그라운드 밖인데도 이탈 안내 팝업이 사라지는 것을 확인

## ✅ 예상 동작

- 두 팝업은 서로 독립적으로 관리되어야 함
- 재연결 팝업이 닫혀도 사용자가 여전히 플레이그라운드를 벗어난 상태라면 이탈 안내 팝업은 계속 유지되어야 함
- 이탈 팝업은 오직 플레이그라운드 복귀(구역 재진입) 시점에만 자동으로 닫혀야 함
