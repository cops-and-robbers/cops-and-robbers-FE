## 📝 현재 문제점

- 이벤트 게임만 예전 경찰 대기 팝업(`AppPopup` + `CountdownTimerContent`)을 써서 일반 게임과 시작 화면이 다르다. 이 팝업은 이벤트 게임 한 곳에서만 쓰인다
- 홈 화면 개발자 도구의 라이프사이클 테스트·테스트 위젯은 더 쓰지 않는데 코드가 남아 있다 (`lib/test_widget_page.dart` 1000줄, `lib/features/lifecycle_test/`)
- 앱 어디서도 호출하지 않는 함수가 남아 있다

<br>

## 🛠️ 해결 방안 / 제안 기능

### 1. 이벤트 게임 시작 연출 통일

- `game_page.dart` `_startIntro()`의 이벤트 게임 분기를 없애 일반 게임과 같은 흐름을 탄다
- `startIntroSteps`의 `isEventGame` 인자 제거
- ⓘ 버튼(`_showGameRulesDialog`)도 이벤트 게임에서 장면을 띄운다
- 쓰는 곳이 없어지는 `app_popup.dart`, `countdown_timer_content.dart`, 문구 키 `gameRobberOnTheRunBanner`·`gameRobberOnTheRunBannerTag` 삭제

### 2. 디버깅 코드 삭제

| 대상 | 위치 |
|---|---|
| 테스트 위젯 페이지 | `lib/test_widget_page.dart` |
| 라이프사이클 테스트 화면 | `lib/features/lifecycle_test/`, 라우트 `/lifecycle-test` |
| 홈 개발자 도구 버튼·메뉴 | `home_page.dart` |
| 테스트 화면 전용 로그 기록 | `LifecycleLogsNotifier`, `LifecycleLog`, `AppLifecycleService`의 로그 저장 |

게임·대기방의 개발자 도구(끊김·재연결 시뮬레이션)는 남긴다.

### 3. 호출 없는 함수 삭제

`topLiftThemed`, `clearDeviceId`, `updateMaxParticipants`, `playerJoinLeave`(진동 상수 포함), `MarqueeAlertBanner.heightFor`, `projectPoint`, `waitProgress`
