## 제목

⚙️ [기능추가][Flutter][딥링크] 방 초대 링크 딥링크 구현 (App Links / Universal Links)

## 본문

## 📝 현재 문제점

- 현재는 방 초대 코드를 친구에게 공유해도 친구가 코드를 직접 보고 앱에서 수동으로 입력해야 한다
- 카톡으로 받은 링크를 눌러 앱이 자동 실행되고 해당 방까지 바로 진입하는 흐름이 없다
- Firebase Dynamic Links는 2025년 8월에 종료되어 더 이상 사용 불가하므로 OS 네이티브 딥링크로 대체 구현이 필요하다

## 🛠️ 해결 방안 / 제안 기능

- Android App Links + iOS Universal Links 기반으로 https URL 딥링크 구현
- URL 패턴: `https://copsnro66ers.site/join/{inviteCode}`
- 카톡/QR로 공유받은 링크를 클릭하면
  - 앱이 설치되어 있으면 앱이 자동 실행되어 해당 방 대기실로 바로 진입
  - 앱이 설치되어 있지 않으면 OS가 폴백 웹페이지를 열고 사용자를 스토어로 안내
- 미로그인 상태에서 링크를 받은 경우 로그인 완료 후 자동으로 해당 방에 진입
- 이미 다른 방에 참가 중일 때는 백엔드가 409로 거부하므로 토스트 안내 후 메인 이동
- 백엔드의 기존 `POST /api/games/join` API를 그대로 활용 (백엔드 신규 API 작업 불필요)

설계 문서:
- 백엔드 / OS 측 작업 가이드: `docs/DEEPLINK.md`
- Flutter 측 구현 설계: `docs/superpowers/specs/2026-05-27-deeplink-frontend-design.md`

## ⚙️ 작업 내용

프론트 (Flutter)

- `app_links` 패키지 추가 및 앱 부트스트랩 단계에서 초기 링크 수신 처리
- Flutter 기본 딥링크 핸들러 비활성화 (`flutter_deeplinking_enabled=false`)
- 콜드 스타트 / 백그라운드 복귀 두 경로 모두 URI 수신 구독
- `lib/core/deeplink/` 모듈 신설 (DeepLinkService, DeeplinkEvent, DeepLinkHandler)
- `go_router` 에 `/join/:inviteCode` 라우트 추가
- 인증 상태 확인 후 미로그인 시 pending invite code 저장 (SharedPreferences) → 로그인 완료 시점에 watch하여 자동 join 흐름 재진입
- 백엔드 `POST /api/games/join` 호출 및 에러 응답 분기 (400 인원 초과, 404 코드 없음, 409 이미 다른 방 참가 중 등)
- ARB(ko/en/ja) 에 사용자 노출 메시지 추가 후 `flutter gen-l10n`
- 대기실(또는 방 생성 직후 화면) 에 "초대 링크 공유" 버튼 추가 (`share_plus` 활용)
- 기존 QR 코드가 인코딩하는 값도 동일한 URL 로 교체

플랫폼 설정

- Android `AndroidManifest.xml` 에 intent-filter 추가 (`autoVerify="true"`, `pathPrefix="/join"`)
- iOS Xcode 에서 Associated Domains capability 추가 (`applinks:copsnro66ers.site`)
- Apple Developer Portal 에서 해당 App ID 에 Associated Domains 활성화

백엔드 의존 (별도 진행 필요)

- `https://copsnro66ers.site/.well-known/assetlinks.json` 호스팅 (디버그 키 / 업로드 키 / Play 앱 서명 키 SHA-256 세 가지 모두 포함)
- `https://copsnro66ers.site/.well-known/apple-app-site-association` 호스팅 (확장자 없이, `application/json`)
- `https://copsnro66ers.site/join/{code}` 폴백 웹페이지 (User-Agent 감지 후 스토어로 redirect)
- iOS AASA validator 사전 검증 (Apple CDN 24시간 캐싱 주의)

테스트

- DeeplinkEvent URI 파싱 단위 테스트 (table-driven)
- 인증 / 게임 상태 / 에러 분기에 대한 Notifier 단위 테스트
- 콜드 스타트 / 백그라운드 복귀 / 미로그인 → 로그인 시나리오 통합 테스트
- ADB 및 `xcrun simctl openurl` 로 실제 단말 검증
