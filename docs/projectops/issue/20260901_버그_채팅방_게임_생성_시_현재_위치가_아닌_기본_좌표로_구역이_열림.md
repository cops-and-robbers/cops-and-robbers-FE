# ❗ [버그][Flutter][게임생성] 채팅방에서 게임 생성 시 현재 위치가 아닌 기본 좌표로 구역이 열림

## 🗒️ 설명

홈에서 "방 만들기"로 들어가면 구역 설정 지도가 **현재 위치**에서 열린다. 그런데 커뮤니티 채팅방에서 게임을 생성하면 현재 위치가 아니라 **기본 좌표**에서 열린다.

원인은 같은 플로우로 들어가는 **두 진입점이 하는 일이 다르기** 때문이다. 홈은 진입 전에 두 가지를 하고, 채팅방은 곧장 라우팅한다.

| | 홈 (`home_page.dart:300` `_onCreateSession`) | 채팅방 (`community_chat_room_page.dart:240` `_startGame`) |
|---|---|---|
| 위치 권한 게이트 | `gameEntryGateProvider.ensure(...)` **있음** | **없음** |
| 이전 초안 정리 | `SessionDraftStorageService().clearDraft()` **있음** | **없음** |
| 라우팅 | `context.go(sessionCreationFlow)` | `context.push(sessionCreationFlow, extra: postId)` |

<br>

> [!WARNING]
> 이건 [#432](https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/432)에서 이미 한 번 고친 문제의 재발이다. 그때 위치 권한·배터리 최적화 게이트가 `home_page`의 private 메서드로만 있어 딥링크 진입이 우회하는 버그를 잡으면서 공용 `GameEntryGate` 헬퍼로 추출했다. 헬퍼는 만들어졌지만 **"게임 생성 플로우로 들어가려면 반드시 이걸 거친다"가 강제되지 않아**, #516에서 추가된 세 번째 진입점이 다시 우회했다.

<br>

## 🔄 재현 방법

1. 앱을 설치 직후 상태로 두거나, 위치 권한을 거부한 상태로 만든다
2. 커뮤니티 → 모집글 채팅방 진입 (방장 계정)
3. 게임 생성 진입
4. 구역 설정 지도가 현재 위치가 아닌 좌표에서 열린다

홈 → "방 만들기"로 같은 절차를 밟으면 현재 위치에서 열린다.

<br>

## 📸 참고 자료

기본 좌표가 나오는 경로는 `ZoneSettingWidget`의 3단 폴백이다.

<details><summary>현재 코드 — 경로가 세 단계로 갈린다</summary>

```dart
// lib/core/widgets/map/zone_setting_widget.dart:139
static const LatLng _fallbackLocation = LatLng(37.5480, 127.0810);

// lib/core/widgets/map/zone_setting_widget.dart:163
_currentCenter =
    widget.initialCenter ??
    await _getCurrentLocation() ??
    _fallbackLocation;
```

`initialCenter`가 non-null이면 **현재 위치 조회 자체를 하지 않는다.** 그 값은 이렇게 채워진다.

```dart
// lib/features/session/presentation/pages/setup_playground_page.dart:151
// 생성 모드: 로컬 저장소에서 복원
_currentCenter = draft?.playgroundCenter;

// lib/features/session/presentation/pages/setup_playground_page.dart:389
initialCenter: _currentCenter,
```

</details>

따라서 증상이 두 갈래로 갈리며, **어느 쪽인지에 따라 원인이 다르다.**

| 실제로 뜨는 좌표 | 원인 |
|---|---|
| `37.5480, 127.0810` (고정) | 위치 권한 게이트를 안 거쳐 `getCurrentPosition()`이 실패 → `_fallbackLocation` |
| 직전에 만들었던 게임의 위치 | `clearDraft()`를 안 해 이전 초안의 `playgroundCenter`가 복원됨 → 현재 위치 조회 건너뜀 |

<br>

## ✅ 예상 동작

- 채팅방에서 게임을 생성해도 홈과 **똑같이** 위치 권한 게이트를 거치고, 이전 초안을 비운 뒤 플로우에 들어간다
- 구역 설정 지도가 현재 위치에서 열린다
- 권한이 없으면 홈과 같은 안내 다이얼로그가 뜨고, 통과하지 못하면 채팅방에 머무른다

## ❓ 확인 필요

- **실제로 뜨는 좌표가 `37.5480, 127.0810`인지, 아니면 직전에 만들었던 게임의 위치인지.** 위 표대로 원인이 갈린다. 다만 두 결함 모두 같은 두 줄의 차이에서 나오므로 **수정 범위는 어느 쪽이든 동일**하다
- 게이트 미통과 시 채팅방에 머무를지, 다른 동작을 할지 (홈은 홈에 머무른다)

## 📌 참고

- **#432** — 딥링크 진입이 같은 게이트를 우회하던 버그. 그때 `core/services/permission/game_entry_gate.dart`의 `GameEntryGate.ensure()`로 추출했고, 홈·딥링크가 공유하게 했다. 이번 건은 그 이후 추가된 진입점이 공유 대상에 들어오지 않은 경우다
- **#516** — 채팅방에서 게임 생성·초대 전송을 추가한 이슈. `_startGame()`이 이때 생겼다
- 라우팅 방식 차이(`go` vs `push`)는 채팅방으로 돌아가기 위한 의도된 선택이므로 그대로 두는 것이 맞다. 문제는 라우팅이 아니라 **진입 전 처리 두 가지의 누락**이다
