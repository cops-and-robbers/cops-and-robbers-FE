## 🔥 구현 기능

홈 화면에 들어오면 **행사 안내 모달**을 띄운다. 켜고 끄기, 이미지, 이동 링크는 Remote Config 값으로 바꾼다. 행사 때마다 앱을 배포하지 않기 위해서다.

| 항목 | 제안 |
|---|---|
| 띄우는 곳 | 홈 화면에 들어왔을 때만. 게임 중과 대기방에서는 띄우지 않는다 |
| 내용 | 이미지 한 장, 누르면 링크로 이동, 닫기 버튼 |
| 켜고 끄기 | Remote Config 값. 기본은 꺼짐 |
| 값이 틀렸을 때 | 주소가 비었거나 이미지를 못 받으면 모달을 띄우지 않는다 |
| 다시 보지 않기 | 행사마다 다른 식별값을 두고, 닫은 행사는 다시 띄우지 않는다 |
| 반영 시점 | 홈 배너와 같이 게시한 값을 바로 받는다 |

<br>

> [!IMPORTANT]
> 값을 바꾸는 화면은 웹 어드민(`/admin/app-config`)이다. 어드민에 모달 탭을 더하는 일은 웹 저장소에 따로 이슈가 필요하다.

<br>

## 📝 현재 문제점

- 원격으로 바꿀 수 있는 안내는 홈의 띠 배너뿐이다(`lib/features/session/presentation/widgets/home_banner.dart`, 높이 68). 행사 안내처럼 눈에 띄어야 하는 내용을 담기에는 작다.
- 화면 가운데 뜨는 안내를 넣으려면 지금은 행사 때마다 앱을 배포해야 한다.
- Firebase 인앱 메시지는 쓰지 않기로 했다. 패키지를 새로 넣어야 하고, 반영이 하루까지 늦을 수 있고, 화면이 앱 디자인과 다르고, 값을 바꾸는 곳이 어드민과 Firebase 콘솔 둘로 갈린다.

<br>

## 🛠️ 해결 방안 / 제안 기능

- 홈 배너(#474)와 같은 방식으로 Remote Config 값을 더한다. 값 이름은 `lib/core/services/remote_config/remote_config_keys.dart`의 배너 값과 짝이 맞게 짓는다.

| 값(이름은 제안) | 뜻 | 기본 |
|---|---|---|
| `modal_enabled` | 모달을 띄울지 | 꺼짐 |
| `modal_image_url` | 모달 이미지 주소 | 빈 값 |
| `modal_link_url` | 눌렀을 때 이동할 주소. 비면 이미지만 보여 준다 | 빈 값 |
| `modal_id` | 행사 식별값. 바뀌면 닫았던 사람에게도 다시 띄운다 | 빈 값 |

- 모달은 앱의 공용 다이얼로그와 디자인 토큰으로 만든다.
- 화면은 ko, en, ja 시안을 먼저 만들어 이 이슈에 올린 뒤 진행한다.

<br>

## ⚙️ 작업 내용

- [ ] Remote Config 값 추가와 기본값(꺼짐)
- [ ] 홈 화면에 들어왔을 때 모달 띄우기, 게임 중과 대기방에서는 띄우지 않기
- [ ] 이미지 누르면 링크 이동, 링크가 비면 이미지만
- [ ] 닫은 행사는 다시 띄우지 않기(식별값이 바뀌면 다시 띄움)
- [ ] 주소가 비었거나 이미지를 못 받으면 띄우지 않기
- [ ] 닫기 버튼 문구 ko, en, ja ARB
- [ ] 테스트: 행사 모달을 닫은 사람이 홈에 다시 들어와도 뜨지 않는다 / 다음 행사로 식별값이 바뀌면 다시 뜬다 / 이미지 주소가 깨진 값이면 뜨지 않는다

<br>

## ❓ 확인 필요

- 다시 보지 않기 방식: 닫으면 그 행사는 끝까지 안 띄울지, "오늘 하루 보지 않기"를 둘지
- 언어별 이미지: 값이 전체 공통이라 ko, en, ja에 같은 이미지가 나간다. 언어별 주소를 따로 둘지
- 이미지 비율과 크기 기준(어드민 올리기 제한과 맞춰야 한다)
- 홈 배너와 모달을 동시에 켰을 때 둘 다 보여 줄지
