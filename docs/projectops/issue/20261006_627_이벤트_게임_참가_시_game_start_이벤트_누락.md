## 🗒️ 설명

대기실을 거치지 않고 게임 화면으로 들어가면 `game_start` 애널리틱스 이벤트가 찍히지 않는다. 지금은 대기실이 소켓으로 `GAME_START`를 받을 때(`waiting_room_page.dart` `_onGameStartEvent`)만 기록한다.

이벤트 게임은 대기실 없이 인게임으로 바로 들어가므로 축제 현장 게임이 통째로 빠진다. 이 이벤트는 어드민 지표 화면의 "게임 시작", 주간 리포트, 신규 사용자 활성화(7일 안에 게임 시작) 계산에 쓰여서, 행사 날일수록 숫자가 낮게 나온다.

<br>

## 🔄 재현 방법

1. 이벤트 게임 방에 코드나 딥링크로 참가한다(`isEventGame == true`)
2. 대기실 없이 인게임으로 이동한다
3. GA4 DebugView에 `game_join`, `game_over`는 들어오지만 `game_start`는 들어오지 않는다

<br>

## ✅ 예상 동작

- 위 세 경로로 게임에 처음 들어갈 때도 `game_start`가 한 번 찍힌다
- 같은 게임에서 두 번 찍히지 않는다. 대기실 소켓 신호와 복귀 확인이 겹칠 수 있으므로 `AnalyticsService`에서 gameId 단위로 한 번만 보낸다
- 이벤트 게임은 대기실 인원을 알 수 없으므로 `participant_count`는 생략할 수 있게 한다. 이 값은 GA4 커스텀 측정기준으로 등록되어 있지 않아 지표 계산에 쓰지 않는다
- 확인은 디버그 빌드에서 `--dart-define=EVENT_GAME_DEV=true`로 이벤트 게임을 열고 GA4 DebugView에서 `game_start`를 확인한다
