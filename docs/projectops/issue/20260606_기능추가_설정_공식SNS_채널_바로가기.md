## 제목

⚙️ [기능추가][설정] 공식 SNS 홍보 채널 바로가기 추가

## 본문

## 📝 현재 문제점

- 앱을 홍보하는 공식 채널(인스타그램, 유튜브, 틱톡)이 있지만, 앱 내에서 해당 채널로 이동할 수 있는 통로가 전혀 없다.
- 사용자가 게임 소식이나 콘텐츠를 접할 경로가 없어 채널 유입과 재방문 유도가 어렵다.

## 🛠️ 해결 방안 / 제안 기능

- 설정 화면 맨 아래에 공식 SNS 채널 아이콘 행을 추가한다.
- 인스타그램 / 유튜브 / 틱톡 아이콘을 가로로 배치하고, 위에는 짧은 안내 문구를 둔다.
- 각 아이콘을 탭하면 외부 브라우저로 해당 채널 페이지가 열린다.
- 아이콘은 이미 존재하는 에셋(instagram.svg, youtube.svg, tiktok.svg)을 그대로 사용한다. 세 에셋 모두 브랜드 컬러가 적용돼 있어 별도 색상 처리가 필요 없다.
- 외부 링크 열기는 기존 공통 유틸을 재사용한다.

## ⚙️ 작업 내용

- 설정 화면 하단 SNS 아이콘 행 UI 추가 (안내 문구 + 인스타/유튜브/틱톡 아이콘 + 각 라벨)
- 각 채널 실제 URL 연결 및 탭 시 외부 브라우저 이동 처리
- 안내 문구·채널 라벨 등 사용자 노출 텍스트 다국어(ko/en/ja) 추가
- 링크를 열 수 없는 경우(설치된 브라우저 없음 등)에 대한 예외 처리
