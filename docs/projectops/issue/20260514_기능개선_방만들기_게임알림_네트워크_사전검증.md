## 제목

🚀 [기능개선][Flutter][설정] 게임 알림 토글 실패 처리 통일 (`AppException.message` 활용)

## 본문

## 📝 현재 문제점

- 게임 알림 토글의 `catch` 블록이 `catch (_)`로 예외를 통째로 버리고 "게임 알림 설정을 변경하지 못했어요" 단일 메시지만 노출함
- 그 결과 네트워크 끊김/서버 오류/검증 실패가 같은 문구로 표시되어 사용자가 원인을 구분할 수 없음
- 이 한계를 보완하려고 호출 직전에 `ConnectivityService.isConnected()` 사전 검증을 두었지만, 다른 화면들은 모두 `e is AppException ? e.message : 기본메시지` 패턴으로 일관 처리하고 있어 게임 알림 토글만 처리 방식이 어긋남

## 🛠️ 해결 방안 / 제안 기능

- 게임 알림 토글의 사전 검증 블록을 제거하고, `catch (e)`에서 `AppException.message`를 그대로 노출함
- `DioExceptionHandler`가 이미 `NetworkException`·`ValidationException`·`ServerException` 등으로 분기해 사용자 메시지를 만들어 두므로, UI는 이를 통과시키기만 하면 됨
- 사유별 안내 문구가 자동으로 분기되고, 다른 화면들과 동일한 실패 처리 패턴으로 통일됨

## ⚙️ 작업 내용

- `lib/features/settings/presentation/pages/settings_page.dart` `_onGamePushToggle`:
  - `connectivityServiceProvider.isConnected()` 사전 검증 블록 제거
  - `catch (_)` → `catch (e)`로 변경하고 `message`에 `e is AppException ? e.message : '게임 알림 설정을 변경하지 못했어요'` 적용
- 사용하지 않게 되는 `core/network/connectivity_service.dart` import 정리
- 방 만들기·방 참가 등 다른 게임 진입 트리거의 실패 처리 점검은 별도 이슈에서 다룸
