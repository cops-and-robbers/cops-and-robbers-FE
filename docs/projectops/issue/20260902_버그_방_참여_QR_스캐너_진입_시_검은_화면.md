# ❗ [버그][Flutter][방참여] 방 참여 QR 스캐너 진입 시 검은 화면만 표시됨

## 🗒️ 설명

홈에서 **게임 참여하기 → 방 참여하기 다이얼로그 → 카메라 아이콘**을 누르면 QR 스캐너 대신 **화면 전체가 검게** 변한다. 뒤로 가기로도 복구되지 않아 앱을 강제 종료해야 한다.

카메라 권한 요청조차 뜨지 않아서 카메라 문제처럼 보이지만, 실제로는 **카메라에 도달하기 전에 내비게이션이 무너지는** 문제다.

**원인**

카메라 아이콘의 `onTap`은 다이얼로그를 닫으려고 `Navigator.of(context).pop()`을 부르는데, 이 `context`가 다이얼로그가 아니라 홈 페이지의 것이다. 그래서 내비게이터가 어긋난다.

- 다이얼로그는 **루트 내비게이터** 위에 떠 있다
- `Navigator.of(context)`는 가장 가까운 내비게이터인 **StatefulShellRoute 브랜치 내비게이터**를 잡는다
- 브랜치에는 홈 페이지 하나뿐이라, `pop()`이 다이얼로그 대신 **홈 페이지를 제거**한다
- 스택이 빈 채로 이어지는 스캐너 `push`도 무너진 내비게이터에 올라가 아무것도 안 그려진다

릴리즈 빌드는 이 상황에서 아무 로그 없이 검은 화면만 남는다. 디버그 빌드로 재현하면 원인이 그대로 찍힌다.

```text
'package:go_router/src/delegate.dart': Failed assertion:
'currentConfiguration.isNotEmpty': You have popped the last page off of the stack,
there are no pages left to show
#7  _HomePageState._showJoinRoomDialogInternal.<anonymous closure> (home_page.dart:464)
```

## 🔄 재현 방법

1. 홈에서 **게임 참여하기** 탭
2. 방 참여하기 다이얼로그에서 입력 칸 오른쪽 **카메라 아이콘** 탭
3. QR 스캐너 대신 검은 화면 표시, 뒤로 가기로 복구 불가

## ✅ 예상 동작

- 카메라 아이콘을 누르면 다이얼로그만 닫히고 QR 스캐너가 열려야 한다
- 카메라 권한이 없으면 권한 요청 다이얼로그가 떠야 한다
- 스캔한 초대코드로 방 참여 플로우가 이어져야 한다

## ⚙️ 환경 정보

- Android / iOS 공통 (내비게이션 구조 문제라 기기와 무관하게 항상 재현)
- 에뮬레이터 Android API 36.1에서 재현·검증
