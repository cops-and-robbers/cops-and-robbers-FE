## 본문

## 📝 현재 문제점

- 대기방 화면에서 아직 입장하지 않은 슬롯을 "대기중" 카드로 표시하고 있음
- 빈 슬롯을 시각적으로 채우는 용도였으나, 실제 참가자 구분에 혼란을 주고 화면 구성을 복잡하게 만듦
- 참가자 카드와 구분이 명확하지 않아 UX 측면에서 개선 필요

## 🛠️ 해결 방안 / 제안 기능

- 대기방에서 "대기중" 카드 노출 제거
- 실제 입장한 참가자만 카드로 표시
- 빈 슬롯 영역은 자연스럽게 처리 (여백 또는 안내 문구로 대체)

## ⚙️ 작업 내용

- 대기방 화면에서 대기중 카드 렌더링 로직 제거
- 참가자 리스트 레이아웃 재정렬
- 빈 슬롯 표시 방식 정리 (필요 시 디자인 확인)
