## 제목

❗ [버그][iOS][권한][i18n] App Store 심사 거부 — 권한 요청 문구가 앱 현지화 언어와 불일치

## 본문

## 🗒️ 설명

- App Store 심사(Guideline 4 - Design)에서 거부됨
- 앱의 권한 요청(permission request) 문구가 앱 현지화 언어와 동일한 언어로 작성되어 있지 않다는 지적
- 사용자가 보는 권한 요청 다이얼로그 문구(위치, 알림 등)가 디바이스/앱 언어 설정과 일치하지 않아 저품질 UX로 판단됨
- iPad(iPad Air 11-inch M3) 환경에서 확인됨

## 🔄 재현 방법

1. 디바이스 언어를 영어(또는 한국어 외 언어)로 설정
2. 앱 실행 후 위치/알림 등 권한 요청 다이얼로그 노출 시점까지 진행
3. 권한 요청 문구가 앱 현지화 언어와 일치하지 않는 것을 확인
