# ⚙️ [기능추가][Flutter][알림] 인게임 FCM 채팅 알림 탭 연동

## 📝 현재 문제점

BE PR #202에서 인게임 채팅 FCM 발송이 추가됐지만, 앱은 `CHAT` 푸시를 탭해도 해당 게임의 전체/팀 채팅으로 연결하지 않는다. API 문서는 작업 트리에서 v2.34.0으로 갱신된 상태다.

| 서버 payload | 값 | 의미 |
|---|---|---|
| `type` | `CHAT` | 인게임 채팅 알림 |
| `gameId` | 문자열 게임 ID | 알림이 발생한 게임 |
| `scope` | `ALL` / `TEAM` | 전체 / 팀 채팅 |

title은 발신자 닉네임, body는 채팅 내용이다. 발신자를 제외하고 `allowGamePush`와 팀 조건을 적용해 전송한다. 메시지 ID는 포함하지 않는다.

<br>

## 🛠️ 해결 방안 / 제안 기능

인게임 채팅 푸시를 탭하면 인증·참가 상태를 확인한 뒤 해당 게임의 채팅 화면과 전체/팀 채널을 연다. 이미 같은 게임에 있으면 기존 화면에서 채팅을 열어 중복 화면을 만들지 않는다.

> [!IMPORTANT]
> 콜드 스타트는 활성 게임 복구가 일반 푸시 목적지 처리보다 먼저 실행된다. 목적지 파서뿐 아니라 게임 복구 분기에도 채팅 진입 의도를 전달해야 한다.

기존 #312의 전경 시스템 알림 억제를 유지한다. FCM 내용을 STOMP 채팅 이력이나 미읽음 카운트에 별도로 추가하지 않는다. 커뮤니티 `postId`·방별 음소거 계약은 적용하지 않는다.

<br>
