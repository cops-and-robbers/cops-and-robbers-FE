## 제목

🚀 [기능개선][Flutter][크레딧] 크레딧 인원 추가 및 기여도별 색상 차별화

## 본문

## 📝 현재 문제점

- 현재 크레딧 화면에 표시되는 인원이 부족하여 실제 프로젝트 기여자가 모두 노출되지 않음
- 모든 멤버가 동일한 스타일로 표시되어 기여도 차이를 시각적으로 인지하기 어려움

## 🛠️ 해결 방안 / 제안 기능

- 누락된 기여자를 크레딧 멤버 목록에 추가
- 기여도가 높은(많이 참여한) 멤버는 다른 색상으로 표시하여 차별점 부여
- 기여도 등급 기준을 정의하고, 등급별 카드/텍스트 색상을 다르게 적용

## ⚙️ 작업 내용

- 추가할 크레딧 멤버 데이터 정리 및 등록
- 기여도 등급 분류 기준 정의 (예: 핵심 기여자 / 일반 기여자)
- 등급별 색상 디자인 적용 (멤버 카드 또는 이름 강조)
- 크레딧 페이지 및 상세 페이지에 일관되게 반영
