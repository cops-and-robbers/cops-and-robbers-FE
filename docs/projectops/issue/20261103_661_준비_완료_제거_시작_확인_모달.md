📝 현재 문제점
---

- 네 번의 QA 모두에서 준비 완료가 불필요했습니다. 방장이 준비하지 않은 사람을 찾아다니는 시간만 들었습니다.
- 지금은 앱과 서버 모두 방장 외 전원이 준비해야 시작할 수 있습니다.

🛠️ 해결 방안 / 제안 기능
---

DEC-0117대로 바꿉니다.

- 참가자의 준비, 준비 취소 버튼과 준비 상태 표시를 없앱니다.
- 시작 권한은 방장에게 둡니다.
- 방장이 시작을 누르면 확인 모달이 뜨고, 모달 안에서 3-2-1을 센 뒤에야 시작 버튼이 켜집니다. 잘못 눌러 시작하는 일을 막기 위해서입니다.
- 팀 구성 검사 같은 나머지 시작 조건은 그대로 둡니다.

⚙️ 작업 내용
---

앱
- 대기방 하단 버튼을 방장 시작 버튼 하나로 정리
- 확인 모달과 3-2-1 카운트 추가, 문구 3개 언어 추가
- 준비 상태 표시, 호출, 관련 에러 문구 정리
- 준비 중 팀 슬롯 변경을 막던 조건 정리

서버 (앱이 필요한 동작을 전달하고 BE가 구현)
- 게임 시작 검사에서 전원 준비 조건 제거
- 구버전 앱 호환 처리

❓ 확인 필요
---

| 안건 | 제안 | 이유 |
|---|---|---|
| 구버전 앱 방장 | 참가 때 서버가 준비 상태를 기본 완료로 두고 준비 API는 당분간 유지 | 구버전 앱은 앱 안에서도 전원 준비를 검사함. 새 앱 참가자는 준비를 누르지 않으므로 구버전 방장의 시작 버튼이 계속 꺼짐 |
| 팀 변경 시 준비 해제 | 서버에서 함께 제거 | 지금 서버는 팀을 바꾸면 준비를 해제함. 이 동작이 남으면 구버전 방장이 다시 막힘 |
| 최소 버전 상향 | 위 호환 처리가 안 되면 Remote Config로 상향 | 혼용 기간에 방 시작이 막히는 것을 방지 |
| 이벤트 게임 | 확인 모달은 함께 적용하고 나머지는 현행 유지 | 이벤트 방은 지금도 준비, 인원 검사가 없음. 모달이 부스 운영을 늦추지 않는지 확인 필요 |
| 모달 중 인원 변화 | 시작 때 서버 검사 결과를 기존 에러로 표시 | 3초 사이 참가자가 나갈 수 있음 |
