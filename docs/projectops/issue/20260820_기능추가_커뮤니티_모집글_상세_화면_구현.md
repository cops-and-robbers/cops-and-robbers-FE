## 📝 현재 문제점

- 모집글 목록(#475)에서 카드를 눌러도 들어갈 화면이 없어 글 내용을 끝까지 볼 수 없음
- 백엔드에 단건 조회·수정·삭제·모집 상태 변경 API가 준비되어 있으나 클라이언트에 연동되지 않음
- 모임 장소가 좌표로만 저장되어 있어 사용자가 위치를 지도로 확인할 방법이 없음

## 🛠️ 해결 방안 / 제안 기능

- 모집글 상세 화면 구현
- 작성자 본인 글의 수정·삭제·모집 상태 변경 연동

## ⚙️ 작업 내용

- 상단 지도 미리보기 — 조작 없는 정지 상태, 탭하면 전체 화면 지도로 확대
- 본문 영역 — 모집 상태, 참여 인원, 제목, 장소, 모임 일시, 내용
- 좋아요·스크랩·공유 3분할 액션
- 채팅 참여하기 버튼
- 댓글 목록과 댓글 입력창 (답글 포함)
- 더보기 메뉴 3갈래 분기 — 내 글(수정·삭제·모집 상태 변경) / 남의 글(신고하기) / 비로그인(로그인 유도)
- 목록 카드의 더보기 메뉴를 상세와 공용으로 쓰도록 위젯 추출
- 삭제·상태 변경 성공 시 목록 갱신
- 화면 문구 다국어 처리 (ko/en/ja)

## 📌 참고

- 좋아요·스크랩·댓글·참여 인원·게시글 신고는 백엔드 단계가 남아 있어 목데이터로 먼저 만든다. 목록 화면과 같은 방식이며 API가 열릴 때마다 하나씩 교체한다
- 채팅 참여하기가 게시글 단위 채팅인지 별도 채널인지 아직 확정되지 않았다. 피그마 와이어프레임 확인 후 연결한다
- 수정은 장소 선택용 지도 UI가 없어 기존 좌표를 그대로 재전송한다. 장소 변경은 지도 선택이 붙을 때 연다
- 상세 조회는 비로그인 공개이므로 로그인 여부에 따라 화면이 갈린다
- 백엔드 요청이 필요한 항목 — 댓글 작성자 아바타 필드, 모집글 상세 장소 입력 필드
- 백엔드 스웨거가 아직 2.15.0이라 커서 페이지네이션·주소 3종은 노션 스펙을 정본으로 삼는다
