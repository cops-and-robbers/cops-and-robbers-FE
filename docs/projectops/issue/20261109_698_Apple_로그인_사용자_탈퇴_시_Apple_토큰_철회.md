📝 현재 문제점
---

- 앱에서 회원 탈퇴를 해도 Apple 로그인 토큰을 철회하지 않습니다.
- Apple은 Sign in with Apple을 쓰는 앱이 계정을 삭제할 때 토큰을 철회하도록 안내하고 있습니다.
- 탈퇴 흐름의 현재 코드는 다음과 같습니다.

  | 단계 | 위치 | 동작 |
  |---|---|---|
  | 1 | `my_page.dart` `_executeDeleteAccount` | `deleteAccountUseCase` 호출 |
  | 2 | 백엔드 `UserService.deleteAccount` | DB 정리, `firebaseAuth.deleteUser` |
  | 3 | `auth_provider.dart` `cleanupAfterAccountDeletion` | Firebase `signOut`, 토큰 삭제 |

- 위 흐름 어디에도 철회 호출이 없고, 백엔드는 Apple 토큰을 저장하지 않습니다. Firebase 사용자 삭제와 Apple 토큰 철회는 별개의 동작입니다.
- 이 상태로 4.0.1까지 출시되어 있어서 **긴급 배포는 필요 없고, 다음 앱 업데이트에 포함**하면 됩니다.

🛠️ 해결 방안 / 제안 기능
---

- Apple 로그인 사용자가 탈퇴할 때 Apple 인증을 한 번 더 받아 `authorizationCode`를 얻고, 백엔드 탈퇴를 호출하기 전에 철회합니다.
- 철회는 Firebase 계정이 살아 있을 때 해야 합니다. 백엔드가 Firebase 사용자를 먼저 지우면 철회할 수 없습니다.
- 로그인 때 받은 `authorizationCode`는 저장하지 않으므로 탈퇴 시점에 새로 받습니다.
- Apple 로그인 버튼은 iOS에서만 노출되므로(`login_page.dart`) Android와 Google 로그인 사용자의 흐름은 바뀌지 않습니다.

#### 변경 후 흐름

```
탈퇴 확인 ('delete' 입력)
  → 진행 중인 게임 확인 (GET /api/user/me/game)
     └ 있으면 안내하고 중단
  → Apple 사용자면 Apple 인증 → revokeTokenWithAuthorizationCode
     └ 취소하거나 실패하면 중단 (탈퇴하지 않음)
  → AppLoading 표시 → DELETE /api/user/me
  → 기존 정리 (cleanupAfterAccountDeletion, 로그인 화면 이동)
```

#### 순서를 이렇게 잡은 이유

| 경우 | 처리 |
|---|---|
| 철회 뒤 탈퇴가 409로 실패 | Apple 연결만 끊기고 계정이 남으므로, 철회 전에 진행 중인 게임을 확인합니다 |
| Apple 인증 창에서 취소 | 탈퇴하지 않고 다이얼로그 흐름을 끝냅니다 |
| Apple 인증 창과 로딩 | 인증 창이 먼저 떠야 하므로 `AppLoading`은 철회 뒤에 띄웁니다 |

#### 구현 예시

`FirebaseAuthDataSource`

```dart
/// Apple 로그인 사용자의 토큰 철회
///
/// Firebase 계정이 살아 있을 때 호출해야 하므로 백엔드 탈퇴 전에 수행합니다.
/// Apple 로그인이 아니면 아무것도 하지 않습니다.
Future<void> revokeAppleTokenIfNeeded() async {
  final isAppleUser = _firebaseAuth.currentUser?.providerData.any(
        (info) => info.providerId == 'apple.com',
      ) ??
      false;
  if (!isAppleUser) return;

  final credential = await SignInWithApple.getAppleIDCredential(scopes: const []);
  await _firebaseAuth.revokeTokenWithAuthorizationCode(credential.authorizationCode);
}
```

- 사용자 취소는 `signInWithApple`과 같이 `ERROR_ABORTED_BY_USER`로 변환해서 조용히 끝냅니다.
- 그 밖의 실패는 기존 `AppException` 처리로 스낵바를 띄우고 탈퇴를 진행하지 않습니다.

⚙️ 작업 내용
---

- `FirebaseAuthDataSource.revokeAppleTokenIfNeeded` 추가
- `_executeDeleteAccount` 앞단에 진행 중인 게임 확인과 토큰 철회 추가
- `AppLoading` 표시 시점을 철회 뒤로 이동
- 철회 실패 안내 문구 추가 (한국어, 영어, 일본어)
- 테스트 추가
  - Apple 사용자는 탈퇴 API 호출 전에 철회한다
  - Google 사용자는 철회를 호출하지 않는다
  - Apple 인증을 취소하면 탈퇴 API를 호출하지 않는다
  - 진행 중인 게임이 있으면 철회와 탈퇴를 호출하지 않는다
- iOS 실기기 확인: 탈퇴 후 설정 > Apple 계정 > Apple로 로그인 목록에서 앱이 사라지는지 확인
