## 📝 현재 문제점

- 마지막 단계 안내 문구의 "추천값"이 개발자 말투로 읽힌다 (디자인 의견)
- `방 만들기` 버튼을 누르면 확인 없이 바로 방이 만들어져, 모드와 세부 설정을 다시 볼 틈이 없다
- 앱 토글은 Material 3 `Switch` 기본 동작이라 꺼지면 손잡이가 작아진다. 디자인에서는 켜짐·꺼짐 모두 같은 크기 손잡이를 쓴다
- 공용 다이얼로그(모서리 16)와 따로 만든 모달(모서리 24, 여백·제목 크기 제각각)의 모양이 달라 화면마다 다이얼로그가 다르게 보인다
- 플레이그라운드를 핀으로 그리다 뒤로 가면 이탈 확인이 떠 흐름이 끊긴다

<br>

## 🛠️ 해결 방안 / 제안 기능

### 1. 안내 문구 변경

- 대상 키: `sessionCreationStepReviewHint` (`lib/l10n/app_ko.arb:895`)
- 사용처: `session_creation_flow_page.dart:972`

### 2. 방 생성 전 확인 모달

| 요소 | 문구 |
|---|---|
| 제목 | 이대로 방을 생성할까요? |
| 설명 | 게임 모드와 세부 설정을 확인했나요? 현재 설정으로 방을 생성해요 |
| 왼쪽 버튼 | 다시 확인 (모달만 닫힘) |
| 오른쪽 버튼 | 방 생성하기 (지금의 생성 흐름 그대로 진행) |

- 지금 흐름: `방 만들기` 버튼 → `_createSessionAndNavigate()` 바로 호출 (`session_creation_flow_page.dart:1017`, `:399`)
- 모달은 공용 다이얼로그(`lib/core/widgets/dialogs/app_dialog.dart`)로 띄운다

### 3. 토글 꺼짐 손잡이 크기 통일

| 위치 | 파일 |
|---|---|
| 마이페이지 게임 알림·커뮤니티 알림 | `lib/features/mypage/presentation/pages/my_page.dart` |
| 방 생성 구역 축소 | `lib/features/session/presentation/widgets/shrink_toggle_card.dart` |

### 4. 다이얼로그 규격 통일 (모달_GUI)

| 항목 | 값 |
|---|---|
| 화면 좌우 여백 | 36 |
| 카드 모서리 / 안쪽 여백 | 24 / 24 |
| 제목 / 설명 | 18 / 14 |
| 제목 → 설명 / 설명 → 버튼 | 8 / 24 |
| 버튼 | 높이 48 · 모서리 12 · 사이 8 · 글자 16 |

- 공용 다이얼로그(`AppDialog`)와 따로 만든 모달 7개(재연결·공용 팝업·게임 종료 인트로·게임 결과·QR·이벤트 검거 성공·이벤트 결과 보드)가 같은 카드 틀을 쓴다
- 호출하는 쪽에서 제목 크기·간격을 따로 지정하던 4곳도 기본값을 따른다

### 5. 플레이그라운드 이탈 확인 제거

- `setup_playground_page.dart` 뒤로 가기에서 확인 다이얼로그를 띄우지 않는다. 감옥 단계의 확인은 유지
