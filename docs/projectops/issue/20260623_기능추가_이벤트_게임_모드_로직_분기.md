## 본문

## 📝 현재 문제점

- 행사장용 이벤트 게임 모드(운영진=도둑 고정 타겟, 사용자=경찰)가 아직 구현되어 있지 않음
- QR 입장 시 대기실/준비 단계 없이 바로 인게임으로 직행하는 플로우가 없음
- 운영진(도둑)이 잡혀도 감옥에 가지 않고 계속 도망가는 이벤트 전용 동작이 없음
- `isEventGame` 분기에 따른 라우팅, UI, 체포 카운트 처리가 부재함
- 참고: `docs/EVENT_GAME_spec.md` (프론트엔드 검토 완료본)

## 🛠️ 해결 방안 / 제안 기능

- `join` 응답의 `isEventGame` 값에 따라 로비를 스킵하고 인게임 화면으로 바로 이동
- 중간 입장자를 위한 부트스트랩 처리 (게임 설정 / 게임 영역 / 참가자 상태를 기존 조회 API로 채움)
- 체포 카운트 및 재체포 방지를 로컬에서 처리하고 영속화 (재접속 시에도 유지)
- 운영진(도둑) ALIVE 상태 UI 분기 (감옥 잠금 오버레이·탈옥 버튼 비활성)
- 경찰 체포 성공 피드백 및 잡은 운영진 "검거됨" 표시
- 이벤트 모드 종료 조건 차이 반영 및 결과 화면을 로컬 카운트("운영진 N명 검거") 기준으로 표시
