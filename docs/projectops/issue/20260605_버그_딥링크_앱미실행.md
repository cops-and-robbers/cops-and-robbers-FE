## 🗒️ 설명

- 게임 초대 딥링크(https://copsnro66ers.site/join/{초대코드})를 클릭하면, 앱이 설치되어 있을 경우 앱이 실행되어 해당 초대 코드의 방으로 입장해야 한다.
- 그러나 앱이 설치되어 있는 상태에서도 앱이 실행되지 않고, 앱스토어 / 플레이스토어로만 이동한다.
- 앱이 미설치된 상태에서 스토어로 이동하는 동작은 정상적으로 작동한다.

## 🔄 재현 방법

1. 앱이 설치된 기기에서 초대 링크(예: https://copsnro66ers.site/join/TQD23J) 클릭
2. 앱이 실행되어 초대 코드(TQD23J) 방으로 자동 입장하는지 확인
3. 앱이 실행되지 않고 앱스토어 / 플레이스토어로 이동되는 현상 확인
