## 🔥 구현 기능

방 입장 튜토리얼 끝에 **추가 기능 장면 두 개(무전 · 좌표)**를 넣고, **필수 장면을 다 본 뒤부터 건너뛰기**를 켠다.

| 순서 | 장면 | 건너뛰기 (처음 볼 때) |
|---|---|---|
| 필수 | 구역 → 지도 → 추격 → QR → 스캔 → 감옥 → 구출 → 탈옥 → 축소 (술래잡기는 감옥·구출·탈옥 대신 탈락) | 없음 (지금과 같음) |
| 추가 기능 | **무전** → **좌표** | **있음** (축소 장면 다음부터) |
| 마무리 | "이제 시작하러 가볼까요?" | 있음 |

장 수: 경찰과 도둑 10 → 12장, 술래잡기 8 → 10장. 다시 볼 때는 지금처럼 처음부터 건너뛸 수 있다.

<br>

## 📝 현재 문제점

- 무전은 누르는 동안만 말하고 한 번에 한 명만 말할 수 있는데, 앱 어디에도 사용법 안내가 없다.
- 좌표 격자(메뉴 "좌표")를 켜고 핑을 찍으면 칸 이름이 팀 채팅으로도 가는데("C3에서 도둑을 봤어요"), 이 기능도 안내가 없어 사람들이 모른다. 격자는 게임마다 꺼진 채로 시작해 모르면 쓸 일이 없다.
- 핑(지도 길게 누르기) 자체는 시작 장면 규칙 카드(`chase_scene_rules.dart`)와 게임 규칙(`game_rules_content.dart`)에 이미 있다.

<br>

## 🛠️ 해결 방안 / 제안 기능

### 무전 장면

- 제목: **경찰만 무전기를 쓸 수 있어요** (술래잡기: 술래만 무전기를 쓸 수 있어요)
- 본문: 버튼을 길게 누르는 동안 말해요 / 한 번에 한 명만 말할 수 있어요
- 그림: 무전 버튼을 누르면 파랗게 차고 커진다 → 다른 경찰이 먼저 말하면 "의민 무전 중" 알약이 뜨고 내 버튼이 잠긴다 (실제 `RadioPttButton`·`RadioSpeakerPill` 모습)
- 튜토리얼은 역할을 모르고 열리므로(모드별 1회) 도둑도 같은 장면을 본다. 문구로 "경찰만"을 알린다.

### 좌표 장면

- 제목: **좌표로 위치를 알려요**
- 본문: 메뉴에서 좌표를 켜고 지도를 길게 누르면 / 칸 이름이 팀 채팅으로도 가요
- 그림 (QR 체포 장면처럼): + 메뉴를 열고 "좌표"를 누른다 → 격자와 칸 이름이 켜지고 C3를 길게 누르면 핑 카드 → "발견"을 고르면 핑이 찍히고 팀 채팅에 "C3에서 도둑을 봤어요"
- 좌표·핑은 도둑도 쓰므로 "경찰만"을 넣지 않는다.

### 건너뛰기

- 처음 볼 때는 축소 장면까지 건너뛰기가 없고, 무전 장면부터 나타난다.

> [!IMPORTANT]
> 문구는 초안이다. ko·en·ja ARB에 넣고 `python3 docs/i18n/_lint_tone.py`로 톤을 검사한다.
