## 🔥 구현 기능

무전 서버가 혼잡해 서버가 `503 RADIO_SERVER_BUSY`를 줄 때, 앱이 이유를 알려 주고 풀리면 다시 연결됐다는 것도 알린다.

| 항목 | 정한 것 |
|---|---|
| 혼잡 안내 | 막힌 순간 스낵바 한 번. 회색 무전 버튼을 누르면 같은 문구를 다시 띄운다 |
| 버튼 | 혼잡한 동안 무전 버튼은 눌리지 않는다(회색) |
| 다시 연결 | 지금처럼 10초마다 다시 시도한다. 연결되면 스낵바 한 번 |
| 문구(초안) | 혼잡: "지금 무전 사용자가 많아요\n혼잡이 풀리면 자동으로 연결돼요" / 복구: "무전이 연결됐어요" (ko·en·ja) |

<br>

## 📝 현재 문제점

- BE #253(v4.4.0)으로 무전 서버 CPU가 높으면 새로 무전에 들어오는 경찰의 토큰 발급이 `503 RADIO_SERVER_BUSY`로 거절된다. 혼잡이 풀리면 같은 요청이 다시 성공한다.
- 앱은 이 코드를 모른다. `radio_session_provider.dart`의 `_issue()`는 종료 코드와 `RADIO_POLICE_WAITING_TIME`만 따로 다루고, 나머지 실패는 "연결 중"인 채 10초마다 다시 시도한다.
- 그래서 사용자에게는 무전 버튼이 회색인 채 아무 설명이 없다. 버튼을 눌러도 출동 대기일 때만 이유를 알려 준다(`game_page.dart` `_explainBlockedRadio`).
- 풀려서 연결돼도 알림이 없어 다시 된다는 걸 모른다.
- `docs/api-docs.json`이 v4.0.0이라 새 에러 코드가 문구 검사(`api-docs errorCode coverage`)에 잡히지 않는다.

<br>

## 🛠️ 해결 방안 / 제안 기능

- `RADIO_POLICE_WAITING_TIME`을 처리한 것과 같은 틀로 간다: 전용 상태 하나, 다시 시도, 눌렀을 때 안내.
- "무전기를 꺼 주세요" 같은 안내는 하지 않는다. 막힌 사람은 아직 무전에 못 들어온 사람이라 꺼도 줄어드는 부하가 없다.
- 문구에 경찰·술래가 들어가지 않아 모드별 문구는 필요 없다.
- BE #259(판 단위 판정)가 들어오든 말든 앱 작업은 같다.

<br>
