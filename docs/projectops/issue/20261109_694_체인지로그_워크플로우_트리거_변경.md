🗒️ 설명
---

- GitHub이 2026-12-02부터 공개 레포의 `pull_request_target` 트리거를 기본으로 제한한다고 안내했다. 지금은 Actions 실행 시 경고만 나온다.
- `.github/workflows/PROJECT-COMMON-AUTO-CHANGELOG-CONTROL.yaml`이 이 트리거를 쓰고 있어서, 그냥 두면 12/2 이후 deploy PR을 열어도 체인지로그 갱신과 자동 머지, 배포 트리거가 돌지 않는다.
- 이참에 트리거 조건도 GitHub 권장 방식대로 좁힌다.
- 같은 실행에서 `actions/upload-artifact@v4`, `actions/download-artifact@v4`가 Node.js 20 지원 종료로 Node.js 24에서 강제 실행된다는 경고도 나온다. 함께 올린다.

🔄 재현 방법
---

1. deploy 브랜치로 PR을 연다.
2. Actions 실행 로그에서 `pull_request_target` 정책 경고를 확인한다.

📸 참고 자료
---

- 경고 문구: `On December 2, 2026, GitHub will restrict pull_request_target on public repositories by default.`
- https://gh.io/securely-using-pull_request_target
- 경고 문구: `Node.js 20 is deprecated. The following actions target Node.js 20 but are being forced to run on Node.js 24: actions/upload-artifact@v4.` (download-artifact@v4도 동일)
- https://github.blog/changelog/2025-09-19-deprecation-of-node-20-on-github-actions-runners/

✅ 예상 동작
---

- 트리거를 `pull_request`로 바꾸고, 같은 레포 안에서 연 PR에서만 실행되게 한다.
- artifact 액션을 Node.js 24 기반 버전(`upload-artifact@v7`, `download-artifact@v8`)으로 올려 경고가 사라진다.
- `main → deploy` 배포 PR은 지금처럼 체인지로그 갱신, 자동 머지, 배포 트리거까지 이어진다.
