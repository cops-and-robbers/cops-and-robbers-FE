# 🚀 [기능개선][Flutter][커뮤니티] 커뮤니티 목록 정렬에 인기순 노출

## 🗒️ 설명

커뮤니티 목록의 정렬 시트에서 인기순을 노출한다.

현재 상태:

- 정렬 시트(`community_sort_sheet.dart`)가 인기순을 의도적으로 숨기고 있다 — 구현 당시 서버가 `sort=POPULAR`에 `400 UNSUPPORTED_LIST_SORT`를 줬기 때문 (DEC-0020: 파라미터는 먼저 열고 미구현 값만 400).
- 이후 BE #175(Swagger v2.24.0)가 인기순을 구현했다 — 점수 = 좋아요×1 + 스크랩×2 + 채팅 참여 멤버×3, 최근 7일 글만 대상, 마감 글은 맨 뒤. `main`에도 포함돼 배포 게이트가 열려 있다.
- FE는 enum·와이어 매핑(`POPULAR`)·라벨(ko/en/ja)·에러 매핑까지 이미 갖춰져 있어, 시트 노출만 되돌리면 된다.

## 🛠️ 작업 내용

1. `community_sort_sheet.dart` — `_order`에 `CommunitySortOption.popular` 추가 (최신순 다음)
2. 시트 고정 높이 270 → 355 상향 (항목 4개 기준 위젯 테스트 실측)
3. "POPULAR는 400" 낡은 주석 갱신 — `community_sort_option.dart` · `community_provider.dart` · `community_remote_datasource.dart` · `error_message_mapper.dart` · `community_wire.dart`
4. 테스트 반전 — `hides_popular_option...` → `shows_all_four_options_when_sort_sheet_opens`

## ✅ 예상 동작

- 정렬 시트에 최신순·인기순·거리순·마감 임박순 4개 항목이 뜬다
- 인기순 선택 시 `GET /api/community-posts?sort=POPULAR`로 첫 페이지부터 다시 조회된다
- 좌표는 기존 가드 그대로 거리순에만 실린다 — 인기순은 좌표 없이 호출
- `flutter analyze` 이상 없음, 커뮤니티 + i18n 테스트 통과

## 📌 참고

- 인기순 점수에서 가중치가 가장 큰 채팅 참여 인원이 목록 카드에 안 보여 순위가 어색해 보일 수 있다 — 서버 목록 응답에 참여 인원 필드가 없어(BE #187의 4필드에도 미포함) 카드 노출은 BE 선행이 필요한 별도 건으로 범위에서 뺐다.
