## 본문

## 📝 현재 문제점

- 바텀 네비게이션의 커뮤니티 탭이 준비중 placeholder 화면으로만 되어 있어 실제 기능이 없음
- 백엔드에 모집 게시글 API(/api/community-posts, v2.15.0)가 준비되어 있으나 클라이언트에 연동되지 않음

## 🛠️ 해결 방안 / 제안 기능

- 커뮤니티(모집 게시판) 화면 UI 구현
- 게시글 목록/상세/작성/수정/삭제 및 모집 상태 변경 API 연동

## ⚙️ 작업 내용

- 게시글 목록 화면 (무한 스크롤, 중복 항목은 id 기준 제거)
- 게시글 상세 화면
- 게시글 작성/수정 화면 (제목, 내용, 모임 일시, 장소, 모집 인원)
- 게시글 삭제
- 모집 상태 변경 (모집중 / 모집완료)
- 화면 문구 다국어 처리 (ko/en/ja)

## 📌 참고

- 목록은 현행 오프셋 방식(page/size) 기준으로 먼저 연동한다
- 백엔드가 커서 기반으로 전환하면 DataSource 쿼리 파라미터와 목록 프로바이더의 다음 페이지 필드만 교체한다 (화면 로직 변경 없음)
