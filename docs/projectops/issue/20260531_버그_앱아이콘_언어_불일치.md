## 제목

❗ [버그][Flutter][앱아이콘] 시스템 언어가 한국어일 때 첫 설치 시 런처 앱 아이콘이 영어로 표시됨

## 본문

## 🗒️ 설명

- 시스템 언어가 한국어이고 인앱 언어 설정이 "시스템 따름"인 상태에서, 앱을 처음 다운로드/설치하면 런처(홈 화면) 앱 아이콘이 영어(Primary) 버전으로 표시됨.
- 콜드 부팅 시점에 로케일에 맞는 앱 아이콘 적용이 안전하지 않은 타이밍에 1회만 시도되고, 실패해도 재시도되지 않아 발생하는 것으로 확인됨.
- 동일한 원인이 두 플랫폼에서 다르게 나타남:
  - iOS: 아이콘 교체가 "작업이 취소되었습니다"로 거부되어 영어 아이콘으로 고정됨. 설정 → 언어 → 시스템을 한 번 더 선택하면 그때서야 한국어 아이콘으로 정상 적용됨. (한 번 적용된 뒤에는 이후 실행에서 정상 유지되어, 첫 설치 때만 재현됨)
  - Android: 처음엔 영어 아이콘으로 떴다가, 앱이 갑자기 백그라운드로 전환(앱이 튕기는 듯한 동작)된 뒤 다시 확인하면 한국어 아이콘으로 바뀌어 있음.

## 🔄 재현 방법

1. 기기 시스템 언어를 한국어로 설정
2. 앱을 처음 설치(또는 삭제 후 재설치)하고 실행 — 인앱 언어 설정은 "시스템 따름" 기본 상태 유지
3. 홈 화면(런처)에서 앱 아이콘 확인 → 영어(Primary) 아이콘으로 표시됨
4. 플랫폼별 후속 현상 확인
   - iOS: 설정 → 언어 → 시스템 재선택 시 한국어 아이콘으로 정상 전환됨
   - Android: 영어로 떴다가 앱이 백그라운드로 전환된 뒤 다시 보면 한국어 아이콘으로 바뀌어 있음

## ✅ 예상 동작

- 시스템 언어가 한국어인 상태에서 앱을 처음 설치하면, 별도 조작(설정 재선택)이나 앱 튕김 없이 한국어 아이콘이 자동으로 표시되어야 함.
- 인앱 언어가 가리키는 로케일과 런처 앱 아이콘이 항상 일치해야 함.
