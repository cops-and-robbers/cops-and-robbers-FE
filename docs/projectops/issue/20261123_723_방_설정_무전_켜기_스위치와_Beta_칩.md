## 🔥 구현 기능

방장이 방 설정에서 무전을 켜고 끈다. **기본값은 꺼짐**이고, 켠 방에서만 경찰에게 무전 버튼이 보인다. 무전 카드에는 Beta 칩을 붙인다.

| 항목 | 정한 것 |
|---|---|
| 위치 | 방 생성 화면과 대기방 설정. 구역 축소 카드와 같은 틀 |
| 기본값 | 꺼짐 |
| 대기방 | 방장이 대기방에서도 바꿀 수 있다 |
| Beta 칩 | 무전 카드 제목 옆에만. 인게임 무전 버튼에는 붙이지 않는다 |
| 인게임 | 서버가 준 값이 켜짐인 방에서만 경찰에게 무전 버튼 |
| 이벤트 게임 | 지금처럼 무전 없음 |

<br>

> [!IMPORTANT]
> 서버 작업(BE #260)이 먼저 필요하다. 방 설정에 `radioEnabled`가 생겨야 한다.

<br>

## 📝 현재 문제점

- 무전 켜짐이 앱 상수로 고정돼 있다(`lib/features/radio/domain/radio_rules.dart` `kRadioEnabledDefault = true`). 서버와 주고받는 값이 아니어서 방장이 고를 수 없고, 모든 일반 게임에서 경찰에게 무전 버튼이 나온다.
- 무전이 베타라는 표시가 앱 어디에도 없다.
- 나중에 유료로 바꿀 때 걸 자리가 없다.

<br>

## 🛠️ 해결 방안 / 제안 기능

- 방 설정 객체의 `radioEnabled`(boolean, 없으면 `false`)를 방 생성·설정 변경 요청에 넣고, 서버가 돌려준 값으로 무전 버튼을 보일지 정한다.
- `kRadioEnabledDefault` 상수는 없앤다.
- 끈 방에서 서버가 토큰을 거절하는 코드는 무전 종료 코드로 처리한다(다시 시도하지 않는다).
- 무전 카드에 한 줄 설명을 넣는다(문구는 시안에서).
- 화면은 ko·en·ja 시안을 먼저 만들어 이 이슈에 올린 뒤 진행한다.

<br>

- [ ] 대기방 설정에서 방장이 변경, 다른 참가자 화면에 반영

- [ ] 끈 방 거절 코드 처리와 문구
- [ ] 문구 ko·en·ja ARB
