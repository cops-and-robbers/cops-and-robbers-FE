## 🖌️ 요청 내용

대기방 **게임 설정 화면**의 맨 위 `모드 · 술래잡기` 행이 다크모드에서도 흰 카드로 나온다. 바로 아래 구역 축소 카드와 같은 다크 톤으로 맞춘다.

| | 현재 | 목표 |
|---|---|---|
| 배경 | `AppColors.white` (InfoCard 기본값) | 다크: `black900` |
| 테두리 | `black100` | 다크: `black800` |
| 라벨·값 글자 | `black800` / `black` 고정 | 다크: 흰 계열 (`ShrinkToggleCard`와 동일 토큰) |

<br>

## 🎯 기대 결과

- 게임 설정 화면(다크)에서 모드 행이 구역 축소 카드와 같은 톤으로 보인다
- 방 생성 확인 화면(라이트 전용)은 변하지 않는다

<br>

## 📋 참고

- 원인: `mode_row_card.dart`가 `InfoCard`에 `backgroundColor`·`borderColor`를 넘기지 않고 `isDarkMode` 파라미터도 없음
- 사용처: `game_settings_page.dart:323` (다크 지원 화면), `session_creation_flow_page.dart:997` (라이트 전용)
- 기준 구현: `shrink_toggle_card.dart`
- 관련: #696 (모드 행 도입, 닫힘)
