# ⚙️ [기능추가][게임][지도] 인게임 지도 좌표 격자 토글

## 🔥 구현 기능

인게임 지도에 **좌표 격자(예: "C3")를 켜고 끄는 버튼**을 단다. 팀원에게 "C3으로 가는 중"처럼 위치를 말이나 채팅으로 정확히 전할 수 있게 한다. 격자를 켠 상태에서 핑을 찍으면 그 칸이 **팀 채팅에도 자동으로** 올라간다.

| 항목 | 내용 |
|---|---|
| 버튼 | 좌측 하단 내 위치 버튼 위. 기본 꺼짐, 설정 저장 없음(게임마다 꺼진 상태로 시작) |
| 칸 크기 | 50·100·200·500·1000m 중 한 변이 12칸 이하가 되는 가장 작은 값 (작은 구역 50m, 기본 500m 구역 100m, 최대 1km 구역 200m) |
| 범위 | 원형·폴리곤 구역에 걸친 칸만 테두리와 라벨 표시 |
| 라벨 | 열은 서→동 A…, 행은 북→남 1…. 구역을 덮는 정사각형 기준으로 매겨 고정 — 구역 밖 칸은 빈자리 |
| 축소 시 | 한 칸이 화면에서 약 24pt보다 작아지면 라벨을 숨기고 선만 남김 |
| 핑 → 팀 채팅 | 격자를 켠 사람이 발견/의심 핑을 찍으면 "C3에서 도둑을 봤어요"처럼 팀 채팅에 내 이름으로 전송. 핑이 거부되거나 구역에 걸친 칸 밖이면 보내지 않고 (경계 칸은 구역 밖 부분도 그 칸 이름으로 보냄), 같은 칸·같은 종류는 10초 안에 한 번만 |

<br>

## 📝 현재 문제점

- 게임 중 "편의점 쪽으로 가는 중"처럼 말하면, 그 장소를 모르는 팀원은 어디인지 알 수 없다.
- 지도 핑(`ping_provider.dart`, 길게 누르기)은 "여기"를 2.5초 찍는 용도라 "어디로 가는 중"을 글·말로 전하지 못한다.

<br>

## 🛠️ 해결 방안

| 구역 반경 | 칸 크기 | 한 변 칸 수 |
|---|---|---|
| 100m | 50m | 4 |
| 300m | 50m | 12 (A–L) |
| 500m (기본값) | 100m | 10 (A–J) |
| 600m까지 | 100m | 최대 12 |
| 1km (최대) | 200m | 10 (A–J) |

| 영역 | 변경 |
|---|---|
| 격자 계산 (신규, 순수 Dart) | 구역 → 칸 크기·격자선·칸 라벨. 범위는 `AreaShape.boundingBox()`(`area_shape.dart:103`, 원형·폴리곤 모두 정사각형), 칸이 구역에 걸쳤는지는 칸 안의 여러 점을 `AreaShape.contains`(`area_shape.dart:38`)로 확인. 기준 반경은 `boundingRadiusInMeters`(`area_shape.dart:81`) |
| `google_map_view.dart` | 격자선은 `Polyline`, 라벨은 비트맵 마커(`PingMarkerFactory`처럼). `updateAreaCircles`(`google_map_view.dart:319`)와 같은 setter 방식. 카메라가 멈출 때 줌을 읽어 라벨 표시 여부 결정 |
| `game_page.dart` | 좌측 하단 내 위치 버튼 열(`game_page.dart:2540`)에 토글 버튼 추가 |
| 라벨 마커 | 켤 때 한 번 만들어 재사용 (반경 500m 원형이면 96개) |
| 색·문구 | 경찰(라이트)·도둑(다크) `AppColors` 토큰, 버튼 접근성 문구 ko/en/ja ARB |
| 핑 → 팀 채팅 (신규, 순수 Dart) | `ping_chat_policy.dart` — 보낼지·어느 칸인지 판정. `game_page.dart` 핑 선택(`_onSelectPing`) 뒤 기존 `ChatNotifier.sendMessage`(scope TEAM). 문구 4종(경찰/도둑 × 발견/의심) ko/en/ja, `docs/i18n/UX_WRITING.md` 기준 |

> [!IMPORTANT]
> 서버 변경은 없다. 모든 기기가 같은 구역 정보로 계산하므로 모두에게 같은 라벨이 뜬다.

<br>

## ❓ 확인 필요

- 칸 판정을 "칸 안의 여러 점"으로 하므로, 점 간격보다 가늘게 걸친 조각은 라벨이 안 붙을 수 있다. 실제로 문제가 되면 정확한 교차 계산으로 바꾼다.
- 라벨 마커 표시 성능(반경 500m 원형 96개)은 실기기에서 확인한다.
- 핑 → 채팅 연결은 테스트 환경의 가짜 지도가 핑 카드를 열지 못해 위젯 테스트가 없다. 실기기에서 확인한다.

<br>

## 📌 참고
