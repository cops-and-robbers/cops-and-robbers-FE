# 🚀 [기능개선][Flutter][방생성] 방 생성 v3 디자인 적용 및 생성 흐름 정리

## 📝 현재 문제점

- 생성을 누르면 바로 시작되지 않는다. 첫 화면이 버튼 두 개짜리 허브라 플레이그라운드 설정 버튼을 한 번 더 눌러야 지도가 뜬다. 플레이그라운드를 마치면 감옥으로 자동 연결되는데, 첫 진입만 허브를 거쳐 동선이 일관되지 않다
- 설정 네 개(인원, 게임 시간, 위치 공유 간격, 경찰 시작 시간)가 슬라이더로 두 화면에 나뉘어 있다. 숫자를 직접 입력하는 기능은 슬라이더 값을 탭해야 나오는 숨은 기능이다
- 위 두 가지를 코치마크 두 개("먼저 플레이그라운드를 지정하세요", "숫자를 탭하면 직접 입력할 수 있어요")가 말풍선으로 보완하고 있다. 화면이 스스로 설명하지 못한다는 뜻이다
- 어긋난 설정 조합(위치 공유 간격 ≥ 게임 시간, 경찰 시작 시간 ≥ 게임 시간)을 방 생성하기를 누른 뒤에야 서버 오류로 알게 된다

## 🛠️ 해결 방안 / 제안 기능

- 생성을 누르면 바로 플레이그라운드 지도로 들어간다. 이어서 감옥 지도, 기본 정보, 최종 확인 순서다. 진행 표시는 구역 / 기본 정보 / 확인 3칸
- 기본 정보는 한 화면에서 한 항목씩 묻고, 답한 항목이 아래로 쌓인다. 숫자 키패드는 화면 하단에 고정하고 항목별 빠른 추가 칩을 둔다
- 최종 확인이 수정 허브를 겸한다. 행을 탭하면 해당 화면으로 바로 이동해 고칠 수 있다
- 어긋난 조합은 입력 시점에 막는다. 게임 시간을 먼저 받으므로 뒤 항목의 상한이 그 자리에서 정해진다

## ⚙️ 작업 내용

- 공용 위젯: 숫자 키패드(빠른 추가 칩 포함), 항목 카드(활성·완료 상태), 키패드 위 전폭 버튼
- 기본 정보 화면 신설. 항목 순서는 인원, 게임 시간, 위치 공유 간격, 경찰 시작 시간
  - 기본값을 연한 색으로 채워 두고, 첫 숫자 입력 시 기존 값을 지우고 새로 시작한다
  - 빠른 추가 칩: 인원 +5/+10/+20, 게임 시간 +5/+10/+30, 위치 공유 +3/+5/+10, 경찰 시작 +1/+3/+5
  - 상한을 넘는 입력은 받지 않고, 카드 힌트와 더 무거운 진동으로 이유를 알린다
  - 완료 카드를 탭하면 그 항목을 제자리에서 다시 수정하고, 뒤로 가기는 맨 위 질문을 접는다 (탭 수정 중의 뒤로 가기는 수정 취소)
  - 위치 공유 간격 0의 "공유되지 않아요" 안내와 게임 시간 초과 경고는 카드 힌트 자리에 둔다
- 최종 확인 화면: 행마다 이동 표시를 붙이고, 설정 행은 해당 항목 활성 상태로, 구역 행은 해당 지도로 연다. 플레이그라운드를 다시 그리면 감옥 설정으로 자동 연결하고, 뒤로 가면 네 항목이 펼쳐진 기본 정보로 되돌아간다
- 생성 흐름 재배치: 허브(step 0) 제거, 생성 즉시 플레이그라운드 지도 진입. 지도 상단에 진행 표시(1/3)를 붙이고, 핀을 그리다 나갈 때만 이탈 확인을 띄운다
- 임시 저장: 숫자는 지금처럼 조용히 복원하고, 구역은 건너뛰지 않고 지도를 열 때 이전 도형을 그려 둔 채로 연다
- 대기실의 게임 설정 수정 화면도 카드 + 키패드 방식으로 전환한다 (스텝 위젯을 그대로 조립한 화면이라 함께 바뀐다)
  - 저장 버튼은 값이 유효한 동안 항상 활성이고, 바뀐 것이 없으면 호출 없이 닫는다 (닉네임 설정과 같은 방식)
- 생성 흐름 코치마크 2종 제거 (`createStep0`, `createStep2`). 지도 튜토리얼은 유지한다
- 아무 데서도 읽지 않는 게임 설정 상수(옛 인원·시간 한계값) 정리

## 📌 참고

- 인원 상한은 백엔드와 함께 150명으로 늘린다. 나머지는 그대로다: 인원 하한 2, 게임 시간 10~180분, 위치 공유 0~30분, 경찰 시작 1~10분
- 서버는 어긋난 조합을 이미 거절한다 (`INVALID_LOCATION_INTERVAL`, `INVALID_POLICE_WAIT_TIME`). 입력 시점 차단이 추가되어도 서버 검증은 안전망으로 그대로 둔다
- 지도 화면 자체는 손대지 않는다. 진행 표시 칸수만 맞춘다
- 다크 모드는 지금과 같이 대기실 수정 화면만 지원한다. 생성 흐름은 라이트 전용을 유지한다
- 다크는 앱의 기존 문법을 따른다: 어두운 면 + 초록 액센트, 밝은 초록 면은 주 버튼 하나, 값 표기는 Moneygraphy
- 색상과 라운드는 앱 팔레트 값과 일치하는 시안이 있다
