## 제목

## 본문

## 📝 현재 문제점

- 앱 실행 시 스플래시 화면에서 네트워크 연결 상태를 확인하지 않음
- 인터넷이 끊긴 상태에서도 앱이 그대로 진행되어, 이후 화면에서 API 호출 실패 등 예기치 못한 오류 발생
- 사용자 입장에서는 어디서부터 잘못된 것인지 파악하기 어렵고, 앱 품질에 대한 신뢰도 저하

## 🛠️ 해결 방안 / 제안 기능

- 스플래시 단계에서 네트워크 연결 상태를 먼저 점검
- 네트워크가 연결되지 않은 경우 이후 플로우(로그인, 홈 등) 진입을 차단
- 사용자에게 연결 상태를 안내하는 다이얼로그 또는 전용 화면 노출
- 재시도 버튼 제공: 다시 연결 상태를 점검하고 정상이면 스플래시 플로우 이어서 진행
- 연결 복구 시 자연스럽게 원래 진입 흐름으로 복귀

## ⚙️ 작업 내용

- 스플래시 단계에 네트워크 연결 상태 체크 단계 추가
- 오프라인 상태 전용 안내 UI 설계 및 적용
- 재시도 인터랙션 및 복구 플로우 정의
- 연결 상태 변화에 따른 화면 전환 시나리오 정리
