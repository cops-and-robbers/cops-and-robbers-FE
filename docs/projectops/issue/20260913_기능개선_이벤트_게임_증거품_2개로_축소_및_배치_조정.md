# 🚀 [기능개선][이벤트게임] 이벤트 게임 증거품 2개로 축소 및 배치 조정

## 📝 현재 문제점

회의에서 이벤트 게임 증거품을 2개로 조정했지만 앱에는 기존 3개 구성이 남아 있다. 증거보드는 3칸 콜라주이고 체포 성공 다이얼로그도 3번 증거품까지 표시한다.

<br>

## 🛠️ 해결 방안 / 제안 기능

| 대상 | 현재 | 변경 |
| --- | --- | --- |
| 진행·결과 증거보드 | 증거품 3칸, 하단에 3번 배치 | 기존 1·2번 증거품만 표시하고 두 칸을 가운데 배치 |
| 수집 상태 | 두 명을 검거해도 3번 칸 잠금 | 두 명 검거 시 두 칸 모두 공개 |
| 체포 성공 알림 | 증거 인덱스 상한 3, 3번 전용 확대 | 인덱스 상한 2, 3번 전용 확대 제거 |

실제 검거 인원 집계·중복 방지·재접속 복원은 유지한다. 기존 검거 기록이 2명을 초과해도 증거품은 2종만 표시한다. 작은 화면에서도 이미지가 겹치거나 다이얼로그를 벗어나지 않게 한다.

<br>
