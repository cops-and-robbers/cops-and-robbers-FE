## 🔥 회의에서 정할 것

클래식 외에 **게임 생성에서 고르는 새 모드**를 넣을지, 넣는다면 어떤 순서로 만들지 정해야 합니다. **인게임 + 메뉴 UI는 확정**했고, 그 외 규칙과 수치는 회의용 제안입니다.

| 모드 (가제) | 한 줄 설명 | 제안 순서 |
|---|---|---|
| AR 미션 | 서버가 뿌린 지점에 가서 카메라로 포착 | 1 |
| 좀비 | 숨은 첫 좀비를 피해 AR로 백신 수집 | 2 |

## 📝 현재 문제점

- 지금은 경찰과 도둑 규칙 하나뿐입니다.
- 도둑은 숨어서 버티는 전략이 유리할 수 있고, 밖으로 나올 이유를 주는 규칙이 없습니다.
- 위치 공개 소리처럼 "추후 게임 모드로 검토"하기로 미뤄 둔 아이디어도 넣을 자리가 없습니다.

## 🛠️ 제안 내용

### 인게임 UI 개편 (모드보다 먼저)

오른쪽 버튼에 모드 버튼까지 더하면 지도가 가려집니다. 가운데 아래 메뉴 버튼 하나로 묶고, 누르면 지도를 어둡게 하고 항목을 부채꼴로 펼칩니다. 클래식에도 함께 적용합니다.

| 버튼 | 지금 | 개편 후 | 이유 |
|---|---|---|---|
| QR | 오른쪽 | 메뉴 (기본 항목 맨 오른쪽) | 많이 쓰지만 잡을 때만 씀. #377에서 줄인 1탭이 2탭으로 되돌아감 |
| 내 위치 | 왼쪽 | 왼쪽 유지 | 구역 이탈 때 복귀 경로 확인 |
| 참가자 | 오른쪽 | 메뉴 | 자주 누르지 않음 |
| 채팅 | 오른쪽 | 오른쪽 유지 | 언제 올지 몰라 안 읽은 수와 새 메시지 말풍선이 항상 보여야 함. 전용 버튼을 두는 DEC-0067도 유지. 말풍선은 지금 위치가 + 버튼과 겹쳐 채팅 버튼 바로 위로 옮김 |
| 좌표 격자 | 왼쪽 | 메뉴 | 켜고 끄는 설정 |
| 포착 (미션) | 없음 | 메뉴 오른쪽 끝 (AR 미션만) | 미션 원 안에서만 활성 |
| 긴급 오염 (좀비) | 없음 | 메뉴 오른쪽 끝 (좀비 팀만) | 포착 자리 |

기존 규칙은 메뉴 안에서 유지합니다. 구역 이탈 중에는 QR과 참가자 항목을 숨기고, 수감 중에는 QR 항목 자리에 수감 항목이 나오며, 이벤트 게임 경찰의 증거보드는 메뉴 오른쪽 끝 항목으로 옮깁니다.

확정한 + 메뉴입니다. 내 위치, +, 채팅 버튼을 같은 높이로 한 줄에 놓습니다. + 버튼은 위치·채팅 버튼과 구분되도록 가운데에 원형으로 두고, 메뉴가 열리면 안쪽 + 아이콘이 돌아 X가 됩니다. 새 메시지 말풍선은 + 버튼과 겹치지 않게 채팅 버튼 바로 위로 옮깁니다.

![확정된 + 메뉴](https://github.com/cops-and-robbers/cops-and-robbers-FE/releases/download/qa-evidence/issue655_20261103-013941_fab-labels.gif)

메뉴 항목은 왼쪽부터 좌표, 참가자, 체포(또는 내 QR) 순서입니다. 많이 쓰는 QR을 오른쪽에 둡니다. 포착, 긴급 오염, 이벤트 게임의 증거보드 같은 모드 전용 항목은 해당 모드에서만 오른쪽 끝에 추가합니다. 클래식은 3개, 모드 전용 항목이 있으면 4개입니다.

QR 항목의 이름은 역할에 따라 정합니다. QR을 찍는 쪽은 하는 행동(체포, 감염)으로, 보여 주는 쪽은 역할과 상관없이 "내 QR"로 씁니다.

| 항목 | 한국어 | 영어 | 일본어 |
|---|---|---|---|
| 좌표 격자 | 좌표 | Grid | 座標 |
| 참가자 | 참가자 | Players | 参加者 |
| QR, 경찰 | 체포 | Arrest | 逮捕 |
| QR, 도둑과 좀비 모드의 사람 | 내 QR | My QR | マイQR |
| QR, 좀비 | 감염 | Infect | 感染 |
| 포착 | 포착 | Capture | 捕捉 |
| 긴급 오염 | 긴급 오염 | Outbreak | 緊急汚染 |
| 증거보드 | 증거보드 | Evidence | 証拠ボード |

QR, 참가자, 좌표는 2탭으로 늘어나므로, 달리면서 쓸 수 있는지 실제 판에서 확인합니다.

진행 순서:

1. 메뉴 버튼을 클래식에 먼저 적용하고 실제 판에서 확인합니다.
2. AR 미션에 포착 항목을 추가합니다.
3. 좀비 모드에 긴급 오염 항목을 추가합니다.

### 공통
- 옵션 조합 없이 모드를 하나만 고릅니다.
- 모드 선택은 게임 생성의 첫 단계로 추가합니다. 생성 단계는 3개에서 4개가 되고, 좀비 모드는 이어지는 감옥 설정을 건너뜁니다.
- 클래식 규칙은 그대로 두고 버튼 배치만 함께 바꿉니다. 서버는 모드 값이 없으면 클래식으로 처리합니다.
- 승률 통계는 모드별로 나눕니다.
- 이벤트 게임 플래그는 클래식 방에만 켭니다.

### AR 미션
- **개편된 클래식 화면을 그대로 쓰고, 메뉴의 포착 항목과 위쪽 게이지만 추가합니다.**
- 서버가 일정 시간마다 지점 3곳을 뿌립니다. **이번 판에서 도둑이 실제로 지나간 위치** 중 플레이그라운드 안, 감옥 밖에서 고릅니다. 원형, 폴리곤 구역 모두 해당합니다.
- 지점이 도둑의 현재 위치를 알려 주지 않도록 몇 분 이상 지난 위치만 쓰고, 지금 도둑이 있는 곳 근처는 뺍니다. GPS가 튀어 생기는 오차는 감수합니다.
- **도둑과 경찰에게 동시에 보여 줍니다.** 경찰이 지점에 가서 잠복할 수 있어야 합니다.
- 판정 반경은 30 m이고, 시간이 지나면 벌칙 없이 사라집니다.
- 도둑이 포착에 성공하면 **전체 게이지**가 차고, 다 채우면 도둑이 승리합니다 (어몽어스 임무 바 방식).
- 지도를 보고 찾아간 뒤 원 안에 들어오면 포착 항목이 활성화되고, 누르면 QR 스캐너와 같은 구성의 포착 화면이 열립니다.
- 그림은 도착하면 화면에 나타나고 현실에 고정되지 않습니다. 자이로로 폰 움직임에 맞춰 옮기고, 위아래 각도는 가속도 센서로 오차를 되돌립니다.
- 그림은 폰을 똑바로 세웠을 때 정면에 놓이고, 틀 안에 3초 유지하면 포착됩니다. 틀을 벗어나면 게이지가 서서히 줄고, 다시 맞추면 이어서 찹니다.
- 캐릭터는 처음엔 멈춰 있다가 틀에 들어오면 도망갑니다. 좌우로 초당 약 20도씩 움직이고 0.6~1.4초마다 방향을 바꾸며, 진행 방향으로 그림을 뒤집습니다. 폰으로 따라가며 3초를 채웁니다. 속도는 현장 테스트로 조정합니다.
- AR은 연출이고 도착 판정은 서버가 합니다. 미션은 도둑 전용으로 시작합니다.

포착 화면입니다. 문구는 낮에도 읽히도록 상단바에 넣고, 게임 화면처럼 그 아래에 게이지를 둡니다. 주변을 볼 수 있게 카메라 화면은 어둡게 하지 않습니다. 포착하면 게이지가 판 전체 미션 게이지로 바뀌고 잠시 후 지도로 돌아갑니다. 배경은 카메라 자리 표시용 그림입니다.

![포착 흐름](https://github.com/cops-and-robbers/cops-and-robbers-FE/releases/download/qa-evidence/issue655_20261103-012415_capture-flow.gif)

![포착 단계별 화면](https://github.com/cops-and-robbers/cops-and-robbers-FE/releases/download/qa-evidence/issue655_20261103-012416_capture-board.png)

구역 안에서 무작위로 뽑지 않는 이유입니다. 지도 데이터로 무작위 지점 4,000개를 시뮬레이션했고, 지도에 없는 길과 출입 제한은 반영되지 않은 추정치입니다.

| 구역 (반경 500 m) | 건물 안 | 보행로 10 m 이내 | 30 m 이내 | 40 m 이내 |
|---|---|---|---|---|
| 세종대 일대 | 13% | 48% | 86% | 92% |
| 건대입구 | 30% | 62% | 95% | 97% |
| 뚝섬 한강공원 (강 포함) | 4% | 32% | 60% | 64% |

### 좀비
- 첫 좀비는 서버가 무작위로 정하고 본인에게만 알립니다. 인원은 방장이 설정합니다.
- 대기 시간에는 감염되지 않습니다. 이후 터치하고 QR을 스캔하면 감옥 없이 바로 좀비가 됩니다.
- 첫 감염이 일어나면 첫 좀비와 감염자를 공개하고 추격전으로 넘어갑니다.
- 사람은 AR 미션과 같은 방식으로 백신을 모아 게이지를 채우면 승리합니다.
- 사람은 메뉴의 포착 항목으로 백신을 포착하고, 좀비는 그 자리에 긴급 오염이 있습니다.
- 좀비의 능력은 **긴급 오염** 하나입니다. 제한 시간 안에 사람이 수리하지 못하면 **게임이 끝나고 좀비가 승리합니다.** 발동자는 밝히지 않습니다.
- 수리는 AR이 아니라 **지점 안에 머무는 방식**입니다. 폰을 넣어 둬도 진행됩니다.

![긴급 오염 수리 흐름](https://github.com/cops-and-robbers/cops-and-robbers-FE/releases/download/qa-evidence/issue655_20261103-013948_decided-s4.png)

| 순서 | 앱 | 서버 |
|---|---|---|
| 발동 | 지점과 마감 시각 표시, 진동 | 지점 생성, 전체 전송, 마감 예약 |
| 머물기 | 원 안이면 게이지 진행, 나가면 멈춤 (GPS 튐 대비 몇 초 여유) | 없음 |
| 완료 | 게이지가 차면 수리 API 호출 | 진행 중, 마감 전, 살아 있는 사람, 최근 위치가 원 근처인지 확인 |
| 결과 | 해제 또는 게임 종료 표시 | 성공 시 해제 이벤트, 마감까지 성공이 없으면 좀비 승리로 종료 |

수리 API 초안은 `POST /api/games/{gameId}/emergencies/{emergencyId}/repair` 입니다. 좌표는 보내지 않고 서버가 가진 최근 위치를 씁니다. 응답은 `200` 성공 또는 이미 해제, `400` 사람이 아니거나 원에서 너무 멂, `409` 이미 마감입니다. 경로와 코드는 BE와 협의합니다.


- 좀비가 모두 나가면 사람이 승리합니다. 클래식의 경찰 전원 퇴장과 같습니다.

| 안건 | 제안 | 비고 |
|---|---|---|
| 수감 항목 위치 | 메뉴의 QR 항목 자리 | 지금은 지도에 바로 나와 수동 탈옥을 찾기 쉬움. 메뉴 안에서도 찾을 수 있는지 확인 필요 |

| 좀비 모드 시간 종료 시 승패 | 게이지를 못 채우면 좀비 승리 | 사람 승리로 두면 숨어서 버티는 게 정답이 됨 |
| 긴급 오염 도달 보장 | 살아 있는 사람 근처의 지나간 위치에서 2곳을 뽑아 1곳만 수리, 제한 시간은 구역 크기에 맞춤, 재사용 대기 유지 | 실패하면 바로 게임이 끝나므로 못 닿는 좌표가 나오면 불공정 |
| 수리 머무는 시간 | 10초, 여러 명이어도 속도는 같음, 수리 중 감염되면 끊김 | 현장 테스트로 조정 |
| 게이지 칸 수, 지점 생성 주기 | 라운드 시간에 맞춰 현장 테스트 | 경찰과 도둑 균형을 좌우함 |
| 후보 위치가 부족할 때 | 그 회차 미션은 건너뜀 | 도둑이 움직이지 않으면 지점이 잘 안 나오고, 지나간 곳 주변에 몰릴 수 있음 |
| AR 체감 | 이 이슈 브랜치의 시험 화면으로 실제 폰에서 확인 중 | 틀 크기, 캐릭터 속도, 게이지 감소 속도 조정 필요. 위치 조건과 포착 API는 아직 연결 안 함 |
| 구버전 앱 처리 | 첫 모드 출시 때 Remote Config 최소 버전 상향 | 서버는 앱 버전을 모름 |
| 위치 약관 | 수집 방식은 그대로, 다음 개정 때 서비스 목록 문구만 확인 | 약관이 이용 목적을 항목별로 나열하고 있음 (법률 판단 아님) |
| 필요한 디자인 | 임시 에셋으로 진행 후 교체 | 메뉴 항목 배치, + 아이콘, 포착 그림, 백신, 좀비 캐릭터가 지금 없음. 시험 화면은 + 는 머티리얼 아이콘, 포착 그림은 `chase.svg` 복사본을 임시로 씀 |
| 역할, 스파이 | 이번 범위에서 보류 | 다시 넣을지 결정 |
| BE 협업 방식 | 앱이 request, response JSON과 필요한 로직을 전달하고 BE가 구현 | 게임 중 도둑 위치 기록 보관(판 종료 시 삭제), 지점 생성, 완료 판정, 게이지, 팀 전환 등 서버 변경 필요 |
