❗ [버그][게임] GPS 수신이 드문 경우 자동 탈옥 누락 수정

## 🗒️ 설명

감옥 안의 유효한 GPS가 한 번만 수신된 뒤 밖으로 이동하면 자동 탈옥이 누락된다. 명확한 내부 위치의 입장 인정과 이탈 확인용 새 위치 조회를 보완한다.

<br>

## 🔄 재현 방법

1. 일반 게임에서 도둑이 체포된다.
2. 감옥 내부 위치를 한 번 수신한 뒤 외부로 이동한다.
3. 외부 위치가 반복 수신돼도 탈옥 API가 호출되지 않는다.

<br>

## 📸 참고 자료

`JailEscapeDetector.update`는 내부 표본 2개와 1초 경과를 모두 요구하며, 외부 표본 수신 시 미완성 내부 후보를 지운다. 시뮬레이터에서 상태 동기화 완료·수감 상태임에도 `hasEnteredJail=false`가 확인됐다. 실폰에서도 동일 증상이 보고됐으나 정확도에 의한 제외 여부는 추가 확인이 필요하다.

<br>

## ✅ 예상 동작

| 상황 | 결과 |
| --- | --- |
| 정확도 여유를 확보한 내부 GPS 1회 후 확실한 이탈 | 자동 탈옥 1회 |
| 감옥 밖에서 체포 후 계속 밖에 머무름 | 자동 탈옥하지 않음 |
| 추가 GPS 이벤트 없음 | 새 위치 조회로 확인, 캐시 재사용 금지 |
| 재체포·종료·연결 변경 | 이전 판정과 대기 작업 무효화 |
