## 제목

⚙️ [기능개선][공통][로딩] 로딩 다이얼로그를 풀스크린 로딩 화면으로 개선

## 본문

## 📝 현재 문제점

- 비동기 작업(방 생성·참가, 팀 변경, 게임 시작, 로그아웃 등) 중 작은 모달 다이얼로그에 스피너와 문구 한 줄만 떠서 "차단당했다"는 인상을 준다.
- 무슨 작업이 진행 중인지, 앱을 꺼도 되는지 알려주지 않아 사용자가 불안해한다.
- 로딩을 닫는 책임이 호출부에 있어(직접 pop), API가 매우 빨리 끝나면 화면이 번쩍이고 사라져 오히려 불안감을 준다.
- 로딩을 닫는 pop이 타이밍에 따라 로딩이 아닌 다른 화면을 닫을 수 있는 구조적 위험이 있다.

## 🛠️ 해결 방안 / 제안 기능

- 도허티 임계(0.4초 이내 피드백)를 지키도록, 로딩을 즉시 띄우는 화면 전체 로딩으로 교체한다.
- 토스처럼 제목(세계관 랜덤 문구) + 안심 서브카피("지금 앱을 끄면 합류가 취소돼요") + 캐릭터 비주얼로 진행 상황을 설명한다.
- 표시/닫기 타이밍의 책임을 호출부에서 컴포넌트로 옮긴다. 작업이 빨리 끝나도 최소 표시 시간을 유지해 깜빡임을 막는다.
- 로딩 중 뒤로가기를 차단하고, 로딩이 닫힌 뒤 에러 안내를 표시한다.
- 일러스트는 나중에 디자이너 자산(SVG/GIF/Lottie)으로 교체할 수 있도록 한 곳에 분리한다.
- 기존 스플래시·딥링크 로딩 화면과 하나의 뷰를 공유한다.

## ⚙️ 작업 내용

- 안심 서브카피 문구 다국어(ko/en/ja) 추가
- 풀스크린 로딩 콘텐츠 뷰 및 로딩 비주얼(파동 링 + 팀 캐릭터) 신설
- 로딩 오버레이 진입점 + 최소 표시 시간 닫기 핸들 신설
- 기존 로딩 다이얼로그 호출부 전체를 신규 방식으로 교체
- 스플래시·딥링크 로딩 화면을 공용 뷰로 통합
- 레거시 로딩 팝업 제거
