## 제목

⚙️ [기능추가][게임][결과다이얼로그] 캐릭터가 다이얼로그를 잡고 있는 게임 종료 결과창 구현

## 본문

## 📝 현재 문제점

- 현재 게임 종료 후 결과 화면은 단순한 Scaffold 레이아웃으로, 세션 ID만 표시되고 있어 디자인 시안이 반영되지 않은 상태
- 승리/패배 결과, 게임 통계(체포 횟수, 남은 도둑, 게임 진행 시간), 액션 버튼(홈으로 / 한 번 더) UI가 없음
- 결과 다이얼로그 상단에 캐릭터(경찰/도둑)가 팔로 다이얼로그를 잡고 있는 연출이 미적용
- 경찰/도둑 각각 승리/패배 상황에 따라 표정·포즈가 다른 캐릭터가 필요하나 에셋 미반영
- 새로 추가된 게임 결과 조회 API(`GET /api/game-results/{gameResultId}`) 미연동 상태

## 🛠️ 해결 방안 / 제안 기능

- 게임 종료 시 팀 결과(승리/패배)에 맞는 캐릭터가 다이얼로그 상단에 걸쳐 있는 오버레이 다이얼로그로 결과창 전환
- 본인 팀(경찰/도둑) × 결과(승리/패배) 4가지 조합에 따라 서로 다른 캐릭터 SVG 분기
- 캐릭터 몸통은 다이얼로그 뒤쪽, 팔은 다이얼로그 앞쪽에 배치되어 "팔이 다이얼로그를 잡은" 입체감 연출
- `GAME_OVER` 이벤트 수신 → `gameResultId`로 결과 조회 API 호출 → 응답 데이터로 다이얼로그 렌더링
- 승리/패배 판정은 응답의 `winnerTeam`과 본인 팀 비교로 결정
- 통계 영역은 API 응답 필드 기반으로 표시
- 액션 버튼 2종: 홈으로 / 한 번 더 (홈으로는 홈 라우트 이동, 한 번 더는 추후 정의)

## 🔗 연동 API

- 엔드포인트: `GET /api/game-results/{gameResultId}`
- 트리거: `GAME_OVER` 이벤트의 `data.gameResultId` 수신 직후 호출
- 응답 스키마
  - `winnerTeam` : 승리 팀 (POLICE / ROBBER)
  - `durationSeconds` : 게임 진행 시간 (초 단위, 분:초 포맷으로 변환 표시)
  - `totalArrestCount` : 총 체포 횟수
  - `remainingRobberCount` : 남은 도둑 수
- 매핑
  - 체포 횟수 → `totalArrestCount`
  - 남은 도둑 → `remainingRobberCount`
  - 게임 진행 시간 → `durationSeconds` (초를 분 단위로 변환)

## 🖼️ 캐릭터 에셋 구조

결과창은 본인 팀(경찰/도둑) × 결과(승리/패배) 조합에 따라 서로 다른 다이얼로그가 노출되므로, 캐릭터는 총 4종이 필요.

- 경찰 승리 캐릭터 (경찰팀이 이겼을 때 경찰 유저가 보는 다이얼로그)
- 경찰 패배 캐릭터 (도둑팀이 이겼을 때 경찰 유저가 보는 다이얼로그)
- 도둑 승리 캐릭터 (도둑팀이 이겼을 때 도둑 유저가 보는 다이얼로그)
- 도둑 패배 캐릭터 (경찰팀이 이겼을 때 도둑 유저가 보는 다이얼로그)

기존 캐릭터 에셋 패턴(`assets/characters/{team}/default/*.svg`)을 따라 `result` 하위 폴더 신설.

예상 폴더 구조

```
assets/characters/
├── police/
│   ├── default/        (기존)
│   └── result/         (신규)
│       ├── win.svg     경찰 승리
│       └── lose.svg    경찰 패배
└── robber/
    ├── default/        (기존)
    └── result/         (신규)
        ├── win.svg     도둑 승리
        └── lose.svg    도둑 패배
```

선택 로직

- 본인 팀 = `POLICE`, `winnerTeam` = `POLICE` → `police/result/win.svg`
- 본인 팀 = `POLICE`, `winnerTeam` = `ROBBER` → `police/result/lose.svg`
- 본인 팀 = `ROBBER`, `winnerTeam` = `ROBBER` → `robber/result/win.svg`
- 본인 팀 = `ROBBER`, `winnerTeam` = `POLICE` → `robber/result/lose.svg`

`pubspec.yaml`에 신규 폴더 경로 2개 등록 필요

```
- assets/characters/police/result/
- assets/characters/robber/result/
```

참고: 디자인 시안에서는 캐릭터 몸통이 다이얼로그 뒤, 팔이 다이얼로그 앞에 걸쳐 있는 입체 구도임. 디자이너가 몸통/팔을 분리된 SVG로 전달할 경우 파일 수는 캐릭터당 2개(body/arms)로 늘어날 수 있음 → 이 경우 `win.svg` 대신 `win_body.svg` / `win_arms.svg` 형태로 분리. 한 장짜리로 올지 분리해서 올지는 디자이너와 협의.
