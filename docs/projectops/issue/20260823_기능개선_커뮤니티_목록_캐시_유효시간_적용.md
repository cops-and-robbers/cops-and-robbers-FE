## 제목

🚀 [기능개선][커뮤니티] 모집글 목록 캐시 유효 시간 적용

## 본문

## 📝 현재 문제점

- 커뮤니티 목록을 한 번 불러오면 화면을 나갔다 돌아와도 다시 불러오지 않는다. 게임을 하고 돌아오거나 몇 시간이 지나도 처음 받아온 목록 그대로다
- 갱신되는 경로는 당겨서 새로고침, 직접 글을 쓰거나 고치거나 지웠을 때, 앱 재시작뿐이다. 그 사이 남이 올린 새 글은 보이지 않는다
- 목록을 캐시해 재조회를 없앤 작업(#477)의 부작용이다. 호출은 줄었지만 낡은 목록을 되돌릴 기준이 없다

## 🛠️ 해결 방안 / 제안 기능

- 목록에 유효 시간을 둔다. 마지막으로 받아온 지 3분이 지나면 낡은 것으로 보고, 화면에 다시 들어올 때 새로 받는다
- 3분 안에 돌아오면 캐시를 그대로 쓴다. 탭을 잠깐 오가는 정도로는 재조회가 일어나지 않는다

## ⚙️ 작업 내용

- 목록을 받아온 시각 기록
- 화면이 다시 보이는 순간 경과 시간을 확인해 유효 시간을 넘겼으면 재조회
- 재조회 트리거 두 가지 — 다른 탭이나 게임에서 커뮤니티로 돌아올 때, 앱이 백그라운드에서 돌아올 때
- 최근 검색어를 타이핑에 맞춰 좁혀 보여주기 (로컬에 이미 있는 목록을 거르는 것이라 서버 요청 없음)
- 유효 시간 판정을 테스트할 수 있도록 시간 기준을 갈아끼울 수 있게 분리

## 📌 참고

- 캐시를 지우는 방식(보는 사람이 없어지면 일정 시간 뒤 버리는 방식)은 이 앱에서 동작하지 않는다. 바텀 네비게이션이 탭 화면을 항상 살려 두어 보는 사람이 사라지는 순간이 없다. 낡았는지 판정한 뒤 다시 받아오는 방식이어야 한다
- 국가 조회는 위치 권한을 새로 얻었을 때만 다시 판정한다. 목록 재조회가 국가 재판정까지 끌고 가지 않도록 분리를 유지한다
- 우리 동네·내 모임 범위는 서버가 아직 열지 않아 호출 자체가 없다
- 본 검색은 지금처럼 실행 시점에 한 번만 호출한다. 타이핑마다 부르는 방식은 백엔드가 명시적으로 반대했다 — 검색이 인덱스를 타지 못해 사실상 전체 스캔이기 때문이다. 실시간 추천 검색어를 하려면 전용 API가 먼저 필요하다
- 3분은 첫 값이며 실사용 후 조정할 수 있다
