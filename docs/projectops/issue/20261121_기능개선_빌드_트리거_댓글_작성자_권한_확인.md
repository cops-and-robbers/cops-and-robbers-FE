# 🚀 [기능개선][CI] 빌드 트리거 댓글 작성자 권한 확인

## 📝 현재 문제점

- `PROJECT-FLUTTER-SUH-LAB-APP-BUILD-TRIGGER.yaml`은 댓글에 키워드(`@suh-lab` + `build`)만 있으면 실행된다. **댓글 작성자가 팀원인지 확인하지 않는다.**
- 댓글·PR에서 읽은 브랜치명을 스크립트 본문에 `${{ }}`로 직접 끼워 넣는다. 입력값은 `env`로 넘기는 것이 GitHub 권장 방식이다.

<br>

## 🛠️ 해결 방안 / 제안 기능

| 항목 | Before | After |
|---|---|---|
| 실행 조건 | 댓글 키워드만 확인 | 키워드 + 작성자가 `OWNER` / `MEMBER` / `COLLABORATOR` |
| 브랜치명 전달 | 스크립트 본문에 `${{ steps.source_info.outputs.branchName }}` | 스텝 `env`로 넘기고 `process.env.BRANCH_NAME` / `$BRANCH_NAME`으로 읽음 |

<br>
