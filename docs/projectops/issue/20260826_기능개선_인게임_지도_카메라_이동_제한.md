# 🚀 [기능개선][인게임][Flutter] 인게임 지도 카메라를 플레이그라운드 주변으로 제한

## 📝 현재 문제점

- 인게임 지도에 줌아웃 제한만 있고 이동(스크롤) 제한이 없어, 플레이그라운드에서 얼마든지 먼 지역까지 지도를 끌고 나갈 수 있다
- 게임과 무관한 지역을 한참 탐색하게 되면 자기 위치나 구역으로 돌아오기 번거롭고, 게임 몰입이 깨진다

## 🛠️ 해결 방안 / 제안 기능

- 플레이그라운드가 설정된 게임에서는 지도 카메라가 구역 주변 일정 범위까지만 이동되도록 제한한다
- 허용 범위는 구역 크기에 비례한 여유(구역 반경의 30%)를 두어, 작은 구역은 조금만·큰 구역은 넉넉히 벗어날 수 있게 한다
- 원형(거리로 설정)·다각형(핀으로 설정) 구역 모두 동일하게 적용한다
- 구역 정보가 로드되기 전에는 기존처럼 제한 없이 동작한다

## ⚙️ 작업 내용

- 구역 크기 기준 카메라 이동 허용 범위 계산 (원형/다각형 공통)
- 인게임 지도에 이동 허용 범위 적용
- 허용 범위 계산 검증 테스트 작성
