## 제목

🚀 [기능개선][약관동의] 로그인 후 약관 명시적 동의 플로우 구현 (이용약관 / 개인정보처리방침 / 위치정보 이용약관)

## 본문

## 📝 현재 문제점

- 현재 앱은 가입 시점에 이용약관·개인정보처리방침을 묵시적으로 동의한 것으로 처리하고 있어 법적 명시적 동의 요건을 충족하지 못한다.
- 위치정보를 핵심 기능으로 사용하는 앱임에도 위치정보 이용약관 동의 절차가 없다.
- 사용자가 어떤 약관에 동의했는지 기록이 남지 않아 추후 약관 개정 시 재동의 처리가 어렵다.
- 백엔드에 약관 동의 API(`PUT/GET /api/user/agreements`)가 신규 구현되었으며(cops-and-robbers-BE #79), 프론트에서 해당 API와 연동되는 약관 동의 플로우가 필요하다.
- 백엔드 배포 시점에 기존 회원의 약관 동의 여부도 모두 `false`로 초기화되므로, 신규 회원뿐 아니라 기존 회원도 다음 로그인 시 반드시 약관 동의 화면을 거쳐야 한다.
- 추후 약관 개정 시에도 동일 메커니즘으로 처리 가능하다. 백엔드가 변경된 약관 필드를 `false`로 초기화하면 로그인 응답 플래그가 다시 `true`가 되어 재동의 화면으로 자동 라우팅된다.

## 🛠️ 해결 방안 / 제안 기능

- 로그인 성공 이후(= 백엔드 JWT 발급 이후) 필수 약관을 아직 동의하지 않은 사용자(신규/기존 구분 없음)에게 약관 동의 화면을 노출한다.
- 약관 동의 화면에서 3종(이용약관, 개인정보처리방침, 위치정보 이용약관)을 필수 체크, 마케팅 수신은 선택 체크로 받는다.
- 로그인 응답의 약관 동의 여부 플래그에 따라 라우팅을 분기하여, 미동의 상태에서는 홈 및 게임 기능 접근을 차단한다.
- 필수 3종 모두 체크되었을 때만 "동의하고 시작하기" 버튼이 활성화되도록 한다.
- 각 약관은 본문 상세 화면(또는 바텀시트)으로 이동할 수 있어야 한다.
- 이미 약관에 동의한 기존 사용자가 재진입하는 경우 서버가 최초 동의 시각을 보존하지만, 프론트에서도 기본적으로 동의 화면을 다시 노출하지 않도록 처리한다.

### 연동 API (백엔드 cops-and-robbers-BE #79)

| Method | Path | 설명 |
| --- | --- | --- |
| `POST` | `/api/auth/login` | 응답에 약관 동의 여부 플래그 포함 (신규 필드) |
| `PUT` | `/api/user/agreements` | 약관 동의 저장 (필수 3종 + 선택 1종) |
| `GET` | `/api/user/agreements` | 현재 사용자의 약관 동의 상태 조회 |

추가로, 필수 약관 미동의 상태에서 게임 방 생성/참여 API 호출 시 서버에서 차단되므로 에러 응답 처리도 필요하다.

### 라우팅 흐름

```
Splash → Google 로그인 → POST /api/auth/login
                              │
                              ├─ 필수 약관 미동의
                              │     → 약관 동의 화면
                              │     → PUT /api/user/agreements
                              │     → (신규 사용자면) 닉네임 설정 화면
                              │     → 홈
                              │
                              └─ 필수 약관 동의 완료
                                    → 닉네임 유무 분기 후 홈
```

### 약관 동의 화면 구성

- 상단: "서비스 이용을 위해 약관에 동의해주세요" 안내
- 전체 동의 체크박스 (필수 3개 + 선택 1개 일괄 체크)
- 이용약관 동의 (필수) + 상세보기
- 개인정보처리방침 동의 (필수) + 상세보기
- 위치정보 이용약관 동의 (필수) + 상세보기
- 마케팅 정보 수신 동의 (선택) + 상세보기
- 하단 "동의하고 시작하기" CTA (필수 3종 체크 시 활성화)

### 에러 / 이탈 처리

- 약관 동의 화면에서 뒤로가기 혹은 앱 종료 시, 다음 접속 때 로그인 응답 플래그에 따라 동일하게 약관 동의 화면부터 재진입한다.
- `PUT /api/user/agreements` 실패 시 기존 에러 처리 컨벤션(`AppException` + 스낵바)에 맞춰 재시도 가능하도록 처리한다.
- 필수 약관 미동의 상태로 게임 방 생성/참여를 시도하여 서버에서 차단되는 경우, 약관 동의 화면으로 이동시킨다.

- 약관 동의 전용 페이지/위젯/Provider 추가

- QA 시나리오 정리 (신규 가입 / 기존 사용자 배포 후 재로그인 / 약관 동의 완료 후 재로그인 / 약관 동의 중 이탈 후 재진입 / 필수 약관 미동의 상태 게임 진입 차단 케이스)
