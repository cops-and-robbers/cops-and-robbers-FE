## 📌 작업 개요

피그마 디자인을 기준으로 프로젝트 전역에서 재사용 가능한 공용 UI 컴포넌트 시스템을 구현했습니다. 화면별 UI 일관성을 확보하고 디자인 변경 시 효율적으로 대응할 수 있도록 중앙 집중식 디자인 시스템을 구축했습니다.

**주요 성과**:
- ✅ 10개 커밋을 통해 체계적으로 공용 컴포넌트 시스템 완성
- ✅ 버튼, 입력, 슬라이더, 칩, 카드 등 핵심 UI 컴포넌트 구현
- ✅ 디자인 시스템 상수화 (색상, 간격, 반경, 텍스트 스타일)
- ✅ Clean Architecture 원칙 준수 및 재사용성 극대화

## 🎯 구현 목표

### 문제점
- 화면별로 UI 컴포넌트 구현 방식이 달라 일관성 부족
- 디자인 수정 시 여러 화면을 개별적으로 수정해야 하는 비효율

- 공용 컴포넌트 사용을 통한 UI 일관성 확보 및 유지보수 효율 개선

### 4. AppSlider 컴포넌트 (b6f19db)

#### 슬라이더 컴포넌트
- **파일**: `lib/core/widgets/inputs/app_slider.dart`
- **주요 기능**:
  - 라벨 + 현재 값 + 단위 표시
  - 최소/최대 값 표시 (선택적)
  - 복합 텍스트 스타일 지원 (prefix/suffix)
  - 컨테이너 옵션 (선택적)
  - 커스터마이징 (색상, 분할 수, 크기)
- **디자인 스펙**:
  - 기본 색상: black 계열 (track, thumb)
  - 라벨: label_16 스타일
  - 값: semibold28 스타일
- **특수 기능**:
  - `displayPrefix`, `displaySuffix`로 "도둑 시작 후 X분 뒤" 같은 복합 표현 지원
  - `showMinMax` 옵션으로 최소/최대 값 표시 제어
- **사용 예시**:
  ```dart
  AppSlider(
    label: '라운드 제한 시간',
    value: 30.0,
    min: 10,
    max: 60,
    unit: '분',
    divisions: 50,
    onChanged: (value) => setState(() => roundTime = value),
  )
  ```

**디자인 시스템 확장**:
- `AppTextStyles`에 `semibold28` 추가 (슬라이더 값 표시용)
- `AppColors`에 다양한 색상 계열 추가 (blue, green, red 각 3단계)

### Clean Architecture 준수

**계층 구조**:
```
lib/core/widgets/          (공용 컴포넌트)
├── buttons/               (버튼 컴포넌트)
│   ├── app_button.dart
│   ├── social_login_button.dart
│   └── zone_setting_button.dart
├── inputs/                (입력 컴포넌트)
│   ├── app_text_field.dart
│   └── app_slider.dart
├── chips/                 (칩 컴포넌트)
│   ├── info_radius_chip.dart
│   └── action_chip.dart
├── cards/                 (카드 컴포넌트)
│   └── info_card.dart
└── map/                   (지도 위젯)
    ├── zone_setting_widget.dart
    └── models/            (도메인 모델)
        ├── zone_shape.dart
        ├── circle_zone_shape.dart
        └── zone_shape_type.dart
```

**설계 원칙**:
- ✅ Single Responsibility: 각 컴포넌트는 하나의 역할만 수행
- ✅ Open/Closed: 확장 가능하도록 설계 (subtitle, contentAlignment 등)
- ✅ Dependency Inversion: 외부에서 의존성 주입
