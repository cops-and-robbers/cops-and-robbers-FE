### 📌 작업 개요

앱 내 아이콘 버튼의 터치 영역이 아이콘 이미지 크기(24x24)와 동일하여 터치하기 어려운 UX 문제 개선. Material Design 권장 최소 터치 타겟(48x48)으로 확대

**이슈**: [#157](https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/157)

---

### 🔍 문제 분석

`GestureDetector`로 `SvgPicture.asset`(24x24)만 직접 감싸는 패턴으로 인해 터치 영역이 아이콘 크기와 동일. 손가락으로 정확히 아이콘 위를 눌러야 하여 여러 번 시도해야 하는 경우 발생

### 🔧 주요 변경사항 상세

#### 적용 패턴

기존 `GestureDetector` 패턴을 유지하면서 `SizedBox(48x48)`로 터치 영역만 확장하는 방식 채택. 프로젝트 전체가 `GestureDetector` 기반이므로 Flutter `IconButton`(Material ripple 포함)은 사용하지 않아 기존 디자인과 일관성 유지

```
GestureDetector
  └── SizedBox (48x48)  ← 터치 영역
       └── Center / Align  ← 아이콘 정렬
            └── SvgPicture (24x24)  ← 아이콘
```

**특이사항**:
- 홈 화면 설정 아이콘은 Row 우측 끝에 위치하므로 `Align(centerRight)`로 아이콘을 우측 정렬. 터치 영역은 좌측으로 확장
- 대기실 앱바 아이콘 간 간격은 기존 `SizedBox(horizontal12)` 대신 48px 터치 영역의 내부 여백으로 자연스럽게 처리

---

#### 랜덤 로딩 메시지 — reconnect 카테고리

`loading_messages.json`에 `reconnect` 카테고리 추가. 재접속 시 3개 메시지 중 랜덤 표시:
- "다시 현장으로 복귀 중..."
- "작전에 재합류하는 중..."
- "현장 복귀 준비 중..."

`LoadingCategory` enum에 `reconnect` 항목 추가하여 기존 랜덤 메시지 인프라 활용

### 📌 참고사항

- `behavior: HitTestBehavior.opaque`가 없던 곳에 추가하여 투명 영역에서도 터치 이벤트 수신 가능하도록 보강
- `SvgIconButton` 공통 위젯은 배경+그림자가 있는 컨테이너형이므로 앱바 아이콘에는 부적합하여 사용하지 않음
- 스플래시 `LoadingPage`는 `const` 제거됨 (런타임 랜덤 메시지 사용으로 인해 컴파일 타임 상수 불가)
