### 📌 작업 개요
게임 중 앱이 꺼진 채 판이 끝나면 같은 방 다음 라운드에 이전 라운드 이동 경로·거리가 복원되던 문제 수정. 기기 기록 파일을 게임 id에 더해 서버 라운드 시작 시각으로 구분함. 함께 `api-docs.json`을 서버 v2.39.0(팀 MVP)으로 맞추고, 결과 조회 요청이 디버그 로그에 안 찍히던 것을 보완함.

**보고서 파일**: `docs/report/20261019_#641_이동_기록_라운드별_구분.md`

### 🔍 문제 분석
- 기기 기록 파일(`game_record.txt`) 머리줄이 `g {gameId}`뿐이라 같은 게임이면 복원함
- 같은 방의 다음 라운드는 gameId가 같음
- 파일을 지우는 곳은 `markEnd` 하나이고, 앱이 살아 있을 때 게임이 끝나야만 실행됨. 앱이 꺼진 채 판이 끝나면 파일이 남음
- 다음 라운드 진입 시 `begin(gameId)`가 그 파일을 복원 → 결과 카드 경로·거리가 부풀고, 30초마다 서버로 가는 누적 거리(팀 MVP 동점 판정용, 서버 v2.39.0)에도 이전 라운드 거리가 들어감. 서버는 라운드 첫 거리 값에 시속 상한 검사를 하지 않음

### ✅ 구현 내용

#### 기록 파일을 라운드 단위로 구분
- **파일**: `lib/features/game/data/datasources/game_record_local_datasource.dart`
- **변경 내용**: 머리줄을 `g <gameId> <시작 시각 ms | ->`로 변경. `openForGame(gameId, startedAt:)`은 gameId가 같고 저장된 시작 시각과 2초(`_sameRoundTolerance`) 이내일 때만 복원. 시작 시각을 모르면 복원하지 않고 새로 시작
- **이유**: 시작 시각은 대기실 경유면 GAME_START의 `startTime`, 앱 재실행이면 게임 설정 API의 `gameStartTime`에서 옴. 두 값의 소수점 자릿수가 다름(dev 실측 `08:03:40.386335565` / `08:03:40.386336`). 문자열이 아니라 시각 차이로 비교함. 같은 방 라운드 간격은 분 단위라 2초 여유로 헷갈리지 않음

#### 진입 시 시작 시각 확보
- **파일**: `lib/features/game/presentation/pages/game_page.dart`, `lib/features/game/presentation/providers/player_game_record_provider.dart`
- **변경 내용**: `begin(gameId, startedAt:)` 직전에 `_initSettingsFromApiIfNeeded()`로 시작 시각을 먼저 채움. 대기실 경유면 이미 있어 추가 요청 없음
- **이유**: `begin` 위치는 그대로 둠. 기록 provider가 keepAlive라 위치 권한이 거부된 판에서도 초기화가 일어나야 이전 판 기록이 화면에 남지 않음

#### 결과 조회 디버그 로그
- **파일**: `lib/features/game/presentation/providers/game_result_provider.dart`
- **변경 내용**: 결과 조회 전용 Dio에 전역 Dio와 같은 `LogInterceptor`(디버그 빌드만) 추가
- **이유**: 401 강제 로그아웃을 피하려고 전역 Dio를 안 쓰는 대신 로그 인터셉터도 빠져 있어, `/api/game-results/{id}`·`/me` 요청만 로그에 안 보였음

#### API 명세·주석
- **파일**: `docs/api-docs.json`, `lib/features/game/data/models/my_game_record_response_model.dart`
- **변경 내용**: 명세를 서버 v2.39.0으로 동기화(`policeMvp`·`robberMvp`·`isMvp`). 내 기록 응답 예시 주석에 `isMvp` 추가. 앱 모델은 이미 맞아 코드 변경 없음

### 🔧 주요 변경사항 상세

**특이사항**:
- 업데이트 직후 게임 중이던 사람은 옛 형식 머리줄이 맞지 않아 그 판 기록을 한 번 복원하지 못함. 버전이 바뀌는 순간 한 번뿐이라 별도 이관 없음
- 설정 API가 실패해 시작 시각을 모르면, 같은 라운드 재진입이어도 복원하지 않음
