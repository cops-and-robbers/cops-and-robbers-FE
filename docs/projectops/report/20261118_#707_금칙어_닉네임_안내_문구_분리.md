### 📌 작업 개요
닉네임 확인에서 금칙어가 든 닉네임을 "중복된 닉네임"으로 안내하던 문제 수정. 서버 응답의 `code`로 사용 가능·중복·금칙어를 나누고, 금칙어에는 전용 문구(ko·en·ja)를 띄움

**보고서 파일**: `docs/projectops/report/20261118_#707_금칙어_닉네임_안내_문구_분리.md`

### 🎯 구현 목표
- BE #247(v4.2.0)부터 금칙어 닉네임도 `isAvailable: false`로 와서 중복과 구분되지 않음. 앱은 `false`를 모두 중복으로 처리
- BE #248(v4.3.0, PR #249)이 응답에 `code`(`AVAILABLE` / `DUPLICATED_NICKNAME` / `BANNED_WORD_NICKNAME`)를 추가. 앱은 이 값으로 문구를 고름
- 서버 `message`(한국어 한 문장)는 화면에 쓰지 않음

| 서버 응답 | 이전 화면 | 이후 화면 |
|---|---|---|
| `isAvailable: true` | 사용 가능한 닉네임이에요 | 그대로 |
| `isAvailable: false`, `code: DUPLICATED_NICKNAME` | 중복된 닉네임이에요. 다른 닉네임을 입력하세요 | 그대로 |
| `isAvailable: false`, `code: BANNED_WORD_NICKNAME` | 중복된 닉네임이에요. 다른 닉네임을 입력하세요 | **사용할 수 없는 표현이 들어 있어요. 다른 닉네임을 입력하세요** |
| `code` 없음 (#248 배포 전 서버) | 기존 동작 | 기존 동작 (false = 중복) |

### ✅ 구현 내용

#### 확인 결과 타입 추가
- **파일**: `lib/features/user/domain/entities/nickname_check_result.dart` (신규)
- **변경 내용**: `NicknameCheckResult` enum (`available` / `duplicated` / `bannedWord`)
- **이유**: `bool`로는 실패 이유 두 가지를 구분할 수 없음

#### 응답 모델에 code 추가
- **파일**: `lib/features/user/data/models/nickname_check_response_model.dart`
- **변경 내용**: `String? code` 추가 (nullable)
- **이유**: #248 배포 전 서버는 `code`를 보내지 않으므로 없어도 파싱되어야 함

#### code → 결과 매핑
- **파일**: `lib/features/user/data/repositories/user_repository_impl.dart`, `lib/features/user/domain/repositories/user_repository.dart`
- **변경 내용**: `checkNickname`이 `Future<bool>` 대신 `Future<NicknameCheckResult>` 반환. `code == 'BANNED_WORD_NICKNAME'`이면 `bannedWord`, 그 밖에는 `isAvailable`로 `available`/`duplicated`
- **이유**: 서버 문자열 해석은 데이터 계층에 둠. 모르는 값·누락은 기존 동작으로 떨어지게 해 서버 배포 순서와 무관하게 동작

#### 닉네임 화면 금칙어 상태
- **파일**: `lib/features/auth/presentation/pages/nickname_setup_page.dart`
- **변경 내용**: `NicknameValidationState.bannedWord` 추가, 결과를 `switch`로 상태에 매핑, 중복 안내와 같은 빨간 표시(`AppColors.red`, `AppIcons.wrongMark`)로 새 문구 표시
- **이유**: 확인 버튼은 여전히 `valid`일 때만 켜지므로 금칙어 닉네임은 저장 단계로 가지 않음

#### 다국어 문구
- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb` (+ `flutter gen-l10n` 생성 파일)
- **변경 내용**: `errorNicknameBannedWord` 키를 `errorNicknameDuplicated` 옆에 추가

| 언어 | 문구 |
|---|---|
| ko | 사용할 수 없는 표현이 들어 있어요. 다른 닉네임을 입력하세요 |
| en | This nickname contains words that aren't allowed. Please enter a different nickname |
| ja | 使用できない表現が含まれています。別のニックネームを入力してください |
