### 📌 작업 개요

채팅 입력바 하단 SafeArea 여백 조정, 채팅 메시지 카카오톡 스타일 그룹핑, 다이얼로그 닫힘 시 채팅 시트 올라오는 버그 수정, 게임 화면 UI 스타일 수정 등 채팅 UX 전반 개선 및 디자인 보완 작업

### 🎯 구현 목표

- 채팅 입력바 하단 SafeArea 여백을 여유 있게 조정
- 채팅 메시지 카카오톡 스타일 그룹핑 (같은 발신자 + 같은 분 기준)
- 다이얼로그 닫힘 시 채팅 시트가 의도치 않게 올라오는 현상 수정
- 채팅 오버레이 접힌 후 다시 펼칠 때 PageView 페이지 복원
- 게임 화면 내 UI 스타일 세부 보정

### ✅ 구현 내용

#### 1. 채팅 입력바 SafeArea 하단 여백 조정

- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`
- **변경 내용**: `safeBottomMargin` 계산에 `+ 12.h` 추가하여 하단 여백 확보
- **이유**: 기존 SafeArea 여백이 답답하게 느껴지는 문제 해소

#### 2. 채팅 메시지 카카오톡 스타일 그룹핑 및 날짜 구분선

- **파일**: `lib/features/chat/presentation/widgets/chat_message_list.dart`
- **변경 내용**: 같은 발신자 + 같은 분(minute) 기준 메시지 그룹핑 로직 추가. 그룹 첫 메시지만 닉네임 표시, 그룹 마지막 메시지만 시간 표시. 날짜가 바뀌는 지점에 "YYYY년 M월 D일 X요일" 구분선 삽입
- **이유**: 연속 메시지에서 닉네임/시간 중복을 제거하여 카카오톡과 유사한 가독성 확보

#### 3. ChatMessageBubble에 showNickname / showTime 파라미터 추가

- **파일**: `lib/features/chat/presentation/widgets/chat_message_bubble.dart`
- **변경 내용**: `showNickname`, `showTime` 파라미터 추가. false일 때 해당 UI 요소 숨김. 메시지 간 여백도 그룹 내(2.h) / 그룹 시작(8.h)으로 차등 적용
- **이유**: 그룹핑 로직과 연계하여 불필요한 닉네임/시간 중복 표시 제거

#### 4. 채팅 타임스탬프 파싱 로직 DTO extension으로 통합

- **파일**: `lib/features/chat/data/models/chat_message_dto.dart`
- **변경 내용**: `ChatMessageTimestamp` extension 추가. `kstDateTime` (DateTime? 변환), `formattedTimeKst` (HH:MM 문자열) 제공. 마이크로초 초과 자릿수 정규화 + `toUtc().toLocal()` 로컬 시간대 변환
- **이유**: bubble과 list 양쪽에서 중복되던 타임스탬프 파싱 로직을 한 곳으로 통합. KST 하드코딩 대신 시스템 로컬 시간대 사용으로 범용성 확보

#### 5. 다이얼로그 닫힘 시 채팅 시트 올라오는 현상 수정

- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`, `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**:
  - ChatOverlay: `_inputBarTouched` 플래그 추가. `Listener(onPointerDown)` 으로 실제 터치 여부 감지, `_onInputFocused()`에서 터치 없이 프로그래매틱 포커스 복원 시 시트 확장 차단
  - GamePage: 규칙 다이얼로그 표시 전 `FocusScope.of(context).unfocus()` 호출
  - 키보드가 닫힐 때 시트를 `_minSize`로 자동 복귀하는 `addPostFrameCallback` 로직 추가
- **이유**: 다이얼로그가 닫히면 이전 포커스(채팅 입력 TextField)가 복원되면서 시트가 의도치 않게 올라오는 문제 해결

#### 6. 채팅 오버레이 펼침 시 PageView 페이지 복원

- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`
- **변경 내용**: `_onSheetChanged()`에서 `_isExpanded`가 true로 전환될 때 `addPostFrameCallback`으로 `_pageController.jumpToPage(_currentPage)` 호출
- **이유**: 시트 접기 시 PageView가 위젯 트리에서 제거되고, 재생성 시 page 0으로 초기화되어 title과 실제 페이지가 불일치하는 문제 수정

#### 7. 게임 화면 UI 스타일 수정

- **파일**: `lib/features/game/presentation/widgets/arrest_lock_overlay.dart`
- **변경 내용**: 체포 안내 텍스트 스타일 `robberParagraph` → `paragraph_14`로 변경, 탈옥 완료 버튼 borderRadius `AppRadius.medium` (8.r) 적용
- **파일**: `lib/features/game/presentation/widgets/participant_overlay.dart`
- **변경 내용**: 도둑팀 헤더 배지의 `badgeColor`와 `badgeBoldColor` 값이 서로 바뀌어 있던 부분 수정
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 하단 AppBar 좌우 패딩 `AppPadding.horizontal24` → `AppSpacing.horizontal12`로 변경

#### 8. 기타 디자인 보정

- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: 공지사항 아이콘 `Loudspeaker.svg` → `icon_notice.svg`로 변경
- **파일**: `lib/features/settings/presentation/pages/legal_document_page.dart`
- **변경 내용**: 법적 문서 텍스트에 `height: 1.4` 줄간격 적용 (본문, 항목, 하위항목 공통)
