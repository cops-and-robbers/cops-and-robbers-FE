### 📌 작업 개요

> **시안 단계 초안이다.** 구현 전이며, 아래 화면은 실제 앱 위젯을 임시 화면에 띄워 iPhone 17 Pro(iOS 26) 시뮬레이터에서 찍은 시안이다. 구현이 끝나면 실제 화면으로 바꾼다.

방장이 방 설정에서 무전을 켜고 끈다. 기본값은 꺼짐이고, 켠 방에서만 경찰에게 무전 버튼이 보인다. 무전 카드에는 Beta 칩을 붙인다. 지금은 앱 상수(`kRadioEnabledDefault = true`)로 모든 일반 게임에서 무전이 켜져 있다. 서버 쪽은 BE #260(`radioEnabled`)이 맡는다.

### 🎯 구현 목표

| # | 항목 | 지금 | 바꾼 뒤 |
|---|---|---|---|
| 1 | 무전 켜기 | 고를 수 없음, 항상 켜짐 | 방 생성 확인 화면의 무전 카드 스위치, **기본 꺼짐** |
| 2 | 대기방 | 없음 | 방장이 게임 설정에서 바꿈, 참가자는 읽기 전용 |
| 3 | 베타 표시 | 없음 | 무전 카드 제목 옆 Beta 칩 (인게임 버튼에는 없음) |
| 4 | 인게임 | 경찰이면 항상 무전 버튼 | 서버 값이 켜짐인 방의 경찰만 |

### ✏️ 문구

| 자리 | 한국어 | English | 日本語 | 출처 |
|---|---|---|---|---|
| 카드 제목 | 무전 | Radio | 無線 | 기존 `radioPttLabel` |
| 카드 설명 | 버튼을 길게 누르는 동안 말해요 | Hold the button to talk | ボタンを長押ししている間話せます | 기존 튜토리얼 무전 장면 `tutorialRadioBody` 첫 줄 (#719) |
| 칩 | Beta | Beta | Beta | 새 문구 (세 언어 공통) |

- 카드 설명은 튜토리얼 무전 장면에 이미 있는 문구를 가져왔다. 역할어(경찰·술래)가 없어 모드별 문구가 필요 없다. 구현할 때는 같은 값으로 새 키를 만들지, 튜토리얼 키를 같이 쓸지 정한다.
- 켜짐·꺼짐 상태에서 설명은 같다.

### 🧩 시안 기준

- 카드는 구역 축소 카드(`ShrinkToggleCard`)와 같은 틀이다: `InfoCard`, 제목 `label_16`, 설명 `tag_12`, 같은 스위치 색 규칙(켜짐: 경찰 `blueVer2Basic` / 도둑 `green`, 꺼짐: `black200` / `black800`).
- 참가자는 구역 축소처럼 스위치를 0.4로 흐리게 보여 주고 누를 수 없다.
- Beta 칩은 커뮤니티 모집 배지(`_StatusChip`)와 같은 토큰 구성이다: 좌우 8·상하 4, `AppRadius.xlarge`, `tag_10`, 배경 `AppColors.logo`, 글자 흰색. 칩 색은 이 시안에서 정한다.
- 카드 위치는 구역 축소 카드 바로 아래다. 방 생성 확인 화면과 대기방 게임 설정 모두 같다.
- 대기방 설정 시안은 화면 윗부분만 그렸다(구역 미리보기 지도 생략).
