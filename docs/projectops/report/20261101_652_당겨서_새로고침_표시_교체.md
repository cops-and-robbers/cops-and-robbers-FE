# 🎨[디자인][공통] 당겨서 새로고침 표시 교체

## 개요
커뮤니티 목록의 당겨서 새로고침 표시를 Material 기본 원판과 회전 링에서 앱의 사이렌 애니메이션과 파랑 파동으로 바꿨습니다. 공개 API는 그대로라 호출부 6곳은 수정하지 않았습니다. 테스트와 렌더링으로 동작을 확인했고, 실기기 확인은 아직 하지 못했습니다.

## 주요 구현 내용

- **사이렌:** `AppIcons.siren`의 좌표를 그대로 `CustomPainter`로 그려 빗살 3개를 따로 움직입니다. 새 에셋과 의존성이 없고 비동기 로딩이 없어 첫 프레임부터 보입니다. 원본 SVG와 렌더링을 비교해 크게 다른 픽셀이 없음을 확인했습니다.
- **색:** `black300` → `blue500` → `blueVer2Rich` → `blueVer2Basic` 토큰을 빗살이 하나 생길 때마다 한 칸씩 바꿉니다. 색 보간은 쓰지 않습니다.
- **파동:** `blueVer2Basic`, 800ms, 가장 먼 귀퉁이까지 퍼집니다. 손을 뗄 때 한 번만 나가고, 루트 오버레이에 띄워 하단 탭까지 덮으며 터치는 막지 않습니다. 표시가 먼저 접히거나 위젯이 사라져도 끝까지 갑니다.
- **진동:** 앱 공용 `VibrationService.buttonTap()`을 임계점 도달과 파동 400ms 지점에 1번씩 호출합니다.
- **iOS 바운스:** 손 뗀 뒤 목록을 바운스 위에 바로 밀면 66~72px 튀어서, `max(0, 60.h * value - 바운스 거리)`만큼만 밀어 바운스에 이어 붙입니다.
- **동작 줄이기:** 사이클과 파동 없이 멈춘 사이렌만 보입니다. 임계점 진동은 그대로 울립니다.

## 주의사항

- **실기기 미확인:** 실제 진동과 감촉, 로그인한 실제 앱의 호출부 6곳, 사이렌 버전의 광고 위 모습은 확인하지 못했습니다. iOS 튐 수치는 시뮬레이터에서 시험본으로 잰 값이고, 최종 위젯은 위젯 테스트로 고정했습니다.
- **리뷰 범위:** 브랜치 리뷰는 물결 점 버전 기준으로 받았고, 사이렌 코드는 별도 리뷰를 받지 않았습니다.
- **좌표 복제:** `icon_siren.svg`를 바꾸면 `RefreshSirenPainter` 좌표도 함께 고쳐야 합니다.
- **토큰 예외:** 파동 끝점 `withAlpha(0)`과 최대 불투명도 0.3은 토큰이 아닙니다. 끝점을 `AppColors.transparent`로 두면 회색 띠가 생겨 `ZoneExitVignette`와 같은 방법을 썼습니다. 파동이 흐리거나 진하면 0.3만 조정하면 됩니다.
- **테마:** 커뮤니티가 라이트 전용이라 다크 값이 없습니다. 게임 화면에 붙이면 `isDarkMode` prop을 더해야 합니다.
- **임시 빌드 주의:** `flutter build ios -t <임시 파일>`은 `ios/Flutter/Generated.xcconfig`에 진입점을 남깁니다. 다음 Xcode 빌드 전에 `flutter build ios --config-only`로 되돌려야 합니다.

검증: `flutter test` 1582건 통과, `flutter analyze lib test` 이슈 없음, 문구 톤 검사 통과.
