### 📌 작업 개요

앱을 처음 사용하는 유저의 진입장벽을 낮추기 위해 `tutorial_coach_mark` 패키지 기반 인앱 튜토리얼 시스템 구축. 홈, 방만들기 플로우, 구역 설정, 대기실, 게임 화면 등 주요 화면에 코치마크 가이드를 적용하고, 설정에서 초기화 가능하도록 구현.

### 🎯 구현 목표

- 각 화면 최초 진입 시 주요 UI 요소를 코치마크로 안내
- SharedPreferences 기반 완료 상태 관리 (화면별 독립)
- 설정 페이지에서 튜토리얼 전체 초기화 지원
- 로그아웃/회원탈퇴 시 튜토리얼 상태 자동 초기화

### ✅ 구현 내용

#### 튜토리얼 인프라 구축
- **파일**: `lib/core/services/tutorial/tutorial_keys.dart`
- **변경 내용**: 화면별 SharedPreferences 키 상수 정의 (`tutorial_home`, `tutorial_create_step0`, `tutorial_setup_playground`, `tutorial_create_step2`, `tutorial_waiting_room`, `tutorial_game`, `tutorial_game_participants`)
- **이유**: 각 화면의 튜토리얼 완료 여부를 독립적으로 추적

#### 튜토리얼 서비스
- **파일**: `lib/core/services/tutorial/tutorial_service.dart`
- **변경 내용**: `isCompleted()`, `markCompleted()`, `resetAll()` 정적 메서드 제공
- **이유**: SharedPreferences 접근을 캡슐화하여 각 화면에서 간편하게 사용

#### 코치마크 스타일 헬퍼
- **파일**: `lib/core/tutorial/app_tutorial_style.dart`
- **변경 내용**: `TutorialTarget`, `TutorialAlign`, `TutorialShape` 내부 타입 정의 + `AppTutorialStyle.target()`, `AppTutorialStyle.show()` 메서드 제공
- **이유**: `tutorial_coach_mark` 패키지 타입을 캡슐화하여 페이지에서 패키지를 직접 import하지 않도록 추상화

#### 홈 화면 튜토리얼
- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: `ConsumerWidget` → `ConsumerStatefulWidget` 변환. 방만들기/방참여하기 버튼에 GlobalKey 부착, `initState`에서 튜토리얼 트리거
- **안내 스텝**: 방만들기 → 방참여하기

#### 방만들기 플로우 튜토리얼
- **파일**: `lib/features/session/presentation/pages/session_creation_flow_page.dart` 외 4개 Step 위젯
- **변경 내용**: Step 0(구역 선택), Step 2(게임 설정)에 GlobalKey 추가. PageView 전환 시 해당 Step 튜토리얼 자동 트리거
- **안내 스텝**: Step 0 — 플레이그라운드 설정 / Step 2 — 라운드 시간, 위치 공유, 경찰 대기

#### 구역 설정 튜토리얼
- **파일**: `lib/features/session/presentation/pages/setup_playground_page.dart`, `lib/core/widgets/map/zone_setting_widget.dart`
- **변경 내용**: `ZoneSettingWidget`에 `radiusChipKey` 파라미터 추가. 플레이그라운드 페이지에서 반경 칩 입력 안내
- **안내 스텝**: 반경 칩 직접 입력 안내 (감옥 페이지는 플레이그라운드에서 이미 안내하므로 제외)

#### 대기실 튜토리얼
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`, `lib/features/session/presentation/widgets/team_section.dart`
- **변경 내용**: 팀 변경(경찰/도둑 AddSlotCard), 초대코드, 게임 설정, 준비 완료 버튼에 GlobalKey 부착. 초대코드 다이얼로그와 겹침 방지 — 다이얼로그 표시 시 튜토리얼 스킵, 미표시 시 튜토리얼 진행
- **안내 스텝**: 경찰팀 변경 → 도둑팀 변경 → 초대코드 → 게임 설정 → 준비 완료

**특이사항**: `_showInviteCodeDialog()`를 `Future<void>`로 변경하여 `await` 가능하게 함. 방장 진입 시 초대코드 다이얼로그가 닫힌 후 튜토리얼 표시.

#### 게임 화면 튜토리얼
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 지도 모드에서 타이머/참가자 버튼 안내. 참가자 목록 최초 진입 시 지도 복귀/QR 체포·탈옥 안내 (별도 키로 관리)
- **안내 스텝 (지도 모드)**: 타이머 → 참가자 버튼
- **안내 스텝 (참가자 모드)**: 지도 복귀 → QR (경찰: "도둑 참가자 카드를 누르거나 QR을 스캔하여 체포해요" / 도둑: "잡히면 경찰에게 QR을 보여주고, 경찰이 스캔하면 체포돼요")

**특이사항**: 지도(전체 화면 하이라이트 무의미), 채팅(DraggableScrollableSheet 접힘 상태라 안 보임), QR(참가자 모드에서만 렌더)은 튜토리얼 대상에서 제외.

#### 설정 페이지 — 튜토리얼 초기화
- **파일**: `lib/features/settings/presentation/pages/settings_page.dart`
- **변경 내용**: "이용 안내" 섹션에 "튜토리얼 초기화" 메뉴 추가. 확인 다이얼로그 → `TutorialService.resetAll()` → "앱을 재실행하면 적용돼요" 스낵바
- **이유**: 앱 재실행 없이 튜토리얼을 즉시 재표시하는 것이 기술적으로 제한적이라 안내 문구로 대체

#### 로그아웃/탈퇴 시 초기화
- **파일**: `lib/features/auth/presentation/providers/auth_provider.dart`
- **변경 내용**: `signOut()`, `forceLogout()`, `cleanupAfterAccountDeletion()` 3개 메서드에 `TutorialService.resetAll()` 호출 추가
- **이유**: 다른 계정으로 로그인하면 튜토리얼이 처음부터 다시 표시되어야 함

### 🧪 테스트 및 검증

- 최초 실행 시뮬레이션: SharedPreferences 클리어 후 각 화면 순차 진입 → 튜토리얼 정상 표시 확인
- 재진입 시 미표시: 각 화면 나갔다 다시 들어갔을 때 튜토리얼 미표시 확인
- 설정 초기화: 튜토리얼 초기화 → 앱 재실행 → 각 화면 튜토리얼 재표시 확인
- 로그아웃 후 재로그인: 튜토리얼 초기화 확인

### 📌 참고사항

- 튜토리얼은 스킵 불가 (`hideSkip: true`) — 각 화면의 UI를 모르면 플레이가 어려워 강제 1회 시청
- `tutorial_coach_mark` 패키지 타입이 페이지로 누출되지 않도록 `AppTutorialStyle`에서 `TutorialTarget`, `TutorialAlign`, `TutorialShape`로 캡슐화
- 방만들기 Step 1(인원 설정), Step 3(최종 확인)은 직관적이라 튜토리얼 제외
- 감옥 구역 설정은 플레이그라운드에서 이미 안내하므로 제외
