### 📌 작업 개요

게임 플레이 중 플레이어가 플레이그라운드 구역 밖으로 이탈하면 경고 팝업을 자동 표시하고, 구역 안으로 복귀하면 자동으로 닫히도록 구현. 기존 진동 피드백과 함께 시각적 안내를 추가하여 플레이어가 구역 이탈을 명확히 인지할 수 있도록 개선.

### 🎯 구현 목표

- 구역 이탈 시 `AppPopup` 형태의 경고 팝업 자동 표시
- 구역 복귀 시 팝업 자동 닫힘
- 이탈/복귀 상태 전환에 따른 팝업 중복 표시 방지
- 팝업 dismiss 시 다른 다이얼로그(재연결 로딩 등)에 영향 없도록 안전한 라우트 제거

### ✅ 구현 내용

#### 1. 구역 이탈 감지 도메인 클래스 추출

- **파일**: `lib/features/game/domain/zone_exit_detector.dart`
- **변경 내용**: 위치 업데이트마다 안/밖 상태 전환을 감지하는 `ZoneExitDetector` 클래스 생성
- **이유**: 이탈/복귀 판단 로직을 Presentation 계층에서 분리하여 단일 책임 원칙 준수 및 독립적 테스트 가능

#### 2. 포커스 가드 도메인 클래스 추출

- **파일**: `lib/features/chat/domain/input_focus_guard.dart`
- **변경 내용**: 사용자 탭에 의한 포커스와 프로그래매틱 포커스 복원을 구분하는 `InputFocusGuard` 클래스 생성
- **이유**: 다이얼로그 닫힘 시 포커스 자동 복원으로 채팅 시트가 의도치 않게 확장되는 버그 방지. 기존 `_userTapped` 플래그 로직을 도메인 클래스로 분리

#### 3. 경고 팝업 표시/닫기 로직

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**:
  - `_zoneExitDetector`를 통해 이탈 시 `_showZoneExitPopup()`, 복귀 시 `_dismissZoneExitPopup()` 호출
  - `_isZoneExitPopupShown` 플래그로 중복 팝업 방지
  - `Builder`로 다이얼로그 context를 캡처하여 `_zoneExitPopupContext`에 저장
  - `whenComplete`에서 팝업 참조 정리
- **이유**: 이탈 → 진동 + 팝업 표시, 복귀 → 팝업 자동 닫힘의 완전한 생명주기 관리

#### 4. 안전한 팝업 닫기 (removeRoute 방식)

- **파일**: `lib/features/game/presentation/pages/game_page.dart` (`_dismissZoneExitPopup`)
- **변경 내용**: `Navigator.pop()` 대신 `Navigator.removeRoute()`를 사용하여 해당 다이얼로그 라우트만 정확히 제거
- **이유**: 구역 이탈 팝업 위에 다른 팝업(재연결 로딩 등)이 쌓여 있을 때 `pop()`은 최상단 라우트를 닫아 잘못된 팝업이 닫히는 버그 발생. `removeRoute()`로 특정 라우트만 제거하여 안전하게 동작

### 🔧 주요 변경사항 상세

#### ZoneExitDetector

내부 `_isOutside` 상태를 추적하며, `update(isOutside:)` 호출 시 이전 상태와 비교하여 상태 전환이 발생한 경우에만 콜백 실행. 동일 상태 반복 시 콜백 중복 호출 방지

#### InputFocusGuard

`_userTapped` 플래그로 사용자 직접 탭과 프로그래매틱 포커스 복원을 구분. `markUserTapped()` → `handleFocusGained()` 순서일 때만 `onAllowFocus` 호출, 그 외엔 `onRejectFocus` 호출. 포커스 상실 시 플래그 자동 리셋

#### 팝업 dismiss 안전성

`showDialog`의 `builder` 내부에서 `Builder` 위젯으로 다이얼로그 context를 캡처. 닫을 때 해당 context에서 `ModalRoute.of()`로 라우트를 찾아 `removeRoute()`로 제거. 이로써 팝업 스택 순서와 무관하게 정확한 팝업만 닫힘

**특이사항**:
- `barrierDismissible: false`로 설정하여 사용자가 팝업을 임의로 닫을 수 없음 (구역 복귀로만 닫힘)
- 다크/라이트 모드(경찰/도둑 팀)에 따른 팝업 스타일 분기 적용

### 🧪 테스트 및 검증

#### ZoneExitDetector 단위 테스트 (7개)
- 구역 밖 전환 시 `onExitZone` 콜백 호출 확인
- 구역 안 복귀 시 `onEnterZone` 콜백 호출 확인
- 밖→안→밖→안 반복 시 콜백 정확한 순서 검증
- 동일 상태 반복 시 중복 호출 방지 검증
- 초기 상태 및 상태 반영 검증

#### InputFocusGuard 단위 테스트 (7개)
- 사용자 탭 후 포커스 → `onAllowFocus` 호출 확인
- 프로그래매틱 포커스 → `onRejectFocus` 호출 확인
- 포커스 상실 시 플래그 리셋 검증
- 연속 시나리오(탭→포커스→해제→재포커스) 검증

#### 팝업 dismiss 안전성 위젯 테스트 (2개)
- `pop()` 사용 시 최상단(잘못된) 라우트가 닫히는 버그 재현
- `removeRoute()` 사용 시 특정 팝업만 정확히 제거되는 수정 방식 검증

### 📌 참고사항

- 기존 `_checkPlaygroundDistance()` 메서드의 직접 이탈 판단 로직이 `ZoneExitDetector.update()` 호출로 대체됨
- 팝업 텍스트: "플레이그라운드를 벗어났어요!" / "구역 안으로 돌아와서 진행해 주세요"
- 진동 피드백(`VibrationService.zoneExit()`)은 기존 동작 유지하며 팝업과 함께 실행
