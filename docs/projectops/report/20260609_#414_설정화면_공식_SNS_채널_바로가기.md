# 설정 화면 공식 SNS 홍보 채널 바로가기 추가 #414

### 📌 작업 개요
설정 화면 하단에 공식 SNS 채널(인스타그램·유튜브·틱톡) 바로가기 행을 추가. 안내 문구와 균일한 슬레이트 톤 원형 아이콘 3개를 노출하고, 탭 시 외부 브라우저로 각 채널을 연다. 안내 문구는 ko/en/ja 다국어로 제공한다.

> 작업은 기능 추가(1) + 문안·스타일 조정(2)으로 나뉘어 진행됨

### 🎯 구현 목표
- 설정 화면 최하단에 공식 SNS 채널 진입 동선 추가
- 채널별 단색 글리프를 동일한 슬레이트 원 안에 통일된 톤으로 노출
- 아이콘만 노출되므로 스크린리더 접근성 확보
- 안내 문구 다국어 대응(ko/en/ja)

### ✅ 구현 내용

#### SNS 채널 행 위젯 신규 추가
- **파일**: `lib/features/settings/presentation/widgets/sns_channel_row.dart`
- **변경 내용**: 안내 문구 + 채널 칩 3개를 세로로 묶은 `SnsChannelRow`(StatelessWidget) 신규 작성
- **이유**: 설정 화면 본문과 분리된 독립 컴포넌트로 두어 재사용·유지보수 용이하게 구성

#### 채널 메타데이터 상수 정의
- **파일**: `lib/core/constants/sns_channels.dart`
- **변경 내용**: `SnsChannel` 모델(글리프 경로·라벨·URL)과 노출 순서가 고정된 `officialSnsChannels` 목록 정의
- **이유**: 위젯에서 URL·라벨을 하드코딩하지 않고 상수 한 곳에서 채널 목록을 관리

#### 슬레이트 톤 컬러 상수 추가
- **파일**: `lib/core/constants/app_colors.dart`
- **변경 내용**: `slate100`(`0xFFF1F5F9`, 원 배경), `slate500`(`0xFF64748B`, 글리프) 추가
- **이유**: 원 배경과 단색 글리프에 적용할 톤을 `AppColors` 팔레트 상수로 일원화 (HEX 하드코딩 회피)

#### 설정 페이지에 행 연결
- **파일**: `lib/features/settings/presentation/pages/settings_page.dart`
- **변경 내용**: 섹션 디바이더 아래에 `const SnsChannelRow()` 배치
- **이유**: 기존 설정 항목과 시각적으로 구분되도록 구분선 뒤 최하단에 배치

#### 안내 문구 다국어 추가
- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb` (+ 자동 생성 `app_localizations*.dart`)
- **변경 내용**: `settingsSnsPrompt` 키 추가
  - ko: `더 많은 소식이 궁금하다면 👀`
  - en: `Curious about more updates? 👀`
  - ja: `もっと最新情報が気になるなら 👀`
- **이유**: 프로젝트 i18n 규칙에 따라 UI 텍스트를 ARB 정본에 추가 후 `AppLocalizations`로 사용

#### 채널 아이콘 에셋 추가
- **파일**: `assets/icons/instagram_black.svg`, `youtube_black.svg`, `tiktok_black.svg`
- **변경 내용**: 단색(검정) 글리프 SVG 3종 추가
- **이유**: 원 안에서 `colorFilter`로 슬레이트색을 입히는 방식이라 단색 글리프 원본이 필요

### 🔧 주요 변경사항 상세

#### SnsChannelRow
안내 문구(`Text`)와 채널 칩 `Row`를 `Column`으로 묶고, `AppPadding.all24`로 전체 여백을 둔다. 칩 사이 간격은 `AppSpacing.horizontal24`, 문구와 칩 묶음 사이는 `AppSpacing.vertical24`로 둔다.

각 칩(`_ChannelChip`)은 지름 44의 `slate100` 원 위에 한 변 22의 글리프를 얹고, `ColorFilter.mode(slate500, BlendMode.srcIn)`로 단색 톤을 통일한다. 탭 시 `launchExternalUrl(channel.url)`로 외부 브라우저를 연다.

**특이사항**:
- **접근성**: 칩에 시각적 텍스트 라벨이 없어 `Semantics(label: channel.label, button: true)`로 스크린리더용 채널명을 제공
- **탭 영역**: `GestureDetector`에 `HitTestBehavior.opaque`를 적용해 원 내부 투명 영역도 탭이 먹도록 처리
- **크기 단위**: 원/글리프 크기에 `.w`(ScreenUtil)를 적용해 반응형 대응

#### 안내 문구 문안·스타일 조정 이력
초기 구현 후 문안과 스타일이 두 차례 조정됨:
1. 안내 문구에서 이모지(👀) 제거
2. 문안을 `더 많은 소식이 궁금하다면 👀`으로 변경(이모지 재반영), 텍스트 스타일을 `tag_12` → `paragraph14Semibold`로, 패딩을 `EdgeInsets.symmetric(h24, v16)` → `AppPadding.all24`로 변경

**특이사항**: 최종 문안에는 이모지(👀)가 다시 포함됨. 중간에 한 번 제거되었다가 문안 개편과 함께 재반영된 결과로, 현재 ko/en/ja 모두 👀로 끝남
