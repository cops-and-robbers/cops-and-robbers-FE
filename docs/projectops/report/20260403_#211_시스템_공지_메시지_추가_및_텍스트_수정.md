### 📌 작업 개요

인게임 시스템 공지 메시지를 확장하고, 마퀴 알림 배너 위젯을 새로 구현하여 게임 이벤트 알림 UX를 전면 개선. 기존 정적 배너를 우→좌 스크롤 마퀴 + 슬라이드 인/페이드아웃 애니메이션으로 교체하고, 체포·탈옥 이벤트의 시스템 채팅 연동 및 참가자 목록 shimmer 로딩 스켈레톤을 추가.

### 🎯 구현 목표

- `GameEventMessages` 상수 확장 (4개 → 12개 메시지)
- 게임 시작 4단계 시퀀스 시스템 채팅 + 배너 연동
- 체포·탈옥 이벤트 시스템 채팅 메시지 자동 생성
- 마퀴 알림 배너 위젯 신규 구현 (우→좌 반복 스크롤)
- 참가자 목록 shimmer 스켈레톤 로딩 (대기방 + 인게임)
- 시스템 메시지 인라인 아이콘 마커 파싱

### ✅ 구현 내용

#### 1. 게임 이벤트 메시지 상수 확장
- **파일**: `lib/core/constants/game_event_messages.dart`
- **변경 내용**: 기존 `gameStart`, `policeMove`, `locationReveal`, `gameOver` 4개에서 12개로 확장
- **추가 항목**: 게임 시작 4단계(`gameStartTime`, `gameStartReady`, `gameStartReportTip`, `gameStartGo`), 경찰 출동 예고(`policeMoveWarning`), 체포 공지(`arrestNotice` — 동적 닉네임 + 아이콘 마커), 탈옥 공지(`escapeNotice`), 도주 인원(`remainingRobbers`), 종료 5분전(`fiveMinutesLeft`)
- **삭제**: `gameStart`, `gameOver` (모달로 대체)

#### 2. 마퀴 알림 배너 위젯
- **파일**: `lib/features/game/presentation/widgets/marquee_alert_banner.dart` (신규)
- **구현 내용**: `SlideTransition`(위→아래 등장) + `FadeTransition`(8초 후 페이드아웃) + `AnimatedBuilder`(우→좌 마퀴 반복 스크롤)
- **특징**: OverflowBox로 긴 텍스트 잘림 방지, 다크모드 폰트 분기(`robberParagraph` / `paragraph14Semibold`), Timer 기반 fade-out으로 연속 메시지 안전 처리

**특이사항**:
- 배너 지속시간 8초 + 페이드아웃 800ms → provider 타이머 8800ms로 위젯 제거 시점 맞춤
- `didUpdateWidget`에서 `_marqueeController..reset()..repeat()`로 repeat 모드 유지 보장
- `_fadeOutTimer?.cancel()`로 연속 메시지 시 이전 타이머 취소

#### 3. 게임 시작 4단계 시스템 메시지 시퀀스
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `_sendGameStartSystemMessages()` 메서드 추가. 게임 페이지 진입 시 10초 간격으로 4단계 메시지를 채팅 + 배너에 동시 발송
- **재입장 방지**: `gameStartTime` 기준 20초 이상 경과 시 스킵 (앱 terminate 후 재접속 대응)
- **순서**: `_initSettingsFromApiIfNeeded()` 완료 후 호출하여 `participantInfo` 로드 보장

#### 4. 체포·탈옥 이벤트 시스템 채팅 연동
- **파일**: `lib/features/game/presentation/providers/game_event_provider.dart`
- **변경 내용**: `GameEventState`에 `lastArrestPoliceNickname`, `arrestEventCount`, `escapeEventCount` 필드 추가. `_handleArrest`에서 경찰 닉네임 파싱 + 배너 메시지 설정(아이콘 마커 strip) + 이벤트 카운터 증가. `_handleEscape`에서 배너 + 카운터 증가.
- **dedup 방식**: STOMP 확정 이벤트 전용 카운터(`arrestEventCount`) 기반. optimistic update의 `arrestedParticipantIds.length`와 분리하여 체포→탈옥→재체포 사이클에서도 정확히 동작

**특이사항**:
- `arrestEventCount`는 `robberNickname != null && policeNickname != null`일 때만 증가 (불완전 이벤트 방어)
- 체포 리스너 selector에 닉네임을 포함하여 race condition 방지 (카운터만 감시 시 `ref.read`로 읽는 닉네임이 다른 이벤트의 것일 수 있음)

#### 5. 시스템 메시지 인라인 아이콘 파싱
- **파일**: `lib/features/chat/presentation/widgets/chat_message_bubble.dart`
- **변경 내용**: `_buildSystemMessage`에서 `Text` → `RichText` + `_parseSystemMessageSpans()` 변경. `@icon_police`/`@icon_robber` 마커를 정규식 파싱 → `WidgetSpan`으로 경찰/도둑 SVG 아이콘 인라인 삽입
- **접근성**: `textScaler: MediaQuery.textScalerOf(context)` 추가하여 시스템 글꼴 크기 설정 반영

#### 6. 시스템 공지 preview 제거
- **파일**: `lib/features/chat/presentation/providers/chat_provider.dart`
- **변경 내용**: `addSystemMessage`에서 `lastPreviewMessage` 설정 제거. 시스템 공지는 배너로만 표시, preview 카드는 유저 간 채팅에만 표시

#### 7. 참가자 목록 shimmer 스켈레톤
- **파일**: `lib/core/widgets/loading/shimmer_participant_skeleton.dart` (신규)
- **적용 위치**: 인게임 참가자 오버레이(`participant_overlay.dart`), 대기방(`waiting_room_page.dart`)
- **구현 내용**: `Shimmer.fromColors` 기반 팀 헤더 + 카드 4개×2행 플레이스홀더. 다크/라이트 모드 색상 분기. 공용 위젯으로 추출하여 DRY 원칙 준수

#### 8. 기타 수정
- 알림 배너 z-index를 경찰 카운트다운보다 위로 변경 (Stack 순서 조정)
- 방장 아바타 색상 조건 제거 — ready 상태 기반으로 통일
- `setBannerMessage()` public 메서드 추가 (STOMP 외 이벤트에서 배너 트리거용)

### 📦 의존성 변경
- `shimmer: ^3.0.0` 패키지 추가 (참가자 목록 로딩 스켈레톤용)

### 🧪 테스트 및 검증
- 게임 시작 → 4단계 시스템 메시지 순차 발송 확인 (10초 간격)
- 앱 terminate 후 재접속 시 시작 메시지 중복 발송 안 됨 확인
- 체포·탈옥 이벤트 → 시스템 채팅 + 배너 동시 표시 확인
- 체포→탈옥→재체포 사이클에서 시스템 메시지 정상 생성 확인
- 마퀴 배너 슬라이드 인/페이드아웃/마퀴 스크롤 동작 확인
- 연속 배너 교체 시 이전 타이머 취소 및 마퀴 repeat 유지 확인
- 인라인 아이콘 마커 파싱 및 렌더링 확인 (채팅 내 경찰/도둑 아이콘)
- shimmer 스켈레톤 로딩 표시 확인 (대기방 + 인게임 참가자 오버레이)

### 📌 참고사항
- `fiveMinutesLeft`, `policeMoveWarning`, `remainingRobbers(n)` 메시지는 상수만 정의. 서버 이벤트 확정 후 별도 이슈에서 연동 예정
- 구역 이탈 `app_popup`은 이번 이슈 범위에서 미구현 (별도 이슈 필요)
- 배너 메시지 큐 미구현 — 동시 이벤트 발생 시 마지막 메시지로 덮어쓰기 방식
