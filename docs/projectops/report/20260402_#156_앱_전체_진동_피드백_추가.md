### 📌 작업 개요

앱 전체에 진동 피드백 시스템 구축. 인게임 이벤트(체포, 탈옥, 위치 공개, 영역 이탈, 게임 종료), 대기방 이벤트(입장/퇴장, 게임 시작), 채팅 수신, UI 버튼 탭에 각각 고유한 진동 패턴 적용. 채팅 알림 on/off 토글 기능 추가 및 체포 시 QR 다이얼로그 자동 닫힘 처리.

### 🎯 구현 목표

- 게임 중 시각적 피드백만으로 부족했던 이벤트 인지를 진동으로 보완
- 이벤트 종류별 차별화된 진동 패턴/강도로 직관적 UX 제공
- 채팅 알림 on/off 토글로 사용자가 게임 중 알림 제어 가능
- 서버 통신 없이 클라이언트 단에서 전부 처리

### ✅ 구현 내용

#### 1. 진동 서비스 코어

- **파일**: `lib/core/constants/vibration_patterns.dart` (신규)
- **변경 내용**: 이벤트별 진동 패턴 상수 중앙 관리. 단일 진동(duration/amplitude)과 패턴 진동(pattern/intensities) 두 가지 타입으로 구분
- **진동 패턴 명세**:
  - 버튼 탭: OS 네이티브 HapticFeedback.lightImpact
  - 채팅 수신: 100ms / amplitude 80
  - 입장·퇴장: 80ms / amplitude 60
  - 게임 시작: [0,200,100,200,100,500] / [0,200,0,200,0,255]
  - 체포: 500ms / amplitude 255 (최대 강도)
  - 탈옥: [0,200,100,200] / [0,200,0,200]
  - 위치 공개: 250ms / amplitude 150
  - 영역 이탈: [0,300,100,300,100,300] / [0,255,0,255,0,255]
  - 게임 종료: [0,200,100,200,100,500] / [0,200,0,200,0,255]

- **파일**: `lib/core/services/vibration_service.dart` (신규)
- **변경 내용**: 싱글톤 서비스. 앱 시작 시 디바이스 지원 여부(vibrator, amplitude, custom pattern) 캐싱. amplitude 미지원 기기에서는 duration만으로 폴백, custom pattern 미지원 시 진동 구간 합산 단일 진동으로 폴백

- **파일**: `lib/main.dart`
- **변경 내용**: 앱 시작 시 `VibrationService.instance().init()` 호출 추가

- **파일**: `pubspec.yaml`
- **변경 내용**: `vibration: ^3.1.8` 의존성 추가

#### 2. 진동 피드백 적용 — UI 버튼 햅틱

- **변경 내용**: 주요 버튼(다이얼로그 확인, 세션 생성, 준비 토글, 게임 시작, 코드 복사, 채팅 전송)에 `VibrationService.instance().buttonTap()` 호출 추가

- **파일**: `lib/features/game/presentation/providers/game_event_provider.dart`
- **변경 내용**: ARREST, ESCAPE, LOCATION_REVEAL, GAME_OVER 이벤트 수신 시 각각 `arrested()`, `escaped()`, `locationRevealed()`, `gameEnd()` 진동 호출

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 위치 스트림에서 플레이그라운드 영역 이탈 감지 로직 추가. `_isOutsideZone` 플래그로 안→밖 전환 시에만 1회 진동 (반복 방지)

- **파일**: `lib/features/lobby/presentation/providers/lobby_provider.dart`
- **변경 내용**: ENTER/EXIT 이벤트 시 `playerJoinLeave()`, GAME_START 이벤트 시 `gameStart()` 진동 호출

- **파일**: `lib/features/chat/presentation/providers/chat_provider.dart`
- **변경 내용**: 메시지 수신 시 알림 on/off 상태 확인 후 `messageReceived()` 진동 호출

#### 4. 채팅 알림 토글 (벨 아이콘)

- **파일**: `lib/features/chat/presentation/providers/chat_notification_provider.dart` (신규)
- **변경 내용**: `StateProvider<bool>` 기반 인메모리 상태. 기본값 true(ON). 게임 종료 시 `ref.invalidate()`로 자동 초기화. SharedPreferences 미사용 (게임당 1회성)
- **설계 원칙**: SRP — VibrationService는 진동만 담당, 알림 on/off는 별도 provider가 관리

- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`
- **변경 내용**:
  - `_buildTitle()`에 벨 아이콘(icon_bell_on/off.svg) 토글 버튼 추가
  - 다크모드: on=green, off=green500 / 라이트모드: on=blue, off=blue500
  - 알림 OFF 시 프리뷰 카드 숨김 + 잔여 프리뷰 즉시 dismissPreview()
  - `expandedMinHeight` 계산에 `_pageIndicatorHeight` 누락 수정 (기존 오버플로우 버그 해결)
  - `_titleAreaHeight` 60→72로 보정 (벨 아이콘 48 + 패딩 24)

- **파일**: `lib/features/chat/presentation/providers/chat_provider.dart`
- **변경 내용**: `_handleUnreadUpdate()`에서 알림 상태 분기. 카운트는 항상 증가, 진동과 프리뷰만 알림 ON일 때 실행. 알림 OFF에서도 힌트 텍스트로 읽지 않은 메시지 수 표시

- **파일**: `lib/core/services/vibration_service.dart`
- **변경 내용**: 채팅 관련 SharedPreferences 로직 전부 제거 (`_chatVibrationKey`, `_isChatVibrationEnabled`, `setChatVibrationEnabled()`, `init()` 내 prefs 로딩). `messageReceived()`는 호출되면 무조건 진동 (호출 여부를 ChatNotifier가 판단)

#### 5. 체포 시 QR 다이얼로그 자동 닫기

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `arrestedParticipantIds` 변화 감지 리스너 추가. 자신이 새로 체포되면 `Navigator.of(context).popUntil((route) => route is! PopupRoute)`로 열려있는 다이얼로그(QR 등) 즉시 닫기. 게임 종료 시 `chatNotificationEnabledProvider` invalidate 추가

### 📌 참고사항

- 모든 진동 처리는 클라이언트 단에서 완결. 서버 통신 불필요
- amplitude 미지원 기기(일부 Android)에서는 duration만으로 자동 폴백
- iOS는 amplitude control을 지원하지 않아 duration 기반으로 동작
- 채팅 알림 토글 상태는 게임 종료 시 자동 초기화되므로 매 게임 시작 시 ON 상태
- 영역 이탈 진동은 안→밖 전환 시 1회만 발생하여 연속 진동 방지
