# 🚀 AppSlider 숫자 키패드 입력 지원 및 위치 공유 간격 최소값 0 허용 #253

### 📌 작업 개요
`AppSlider`의 값 표시 영역을 탭하면 숫자 키패드로 직접 입력할 수 있도록 편집 모드를 추가하고, 위치 공유 간격 슬라이더의 최소값을 0으로 내려 "위치 공유 비활성화" 상태를 지원. 드래그 기반 기존 사용성은 그대로 유지. 위치 공유 0 허용은 백엔드 API 미지원으로 1로 임시 롤백(`TODO` 주석으로 표기).

### 🎯 구현 목표
- AppSlider 값 영역 탭 → 숫자 키패드로 직접 입력
- 입력값 `min~max` 자동 클램핑, 디바운스 처리, 포커스/제출 시 편집 종료
- 기존 `displayValue` / `displayPrefix` / `displaySuffix` / `valueFormatter` 조합과 호환
- 위치 공유 간격 최소값 0 허용 (0 = 위치 공유 비활성화)
- 숫자 키패드에는 "완료" 키가 없는 플랫폼 한계 → 화면 전환 시 키패드 잔존 방지

### 🔧 주요 변경사항 상세

#### `_EditableValueText` (app_slider.dart 내부)
비공개 `StatefulWidget`으로 값 영역을 캡슐화. 비편집 시 일반 `Text`, 편집 시 `IntrinsicWidth` + `ConstrainedBox(minWidth: 24.w)` + `TextField`로 전환.

- `keyboardType: TextInputType.numberWithOptions(decimal: false)` — 정수 입력 전용
- `inputFormatters: [FilteringTextInputFormatter.digitsOnly]` — 숫자 외 차단
- `maxLength: max.toInt().toString().length` — 상한 자릿수 제한 (카운터 UI는 숨김)
- `Timer(const Duration(milliseconds: 100), _applyCurrentInput)` — 디바운스로 과도한 `onChanged` 호출 방지
- `_focusNode.addListener`로 포커스 해제 감지 → 자동 `_completeEditing()`

**특이사항**:
- `editable && displayValue != null` 조합은 `assert`로 금지 — `displayValue`는 임의 문자열이라 숫자 입력 위치 특정 불가
- 편집 중에 부모가 `didUpdateWidget`으로 value를 밀어넣어도 controller를 덮어쓰지 않음 (사용자 입력 보호). 편집 종료 후 다음 `_startEditing()`에서 최신 값으로 재바인딩
- `mainAxisSize: MainAxisSize.min` + `IntrinsicWidth`로 TextField 폭이 내용에 맞게 축소됨 → 기존 Row 레이아웃과 호환

#### 위치 공유 간격 기본/최소값 정책
- 초기 커밋: `min: 0`, 기본값 `1분`
- 중간 커밋: 기본값 `1분 → 5분` (실사용자가 0 또는 1로 잘못 시작하는 사례 방지)
- 최종 롤백: `min: 0 → 1` (서버 검증이 0을 거부)
- 코드에 `TODO : 추후에 API 생기면 0으로 변경` 주석으로 복원 조건 명시

#### 키패드 잔존 방지 흐름
숫자 키패드에는 "완료" 키가 없어서 사용자가 명시적으로 닫을 방법이 없음. 해결책은 세 가지 레이어에서 방어:

1. **편집 종료 자동화**: `_focusNode`의 포커스가 다른 위젯으로 옮겨가면 `_completeEditing()` 호출 — 이때 키패드도 닫힘
2. **페이지 이동 시 강제 해제**: `_goToPreviousStep()` / `_goToNextStep()` 시작부에 `FocusScope.of(context).unfocus()`
3. **설정 수정 페이지 저장/뒤로**: `_saveSettings()` / `PreviousButton.onPressed`에도 동일한 `unfocus()` 호출
