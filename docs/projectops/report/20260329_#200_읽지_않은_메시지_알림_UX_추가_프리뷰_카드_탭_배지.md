### 📌 작업 개요

채팅 시트가 접혀있거나 다른 탭을 보고 있을 때 새 메시지 도착을 인지할 수 없는 문제 해결. 슬라이드-인 프리뷰 카드 + 탭 읽지 않은 배지 + 입력바 힌트 텍스트를 통해 읽지 않은 메시지 알림 UX 구현. 추가로 욕설 필터링 구조를 Extension 기반 공통 패턴으로 리팩토링, 매직 문자열 상수화, 디자인 시스템 일관성 정리, 프리뷰 카드 디자인 개편(스코프별 태그·공지·+N 배지), 시스템 메시지 프리뷰 지원까지 포함.

**PR**: [#201](https://github.com/cops-and-robbers/cops-and-robbers-FE/pull/201) (19 commits, +1,782 / -571)

### 🎯 구현 목표

- 채팅 시트 접힘 상태에서 새 메시지 프리뷰 카드 표시
- 시트 펼침 상태에서 다른 탭에 읽지 않은 메시지 있으면 빨간 점 배지 표시
- 입력바 힌트 텍스트에 전체/팀 읽지 않은 메시지 수 분리 표시
- 프리뷰 카드 탭 시 해당 스코프 탭으로 시트 자동 펼침
- 욕설 필터링을 Extension으로 통합하여 프리뷰 카드 포함 모든 표시 지점에 적용
- 매직 문자열(`'TEAM'`, `'ALL'` 등) 상수 클래스로 추출
- 하드코딩 레이아웃 값을 디자인 시스템 상수(`AppSpacing`/`AppRadius`)로 치환
- 프리뷰 카드 디자인 개편 — 스코프별 태그 색상 분리, 공지 타입 추가, +N 배지

### 🔧 주요 변경사항 상세

#### 읽지 않은 메시지 동작 흐름

```
새 메시지 도착 → _handleUnreadUpdate()
  ├─ myParticipantId 미설정(null)? → 필터링 스킵 (모든 메시지 카운트)
  ├─ 내 메시지? → 무시
  ├─ 차단된 사용자? → 무시
  ├─ 시트 펼쳐짐 + 해당 탭 보는 중? → 무시 (바로 읽힘)
  └─ 그 외 → 카운트 증가 + lastPreviewMessage 설정
       ├─ TEAM: 항상 프리뷰 덮어씀 (우선순위 높음)
       └─ ALL: 팀 프리뷰가 있으면 프리뷰 안 바꿈
```

#### 시스템 메시지(공지) 프리뷰 흐름

```
addSystemMessage() → allScopeMessages에 추가 + lastPreviewMessage 설정
  ├─ unreadCount 증가 안 함 (공지는 읽지 않은 메시지에 포함되지 않음)
  └─ 프리뷰 카드에서 "공지" 태그 + red 텍스트로 표시
```

#### 프리뷰 카드 배치 구조

프리뷰 카드는 `DraggableScrollableSheet` 외부 Stack에 `Positioned`로 배치. 시트 내부에 두면 Container의 `Clip.hardEdge`에 의해 잘리는 문제가 있어 외부로 이동.

### 📌 참고사항

- 서버 API 변경 없음 (클라이언트 전용 기능)
- `ChatMessageDto` freezed 모델 변경 없음 — Extension으로 기능 확장
- `_myParticipantId`를 `int?`로 변경하여 sentinel 값(-1) 대신 null safety 활용
- `GAME_START` 이벤트는 로비 STOMP에서 수신 후 네비게이션되므로 게임 페이지의 Game Event STOMP에서는 재수신 불가 — 게임 시작 시스템 메시지 순차 주입 로직은 이 제약으로 제거됨
- `GameEventMessages`에 추가된 메시지 상수들(`timeLimit`, `chatGuide`, `policeMoveWarning`, `fiveMinWarning`)은 향후 게임 진행 단계별 공지 구현 시 사용 예정
- App Store 가이드라인 1.2(UGC) 준수: 모든 채팅 텍스트 표시 지점에 필터링 보장
