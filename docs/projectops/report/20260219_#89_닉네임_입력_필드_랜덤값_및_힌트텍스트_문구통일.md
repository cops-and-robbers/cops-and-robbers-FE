### 📌 작업 개요

닉네임 설정 페이지에서 사용자가 랜덤 닉네임을 삭제했을 때 노출되는 placeholder 텍스트가 백엔드 랜덤 닉네임과 톤앤매너가 불일치하는 문제 수정.
기존 하드코딩된 placeholder(`"포근포근백설기"`)를 백엔드에서 생성한 랜덤 닉네임 응답값으로 대체하여 문구를 통일함.

**이슈**: [#89](https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/89)

---

### 🔍 문제 분석

**기존 동작:**

- 백엔드 랜덤 닉네임 패턴: `"민첩한괴도5308"`, `"집요한괴도4053"` (형용사 + 괴도 + 숫자4자리)
- placeholder 텍스트: `"포근포근백설기"` (하드코딩, 귀여운/따뜻한 톤)
- 사용자가 입력창을 비웠을 때 보이는 힌트가 백엔드 닉네임과 전혀 다른 톤 → UX 혼란

**원인:**

- placeholder 문자열이 하드코딩되어 있어 백엔드 닉네임 생성 규칙과 독립적으로 관리되고 있었음

---

### ✅ 구현 내용

#### hintText를 백엔드 랜덤 닉네임 응답값으로 통일

- **파일**: `lib/features/auth/presentation/pages/nickname_setup_page.dart`
- **변경 내용**: `AppTextField`의 `hintText`를 하드코딩 문자열에서 `widget.initialNickname`(백엔드 응답값)으로 변경
- **이유**: 백엔드가 생성한 실제 랜덤 닉네임을 placeholder로 사용하면 톤앤매너가 자동으로 일치

---

### 🔧 주요 변경사항 상세

#### nickname_setup_page.dart (270번 라인)

`_buildNicknameInputRow()` 메서드 내 `AppTextField`의 `hintText` 로직 변경:

**변경 전:**

```dart
AppTextField(
  hintText: '포근포근백설기',
  ...
)
```

**변경 후:**

```dart
AppTextField(
  hintText: widget.initialNickname.isNotEmpty
      ? widget.initialNickname
      : '닉네임을 입력하세요',
  ...
)
```

**동작 방식:**

- `initialNickname`이 존재하는 경우 (정상 플로우): 백엔드가 생성한 랜덤 닉네임이 placeholder로 표시
- `initialNickname`이 빈 문자열인 경우 (예외 플로우): 기본 안내 메시지 `"닉네임을 입력하세요"` 표시

**특이사항:**

- 별도 상수 파일 생성 없이 기존 `widget.initialNickname` 속성을 활용하여 간결하게 해결
- 백엔드 닉네임 생성 규칙이 변경되더라도 프론트엔드 수정 불필요 (동적으로 반영)

### 🧪 테스트 및 검증

- 닉네임 설정 페이지 진입 시 백엔드 랜덤 닉네임이 입력창에 자동 입력됨 확인
- 입력창 내용을 모두 삭제했을 때 placeholder에 동일한 랜덤 닉네임이 표시됨 확인
- `initialNickname`이 빈 문자열일 경우 `"닉네임을 입력하세요"` 폴백 메시지 표시 확인
