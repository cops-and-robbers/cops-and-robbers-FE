### 📌 작업 개요

로비에서 방장이 특정 참가자를 강제 퇴장시키는 기능 구현. 백엔드 `DELETE /api/games/{gameId}/lobby/{participantId}` API 연동, STOMP `KICKED` 이벤트 처리, 강퇴 확인 다이얼로그 및 사용자 피드백 UI 추가.

### 🎯 구현 목표

- 방장 전용 강제 퇴장 UI 및 확인 다이얼로그 제공
- KICKED STOMP 이벤트 수신 시 강퇴당한 유저/나머지 유저에게 각각 다른 피드백
- 에러 응답 처리 (권한 없음, 게임 상태 불일치 등)

### ✅ 구현 내용

#### KICKED 이벤트 타입 추가
- **파일**: `lib/features/lobby/data/models/lobby_event_dto.dart`
- **변경 내용**: `LobbyEventType`에 `kicked = 'KICKED'` 상수 추가
- **이유**: STOMP 로비 이벤트에서 강제 퇴장 타입 식별

#### kickMember API 메서드 추가 (Retrofit)
- **파일**: `lib/features/session/data/datasources/session_remote_datasource.dart`
- **변경 내용**: `@DELETE('/api/games/{gameId}/lobby/{participantId}')` Retrofit 메서드 추가
- **이유**: 백엔드 강제 퇴장 API 호출

#### kickMember Riverpod Provider 추가
- **파일**: `lib/features/session/presentation/providers/session_provider.dart`
- **변경 내용**: `kickMemberProvider(gameId, participantId)` 추가
- **이유**: UI에서 API 호출을 위한 provider 제공

#### KICKED 이벤트 핸들러 추가
- **파일**: `lib/features/session/presentation/providers/waiting_room_participants_provider.dart`
- **변경 내용**: `handleLobbyEvent`에 `KICKED` 케이스 추가. `kickedParticipantId`로 해당 참가자를 목록에서 제거
- **이유**: KICKED 이벤트 수신 시 참가자 목록 실시간 갱신

#### 방장 강퇴 확인 다이얼로그 + API 호출
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**:
  - `_showKickDialog(member)` 메서드 추가 — `AppDialog.confirm` 으로 확인 후 `kickMemberProvider` 호출
  - 양쪽 `TeamSection`에 `onMemberTap` 콜백 전달 (방장일 때만 활성화, 자기 자신 탭 무시)
  - `isDestructive: true`, `confirmTextColor: AppColors.white`, `isDarkMode: 방장 팀 기준`
- **이유**: 방장만 다른 참가자를 강퇴할 수 있도록 UI 제한

#### KICKED 이벤트 UI 피드백
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**:
  - `_handleKickedEvent(data, myPid)` 메서드 추가
  - 강퇴당한 본인 (`kickedPid == myPid`) → `AppDialog.show` "방에서 내보내졌어요" + 홈 이동
  - 다른 유저 (`kickedPid != myPid`) → 스낵바 "{닉네임}님이 내보내졌어요"
  - `null == null` 오인식 방어 가드 추가 (`kickedPid == null || myPid == null → return`)
  - `catch (_)` 추가로 non-DioException도 처리
- **이유**: 강퇴당한 유저와 나머지 유저에게 각각 적절한 피드백 제공

### 🔧 주요 변경사항 상세

#### 강퇴 흐름
1. 방장이 참가자 카드 탭 → 확인 다이얼로그 표시
2. "내보내기" 확인 → `DELETE /api/games/{gameId}/lobby/{participantId}` API 호출
3. 서버가 STOMP `KICKED` 이벤트 브로드캐스트
4. 강퇴당한 유저: 다이얼로그 + 홈 이동 / 나머지: 스낵바 + 카드 제거

#### 다이얼로그 스펙
- **title**: `{닉네임}님을 내보낼까요?`
- **message**: `강퇴된 유저는 방에서 즉시 내보내져요\n다시 방에 참가하려면 초대코드를 입력해야 해요`
- **cancelText**: 취소 / **confirmText**: 내보내기 (흰색, 빨간 배경)
- **isDarkMode**: 방장 본인 팀 기준 (도둑 → dark, 경찰 → light)

**특이사항**:
- 참가자 목록 제거는 클라이언트에서 직접 하지 않고, 서버 STOMP `KICKED` 이벤트로 모든 클라이언트 동시 반영
- `null == null` 비교 방어: `kickedPid`와 `myPid` 모두 null일 때 self-kick으로 오인식하는 버그 방지

- 방장 자기 카드 탭 → 무반응
- 일반 유저 카드 탭 → 무반응
- 다크모드(도둑팀 방장) → 다이얼로그 다크 테마
