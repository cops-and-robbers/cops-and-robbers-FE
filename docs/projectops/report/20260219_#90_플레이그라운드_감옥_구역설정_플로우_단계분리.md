### 📌 작업 개요
세션 생성 Step 0(구역 선택)에서 플레이그라운드와 감옥 구역 설정 버튼이 동시에 노출되던 구조를 단계형으로 변경.
플레이그라운드 설정 완료 후에만 감옥 버튼이 노출되도록 조건부 렌더링 적용.
추가로 플레이그라운드 재설정 시 감옥 데이터가 초기화되지 않아 범위 밖 감옥으로 다음 진행이 가능하던 버그 수정.

### 🎯 구현 목표
- 초기 진입 시 플레이그라운드 설정 버튼만 노출하여 인지적 부담 감소
- 플레이그라운드 → 감옥 순서의 설정 흐름을 UI에서 명확히 표현
- 플레이그라운드 재설정 시 감옥 데이터 무효화 처리

### ✅ 구현 내용

#### 1. 감옥 버튼 조건부 렌더링
- **파일**: `lib/features/session/presentation/widgets/session_creation_steps/step_0_select_area_content.dart`
- **변경 내용**: `build()` 메서드에서 `isPlaygroundSet` 플래그 기반으로 감옥 `ZoneSettingButton`을 조건부 렌더링. 플레이그라운드 미설정 시 감옥 버튼과 간격(`SizedBox`)을 포함하여 완전히 숨김 처리
- **이유**: 플레이그라운드가 선행되어야 하는 구조적 관계를 UI에 반영하여 설정 순서 가이드 제공

#### 2. 플레이그라운드 재설정 시 감옥 초기화
- **파일**: `lib/features/session/presentation/pages/session_creation_flow_page.dart`
- **변경 내용**: `_onPlaygroundSet()` 콜백에서 플레이그라운드 값 갱신 시 `_prisonCenter`와 `_prisonRadiusMeters`를 `null`로 초기화
- **이유**: 플레이그라운드 범위가 변경되면 기존 감옥 위치가 새 플레이그라운드 밖에 있을 수 있음. 감옥 데이터를 초기화하여 사용자가 새 범위 내에서 재설정하도록 유도

#### 3. 감옥 설정 검증 문구 중앙 정렬
- **파일**: `lib/features/session/presentation/pages/setup_prison_page.dart`
- **변경 내용**: 감옥 범위 검증 실패 안내 문구의 `Alignment`를 `centerLeft`에서 `center`로 변경
- **이유**: 검증 실패 메시지의 시각적 가독성 향상

### 🔧 주요 변경사항 상세

#### step_0_select_area_content.dart
`playgroundCenter`와 `playgroundRadiusMeters`가 모두 non-null인지 확인하는 `isPlaygroundSet` 변수 추가.
Dart의 collection-if + spread 문법(`if (isPlaygroundSet) ...[...]`)으로 감옥 버튼과 간격을 한 블록으로 묶어 조건부 렌더링 처리.

#### session_creation_flow_page.dart
`_onPlaygroundSet()` 내부 `setState`에서 감옥 관련 상태 2개를 null로 초기화.
이에 따라 감옥 버튼이 자동으로 숨겨지고(조건부 렌더링 연동), "다음" 버튼도 비활성화됨(기존 `_isNextButtonEnabled` 로직이 양쪽 모두 설정 필요로 검증).
