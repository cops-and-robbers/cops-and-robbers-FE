### 📌 작업 개요

무전 서버가 혼잡해 서버가 `503 RADIO_SERVER_BUSY`를 주면(BE #253·#261), 앱이 이유를 알려 주고 혼잡이 풀려 연결되면 다시 알린다. 이전에는 무전 버튼이 회색인 채 아무 설명이 없었다.

| 1 | 혼잡으로 막힘 | "연결 중"인 채 10초마다 재시도, 안내 없음 | 무전 상태 `serverBusy`, 막힌 순간 스낵바 한 번 |
| 2 | 회색 버튼을 누름 | 출동 대기일 때만 이유 안내 | 혼잡 중이면 같은 안내 |

### ✅ 구현 내용

- `RadioStatus.serverBusy` 추가. `RADIO_SERVER_BUSY`는 방 밖에서 막혔을 때만 이 상태로 둔다(이미 무전 중인 경찰의 재발급 거절, 게임 종료 뒤 늦은 응답은 무시). 혼잡 중 재시도는 상태를 "연결 중"으로 덮지 않는다.
- `radioStatusNotice(l10n, previous, next)`(`radio_ptt_button.dart`)가 안내할 문구를 정하고, `game_page.dart`가 상태 리스너로 스낵바를 띄운다. 회색 버튼을 누르면 `_explainBlockedRadio`가 같은 문구를 띄운다.
- 문구(ko·en·ja): `errorCodeRadioServerBusy` "지금 무전 사용자가 많아요 / 혼잡이 풀리면 자동으로 연결돼요", `radioConnected` "무전이 연결됐어요". 에러 매핑에 `RADIO_SERVER_BUSY` 추가.
- `docs/api-docs.json` v4.0.0 → v4.4.0(개발 서버 `/v3/api-docs`).
