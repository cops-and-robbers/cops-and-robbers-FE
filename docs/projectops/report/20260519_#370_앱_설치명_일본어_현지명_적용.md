# 앱 설치명 다국어 지원 및 일본어 현지명(ケイドロ) 적용 #370

### 📌 작업 개요

홈 화면에 표시되는 앱 설치명을 OS 언어 설정에 따라 3개 국어(ko/en/ja)로 노출하도록 네이티브 리소스를 구성. 동시에 인앱 브랜드명도 일본어 현지명 `ケイドロ`로 통일하여 설치명과 인앱 표기를 일치시킴.

- Android: `strings.xml` 로케일별 분기 + `AndroidManifest.xml` 참조 변경
- iOS: `InfoPlist.strings` 로케일별 분기 + `Info.plist`에 `CFBundleLocalizations` 등록
- 인앱 ARB: `appBrandName`, `pageCreditsTitle` 일본어 현지명 반영

### 🎯 구현 목표

- OS 언어가 한국어면 `경찰과도둑`, 일본어면 `ケイドロ`, 그 외는 `Cops and Robbers`로 앱 설치명 표시
- 인앱에서 노출되는 브랜드명도 동일한 일본어 표기(`ケイドロ`)로 통일
- 트랜스리터레이션(`コップス・アンド・ロバーズ`) 대신 일본 현지에서 실제로 쓰이는 게임명을 사용

### ✅ 구현 내용

#### Android — 로케일별 strings.xml 추가
- **파일**: `android/app/src/main/res/values/strings.xml`, `values-ko/strings.xml`, `values-ja/strings.xml`
- **변경 내용**: 각 로케일에 `<string name="app_name">` 정의 — default(`Cops and Robbers`), ko(`경찰과도둑`), ja(`ケイドロ`)
- **이유**: 안드로이드 표준 리소스 분기 방식. OS 언어에 맞는 `values-{lang}/strings.xml`을 자동 선택

#### Android — Manifest에서 문자열 리소스 참조
- **파일**: `android/app/src/main/AndroidManifest.xml`
- **변경 내용**: `android:label`을 하드코딩에서 `@string/app_name` 참조로 변경
- **이유**: 매니페스트에 직접 문자열을 박으면 로케일 분기가 동작하지 않음

#### iOS — 로케일별 InfoPlist.strings 추가
- **파일**: `ios/Runner/Base.lproj/InfoPlist.strings`, `ko.lproj/InfoPlist.strings`, `ja.lproj/InfoPlist.strings`
- **변경 내용**: 각 lproj에 `CFBundleDisplayName` 정의
- **이유**: iOS는 lproj 디렉토리 기반으로 표시명 분기. Base는 기본값(영문)

#### iOS — Info.plist에 CFBundleLocalizations 등록
- **파일**: `ios/Runner/Info.plist`
- **변경 내용**: `CFBundleLocalizations` 배열에 `en`, `ko`, `ja` 추가. 기존 fallback 표시명을 `Cops and Robbers`로 변경
- **이유**: iOS에 앱이 지원하는 로케일 목록을 명시해야 lproj 분기가 동작

#### iOS — Xcode 프로젝트에 lproj 등록
- **파일**: `ios/Runner.xcodeproj/project.pbxproj`
- **변경 내용**: `knownRegions`에 ko/ja 추가, `InfoPlist.strings` Variant Group에 ko/ja 파일 등록, BuildFile 항목 추가
- **이유**: Xcode가 lproj 파일을 빌드에 포함시키려면 pbxproj에 명시적으로 등록해야 함

#### 인앱 ARB — 일본어 브랜드명 현지화
- **파일**: `lib/l10n/app_ja.arb`
- **변경 내용**: `appBrandName`을 `コップス・アンド・ロバーズ` → `ケイドロ`로 변경, `pageCreditsTitle`도 동일하게 갱신
- **이유**: 네이티브 설치명이 `ケイドロ`인데 인앱에서 트랜스리터레이션을 쓰면 일관성 깨짐. 일본에서 실제로 쓰는 게임명을 사용하여 자연스럽게 함

#### i18n 가이드 규칙 갱신
- **파일**: `.claude/rules/10_I18N_GUIDE.md`
- **변경 내용**: 게임 타이틀 컨벤션 표에서 ja를 "브랜드명 유지"에서 "일본 현지 게임명 `ケイドロ`"로 수정
- **이유**: 기존 규칙이 "ja는 브랜드명(Cops and Robbers) 유지"였으나 이번 결정으로 현지명 사용 정책 변경. 가이드 정본을 일치시킴

### 🔧 주요 변경사항 상세

#### 안드로이드 로케일 분기 동작
OS 언어가 한국어면 `res/values-ko/strings.xml`, 일본어면 `res/values-ja/strings.xml`, 그 외는 `res/values/strings.xml`이 선택된다. `AndroidManifest.xml`의 `android:label="@string/app_name"`이 이 리소스를 참조하므로 앱 설치명/홈 화면 라벨이 자동 분기된다.

#### iOS 로케일 분기 동작
앱 시작 시 시스템 언어 매칭 우선순위에 따라 `{lang}.lproj/InfoPlist.strings`의 `CFBundleDisplayName`이 적용된다. `CFBundleLocalizations`에 지원 로케일이 등록되어 있어야 분기가 활성화되며, 없으면 Base(영문)로 폴백된다.

**특이사항**:
- `pbxproj`는 Xcode가 생성·관리하는 파일이라 텍스트 편집이 까다롭다. `knownRegions`, `PBXVariantGroup`, `PBXBuildFile` 세 영역을 모두 일관성 있게 수정해야 빌드 시 lproj가 번들에 포함됨
- iOS 시뮬레이터/실기에서 언어 변경 후 앱을 완전히 종료·재실행해야 표시명 갱신이 반영됨

#### ケイドロ 선정 근거
일본에서 cops-and-robbers류 술래잡기 게임의 실제 명칭은 `ケイドロ`(경찰+도둑) 또는 `ドロケイ`(도둑+경찰). 지역별로 호칭이 갈리지만 전자가 더 보편적. 트랜스리터레이션은 외국 IP를 그대로 들여온 인상이라 게임 도메인에 어울리지 않음.
