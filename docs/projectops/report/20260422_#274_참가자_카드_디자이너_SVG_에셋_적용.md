### 📌 작업 개요

대기방과 게임방 참가자 카드에 디자이너가 최종 확정한 캐릭터 SVG 에셋 적용. 기존 `Icon.person` placeholder + 회색 박스 배경 제거하고 팀(경찰/도둑) × 상태(ready/not_ready/jailed) 조합의 SVG 렌더링으로 교체.

### 🎯 구현 목표

- 대기방/게임방 참가자 카드의 임시 위젯을 디자이너 제공 SVG로 교체
- 팀 테마(경찰/도둑)별, 상태별(레디/비레디/수감) SVG 자동 분기
- 확장 가능한 에셋 경로 구조 설계 (스킨 시스템 대비)
- 에셋 번들링 검증 테스트로 누락 방지

### ✅ 구현 내용

#### 캐릭터 SVG 에셋 5종 추가
- **경로**: `assets/characters/{team}/default/{state}.svg`
- **파일**:
  - `police/default/ready.svg`, `police/default/not_ready.svg`
  - `robber/default/ready.svg`, `robber/default/not_ready.svg`, `robber/default/jailed.svg`
- **이유**: 향후 스킨 시스템(`default` 외 스킨 추가)과 상태 확장(경찰 수감 등) 대비한 3단 폴더 구조(`team/skinId/state`)

#### 에셋 경로 헬퍼 추가
- **파일**: `lib/core/constants/character_assets.dart` (신규)
- **변경 내용**: `characterAssetPath({team, skinId, state})` 함수로 경로 생성 중앙화
- **이유**: 경로 하드코딩 제거 및 새 스킨/상태 추가 시 한 곳만 수정

#### 참가자 카드 SVG 렌더링
- **파일**: `lib/features/session/presentation/widgets/participant_card.dart`
- **변경 내용**:
  - `Icon.person` + `Container(배경 박스)` → `SvgPicture.asset(_characterAssetPath, fit: BoxFit.contain)` 교체
  - `gameStatus` 파라미터 추가 (null = 대기방, 값 있음 = 게임방)
  - 상태별 SVG 자동 매핑 로직 `_characterAssetPath` getter 구현
- **이유**: 대기방/게임방 컨텍스트를 하나의 위젯에서 처리, 호출부에서 분기 로직 몰라도 됨

#### 게임방 참가자 오버레이 상태 매핑
- **파일**: `lib/features/game/presentation/widgets/participant_overlay.dart`
- **변경 내용**: 체포/탈옥 낙관적 업데이트를 반영한 `gameStatusByParticipantId` 맵 구축
- **이유**: 서버 이벤트 도착 전에도 로컬 상태 변경을 즉시 SVG에 반영

#### TeamSection 파라미터 확장
- **파일**: `lib/features/session/presentation/widgets/team_section.dart`
- **변경 내용**:
  - `gameStatusByParticipantId` 맵 전달용 파라미터 추가
  - `currentUserTeam` 파라미터 추가 → 반대 팀 섹션에만 `AddSlotCard` 렌더링
- **이유**: 게임 상태 맵을 개별 참가자 카드로 내려주고, 팀 변경 카드를 자기 팀이 아닌 쪽에만 표시

#### 체포 잠금 오버레이 SVG 교체
- **파일**: `lib/features/game/presentation/widgets/arrest_lock_overlay.dart`
- **변경 내용**: 회색 박스 placeholder → `robber/default/jailed.svg` 적용
- **이유**: 참가자 카드의 `JAILED` 상태와 시각적 일관성 확보

### 🔧 주요 변경사항 상세

#### SVG 매핑 규칙 (`participant_card.dart:113-128`)

```
게임방 컨텍스트 (gameStatus != null):
  - JAILED + robber      → robber/default/jailed.svg
  - 그 외 (ALIVE/POLICE_WAITING) → {team}/default/ready.svg

대기방 컨텍스트 (gameStatus == null):
  - isReady || isHost    → {team}/default/ready.svg
  - 그 외                → {team}/default/not_ready.svg
```

**특이사항**:
- **방장은 항상 레디 취급**: 방장 UI에 레디 버튼이 없으므로 `isReady` 값과 무관하게 `ready.svg` 강제
- **게임방에서는 `isReady` 무시**: 게임 시작 후 백엔드가 `isReady`를 리셋(혹은 의미 없음) → 게임 상태만 본다
- **레디/비레디 시각 구분은 SVG 자체가 담당**: Opacity 효과 미사용 (디자이너 의도대로 각각 다른 그림)

#### 대기실 튜토리얼 팀 변경 카드 분기 (`f8de402`)
- 기존 5단계 → 4단계로 축소 (사용자 팀에 따라 단일 팀 변경 스텝만 표시)
- 반대 팀 정원 초과 시 팀 변경 스텝 자동 skip 가드
- 튜토리얼 진행 중 팀 변경 감지 시 자연 종료(finish) 안전장치

#### 카드 탭 체포 디버그 전용 제한 (`6dfad95`)
- **파일**: `lib/features/game/presentation/widgets/participant_overlay.dart`
- 실제 배포 빌드에서는 QR 스캔(대면 확인)만 유효한 체포 경로
- 디버그 빌드는 시뮬레이터/에뮬레이터 검증용으로 카드 탭 체포 유지

#### 탈옥 낙관적 업데이트 수정 (`12a552c`)
- **파일**: `lib/features/game/presentation/providers/game_event_provider.dart`
- 탈옥 시 `jailedParticipantIds` 집합에서도 제거 → SVG가 `jailed.svg` → `ready.svg`로 정상 전환
- 기존에 수감 집합이 정리되지 않아 UI가 어색하게 깜빡이던 문제 해결

#### 게임 시작 후 not_ready 오표시 수정 (`bb793cf`)
- **파일**: `lib/features/session/presentation/widgets/participant_card.dart`
- 게임 시작 직후 `isReady`가 false로 리셋되면서 `not_ready.svg`가 잘못 표시되던 버그
- `gameStatus != null` 이면 `isReady` 보지 않도록 분기 추가

#### 시스템 메시지 띄어쓰기 (`f6ea985`)
- **파일**: `lib/core/constants/game_event_messages.dart`
- 가독성 조정 (세부 텍스트 정렬)

### 🧪 테스트 및 검증

#### 에셋 번들링 자동 검증
- **파일**: `test/core/constants/character_assets_bundle_test.dart` (신규)
- **검증 항목**: 5개 SVG(police ready/not_ready, robber ready/not_ready/jailed)가 모두 번들에 포함되고 올바른 SVG 형식인지 확인
- **목적**: `pubspec.yaml` 경로 등록 누락 시 런타임 에러 대신 테스트 단계에서 조기 감지

```dart
// 예시: loads_police_ready_svg_when_bundled
final path = characterAssetPath(team: 'police', state: 'ready');
final data = await rootBundle.loadString(path);
expect(data, contains('<svg'), reason: '$path 가 번들에 없거나 SVG 형식이 아님');
```

### 📌 참고사항

#### 에셋 확장 가이드
새 스킨 또는 상태 추가 시:
1. `assets/characters/{team}/{skinId}/{state}.svg` 경로로 파일 배치
2. `pubspec.yaml` `flutter.assets:`에 `assets/characters/{team}/{skinId}/` 경로 등록
3. `character_assets_bundle_test.dart`에 번들링 테스트 추가

#### 배경 박스 제거 주의
- 기존 `Container(color: _avatarColor, borderRadius: 4.r)`가 제거됨
- 카드가 "사각형 박스 안의 인물" → "캐릭터만 떠 있는 형태"로 변경되어 디자인 의도에 맞춤
- 레이아웃 크기(72x84)는 동일 유지 → 기존 리스트 정렬 영향 없음

#### 디버그 모드와 릴리즈 모드 차이
- 디버그 빌드: 참가자 카드 탭해도 체포 가능 (시뮬레이터 편의)
- 릴리즈 빌드: QR 스캔만 유효
- 테스트 시 이 차이 인지 필요
