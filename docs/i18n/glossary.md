# 도메인 용어집 (Glossary)

> LLM 번역 시 **반드시** 이 용어집의 번역을 따를 것 (일관성이 최우선)

## 번역 톤 가이드

- **ko**: 친근한 존댓말 ("~해주세요", "~예요/~이에요"), 마침표 안 찍음
- **en**: Sentence case, friendly but not overly casual ("Please try again", not "Try again pls")
- **ja**: です/ます체 (정중체), 마침표(。) 안 찍음, 외래어는 카타카나

## 특수 표기 규칙

- placeholder `{nickname}`, `{count}`, `$minutes` 등은 **번역하지 않고 그대로 유지**
- 아이콘 마커 `@icon_police`, `@icon_robber` 같은 것도 **그대로 유지**
- 줄바꿈 `\n`은 위치 그대로 유지 (한국어 문장 길이와 영어/일본어 길이가 달라도 줄바꿈 위치는 원문 따름)
- 마침표 정책: 문장 끝 `.` `。` 제거. 단 여러 문장이 이어질 때 사이의 마침표는 의미상 필요하면 유지
