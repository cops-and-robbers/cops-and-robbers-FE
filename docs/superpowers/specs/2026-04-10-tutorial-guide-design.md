# 게임 화면 튜토리얼 가이드 설계

> 작성일: 2026-04-10
> 이슈: #212

## 목적

앱을 처음 사용하는 유저가 각 화면의 UI 요소를 이해할 수 있도록 코치마크 기반 튜토리얼을 제공한다.

## 패키지

- **추가**: `tutorial_coach_mark: ^1.3.3`
- **제거**: `showcaseview: ^5.0.1` (미사용 상태)

## 아키텍처

### TutorialService

SharedPreferences 기반으로 화면별 튜토리얼 완료 여부를 관리하는 서비스.

**위치**: `lib/core/services/tutorial/tutorial_service.dart`

**책임**:
- 화면별 완료 여부 조회 (`isCompleted(key)`)
- 완료 처리 (`markCompleted(key)`)
- 전체 초기화 (`resetAll()`)

**키 목록**:

| 키 | 화면 | 안내 요소 |
|---|------|----------|
| `tutorial_home` | 홈 | 방만들기 버튼, 방참여하기 버튼 |
| `tutorial_create_step0` | 방만들기 Step 0 | 구역 선택 (플레이그라운드, 감옥 설정) |
| `tutorial_create_step1` | 방만들기 Step 1 | 인원 설정 (최대 참가자) |
| `tutorial_create_step2` | 방만들기 Step 2 | 게임 설정 (라운드 시간, 위치 공유 간격, 경찰 대기 시간) |
| `tutorial_create_step3` | 방만들기 Step 3 | 최종 확인 + 방 생성하기 |
| `tutorial_waiting_room` | 대기실 | 팀 선택, 준비 완료, 초대 코드 공유, 게임 규칙 |
| `tutorial_game` | 게임 화면 | 지도, 채팅, 체포/탈옥, 타이머, 참가자 목록, QR 스캔 |

### 트리거 방식

- 각 화면 최초 진입 시 자동 시작 (스킵 불가, 한번은 반드시 봐야 함)
- `initState` (또는 `build` 후 `WidgetsBinding.addPostFrameCallback`)에서 `TutorialService.isCompleted(key)` 체크
- 미완료면 `TutorialCoachMark.show()` 실행
- 튜토리얼 완료 콜백에서 `TutorialService.markCompleted(key)` 호출

### 설정 페이지 연동

`settings_page.dart`의 "이용 안내" 섹션에 "튜토리얼 초기화" 메뉴 추가.

- 탭 시 확인 다이얼로그 → 확인 → `TutorialService.resetAll()` → "튜토리얼이 초기화되었어요" 스낵바
- 이후 각 화면 재진입 시 튜토리얼 다시 표시

## 파일 구조

```
lib/core/services/tutorial/
├── tutorial_service.dart          # SharedPreferences 기반 완료 상태 관리
└── tutorial_keys.dart             # 키 상수 정의

lib/core/tutorial/
├── tutorial_step_builder.dart     # TargetFocus 생성 헬퍼
└── tutorial_styles.dart           # 코치마크 공통 스타일 (색상, 폰트, 패딩)
```

각 화면의 튜토리얼 정의는 해당 화면 파일 내부 또는 같은 폴더의 별도 파일에 배치:
- `home_page.dart` 내부에서 `GlobalKey` 지정 + 튜토리얼 스텝 정의
- 게임 화면처럼 스텝이 많으면 `game_tutorial.dart` 같은 별도 파일 분리

## GlobalKey 전략

`tutorial_coach_mark`는 `GlobalKey`로 대상 위젯을 식별한다.

- 튜토리얼 대상 위젯에 `GlobalKey` 할당
- 키 네이밍: `_tutorialKeyCreateRoom`, `_tutorialKeyJoinRoom` 등
- StatefulWidget의 State에서 관리

## 구현 제외 사항

- 튜토리얼 중 뒤로가기 방지 (불필요 — 코치마크가 오버레이라 자연스럽게 차단)
- 애니메이션 커스터마이징 (기본 제공 애니메이션 사용)
- 튜토리얼 진행률 표시 (불필요)
- 방참여하기 플로우 튜토리얼 (초대 코드 입력만이라 홈 화면 안내로 충분)
