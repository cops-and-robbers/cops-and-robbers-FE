# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 지도 핑 기능 추가
- 지도를 길게 누르면 팀원에게 "발견" 또는 "의심" 핑을 보낼 수 있습니다.
- 핑 마커는 일정 시간이 지나면 자동으로 사라지며, 연속 전송에는 짧은 대기 시간이 있습니다.

2. 초대 링크로 앱 바로 열기
- 방 초대 링크나 QR 코드를 누르면 앱이 실행되어 해당 방으로 바로 이동합니다.
- 앱이 설치되어 있어도 링크가 스토어로 이동하던 문제를 수정했습니다.
- 앱이 꺼진 상태에서 초대 링크로 들어올 때 화면이 멈추던 문제를 수정했습니다.

3. 안정성 개선 및 버그 수정
- 전반적인 안정성을 개선했습니다.

==========

[English]

Key changes in this version:

1. Map Ping Feature Added
- Long-press the map to send a "Found" or "Suspect" ping to your teammates.
- Ping markers disappear automatically after a while, with a short cooldown between sends.

2. Open the App Directly from Invite Links
- Tapping a room invite link or QR code now launches the app and takes you straight to the room.
- Fixed an issue where links opened the app store even when the app was already installed.
- Fixed an issue where the screen could freeze when entering through an invite link from a closed app.

3. Stability Improvements & Bug Fixes
- Improved overall stability.
