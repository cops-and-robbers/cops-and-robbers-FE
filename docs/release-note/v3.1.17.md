# [주요 변경사항 — 애플 제출용]

```text
[한국어]
이번 버전의 주요 변경사항입니다.

1. 자동 탈옥 개선
- 체포 후 감옥에 들어갔다 나가면 자동 탈옥합니다. 백그라운드나 일시적인 연결 끊김 중에도 판정하며, 실패하면 다시 요청합니다

2. 수감 버튼 위치 변경
- 화면 왼쪽 아래에 있던 수감 버튼을 수감 중 QR 버튼 자리로 옮겼습니다. 자동 탈옥이 되지 않을 때 직접 탈옥할 수 있습니다

3. 커뮤니티 알림 이동
- 커뮤니티 채팅·게임 초대·고정 채팅 알림을 누르면 해당 채팅방으로 이동합니다. 게임이나 대기실에 있을 때는 이동하지 않고 안내 문구를 표시합니다

4. 모임 장소에서 구역 설정 시작
- 모집글 채팅방에서 만든 게임은 모임 장소에서, 홈에서 만든 게임은 현재 위치에서 구역 설정을 시작합니다

5. 게임 시작 시 지도 위치
- 다른 장소를 거치지 않고 내 위치나 게임 구역에서 바로 지도를 표시합니다

6. 안정성 개선 및 버그 수정
- 탭 화면의 안내 메시지가 하단 메뉴와 겹치던 위치를 바로잡았습니다

---
[English]

Key changes in this version:

1. Improved Automatic Escape
- After being arrested, entering and then leaving the jail triggers an automatic escape. Detection continues in the background or during brief disconnects, and failed requests are retried

2. Jail Button Moved
- The jail button, previously in the lower left, now appears in place of the QR button while jailed. Use it to escape manually if the automatic escape does not happen

3. Community Notification Navigation
- Tapping a community chat, game invitation, or pinned chat notification opens that chat room. While in a game or waiting room, a message is shown instead so your game is not interrupted

4. Zone Setup Starts at the Meeting Place
- Games created from a recruitment post chat start zone setup at the meeting place; games created from Home still start at your current location

5. Map Position at Game Start
- The map opens directly at your location or the game zone, without showing a different place first

6. Stability Improvements & Bug Fixes
- Fixed notice messages on tab screens overlapping the bottom menu
```
