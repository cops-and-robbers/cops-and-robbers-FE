==========

[한국어]

이번 버전의 주요 변경사항입니다.

1. 체포 상태 복원
- 앱을 종료했다가 다시 실행해도 체포된 상태와 그 시각 효과가 유지됩니다.

2. 백그라운드 게임 종료 후 결과 화면 안정화
- 게임이 백그라운드에서 종료된 뒤 결과 화면을 닫거나 버튼을 눌렀을 때 발생하던 비정상 종료 문제를 수정했습니다.

3. 강퇴 직후 대기실 안정성 개선
- 강퇴 처리된 후 대기실로 돌아갔을 때 일부 사용자 동작이 정상적으로 처리되지 않던 문제를 보강했습니다.

4. 안정성 개선 및 버그 수정
- 잔여 안정성 이슈를 정리했습니다.

==========

[English]

Key changes in this version:

1. Arrest Status Restored on Restart
- Your arrested status and its visual effects now persist after restarting the app.

2. Result Screen Stability After Background Game End
- Fixed an issue where the result screen could crash when a game ended while the app was in the background.

3. Lobby Stability After Being Kicked
- Improved stability for actions performed in the lobby right after being kicked from a room.

4. Stability Improvements & Bug Fixes
- Resolved minor remaining issues.
