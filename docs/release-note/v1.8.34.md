- 튜토리얼 화면 디자인을 개선했습니다
- 공지사항과 채팅 메시지 시간이 기기 시간대 기준으로 정확하게 표시됩니다
- 게임 재접속 시 도둑 위치 복구 안정성을 개선했습니다
- 안정성 개선 및 버그 수정

==========

[한국어]

이번 버전의 주요 변경사항입니다.

1. 게임 알림 수신 동의 설정 추가
- 설정 페이지에서 게임 진행 중 발생하는 이벤트 알림 수신 여부를 직접 설정할 수 있습니다.
- 토글을 켜고 끄는 즉시 화면에 반영되며, 통신이 실패하면 이전 상태로 자동 복원됩니다.

2. 튜토리얼 화면 디자인 개선
- 튜토리얼 카탈로그 화면의 뒤로가기 버튼과 여백, 항목 간격을 정돈하여 가독성을 높였습니다.

3. 시간 표시 정확성 개선
- 공지사항과 채팅 메시지 시간이 기기에 설정된 시간대를 기준으로 표시됩니다.
- 해외에서 접속하더라도 현지 시간 기준으로 일관된 시각을 확인할 수 있습니다.
- 게임 방 생성 시각도 동일한 기준으로 정규화되었습니다.

4. 게임 재접속 안정성 개선
- 네트워크가 일시적으로 끊겼다가 재접속될 때 도둑 위치 정보가 더 안정적으로 동기화됩니다.

5. 안정성 개선 및 버그 수정
- 위치정보 이용약관 시행일을 갱신하고, 게임 종료 시 위치 수집 중단 동작 설명을 보완했습니다.

==========

[English]

Key changes in this version:

1. Game Notification Consent Setting Added
- You can now manage whether to receive in-game event notifications directly from the Settings page.
- Changes apply to the screen immediately, and the previous state is automatically restored if the update fails.

2. Tutorial Screen Design Improvements
- The back button, padding, and item spacing on the tutorial catalog screen have been refined for better readability.

3. Improved Time Display Accuracy
- Notice and chat message times are now displayed based on the device's configured time zone.
- Users connecting from overseas will see consistent times based on their local zone.
- Game room creation times have been normalized to the same standard.

4. Game Reconnection Stability
- Robber location data is now more reliably synchronized when the network briefly disconnects and reconnects.

5. Stability Improvements & Bug Fixes
- Updated the location information terms effective date and clarified the description of how location collection stops when a game ends.
