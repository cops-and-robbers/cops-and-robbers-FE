[한국어]

이번 버전의 주요 변경사항입니다.

1. 버그 제보 기능 정상화
- 설정 화면에서 버그 제보가 정상적으로 접수되지 않던 문제를 해결했습니다.
- 제보 내용은 최대 1000자까지 입력할 수 있습니다.

2. 공지사항 게시판 추가
- 공지사항 페이지에서 최신 공지를 확인할 수 있습니다.
- 페이지 단위로 이전 공지를 둘러볼 수 있습니다.

3. 푸시 알림 처리 개선
- 앱을 사용 중인 동안에는 푸시 알림이 화면 상단에 표시되지 않습니다.
- 백그라운드에서 푸시 알림을 받으면 끊긴 게임 연결을 자동으로 복구합니다.
- 알림을 탭해 앱에 진입할 때도 게임 상태가 정상적으로 동기화됩니다.

4. 앱 시작 성능 최적화
- 알림 권한 부여 직후 알림 토큰이 정상 발급되도록 초기화 순서를 다듬었습니다.

5. 안내 문구 개선
- 앱 내 일부 라벨과 안내 문구를 더 명확하게 다듬었습니다.
- 위치 권한 요청 안내 문구의 표현과 마침표 처리를 개선했습니다.

6. 안정성 개선 및 버그 수정
- 버그 제보 중 인증이 만료되었을 때 로딩 화면이 종료되지 않던 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. Bug Reporting Fixed
- Resolved an issue where bug reports were not being submitted properly from the Settings screen.
- Reports support up to 1000 characters.

2. Notices Board Added
- View the latest announcements on the Notices page.
- Browse previous announcements with pagination.

3. Push Notification Improvements
- Push notifications no longer appear at the top of the screen while you are using the app.
- The app automatically restores disconnected game sessions when receiving push notifications in the background.
- Game state now syncs correctly when entering the app via a notification tap.

4. Faster App Startup
- Adjusted the initialization order so that notification tokens are issued correctly right after permission is granted.

5. Clearer Wording
- Refined labels and notices throughout the app for better clarity.
- Improved the wording and punctuation of the location permission notice.

6. Stability Improvements & Bug Fixes
- Fixed an issue where the loading indicator would not dismiss when authentication expired during bug reporting.
