[한국어]

이번 버전의 주요 변경사항입니다.

1. 백그라운드 게임 안정성 개선
- 게임 진행 중 화면을 끄거나 다른 앱으로 잠깐 이동해도 도둑 위치 공유와 게임 알림이 끊기지 않습니다.
- 게임이 종료되면 백그라운드 동작이 자동으로 정리됩니다.
- 위치 권한은 "앱 사용 중에만 허용"으로도 충분합니다.

2. 끊김 복구 개선
- 네트워크가 일시적으로 끊겼다가 복구될 때 자동 재연결 시도가 더 빨라졌습니다.
- 재연결 버튼을 누르면 게임 알림과 채팅이 한 번에 복구됩니다.

3. 안드로이드 기기 안정성 강화
- 일부 안드로이드 기기에서 절전 정책으로 게임이 끊기던 문제를 개선했습니다.
- 방 만들기 또는 방 참여하기 시 안내에 따라 한 번 설정하면 이후 게임이 안정적으로 진행됩니다.

4. 안정성 개선 및 버그 수정
- 게임 진입 시 일부 환경에서 발생하던 동시성 문제를 수정했습니다.
- 게임 라이프사이클 관련 안정성 항목을 보강했습니다.

==========

[English]

Key changes in this version:

1. Background Game Stability Improvements
- Robber location sharing and game notifications now continue uninterrupted even when the screen is off or you briefly switch to another app.
- Background activity automatically cleans up when the game ends.
- The "Allow While Using App" location permission is sufficient.

2. Reconnection Improvements
- Automatic reconnection is now faster when the network is briefly interrupted.
- Tapping the reconnect button restores both game notifications and chat at once.

3. Android Device Stability Enhancements
- Fixed an issue where some Android devices interrupted gameplay due to power-saving policies.
- A one-time setup guided when creating or joining a room ensures stable gameplay afterward.

4. Stability Improvements & Bug Fixes
- Fixed concurrency issues that occurred when entering a game in certain environments.
- Strengthened game lifecycle stability items.
