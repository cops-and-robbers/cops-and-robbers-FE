# [주요 변경사항 — 애플 제출용]

```text
[한국어]
이번 버전의 주요 변경사항입니다.

1. 자동 탈옥 개선
- 체포된 뒤 감옥 안에 들어갔다가 감옥 밖으로 나가면 자동으로 탈옥합니다
- 감옥 밖에서 체포된 경우와 감옥 안에서 체포된 경우 모두 동작합니다
- 앱이 백그라운드에 있거나 연결이 잠시 끊겨도 탈옥 판정이 이어집니다
- 탈옥 요청이 실패하면 감옥 밖에 있는 동안 다시 요청합니다

2. 수감 버튼 위치 변경
- 기존: 수감 버튼이 화면 왼쪽 아래에 있었습니다
- 변경: 수감 중에는 QR 버튼 자리에 수감 버튼이 표시됩니다
- 자동 탈옥이 되지 않을 때 이 버튼으로 직접 탈옥할 수 있습니다

3. 커뮤니티 알림 이동
- 커뮤니티 채팅, 게임 초대, 고정 채팅 알림을 누르면 해당 채팅방으로 이동합니다
- 게임이나 대기실에 있을 때 커뮤니티 알림을 누르면 게임이 끊기지 않도록 이동하지 않고 안내 문구를 표시합니다

4. 모임 장소에서 구역 설정 시작
- 모집글 채팅방에서 게임을 만들면 구역 설정 지도가 모집글의 모임 장소에서 시작합니다
- 홈에서 게임을 만들면 기존처럼 현재 위치에서 시작합니다
- 내 위치 버튼을 누르면 현재 위치로 이동합니다

5. 게임 시작 시 지도 위치
- 기존: 게임을 시작하면 지도가 다른 장소를 먼저 보여준 뒤 내 위치로 이동했습니다
- 변경: 내 위치나 게임 구역 중 먼저 확인된 위치에서 바로 지도를 표시합니다

6. 안정성 개선 및 버그 수정
- 탭 화면에서 안내 메시지가 하단 메뉴와 겹치거나 너무 높이 뜨던 위치를 바로잡았습니다

---
[English]

Key changes in this version:

1. Improved Automatic Escape
- After being arrested, entering the jail and then leaving it now triggers an automatic escape
- This works whether you were arrested outside or inside the jail
- Escape detection continues even when the app is in the background or the connection drops briefly
- If an escape request fails, it is retried while you remain outside the jail

2. Jail Button Moved
- Before: the jail button was in the lower left of the screen
- After: while jailed, the jail button appears in place of the QR button
- If the automatic escape does not happen, you can use this button to escape manually

3. Community Notification Navigation
- Tapping a community chat, game invitation, or pinned chat notification now opens that chat room
- While in a game or waiting room, tapping a community notification shows a message instead of leaving the screen, so your game is not interrupted

4. Zone Setup Starts at the Meeting Place
- Creating a game from a recruitment post chat room now starts the zone setup map at the post's meeting place
- Creating a game from Home still starts at your current location
- Tapping the My Location button moves the map to your current location

5. Map Position at Game Start
- Before: when a game started, the map briefly showed a different location before moving to yours
- After: the map opens directly at your location or the game zone, whichever is available first

6. Stability Improvements & Bug Fixes
- Fixed the position of notice messages on tab screens that overlapped the bottom menu or appeared too high
```
