v1.8.23

- 인게임 튜토리얼을 별도 카탈로그 페이지로 새로 구성했습니다
- 게임 규칙 다이얼로그와 설정 메뉴 등 튜토리얼 재방문 진입점을 추가했습니다
- 플레이그라운드 이탈 시 화면을 가리지 않는 비네트 경고 방식으로 변경했습니다
- 재접속 시 경찰 대기 시간이 잘못 표시되던 문제를 수정했습니다
- 크레딧 페이지 인원을 보강하고 티어별 스타일을 적용했습니다
- 안드로이드 3버튼 네비게이션 환경에서 우측 액션 버튼 위치를 보정했습니다
- 안정성 개선 및 버그 수정

==========

[한국어]

이번 버전의 주요 변경사항입니다.

1. 인게임 튜토리얼 페이지 신설
- 기존: 게임 화면에 코치마크 오버레이를 띄워 기능을 안내했습니다.
- 변경: 별도의 튜토리얼 카탈로그 페이지에서 모든 기능 설명을 모아 볼 수 있습니다.
- 대기방 코치마크를 처음 완료하면 인게임 튜토리얼 안내 다이얼로그가 표시됩니다.
- 게임 규칙 다이얼로그와 설정 메뉴, 카탈로그 진입점에서 튜토리얼을 다시 열 수 있습니다.
- 도둑팀에서도 안내 다이얼로그의 테마가 어색하지 않게 보정했습니다.

2. 플레이그라운드 이탈 경고 방식 변경
- 기존: 이탈 시 화면 전체를 어둡게 덮는 차단형 오버레이가 표시되었습니다.
- 변경: 화면 가장자리에 비네트 그라데이션을 띄우는 비차단 오버레이로 바뀌어, 이탈 중에도 지도와 채팅을 정상적으로 사용할 수 있습니다.
- 이탈 중 다른 화면으로 이동하려고 하면 자동으로 지도로 돌아옵니다.
- 체포, 게임 종료, 재연결 모달이 뜰 때 남아있던 이탈 경고를 정리했습니다.
- 경고 배너 아이콘을 표준 경고 아이콘으로 교체했습니다.

3. 재접속 시 경찰 대기 시간 오표시 수정
- 게임에 재접속할 때 경찰 대기 시간이 실제와 다르게 표시되던 문제를 수정했습니다.
- 서버 시각에 시간대 정보가 누락된 경우에도 한국 시간 기준으로 올바르게 계산됩니다.

4. 크레딧 페이지 인원 보강
- 크레딧 페이지에 기여자 명단을 추가하고 티어 단위로 구분했습니다.
- 흐르는 텍스트의 스타일이 티어에 따라 달라집니다.

5. 안정성 개선 및 버그 수정
- 안드로이드 3버튼 네비게이션 환경에서 우측 액션 버튼이 시스템 영역과 겹치지 않도록 위치를 보정했습니다.
- 대기방 코치마크가 간헐적으로 완료 처리되지 않던 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. New In-Game Tutorial Page
- Previous: Coach marks overlaid on the game screen explained features in place.
- Updated: A dedicated tutorial catalog page now consolidates every feature explanation.
- A guidance dialog appears the first time the waiting-room coach marks are completed.
- The tutorial can be reopened from the game rules dialog, the settings menu, and the catalog entry.
- The guidance dialog theme has been refined for the robber team.

2. Non-Blocking Zone Exit Warning
- Previous: Leaving the playground darkened the entire screen with a blocking overlay.
- Updated: A vignette gradient now appears along the screen edges, so the map and chat remain usable while outside the zone.
- Attempting to navigate to other screens during a zone exit now redirects back to the map.
- Lingering exit warnings during arrest, game-over, and reconnection modals have been cleared.
- The warning banner now uses a standard alert icon.

3. Police Wait Time Display Fix on Reconnect
- Fixed an issue where the police wait time was shown incorrectly after reconnecting to a game.
- Server timestamps without a timezone are now correctly interpreted as Korea Standard Time.

4. Credits Page Update
- Added contributors to the credits page, organized into tiers.
- Marquee text styling now varies by tier.

5. Stability Improvements & Bug Fixes
- Adjusted the right-side action button position on Android 3-button navigation devices to avoid overlap with the system area.
- Fixed an issue where waiting-room coach marks were occasionally not marked as completed.
