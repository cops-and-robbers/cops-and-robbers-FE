# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 초대 링크로 게임 참가

- 친구에게 받은 방 초대 링크를 누르면 앱이 실행되며 해당 방에 바로 참가합니다.
- 이미 다른 방에 참가 중인 경우, 새로 참가하는 대신 진행 중인 방으로 이동합니다.

2. 언어별 앱 아이콘 자동 전환

- 기기 설정 언어에 맞춰 홈 화면의 앱 아이콘이 자동으로 변경됩니다.
- 지원하지 않는 언어의 경우 기본 언어로 표시됩니다. 기존: 한국어 / 변경: 영어

3. 언어별 로고 및 스플래시 화면

- 앱 실행 시 표시되는 로고와 스플래시 화면이 선택한 언어에 맞춰 적용됩니다.

4. 게임 종료 처리 개선

- 게임 종료 신호가 누락되는 경우에도 게임이 정상적으로 종료되도록 보완했습니다.
- 게임 종료 후 화면 표시 일관성을 개선했습니다.

5. 오류 안내 문구 개선

- 오류가 발생할 때 표시되는 안내 문구를 한국어·영어·일본어로 제공하고, 상황에 맞게 더 정확하게 표시하도록 정비했습니다.

6. 안정성 개선 및 버그 수정

- 여러 화면에서 발생할 수 있는 오류를 수정하고 전반적인 안정성을 높였습니다.

==========

[English]

Key changes in this version:

1. Join Games via Invite Link

- Tapping a room invite link from a friend launches the app and takes you straight into that room.
- If you are already in another room, you are returned to your active room instead of joining a new one.

2. Automatic Language-Based App Icon

- The home screen app icon now changes automatically to match your device language.
- For unsupported languages, the default language is used. Before: Korean / After: English

3. Language-Based Logo and Splash Screen

- The logo and splash screen shown at launch now match your selected language.

4. Improved Game-Over Handling

- The game now ends correctly even when the game-over signal is missed.
- Improved screen consistency after a game ends.

5. Improved Error Messages

- Error messages shown when something goes wrong are now provided in Korean, English, and Japanese, and refined to display more accurately for each situation.

6. Stability Improvements & Bug Fixes

- Fixed various errors that could occur across multiple screens and improved overall stability.
