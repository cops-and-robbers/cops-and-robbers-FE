# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 커뮤니티 신설

- 같이 게임할 사람을 모으는 모집글을 쓰고, 가까운 순이나 최신 순으로 목록을 볼 수 있습니다.
- 제목과 장소로 검색하고, 관심 있는 글은 스크랩해 따로 모아 봅니다.
- 글에 댓글과 답글을 달고 좋아요를 누를 수 있습니다.
- 모집 상태를 모집 중과 마감으로 바꾸고, 내가 쓴 글을 고치거나 지울 수 있습니다.
- 글과 댓글, 채팅 메시지를 신고할 수 있습니다.
- 모집글 링크를 공유하면 앱에서 그 글로 바로 열립니다.

2. 모집글 단체 채팅

- 모집글마다 단체 채팅방이 열리고, 참여한 방은 커뮤니티의 내 모임 탭에 모입니다.
- 새 메시지가 실시간으로 도착하고, 안 읽은 개수를 목록에서 바로 확인합니다.
- 방마다 알림을 켜고 끌 수 있습니다.
- 글쓴이는 참가자를 내보낼 수 있습니다.
- 글쓴이가 채팅방에서 게임을 만들면 초대 카드가 올라가고, 카드를 눌러 바로 참여합니다.

3. 알림함과 알림 설정

- 커뮤니티 화면 오른쪽 위 종 아이콘에서 내 글에 달린 댓글과 답글을 모아 봅니다.
- 안 읽은 알림이 있으면 종 아이콘에 표시가 붙습니다.
- 푸시 알림을 누르면 해당 글로 바로 이동합니다.
- 알림은 전체, 글별, 댓글별로 나눠 켜고 끌 수 있습니다.

4. 홈·공지사항·마이페이지 새 디자인

- 홈, 커뮤니티, 마이페이지를 하단 탭으로 오갈 수 있습니다.
- 홈 화면을 프로필 카드와 게임 생성·참여 버튼 중심으로 다시 만들었습니다.
- 프로필 아이콘을 골라 바꿀 수 있습니다.
- 공지사항에 카테고리 필터를 추가하고 새 디자인을 적용했습니다.
- 설정을 마이페이지로 옮기고, 버그 제보와 오픈소스 라이선스 항목을 추가했습니다.

5. 앱 소개 온보딩

- 설치 후 처음 켤 때 게임 방법을 네 장으로 소개합니다.
- 화면 안에서 순서대로 뜨던 기존 안내는 없앴습니다.
- 마이페이지의 앱 소개 다시 보기로 언제든 다시 볼 수 있습니다.

6. 언어 설정 반영

- 앱에서 고른 언어를 함께 보내 공지와 자동 생성 닉네임을 그 언어로 받습니다.
- 아직 번역이 없어 다른 언어로 대체된 공지에는 안내를 함께 보여줍니다.

7. 게임 화면 개선

- 게임 생성을 지도에서 바로 시작하고, 인원과 시간을 한 항목씩 입력하도록 바꿨습니다.
- 게임 중 지도를 게임 구역 주변까지만 움직이도록 제한했습니다.
- 이용약관과 개인정보처리방침 등 법적 문서를 웹으로 보여줘 항상 최신 내용을 확인합니다.

8. 안정성 개선 및 버그 수정

- 도둑으로 게임한 뒤 대기방을 나오면 어두운 테마가 앱 전체에 남던 문제를 수정했습니다.
- 채팅방에서 게임을 만들 때 현재 위치가 아닌 기본 좌표로 구역이 열리던 문제를 수정했습니다.
- 필수 약관에 동의하지 않은 상태에서 기능을 쓰면 이유를 안내합니다.
- 목록 화면에서 탭을 다시 누르거나 앱으로 돌아오면 최신 내용을 다시 받아옵니다.
- 새 도메인으로 옮기고 초대 링크를 새 주소로 바꿨습니다.

==========

# [심사 노트 — App Review Information]

[한국어]

초대 코드는 앱 안에서 게임을 만들면 자동으로 발급됩니다. 저희가 미리 전달드릴 수 있는 고정 코드는 없습니다.

초대 코드 확인 방법

1. 앱을 실행하고 Apple로 로그인합니다. 별도의 데모 계정은 필요하지 않습니다.
2. 닉네임을 입력하고 위치 권한을 허용합니다.
3. 하단 탭의 홈에서 게임 생성하기를 선택합니다.
4. 지도에서 게임 구역과 감옥 위치를 지정하고, 인원과 시간을 설정한 뒤 게임을 만듭니다.
5. 대기실로 이동하면 초대 코드가 화면에 바로 표시됩니다. 이 값이 초대 코드입니다.
6. 다른 기기에서 홈의 게임 참여하기를 선택하고 이 코드를 입력하면 같은 게임에 입장합니다. 코드 직접 입력과 QR 코드 스캔 모두 지원합니다.

심사 시 참고 사항

- 실시간 위치 기반 멀티플레이 게임입니다. 방장은 다른 참가자가 입장해 준비를 완료한 뒤에 게임 시작 버튼을 사용할 수 있으므로, 게임 진행까지 확인하시려면 기기 2대가 필요합니다.
- 기기 1대만 사용 가능하시면 App Store Connect로 회신해 주세요. 심사용 게임을 즉시 개설하고 초대 코드를 전달드리겠습니다.
- 게임 구역은 게임을 만든 위치를 기준으로 설정됩니다. 심사 담당자님 위치에서 직접 만드시면 구역 안에서 정상적으로 진행됩니다.
- 이번 버전에 추가된 커뮤니티는 하단 탭의 커뮤니티에서 바로 확인하실 수 있습니다. 로그인 없이도 목록과 상세를 볼 수 있고, 글쓰기와 댓글, 채팅은 로그인 후 사용합니다.

[English]

The invite code is generated in-app when you create a game — there's no fixed code we can provide in advance.

How to obtain an invite code

1. Launch the app and sign in with Apple. No demo account needed.
2. Enter a nickname and allow location permission.
3. On the Home tab, select Create game.
4. Set the game area and jail location on the map, set player count and duration, then create the game.
5. In the waiting room, the invite code is shown on screen.
6. On another device, select Join game on the Home tab and enter the code (manual entry or QR scan).

Notes for review

- Real-time location-based multiplayer: the host can only start after another participant joins and marks ready, so two devices are needed for full gameplay.
- One device only? Reply via App Store Connect — we'll open a review game and send the invite code right away.
- The game area is centered on where the game is created; create it at your own location to stay inside the play area.
- Community (new this version) is under the Community tab. Lists and post details are readable without sign-in; posting, commenting, and chat require sign-in.
