# [주요 변경사항 — 애플 제출용]

```text
[한국어]
이번 버전의 주요 변경사항입니다.

1. 게임 시작 연출 추가
- 게임이 시작되면 내 역할을 알려 주는 배너가 표시됩니다.
- 경찰에게는 대기 화면, 도둑에게는 규칙 설명 화면이 표시되며 이후에도 안내 버튼에서 규칙을 다시 볼 수 있습니다.

2. 지도 좌표 격자 추가
- 게임 지도에서 좌표 격자(예: C3)를 켜고 끌 수 있습니다.
- 격자를 켠 상태에서 발견·의심 핑을 찍으면 해당 칸이 팀 채팅에도 올라갑니다.

3. 이동 경로 복원
- 게임 중 앱이 종료되어도 같은 게임에 다시 들어오면 내 이동 경로와 거리가 복원됩니다.
- 같은 방에서 다음 판을 시작할 때 이전 판의 이동 기록이 이어지던 문제를 수정했습니다.

4. 잠금 화면 표시 개선
- 잠금 화면과 다이내믹 아일랜드에 표시되는 게임 정보의 표시 문제를 개선했습니다.

5. 안정성 개선 및 버그 수정

---
[English]

Key changes in this version:

1. Game Start Presentation Added
- A banner now shows your role when the game starts.
- Police see a waiting screen and robbers see a rules screen. The rules can be viewed again from the info button.

2. Map Coordinate Grid Added
- You can turn a coordinate grid (e.g. C3) on and off on the game map.
- With the grid on, pings you place are also posted to team chat with their grid cell.

3. Movement Route Recovery
- If the app closes during a game, your movement route and distance are restored when you rejoin the same game.
- Fixed an issue where the previous game's movement record carried over when starting the next game in the same room.

4. Lock Screen Display Improvements
- Improved how game information appears on the lock screen and Dynamic Island.

5. Stability Improvements & Bug Fixes
```
