# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 내 기록 화면 추가
- 게임이 끝나면 이동 거리와 이동 경로, 체포·탈출 횟수, 승패 결과를 한눈에 확인할 수 있습니다.

2. 내 기록 공유
- 내 기록 카드를 이미지로 저장하거나 공유 시트를 통해 친구에게 공유할 수 있습니다.

3. 안정성 개선 및 버그 수정
- 로그아웃 중 일부 오류가 발생해도 로컬 로그인 정보가 정상적으로 정리되도록 개선했습니다.
- 서버 연결 주소를 갱신했습니다.

==========

[English]

Key changes in this version:

1. My Record Screen Added
- After a game ends, you can view your travel distance, route, arrest and escape counts, and match results at a glance.

2. Share Your Record
- Save your record card as an image or share it with friends through the native share sheet.

3. Stability Improvements & Bug Fixes
- Improved logout so that local login data is cleared properly even if an error occurs during the process.
- Updated the server connection address.
