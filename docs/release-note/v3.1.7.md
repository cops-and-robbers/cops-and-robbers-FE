# [주요 변경사항 — 애플 제출용]

```text
[한국어]
이번 버전의 주요 변경사항입니다.

1. 구역을 그려서 만드는 방식
- 지도를 꾹 누른 채 손가락을 움직이면 움직인 자취가 그대로 게임 구역이 됩니다
- 기존: 구역의 꼭짓점을 하나씩 눌러 찍어야 했습니다
- 변경: 한 번에 그려서 만들고, 다시 그리면 새 구역으로 바뀝니다
- 꼭짓점을 찍을 때 있던 개수 제한과 간격 제한을 없앴습니다
- 선이 겹치게 그려도 처음 만나는 지점에서 모양을 닫아 구역으로 인정합니다

2. 그린 구역 다듬기
- 구역을 그리면 꼭짓점마다 동그란 손잡이가 표시됩니다
- 손잡이를 꾹 눌러 끌면 그 꼭짓점만 옮길 수 있습니다
- 옮긴 결과 선이 겹치면 원래 자리로 되돌리고 안내합니다

3. 구역 설정 화면
- 지도가 화면 아래까지 넓어져 더 넓은 범위를 보면서 설정할 수 있습니다
- 거리로 설정과 핀으로 설정을 오갈 때 지도 크기가 바뀌지 않습니다
- 표시되는 구역 넓이가 오목한 모양에서도 실제 넓이와 맞게 계산됩니다

4. 대기실 문구
- 준비 완료 상태에서 누르는 버튼의 문구를 준비 취소로 바꿔, 누르면 무엇이 일어나는지 분명하게 했습니다

---
[English]

Key changes in this version:

1. Draw a zone instead of placing points
- Press and hold the map and move your finger; the path you trace becomes the game zone
- Before: you had to tap each corner of the zone one at a time
- After: you draw the whole zone at once, and drawing again replaces it
- The limits on how many corners you could place and how far apart they had to be are gone
- If your stroke crosses itself, the shape closes at the first crossing and is still accepted

2. Fine-tune the zone you drew
- Each corner of the zone shows a round handle
- Press and hold a handle and drag it to move that corner only
- If the move would make the outline cross itself, the corner returns to its original spot and a message explains why

3. Zone setup screen
- The map now extends further down the screen, so you can see more while setting the zone
- Switching between distance mode and pin mode no longer changes the map size
- The zone area shown is now correct for concave shapes as well

4. Waiting room wording
- Once you are ready, the button now reads Cancel Ready, so it is clear what pressing it does
```
