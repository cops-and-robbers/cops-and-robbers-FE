==========

[한국어]

이번 버전의 주요 변경사항입니다.

1. 게임 종료 후 위치 정보 수집 미중단 수정
- 게임이 끝난 후 결과 화면이 표시되는 동안 위치 정보 수집이 계속 유지되던 문제를 수정했습니다.
- 게임 종료 시점부터 위치 정보 수집이 즉시 중단됩니다.

2. 방장 권한 이전 시 팀 변경 버튼 미표시 수정
- 기존: 준비 완료 상태에서 방장 권한이 이전되면 팀 변경 버튼이 표시되지 않았습니다.
- 변경: 방장 권한 이전 시 준비 상태가 초기화되어 팀 변경 버튼이 정상 표시됩니다.

3. 대기방 입장·퇴장 시 진동 제거
- 다른 참가자가 대기방에 입장하거나 퇴장할 때 발생하던 불필요한 진동을 제거했습니다.

==========

[English]

Key changes in this version:

1. Fixed Location Data Collection Not Stopping After Game Over
- Fixed an issue where location data collection continued while the results screen was displayed after a game ended.
- Location data collection now stops immediately when the game ends.

2. Fixed Team Change Button Not Appearing After Host Transfer
- Before: When host privileges were transferred while in the ready state, the team change button was not displayed.
- After: The ready state is now reset upon host transfer, allowing the team change button to appear correctly.

3. Removed Unnecessary Vibration on Waiting Room Entry and Exit
- Removed unnecessary vibration that occurred when other participants entered or left the waiting room.
