# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 이벤트 게임 모드 추가
- 행사 진행을 위한 이벤트 게임 모드를 추가했습니다. 운영진을 찾아 검거하는 방식으로 진행됩니다.

2. 검거 증거 화면과 결과 확인
- 운영진을 검거하면 증거 화면이 표시되고, 게임이 끝나면 검거한 인원을 결과 화면에서 확인할 수 있습니다.

3. 진행 중인 게임 바로 참여
- 초대 코드로 이미 진행 중인 이벤트 게임에 바로 참여할 수 있습니다.

4. 안내 창 버튼 언어 표시 수정
- 영어·일본어로 설정된 기기에서 확인·취소 버튼이 한국어로 표시되던 문제를 수정했습니다.

5. 안정성 개선 및 버그 수정
- 검거 기록이 재접속 후에도 유지되도록 개선했습니다.

==========

[English]

Key changes in this version:

1. Event Game Mode Added
- Added an event game mode for running live events. Players find and catch staff members during play.

2. Capture Evidence and Results
- When you catch a staff member, an evidence screen appears, and you can review how many you caught on the results screen when the game ends.

3. Join an Ongoing Game Directly
- Use an invite code to join an event game that is already in progress.

4. Dialog Button Language Fix
- Fixed an issue where confirm and cancel buttons appeared in Korean on devices set to English or Japanese.

5. Stability Improvements & Bug Fixes
- Capture records are now preserved even after reconnecting.
