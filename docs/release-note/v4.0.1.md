# [주요 변경사항 — 애플 제출용]

```text
[한국어]
이번 버전의 주요 변경사항입니다.

1. 구역 축소: 켜면 게임 중 원형 구역이 정해진 시각마다 줄어들고, 남은 시간은 잠금 화면에도 표시됩니다.
2. 튜토리얼: 방에 처음 들어오면 경찰·도둑 튜토리얼이 나오고, 대기방 ⓘ로 다시 볼 수 있습니다.
3. 방 만들기: 플레이그라운드 → 감옥 → 최종 확인 3단계로 줄였습니다.
4. 대기방: 준비 단계를 없애고, 방장이 시작 전에 두 팀 인원을 확인합니다.
5. 연출: 게임 시작 장면, 출동 카운트다운, MVP 결과 화면을 새로 만들었습니다.
6. 게임 화면: 버튼을 화면 아래 하나의 메뉴로 모았습니다.
7. 안정성 개선 및 버그 수정

---
[English]

Key changes in this version:

1. Shrinking area: When on, the circle area shrinks at set times during the game, and the time left also shows on the lock screen.
2. Tutorial: A cops and robbers tutorial plays the first time you join a room, and can be replayed with ⓘ in the waiting room.
3. Room creation: Now three steps: Playground → Jail → Final Check.
4. Waiting room: The ready step is removed, and the host checks both teams before starting.
5. Scenes: New game start scenes, dispatch countdown, and MVP result screen.
6. In-game: Buttons are gathered into one menu at the bottom of the screen.
7. Stability improvements & bug fixes
```
