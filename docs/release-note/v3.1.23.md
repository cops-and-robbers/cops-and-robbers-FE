# [주요 변경사항 — 애플 제출용]

```text
[한국어]
이번 버전의 주요 변경사항입니다.

1. 앱 재실행 시 잠금 화면 표시 유지
- 게임 중 앱을 다시 실행해도 잠금 화면의 게임 표시가 사라지지 않고 이어서 표시됩니다
- 같은 방에서 새 게임이 시작된 경우에는 이전 표시를 닫고 새 게임 기준으로 표시합니다
- 종료 시각이 지난 표시는 앱을 실행할 때 정리됩니다

2. 게임 종료·로그아웃 시 잠금 화면 표시 정리
- 앱을 다시 실행했을 때 진행 중인 게임이 없는 것으로 확인되면 잠금 화면과 다이내믹 아일랜드의 게임 표시가 사라집니다
- 로그아웃, 인증 만료, 회원 탈퇴 시에도 게임 표시가 사라집니다
- 게임 상태를 확인하지 못한 경우에는 표시를 그대로 둡니다

3. 안정성 개선 및 버그 수정
- 게임 종료 직후 같은 게임에 다시 들어갔을 때 종료 예정인 표시가 다시 선택되던 문제를 수정했습니다

---
[English]

Key changes in this version:

1. Lock Screen Display Kept When the App Is Reopened
- If you reopen the app during a game, the game display on the lock screen is kept and continues to update instead of disappearing
- If a new game starts in the same room, the previous display is closed and the new game is shown
- A display whose end time has passed is removed when the app is launched

2. Lock Screen Display Removed When a Game Ends or You Log Out
- If the app finds on launch that there is no game in progress, the game display on the lock screen and in the Dynamic Island is removed
- The game display is also removed on logout, session expiry, and account deletion
- If the game status cannot be checked, the display is left as it is

3. Stability Improvements & Bug Fixes
- Fixed an issue where a display that was about to end could be selected again when re-entering the same game right after it ended
```
