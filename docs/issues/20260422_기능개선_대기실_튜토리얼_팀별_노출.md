## 제목

🚀 [기능개선][Flutter][대기실][튜토리얼] 대기실 튜토리얼 팀별 1회씩 노출 및 팀 변경 시 재노출

## 본문

## 📝 현재 문제점

- 대기실 튜토리얼이 단일 키로 완료 여부를 저장해 경찰/도둑 구분 없이 최초 진입 시 1회만 노출된다.
- 팀 변경 카드 안내는 현재 사용자의 반대 팀 첫 번째 슬롯을 가리키도록 분기되어 있는데, 한쪽 팀에서 튜토리얼을 본 뒤 반대 팀으로 변경해도 새로운 반대 팀 위치를 안내하는 튜토리얼이 다시 뜨지 않는다.
- 튜토리얼 초기화 시점에 현재 팀 값을 한 번만 읽는 구조라, 이미 대기실에 들어와 있는 상태에서 TEAM_UPDATE 이벤트가 오면 안내 타깃이 실제 UI와 어긋날 수 있다.

## 🛠️ 해결 방안 / 제안 기능

- 대기실 튜토리얼 완료 상태를 경찰/도둑 각각 별개의 키로 분리하여 팀별로 1회씩 노출되도록 한다.
- 팀이 최초로 확정되는 시점과 팀이 변경되는 시점 모두에서 해당 팀 기준 튜토리얼이 자동으로 실행되게 한다.
- 튜토리얼 진행 중 사용자가 반대 팀으로 이동하면 현재 튜토리얼을 종료 처리하고, 새 팀 기준 튜토리얼이 아직 노출된 적 없다면 즉시 이어서 보여준다.
- 양쪽 팀 모두 튜토리얼을 완료한 사용자는 이후 팀을 오가도 더 이상 튜토리얼이 뜨지 않는다.

## ⚙️ 작업 내용

- 대기실 튜토리얼 완료 키를 팀별로 분리하고 팀 문자열에 대응하는 키 헬퍼 추가
- 튜토리얼 노출 함수가 현재 팀 값을 내부에서 다시 읽지 않고 호출부에서 전달받은 팀 기준으로 동작하도록 변경
- 참가자 진입 후 직접 튜토리얼을 호출하던 흐름을 제거하고, 팀 상태 변경을 감지하는 리스너에서 초기 노출과 재노출을 한 곳에서 처리하도록 통합
- 반대 팀 정원이 꽉 차서 팀 변경 카드가 렌더링되지 않은 경우 해당 스텝만 조용히 건너뛰는 기존 가드 유지
- 이전에 단일 키로 튜토리얼을 완료한 사용자는 새 구조에서 경찰/도둑 각각 최초 진입 시 한 번씩 다시 노출 (의도된 동작)
