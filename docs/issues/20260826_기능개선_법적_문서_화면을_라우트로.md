# 🚀 [기능개선][Flutter][약관] 법적 문서 화면을 최상위 라우트로 올리기

## 📝 현재 문제점

- 법적 문서 화면을 여는 곳이 열한 군데인데 전부 `Navigator.push` 로 띄운다. 그래서 전환이 `MaterialPageRoute` 기본값이고, 앱의 다른 화면이 쓰는 공용 전환과 어긋난다. 마이페이지에서 약관 설정까지는 슬라이드로 들어가는데 거기서 약관 상세로 넘어갈 때만 플랫폼 기본 전환이다
- 화면이 제목을 인자로 받는다. 제목은 문서 종류가 정해지면 따라오는 값인데 호출부가 따로 넘기고 있어, 이용약관 제목에 개인정보 문서를 넣어도 아무도 잡지 못한다
- 오픈소스 라이선스만 마이페이지 하위 라우트로 올라가 있다. 같은 화면인데 진입 경로에 따라 방식이 다르다

## 🛠️ 해결 방안 / 제안 기능

- 법적 문서 화면을 최상위 라우트 하나로 올린다. 마이페이지 하위가 아니라 최상위인 이유는, 로그인과 가입 동의 화면에서도 같은 화면을 열기 때문이다
- 문서 종류에서 제목을 끌어오는 함수를 두고 화면이 스스로 제목을 정하게 한다. 게임 종료 사유 문구를 다루는 기존 방식과 같은 형태다
- 오픈소스 라이선스도 이 라우트로 흡수한다

## ⚙️ 작업 내용

- `/legal/:doc` 최상위 라우트 신설. 문서 다섯 종(이용약관, 개인정보 처리방침, 위치정보 이용약관, 마케팅 수신 동의, 오픈소스 라이선스)을 받는다
- 알 수 없는 값이 들어왔을 때의 처리를 정한다. 커뮤니티 게시글 상세가 잘못된 경로를 다루는 방식을 참고한다
- 문서 종류에서 제목을 끌어오는 함수 추가와 단위 테스트
- 화면에서 제목 인자 제거
- 호출부 열한 곳을 라우트 이동으로 교체 (로그인 3, 가입 동의 4, 약관 설정 4)
- 마이페이지 하위의 오픈소스 라이선스 라우트 제거

## 📌 참고

- 지금 동작이 깨져 있지는 않다. 전환 연출이 튀는 것과, 제목이 어긋날 여지가 있는 것이 대상이다
- 목록 안의 항목을 라우트로 두는 방식은 커뮤니티 게시글 상세(`:postId`)에 선례가 있다
- 탭 스택에 남는 문제는 이미 없다. 약관 상세가 루트 네비게이터에 올라가 있어서다
- 최상위 라우트가 되면 나중에 앱 딥링크를 열 때 약관 링크를 앱에서 바로 여는 길이 생긴다. 지금은 초대 링크만 통과시키는 화이트리스트라 외부 진입점이 되지는 않는다
- v3 배포 전에 처리하는 것이 좋다. 배포 후로 미루면 전환 불일치가 사용자에게 나간다
