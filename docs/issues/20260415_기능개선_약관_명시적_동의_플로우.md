## 제목

🚀 [기능개선][약관동의] 로그인 후 약관 명시적 동의 플로우 추가 (이용약관 / 개인정보처리방침 / 위치정보 이용약관)

## 본문

## 📝 현재 문제점

- 현재 가입 시 이용약관과 개인정보처리방침을 묵시적으로 동의한 것으로 간주하고 있어, 법적으로 명시적 동의가 필요한 요건을 충족하지 못한다.
- 위치정보를 핵심 기능으로 사용하는 앱이지만 위치정보 이용약관에 대한 동의 절차가 존재하지 않는다.
- 사용자가 어떤 약관에 동의했는지 기록이 남지 않아 추후 약관 개정 시 재동의 처리도 어렵다.

## 🛠️ 해결 방안 / 제안 기능

- 로그인 성공 이후(= 백엔드 JWT 발급 이후) 신규 가입자 또는 아직 동의하지 않은 사용자에게 약관 동의 화면을 노출한다.
- 약관 동의 화면에서 3종(이용약관, 개인정보처리방침, 위치정보 이용약관)을 필수 체크, 마케팅 수신은 선택 체크로 받는다.
- 백엔드의 `LoginResponse.requiresAgreement` 필드에 따라 라우팅을 분기하여, 미동의 상태에서는 홈 및 게임 기능 접근을 차단한다.
- 필수 3종 모두 체크되었을 때만 "동의하고 시작하기" 버튼이 활성화되도록 한다.
- 각 약관은 본문 상세 화면(또는 바텀시트)으로 이동할 수 있어야 한다.

### 라우팅 흐름

```
Splash → Google 로그인 → /api/auth/login
                              │
                              ├─ requiresAgreement = true
                              │     → 약관 동의 화면
                              │     → POST /api/auth/agreements
                              │     → (신규) 닉네임 설정 화면
                              │     → 홈
                              │
                              └─ requiresAgreement = false
                                    → 닉네임 유무 분기 후 홈
```

### 약관 동의 화면 구성

- 상단: "서비스 이용을 위해 약관에 동의해주세요" 안내
- 전체 동의 체크박스 (필수 3개 + 선택 1개 일괄 체크)
- 이용약관 동의 (필수) + 상세보기
- 개인정보처리방침 동의 (필수) + 상세보기
- 위치정보 이용약관 동의 (필수) + 상세보기
- 마케팅 정보 수신 동의 (선택) + 상세보기
- 하단 "동의하고 시작하기" CTA (필수 3종 체크 시 활성화)

### 에러 / 이탈 처리

- 약관 동의 화면에서 뒤로가기 혹은 앱 종료 시, 다음 접속 때도 동일하게 약관 동의 화면부터 재진입한다 (`requiresAgreement` 응답 기준).
- `POST /api/auth/agreements` 실패 시 기존 에러 처리 컨벤션(`AppException` + 스낵바)에 맞춰 재시도 가능하도록 처리한다.
