# ❗ [버그][커뮤니티] 조회 상태와 관계없이 정렬 메뉴 항상 표시

## 🗒️ 설명

커뮤니티에서 인기순 등으로 정렬을 변경한 뒤 결과가 없으면 정렬 메뉴가 사라져 다른 정렬을 선택할 수 없습니다. 조회 상태와 관계없이 정렬 메뉴를 표시해 다시 선택할 수 있게 합니다.

코드 확인 결과 `community_feed_list.dart`의 `_buildSortLabel`은 게시글이 있는 `_buildList`에서만 호출됩니다. 빈 결과·로딩·오류 분기에는 정렬 메뉴가 없습니다. 이 위젯은 커뮤니티 목록과 검색 결과에서 공유합니다.

<br>

## 🔄 재현 방법

1. 커뮤니티 목록에서 정렬 메뉴를 엽니다.
2. 조회 결과가 없는 정렬(예: 인기순)을 선택합니다.
3. 빈 상태 안내와 함께 정렬 메뉴가 사라져 다른 정렬로 돌아갈 수 없는지 확인합니다.

<br>

## ✅ 예상 동작

- 게시글 유무·로딩·오류에 관계없이 정렬 메뉴가 표시되고 다른 정렬을 선택할 수 있습니다.
- 목록과 검색 결과에 동일하게 적용합니다.
- 기존 정렬 옵션과 거리순 실패 시 최신순 표시 동작을 유지합니다.
