## 제목

❗ [버그][게임][참가자목록] 마지막 도둑 체포 시 도둑 캐릭터 SVG가 jailed → ready 로 바뀜

## 본문

## 🗒️ 설명

- 경찰이 마지막 도둑을 체포하여 게임이 종료될 때, 참가자 목록 오버레이에 표시되는 도둑 캐릭터 SVG가 jailed 상태로 바뀌었다가 다시 ready(활동 중) 상태 SVG 로 변경된다.
- 체포된 도둑은 게임 종료 후에도 jailed 상태로 표시되어야 하지만, 실제로는 ready SVG 로 되돌아간 채 유지된다.
- 게임 로직(체포 처리·승패 판정)에는 문제가 없으며, 참가자 목록 UI 표시에 한정된 문제.

## 🔄 재현 방법

1. 경찰 N명, 도둑 1명으로 게임 시작
2. 경찰 플레이어가 참가자 목록(사람 아이콘) 오버레이를 연 상태로 유지
3. 경찰이 마지막 도둑을 체포 (QR 스캔 또는 디버그 카드 탭)
4. 체포 직후 참가자 목록의 도둑 아바타가 jailed.svg 로 바뀐 것을 확인
5. 직후 "게임 종료!" 팝업이 뜨는 시점에 도둑 아바타가 ready.svg 로 변경됨
6. 결과 다이얼로그가 닫힐 때까지 도둑 아바타는 ready 상태로 남아 있음 (jailed 로 복구되지 않음)
