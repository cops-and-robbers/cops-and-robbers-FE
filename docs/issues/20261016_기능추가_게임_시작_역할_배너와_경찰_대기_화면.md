# ⚙️ [기능추가][게임] 게임 시작 역할 배너와 경찰 대기 화면 추가

## 🔥 구현 기능

게임이 시작되면 **내 역할과 미션을 크게 보여 주고**, 경찰이 기다리는 동안과 도둑의 처음 12초 동안 **게임 규칙을 한 장면 안에서 읽게** 한다. 경찰 출동 순간은 배너와 진동으로 알린다. 이벤트 게임은 지금 그대로 둔다.

| 화면 | 언제 | 내용 |
|---|---|---|
| ① 역할 배너 | 시작 직후(시작 후 20초 안에 진입) | 팀색 사선 줄무늬 띠에 내 팀 캐릭터, 팀 이름, 미션 한 줄. 약 3.7초, 탭하면 바로 닫힘 |
| ② 경찰 대기 화면 | 경찰, 출동 전 | 지금의 대기 팝업을 대신한다. 남은 시간, 멀어지는 도둑, 규칙이 3초마다 바뀜. 대기 중에는 지금처럼 나갈 수 없음 |
| ③ 도둑 설명 화면 | 도둑, ① 다음 | 12초 또는 출동 또는 탭 중 먼저 오는 것까지. 규칙 4줄 |
| ④ 출동 배너 | 화면이 떠 있는 동안 출동 시각이 지날 때 한 번 | 팀별 진동 |
| ⑤ 규칙 다시 보기 | 앱바 ⓘ | 같은 장면으로 규칙을 다시 본다 |
| ⑥ ⓘ 위치 안내 | 첫 게임 한 번 | 규칙은 ⓘ에서 다시 볼 수 있다고 알림 |

<br>

## 📝 현재 문제점

- 시작하면 위쪽 공지 배너에 "게임 시작!" 같은 글만 차례로 흘러가고, 내가 어느 팀인지·무엇을 해야 하는지는 따로 알려 주지 않는다.
- 경찰은 지도 위 팝업(`_showPoliceTimerIfNeeded`, `game_page.dart:428`)으로 대기 시간만 본다.

<br>

## 🛠️ 해결 방안

| 영역 | 변경 |
|---|---|
| `game_page.dart` | 시작 흐름 단계 진행을 붙이고, 대기·설명 장면을 지도·앱바 위, 공지 배너·플로팅 버튼 아래에 끼운다. 일반 게임에서는 대기 팝업 대신 ②를 띄운다 |
| `game_event_provider.dart` | 일반 게임에서 START·`POLICE_MOVE_START` 공지 배너를 띄우지 않는다(채팅 기록은 유지) |
| 시작 때 시스템 메시지 | 10초 "잠시 후 게임이 시작돼요"·30초 "게임 시작!"은 채팅에만 남긴다 |
| 대기실 규칙 다이얼로그 | 핑 규칙 한 줄을 4번으로 더한다 |
| 에셋 | `assets/characters/{police,robber}/start/default/`, `assets/backgrounds/start_wait/` (배경 3종 × 낮·밤) |
| 문구 | ko/en/ja ARB에 추가 |

> [!IMPORTANT]
> 시각은 모두 서버 `gameStartTime` + `policeWaitMinutes`로 계산한다. 앱을 다시 켜도 같은 상태가 돼야 한다(출동 전이면 경찰은 ②부터, 도둑은 지도부터).

<br>
