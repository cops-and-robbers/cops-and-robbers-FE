# 🚀 [기능개선][게임생성][구역설정] 감옥 설정 지도를 플레이그라운드 중심에서 시작

## 📝 현재 문제점

새 감옥을 설정할 때 지도가 **항상 현재 GPS 위치**에서 열린다. #605로 모집글 채팅방에서 만든 게임은 플레이그라운드가 모임 장소에서 시작하지만, 다음 단계인 감옥 지도는 다시 현재 위치로 돌아간다. 감옥은 플레이그라운드 안에 있어야 하므로 사용자가 방금 그린 플레이그라운드를 지도에서 다시 찾아가야 한다.

<br>

## 🛠️ 해결 방안 / 제안 기능

진입 경로별로 시작 위치를 따로 넘기지 않고, **감옥 화면 안에서 플레이그라운드 중심을 새 감옥의 시작 위치로 쓴다.** 방 생성(홈·모집글)·방 수정 어디서 들어와도 같은 규칙이 적용된다.

| 상황 | 기대 동작 |
|---|---|
| 새 감옥 (원형 플레이그라운드) | 플레이그라운드 원의 중심에서 시작 |
| 새 감옥 (핀 플레이그라운드) | 플레이그라운드 꼭짓점들의 중심(`AreaShape.centroid`)에서 시작 |
| 기존 감옥이 있음 (재편집·방 수정) | 기존 감옥 위치 유지 |
| 내 위치 버튼 | 사용자가 요청했을 때 현재 위치로 이동 |

<br>

## 🔄 확인 시나리오

1. 현재 위치 A와 떨어진 장소 B에 플레이그라운드를 설정한다 (모집글 채팅방 진입 또는 지도를 옮겨서).
2. 다음 단계인 감옥 설정 지도가 A에서 열리는 현상을 확인한다.
3. 개선 후에는 B(플레이그라운드 가운데)에서 열려야 한다. 원형·핀 모드 모두 확인한다.
