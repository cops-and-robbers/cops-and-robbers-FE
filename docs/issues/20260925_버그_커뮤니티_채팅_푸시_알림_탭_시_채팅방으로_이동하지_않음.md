❗ [버그][Flutter][알림] 커뮤니티 채팅 푸시 알림 탭 시 채팅방으로 이동하지 않음

## 🗒️ 설명

커뮤니티 채팅 푸시 알림(일반 채팅·게임 초대·고정 채팅 등록/수정/삭제)을 탭하면 앱만 열리고 **해당 모집글의 채팅방으로 이동하지 않는다.** 서버는 이동에 필요한 `postId`를 이미 보내고 있으므로 **앱(FE)만 고치면 된다** — 백엔드 변경은 필요 없다.

> [!IMPORTANT]
> **범위 추가 (2026-09-25):** 게임·대기실 중(앱이 백그라운드여도)에는 커뮤니티 채팅과 **댓글·답글** 알림을 탭해도 이동하지 않고 스낵바("지금은 커뮤니티 알림을 열 수 없어요")만 띄운다. 게임 위에 커뮤니티 화면이 얹힌 뒤 강퇴·나가기·게시글 보기가 `go`로 스택을 갈아엎으면 `GamePage.dispose()`가 소켓과 백그라운드 위치를 끊기 때문이다(`community_chat_room_page.dart:73`, `community_chat_room_info_page.dart:143·233`, `game_page.dart:396`). 댓글·답글은 #500부터 같은 위험이 있었다. 서버는 게임 참여 여부로 커뮤니티 푸시를 거르지 않으므로 앱에서 막는다. 인게임 채팅(`CHAT`)과 콜드 스타트(게임 복귀 우선)는 그대로다.

<br>

## 🔄 재현 방법

1. 커뮤니티 모집글 채팅방에 참여한 상태에서 앱을 백그라운드로 보내거나 종료한다.
2. 다른 참여자가 그 채팅방에 메시지를 보내거나(게임 초대 포함), 방장이 고정 채팅을 등록·수정·삭제한다.
3. 도착한 푸시 알림을 탭한다 → 채팅방이 아니라 마지막 화면(또는 홈)이 열린다.

<br>

## ✅ 예상 동작

- 커뮤니티 채팅·게임 초대·고정 채팅 푸시를 탭하면 해당 `postId`의 채팅방(`/community/:postId/chat`)이 열린다.
- 앱 실행 중·백그라운드·종료(콜드 스타트) 세 경우 모두 같은 목적지로 간다.

<br>

## ❓ 확인 필요

- 탈퇴·강퇴 등으로 이미 멤버가 아닌 방의 푸시를 탭했을 때 채팅방 대신 어디로 보낼지(게시글 상세 또는 무시).
- `TEXT`·`PIN_*`는 이름이 일반적이라 나중에 다른 푸시와 겹칠 수 있다. 지금은 인게임 시스템 이벤트(`ARREST` 등)와 겹치지 않는다. 서버에 `COMMUNITY_CHAT` 같은 전용 `type`을 요청할지는 선택 사항이다(이번 수정에는 불필요).
