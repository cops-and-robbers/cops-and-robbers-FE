## 제목

🚀 [기능개선][Web][딥링크] /join/{code} 페이지를 스토어 폴백에서 앱 능동 실행(핸드오프) 브릿지로 개선

## 본문

## 📝 현재 문제점

- 초대 딥링크(https://copsnro66ers.site/join/{초대코드})가 앱이 설치되어 있어도, 카카오톡/인스타그램/당근 인앱 브라우저, QR 스캔, 브라우저 주소창 직접 입력으로 접근하면 앱이 실행되지 않고 앱스토어/플레이스토어로만 이동한다.
- 반면 메모/문자 앱에서 링크를 직접 탭하면 앱이 정상적으로 열린다. 즉 도메인 검증 파일(assetlinks.json / apple-app-site-association), Android App Links / iOS Universal Links, 앱 네이티브 설정은 모두 정상임이 확인되었다.
- 원인: 인앱 브라우저/QR/주소창 입력은 OS의 자동 링크 가로채기가 발동하지 않아 웹페이지로 진입하는데, 현재 /join/{code} 페이지에는 "스토어 안내(미설치 사용자용 폴백)" 기능만 있고, 설치된 앱을 직접 여는 핸드오프 로직이 전혀 없다. (배포된 페이지/번들 전수 확인 결과 앱 실행 관련 로직 부재 확정)
- 기존 가이드(docs/DEEPLINK.md, 관련 이슈 20260528_기능요청_딥링크_핸드오프_Nextjs)는 페이지를 "앱 미설치 사용자용 폴백"으로만 설계했고, 인앱 환경에서 설치된 앱을 능동적으로 깨우는 처리가 빠져 있었다.

## 🛠️ 해결 방안 / 제안 기능

- /join/{code} 페이지를 "스토어 폴백"에서 "능동 핸드오프 브릿지 페이지"로 개선한다.
- 페이지 진입 시 설치된 앱을 직접 실행 시도하고, 실패(미설치)일 때만 스토어로 안내한다.
- 인앱 브라우저는 외부 브라우저로 탈출시키고, 탈출 수단이 없는 환경은 안내 문구를 노출한다.
- 목표: 네이버지도 공유 링크처럼 어떤 진입 경로(인앱/QR/주소창)에서도 설치된 앱으로 연결된다.
- 검증 파일(.well-known/*)과 vercel.json 설정은 현행 유지한다(정상 동작 중).

## ⚙️ 작업 내용

1. /join/[code] 페이지에 클라이언트 사이드 핸드오프 로직 추가 (서버 렌더링 폴백 UI는 유지)
2. User-Agent로 인앱 브라우저 감지 후 외부 브라우저 탈출 처리
   - 카카오톡: 외부 브라우저로 여는 전용 스킴 사용
   - 라인: 외부 브라우저 강제 파라미터 사용
   - 인스타그램/당근 등 공식 탈출 수단이 없는 환경: "다른 브라우저(Safari/Chrome)로 열기" 안내 노출
3. 설치된 앱 능동 실행 시도 + 미설치 시 스토어 폴백
   - Android: 앱 직접 실행, 미설치 시 Play 스토어(com.elipair.copsandrobbers)로 이동
   - iOS: 앱 커스텀 스킴으로 실행, 미설치 시 App Store(id6756843948)로 이동
4. 수동 "앱에서 열기" 버튼 + 스토어 버튼 폴백 UI 제공(자동 실행 실패/데스크톱 대비)
5. 진입 경로별 검증: 카카오톡/인스타/당근 인앱, QR(기본 카메라), 주소창 직접 입력 각각에서 설치 시 앱 실행 / 미설치 시 스토어 이동 확인

## ⚠️ 선결 의존성 (모바일 앱 측)

- iOS 커스텀 스킴 실행은 모바일 앱이 해당 스킴을 등록해야 작동한다. iOS는 웹 변경 + 앱 측 작업(App Store 재배포)이 함께 필요하다.
- Android는 기존 App Links 기반으로 동작하므로 웹 변경만으로 즉시 적용 가능하다.
- 핸드오프 구체 레퍼런스 로직은 아래 "레퍼런스 구현 코드" 섹션 참고.

## 💻 레퍼런스 구현 코드 (Next.js App Router 기준)

> iOS 커스텀 스킴(copsandrobbers://)은 모바일 앱이 등록해야 동작한다(위 선결 의존성 참고). App Store ID(6756843948)와 패키지명은 실제 값이다.

app/join/[code]/JoinBridge.tsx

```tsx
'use client';
import { useEffect, useState } from 'react';

const PKG = 'com.elipair.copsandrobbers';
const APP_STORE = 'https://apps.apple.com/kr/app/id6756843948';
const PLAY_STORE = `https://play.google.com/store/apps/details?id=${PKG}`;

export default function JoinBridge({ code }: { code: string }) {
  const [stuck, setStuck] = useState<'inapp' | 'desktop' | null>(null);

  const openApp = () => {
    const ua = navigator.userAgent;
    const url = window.location.href;

    // 1) 인앱 브라우저 탈출
    if (/kakaotalk/i.test(ua)) {                          // 카카오톡 → 외부 브라우저
      window.location.href = 'kakaotalk://web/openExternal?url=' + encodeURIComponent(url);
      return;
    }
    if (/line/i.test(ua)) {                               // 라인 → 외부 브라우저
      window.location.href = url + (url.includes('?') ? '&' : '?') + 'openExternalBrowser=1';
      return;
    }
    if (/instagram|fbav|fb_iab|daangn|karrot/i.test(ua)) { // 인스타/당근 등 탈출 스킴 없음
      setStuck('inapp');                                  // → 안내 UI
      return;
    }

    // 2) 정상 브라우저 → 설치 앱 능동 호출
    if (/android/i.test(ua)) {
      window.location.href =
        `intent://copsnro66ers.site/join/${code}` +
        `#Intent;scheme=https;package=${PKG};` +
        `S.browser_fallback_url=${encodeURIComponent(PLAY_STORE)};end`;
      return;
    }
    if (/iphone|ipad|ipod/i.test(ua)) {
      let opened = false;
      const onHide = () => { if (document.hidden) opened = true; };
      document.addEventListener('visibilitychange', onHide);
      window.location.href = `copsandrobbers://join/${code}`;   // 앱 미설치면 무반응
      window.setTimeout(() => {                                  // → 1.5초 후 App Store
        document.removeEventListener('visibilitychange', onHide);
        if (!opened) window.location.href = APP_STORE;
      }, 1500);
      return;
    }

    setStuck('desktop'); // 데스크톱 등
  };

  useEffect(() => { openApp(); }, []); // eslint-disable-line react-hooks/exhaustive-deps

  // 폴백 UI: 자동 실행 실패 / 탈출 불가 인앱 / 데스크톱 대비
  return (
    <main>
      <button onClick={openApp}>앱에서 열기</button>
      <a href={APP_STORE}>App Store</a>
      <a href={PLAY_STORE}>Google Play</a>
      {stuck === 'inapp' && <p>우측 상단 ⋯ → ‘다른 브라우저로 열기’(Safari/Chrome)로 열어주세요</p>}
    </main>
  );
}
```

app/join/[code]/page.tsx

```tsx
import JoinBridge from './JoinBridge';

export default async function Page({ params }: { params: Promise<{ code: string }> }) {
  const { code } = await params;
  return <JoinBridge code={code} />;
}
```

구현 메모

- 검증 파일(.well-known/assetlinks.json, apple-app-site-association)과 vercel.json은 현행 유지(정상 동작 중). 본 작업은 /join/[code] 페이지 로직만 변경.
- iOS는 커스텀 스킴 미설치 시 "Safari에서 페이지를 열 수 없습니다" 경고가 잠깐 뜰 수 있다. visibilitychange로 앱 실행 여부를 감지해 실행 안 됐을 때만 App Store로 보낸다.
- 카카오톡 외부 탈출 후 외부 브라우저에서 페이지가 다시 로드되며 위 로직이 재실행된다.
- Pages Router를 쓰는 경우 동일 로직을 pages/join/[code].tsx 의 클라이언트 컴포넌트로 옮기면 된다.
