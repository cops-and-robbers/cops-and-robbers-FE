# 본문

## 📝 현재 문제점

- 백엔드 `api-docs.json`에 공지사항(Notice) API가 추가되었으나 프론트에 미연동되어 사용자가 공지사항을 확인할 수 없음
- 관련 엔드포인트
  - `GET /api/notices` — 공지사항 목록 조회 (페이지네이션, 고정 공지 우선 정렬)
  - `GET /api/notices/{noticeId}` — 공지사항 단건 조회
  - `POST /api/notices` — 공지사항 생성 (관리자)
  - `PUT /api/notices/{noticeId}` — 공지사항 수정 (관리자)
  - `DELETE /api/notices/{noticeId}` — 공지사항 삭제 (관리자)

## 🛠️ 해결 방안 / 제안 기능

- 사용자 앱에서는 조회 API(GET 2종)만 연동
- 관리자 전용(POST/PUT/DELETE)은 본 이슈 범위에서 제외
- 공지사항 목록/상세 진입 동선 및 화면 구성은 디자인 시안 확인 후 반영
