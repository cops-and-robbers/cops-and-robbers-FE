# 🚀 [기능개선][약관] 약관 페이지 진입 시 서버 동의 상태 조회하여 체크박스 초기화

## 📝 현재 문제점

- 백엔드에서 정책 갱신으로 특정 약관(예: 위치정보 이용약관)을 false로 변경하면 사용자는 약관 동의 페이지로 다시 진입한다
- 이때 약관 페이지의 체크박스가 4개 모두 미체크 상태로 표시된다
- 사용자는 이미 동의했던 이용약관·개인정보 처리방침까지 다시 일일이 체크해야 한다
- 원인: 약관 페이지 진입 시 서버의 현재 동의 상태를 조회하지 않고, 모든 체크박스를 기본값(false)으로 초기화하기 때문
- 인증 초기화 단계에서 `GET /api/user/agreements`를 호출하긴 하지만, 필수 약관 모두 동의 여부 boolean(`hasAllRequired`)만 추출하고 개별 항목 상태는 사용되지 않는다

## 🛠️ 해결 방안 / 제안 기능

- 약관 동의 페이지 진입 시 `GET /api/user/agreements`를 호출하여 서버의 현재 동의 상태를 조회한다
- 응답으로 받은 각 약관별 동의 여부(이용약관, 개인정보처리방침, 위치정보, 마케팅)를 체크박스 초기값에 반영한다
- 결과적으로 정책 변경으로 false로 갱신된 약관만 사용자가 새로 체크하면 되도록 동작한다
- 필수 3종 약관의 강제 동의 정책 자체는 유지한다 (백엔드 정책)
- 네트워크 실패 등 조회 실패 시 기존 동작(전부 미체크)으로 폴백하고 에러 메시지를 안내한다

## ⚙️ 작업 내용

- 약관 동의 화면 진입 시 서버에서 현재 동의 상태를 조회하는 로직 추가
- 응답값으로 약관 체크박스 초기 상태를 채우도록 상태 관리 로직 보완
- 로드 실패 시 폴백 처리 및 에러 안내 메시지 표시
- 설정 화면의 약관 관리 페이지와 동일한 패턴으로 일관성 유지
