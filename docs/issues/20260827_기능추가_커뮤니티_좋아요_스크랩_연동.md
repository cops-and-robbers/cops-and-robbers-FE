## 제목

⚙️ [기능추가][API연동][커뮤니티] 모집글 좋아요·스크랩 서버 연동

## 본문

## 📝 현재 문제점

- 좋아요와 스크랩이 앱 메모리에만 저장된다. 앱을 껐다 켜면 사라지고 다른 사람 화면에도 반영되지 않는다
- 스크랩한 글을 모아 볼 화면이 없다
- 서버 응답에 좋아요 수, 스크랩 수, 내가 눌렀는지 여부가 없어 버튼의 처음 상태를 그릴 수 없다. 이 값이 내려오기 전에는 착수할 수 없다

## 🛠️ 해결 방안 / 제안 기능

- 좋아요와 스크랩을 서버 연동으로 전환
- 내가 스크랩한 글 목록 화면 추가

## ⚙️ 작업 내용

- 좋아요 등록·취소, 스크랩 등록·취소를 서버 연동으로 전환한다
- 내 스크랩 목록을 조회한다. 이어 보기 방식이다
- 목록과 상세의 좋아요 수, 스크랩 수, 눌림 상태를 서버 값으로 표시한다
- 예시 데이터로 채워둔 저장소를 제거한다
- 실패 안내를 다국어 처리한다 (ko/en/ja)

## 📌 참고

- 선행 필요. 모집글 목록·상세 응답에 좋아요 수, 스크랩 수, 내가 눌렀는지 여부가 없다. 등록과 취소도 응답 본문이 없어 결과를 되받지 못한다. 서버가 이 값을 내려주기 전에는 버튼 초기 상태를 그릴 방법이 없다
- 인기순 정렬이 이미 좋아요와 스크랩을 세고 있어, 저장 구조를 바꾸지 않고 응답에 실을 수 있는 것으로 보인다
- 스크랩만은 내 스크랩 목록을 전부 훑어 우회할 수 있으나 좋아요는 그럴 수단도 없다
- 댓글·신고 이슈와 같은 화면, 같은 상태를 건드린다. 그 이슈를 먼저 끝내고 진행한다
