## 📝 현재 문제점

BE #205 / #208에서 참가자별 체포 수·잡힌 횟수가 서버에 저장되고 조회 API가 열렸지만, 앱은 `/me` 경로 자체가 없다(`lib/core/constants/api_endpoints.dart:130`에 `/api/game-results/{gameResultId}`만 존재). 결과 카드의 "체포 횟수"는 `totalArrestCount`(팀 합계)라 경찰도 도둑도 **자기 기록을 볼 수 없다**(`game_over_result_dialog.dart:806`).

| `/me` 필드 | 의미 | 사용 |
|---|---|---|
| `arrestCount` | 내가 체포한 횟수 (경찰 행만 증가) | 경찰 개인 탭 |
| `arrestedCount` | 내가 잡힌 횟수 (도둑 행만 증가) | 도둑 개인 탭 |
| `status` | 종료 시점 상태 (`ALIVE` / `JAILED`) | 도둑 개인 탭 |
| `team` | 팀 | 행 구성 분기 |
| `nickname`, `leftAt` | — | 사용 안 함 (카드에 내 캐릭터가 있고, 퇴장자는 이 다이얼로그를 보지 않아 `leftAt`은 항상 null) |

<br>

## 🛠️ 해결 방안 / 제안 기능

결과 다이얼로그 하나를 유지하고 `SegmentedToggle`(채팅 오버레이·커뮤니티 범위·구역 타입에서 쓰는 공용 위젯)로 **전체 / 개인** 탭을 둔다. 카드 높이가 튀지 않도록 헤더(제목·토글·날짜·거리·지도)는 공통이고 통계 3행만 갈린다.

> [!IMPORTANT]
> 팀에 **로직상 불가능한 값은 표시하지 않는다.** 경찰은 잡히지 않고 도둑은 체포하지 않으므로(`validateArrest`), 경찰 개인 탭에 잡힌 횟수·도둑 개인 탭에 체포 횟수를 넣지 않는다.

> [!IMPORTANT]
> **팀 체포 기여도** = `arrestCount ÷ totalArrestCount`. 두 API 값의 나눗셈이며 **정수 % 로 표시**(소수점 없음, 3÷7 → `43%`). 팀 총 체포가 0이면 `-`.

- 라벨을 가른다 — 「전체」의 "체포 횟수"는 팀 합계(기존 `labelArrestCount`), 「개인」은 "내 체포 횟수 / 잡힌 횟수" 새 키. 같은 라벨이 탭마다 다른 숫자로 보이면 안 된다.
- 로딩·실패 시 `'-'` placeholder — 기존 `_placeholderRows` 패턴을 개인 탭에도 적용한다. `/me` 실패가 전체 탭에 영향을 주지 않는다.
- 공유 이미지는 `RepaintBoundary`가 찍는 **보이는 탭** 그대로. 기본 탭이 「전체」라 기존 공유 이미지와 같다.
- `/me`는 `gameResultDioProvider`(전역 AuthInterceptor 미사용, 401을 강제 로그아웃으로 번지게 하지 않는 전용 Dio)를 그대로 쓴다.
