# 본문

## 📝 현재 문제점

- 백엔드 `api-docs.json`의 `MyPageResponse`에 알림 수신 동의 필드가 추가되었으나 프론트 미연동
  - `allowGamePush` — 게임 알림 수신 여부
  - `allowMarketingPush` — 마케팅 알림 수신 여부
- 사용자가 마이페이지에서 알림 수신 여부를 확인하거나 변경할 수 없는 상태

## 🛠️ 해결 방안 / 제안 기능

- 마이페이지 화면에 게임 알림 / 마케팅 알림 토글 UI 추가
- `GET /api/user/me` 응답의 새 필드(`allowGamePush`, `allowMarketingPush`) 매핑
- 토글 변경 시 호출할 갱신용 엔드포인트는 백엔드에 확인 필요 (현재 api-docs.json에 별도 PATCH 엔드포인트 미명시)
- FCM 토큰 정책과 충돌하지 않는지 확인 (게임 알림 OFF 시 푸시 수신 차단 동작 등)

## ⚙️ 작업 내용

- [ ] `MyPageResponse` DTO에 `allowGamePush`, `allowMarketingPush` 필드 추가
- [ ] User Entity 동기화
- [ ] 마이페이지 알림 설정 토글 UI 추가
- [ ] 토글 상태 갱신 API 백엔드 확인 후 연동 (없으면 별도 이슈로 분리)
- [ ] 마케팅 알림 OFF 사용자 대상 동작 정책 확인
- [ ] `flutter pub run build_runner build --delete-conflicting-outputs` 실행

## ❓ 확인 필요 사항

- 알림 수신 동의 변경용 PATCH/PUT 엔드포인트 존재 여부 (백엔드 확인)
- 약관 동의 플로우(`/api/user/agreements`)와의 관계 정리 필요 여부
