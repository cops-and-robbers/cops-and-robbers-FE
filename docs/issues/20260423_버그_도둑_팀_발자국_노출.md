## 제목

❗ [버그][게임][지도] 도둑 팀 재접속/초기 진입 시 이전 공개 발자국이 복구되어 노출됨

## 본문

## 🗒️ 설명

- 도둑 팀 플레이어가 게임 도중 접속이 끊겼다가 재접속하거나, 게임에 처음 진입하는 시점에 이미 공개된 동료 도둑의 발자국이 지도에 즉시 복구되어 표시됨
- 접속 유지 중 실시간 위치 공개 이벤트로 동료 위치를 확인하는 것은 정상 동작(전략상 필요)이므로 유지되어야 함
- 재접속/초기 진입 순간에만 과거 공개 위치까지 한꺼번에 노출되는 부분이 게임 밸런스를 해침 (도둑이 잠깐 끊고 다시 들어오면 지금까지 공개된 이력이 전부 드러남)

## 🔄 재현 방법

1. 게임 방을 생성하고 도둑 2명 이상으로 경찰/도둑 팀을 구성해 참가
2. 게임 시작 후 경찰 대기 시간이 끝나고 위치 공개 주기가 최소 1회 이상 진행될 때까지 대기
3. 도둑 플레이어 A가 앱을 강제 종료 후 재접속 → 지도에 이전 공개된 발자국이 즉시 복구되어 표시되는지 확인
4. 추가 재현: 게임 진행 중간에 도둑 B가 처음 진입해도 동일 현상 발생

## 📸 참고 자료

현재 동작 구조:

- 게임 이벤트 STOMP 연결 성공 시 마지막 공개 도둑 위치 조회 API를 호출해 공개된 모든 도둑 위치를 복구함
- 이 복구 로직이 팀 구분 없이 실행되어 도둑 팀에서도 동일하게 과거 공개 위치를 불러옴
- 실시간 위치 공개 이벤트는 양 팀 공통 채널로 브로드캐스팅되고 있어 도둑 팀도 이벤트 자체는 정상 수신함

## ✅ 예상 동작

- 도둑 팀은 접속 유지 중에는 실시간 위치 공개 이벤트로 동료 도둑 위치를 지도에서 확인할 수 있음 (현재 정상 동작, 변경 없음)
- 도둑 팀이 재접속하거나 게임에 최초 진입하는 시점에는 과거 공개된 발자국이 복구되어 표시되지 않음
- 재접속 이후 다음 위치 공개 이벤트가 도착한 시점부터 동료 도둑 위치가 다시 지도에 표시되기 시작
- 배너, 진동, 다음 공개까지 카운트다운 타이머 등 공개 관련 UI 신호는 양 팀 공통 유지
- 경찰 팀 동작은 현재와 동일 (재접속 시 공개된 도둑 발자국이 정상 복구되어 표시됨)
