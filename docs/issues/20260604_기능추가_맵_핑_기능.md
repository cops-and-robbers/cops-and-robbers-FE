## 본문

## 📝 현재 문제점

- 게임 화면(game_page)에서 도둑/경찰의 위치나 상황을 팀원에게 빠르게 알릴 수단이 없다.
- 음성/채팅만으로는 특정 지점을 정확히 가리키기 어려워 실시간 협업이 떨어진다.

## 🛠️ 해결 방안 / 제안 기능

- 맵을 길게 누르면(롱프레스) 해당 좌표 위에 핑 종류 선택 UI가 뜨고, 종류를 선택하면 그 위치에 핑이 찍힌다.
- 핑 종류는 두 가지로 구분한다.
  - 발견: 상대를 발견했을 때 사용
  - 의심: 상대가 있을 것으로 의심되는 지점에 사용
- 찍힌 핑은 같은 팀원에게 실시간으로 공유되어 함께 볼 수 있다. (서버는 STOMP / Redis 기반으로 제공 예정)
- 선택 UI와 핑 마커는 첨부 이미지 형태를 기준으로 한다. (좌표 위에 발견/의심 선택 카드 → 선택 시 해당 좌표에 핀 마커 표시)

## ⚙️ 작업 내용

- 맵 롱프레스 제스처로 누른 좌표 감지
- 누른 좌표 위에 발견/의심 핑 종류 선택 UI 표시
- 선택한 핑 종류 + 좌표를 서버로 전송 (실시간 통신)
- 팀원에게 수신된 핑을 맵 위에 마커로 표시 (발견/의심 구분)
- 핑 마커 시각 디자인 (발견/의심 아이콘 구분, 팀 테마 대응)
- 핑 유지/제거 정책 정의 필요 (일정 시간 후 자동 소멸 여부, 동시 핑 개수 제한 등)
