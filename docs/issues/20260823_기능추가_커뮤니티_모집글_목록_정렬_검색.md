⚙️ [기능추가][커뮤니티] 모집글 목록 정렬·검색 추가 및 변경된 API 연동

## 본문

## 📝 현재 문제점

- 백엔드가 목록 정렬(거리순·마감 임박순)과 키워드 검색을 열었으나 앱은 최신순 고정이고 상단 검색 아이콘이 동작하지 않음
- 모임 날짜가 지난 글에 종료 상태가 새로 생겼는데 앱이 이 값을 모름 — 지난 글이 섞이면 목록과 상세가 열리지 않음
- 정렬 바텀시트는 이미 있으나 선택해도 목록이 바뀌지 않고 라벨만 바뀜
- 응답에 복사용 지번 주소가 실려 오기 시작했으나 코드 주석은 아직 준비 예정 상태로 남아 있음

## 🛠️ 해결 방안 / 제안 기능

- 종료 상태 연동, 그리고 앱이 모르는 상태값이 와도 화면이 깨지지 않도록 처리
- 목록 정렬 3종(최신순·마감 임박순·거리순) 서버 연동
- 모집글 검색 화면 신설 — 제목·장소명·지역 검색, 최근 검색어

## ⚙️ 작업 내용

- 종료 상태 추가 — 목록·상세 배지 표기, 카드 흐림 처리, 종료된 글의 모집 상태 변경 메뉴 숨김
- 알 수 없는 상태값은 마감으로 처리 — 다음에 상태가 또 늘어나도 화면이 깨지지 않게
- 정렬 연동 — 최신순·마감 임박순·거리순. 인기순은 서버가 아직 열지 않아 시트에서 제외
- 거리순 선택 시 위치 권한 확보, 거부하면 안내 후 이전 정렬 유지
- 검색 화면 신설 — 검색 실행 시점에 1회 조회, 최근 검색어 저장(최대 10개)·개별 삭제·전체 삭제
- 검색 결과 화면에도 정렬 시트 적용
- 목록과 검색이 무한 스크롤 목록을 공용 위젯으로 사용
- 조회 조건(국가·정렬·검색어)이 바뀌면 첫 페이지부터 다시 조회
- 화면 문구 다국어 처리 (ko/en/ja)

## 📌 참고

- 종료 상태는 서버가 저장하지 않고 조회 시점에 판정한다. 모임 날짜가 지나면 작성자가 지정한 마감보다 날짜가 우선한다
- 마감·종료된 글은 정렬과 무관하게 목록 맨 뒤에 온다 — 앱이 따로 다시 정렬하지 않는다
- 검색어는 공백을 제외하고 2자 이상이어야 하며, 미만이면 서버에 보내기 전에 앱에서 먼저 막는다
- 커서에 국가·정렬·검색어가 묶여 있어 조건이 바뀌면 이전 커서를 쓸 수 없다
- 거리순은 좌표를 함께 보내야 하고, 다른 정렬에서 좌표를 보내면 거절된다
- 우리 동네·내 모임 범위와 인기순 정렬은 서버가 아직 열지 않았다
- 신규 회원 닉네임 언어 결정(로그인 요청 헤더)은 영역이 달라 별도 이슈로 분리한다
- 서버 스웨거 2.21.0 기준
