## 본문

## 📝 현재 문제점

- 인게임 화면에서 지도를 길게 눌러 핀을 찍는 동작에 별도의 진동 피드백이 없어, 길게 클릭이 인식됐는지 사용자가 즉각 알기 어렵다.
- 인게임 튜토리얼(in_game_tutorial_page)에 지도에 핀을 찍는 방법에 대한 안내가 없어, 사용자가 핀 기능을 인지하지 못한다.

## 🛠️ 해결 방안 / 제안 기능

- 인게임에서 길게 클릭(롱프레스) 시 시스템 기본 진동 피드백을 제공해 동작 인식을 명확히 한다.
- 인게임 튜토리얼에 지도 핀 찍는 법 안내 단계를 추가해, 사용자가 핀 기능과 사용 방법을 학습하도록 한다.

## ⚙️ 작업 내용

- 인게임 지도 롱프레스 시 시스템 기본 진동 피드백 연동
- 인게임 튜토리얼에 지도 핀 찍기 미션/안내 단계 추가
- 핀 찍기 안내 문구 다국어(i18n) 반영
