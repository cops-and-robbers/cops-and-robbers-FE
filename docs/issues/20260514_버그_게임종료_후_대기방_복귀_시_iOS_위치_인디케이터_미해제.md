## 제목

❗ [버그][게임][iOS] 게임 종료 후 대기방 복귀 시 iOS 위치 인디케이터 미해제

## 본문

## 🗒️ 설명

게임이 종료된 후 결과 다이얼로그에서 "한 번 더" 버튼을 눌러 대기방으로 복귀했을 때,
iOS 상태바의 파란색 위치 인디케이터(위치정보 공유 중)가 계속 표시된다.
대기방에서 앱을 백그라운드로 내려도 인디케이터가 유지되어, 위치 수집이 지속되는 것처럼 보인다.

위치 정보는 인게임 화면에서만 수집해야 하며, 게임 종료 후에는 즉시 해제되어야 한다.

## 🔄 재현 방법

1. 게임에 참가하여 게임이 진행 중인 상태로 대기한다
2. 게임이 종료된다 (시간 초과 또는 전원 체포)
3. 게임 종료 결과 다이얼로그가 표시된다
4. "한 번 더" 버튼을 눌러 대기방으로 이동한다
5. 대기방 화면에서 앱을 백그라운드로 내린다
6. iOS 상태바에 파란색 위치 인디케이터가 표시되는 것을 확인한다

## 📸 참고 자료

- iOS 상태바 상단에 위치 인디케이터(파란색 바, "위치정보 공유 중" 문구) 표시
- 홈으로 이동 시에도 동일하게 재현될 가능성 있음

## ✅ 예상 동작

- 게임 종료 후 결과 다이얼로그가 표시되는 시점부터 iOS 위치 수집이 중단되어야 한다
- 대기방 또는 홈으로 복귀한 이후 앱을 백그라운드로 내려도 위치 인디케이터가 표시되지 않아야 한다
