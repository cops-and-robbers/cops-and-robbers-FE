⚙️ [기능추가][Flutter][커뮤니티] 채팅 목록 실시간화 — 유저당 알림 채널·안 읽은 개수·방별 음소거

🔥 구현 기능
---

내 모임(채팅방 목록) 화면이 **켜져 있는 채로 갱신되게** 만들고, 안 읽은 개수와 방별 음소거를 붙입니다.

| 항목 | 지금 | 이 이슈 후 |
|---|---|---|
| 다른 방에 새 메시지 | 모름 | 그 자리에서 미리보기·개수 갱신 |
| 안 읽은 개수 | 없음 | 서버 값 + 소켓 이벤트로 +1 |
| 방별 음소거 | 로컬 상태(앱 껐다 켜면 초기화) | 서버 저장 |
| 목록 갱신 | 화면 복귀 시 재조회 4경로 | 불필요 |

📝 현재 문제점
---

> [!WARNING]
> 목록 화면에서는 어느 방도 구독하지 않아, 다른 방에 대화가 오간 것을 알 통로가 없습니다. 화면을 떠났다 돌아와야 보입니다.

채팅방 사이드바의 종 아이콘도 지금은 로컬 상태로만 동작합니다 — 서버에 보낼 곳이 없어 앱을 재시작하면 풀립니다.

백엔드 #182로 소켓 채널과 API가 모두 열렸습니다.

🛠️ 해결 방안 / 제안 기능
---

**① 유저당 알림 채널 구독**

```
/subscribe/user/{userId}/community/chat
```

목록 화면에서 방마다 구독하지 않고 **이 채널 하나만** 구독합니다. 방이 100개여도 구독은 1개입니다. 이벤트는 방 채널과 **같은 형식**이라 기존 파서를 그대로 씁니다.

**② 소켓 수명 재배치 (선행 작업)**

> [!IMPORTANT]
> 지금 앱은 소켓을 **채팅방에 들어갈 때 열고 나올 때 끊습니다**(`CommunityChatRepositoryImpl`). 개인 채널을 앱 수명 동안 유지하려면 연결을 여는 자리를 로그인 시점으로 옮기고, 방 나가기가 소켓 전체가 아니라 **방 구독만** 해제하도록 바꿔야 합니다. 이걸 먼저 하지 않으면 방에서 나올 때마다 개인 채널이 같이 죽습니다.

**③ 안 읽은 개수**

| 출처 | 역할 |
|---|---|
| `GET /chat/rooms`의 `unreadCount` | 기준선 |
| 소켓 이벤트 | 기준선에 +1 |
| `POST /{postId}/chat/read` | 읽은 위치 기록 → 개수 내려감 |

> [!IMPORTANT]
> +1 조건을 서버 집계와 맞춰야 합니다 — **`senderId`가 내 id가 아니고, `messageType`이 `SYSTEM`이 아닐 때만** 셉니다. 개인 채널은 발신자 본인에게도 오므로 `senderId` 판정이 빠지면 내가 보낼 때마다 내 배지가 오릅니다. `GAME_INVITE`는 셉니다.

> [!IMPORTANT]
> `POST /chat/read`를 부르지 않으면 로컬에서 0으로 만들어도 다음 조회에서 원래 숫자가 돌아옵니다.

**④ 중복 수신**

방 화면에 있는 동안 방 채널과 개인 채널이 같은 메시지를 두 번 보냅니다. UNSUBSCRIBE 하지 않고 **서버 발급 `id`로 거릅니다** — `community_chat_timeline.dart`의 `receive`가 이미 그렇게 동작합니다.

**⑤ 방별 음소거**

`PUT /api/community-posts/{postId}/chat/notification`. 현재 상태는 **멤버 목록 응답**(`GET /{postId}/chat/members`)의 `notificationEnabled`로 내려옵니다.

> [!TIP]
> 음소거는 푸시만 막습니다. 목록 갱신과 안 읽은 개수는 그대로 올라갑니다 (카카오톡과 같은 동작).

⚙️ 작업 내용
---

- 소켓 연결 시점을 방 진입 → 로그인으로 이동, 방 나가기가 방 구독만 해제하도록 변경
- 유저당 알림 채널 구독(CONNECT 직후·재연결마다) 및 목록 갱신 배선
- `ChatRoomResponse.unreadCount` 매핑, 목록 타일에 개수 표시
- 소켓 이벤트 +1 규칙(`senderId`·`SYSTEM` 제외) 구현
- `POST /chat/read` 호출 배선
- `CommunityChatMemberListResponse.notificationEnabled` 매핑 + 사이드바 종 아이콘 서버 연동
- 목록 복귀 시 재조회 4경로 정리

❓ 확인 필요
---

- **`POST /chat/read`를 언제 부를지** — 방 나갈 때 / 메시지가 화면에 보일 때마다.
- **음소거한 방의 개수 표시** — 카카오톡처럼 그대로 보여줄지, 흐리게 할지.
