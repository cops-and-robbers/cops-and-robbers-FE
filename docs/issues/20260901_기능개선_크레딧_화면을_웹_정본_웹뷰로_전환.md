# 🚀 [기능개선][크레딧] 앱 크레딧 화면을 웹 정본 + 임베드 웹뷰로 전환

> GitHub: https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/519

## 🔥 구현 기능

| 항목 | 내용 |
|---|---|
| 대상 | 크레딧 화면 `CreditsPage` (설정 > 앱 버전 5탭 히든 진입) |
| 현재 | 멤버·사진·기여자가 앱 네이티브에 하드코딩 |
| 요청 | 웹 정본(`/credits/embed`)을 웹뷰로 열도록 교체 |
| 효과 | 인원·기여 변경 시 앱 재배포·심사 없이 웹 배포만으로 갱신 |

<br>

## 📝 현재 문제점

- 개발 참여자 크레딧 화면(`CreditsPage`)이 앱 네이티브에 하드코딩돼 있다. 인원·기여도가 바뀔 때마다 앱 재배포·심사가 필요하다.
- 이용약관 등 법적 문서는 이미 같은 문제를 겪어 **웹 정본 + 앱 임베드 웹뷰(JS off)** 로 전환했다(DEC-0036, FE #481). 크레딧도 같은 패턴을 적용한다.

## 🛠️ 구현 방식 (확정)

웹 정본은 완료됐다(dongsim-web#82, PR dongsim-web#83). 화면은 단순 리스트가 아니라 게임 문법(밤 지도 + 역할색 핑 카드 + 발자국 + 기여 티어 별 마퀴)으로 재설계했고, 연출은 전부 CSS라 JS off 웹뷰에서 그대로 돈다.

앱 쪽은:

- `CreditsPage` 를 네이티브 구현에서 **웹뷰 구현으로 교체**한다. 라우트(`/mypage/credits`)·진입(설정 > 버전 5탭)·블러 페이드 전환은 그대로 둔다.
- URL 은 `https://copsandrobbers.app/credits/embed` **단일**이다. 화면에 문장이 거의 없어(이름·역할) 언어 분기를 두지 않는다. `LegalDoc` enum 은 건드리지 않고 `AppUrls` 에 주소만 추가한다.
- 웹뷰 골격은 `legal_document_page.dart` 의 검증된 방식(JS off, 메인 프레임만 실패 처리, 로딩·재시도)을 따르되, 크레딧에 맞게 둘이 다르다:
  - 배경·스피너·앱바가 **다크** (웹 화면이 밤 지도라 흰 배경이면 전환에서 번쩍인다)
  - 멤버 카드에 **소셜 링크**가 있다. 같은 호스트는 내부 진행, 그 외 https 는 `launchExternalUrl` 로 외부 브라우저에 위임한다 (legal 은 전부 차단)
- 네이티브 크레딧 구현(`features/credits` 의 카드·플립·마퀴 위젯, 상세 페이지, 멤버 데이터)과 `assets/credits/` 사진 13장을 제거한다. 앱 용량이 그만큼 줄어든다.

## 📌 참고

- 패턴 근거: DEC-0036(법적 문서 웹 정본+앱 임베드 웹뷰), ISS-0147(FE #481 전환 사례)
- 웹 정본: dongsim-web `content/credits/credits.json` (인원 변경은 이제 여기만 고친다). 앱 크레딧에 없던 마케팅 참여자도 웹 정본에서 합류했다
- 기존 크레딧 화면 이력: ISS-0062(신규 구현), ISS-0064(카드 리디자인+플립 애니메이션), ISS-0090(기여도 색상)
