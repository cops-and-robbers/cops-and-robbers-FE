# 🚀 [기능개선][커뮤니티][게임생성] 채팅방에서 게임 생성 시 모집글 모임 장소를 초기 위치로 사용

## 📝 현재 문제점

커뮤니티 모집글에 모임 장소를 지정했는데도, 해당 채팅방에서 게임을 만들면 구역 설정 지도가 **방을 만드는 사람의 현재 위치**에서 열린다. 모임 장소와 현재 위치가 다르면 이미 지정했던 장소를 지도에서 다시 찾아야 한다.

<br>

## 🛠️ 해결 방안 / 제안 기능

채팅방에서 게임 생성에 진입하면 **모집글에 저장된 위도·경도를 구역 설정의 초기 위치로 사용**한다. 역지오코딩된 주소를 다시 좌표로 변환할 필요 없이 저장된 좌표를 전달하면 된다. 이후에는 사용자가 지도를 움직여 게임 구역을 조정하고 확정한다.

| 진입·조작 | 기대 동작 |
|---|---|
| 모집글 채팅방 → 게임 생성 | 해당 모집글의 모임 장소에서 시작 |
| 홈 → 게임 생성 | 기존처럼 현재 위치에서 시작 |
| 생성 도중 뒤로가기·구역 재편집 | 사용자가 이미 설정한 구역 유지 |
| 내 위치 버튼 | 사용자가 요청했을 때 현재 위치로 이동 |

<br>

## 🔄 확인 시나리오

1. 현재 위치 A와 다른 장소 B를 선택해 모집글을 만든다.
2. 작성자 계정으로 해당 모집글 채팅방에 들어가 게임 생성을 누른다.
3. 첫 구역 설정 지도가 A에서 열리는 현상을 확인한다.
4. 개선 후에는 B에서 열리고, GPS 응답이 뒤늦게 와도 A로 덮어쓰지 않아야 한다.
