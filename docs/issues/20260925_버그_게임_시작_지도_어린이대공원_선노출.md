# ❗ [버그][인게임][지도] 게임 시작 시 어린이대공원이 먼저 표시된 뒤 현재 위치로 이동

## 🗒️ 설명

게임 시작으로 인게임 화면에 진입하면 지도가 **어린이대공원 부근을 먼저 보여준 뒤 현재 위치로 이동**한다. 실제 게임 장소와 무관한 지역이 잠깐 표시되고 카메라가 이동해, 잘못된 장소에서 게임이 시작되는 것처럼 보인다.

<br>

## 🔄 재현 방법

1. 어린이대공원과 다른 장소에서 위치 권한을 허용한 상태로 게임에 참가한다.
2. 대기방에서 게임을 시작해 인게임 지도를 연다.
3. 첫 지도에는 어린이대공원 부근이 나오고, 위치 조회가 끝난 뒤 현재 위치로 이동하는지 확인한다.

사용자 제보와 현재 코드 경로를 대조했다. 실기기에서의 표시 시간·발생 빈도·OS별 차이는 확인하지 않았다.

<br>

## ✅ 예상 동작 / 개선 방향

- 인게임 지도의 첫 표시부터 현재 위치 또는 해당 게임 구역을 보여준다. 위치를 준비하는 동안에는 로딩을 유지하는 방법도 가능하다.
- GPS 응답을 기다린다는 이유로 게임과 무관한 어린이대공원 좌표를 먼저 노출하지 않는다.
- 위치 조회 실패 시에도 사용할 초기 화면·게임 구역 폴백을 정하고, 사용자가 내 위치 버튼으로 재시도할 수 있도록 한다.
- 지도 표시를 위한 폴백 좌표를 실제 사용자 위치로 서버에 전송하지 않는다.
