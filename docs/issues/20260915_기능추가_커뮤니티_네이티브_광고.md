# ⚙️ [기능추가][커뮤니티][AdMob] 커뮤니티 목록 및 게시글 상세 네이티브 광고 추가

## 🗒️ 설명

기존 AdMob·UMP 동의·Remote Config 광고 게이트를 재사용해 커뮤니티 콘텐츠 흐름에 네이티브 광고 고급형을 추가한다.

광고는 현재 커뮤니티 모집글 카드와 같은 리스트형 디자인으로 표시하며, AdMob에서 허용한 이미지·동영상 미디어 유형을 모두 지원한다. 광고 로드 실패나 재고 없음은 콘텐츠 조회·댓글 작성·채팅방 참여를 막지 않는다.

<br>

## 🔥 구현 기능

| 화면 | 배치 |
|---|---|
| 전체 | 목록 맨 위 1개, 이후 실제 게시글 5개마다 1개 |
| 우리 동네 | 상단 광고 1개 + 기존 준비 중 안내 유지 |
| 내 모임 | 목록 맨 위 1개, 이후 실제 채팅방 5개마다 1개. 빈 목록도 상단 광고 + 기존 참여 중인 채팅방 없음 안내 유지 |
| 게시글 상세 | 댓글 영역 상단 1개. 댓글이 없어도 게시글 본문이 있으면 표시 |

> [!IMPORTANT]
> 검색·스크랩·커뮤니티 알림함에는 광고를 추가하지 않는다. `우리 동네`와 `내 모임`의 상단 광고는 콘텐츠 유무와 독립적으로 요청하며, 기존 준비 중·빈 목록 안내를 유지한다. 상세의 반응 버튼·채팅방 참여 버튼과 댓글 입력창도 그대로 유지한다.

<br>

## 🛠️ 해결 방안 / 제안 기능

- iOS 광고 단위 ID: `ca-app-pub-7675755123462739/9922385728`
- Android 광고 단위 ID: `ca-app-pub-7675755123462739/8609304058`
- 디버그·테스트 빌드는 Google 공식 네이티브 테스트 광고 단위 ID를 사용한다.
- 기존 `ads_enabled`를 전면광고와 네이티브 광고가 함께 사용하는 전역 광고 게이트로 유지한다.
- Android `NativeAdFactory`와 iOS `FLTNativeAdFactory`에 같은 리스트형 레이아웃을 등록한다.
- 광고 객체는 표시 자리별로 소유하고 화면 이탈·로드 실패 시 해제한다.
- 광고 항목은 서버 응답과 페이지 커서에 섞지 않고 화면에서만 조합해 누적 콘텐츠 5개 간격을 유지한다.
- 정렬 메뉴는 현재처럼 데이터 상태 분기 밖에 유지한다.

## 📌 참고

- 기존 전면광고와 게임 종료 흐름은 변경하지 않는다.
- 네이티브 광고 UI는 `CommunityPostCard`의 배경·모서리·그림자·타이포·목록 여백을 기준으로 맞춘다.
- Ad attribution과 AdChoices, 동영상 컨트롤은 가리거나 콘텐츠 UI로 위장하지 않는다.
- 새 광고 단위는 생성 직후 실제 광고 게재까지 최대 1시간이 걸릴 수 있으므로 개발 중에는 테스트 광고로 검증한다.
