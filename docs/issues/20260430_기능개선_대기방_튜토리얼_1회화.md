## 제목

🚀 [기능개선][Flutter][대기방] 대기방 튜토리얼을 팀과 무관하게 1회만 노출

## 본문

## 📝 현재 문제점

- 대기방 튜토리얼이 팀별 키(`tutorial_waiting_room_police`, `tutorial_waiting_room_robber`)로 분리되어 있어, 한 사용자가 경찰일 때 1번, 도둑으로 변경하면 또 1번, 총 최대 2번 노출됨.
- 동일한 사용자에게 거의 같은 안내를 반복해서 띄우는 것이 불필요하게 느껴짐.
- 1번 스텝 문구가 "도둑팀으로 이동할 수 있어요" / "경찰팀으로 이동할 수 있어요"로 팀에 종속되어 있어, 키를 통합하면 문구도 함께 정리해야 함.

## 🛠️ 해결 방안 / 제안 기능

- 팀 구분 없이 통합된 단일 키(`tutorial_waiting_room`)로 변경하여, 사용자가 대기방에서 어떤 팀으로 진입하든 튜토리얼을 1회만 노출.
- 1번 스텝(팀 변경 안내) 문구를 팀 중립으로 변경.
  - 변경 전: "이 버튼을 눌러 도둑팀(또는 경찰팀)으로 이동할 수 있어요"
  - 변경 후: "이 버튼을 눌러 다른 팀으로 이동할 수 있어요"
- 1번 스텝 타겟은 기존과 동일하게 반대 팀의 첫 빈 슬롯(`AddSlotCard`)을 가리킴.
- 반대 팀이 꽉 차서 빈 슬롯이 없으면 기존 동작과 동일하게 1번 스텝 스킵, 나머지 3스텝(초대 코드, 게임 설정, 준비 버튼)만 노출하고 완료 처리.
- 기존 팀별 키는 마이그레이션 처리 없이 코드에서 참조 제거. SharedPreferences에 남은 값은 동작에 영향 없음.

  - 팀 변경 리스너 주석 갱신 (단일 키 동작에 맞춰 정리)
- 회귀 테스트 시나리오

  - 신규 사용자가 도둑으로 입장 → 튜토리얼 1회 노출 → 경찰로 변경 시 재노출 안 됨 확인
  - 반대 팀 정원이 꽉 찬 상태로 입장 → 1번 스텝 스킵, 3스텝만 노출 후 완료 처리 확인
