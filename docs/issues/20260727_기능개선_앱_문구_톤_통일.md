# 🚀 [기능개선][i18n][문구] 다이얼로그·스낵바 문구 톤 통일 (UX 라이팅 가이드 적용)

## 📝 현재 문제점

- 다이얼로그, 스낵바 등 사용자에게 보이는 문구의 말투가 통일돼 있지 않다. '~습니다'체와 '~해요'체가 섞여 있어 같은 화면 흐름 안에서도 톤이 튄다
- 한국어 문구 643개 중 150개가 해요체·경어 기준에 어긋난다 (에러 안내 121건, 게임 화면·시스템 채팅 15건, 다이얼로그·스낵바 15건 등)
- '~하시겠습니까', '~하시겠어요' 같은 과도한 경어가 남아 있어 캐주얼한 게임 분위기와 맞지 않는다
- 다이얼로그 왼쪽 버튼이 '취소'로 돼 있어, 사용자가 진행 중이던 작업이 취소된다고 오해할 여지가 있다
- 문구 끝에 마침표를 찍지 않는 프로젝트 규칙을 어긴 항목이 3건 남아 있다

## 🛠️ 해결 방안 / 제안 기능

- docs/i18n/UX_WRITING.md 의 보이스톤 가이드를 기준으로 한국어 문구 톤을 통일한다
- 해요체와 캐주얼한 경어는 대상 전체에 적용한다
- 능동형 전환은 문장이 자연스러워지는 항목만 선별해서 적용한다
- 에러 안내는 긍정형 전환 대상에서 제외한다. 무엇이 실패했는지 알려주는 정보가 사라지면 오히려 사용자가 불편해지기 때문이다
- 다이얼로그 왼쪽 버튼 문구를 '닫기'로 통일하고, 도메인 용어집의 UI 공통 용어도 함께 맞춘다
- 사용자에게 보이는 문구만 대상으로 하고, 디버그 로그와 예외 원인 문자열은 그대로 둔다. 원인 추적이 어려워지면 안 되기 때문이다
