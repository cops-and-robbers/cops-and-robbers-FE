# 🚀 [기능개선][Flutter][약관] 법적 문서를 웹뷰로 전환하기

## 📝 현재 문제점

- 같은 문서가 앱 assets/legals 와 웹 두 곳에 있고 사람이 손으로 맞추고 있다. 한쪽만 고치면 조용히 어긋나는데 법적 문서라 위험하다
- 일본에 출시했는데 일본 사용자가 한국어 약관을 본다. 하드코딩 한국어는 iOS 심사 리젝 전례가 있다 (#446)
- 문구 하나 고치려면 앱을 다시 배포하고 심사를 받아야 한다. 약관은 시행일 전에 공지해야 하는 문서라 심사 기간이 그대로 위험이 된다
- 상단 링크 버튼이 2월에 임시로 만든 Google Sites 를 가리킨다. 지금은 공식 사이트에 같은 문서가 있어서 주소가 두 벌이다
- 문서 경로와 링크 주소를 호출부에서 따로 넘기고 있어, 짝이 어긋나도 아무도 못 잡는다

## 🛠️ 해결 방안 / 제안 기능

- 웹을 정본으로 삼는 작업이 웹 쪽에서 끝났다. 언어별 주소 12개가 이미 프로덕션에 있다 (dongsim-web #47, #49)
- LegalDocumentPage 의 본문을 웹뷰로 교체한다. 앱바는 그대로 두어 화면이 바뀐 티가 나지 않게 한다
- 웹 화면은 앱 렌더 코드를 그대로 재현해 두었다. 색, 타이포, 여백, 줄간격이 같고 기기 폭에 따른 배율도 맞췄다
- 문서를 enum 으로 받아 로케일에 따라 주소를 조립한다. 경로와 링크를 따로 넘기던 구조를 없앤다

## ⚙️ 작업 내용

- 웹뷰 패키지 추가, 본문을 그리던 코드 제거
- 문서 종류를 enum 으로 받도록 시그니처 변경, 로케일에 따라 ko / ja / en 주소 조립
- 로딩, 실패, 재시도 상태 처리
- 상단 링크 버튼과 externalUrl 파라미터 제거
- assets/legals 4종과 pubspec 등록 삭제
- AppUrls 의 법적 문서 4개 상수 삭제 (storeUrl 은 다른 곳에서 쓰이므로 유지)
- 번역되지 않았다는 고지 배너 삭제
- 호출부 5곳 정리 (로그인 3, 가입 동의, 설정)

## 📌 참고

- PR base 는 20260812_#470_v3_앱_전면_개편 이다. main 이 아니다
- 오프라인 열람은 받지 않기로 했다. 실시간 세션이라 네트워크가 없으면 게임 자체가 돌아가지 않고, 가입 동의 화면도 로그인 API 를 탄다. 오프라인에서 약관만 여는 경우는 설정 화면 하나뿐이다
- 낡은 번들을 폴백으로 남기지 않는 이유도 같다. 약관을 개정해서 웹만 고치면 번들은 구버전인데, 그 상태에서 네트워크가 끊기면 사용자가 시행일이 지난 옛 약관을 현재 약관으로 읽게 된다. 빈 화면보다 나쁘다
- 기기에 HTML 을 저장하는 캐시도 만들지 않는다. 두 번째부터 빨라지는 건 웹뷰 기본 캐시가 이미 해결하고, 폰트는 재검증 없이 캐시되도록 웹에서 처리했다. 파일 캐시의 순이득은 오프라인 하나인데 그것을 받지 않기로 했다
- 상단 링크 버튼을 없애는 것은 UI 변경이다. 웹뷰 화면에 떠 있는 것이 이미 원본이라 같은 문서를 두 번 여는 버튼이 되고, 남기면 문서마다 주소를 두 벌 관리해야 해서 없앤다. 주소를 손에 쥐여주는 기능이 필요해지면 링크가 아니라 공유 버튼이 맞는 형태다
- 우리 HTML 은 스크립트가 없어서 웹뷰에서 자바스크립트를 꺼도 된다. 법적 문서 뷰어에 스크립트 실행 권한을 주지 않는다
- App Store Connect 와 Play Console 의 개인정보처리방침 주소도 사람이 바꿔야 Google Sites 를 완전히 접을 수 있다. 코드 밖 작업이라 배포 전에 따로 처리한다
- 약관 버전 추적은 이 범위 밖이다. 지금은 동의 여부와 시각 하나만 저장하고 문서별 시행일이 서로 다른데, 개정했을 때 누가 구버전 동의자인지 가릴 수 없다. 백엔드 변경이 필요해서 별도 이슈로 다룬다
