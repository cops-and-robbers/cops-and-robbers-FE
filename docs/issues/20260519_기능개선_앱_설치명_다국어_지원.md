## 제목

🚀 [기능개선][i18n][Flutter] 앱 설치명 다국어 지원 (ko/en/ja)

## 본문

## 📝 현재 문제점

- Android `AndroidManifest.xml`에 `android:label="경찰과도둑"` 한국어로 하드코딩되어 있음
- iOS `Info.plist`의 `CFBundleDisplayName` 값도 "경찰과도둑"으로 하드코딩되어 있음
- 영문/일본어 OS를 사용하는 사용자도 홈 화면 아이콘에 한글 앱 이름이 노출됨
- 앱 내부 UI 텍스트는 ARB(`lib/l10n/app_*.arb`)로 이미 i18n 처리가 되어 있지만, 앱 설치명(OS가 앱 실행 전에 읽는 값)은 i18n 미적용 상태

## 🛠️ 해결 방안 / 제안 기능

- 네이티브 리소스 i18n 표준 방식 적용 (Android `strings.xml`, iOS `InfoPlist.strings`)
- 앱 설치명은 OS가 앱 실행 전에 읽는 값이라 ARB가 아닌 네이티브 리소스로만 처리 가능
- 로케일별 앱 설치명 정책 확정:
  - default (영어): Cops and Robbers
  - ko: 경찰과도둑
  - en: Cops and Robbers
  - ja: ケイドロ (일본에서 실제 사용하는 놀이 이름, ARB의 `appBrandName`과 일치)
- ARB의 `appBrandName` 정책과 일치시켜 브랜드 통일성 유지

## ⚙️ 작업 내용

Android:

- `android/app/src/main/res/values/strings.xml` 신규 (default: Cops and Robbers)
- `android/app/src/main/res/values-ko/strings.xml` 신규 (경찰과도둑)
- `android/app/src/main/res/values-ja/strings.xml` 신규 (ケイドロ)
- `android/app/src/main/AndroidManifest.xml`의 `android:label`을 `@string/app_name` 참조로 변경

iOS:

- `ios/Runner/Base.lproj/InfoPlist.strings` 신규 (Cops and Robbers)
- `ios/Runner/ko.lproj/InfoPlist.strings` 신규 (경찰과도둑)
- `ios/Runner/ja.lproj/InfoPlist.strings` 신규 (ケイドロ)
- `ios/Runner/Info.plist`의 `CFBundleDisplayName` fallback을 "Cops and Robbers"로 변경
- `ios/Runner/Info.plist`에 `CFBundleLocalizations` 배열 추가 (ko, en, ja)
- `ios/Runner.xcodeproj/project.pbxproj`의 `knownRegions`에 ko/ja 추가 및 `InfoPlist.strings` variant group 등록

검증:

- Android 에뮬레이터 OS 언어를 ko/en/ja/기타로 변경 후 앱 재설치하여 홈 화면 아이콘 이름 확인
- iOS 시뮬레이터 Settings → General → Language & Region 변경 후 재설치하여 홈 화면 이름 확인

영향 없는 영역 (변경 불필요):

- Dart 코드, ARB(`lib/l10n/app_*.arb`), `pubspec.yaml`, `.env`, `version.yml`, CI/CD 워크플로우, Firebase 설정 파일
