# 🚀 [기능개선][문서] 문서 디렉터리를 docs로 통합하고 참조 경로 정리

## 📝 현재 문제점

작업 문서가 저장소 루트의 숨김 폴더에 분산되어 있고, Superpowers 산출물도 `.superpowers/`와 `docs/superpowers/`로 나뉘어 있다. 문서를 `docs/`로 모으면서 스킬·커맨드가 사용하는 생성 경로와 기존 참조를 함께 갱신한다.

<br>

## 🛠️ 해결 방안 / 제안 기능

| 기존 경로 | 통합 경로 |
|---|---|
| `.issues/` | `docs/issues/` |
| `.pr/` | `docs/pr/` |
| `.report/` | `docs/report/` |
| `.release-note/` | `docs/release-note/` |
| `.superpowers/` | `docs/superpowers/`에 병합 |

Superpowers의 `specs/`, `plans/`, `brainstorm/`, `sdd/`를 한 폴더 아래에서 관리한다. 기존 Git 추적·제외 정책은 유지한다.

<br>

## 📌 참고

현재 로컬에서 문서 정리까지 완료했으며 커밋·push는 아직 수행하지 않았다. FE 변경과 브레인 볼트 참조 변경은 각 저장소에서 별도로 커밋한다.
