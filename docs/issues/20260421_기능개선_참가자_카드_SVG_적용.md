## 제목

🚀 [기능개선][디자인][대기방][게임방] 참가자 카드 디자이너 SVG 에셋 적용

## 본문

## 📝 현재 문제점

- 대기방과 게임방의 참가자 카드가 임시 이미지/기본 위젯으로 표시되고 있음
- 디자이너가 최종 확정한 캐릭터 SVG 에셋을 전달해 주었으나 아직 반영되지 않음
- 해상도 의존적인 PNG보다 SVG가 적합하다는 결론에 따라 에셋 포맷 통일 필요

## 🛠️ 해결 방안 / 제안 기능

- 대기방(`participant_card`)과 게임방에서 사용하는 참가자 카드의 캐릭터 이미지를 디자이너가 제공한 SVG로 교체
- 팀 테마(경찰/도둑)에 따라 다른 SVG가 있다면 `isDarkMode` 분기에 맞춰 각각 적용
- 기존 이미지 참조(assets 경로, 위젯 내부 이미지 컴포넌트)를 `SvgPicture` 기반으로 대체

## ⚙️ 작업 내용

- [ ] 디자이너로부터 전달받은 SVG 파일 `assets/` 하위 적절한 위치에 배치 (예: `assets/characters/`)
- [ ] `pubspec.yaml`에 에셋 경로 등록
- [ ] 대기방 참가자 카드(`lib/features/session/presentation/widgets/participant_card.dart`)에 SVG 적용
- [ ] 게임방에서 사용하는 참가자 카드/아바타 위젯에 동일 SVG 적용
- [ ] 팀 테마별(경찰/도둑) SVG 분기 처리 확인
- [ ] 기존에 사용하던 PNG/임시 이미지 에셋 정리
- [ ] 다양한 화면 크기에서 시각적 확인
