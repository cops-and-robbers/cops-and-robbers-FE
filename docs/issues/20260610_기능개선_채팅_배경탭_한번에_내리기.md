## 제목

🚀 [기능개선][채팅] 인게임 채팅 배경 탭 한 번으로 키보드+오버레이 동시 닫기 재도전

## 본문

## 📝 현재 문제점

- 인게임에서 채팅을 올린 뒤 다시 내릴 때 동작이 번거롭다.
- 키보드를 먼저 내리고, 그 다음 빈 공간이나 채팅 오버레이를 잡고 내려야 해서 두 단계로 조작해야 한다.
- 사용자는 배경(빈 공간)을 한 번 누르면 키보드와 채팅 오버레이가 한 번에 닫히길 기대한다.

## 🛠️ 해결 방안 / 제안 기능

- 인게임 채팅 영역 바깥(배경)을 탭하면 키보드 + 채팅 오버레이가 동시에 닫히도록 개선한다.
- 과거에 이 기능을 시도했을 때, 키보드 닫기를 처리하는 프로바이더(상태)의 변화가 의도치 않게 다른 다이얼로그까지 전파되어 문제가 발생한 이력이 있다. 이번에 재도전한다.
- 키보드/오버레이를 닫는 상태 전이가 채팅 영역에만 국한되고, 게임 내 다이얼로그 등 다른 위젯으로 전파되지 않도록 범위를 격리한다.

## ⚙️ 작업 내용

- 배경 탭 제스처로 키보드와 채팅 오버레이를 한 번에 닫는 동작 구현
- 닫기 상태 전이가 다이얼로그 등 외부로 전파되지 않도록 상태 범위 격리
- 채팅 열기/닫기, 다이얼로그 노출 등 상호작용 시나리오에서 의도치 않은 닫힘/충돌 없는지 검증

## 🔗 참고 이력

- 채팅 오버레이 포커스 복원 버그 이력 (showGeneralDialog 포커스 복원 → 시트 자동확장 버그, 과거 롤백 후 _userTapped 플래그로 해결한 사례) 참고
