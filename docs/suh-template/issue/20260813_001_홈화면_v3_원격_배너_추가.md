## 제목

⚙️[기능추가][홈화면] v3 원격 배너 추가

## 본문

## 📝 현재 문제점

- v3 홈 화면에 운영 중인 이벤트나 안내를 노출할 수 있는 배너 영역이 없음
- 배너 이미지와 이동 링크를 변경하려면 앱 배포 없이 운영에서 즉시 반영할 수 있어야 함
- 홈 화면 재진입마다 동일 이미지를 반복 다운로드하지 않도록 불필요한 네트워크 사용을 방지해야 함

## 🛠️ 해결 방안 / 제안 기능

- 방 만들기·참여하기 버튼 아래 16 간격에 v3 홈 배너 추가
- 배너는 홈 콘텐츠 좌우 여백에 맞는 전체 폭, 높이 68, 모서리 반경 12로 구성
- Firebase Remote Config로 배너 활성 여부, 이미지 주소, 이동 링크를 관리
- 앱 실행 중 Remote Config 변경사항이 게시되면 활성 여부와 이미지·링크를 반영
- 동일 이미지 주소는 앱 실행 중 캐시를 사용하고, 주소가 변경되면 새 이미지를 로드
- 이동 링크가 있을 때만 배너 탭으로 외부 페이지를 열고, 설정 누락이나 이미지 로드 실패 시 배너를 안전하게 숨김

## ⚙️ 작업 내용

- Remote Config 배너 설정 및 안전한 기본값 추가
- 홈 화면 v3 규격에 맞는 배너 UI 추가
- 실시간 설정 변경과 이미지 캐시 동작 연결
- 배너 노출·비노출, 크기, 링크 및 오류 상황 검증

## ✅ 완료 조건

- 비활성 상태에서는 배너와 전용 간격이 표시되지 않음
- 활성 상태에서는 지정된 v3 크기와 모서리 반경으로 이미지가 표시됨
- 앱 실행 중 Remote Config 변경사항이 반영됨
- 홈 재진입 시 동일 이미지를 불필요하게 다시 다운로드하지 않음
- 링크가 있을 때만 외부 페이지 이동이 동작함
- 잘못된 설정이나 이미지 로드 실패가 홈 화면 사용을 방해하지 않음
- 관련 테스트와 Flutter 정적 분석이 통과함
