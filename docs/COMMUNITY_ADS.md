# 광고 표시와 Remote Config

| Boolean 키 | 앱 기본값 | 범위 |
|---|---|---|
| `ads_enabled` | `false` | 모든 광고의 상위 스위치 |
| `community_ads_enabled` | `true` | 커뮤니티 목록·상세의 네이티브 광고 슬롯 |
| `game_end_ads_enabled` | `true` | 게임 종료 전면 광고 |

전역 스위치와 해당 하위 스위치가 모두 `true`여야 광고를 표시한다. 하위 키를 아직 게시하지 않은 경우에도 기존 전역 스위치 동작은 유지된다. 게임 종료 전면 광고는 사전 로드와 실제 표시 직전에 모두 스위치를 검사한다.

커뮤니티 광고 슬롯은 최초 프레임부터 광고와 같은 높이·여백을 확보한다. 기본 높이는 122이며 글자 확대 시 계산된 광고 높이를 사용한다.

- 로딩 중: 스켈레톤. 기기의 애니메이션 줄이기 설정을 따른다.
- 성공: 같은 크기 안에서 네이티브 광고로 교체한다.
- 초기화 실패·로드 실패·15초 무응답: 같은 크기의 ‘모집글 작성’ 앱 안내 카드로 교체한다. 광고 배지를 붙이지 않으며 기존 모집글 작성 경로로 이동한다.
- 슬롯 OFF: 광고와 스켈레톤·안내 카드·여백을 모두 제거한다. 운영 중 스위치를 변경하면 이 제거로 목록 위치는 바뀔 수 있다.

전체·우리 동네·내 모임은 상단 1개와 콘텐츠 5개마다 슬롯을 사용한다. 빈 목록에도 상단 슬롯과 기존 빈 상태 안내를 함께 표시한다. 상세는 댓글 영역의 단일 슬롯에 같은 상태 전환을 적용한다.
