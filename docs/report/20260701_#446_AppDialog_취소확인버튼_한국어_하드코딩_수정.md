# AppDialog 확인/취소 버튼 한국어 하드코딩 수정 (App Store Guideline 4 리젝 대응)

### 📌 작업 개요
영어 iPad에서 다이얼로그의 취소 버튼이 한국어 "취소"로 노출되어 App Store Guideline 4(Design) 리젝. 공용 다이얼로그 컴포넌트 AppDialog의 확인/취소 버튼 기본값이 한국어로 하드코딩된 것이 원인. 기본값을 제거하고 AppLocalizations로 대체하여 기기 언어를 따르도록 수정.

### 🔍 문제 분석
`AppDialog.confirm` / `AppDialog.show` / AppDialog 위젯 생성자의 confirmText·cancelText 기본값이 각각 '확인' / '취소'로 하드코딩됨. 호출부가 이 파라미터를 생략하면 기기 언어와 무관하게 한국어가 그대로 렌더링됨.

- 노출 지점: 대기방 나가기 다이얼로그(cancelText 생략), 설정 로그아웃·튜토리얼 초기화 다이얼로그
- 리뷰어 문구는 "permission requests 언어 불일치"였으나, iOS 네이티브 권한 문구(Info.plist)는 이미 영어로 정상. 실제 결함은 Flutter 다이얼로그의 하드코딩 기본값
- 전수 스윕 결과, 릴리즈 빌드에서 사용자에게 노출되는 하드코딩 한국어는 AppDialog가 유일. 예외 message는 ErrorMessageMapper로 l10n 변환되어 미노출, 데드코드·디버그 전용 화면은 릴리즈 미도달

### ✅ 구현 내용

#### AppDialog 버튼 기본값 l10n 적용
- **파일**: `lib/core/widgets/dialogs/app_dialog.dart`
- **변경 내용**: confirmText·cancelText의 하드코딩 기본값('확인'/'취소') 제거 → `String?`로 변경. `.show`·`.confirm`에서 `?? l10n.buttonConfirm` / `?? l10n.buttonCancel`로 resolve. 위젯 confirmText는 `required`로 변경하여 하드코딩 기본값 원천 차단
- **이유**: 기본값을 한 지점(공용 컴포넌트)에서 l10n으로 처리하면 호출부 30여 곳을 수정하지 않아도 모두 기기 언어를 따름

#### 회귀 테스트 추가
- **파일**: `test/core/widgets/dialogs/app_dialog_cancel_l10n_test.dart`
- **변경 내용**: 영어/한국어 로케일에서 cancelText·confirmText 생략 시 버튼 문구가 현지화되는지 검증하는 위젯 테스트 3종 추가
- **이유**: 리젝 시나리오(영어 기기 + cancelText 생략 → "Cancel", "취소" 아님)를 재현·고정하여 재발 방지

### 🔧 주요 변경사항 상세

#### app_dialog.dart
- AppLocalizations import 추가
- `.show`: confirmText `String? `로 변경, 빌더에서 `confirmText ?? l10n.buttonConfirm` 적용. cancelText는 nullable 유지(1버튼/2버튼 시맨틱 보존)
- `.confirm`: confirmText·cancelText 모두 nullable로 변경, 빌더에서 각각 `?? l10n.buttonConfirm`·`?? l10n.buttonCancel` 적용
- 위젯 생성자: confirmText를 required로 변경

**특이사항**:
- `cancelText == null → 1버튼(확인만)`, `!= null → 2버튼(취소+확인)` 시맨틱을 그대로 보존. `.confirm`은 항상 2버튼이므로 cancelText를 l10n으로 강제 주입, `.show`는 null 의미(취소 버튼 없음)를 유지
- ARB에 buttonConfirm·buttonCancel이 이미 존재하여 ARB 변경·gen-l10n 불필요

### 🧪 테스트 및 검증
- `flutter analyze`: 무이슈 (기존 info 린트 5건은 무관)
- 신규 회귀 테스트 3종 통과

  - 한국어 로케일 + cancelText 생략 → "취소" 노출
  - 영어 로케일 + confirmText 생략 → "Confirm" 노출, "확인" 아님
