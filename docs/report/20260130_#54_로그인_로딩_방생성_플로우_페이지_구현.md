## 📋 작업 개요

### 문제 정의
공통 컴포넌트는 구현되었으나, 로그인/로딩/방 생성 플로우 페이지들이 아직 구성되지 않은 상태였습니다.

### 해결 방안
Figma 디자인을 기반으로 다음 페이지들을 구현했습니다:
- 로그인 페이지 (Google 소셜 로그인)
- 로딩 페이지 (앱 초기화)
- 방 생성 플로우 페이지들 (닉네임 설정, 구역 선택, 게임 설정 등)

**주요 파일**:

**저장 데이터**:

**API**:
```dart
// 저장
await SessionDraftStorageService().updateNickname(nickname);
await SessionDraftStorageService().updatePlaygroundZone(center, radius);

// 불러오기
final draft = await SessionDraftStorageService().loadDraft();

// 초기화
await SessionDraftStorageService().clearDraft();
```
