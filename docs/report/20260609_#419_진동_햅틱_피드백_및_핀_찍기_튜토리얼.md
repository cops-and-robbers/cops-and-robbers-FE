# 진동 햅틱 피드백 확장 및 지도 핀 찍기 튜토리얼 (#419)

### 📌 작업 개요

인게임 햅틱 피드백을 확장하고, 인게임 튜토리얼에 "핀 찍는 법" 미션을 추가. 이어서 앱 전역의 버튼 탭 햅틱을 공통 버튼 위젯에 중앙화하여 일관성을 확보.

4개 커밋으로 단계 진행:
1. `9011a9b` 인게임 롱프레스·액션 버튼 진동 피드백 추가
2. `7b60d90` 지도 핀 찍기 튜토리얼 안내 추가
3. `96c3113` 핑 마커 크기 ScreenUtil 반응형 처리
4. `2725ab0` 공통 버튼 탭 햅틱 중앙화

핵심 설계: OS 네이티브 `HapticFeedback`(시스템 기본 진동)을 사용. 롱프레스는 medium, 일반 버튼 탭은 light로 강도를 구분.

---

### ✅ 구현 내용

#### 1. 인게임 진동 피드백 (`9011a9b`)

- **파일**: `lib/core/services/vibration_service.dart`, `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `VibrationService.longPress()` 추가(= `HapticFeedback.mediumImpact()`). 게임 맵 롱프레스(`_onMapLongPress`) 인식 즉시 1회 발동. 인게임 액션 버튼(내 위치·참가자·다시 지도·QR)에 탭 햅틱 부여.
- **이유**: 핀(핑) 찍기 같은 의도적 제스처와 일반 탭의 촉각을 구분해 조작 확신을 높임. `vibration` 패키지의 커스텀 패턴이 아닌 OS 네이티브 햅틱을 써서 "시스템 기본" 요구에 부합.

> 참고: 이 커밋의 4개 버튼 탭 햅틱은 이후 커밋 4(중앙화)에서 공통 위젯 내장으로 대체됨.

#### 2. 지도 핀 찍기 튜토리얼 미션 (`7b60d90`)

- **파일**: `lib/features/tutorial/presentation/pages/in_game_tutorial_page.dart`, `lib/l10n/app_{ko,en,ja}.arb` + 생성물, `test/features/tutorial/presentation/pages/in_game_tutorial_page_test.dart`(신규)
- **변경 내용**: 기존 3개 미션(QR→참가자→지도복귀) 뒤에 "핀 찍기"(4번째) 추가. 지도 placeholder 롱프레스 → 실제 `PingSelectionCard`(발견/의심) 오버레이 → 선택 시 그 자리에 마커 표시 → 미션 완료. step 3 동안 "맵 아무 곳이나 길게 눌러보세요" 펄스 힌트 노출.
- **이유**: 실제 게임의 핀 메커닉을 동일 위젯(`PingSelectionCard`) 재사용으로 "실전 재현". 학습 효과 + 코드 중복 회피.

#### 3. 핑 마커 반응형 (`96c3113`)

- **파일**: `lib/features/game/presentation/widgets/ping_marker_factory.dart`
- **변경 내용**: 마커 크기 고정값 `24.0` → ScreenUtil `24.w`로 변경.
- **이유**: 실 게임 마커(비트맵)와 튜토리얼 마커(위젯) 크기를 모든 기기 폭에서 동일하게 맞춤. 위젯이 아닌 비트맵 렌더 컨텍스트지만 ScreenUtil `.w`는 전역 싱글턴이라 동작.

#### 4. 공통 버튼 탭 햅틱 중앙화 (`2725ab0`)

- **파일**: `app_button.dart`, `previous_button.dart`, `svg_icon_button.dart`, `flat_icon_button.dart`, `zone_setting_button.dart`, `app_dialog.dart`, `home_page.dart`, `session_creation_flow_page.dart`, `waiting_room_page.dart`, `game_page.dart`, `in_game_tutorial_page.dart` (11개)
- **변경 내용**: 공통 버튼 위젯 5종에 탭 햅틱을 내장(활성 상태에서만 발동). 화면별로 흩어져 있던 수동 호출 6곳 제거.
- **이유**: 탭 햅틱이 호출처마다 수동으로 들어가 화면별 누락이 발생. 공통 위젯에 1회 내장으로 앱 전체 버튼이 일관된 피드백을 갖도록 통일.

### 🔧 주요 변경사항 상세

#### 햅틱 강도 정책

- **롱프레스(핀 찍기)**: `HapticFeedback.mediumImpact()` — 의도적 제스처
- **버튼 탭**: `HapticFeedback.lightImpact()` — 가벼운 확인
- 게임 이벤트(체포/탈옥/위치공개/이탈/종료)는 기존 `vibration` 패키지 패턴 유지(이번 작업 범위 밖)

#### 중앙화 구조

- 내장 대상: `AppButton`(19개 화면), `PreviousButton`(18개 화면 뒤로가기), `SvgIconButton`, `FlatIconButton`, `ZoneSettingButton`
- `MyLocationButton`은 내부에서 `SvgIconButton`을 사용하므로 별도 수정 없이 자동 커버
- 게이팅: `AppButton`은 로딩/비활성(`onPressed == null`) 시 미발동하도록 처리
- 부수 효과: 그동안 햅틱이 없던 로그인·동의·닉네임·설정 화면들과 `AppDialog` 취소 버튼도 자동으로 탭 피드백을 받게 됨

**특이사항**:
- 중복 진동 방지를 위해 공통 위젯을 타는 수동 호출(`app_dialog` ×2, `home`, `session_creation`, `waiting_room` ×2, `game_page` ×4)을 제거. 커스텀 제스처(채팅 전송/알림 토글, 초대코드 복사, 코드 카드, 튜토리얼 핀 선택)는 공통 버튼이 아니라 그대로 유지.
- 튜토리얼은 미션 진행 햅틱이 SvgIconButton 미션(위젯 내장)과 핀 선택(`PingSelectionCard`, 공통 버튼 아님) 양쪽에서 쓰이므로, `_tryAdvanceMission`에서 빼고 `_onTutorialSelectPing`으로 옮겨 핀 선택 피드백을 보존.

#### 튜토리얼 오버레이 배치

- 핀 선택 카드·배치 마커는 `_buildMapMode` 최상위 `Stack`에 추가(placeholder 내부에 `Positioned`를 넣으면 `ParentDataWidget` 에러). 실 게임 구조를 그대로 미러링.
- 배치 마커는 실 게임과 동일하게 24×24 center anchor(`FractionalTranslation(-0.5, -0.5)`).

#### i18n

- 신규 키: `tutorialMissionDropPing`(미션 안내), `tutorialPingLongPressHint`(힌트 배지)
- 수정: `tutorialMissionProgress` 진행도 `/3` → `/4` (ko/en/ja)
- ARB 수정 후 `flutter gen-l10n` 재생성

### 📌 참고사항

- **진동 on/off 사용자 설정 부재**: 현재 `VibrationService`는 기기 지원 여부(`_hasVibrator`)만 게이팅하고 사용자 선호 토글은 없음. 중앙화로 거의 모든 버튼이 진동하게 됐으므로, 설정 화면에 전역 on/off 토글(영속 저장) 추가가 후속 과제로 의미 있음.
- **추가 가능한 게임 이벤트 햅틱**(미반영, 후속 후보): 경찰 이동 시작(POLICE_MOVE_START), 강퇴(KICKED), 입퇴장(`playerJoinLeave()`는 정의돼 있으나 미연결), 거부/실패 피드백(핀 쿨다운·체포 불가·QR 실패 등).
