### 📌 작업 개요
바텀 네비게이션 골격(별도 보고서 `20260812_#472_바텀_네비게이션_추가.md`) 위에 실제 콘텐츠를 채운 후속 작업. 홈 화면을 새 디자인으로 리뉴얼하고, 준비중 placeholder였던 마이페이지 탭에 기존 설정 화면을 이관해 프로필 아이콘 선택 기능을 붙였다.

### 🎯 구현 목표
- 홈 화면 리뉴얼: 고정 헤더 + 프로필 카드 + 일러스트 카드 + 게임 생성/참여 버튼
- 설정 화면을 마이페이지 탭으로 이관 (독립 화면 → 탭 루트 화면)
- 프로필 아이콘 선택 기능 (마이페이지에서 선택 → 홈에 즉시 반영, 앱 재시작 후에도 유지)
- 흩어져 있던 `BoxShadow` 인라인 정의를 공용 상수로 통합

### 🔧 주요 변경사항 상세

#### 프로필 아이콘 provider
`build()`가 동기 함수라 `SharedPreferences`(비동기)를 직접 읽을 수 없어, 첫 프레임은 기본값(id=1)으로 반환하고 `Future.microtask`로 저장값을 읽어 다음 프레임에 덮어쓴다.

**특이사항**:
- 저장된 id가 현재 에셋 목록(`kProfileIconIds`)에 없으면 무시하고 기본값 유지 + 저장값 제거 — 향후 아이콘 에셋이 교체·제거돼도 깨진 경로를 렌더링하지 않는다
- `select()`도 알 수 없는 id는 무시. 두 방향 모두 테스트로 커버

#### 홈 일러스트 카드
배경 이미지가 카드 크기를 정하고, 그 위에 말풍선(상단)과 경찰·도둑 캐릭터 쌍(하단)을 `Stack`으로 얹는 구조.

**특이사항**:
- `BoxDecoration`의 `borderRadius`만으로는 배경 이미지 모서리가 라운드로 잘리지 않아(실기 확인 결과 직각 렌더) `ClipRRect`로 명시적으로 감쌌다
- 경찰·도둑을 각각 배치하던 방식 대신 겹침·정렬이 확정된 단일 에셋(`assets/characters/home/default.svg`)으로 교체
- 튜토리얼 코치마크는 두 버튼을 하나의 영역으로 하이라이트하도록 `Row`에 단일 `GlobalKey`를 부여

#### 바텀 네비게이션 바 하단 인셋 재조정
`SafeArea` 대신 `MediaQuery.viewPaddingOf(context).bottom`에서 18을 덜어낸 값만큼만 하단 패딩을 준다. 바 높이는 92 → 84로 축소.

**특이사항**:
- `SafeArea`는 홈 인디케이터 인셋을 전부 더해 실기에서 바가 과하게 두꺼워졌다. 디자인 높이를 맞추려면 인셋 일부만 반영해야 해 직접 계산으로 전환 (음수 방지 `clamp` 포함)

#### 라우팅 정리
`/home/settings`와 `/home/settings/credits` 라우트를 제거하고 `RoutePaths`에서도 삭제. 크레딧 페이지(앱 버전 5탭 이스터에그)는 라우트 없이 마이페이지 내부에서 `Navigator.push`로 진입한다.

**특이사항**:
- `MainScaffold`를 `buildInstantTransition`으로 감싸 탭 전환 시 셸 자체에 전환 애니메이션이 걸리지 않게 했다
- 홈 라우트도 `buildSmoothFade` → 기본 `builder`로 변경 (탭 브랜치 루트라 페이드가 중복 적용됨)
