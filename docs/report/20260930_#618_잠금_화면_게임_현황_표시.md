### 📌 작업 개요
게임 중 폰을 잠그거나 다른 앱을 써도 **잠금 화면에서 게임 현황**(남은 게임 시간 · 남은 도둑 `N/M` · 다음 위치 공개)을 보도록 추가. Android는 게임 진행 FGS 알림을 채워 Android 16+ Live Updates로 승격하고, iOS는 16.2+ Live Activity(잠금 화면 + 다이내믹 아일랜드)를 새로 띄운다.

**보고서 파일**: `docs/report/20260930_#618_잠금_화면_게임_현황_표시.md`

### 🎯 구현 목표
- 게임 화면 상단 타이머·참가자 목록 "도주 중" 수·위치 공개 카운트다운과 **같은 값**을 잠금 화면에 표시
- 값은 전부 앱이 인게임에서 계산하고, 초 단위 카운트다운은 OS가 그린다. **서버 푸시 없음**
- 잠금 화면 현황 때문에 **추가 네트워크 호출을 만들지 않음**
- 사용자가 표시를 닫으면 그 게임 동안 다시 띄우지 않음
- 팀별 테마: 경찰 = 밝은 배경·파랑·Pretendard·고양이 캐릭터 / 도둑 = 어두운 배경·초록·Moneygraphy·쥐 캐릭터

### 🔧 주요 변경사항 상세

#### 최신 값 보관 계약 (`MethodChannelBackgroundService`)
`update`는 실행 여부와 관계없이 마지막 값을 보관한다. 실행 중이면 바로 보내고, 아니면 보관만 한다. `start`가 네이티브 호출까지 성공하면 보관 값을 한 번 보낸다. `stop`은 실행 중이 아니어도 보관 값을 비운다.

**특이사항**:
- 컨트롤러는 게임 화면 첫 빌드부터 값을 내지만 서비스 시작은 비동기 초기화 뒤다. 이 계약이 없으면 먼저 온 값이 버려지고, "같은 값 재전송 안 함" 때문에 표시가 영영 비어 있을 수 있다
- `start` 실패 시 실행 상태만 롤백하고 보관 값은 다음 `start` 성공 때 보낸다
- `update` 실패는 로그만 남긴다. 표시 실패가 게임 진행을 막지 않는다

#### Android 알림 (`GameSessionNotification`)
- 승격 여부(`canPostPromotedNotifications`)로 동작을 가르지 않는다. Android 15 이하나 승격 불가 환경에서는 같은 내용이 일반 알림으로 보인다
- `shortCriticalText`를 쓰지 않아 상단바 칩에는 남은 게임 시간 카운트다운이 나온다
- 제목은 Dart가 넘긴 앱 언어 제목을 우선하고, 첫 알림(현황 도착 전)만 리소스 문자열을 쓴다
- Live Updates는 colorized·커스텀 레이아웃을 금지하므로 팀 테마는 강조색·sub text·large icon까지만 적용
- **사용자가 닫으면 이번 게임 동안 재게시하지 않는다**(가이드: 닫힌 Live Update 재게시 시 승격 권한을 잃을 수 있음). `setDeleteIntent` → 닫힘 표시. FGS·wakelock·위치 추적은 그대로 돈다
- 닫힘 표시와 보관 값은 `stop`·`onDestroy`에서 비우고, 늦게 도착한 닫힘 브로드캐스트에 대비해 다음 게임 서비스 `onCreate`에서 한 번 더 끈다
- `androidx.core:core:1.17.0` 직접 선언. `setRequestPromotedOngoing`은 1.17.0부터 있다. `POST_PROMOTED_NOTIFICATIONS`는 런타임 요청이 없는 권한

#### iOS Activity 매니저 (`GameStatusActivityManager`)
- **생성은 포그라운드에서만 된다.** 위치 백그라운드 모드로 앱이 살아 있어도 `Activity.request`는 백그라운드에서 실패한다. 실패하면 "생성 대기"로 두고 `didBecomeActive`에서 보관한 최신 값으로 다시 만든다. 갱신·종료는 백그라운드에서도 된다
- **사용자가 닫으면 이번 게임 동안 다시 만들지 않는다.** `activityStateUpdates`에서 앱이 끝내지 않은 종료를 받으면 닫힘 표시를 켠다. `stop`은 활성 ID를 먼저 비워 앱 종료가 사용자 닫힘으로 기록되지 않게 한다
- `staleDate = endAt`. 앱이 강제 종료돼 `stop`이 오지 않으면 종료 시각 뒤 모든 뷰가 도둑 수·공개 줄을 숨기고 "게임 종료"만 보인다
- 앱 실행 시(`didFinishLaunching`) 남아 있는 Activity를 모두 종료해 이전 게임 표시를 정리한다
- 사용자가 설정에서 Live Activity를 끈 경우(`areActivitiesEnabled == false`) 조용히 건너뛴다

#### iOS 뷰 (`GameStatusCard`·`GameStatusLiveActivity`)
- 잠금 화면 카드: 언어별 앱 아이콘·앱 이름·팀 배지 / 큰 남은 시간 카운트다운 / 남은 도둑·위치 공개 / 팀 캐릭터 / 진행 막대(`ProgressView(timerInterval:)`)
- 카드는 ActivityKit에 기대지 않는 순수 SwiftUI(`GameStatusCard`)로 분리해 맥에서 렌더링해 확인
- 다이내믹 아일랜드: 펼침은 캐릭터·남은 시간·도둑/공개·진행 막대, compact는 캐릭터 + 남은 시간, minimal은 캐릭터. 배경은 항상 검정이라 강조색만 팀을 따른다
- 캐릭터는 온보딩 일러스트(경찰 고양이·도둑 쥐)를 **좌우반전**해 카드 오른쪽에서 안쪽(왼쪽)을 보도록 했다. 확장 기능 에셋 SVG를 반전했고 Android 알림 큰 이미지 PNG도 같은 SVG에서 만들었다. 온보딩 원본은 그대로
- 확장 기능 버전은 `LiveActivity.xcconfig`가 `Flutter/Generated.xcconfig`를 포함해 본 앱과 같게 맞춘다(다르면 App Store 검증 거절)
- 폰트는 Pretendard-SemiBold·Moneygraphy만 확장 기능에 넣어 용량 증가를 줄였다

#### 문구 (ARB)
- `lockScreenRemainingTime`·`lockScreenRemainingRobbers`·`lockScreenRevealAt`·`lockScreenLocationReveal`·`lockScreenGameOver`를 ko/en/ja에 추가. 팀 라벨·"남은 도둑" 라벨은 기존 키 재사용

- 잠금 화면에 팀이 드러나는 것은 팀별 테마 결정에 따른 의도된 동작. 내 역할·수감 상태는 표시하지 않는다
- 이슈 본문의 "경찰 대기 중엔 경찰 출발" 표기와 달리, 게임 화면과 같게 대기 중에도 첫 위치 공개까지 카운트다운한다
