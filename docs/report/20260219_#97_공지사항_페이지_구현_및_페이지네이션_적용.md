### 📌 작업 개요

홈 화면의 공지사항 아이콘 버튼에 연결된 페이지가 없던 문제를 해결.
공지사항 목록 페이지를 아코디언(펼침/접기) 형태로 구현하고,
하단에 슬라이딩 윈도우 방식의 페이지네이션 바를 적용.

### 🎯 구현 목표

- 공지사항 목록 페이지 UI 구현 (아코디언 형태)
- 페이지네이션 바 공용 위젯 구현
- 홈 화면 공지사항 버튼 → 공지사항 페이지 네비게이션 연결
- 라우터 경로 등록

### ✅ 구현 내용

#### 1. 공지사항 페이지 (NoticesPage) 신규 생성
- **파일**: `lib/features/notice/presentation/pages/notices_page.dart`
- **변경 내용**: 공지사항 목록을 아코디언 형태로 표시하는 `StatefulWidget` 구현
- **주요 기능**:
  - 제목 탭 시 내용 펼침/접기 (한 번에 하나만 펼침)
  - 페이지당 10개 공지사항 표시
  - 날짜 `yyyy.MM.dd` 형식 표시
  - 현재 더미 데이터 사용 (API 연동 시 대체 예정)

#### 2. 페이지네이션 바 (PaginationBar) 공용 위젯 신규 생성
- **파일**: `lib/core/widgets/pagination_bar.dart`
- **변경 내용**: 슬라이딩 윈도우 방식 페이지네이션 바 위젯 구현
- **페이지 번호 표시 로직**:
  - 첫 페이지: `1 2 3 ... n` (첫 3개 + 생략 + 마지막)
  - 마지막 페이지: `1 ... n-2 n-1 n` (첫 + 생략 + 마지막 3개)
  - 중간 페이지: `... prev curr next ...` (현재 ±1 슬라이딩 윈도우)
  - 4페이지 이하: 전체 표시
- **화살표 버튼**: 첫/마지막 페이지에서 완전히 숨김 (조건부 렌더링)
- **선택 원**: 24x24 크기, `AppColors.black100` 배경

#### 3. 홈 화면 네비게이션 연결
- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: 공지사항 아이콘 버튼의 `TODO` 주석을 실제 네비게이션(`context.push(RoutePaths.notices)`)으로 교체

#### 4. 라우터 경로 등록
- **파일**: `lib/router/app_router.dart`
- **변경 내용**: `/home/notices` 경로에 `NoticesPage` 등록, 오른쪽 슬라이드 전환 애니메이션 적용

- **파일**: `lib/router/route_paths.dart`
- **변경 내용**: `notices` 경로 상수 및 `noticesName` 라우트 이름 추가

### 🔧 주요 변경사항 상세

#### PaginationBar - 슬라이딩 윈도우 방식

페이지네이션 로직을 3가지 케이스로 분리하여 구현:

1. **첫 페이지** (`currentPage == 0`): 첫 3개 페이지 + `...` + 마지막 페이지
2. **마지막 페이지** (`currentPage == totalPages - 1`): 첫 페이지 + `...` + 마지막 3개 페이지
3. **중간 페이지**: 현재 페이지 ±1 범위만 표시, 양쪽에 `...`

**특이사항**:
- `PaginationBar`는 `core/widgets/`에 배치하여 다른 기능에서도 재사용 가능
- 0-based 인덱스를 내부적으로 사용하고, 표시는 1-based로 변환
- 화살표 버튼은 `Opacity` 대신 `if` 조건부 렌더링으로 불필요한 위젯 트리 제거

#### NoticesPage - 아코디언 UI

`_expandedIndex` 상태값으로 현재 펼쳐진 공지사항을 관리. 같은 항목 탭 시 접기, 다른 항목 탭 시 전환. 페이지 변경 시 펼침 상태 초기화.

**특이사항**:
- 현재 더미 데이터 100개 사용 (API 엔드포인트 완성 후 연동 예정)
- `_NoticeItem` private 클래스는 API 연동 시 `NoticeEntity`로 대체 예정
