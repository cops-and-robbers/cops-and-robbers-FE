# 인게임 지도 초기 위치 개선

## 작업 개요

게임 시작 시 어린이대공원 부근을 먼저 표시하던 #606의 초기 카메라 경로를 수정했다. GPS 좌표 또는 해당 게임 구역 중심 중 먼저 준비된 위치에서 지도를 생성한다.

## 원인

`GoogleMapView`가 고정 기본 좌표(`37.5480, 127.0810`)로 네이티브 지도를 생성한 다음, `onMapCreated`에서 GPS를 조회하고 카메라를 이동했다. 따라서 GPS가 정상적으로 응답해도 서로 다른 장소가 차례로 표시됐다.

## 변경 내용

| 파일 | 변경 |
|---|---|
| `lib/features/game/presentation/pages/game_page.dart` | 게임 구역 중심을 지도에 전달하고, 초기 내 위치 버튼을 미선택 상태로 표시 |
| `lib/features/game/presentation/widgets/google_map_view.dart` | 초기 좌표가 준비되면 지도 생성, 늦은 초기 GPS 응답 무시, 명시적 내 위치 요청은 지도 준비 후 적용 |
| `test/features/game/presentation/widgets/google_map_initial_camera_test.dart` | GPS 응답 순서·실패·화면 종료·네이티브 생성 지연 회귀 테스트 추가 |
| `test/features/game/presentation/pages/game_page_auto_escape_test.dart` | 실제 게임 화면에서 지연된 원형·폴리곤 구역의 중심·경계·최소 줌·오버레이 검증 |

### 초기 위치 선택과 내 위치 이동

- GPS와 게임 구역 모두 준비되지 않았으면 로딩을 표시한다.
- 게임 구역이 먼저 도착하면 해당 중심에서 시작한다. 늦은 초기 GPS가 화면이나 사용자 지도 조작을 덮어쓰지 않는다.
- 내 위치 버튼으로 재시도할 수 있다. 이 요청은 초기 GPS 응답보다 우선하며, 네이티브 지도 생성 도중 성공한 요청도 지도 준비 후 적용한다.
- `GoogleMapViewState`를 유지해 지도 생성 전 수신한 구역 경계·카메라 제한·오버레이를 보존한다.
- 서버 위치 전송 경로와 공용 위치 서비스는 변경하지 않았다.

## 검증

- 수정 전 회귀 테스트에서 좌표 준비 전에 기본 좌표로 지도가 생성되는 실패를 확인했다.
- 추가 검토에서 네이티브 지도 생성 도중 내 위치 요청이 유실되는 실패를 재현하고 수정했다.
- 관련 테스트 **46개 통과**: 지도 초기화 10개 + 게임 화면 36개.
- `flutter analyze --no-pub`: **No issues found**.
- 전체 테스트: **1,315개 통과 / 6개 실패**. 실패는 모두 미수정 `community_page_test.dart`의 정렬 시트 하단 37px overflow다. 기준 커밋 `f09501426bc852ef19f3fd9d9ac869da2672be43`을 별도 임시 디렉터리에 추출해 해당 파일을 실행했고, **19개 통과 / 동일한 6개 실패**로 기존 문제임을 확인했다.
- `git diff --check` 통과.

실행 명령:


## 남은 확인

- Android/iOS 실기기에서 실제 지도 타일의 첫 표시, GPS 지연·권한 거부, 내 위치 버튼을 확인해야 한다. 이번 검증은 위젯 테스트의 플랫폼 경계를 대체해 수행했다.
- GPS와 게임 구역 조회가 모두 실패하면 지도는 로딩 상태를 유지한다. 내 위치 버튼의 성공 응답으로 지도를 표시할 수 있다.
