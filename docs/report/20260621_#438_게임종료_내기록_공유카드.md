### 📌 작업 개요

게임 종료 후 개인 활동 기록(이동 거리·이동 경로·역할별 카운트·플레이타임·승패)을 별도 다이얼로그로 제공하고, 카드를 PNG로 캡처해 네이티브 공유 시트로 공유하는 기능을 추가했다. 갤러리 저장은 별도 버튼 없이 공유 시트의 "이미지 저장" 항목으로 수행한다. 경로 영역은 실제 구글 지도 스냅샷 우선, 오프라인·실패·타임아웃 시 `CustomPainter` 기반 스타일라이즈드 경로로 폴백한다. 모든 기록은 메모리에만 유지되며 다음 게임 시작 시 초기화된다.

---

### 🎯 구현 목표

- 역할별 개인 통계를 공유 가능한 카드 형태로 시각화
- 구글 지도 스냅샷 + CustomPainter 이중 폴백으로 오프라인 환경 대응
- 카드 캡처 → 네이티브 공유 시트(share_plus) 원스텝 공유 — 갤러리 저장은 공유 시트 내 "이미지 저장" 활용
- STOMP 확정 이벤트 기준 실시간 누적 (체포·탈옥·잡힘 위치 포함)

### 🔧 주요 변경사항 상세

#### 지도 스냅샷 vs 캡처 타이밍 문제
라이브 `GoogleMap`(플랫폼 뷰)는 `RepaintBoundary.toImage()` 캡처 시 빈 이미지로 찍힌다. 이를 방지하기 위해 스냅샷(`takeSnapshot()`) 완료 후 `Image.memory`로 정적 교체 → `addPostFrameCallback`으로 정적 렌더 확인 → 부모의 `_mapReady = true` 흐름으로 캡처 버튼이 활성화된다. 경로가 없으면 이 대기 없이 즉시 활성화.

#### 로딩 오버레이 흰 모서리 버그 수정
초기 구현은 로딩 오버레이(`Positioned.fill`)가 카드+버튼 전체를 덮는 구조였다. 로딩 중 disabled 버튼의 기본 배경(`black100`, 거의 흰색)이 오버레이의 `xxlarge` 라운드 모서리 틈으로 노출되는 문제 발생. 오버레이를 캡처 카드(`RepaintBoundary`)만 덮는 내부 `Stack`으로 이동해 해결. 버튼은 로딩 중 disabled 상태 그대로 노출되며, 다크 테마에서 기본 disabled 톤이 튀는 문제는 팀 테마 기준 회색(`disabledBackgroundColor`/`disabledForegroundColor`)으로 지정해 처리.

#### 갤러리 저장 버튼 제거 → 닫기 버튼 교체
gal 패키지가 사진 권한 미보유 시 시스템 권한 프롬프트 없이 `ACCESS_DENIED` 예외를 던져 저장이 실패하는 문제 발생. 공유 시트의 "이미지 저장" 항목으로 갤러리 저장이 이미 가능하므로 갤러리 직접 저장 기능을 제거하고, 해당 자리에 닫기 버튼(`Navigator.pop`)을 배치. 닫기는 지도 로딩 중에도 항상 활성이라 사용자가 로딩에 갇히지 않는다.

#### 공유 완료 스낵바
`shareImageBytes`가 `ShareResultStatus` 기반 bool을 반환하도록 변경. 공유 시트에서 사용자가 실제로 공유/저장을 완료했을 때만 "공유했어요"(`messageShareComplete`, ko/en/ja) AppSnackbar를 표시한다. 시트를 그냥 닫으면(취소) 아무 표시도 하지 않는다.

#### keepAlive 이유
`PlayerGameRecordNotifier`는 `@Riverpod(keepAlive: true)`로 선언했다. `_prepareGameOverPresentation()`에서 위치 스트림을 cancel한 뒤 `MyRecordDialog`를 여는 순서이므로, autoDispose이면 다이얼로그가 provider를 watch하는 순간 이미 dispose된 상태일 수 있다. keepAlive로 선언해 게임 전체 생명주기를 보장하고, 다음 게임 `initState`에서 `reset()`으로 명시적 초기화.

#### GPS 노이즈 필터
`addPoint(p)`: `Geolocator.distanceBetween`으로 직전 점과 2m 미만 이동을 제외한다. 이동 없이 고정된 상태에서 GPS 진동이 거리를 부풀리는 것을 방지.

#### 경도 라디안 보정 (route_geometry.dart 회귀 방지)
경도를 도(degree) 그대로 x로 쓰면 π/180 ≈ 57배 차이가 생겨 경로가 세로로 납작해진다. `_mercatorX`에서 `lon * π / 180`으로 변환해 y축(`ln(tan(...))`)과 같은 라디안 단위로 맞춘다. 관련 회귀 테스트(`does_not_flatten_square_route_into_a_line`)로 검증.

### 📌 참고사항

- **기록은 휘발성**: 백엔드에 저장하지 않는다. 앱 강제 종료 시 현재 게임의 기록은 유실된다
- **더미 모드 제외**: `widget.isDummy`가 true이면 `reset()`과 `markEnd()` 호출이 생략된다
- `RouteMapSnapshot`은 경로가 1점 이상일 때만 사용하도록 `assert`로 보호됨. 빈 경로에는 "이동 기록 없음" 텍스트 표시
- i18n 키(`labelMyRecord`, `labelTravelDistance`, `labelMyArrestCount`, `labelMyEscapeCount`, `labelResult`, `messageShareComplete`, `messageSaveFailed`, `labelNoRoute`, `legendArrestSpot`, `legendCaughtSpot`, `buttonViewMyRecord`)를 ko/en/ja ARB 파일에 추가하고 `flutter gen-l10n`으로 자동 생성 파일 갱신
- `messageSaveComplete` 키는 갤러리 직접 저장 제거에 따라 ARB에서 삭제, 공유 완료용 `messageShareComplete`("공유했어요")로 대체
- `game_localizations*.dart`(자동 생성) 파일은 ARB에서 재생성한 결과이며 직접 편집하지 않음
