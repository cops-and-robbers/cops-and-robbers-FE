### 📌 작업 개요

서버 통신에 현재 앱 언어를 실었다.

모든 API 요청에 `Accept-Language` 헤더가 붙고, 공지사항 목록은 `language` 쿼리로 현재 언어의 제목·본문을 받는다. 닉네임 입력 상한은 서버 허용치와 같은 20자로 늘렸다.

- 커밋 4개 / 파일 9개 / +77 −15
- `flutter analyze` 에러 · 경고 0

### 🎯 구현 목표

- 서버가 언어에 따라 달라지는 응답(닉네임 생성, 공지 번역)을 현재 앱 언어로 내려줄 수 있게 한다
- 언어를 설정에서 바꾸면 이후 통신과 공지 화면이 곧바로 따라오게 한다
- 알파벳 닉네임이 들어갈 수 있게 입력 상한을 서버와 맞춘다

### ✅ 구현 내용

#### Accept-Language 인터셉터

- **파일**: `lib/core/network/dio_client.dart`
- **변경 내용**: 인터셉터 체인 맨 앞에 `Accept-Language` 주입 인터셉터 추가. `DioClient.create` 가 `currentLanguageCode` 콜백을 받고, provider 가 `appLocaleProvider` 의 현재 언어 코드를 넘긴다
- **이유**: 언어는 설정에서 언제든 바뀔 수 있다. BaseOptions 고정값이 아니라 요청 시점마다 콜백으로 읽어야 바뀐 언어가 다음 요청부터 바로 실린다

재발급 전용 plain Dio 에는 붙이지 않았다. 재발급 응답은 언어와 무관하다.

#### 공지사항 언어 조회

- **파일**: `notice_remote_datasource.dart`(+생성물), `notice_repository_impl.dart`, `notice_repository.dart`, `notice_provider.dart`
- **변경 내용**: `GET /api/notices` 에 `language` 쿼리 추가. 도메인 인터페이스부터 datasource 까지 필수 파라미터로 전달하고, provider 의 `build()` 가 `appLocaleProvider` 의 언어 코드를 watch 한다
- **이유**: 카테고리와 같은 방식이다. 언어가 바뀌면 build 가 재실행되어 0페이지부터 현재 언어로 다시 조회되므로, 화면 쪽에 갱신 로직을 따로 두지 않는다

`select` 로 언어 코드만 구독해서, 시스템 추종 여부 토글처럼 언어가 그대로인 상태 변화에는 재조회하지 않는다. 번역이 없는 공지는 서버가 한국어로 내려주므로(원문 폴백) 빈 화면이 생기지 않는다.

#### 닉네임 입력 상한 20자

- **파일**: `nickname_setup_page.dart`
- **변경 내용**: `maxLength` 10 → 20
- **이유**: 서버가 20자까지 받도록 늘었고, 언어별로 생성되는 알파벳 닉네임은 10자를 넘는다

#### 칩 버튼 고정 너비 제거

- **파일**: `lib/core/widgets/chips/action_chip.dart`
- **변경 내용**: 너비를 넘기지 않은 `ActionChip` 은 고정 100 대신 "최소 100, 내용이 길면 확장"으로 동작한다. 너비를 넘긴 호출부는 그대로 고정이다
- **이유**: 영어 라벨 "Check duplication" 이 고정 너비를 30px 넘쳐 overflow 가 났다. 한국어 라벨은 최소 너비 안에 들어 기존과 같은 모습이고, 지도의 "핀 전체 지우기" 칩도 같은 방식으로 안전해진다

### 🔧 주요 변경사항 상세

#### 언어 코드 계약

`Accept-Language` 와 `language` 쿼리 모두 ISO 639-1 코드(ko·en·ja) 그대로다. `appLocaleProvider` 가 지원 목록 밖 언어를 이미 걸러 주므로 앱에서 별도 검증은 없다. 서버는 모르는 언어 값을 한국어로 처리한다.

**특이사항**:
- 서버는 모르는 쿼리 파라미터를 400 으로 거절한다. `language` 를 보내는 이 변경은 서버 운영 반영 뒤에 나가야 하며, 그래서 PR base 를 `20260812_#470_v3_앱_전면_개편` 으로 잡았다
- 언어를 바꿔도 이미 만들어진 닉네임은 소급 변경되지 않는다. 닉네임 변경 화면에서 직접 바꾸는 것이 안내 경로다

### 🧪 테스트 및 검증

- 요청 로그에서 모든 호출에 `Accept-Language` 헤더가 실리고 공지 조회에 `language` 쿼리가 붙는 것 확인
- 번역이 있는 공지는 해당 언어로, 번역이 없는 공지는 한국어로 표시되는 것 확인
- 닉네임 화면 영어 로캘에서 20자 입력과 칩 overflow 해소 확인
- repository 단위 테스트에 언어 전달 검증 1개 추가, 기존 5개는 필수 파라미터에 맞춰 갱신
- `flutter analyze` 에러 · 경고 0 (남은 5건은 이번 변경과 무관한 파일)
