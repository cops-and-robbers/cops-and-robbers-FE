### 📌 작업 개요
수감(체포) 중 지도 표현을 "지도 스타일 교체"에서 "전면 철창 오버레이"로 변경.
지도는 도둑모드 스타일을 그대로 유지하고, 그 위에 세로 창살·상하 레일·상하 암부를 그리는 오버레이만 덮는다. 감옥 노란 강조·맥동, 수감 안내 버튼, 수동·자동 탈옥은 변경 없음.
함께 인게임 채팅 버튼 아이콘을 틴트에서도 줄이 보이는 말풍선으로 교체.

**보고서 파일**: `docs/report/20260913_#571_수감_화면_전면_철창_오버레이_적용.md`

### 🎯 구현 목표
- 수감 시 `MapStyles.arrested`로 지도 JSON 스타일을 통째로 바꾸던 동작 제거 — 화면 전체 색이 바뀌어 "다른 지도로 갈아탄" 인상을 주던 문제
- 앱바 아래부터 화면 바닥까지 끊김 없는 세로 창살로 "갇힌 시야" 표현
- 암부는 위아래에만 두어 감옥·내 위치가 놓이는 화면 중앙은 가장 밝게 유지
- 지도 조작·액션 버튼은 그대로 동작 (오버레이는 터치를 먹지 않음)
- 디자이너 시안이 나오면 한 파일 교체로 끝나도록 오버레이를 순수 비주얼 위젯으로 격리
- 채팅 버튼 아이콘이 초록 통짜 덩어리로 보이던 문제 해결

### ✅ 구현 내용

#### 전면 철창 오버레이 위젯 추가
- **파일**: `lib/features/game/presentation/widgets/jail_bars_overlay.dart` (신규)
- **변경 내용**: `JailBarsOverlay` — `IgnorePointer → SafeArea → Padding(top: kToolbarHeight) → RepaintBoundary → CustomPaint` 구조. `_JailBarsPainter`가 상하 암부 그라데이션, 세로 창살(폭 8dp · 간격 50dp, 가운데 밝은 띠로 금속 질감), 상하 가로 레일(12dp)을 그린다
- **이유**: 게임 상태를 받지 않는 순수 비주얼이라 호출부·지도·게임 로직과 분리된다. 시안이 오면 `CustomPaint` 자리에 `Image.asset`을 넣으면 끝

#### 지도 스타일 교체 제거
- **파일**: `lib/features/game/presentation/widgets/google_map_view.dart`
- **변경 내용**: `style:` 분기에서 `isArrested ? MapStyles.arrested : …` 제거 → `isDarkMode ? MapStyles.dark : null`만 남김. `isArrested` 프로퍼티는 감옥 강조·맥동에 계속 쓰이므로 유지
- **이유**: 수감 표현을 오버레이가 전담하므로 스타일 교체는 불필요

#### `MapStyles.arrested` 상수 삭제
- **파일**: `lib/core/constants/map_styles.dart`
- **변경 내용**: 참조가 사라진 `arrested` JSON 스타일 상수 제거
- **이유**: 위 변경으로 고아가 된 코드 정리

#### 게임 화면 스택에 오버레이 배치
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 지도(index 0) 바로 뒤에 `index 0b`로 `if (isArrestedNow) const JailBarsOverlay() else const SizedBox.shrink()` 추가
- **이유**: 지도 바로 위·버튼과 전체 화면 패널(참가자·채팅) 아래에 깔려야 한다. 이 파일의 "if/else로 자식 개수 고정" 컨벤션을 따라 `ChatOverlay` 상태 보존을 깨지 않는다

#### 암부용 색상 상수 추가
- **파일**: `lib/core/constants/app_colors.dart`
- **변경 내용**: `blackAlpha60`(`0x99080A0C`), `blackAlpha0`(`0x00080A0C`) 추가
- **이유**: 디자인 시스템 규칙(`withValues` 금지, 팔레트 상수만 사용) 준수. 기존 `yellowAlpha20` 패턴과 동일

#### 인게임 채팅 버튼 아이콘 교체
- **파일**: `lib/features/game/presentation/pages/game_page.dart:2540`, `assets/icons/icon_comment.svg`
- **변경 내용**: 채팅 버튼 `AppIcons.speechBubble → AppIcons.comment`. `icon_comment.svg`는 말풍선과 줄 3개를 path 하나로 합쳐 줄이 **구멍(subpath)** 으로 남는 버전으로 교체
- **이유**: `SvgIconButton`의 `iconColor`는 `ColorFilter.mode(color, BlendMode.srcIn)`이라 SVG의 모든 픽셀을 한 색으로 칠한다. 기존 `icon_speech_bubble.svg`는 줄이 없는 실루엣이고, 기존 `icon_comment.svg`는 흰 줄이 별도 path라 틴트에 묻혀 사라졌다. 구멍 방식이면 틴트를 먹어도 줄이 투명하게 남는다

### 🔧 주요 변경사항 상세

#### jail_bars_overlay.dart
- 창살 시작 x는 `(간격 − 폭) / 2`로 잡아 좌우 여백이 대칭
- 상하 암부·레일 높이는 `min(값, size.height / 2)`로 제한 — `splitScreenMode: true` 환경(분할 화면·폴더블 커버)에서 캔버스가 낮아지면 위아래 암부가 겹쳐 중앙까지 어두워지는 것을 막는다
- `RepaintBoundary`로 감싸 게임 타이머의 1초 `setState`에 딸려 정적 페인터가 매초 다시 그려지지 않게 한다
- 창살이 감옥 원과 라벨을 가로지르는 것은 의도된 표현 (창살 너머로 감옥이 보이는 그림). 폴리곤 감옥 마스크 계산까지 붙여 구멍을 뚫는 안은 채택하지 않음

**특이사항**:
- 창살 폭·간격·레일·암부 높이는 위젯 `build`의 상수 4개라 실기기 확인 후 바로 조정 가능
- 9/9 회의에서 "전체 철창 오버레이는 버튼이 안 눌린다고 오해할 수 있다"는 반론이 있었음. 버튼을 창살 위 레이어에 두는 것으로 완화했으나 실사용 확인 대상

#### icon_comment.svg
- `AppIcons.comment`는 `community_notification_card.dart:33`(답글 알림, 틴트 없음)도 쓴다. 실루엣이 같고 흰 줄이 투명 구멍으로 바뀐 것이라 흰 카드 위에서는 차이가 없다
- `AppIcons.speechBubble`은 `community_comment_list.dart:270`이 계속 쓰며 건드리지 않았다
