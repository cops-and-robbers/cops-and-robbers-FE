### 📌 작업 개요
게임 중 누적 이동 거리를 서버에 저장해 팀 MVP를 판정하는 기능(FE #628, BE #212)과 앞으로의 이동 경로(좌표) 저장에 맞춰 법적 문서 3종의 ko 개정 원고를 작성. 시행일은 2026-10-23.

**보고서 파일**: `docs/report/20261018_#637_게임_기록_보관_반영_약관_3종_개정.md`

### 🎯 구현 목표
- 서버에 저장되는 게임 기록(이동 거리·MVP)과 향후 이동 경로 보관의 근거를 약관 본문에 마련
- 실제 동작과 어긋난 기존 서술 정정 — "좌표는 종료 즉시 삭제, 별도 동의 없이 서버에 영구 저장 안 함", "동선·통계는 단말에서만 쓰고 폐기", "게임 활동 정보는 세션 종료 시까지"
- 웹 담당자가 정본(`dongsim-web/content/legal`)에 옮길 수 있게 조항별 전·후 비교표 제공

### 🔧 주요 변경사항 상세

#### 게임 기록 보유
서비스 운영 기간 동안 보관하고, 같은 게임 다른 참가자의 기록 보존을 위해 **회원 탈퇴 후에도 닉네임을 포함해 삭제하지 않는다**. 현재 서버 동작(탈퇴 처리가 `game_result_participants`를 건드리지 않음)과 같아 BE 작업은 없다.

#### 이동 경로(좌표)
서비스 시작 전에는 보관하지 않고, 보유 기간·파기 방법은 시작 전에 공지로 안내한다고 적었다.

**특이사항**:
- 시행일·부칙: 3종 모두 2026-10-23. 부칙은 기존 문장을 두고 새 문장을 추가
- 원고의 `<!-- 검수 -->` 주석은 확인 필요 지점이며 정본에는 싣지 않는다
- 위치정보이용약관 제17조 회사 주소 빈칸은 기존 미결 항목으로 이번 범위 밖
