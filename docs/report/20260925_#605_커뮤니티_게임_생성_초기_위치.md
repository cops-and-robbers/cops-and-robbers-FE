# 커뮤니티 게임 생성 초기 위치 개선

## 작업 개요

모집글 채팅방에서 게임을 만들 때 모집글에 저장된 모임 장소에서 구역 설정 지도를 시작하도록 #605를 구현했다. 역지오코딩된 주소를 재조회하지 않고 기존 위도·경도를 전달한다.

## 원인

채팅방은 모집글 좌표를 알고 있었지만 공통 게임 생성 진입점에는 글 ID만 전달했다. 이전 초안을 비운 뒤 열린 구역 설정 화면은 초기 위치를 받지 못해 현재 GPS 위치를 사용했다.

## 변경 내용

| 파일 | 변경 |
|---|---|
| `lib/features/community/presentation/pages/community_chat_room_page.dart` | 모집글의 위도·경도를 게임 생성 진입점에 전달 |
| `lib/features/session/presentation/game_creation_entry.dart` | 글 ID와 초기 좌표를 함께 전달. 권한 게이트와 이전 초안 삭제 유지 |
| `lib/router/app_router.dart` | 생성 흐름과 구역 설정 경로의 타입 있는 인자 전달 |
| `lib/features/session/presentation/pages/session_creation_flow_page.dart` | 구역 설정에 모임 장소 전달. 이미 설정한 도형도 계속 전달 |
| `lib/features/session/presentation/pages/setup_playground_page.dart` | 원형·핀 모드의 초기 중심 선택에 기존 도형/초안을 우선하고, 없으면 모임 장소 사용 |
| `lib/core/widgets/map/pin_zone_setting_widget.dart` | 기존 꼭짓점이나 초기 좌표가 있으면 GPS를 기다리지 않고 지도 표시 |
| `test/features/session/presentation/pages/setup_playground_initial_location_test.dart` | 실제 생성 흐름, 위치 우선순위, 모드 전환, 내 위치 버튼 회귀 검증 |

### 위치 선택

- 채팅방에서 새로 만들면 모임 장소에서 시작한다.
- 홈에서 만들면 기존처럼 현재 위치에서 시작한다.
- 생성 중 재편집하거나 원형·핀 모드를 전환하면 이미 설정한 구역을 보존한다. 처음 여는 반대 모드는 현재 설정한 구역 중심에서 시작한다.
- 내 위치 버튼을 누르면 실제 GPS 위치로 이동한다. 늦은 GPS 응답이 모임 장소를 덮어쓰지 않는다.
- 생성 후 초대 전송에 필요한 `communityPostId` 전달을 유지한다. 초대 전송 로직은 변경하지 않았다.

## 검증

- 수정 전 테스트에서 원형↔핀 전환 시 현재 GPS로 돌아가는 실패를 확인했다.
- 실제 앱의 생성 경로를 재사용해 공통 진입점 → 생성 흐름 → 구역 설정까지 모임 좌표가 도착하고, 글 ID와 초안 삭제가 유지되는지 검증했다.
- 좌표 전달을 임시로 제거하면 해당 회귀 테스트가 모임 장소 대신 GPS 위치를 표시해 실패하는 것도 확인했다. 검증 후 전달 코드를 복원했다.
- 최종 관련 테스트 **20개 통과**: 새 위치 테스트 10개 + 기존 진입/초안 테스트 6개 + 다크 테마 테스트 4개.
- `flutter analyze --no-pub`: **No issues found**.
- 전체 테스트 실행에서는 **1,312개 통과 / 6개 실패**. 이후 추가한 생성 경로 테스트는 위 최종 관련 테스트에 포함해 통과했다.
- 실패 6건은 모두 `community_page_test.dart`의 정렬 시트 하단 37px overflow다. 기준 커밋 `f09501426bc852ef19f3fd9d9ac869da2672be43`을 별도 임시 디렉터리에 추출해 해당 파일을 실행했고, **19개 통과 / 동일한 6개 실패**로 기존 문제임을 확인했다.
- `git diff --check` 통과.

## 남은 확인

Android/iOS 실기기에서 현재 위치 A와 모임 장소 B를 다르게 설정한 뒤 첫 지도, 원형·핀 전환, 재편집, 내 위치 버튼, 생성 후 채팅방 초대 전송을 확인해야 한다. 실제 지도 타일과 게임 생성 API·초대 전송 전체 여정은 이번 자동 검증에 포함하지 않았다.
