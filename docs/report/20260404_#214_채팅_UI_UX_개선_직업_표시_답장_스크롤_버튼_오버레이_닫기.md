### 📌 작업 개요

채팅 UI/UX 전반 개선 작업. 채팅 메시지에 발신자 직업(경찰/도둑) 아이콘 표시, 최신 메시지로 빠르게 이동하는 스크롤 FAB 버튼 추가, 채팅 오버레이 영역 밖 터치 시 시트 접기, 스낵바 다크모드 대응 및 매직넘버 상수화 등을 구현

### 🎯 구현 목표

- 채팅 버블에서 발신자의 직업(경찰/도둑)을 아이콘으로 즉시 확인 가능하게 함
- 채팅을 위로 스크롤한 후 최신 메시지로 빠르게 돌아갈 수 있는 FAB 버튼 제공
- 채팅 오버레이 밖을 터치하면 시트가 접히도록 UX 개선
- 스낵바 다크모드 배경색 대응 및 매직넘버 상수 교체

### ✅ 구현 내용

#### 1. 채팅 버블 닉네임 옆 직업 아이콘 표시
- **파일**: `lib/features/chat/presentation/widgets/chat_message_bubble.dart`
- **변경 내용**: `_roleIconPath` getter 추가하여 sender의 team 값(POLICE/ROBBER)에 따라 다크/라이트 모드별 SVG 아이콘 경로 반환. 닉네임 `Text` 위젯을 `Row`로 감싸서 12×12 아이콘을 닉네임 왼쪽에 배치
- **이유**: 발신자가 경찰인지 도둑인지 닉네임만으로 구분 불가능 → 직업 아이콘으로 즉시 식별 가능

#### 2. 채팅 스크롤 하단 이동 FAB 버튼 추가
- **파일**: `lib/features/chat/presentation/widgets/chat_message_list.dart`
- **변경 내용**: `ScrollController` 리스너로 스크롤 위치 추적하여 200px 이상 위로 스크롤 시 `_showScrollToBottom` 상태를 true로 전환. `Stack` + `Positioned`로 우하단에 40×40 원형 FAB 표시. 탭 시 `animateTo(0)`으로 최하단 이동
- **이유**: 대화 중 위로 스크롤한 후 최신 메시지로 빠르게 돌아갈 수단이 없었음

**특이사항**:
- `reverse: true` ListView에서 pixels 0이 최하단, 위로 스크롤하면 pixels 증가
- `hasClients` 가드로 컨트롤러 미연결 시 예외 방어
- `didUpdateWidget`에서 새 메시지 수신 시 하단 근처(100px)일 때만 자동 스크롤

#### 3. 채팅 오버레이 바깥 영역 탭 시 시트 접기
- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`
- **변경 내용**: `_collapseSheet()` 헬퍼 메서드 추가 (`isAttached` 가드 포함). `build()`에서 `_isExpanded && !isKeyboardOpen` 조건으로 `Positioned.fill` + `GestureDetector(onTap: _collapseSheet)` 배리어를 `DraggableScrollableSheet` 위에 오버레이
- **이유**: 채팅 시트를 펼친 상태에서 지도 영역을 탭해도 시트가 닫히지 않아 조작이 불편했음

**특이사항**:
- 키보드가 열린 상태에서는 배리어 비활성화 (키보드 닫기와 시트 접기가 동시에 발생하면 UX 혼란)
- 배리어는 `Stack`에서 시트보다 아래 z-order에 배치하여 시트 내부 터치는 정상 동작

#### 4. 스낵바 다크모드 배경색 대응
- **파일**: `lib/core/widgets/snackbars/app_snackbar.dart`
- **변경 내용**: `show()` 메서드에 `isDarkMode` 파라미터 추가. 다크모드일 때 배경색을 `AppColors.black`으로, 라이트모드는 기존 `AppColors.black600` 유지
- **이유**: 도둑팀(다크모드) 화면에서 스낵바 배경이 밝게 표시되어 디자인 불일치

#### 5. 스낵바 매직넘버 상수 교체
- **파일**: `lib/core/widgets/snackbars/app_snackbar.dart`
- **변경 내용**: 하드코딩된 padding, margin 값을 `AppSpacing`, `AppRadius` 상수로 교체
- **이유**: 디자인 시스템 일관성 유지 및 향후 변경 시 일괄 수정 가능

#### 6. 채팅 입력바 패딩 조정
- **파일**: `lib/features/chat/presentation/widgets/chat_input_bar.dart`
- **변경 내용**: 외부 컨테이너 좌우 패딩을 `AppSpacing.horizontal20`으로, 내부 TextField 좌측을 `horizontal20`, 전송 버튼 우측을 `horizontal12`로 조정
- **이유**: 디자인 시안 대비 좌우 여백 불일치 수정

#### 7. 팀 변경 슬롯 아이콘 교체
- **파일**: `lib/features/session/presentation/widgets/participant_card.dart`
- **변경 내용**: `AddSlotCard`의 아이콘을 `Icons.add` → `icon_change.svg`로 교체. 크기 24×24, 다크/라이트별 colorFilter 적용
- **이유**: 팀 변경 슬롯의 의미를 더 명확하게 전달하는 전용 아이콘 적용
