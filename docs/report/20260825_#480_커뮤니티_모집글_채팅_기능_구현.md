## ⚙️ [기능추가][커뮤니티] 모집글 채팅 기능 구현

### 📌 작업 개요

모집글 상세의 "채팅 참여하기" 버튼이 준비 중 안내만 띄우던 것을 실제 동작으로 연결했다. 모집글 단위 채팅방을 신설해 참여·실시간 대화·나가기를 붙이고, 참여 중인 채팅방을 모아 볼 수 있는 목록 화면도 새로 만들었다.

### 🎯 구현 목표

- 모집글 단위 채팅방 신설 — 상세에서 참여하고 방에 들어가 실시간으로 대화
- 내 채팅방 목록 화면 신설 — 참여 중인 방과 마지막 메시지 확인
- 채팅방 나가기

### ✅ 구현 내용

#### 채팅 도메인·데이터 계층 추가

- **파일**: `lib/features/community/domain/repositories/community_chat_repository.dart`, `data/repositories/community_chat_repository_mock.dart`, `domain/entities/community_chat_*.dart`
- **변경 내용**: 메시지·이벤트·멤버·룸·페이지 엔티티(Freezed)와 저장소 인터페이스, mock 구현 추가
- **이유**: 서버 API가 정리되기 전까지 화면·상태 관리를 mock으로 먼저 검증

#### 채팅방 상태 관리

- **파일**: `providers/community_chat_room_provider.dart`, `providers/community_chat_rooms_provider.dart`
- **변경 내용**: 방 상태 Notifier와 구독 관리, 내 채팅방 목록 Provider 추가
- **이유**: 지금 보고 있는 방만 구독하고 목록 화면에서는 구독하지 않는다 — 서버가 연결마다 주기적 확인을 스레드 하나로 처리해 연결이 늘면 부하가 그대로 늘어나기 때문

#### 채팅방 화면 신설

- **파일**: `pages/community_chat_room_page.dart`
- **변경 내용**: 실시간 송수신, 위로 스크롤 시 이전 대화 페이지네이션, 보낸 메시지를 먼저 그린 뒤 서버 응답으로 확정
- **이유**: 전송 즉시 화면에 보여야 자연스러운데, 서버 확인 응답이 뒤늦게 와도 같은 메시지가 두 번 그려지지 않도록 앱에서 식별 키를 만들어 대조

#### 채팅방 정보(사이드바) 화면

- **파일**: `pages/community_chat_room_info_page.dart`
- **변경 내용**: 참가자 목록, 모집글 보기·나가기 메뉴, 우측 상단 공지 알림 아이콘 추가. 작성자는 나가기 버튼 자체를 숨김(서버 `AUTHOR_CANNOT_LEAVE`)
- **이유**: 시안이 전체 화면이라 drawer 대신 push로 구현. 모집글 보기는 `push` 대신 `go`로 이동해, 뒤로가기 한 번으로 커뮤니티 목록까지 나가도록 스택을 정리

#### 채팅방 공지 화면 신설

- **파일**: `pages/community_chat_notice_page.dart`

#### 내 채팅방 목록

- **파일**: `widgets/community_chat_room_list.dart`, `widgets/community_chat_room_tile.dart`
- **변경 내용**: 마지막 메시지와 시각 표기, 대화가 없는 방은 맨 뒤로 정렬
- **이유**: 내 모임 탭에서 참여 중인 방을 한눈에 확인

#### 채팅·댓글 입력창 공통화

- **파일**: `widgets/community_message_input.dart` (신규), `widgets/community_comment_input.dart` (기존 로직 이관)
- **변경 내용**: 채팅 입력창과 댓글 입력창이 쓰던 중복 UI를 하나의 컴포넌트로 추출
- **이유**: 두 입력창의 생김새·동작이 사실상 같아서 따로 유지할 이유가 없었음

#### 채팅 말풍선 공유

- **파일**: `lib/core/widgets/chat/chat_bubble.dart` (신규), `lib/features/chat/presentation/widgets/chat_message_bubble.dart`
- **변경 내용**: 게임 채팅 말풍선의 본체를 공용 `ChatBubble`로 추출해 커뮤니티 채팅과 공유
- **이유**: 두 화면의 말풍선이 이번 작업으로 거의 동일해져 중복 유지보다 공유가 합리적

#### 참여·나가기 시스템 메시지

- **변경 내용**: 참여·나가기 알림 문구를 서버가 아니라 앱에서 조립
- **이유**: 닉네임을 바꾸면 지난 대화에 남은 이름도 함께 바뀌어야 해서, 서버가 문구를 고정해 내려주는 방식 대신 현재 닉네임을 조회해 앱에서 조립

#### 라우터·문구·아이콘 정리

- **파일**: `lib/router/route_paths.dart`, `lib/router/app_router.dart`, `lib/l10n/app_ko.arb`/`app_en.arb`/`app_ja.arb`
- **변경 내용**: 채팅방/정보/공지 경로 추가, ko/en/ja 문구 추가, 커뮤니티 화면 아이콘 크기 24로 통일, 댓글 그룹 구분선·여백 정리

### 🔧 주요 변경사항 상세

#### 구독은 보는 방만, 나가면 즉시 해제

목록 화면에서는 어떤 방도 구독하지 않고, 진입한 방만 구독한다. 나가기에 성공하면 그 자리에서 구독을 끊는다 — 서버는 구독 시점에만 자격을 확인하므로, 끊지 않으면 나간 방의 메시지가 계속 들어온다.

#### 낙관적 전송과 중복 렌더 방지

메시지를 보내는 즉시 화면에 그리고, 서버 확인 응답이 오면 로컬 항목을 서버 항목으로 교체한다. 두 항목을 같은 메시지로 식별하는 키가 없으면 전송 직후 목록에 같은 메시지가 두 번 나타난다.

#### 마감·종료된 글의 대화

새 참여만 막고, 이미 참여 중인 사람의 대화는 그대로 유지한다.
