## 📌 작업 개요

GitHub Actions CI/CD로 업로드된 iOS 빌드가 iOS 18.5 SDK로 빌드되어 App Store Connect에서 경고 발생. 2026년 4월 이후 해당 SDK로는 앱 업로드 및 배포 불가 예정. CI 환경의 Xcode 버전을 26.0으로 업그레이드하여 iOS 26 SDK 사용하도록 수정.

---

## 🔍 문제 분석

### 원인
- GitHub Actions의 iOS 빌드 워크플로우가 Xcode 16.4 사용
- Xcode 16.4는 iOS 18.5 SDK 포함
- Apple의 새로운 정책: 2026년 4월부터 iOS 26 SDK 이상 필수

### App Store Connect 경고 메시지
```
90725: SDK version issue. This app was built with the iOS 18.5 SDK.
Starting April 2026, all iOS and iPadOS apps must be built with the
iOS 26 SDK or later, included in Xcode 26 or later, in order to be
uploaded to App Store Connect or submitted for distribution.
```

### 영향 범위
- **즉시**: App Store Connect에서 경고 표시
- **2026년 4월 이후**: 앱 업로드 및 배포 불가능

---

## ✅ 구현 내용

### 1. GitHub Actions 워크플로우 Xcode 버전 업그레이드

#### 프로덕션 배포 워크플로우
- **파일**: [.github/workflows/PROJECT-FLUTTER-IOS-TESTFLIGHT.yaml](.github/workflows/PROJECT-FLUTTER-IOS-TESTFLIGHT.yaml)
- **변경 라인**: 74번째 줄
- **변경 내용**: `XCODE_VERSION: "16.4"` → `"26.0"`
- **영향**: deploy 브랜치로 푸시 시 TestFlight 자동 배포

#### 테스트 배포 워크플로우
- **파일**: [.github/workflows/PROJECT-FLUTTER-IOS-TEST-TESTFLIGHT.yaml](.github/workflows/PROJECT-FLUTTER-IOS-TEST-TESTFLIGHT.yaml)
- **변경 라인**: 59번째 줄
- **변경 내용**: `XCODE_VERSION: "16.4"` → `"26.0"`
- **영향**: 테스트 빌드도 iOS 26 SDK 사용

**변경 이유**: GitHub Actions macos-15 러너는 Xcode 26.0을 지원하며, 이를 사용하여 iOS 26 SDK로 빌드하도록 설정

## 🔧 주요 변경사항 상세

### PROJECT-FLUTTER-IOS-TESTFLIGHT.yaml

**변경 전**:
```yaml
env:
  FLUTTER_VERSION: "3.35.5"
  XCODE_VERSION: "16.4"  # iOS 18.5 SDK
  PROJECT_TYPE: "flutter"
```

**변경 후**:
```yaml
env:
  FLUTTER_VERSION: "3.35.5"
  XCODE_VERSION: "26.0"  # iOS 26 SDK ✅
  PROJECT_TYPE: "flutter"
```

이 설정은 두 곳에서 Xcode를 선택하는 데 사용:
- `prepare-build` job (110번째 줄)
- `build-ios` job (231번째 줄)

```yaml
- name: Select Xcode version
  run: sudo xcode-select -s /Applications/Xcode_${{ env.XCODE_VERSION }}.app/Contents/Developer
```

### PROJECT-FLUTTER-IOS-TEST-TESTFLIGHT.yaml

**변경 전**:
```yaml
env:
  FLUTTER_VERSION: "3.35.5"
  XCODE_VERSION: "16.4"  # iOS 18.5 SDK
  PROJECT_TYPE: "flutter"
  ENV_FILE_PATH: ".env"
```

**변경 후**:
```yaml
env:
  FLUTTER_VERSION: "3.35.5"
  XCODE_VERSION: "26.0"  # iOS 26 SDK ✅
  PROJECT_TYPE: "flutter"
  ENV_FILE_PATH: ".env"
```

이 설정은 두 곳에서 Xcode를 선택하는 데 사용:
- `prepare-test-build` job (194번째 줄)
- `build-ios-test` job (422번째 줄)

## 🧪 테스트 및 검증

### 로컬 빌드 검증
현재 워크플로우는 CI 환경에서만 실행되며, 로컬 빌드는 개발자의 Xcode 버전을 따릅니다.

Flutter 3.35.5는 Xcode 26.0을 공식 지원하므로 호환성 문제가 없습니다.

### CI 검증 계획
1. **GitHub Actions 모니터링**
   - `Select Xcode version` 단계에서 Xcode 26.0 사용 확인
   - `Create Archive` 단계에서 iOS 26 SDK로 빌드 확인
   - `Upload to TestFlight` 성공 확인

2. **App Store Connect 검증**
   - 새 빌드의 경고 탭 확인
   - **90725 경고 미발생 확인** ✅
