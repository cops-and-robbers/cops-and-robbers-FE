### 📌 작업 개요
기존 Material SnackBar를 피그마 디자인 시안 기반의 커스텀 스낵바(AppSnackbar)로 전면 교체.
Overlay 기반 위젯으로 구현하여 앱 전체 디자인 통일감 확보 및 상태별 시각적 구분 적용.

### 🎯 구현 목표
- 피그마 시안에 맞는 커스텀 스낵바 위젯 구현
- 기존 Material SnackBar 호출부를 새 디자인으로 전면 교체
- 상태별(성공/에러/경고) 배경색 및 아이콘 커스터마이징 지원

### ✅ 구현 내용

#### 커스텀 스낵바 위젯 신규 구현
- **파일**: `lib/core/widgets/snackbars/app_snackbar.dart` (신규)
- **변경 내용**: Overlay 기반 커스텀 스낵바 위젯 구현
- **주요 스펙**:
  - 슬라이드업(easeOutBack) + 페이드(easeOut) 진입/퇴장 애니메이션 (300ms)
  - 위치: 하단 105px, 좌우 20px 마진, 12px 라운드
  - SVG 아이콘 + 텍스트 가로 배치 (기본 아이콘: icon_siren.svg)
  - 배경색 커스터마이징 (기본: black600)
  - 자동 닫힘 (기본 3초)
  - 동시 1개만 표시 (새 스낵바 호출 시 기존 즉시 제거)

#### 스낵바 아이콘 에셋 추가
- **파일**: `assets/icons/icon_siren.svg` (신규)
- **변경 내용**: 스낵바 기본 아이콘으로 사용할 사이렌 SVG 아이콘 추가

#### 기존 Material SnackBar 전면 교체
- **파일**: 10개 페이지/위젯 파일
  - `login_page.dart`, `nickname_setup_page.dart`, `home_page.dart`
  - `waiting_room_page.dart`, `session_creation_flow_page.dart`
  - `game_settings_page.dart`, `game_settings_edit_page.dart`
  - `settings_page.dart`, `session_code_card.dart`, `participant_overlay.dart`
- **변경 내용**: `ScaffoldMessenger.of(context).showSnackBar(SnackBar(...))` 호출부를 `AppSnackbar.show(context, message: ..., backgroundColor: ...)` 로 교체
- **이유**: Material SnackBar의 기본 스타일 대신 피그마 시안에 맞는 통일된 디자인 적용

#### 린트 경고 해소
- **파일**: 교체된 10개 파일
- **변경 내용**: async gap 이후 BuildContext 사용 부분에 `mounted` 체크 추가 또는 `// ignore: use_build_context_synchronously` 주석 적용
- **이유**: AppSnackbar.show는 BuildContext를 직접 사용하므로 async gap 경고 해소 필요

### 🔧 주요 변경사항 상세

#### AppSnackbar API
```dart
// 기본 사용
AppSnackbar.show(context, message: '저장되었습니다.');

// 에러 스낵바 (빨간 배경)
AppSnackbar.show(context, message: '오류 발생', backgroundColor: AppColors.red);

// 성공 스낵바 (파란 배경)
AppSnackbar.show(context, message: '완료', backgroundColor: AppColors.blue);

// 즉시 닫기
AppSnackbar.dismiss();
```

**특이사항**:
- Material SnackBar와 달리 Overlay 기반이므로 Scaffold 없이도 사용 가능
- static 메서드로 어디서든 호출 가능하며, 동시에 1개만 표시되는 싱글톤 패턴 적용

#### Android 보안 설정 정리
- **파일**: `android/app/src/main/AndroidManifest.xml`
- **변경 내용**: `usesCleartextTraffic="true"` 속성 제거
- **이유**: HTTP 평문 통신 허용 설정 제거하여 보안 강화 (HTTPS만 허용)
