### 📌 작업 개요

Firebase Remote Config를 활용하여 앱 버전 관리 및 서버 점검 모드를 구현. 앱 시작 시 Remote Config 값을 가져와 점검 모드, 강제/선택/권고 업데이트 여부를 판단하고 적절한 UI를 표시한다.

### 🎯 구현 목표

- Firebase Remote Config 도입 및 초기화
- 앱 버전과 `minimum_version` 비교하여 강제/선택 업데이트 제어
- 앱 버전과 `latest_version` 비교하여 권고 업데이트 안내
- 서버 점검 모드(`maintenance`) 활성화 시 전용 점검 페이지 표시
- 설정 페이지 하단에 현재 앱 버전 표시

### ✅ 구현 내용

#### 1. Firebase Remote Config 의존성 추가
- **파일**: `pubspec.yaml`
- **변경 내용**: `firebase_remote_config: ^6.3.0` 추가

#### 2. Remote Config 서비스 (싱글톤)
- **파일**: `lib/core/services/remote_config/remote_config_service.dart`
- **변경 내용**: `RemoteConfigService` 싱글톤 클래스 생성. Firebase Remote Config 초기화, fetch, 값 조회 담당
- **파라미터**: `minimum_version`, `latest_version`, `force_update`, `maintenance`, `maintenance_message`
- **특이사항**: 디버그 모드에서는 `minimumFetchInterval`을 0으로 설정하여 매번 최신 값 fetch. fetch 실패 시 기본값으로 앱 정상 진행 (fail-open)

#### 3. 앱 버전 체크 로직
- **파일**: `lib/core/services/remote_config/app_version_checker.dart`
- **변경 내용**: `AppVersionChecker.check()` 정적 메서드로 버전 체크 실행. 시맨틱 버전 비교 함수 내장
- **체크 순서**:
  1. `maintenance == true` → 점검 모드
  2. `현재 버전 < minimum_version` → `force_update`에 따라 강제/선택 업데이트
  3. `현재 버전 < latest_version` → 권고 업데이트
  4. 그 외 → 정상 진입

#### 4. 업데이트/점검 처리 헬퍼
- **파일**: `lib/core/services/remote_config/update_dialog_helper.dart`
- **변경 내용**: `UpdateDialogHelper.handleResult()`로 버전 체크 결과에 따른 분기 처리
  - 점검/강제 업데이트 → 전용 페이지로 `context.go()` 이동 (뒤로가기 스택 제거로 자연스러운 차단)
  - 선택/권고 업데이트 → `AppDialog`로 다이얼로그 표시 ("나중에" 선택 가능)

#### 5. 서버 점검 페이지
- **파일**: `lib/core/widgets/pages/maintenance_page.dart`
- **변경 내용**: 앱 아이콘 + 점검 안내 메시지 표시. `maintenance_message`가 설정되어 있으면 점검 시간 등 추가 표시

#### 6. 강제 업데이트 페이지
- **파일**: `lib/core/widgets/pages/force_update_page.dart`

#### 7. 스토어 URL 상수

### 🔧 주요 변경사항 상세

#### Remote Config 파라미터 (Firebase 콘솔)

| 파라미터 | 유형 | 용도 | 기본값 |
|---|---|---|---|
| `minimum_version` | 문자열 | 최소 허용 버전 | `1.0.0` |
| `latest_version` | 문자열 | 최신 버전 (권고 업데이트 기준) | `1.0.0` |
| `force_update` | 부울 | 강제 업데이트 여부 | `false` |
| `maintenance` | 부울 | 서버 점검 모드 | `false` |
| `maintenance_message` | 문자열 | 점검 안내 메시지 (시간 등) | 빈 문자열 |

#### 버전 체크 결과별 동작

| 결과 | 조건 | 동작 | 앱 사용 |
|---|---|---|---|
| `maintenance` | `maintenance == true` | 점검 페이지 이동 | 차단 |
| `forceUpdate` | `현재 < minimum` + `force_update == true` | 강제 업데이트 페이지 이동 | 차단 |
| `optionalUpdate` | `현재 < minimum` + `force_update == false` | 업데이트 다이얼로그 | 사용 가능 |
| `recommendUpdate` | `현재 < latest` | 새 버전 안내 다이얼로그 | 사용 가능 |
| `upToDate` | 그 외 | 없음 | 사용 가능 |

#### SplashPage 체크 순서 (앱 시작 흐름)

```
1단계: Remote Config 체크 (앱 게이트)
  → 점검 중 → /maintenance 페이지
  → 강제 업데이트 → /force-update 페이지
  → 선택/권고 업데이트 → 다이얼로그 후 진행

2단계: 인증 체크 (Auth 게이트)
  → 미인증 → 로그인

3단계: 활성 게임 체크 (Session 게이트)
  → WAITING → 대기실
  → IN_PROGRESS → 게임
  → 없음 → 홈
```
