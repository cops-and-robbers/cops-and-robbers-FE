### 📌 작업 개요

Apple App Store 가이드라인 1.2 (UGC 필수 요구사항) 대응을 위해 채팅 기능에 **비속어 필터링**, **유저 신고**, **유저 차단** 기능을 추가. App Store 리젝 대응(#173)과 연계된 작업.

### 🎯 구현 목표

- 채팅 메시지 내 비속어/욕설 자동 마스킹 처리
- 메시지 롱프레스 → 컨텍스트 메뉴(복사/신고/차단) 표시
- 신고 카테고리 선택 및 확인 다이얼로그 제공
- 차단된 유저의 메시지 숨김 처리 (게임 세션 동안 유지)
- 다크모드(도둑팀) 스타일 전면 지원

### ✅ 구현 내용

#### 1. 비속어 필터링 (ProfanityFilter)
- **파일**: `lib/core/services/content_filter/profanity_filter.dart` (신규)
- **변경 내용**: 욕설/비하/스팸 키워드 목록을 보유한 정적 필터 클래스 구현. `filter()` 메서드로 메시지 내 금칙어를 `***`로 치환
- **적용 방식**: `ChatMessageDto`에 `filteredMessage` 확장 프로퍼티 추가 — 원본 `message`는 보존하고 UI 표시 시에만 필터링 적용

#### 2. 신고 카테고리 Enum
- **파일**: `lib/features/chat/domain/constants/report_categories.dart` (신규)
- **변경 내용**: `ReportCategory` enum 정의 — 낚시/도배, 욕설/비하, 사칭/사기, 광고/스팸, 부정행위, 팀 사기 저하, 기타(직접 작성) 7개 카테고리

#### 3. 채팅 컨텍스트 메뉴 (ChatContextMenu)
- **파일**: `lib/features/chat/presentation/widgets/chat_context_menu.dart` (신규)
- **변경 내용**: 메시지 롱프레스 시 표시되는 오버레이 메뉴 구현
  - **액션 모드**: 복사하기, 신고하기, 차단하기 (본인 메시지는 복사하기만 표시)
  - **신고 카테고리 모드**: 신고하기 탭 시 카테고리 선택 화면으로 전환
  - **기타(직접 작성)**: `TextSubmitPage`로 이동하여 사유 작성
  - 나머지 카테고리: `AppDialog` 확인 다이얼로그 표시 후 신고 접수
- **위치 계산**: `_MenuPositioner` 위젯으로 메뉴 크기 측정 후 메시지 위에 배치. 화면 밖 오버플로우 방지 로직 포함
- **스타일**: 다크모드 완전 지원 (배경색, 텍스트, 아이콘, 디바이더 색상)

#### 4. 유저 차단 기능
- **파일**: `lib/features/chat/presentation/providers/chat_provider.dart`
- **변경 내용**: `ChatState`에 `blockedParticipantIds` (Set<int>) 추가. `blockUser()` 메서드로 차단 ID 추가
- **적용 방식**: `ChatMessageList`에서 `blockedParticipantIds`로 메시지 필터링 — 차단 유저 메시지 렌더링 제외
- **유효 범위**: 게임 세션 동안만 유지 (로컬 상태), `disconnectChat()` 시 초기화

#### 5. 메시지 목록 차단 필터링
- **파일**: `lib/features/chat/presentation/widgets/chat_message_list.dart`
- **변경 내용**: `blockedParticipantIds` 파라미터 추가. 렌더링 전에 차단된 유저 메시지 필터링 처리. 읽지 않은 메시지 카운트에서도 차단 유저 제외

#### 6. 메시지 버블 롱프레스 지원
- **파일**: `lib/features/chat/presentation/widgets/chat_message_bubble.dart`
- **변경 내용**: `onLongPress` 콜백 추가. 버블 Container의 BuildContext를 전달하여 컨텍스트 메뉴가 정확한 위치에 표시되도록 구현. 표시 텍스트를 `filteredMessage`로 변경

#### 7. ChatOverlay 컨텍스트 메뉴 연결
- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`
- **변경 내용**: `ChatMessageList`에 `onMessageLongPress` 콜백 연결 → `ChatContextMenu.show()` 호출. `blockedParticipantIds` 전달

#### 8. 범용 텍스트 입력 페이지 (TextSubmitPage)
- **파일**: `lib/core/widgets/pages/text_submit_page.dart` (신규)
- **변경 내용**: 텍스트 입력 + 제출 버튼으로 구성된 범용 페이지 위젯. 신고 작성(기타 카테고리)과 버그 제보에서 재사용
- **특징**: `isDestructive` 옵션(빨간 버튼), 다크모드 지원, 입력 텍스트 유무에 따른 버튼 활성화, `Expanded+ScrollView`로 하단 고정 + 오버플로우 방지

#### 9. 설정 페이지 — 버그 제보 연결
- **파일**: `lib/features/settings/presentation/pages/settings_page.dart`
- **변경 내용**: 버그 제보 메뉴에서 `TextSubmitPage`를 재사용하여 버그 제보 페이지 연결

#### 10. 차단 아이콘 에셋 추가
- **파일**: `assets/icons/icon_block.svg` (신규)
- **변경 내용**: 차단 메뉴 및 차단 스낵바에서 사용하는 SVG 아이콘 추가

### 🔧 주요 변경사항 상세

#### 비속어 필터링 아키텍처
`ProfanityFilter`는 `core/services/` 하위에 배치. 채팅 외 다른 UGC 기능에서도 재사용 가능한 구조. `ChatMessageDto`의 extension으로 `filteredMessage` 프로퍼티를 제공하여 원본 데이터 보존 + 표시 시 마스킹 분리.

**특이사항**:
- 현재 로컬 하드코딩 단어 목록 사용. TODO로 서버 동적 로드 기능 예정
- 단순 `contains` + `replaceAll` 방식 — 초성 변형(ㅅㅂ) 포함하지만 우회 가능성 존재

#### 컨텍스트 메뉴 위치 계산
`_MenuPositioner`는 첫 프레임에서 투명하게 렌더링하여 크기를 측정한 뒤, 두 번째 프레임에서 정확한 위치에 배치. 메시지 위(AppSpacing.vertical8 간격)에 표시하며 화면 밖 오버플로우 시 보정 처리.

#### 차단 유저 메시지 처리
차단은 프론트엔드 로컬 상태로만 관리 (서버 API 미연동). `ChatState.blockedParticipantIds`에 participantId 추가 → `ChatMessageList`에서 렌더링 필터링 + `_handleUnreadUpdate`에서 읽지 않은 카운트 제외.
