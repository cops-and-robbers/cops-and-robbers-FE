### 📌 작업 개요

인게임 참가자 오버레이(ParticipantOverlay)에서 대기실과 동일한 **방장 우선 정렬** 및 **내 카드 볼드 강조**가 누락된 문제 수정. 추가로 다크모드에서 참가자 카드 닉네임 색상 가독성 개선.

### 🎯 구현 목표

- 인게임 참가자 오버레이에서 방장 우선 정렬 적용
- 내 카드 볼드 강조 처리 추가
- 대기실 ↔ 인게임 참가자 목록 표시 일관성 확보
- 다크모드 닉네임 색상 가독성 개선

### ✅ 구현 내용

#### 1. GameParticipantInfo에 hostParticipantId 필드 추가
- **파일**: `lib/features/session/presentation/providers/game_participant_provider.dart`
- **변경 내용**: `GameParticipantInfo` 데이터 클래스에 `hostParticipantId` 필드 추가, `copyWith` 반영, `setHostParticipantId()` 메서드 추가
- **이유**: 기존에는 `isHost`(bool)만 있어 방장 여부만 알 수 있었고, 방장의 participantId는 `waitingRoomParticipantsProvider`에만 존재. 이 provider는 `keepAlive`가 아니라 게임 화면 진입 시 auto-dispose되어 인게임에서 방장 ID 접근 불가

#### 2. 대기실에서 hostParticipantId 전달 및 동기화
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: `initFromLobby()` 호출 시 `hostParticipantId: lobbyInfo.hostParticipantId` 전달. `HOST_CHANGED` 이벤트 처리 시 `setHostParticipantId(newHostId)` 호출 추가
- **이유**: `GameParticipantNotifier`(keepAlive)에 방장 ID를 저장하여 게임 화면까지 유지되도록 보장

#### 3. 인게임 오버레이에 정렬 및 강조 적용
- **파일**: `lib/features/game/presentation/widgets/participant_overlay.dart`
- **변경 내용**: 경찰팀/도둑팀 TeamSection 호출 시 `hostParticipantId`와 `myParticipantId` 파라미터 추가 전달
- **이유**: TeamSection 내부의 기존 정렬 로직(`hostParticipantId` 기준 방장 우선)과 ParticipantCard의 볼드 강조 로직(`myParticipantId` 비교)이 이미 구현되어 있으나, 오버레이에서 해당 값을 전달하지 않아 동작하지 않았음

#### 4. 다크모드 닉네임 색상 조정
- **파일**: `lib/features/session/presentation/widgets/participant_card.dart`
- **변경 내용**: 다크모드 일반 닉네임 `AppColors.black300` → `AppColors.black100`, 다크모드 내 닉네임(방장 포함) `AppColors.black600` → `AppColors.black100` (볼드 유지)
- **이유**: 다크 배경에서 `black300`, `black600`은 가독성이 낮아 `black100`으로 변경하여 명확하게 표시

### 🔧 주요 변경사항 상세

#### game_participant_provider.dart
`GameParticipantInfo`에 `hostParticipantId` 필드 추가. `initFromLobby()`에 파라미터 추가하여 로비 조회 시 방장 ID 저장. `setHostParticipantId()` 메서드로 방장 변경 이벤트에 대응.

#### waiting_room_page.dart
`initFromLobby()` 호출부에 `hostParticipantId` 인자 추가. `HOST_CHANGED` 이벤트 핸들러에서 기존 `setIsHost()` 호출 직후 `setHostParticipantId()` 호출 추가하여 방장 변경 시 ID도 동기화.

#### participant_overlay.dart
`build()` 메서드에서 `gameParticipantNotifierProvider`로부터 `hostParticipantId` 읽어서 경찰팀/도둑팀 TeamSection에 전달. `myParticipantId`는 기존 `widget.myParticipantId` 활용.

#### participant_card.dart
닉네임 색상 조건에서 `isDarkMode` 분기 추가. 다크모드일 때 `isMe` 여부와 관계없이 `black100` 사용 (볼드 여부로 구분).

### 🧪 테스트 및 검증
- 대기실 → 인게임 전환 후 참가자 오버레이에서 방장이 맨 앞에 표시되는지 확인
- 내 카드가 볼드로 강조되는지 확인
- 방장 변경(HOST_CHANGED) 이벤트 발생 시 오버레이 정렬이 갱신되는지 확인
- 다크모드(도둑팀)에서 닉네임이 `black100`으로 표시되어 가독성 확보되는지 확인

### 📌 참고사항
- TeamSection의 정렬 로직은 **방장만 맨 앞**으로 이동하며, "나"에 대한 별도 정렬 순서는 없음 (볼드 강조로만 구분)
- `GameParticipantInfo`는 `keepAlive: true` provider이므로 게임 종료 시 `clear()` 호출로 정리됨
