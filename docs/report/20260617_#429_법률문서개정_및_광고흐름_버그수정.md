# #429 법률 문서 개정 및 광고 흐름 버그 수정

## 📌 작업 개요

AdMob·Firebase Analytics 연동(#429) 후속 작업으로, 세 가지 범주의 변경이 이루어졌다.

1. **법률 문서 개정** — 광고·분석 도입 사실을 반영해 개인정보 처리방침과 이용약관을 현행화(시행일 2026-06-29)
2. **게임 종료 광고 흐름 버그 수정** — 실기기에서 재현된 "광고 때문에 화면 이동 불가" 및 "홈 도착 후 대기방으로 튕김" 두 가지 버그를 구조적으로 제거
3. **앱 아이콘 디버그 가드** — 디버그 Android 환경에서 activity-alias 토글이 `flutter run`을 깨뜨리던 문제 방지

---

## 🔍 버그 분석 (광고 흐름)

**증상 1 — 화면 이동 불가**: 결과 다이얼로그의 "홈으로"·"한 번 더" 탭 후 광고 닫힘 콜백에서 라우팅을 시도할 때, `PopScope(canPop: false)` 다이얼로그가 여전히 스택에 있어 이동이 차단됨.

**증상 2 — 대기방 튕김**: "홈으로" 이동 후 홈의 활성 게임 안전망이 서버의 WAITING 참가 상태를 읽고 사용자를 다시 대기방으로 보냄. 서버는 게임 종료 후 세션을 재대결용 WAITING 상태로 되돌리면서 참가자를 그대로 유지하기 때문.

**증상 3 — no-fill 누락**: 광고 네트워크가 일시적으로 재고 없음(`No ad to show`)을 반환해도 재시도 없이 포기, 결과 화면 체류 시간 동안 노출 기회를 잃음.

## ✅ 구현 내용

### 1. 법률 문서 개정

- **파일**: `docs/legals/개인정보처리방침.md`, `assets/legals/privacy_policy.json`
- **변경 내용**: 총 10곳 수정
  - **⑧ 광고 및 분석 정보** 항목 신설: 광고 식별자(AAID/IDFA), 앱 인스턴스 ID, 이벤트 로그 등 수집 사실 명시
  - **위탁 섹션**: Google(Firebase Analytics, Google Mobile Ads) SDK 블록 추가, 수집 항목·이전 목적 갱신
  - **국외이전·보유기간·이용자 권리** 섹션: 광고 식별자 관련 내용 반영
  - 기존 "행태정보·광고 식별자 기반 맞춤형 광고나 추적을 하지 않습니다"라는 허위 문구 제거 및 정확한 고지로 교체
  - iOS/Android opt-out 경로(OS 설정에서 광고 ID 재설정·맞춤 광고 해제) 안내 추가

- **파일**: `docs/legals/이용약관.md`, `assets/legals/terms_of_service.json`
- **변경 내용**: 총 3곳 수정
  - **제5조 ③**: "향후 광고가 게재될 수 있음" → "광고를 게재하며, 광고 식별자 등 처리는 개인정보 처리방침에 따름"으로 현재형 전환
  - **제7조 ⑥**: "위치 정보를 광고 목적으로 이용하지 않는다"는 사실 명시 추가(GPS는 게임 전용, 광고 SDK 처리 정보와 연결하지 않음)
  - 시행일: 2026년 6월 29일

- **이유**: 앱이 `assets/legals/*.json`을 `rootBundle.loadString`으로 렌더링하므로 JSON이 실제 정본이다. 마크다운은 원본 문서로 JSON과 동기화 유지.

### 2. 게임 종료 광고 흐름 리팩토링 — navigate-first 패턴

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `_exitGameAfterAd()` 메서드 도입
  - 기존: 광고 닫힘 콜백에서 `context.go()` 호출 → 콜백 유실·가드 차단 시 사용자가 갇힘
  - 변경: `context.go(destination)` 먼저 실행 → 광고를 그 위에 표시 → 광고 닫힘 시 별도 처리 없음
  - `_exitTriggered` 플래그로 다중 탭 이벤트 중복 방지
  - "홈으로" 선택 시 `_requestLeaveGameSilently()` 호출(fire-and-forget)로 서버에서 참가 상태 정리

### 3. `game_over_guard.dart` — shouldRequestLeaveGameAfterGameOver 활성화

- **파일**: `lib/features/game/presentation/helpers/game_over_guard.dart`
- **변경 내용**: `shouldRequestLeaveGameAfterGameOver()` 반환값 `false → true`
- **이유**: 서버가 게임 종료 후에도 참가자를 WAITING 대기방에 유지하는 설계이므로, "홈으로" 이탈 시 퇴장 API를 명시적으로 호출해야 활성 게임 안전망(스플래시 복구·홈 안전망·resume 체크)이 대기방으로 되돌리는 레이스를 막을 수 있다.

---

### 4. `app_router.dart` / `home_page.dart` — fromGameExit 파라미터

- **파일**: `lib/router/app_router.dart`, `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**
  - "홈으로" 목적지를 `/home?fromGameExit=true`로 설정
  - `app_router.dart`에서 쿼리 파라미터를 파싱해 `HomePage(skipActiveGameCheck: true)` 전달
  - `home_page.dart`에서 `skipActiveGameCheck`가 `true`면 활성 게임 안전망을 1회 건너뜀
- **이유**: 퇴장 API가 비행 중일 수 있어, leave 완료 전 홈 진입 시 stale WAITING 상태를 읽어 대기방으로 되돌리는 레이스를 1회 차단하기 위함.

---

### 5. `ad_service.dart` — no-fill 백오프 재시도

- **파일**: `lib/core/services/ads/ad_service.dart`
- **변경 내용**: `preloadGameEndInterstitial()`에 최대 3회 지수 백오프(2초 → 4초) 재시도 추가
  - 첫 시도 no-fill 시 2초 대기 후 재시도, 그래도 no-fill이면 4초 대기 후 마지막 시도
  - 3회 모두 실패해도 `_isLoading = false`로 정리 후 fail-open 처리(이탈 흐름 차단 없음)
  - `retryBaseDelay` 생성자 파라미터로 테스트 시 `Duration.zero` 주입 가능

---

### 6. `locale_app_icon_observer.dart` — 디버그 Android 가드

- **파일**: `lib/core/services/app_icon/locale_app_icon_observer.dart`
- **변경 내용**: `startLocaleAppIconObserver()`에 `kDebugMode && Android` 조건 추가 시 `null` 반환(옵저버 미등록)
- **이유**: 디버그 빌드에서 activity-alias 토글이 기본 런처 alias를 비활성화하면 이후 `flutter run`이 "Activity class does not exist (Error type 3)"로 실패함. 릴리스·프로파일 빌드와 iOS 디버깅에는 영향 없음.

## 📌 참고사항

- **앱 정본은 JSON**: `assets/legals/privacy_policy.json`, `assets/legals/terms_of_service.json`이 앱 내 렌더링 정본이고, `docs/legals/*.md`는 원본 문서. 스토어 정책 URL이 가리키는 Google Sites 웹 버전도 같은 내용으로 별도 업데이트가 필요하다.
- **출시 운영 순서**: 웹 게시(Google Sites) → 앱 심사 → 2026-06-29 이후 `ads_enabled` Remote Config `true` 전환
- **광고 opt-out**: 맞춤형 광고는 이용자 동의·OS 설정에 따르며, 위치 정보는 광고 SDK에 연결하지 않는다(GPS는 게임 전용).
- `_exitTriggered` 플래그는 `_showFallbackResultDialog`, `_showGameOverDialog` 두 경로 모두에서 공유되므로 중복 광고 노출이나 이중 이탈 이벤트 기록을 방지한다.
