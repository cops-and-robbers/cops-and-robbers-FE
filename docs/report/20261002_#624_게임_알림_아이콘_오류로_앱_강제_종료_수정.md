### 📌 작업 개요
Android 게임 진행 알림(id=1001) 표시 중 앱이 강제 종료되는 문제 수정. 알림 small icon 벡터(`ic_stat_notification.xml`)의 `pathData`를 모양 변경 없이 축약해 AAPT 문자열 한도 아래로 낮춤.

**보고서 파일**: `docs/report/20261002_#624_게임_알림_아이콘_오류로_앱_강제_종료_수정.md`

### 🔍 문제 분석
- `pathData` 문자열이 34,747바이트로 AAPT UTF-8 문자열 한도(32,767바이트) 초과
- 초과한 값은 패키징 때 `STRING_TOO_LARGE`로 치환됨. 수정 전 APK에서 `android:pathData="STRING_TOO_LARGE"` 확인
- SystemUI가 알림 아이콘을 만들 때 벡터 파서가 `R is not a valid verb`로 실패 → 포그라운드 서비스 알림 오류(`BadForegroundServiceNotificationException`)로 앱 프로세스 종료
- 같은 아이콘을 게임 알림(`GameSessionNotification`, `GameSessionForegroundService`), FCM 기본 아이콘(`AndroidManifest.xml`), 로컬 알림(`local_notifications_service.dart`)이 함께 사용

### ✅ 구현 내용

#### 알림 아이콘 벡터 경로 축약
- **파일**: `android/app/src/main/res/drawable/ic_stat_notification.xml`
- **변경 내용**: `pathData`의 불필요한 소수점 `.00`과 공백 제거. 34,747 → 17,323바이트
- **이유**: 경로 값은 그대로 두고 표기만 줄여 아이콘 모양 유지

#### 한도 주석 추가
- **파일**: `android/app/src/main/res/drawable/ic_stat_notification.xml`
- **변경 내용**: 파일 상단 주석에 "`pathData`는 32,767바이트 미만으로 유지" 사유 추가
- **이유**: 이후 아이콘 교체 시 같은 한도 초과 재발 방지

### 🔧 주요 변경사항 상세

#### pathData 축약 방식
숫자 값과 명령 문자 순서를 바꾸지 않고 `.00` 표기와 중복 공백만 제거. 수정 전후 경로의 숫자 값 시퀀스(4,352개)가 동일함을 대조해 확인. fill rule(`evenOdd`)·크기·색상(`#FFFFFF`) 변경 없음.

**특이사항**:
- 17,323바이트로 한도 대비 여유는 약 47%. 더 복잡한 경로로 교체하면 다시 초과할 수 있음
- Android 네이티브 알림·포그라운드 서비스 코드는 변경 없음

### 🧪 테스트 및 검증
- 수정 전후 `pathData` 바이트 수 및 숫자 값 시퀀스 대조: 일치
- `flutter build apk --debug --no-pub` 통과
- 수정 APK의 `pathData`가 소스와 동일하고 `STRING_TOO_LARGE`가 없음을 확인
- 에뮬레이터(Android 15 / API 35)에 수정 APK 설치 후 `Icon.loadDrawable`·Canvas 렌더링 통과(비투명 픽셀 1,976개)
- 게임 재진입·플레이 중 알림 표시와 크래시 미발생: **미확인** (빌드·아이콘 렌더링 검증을 전체 플레이 검증으로 보지 않음)
