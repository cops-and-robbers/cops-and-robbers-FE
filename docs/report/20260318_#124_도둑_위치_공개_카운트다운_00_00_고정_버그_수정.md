### 📌 작업 개요

게임 중 "다음 도둑 위치 공개까지" 카운트다운이 00:00에 도달한 후 다음 주기로 자동 리셋되지 않고 00:00에 고정되는 버그 수정. 클라이언트 측에서 위치 공유 간격(n분)에 맞게 자동 순환 카운트다운 로직 추가. 부가적으로 iOS 위치 권한 및 알림 안내 문구 개선.

---

### 🔍 문제 분석

**근본 원인**: `LocationRevealCountdown` 위젯이 서버에서 전달받은 `nextRevealTime`만 단순 비교하여 남은 시간을 계산. 카운트다운이 0 이하가 되면 `Duration.zero`로 고정되어 00:00 표시.

**문제 코드 (수정 전)**:
```dart
final diff = widget.nextRevealTime!.difference(DateTime.now());
_remaining = diff.isNegative ? Duration.zero : diff;
```

- `nextRevealTime`이 과거 시각이 되면 항상 `Duration.zero` 반환
- 서버에서 `LOCATION_REVEAL` 이벤트를 수신해야만 `nextRevealTime`이 갱신됨
- 서버 응답이 지연되면 카운트다운이 00:00에 멈춰 보이는 현상 발생

### ✅ 구현 내용

#### 1. 카운트다운 자동 순환 로직 추가
- **파일**: `lib/features/game/presentation/widgets/location_reveal_countdown.dart`
- **변경 내용**: `intervalMinutes` 파라미터 추가 및 `_update()` 메서드에 자동 순환 로직 구현
- **이유**: 서버 이벤트 수신 여부와 관계없이 클라이언트 측에서 다음 주기를 자동 계산하여 카운트다운이 끊김 없이 순환

#### 2. GamePage에서 interval 전달
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `LocationRevealCountdown` 위젯에 `intervalMinutes: interval` 파라미터 전달
- **이유**: 게임 설정의 위치 공유 간격 값을 카운트다운 위젯에 연결

#### 3. iOS 위치 권한 및 알림 안내 문구 개선
- **파일**: `ios/Runner/Info.plist`, `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: 위치 정보 사용 목적과 공유 범위를 구체적으로 설명하는 문구로 변경
- **이유**: 사용자에게 위치 정보 수집 목적, 공유 대상, 중단 시점을 명확히 안내

### 🔧 주요 변경사항 상세

#### LocationRevealCountdown 위젯 (`location_reveal_countdown.dart`)

`intervalMinutes` 파라미터를 새로 추가하여 위치 공유 간격(분)을 전달받도록 수정.

`_update()` 메서드에 while 루프 기반 자동 순환 로직 추가:
```dart
var target = widget.nextRevealTime!;
final interval = widget.intervalMinutes;
if (interval != null && interval > 0) {
  final intervalDuration = Duration(minutes: interval);
  while (target.isBefore(DateTime.now())) {
    target = target.add(intervalDuration);
  }
}
```

- `nextRevealTime`이 과거 시각이면 `intervalMinutes`만큼 반복 더해서 미래 시점의 다음 주기를 계산
- 서버 이벤트가 지연되어도 클라이언트 측에서 자동으로 다음 카운트다운 시작
- `intervalMinutes`가 null이거나 0 이하이면 기존 동작 유지 (하위 호환)

#### GamePage (`game_page.dart`)

`LocationRevealCountdown` 위젯 생성 시 `intervalMinutes: interval` 전달 추가 (1줄 변경)

### 🧪 테스트 및 검증

- 게임 시작 후 카운트다운이 00:00에 도달했을 때 자동으로 다음 주기로 넘어가는지 확인
- 서버 `LOCATION_REVEAL` 이벤트 지연 시에도 카운트다운이 멈추지 않고 순환하는지 확인
- `intervalMinutes`가 null인 경우 기존 동작(00:00 고정)과 동일하게 동작하는지 확인
- 앱이 백그라운드에서 복귀 시 `didChangeAppLifecycleState`에서 정확한 남은 시간 재계산 확인
- iOS 위치 권한 요청 시 변경된 문구가 정상 표시되는지 확인

### 📌 참고사항

- `while` 루프로 순환 계산하므로, `intervalMinutes`가 매우 작은 값이고 `nextRevealTime`이 먼 과거인 경우 반복 횟수가 증가할 수 있으나, 실제 게임 시나리오에서는 문제 없는 수준
- 서버에서 `LOCATION_REVEAL` 이벤트가 도착하면 `nextRevealTime`이 갱신되어 자연스럽게 서버 시각 기준으로 동기화됨
