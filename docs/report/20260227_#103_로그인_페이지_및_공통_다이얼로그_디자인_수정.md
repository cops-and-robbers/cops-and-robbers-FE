### 📌 작업 개요

디자이너 검수에서 발견된 로그인 페이지 및 공통 다이얼로그(AppDialog/AppPopup) UI 불일치 수정.
다이얼로그 간격 커스터마이징을 위한 `DialogSpacing` 클래스 도입, `AppPopup` 자동 종료 기능 추가, `CountdownTimerContent` 위젯 신규 구현.
CodeRabbit 리뷰 피드백 반영하여 타이머 안전성 및 카운트다운 동기화 개선.
PaginationBar를 플로팅 스타일로 전면 개편하고, NoticesPage 레이아웃을 Stack 기반으로 변경하여 safe area를 반영.

### 🎯 구현 목표

- AppDialog 키보드 올라올 때 다이얼로그 과도한 상승 방지
- 다이얼로그별 섹션 간격을 유연하게 조절할 수 있는 구조 도입
- AppPopup에 자동 종료(autoCloseDuration) 기능 추가
- 카운트다운 타이머 위젯 구현 (게임 시작 대기 등에 활용)
- 개발자 도구 FAB를 로그인 페이지에서 홈 페이지로 이동
- 코드 리뷰에서 발견된 dead code, 메모리 누수, 디자인 시스템 불일치 정리
- PaginationBar 플로팅 스타일 적용 (pill radius, shadow, SVG 아이콘)
- NoticesPage Stack 레이아웃 전환 및 safe area 반영

### ✅ 구현 내용

#### 1. DialogSpacing 클래스 도입
- **파일**: `lib/core/widgets/dialogs/dialog_spacing.dart` (신규)
- **변경 내용**: `@immutable` 클래스로 4개 간격 포인트(`avatarToTitle`, `titleToMessage`, `toContent`, `toButtons`) 오버라이드 지원
- **이유**: 특정 다이얼로그에서만 간격 조절이 필요한 상황 대응. 기존 `contentSpacing` 단일 파라미터로는 유연성 부족

#### 2. AppDialog 디자인 수정 및 리팩토링
- **파일**: `lib/core/widgets/dialogs/app_dialog.dart`
- **변경 내용**:
  - 키보드 인셋 반영률 100% → 40%로 축소 (다이얼로그 과도한 상승 방지)
  - 컨테이너 좌우 패딩 16→12로 축소, 메시지 영역 좁은 패딩 적용

  - `show()`와 `confirm()` 정적 메서드의 `showGeneralDialog` 보일러플레이트를 `_buildAndShow` 공용 래퍼로 추출 (DRY)
  - DartDoc에 `DialogSpacing` 사용 예시 추가
- **이유**: 디자인 시안 반영 및 다이얼로그 간격 유연성 확보

#### 3. AppPopup 자동 종료 기능
- **파일**: `lib/core/widgets/dialogs/app_popup.dart`
- **변경 내용**:

  - `autoCloseDuration` 설정 시 `barrierDismissible` 자동 false 처리
  - `PopScope(canPop: false)`로 뒤로가기 버튼 차단
  - 타이머 콜백에 `ModalRoute.of(context)?.isCurrent` 검증 추가 (다른 라우트가 위에 있을 때 잘못된 pop 방지)
- **이유**: 게임 종료, 카운트다운 등 일정 시간 후 자동으로 닫히는 팝업 필요

#### 4. CountdownTimerContent 위젯
- **파일**: `lib/core/widgets/dialogs/countdown_timer_content.dart` (신규)

### 🔧 주요 변경사항 상세

#### DialogSpacing 구조
```
avatarToTitle  — 아바타 ↔ 타이틀 (기본: vertical16)
titleToMessage — 타이틀 ↔ 메시지 (기본: vertical12)
toContent      — 메시지/타이틀 ↔ 커스텀콘텐츠 (기본: message 유무에 따라 vertical12 또는 vertical20)
toButtons      — 콘텐츠 ↔ 버튼 (기본: vertical20)
```
각 필드가 null이면 기본값 사용. 특정 다이얼로그에서만 필요한 간격을 오버라이드.

#### AppPopup 타이머 안전성
타이머 대기 중 다른 다이얼로그/화면이 push된 경우, `ModalRoute.of(context)?.isCurrent` 검증으로 현재 라우트가 팝업일 때만 pop 실행. 다른 라우트를 실수로 닫는 버그 방지.

#### CountdownTimer 동기화
기존: `_remainingSeconds`가 0이 된 뒤 **다음 tick**(1초 후)에 onComplete 호출
수정: 감소 직후 0 체크하여 즉시 onComplete 호출. autoCloseDuration과 정확히 동기화.

#### PaginationBar 슬라이딩 윈도우 알고리즘
```
totalPages ≤ 5  → 모든 페이지 표시
page 0~1        → [0, 1, 2, ···, last]        (5 slots)
page last-1~last→ [0, ···, n-3, n-2, n-1]    (5 slots)
그 외            → [···, prev, curr, next, ···] (5 slots)
```
모든 경우 동일한 슬롯 수를 유지하여 바 크기가 일정하게 고정.

#### NoticesPage safe area 처리
```dart
final bottomSafeArea = MediaQuery.paddingOf(context).bottom;
final paginationBottomOffset = AppSpacing.vertical16 + bottomSafeArea;
```
프로젝트 내 다른 페이지(`login_page.dart`, `game_page.dart`)의 safe area 패턴을 참고하여 `MediaQuery.paddingOf` 사용. 제스처 내비게이션 바가 있는 디바이스에서도 페이지네이션 바가 시스템 UI와 겹치지 않음.

**특이사항**:
- 개발자 도구 FAB는 현재 릴리즈 빌드에서도 표시됨 (디자이너 확인용). 추후 `kDebugMode` 가드 적용 예정
- `AppPopup`의 `42.h` 패딩은 AppSpacing에 없는 비표준값 (별도 이슈로 정규화 권장)
