### 📌 작업 개요

커뮤니티 네이티브 광고 슬롯이 로드 결과에 따라 사라지며 목록 위치가 바뀌던 동작을 개선했다.
광고가 활성화된 동안 최초 프레임부터 122pt 공간을 예약하고, 로딩·성공·실패 상태를 같은 크기 안에서 전환하도록 구성했다. 전역 광고 스위치 아래에는 커뮤니티 광고와 게임 종료 광고를 각각 제어하는 하위 스위치를 추가했다.

### 🎯 구현 목표

- 광고 로딩 전후의 목록 레이아웃 시프트 방지
- 로딩 중 스켈레톤, 성공 시 광고, 실패 시 앱 안내 카드 제공
- 초기화 또는 광고 응답이 지연돼도 예약한 공간과 다음 콘텐츠 위치 유지
- 전역 광고 제어를 유지하면서 커뮤니티와 게임 종료 광고를 독립적으로 중단 가능
- 운영 설정과 광고 상태 전환 규칙 문서화 및 회귀 테스트 추가

### ✅ 구현 내용

#### 122pt 광고 공간 예약

- **파일**: `lib/features/community/presentation/widgets/community_native_ad.dart`
- **변경 내용**: 광고 활성 상태에서 로드 완료를 기다리지 않고 고정 높이 컨테이너를 즉시 표시. 기본 글자 크기에서는 120pt 미디어 높이에 상하 1pt 경계 여유를 더한 122pt 사용
- **이유**: 광고가 늦게 나타나거나 실패해도 뒤따르는 모집글, 채팅방 및 댓글의 화면 위치가 움직이지 않도록 보장

접근성 글자 확대 시에는 제목, 본문, 메타데이터 3행에 필요한 높이를 계산해 122pt보다 큰 값을 사용한다. 슬롯의 외부 여백과 카드 장식도 상태 전환 동안 동일하게 유지한다.

#### 로딩 스켈레톤과 성공 광고 교체

- **파일**: `lib/features/community/presentation/widgets/community_native_ad.dart`
- **변경 내용**: 광고 상태를 `loading`, `loaded`, `fallback`으로 구분. 로딩 중 텍스트와 미디어 자리의 스켈레톤을 표시하고 성공 콜백 수신 시 같은 컨테이너 안의 `AdWidget`으로 교체
- **이유**: 빈 영역 대신 로딩 상태를 명확히 보여 주면서 콘텐츠 위치와 광고 카드 크기를 유지

스켈레톤은 기기의 애니메이션 줄이기 설정을 따르고 접근성 읽기 대상에서 제외한다. 광고가 로드되면 15초 타이머를 취소한 뒤 광고 표시 상태로 전환한다.

#### 실패·무응답 대체 카드

- **파일**: `lib/features/community/presentation/widgets/community_native_ad.dart`
- **변경 내용**: SDK 초기화 실패, 광고 로드 실패, 예외 또는 15초 동안 응답이 없는 경우 동일 크기의 모집글 작성 카드로 전환. 카드를 누르면 기존 커뮤니티 모집글 작성 화면으로 이동
- **이유**: 광고 재고나 SDK 상태와 관계없이 예약한 공간을 유용한 앱 내부 진입점으로 대체하고 레이아웃 시프트 방지

대체 전환 시 진행 중인 타이머를 취소하고 보유한 광고 객체를 해제한다. 15초 이후 도착한 초기화 결과는 상태 확인으로 무시하며, 화면 이탈 시에도 타이머와 광고 객체를 정리한다. 대체 카드는 광고 배지를 표시하지 않는다.

#### 광고 OFF 시 슬롯 제거

- **파일**: `lib/features/community/presentation/widgets/community_native_ad.dart`
- **변경 내용**: 전역 또는 커뮤니티 하위 스위치가 꺼지면 광고, 스켈레톤, 대체 카드와 여백을 모두 제거
- **이유**: 원격 스위치의 중단 의도를 즉시 반영하고 비활성 상태에서 광고용 공간을 남기지 않도록 처리

광고가 활성화된 동안에는 상태 변화와 관계없이 다음 콘텐츠 위치를 유지한다. 운영 중 스위치를 OFF로 변경해 슬롯 자체를 제거하는 경우에는 목록 위치가 바뀔 수 있다.

#### 전역·하위 Remote Config 스위치 분리

- **파일**: `lib/core/services/remote_config/remote_config_keys.dart`, `lib/core/services/remote_config/remote_config_service.dart`, `lib/core/services/ads/ad_service.dart`
- **변경 내용**:
  - `ads_enabled`: 모든 광고의 상위 스위치 유지
  - `community_ads_enabled`: 커뮤니티 목록·상세 네이티브 광고 제어
  - `game_end_ads_enabled`: 게임 종료 전면 광고 제어
  - Remote Config 실시간 활성화 이벤트를 각 광고 Provider에 전달
- **이유**: 긴급 중단용 전역 스위치를 유지하면서 광고 영역별로 노출을 독립 제어

전역 스위치 기본값은 `false`, 두 하위 스위치 기본값은 `true`다. 하위 키가 아직 게시되지 않은 환경에서도 기존 전역 스위치 기반 동작을 유지한다. 커뮤니티 광고는 전역과 커뮤니티 하위 스위치가 모두 활성화돼야 슬롯을 만든다.

#### 게임 종료 광고 게이트

- **파일**: `lib/core/services/ads/ad_service.dart`
- **변경 내용**: 게임 종료 광고 서비스의 활성 조건을 `ads_enabled`와 `game_end_ads_enabled`의 조합으로 변경. 사전 로드와 실제 표시 직전에 같은 조건 확인
- **이유**: 사전 로드 이후 설정이 변경돼도 이미 로드된 광고가 노출되지 않도록 최종 표시 경로까지 제어

게이트가 닫혀 있거나 광고가 준비되지 않은 경우 완료 콜백을 즉시 실행해 게임 종료 이후 이동을 막지 않는다. 로드·표시 예외에서도 기존 fail-open 동작을 유지한다.

#### 운영 문서 추가

- **파일**: `docs/COMMUNITY_ADS.md`
- **변경 내용**: 세 Remote Config 키의 기본값과 적용 범위, 슬롯 상태별 표시 규칙, 화면별 배치 및 OFF 시 동작 문서화
- **이유**: 콘솔 설정과 클라이언트 상태 전환의 관계를 한 문서에서 확인할 수 있도록 정리

### 🔧 주요 동작 흐름

1. 커뮤니티 슬롯이 `ads_enabled`와 `community_ads_enabled`를 확인한다.
2. 두 스위치가 활성화되면 122pt 카드와 로딩 스켈레톤을 즉시 표시한다.
3. 기존 광고 서비스의 SDK 초기화 후 네이티브 광고를 요청한다.
4. 성공하면 같은 공간의 스켈레톤을 광고로 교체한다.
5. 초기화 실패, 로드 실패, 예외 또는 15초 무응답이면 같은 공간을 모집글 작성 카드로 교체한다.
6. 전역 또는 커뮤니티 스위치가 꺼지면 슬롯 전체를 제거한다.

게임 종료 광고는 `ads_enabled`와 `game_end_ads_enabled`가 모두 활성화된 경우에만 사전 로드하며, 실제 표시 직전에도 같은 게이트를 다시 검사한다.

### 📦 의존성 변경

- 새 패키지 의존성 없음
- 기존 광고 SDK, Riverpod, Remote Config, `shimmer` 및 앱 디자인 토큰 재사용
- 광고 단위 ID와 운영 식별 정보는 보고서에 포함하지 않음

### 🧪 테스트 및 검증

- 관련 테스트 18개 통과
- 네이티브 광고 성공·실패 전환 후 다음 콘텐츠 위치 유지 확인
- SDK 초기화 실패와 15초 무응답에서 같은 크기의 모집글 작성 카드 전환 확인
- 늦게 완료된 초기화 결과 무시 및 대기 중 화면 제거 시 예외 없음 확인
- 커뮤니티 하위 스위치 OFF 시 슬롯과 여백 제거 확인
- 게임 종료 광고의 상위·하위 스위치 조합과 사전 로드·표시 게이트 확인
- 정적 분석 통과
- 전체 테스트 1,234개 통과, 기존 커뮤니티 정렬창의 37px 오버플로 6개 실패
- 실제 기기 확인은 수행하지 않음

### 📌 참고사항

- 광고 활성 상태에서 로딩·성공·실패 전환은 카드 크기를 유지한다.
- Remote Config로 슬롯을 OFF하면 광고 관련 UI와 공간을 모두 제거하므로 목록 위치가 바뀔 수 있다.
- 대체 카드는 광고가 아니며 광고 표기 없이 기존 모집글 작성 경로를 사용한다.
- 하위 스위치는 기능별 제어용이며 `ads_enabled`가 꺼져 있으면 광고를 표시하지 않는다.
