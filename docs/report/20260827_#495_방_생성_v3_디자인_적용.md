### 📌 작업 개요

방 생성에 v3 시안을 적용하고 생성 흐름을 정리했다.

생성을 누르면 바로 플레이그라운드 지도로 들어가고, 감옥 지도와 기본 정보 입력을 거쳐 최종 확인에서 방을 만든다. 설정 네 개는 슬라이더 대신 화면에 고정된 숫자 키패드로 한 항목씩 묻고, 답한 항목이 아래로 쌓인다.

- 커밋 4개 / 파일 29개 / +2245 −1246
- `flutter analyze` 에러 · 경고 0, 테스트 787개 통과

### 🎯 구현 목표

- 생성을 누르면 바로 시작되게 한다. 버튼만 있는 허브 화면을 없앤다
- 설정 입력을 시안대로 숫자 키패드 방식으로 바꾸고, 한 화면에서 한 항목씩 묻는다
- 어긋난 설정 조합을 방 생성하기 이후가 아니라 입력 시점에 잡는다
- 최종 확인에서 어느 항목이든 바로 고치러 갈 수 있게 한다

### ✅ 구현 내용

#### 공용 위젯 3종

- **파일**: `number_pad.dart`, `setting_field_card.dart`, `keypad_cta_button.dart` 신규
- **변경 내용**: 화면 하단 고정 숫자 키패드(빠른 추가 칩 포함), 설정 항목 카드(활성·완료·제안값 상태), 키패드 위 전폭 버튼
- **이유**: 방 생성과 대기실 설정 수정이 같은 입력 방식을 쓴다. 키패드는 값 해석을 하지 않고 입력 이벤트만 올려, 두 화면이 다른 정책을 얹을 수 있다

치수와 색은 시안 실측값이다. 카드 56(힌트 있으면 78), 키패드 영역 361, 칩 114x34 라운드 9, 전부 앱 팔레트 토큰이다.

#### 설정 값 편집 규칙 분리

- **파일**: `game_setting_values_editor.dart` 신규
- **변경 내용**: 값 4개와 입력 상태를 순수 Dart 로 분리했다. 항목 활성화 직후 첫 숫자는 값을 교체하고, 상한을 넘는 이어치기는 무시하며, 빠른 추가는 상한에서 멈춘다
- **이유**: 제안값을 지우고 다시 칠 필요가 없어야 한다. 규칙이 위젯 밖에 있어 두 화면이 공유하고 단위 테스트가 붙는다

상한을 넘는 입력은 조용히 무시하지 않는다. 카드 힌트에 이유("최대 150명까지 설정할 수 있어요")를 띄우고 일반 키보다 무거운 진동을 준다. 자동 보정(155 → 150)은 치지 않은 숫자가 화면에 나타나므로 쓰지 않았다.

위치 공유 간격과 경찰 시작 시간은 게임 시간보다 짧아야 한다. 게임 시간을 나중에 줄이면 이미 답한 항목이 빨간 경고로 바뀌고 완료가 막힌다. 서버 검증은 안전망으로 그대로 둔다.

#### 기본 정보 화면 (한 항목씩 쌓기)

- **파일**: `basic_settings_form.dart` 신규
- **변경 내용**: 새 질문이 위에 나타나고 답한 항목이 아래로 밀린다. 기본값은 연한 색으로 채워 두고, 답한 카드를 탭하면 제자리에서 다시 수정한다
- **이유**: 필드가 밑으로 쌓이면 스크롤이 생긴다. 키패드는 닫히지 않는 화면 고정 부품이라, 탭은 키패드의 과녁만 바꾼다

뒤로 가기는 맨 위 질문을 접는다. 카드 탭이 제자리 수정이라면 뒤로 가기는 흐름 한 단계 취소다. 접힌 항목의 값은 남아 있어 다시 나아가면 복원된다. 탭으로 고치러 내려간 상태의 뒤로 가기는 수정 취소로 동작한다.

#### 생성 흐름 재배치

- **파일**: `session_creation_flow_page.dart` 재작성, `app_router.dart`, 지도 2페이지
- **변경 내용**: 허브(step 0) 제거. 생성 즉시 플레이그라운드 지도 진입, 감옥까지 마치면 기본 정보, 그 다음 최종 확인이다. 진행 표시는 3칸이고 지도 화면 상단에도 붙는다
- **이유**: 첫 화면이 아무것도 묻지 않는 버튼 허브였다. 플레이그라운드 완료 후 감옥으로 자동 연결되는 기존 동선과도 어긋나 있었다

핀을 그리다 나갈 때만 이탈 확인을 띄운다. 원형은 그린 노력이 없어 바로 나간다. 고칠 초기 도형이 있으면 나가도 원래 도형이 남으므로 묻지 않는다.

#### 최종 확인이 수정 허브를 겸한다

- **파일**: `zone_list_card.dart`, `setting_list_card.dart` 행 탭 추가
- **변경 내용**: 구역 행 탭은 해당 지도로, 설정 행 탭은 그 항목만 활성화된 기본 정보로 연다. 확인을 누르면 바로 되돌아온다. 플레이그라운드를 다시 그리면 감옥 설정으로 자동 연결된다
- **이유**: 수정하려고 뒤로 가기로 전 화면을 되짚는 구조를 없앤다

항목 수정 모드에서는 확인을 눌러야 값이 반영된다. 뒤로 가기는 수정 취소다. 최종 확인에서 뒤로 가면 네 항목이 펼쳐진 기본 정보로 돌아가고, 거기서 계속 되짚어 지도까지 갈 수 있다.

#### 대기실 설정 수정 화면 전환

- **파일**: `game_settings_edit_page.dart` 재작성
- **변경 내용**: 슬라이더를 걷어내고 카드 + 키패드로 바꿨다. 저장은 값이 유효한 동안 항상 활성이고, 바뀐 것이 없으면 호출 없이 닫는다
- **이유**: 생성과 수정이 같은 입력 방식을 써야 한다. 무변경 저장의 즉시 닫기는 닉네임 설정 화면과 같은 방식이다

다크(도둑 테마)는 앱의 기존 문법을 따랐다. 어두운 면 + 초록 액센트, 밝은 초록 면은 주 버튼 하나, 값 표기는 Moneygraphy, 비활성 버튼은 대기실 시작 버튼과 같은 모습이다.

#### 정리

- 생성 흐름 코치마크 2종 제거. "먼저 플레이그라운드를 지정하세요"와 "숫자를 탭하면 직접 입력할 수 있어요"는 화면이 스스로 설명하지 못하던 부분을 말풍선으로 때운 것이었고, 새 구조에서는 그 내용이 화면 자체가 됐다. 지도 튜토리얼은 유지했다
- 스텝 위젯 4종 삭제, 아무 데서도 읽지 않는 게임 설정 상수 9개 제거 (실제 상한과 다른 `maxPlayers = 30` 포함)
- l10n 라벨을 시안 카피로 갱신(게임 시간, 경찰 시작 시간, 도둑 시작 후), 안 쓰는 키 11개 제거, ko·en·ja 동기화

### 🔧 주요 변경사항 상세

#### 인원 상한 150명

참여 인원 상한을 50에서 150으로 늘렸다. 서버의 `@Max` 도 함께 150으로 바뀌며, 이 PR 은 서버 반영과 같이 머지한다.

#### 임시 저장은 지도 위에 그려서 복원한다

숫자는 지난 값을 연한 색 제안값으로 조용히 복원한다. 구역은 화면을 건너뛰지 않고 지도를 열 때 이전 도형이 그려진 채로 연다. 그대로 쓰려면 완료만 누르면 되고, 오래된 구역이 눈에 보이므로 확인 없이 방이 만들어지는 일이 없다.

### 📎 이번 범위에서 제외

**카드 등장 애니메이션** - 쌓임 높이 전환(250ms)까지 넣었다. 새 카드가 위에서 미끄러져 들어오는 연출은 후속에서 다듬을 수 있다.
