### 📌 작업 개요
게임 시작 직후 내 역할과 미션을 큰 배너로 보여 주고, 경찰 대기 시간과 도둑의 처음 12초 동안 규칙을 한 장면 안에서 읽게 하는 시작 흐름 추가. 경찰 출동 순간은 배너와 팀별 진동으로 알림. 이벤트 게임은 기존 동작 유지.

**보고서 파일**: `docs/report/20261016_#634_게임_시작_역할_배너와_경찰_대기_화면_추가.md`

### 🎯 구현 목표
- 시작 시 역할 배너(팀색 사선 줄무늬 띠, 캐릭터, 팀 이름, 미션)를 약 3.7초 표시. 탭하면 바로 닫힘
- 경찰: 기존 대기 팝업을 대신하는 대기 화면 (남은 시간, 멀어지는 도둑, 3초마다 바뀌는 규칙)
- 도둑: 12초 또는 출동 또는 탭 중 먼저 오는 시점까지 설명 화면 (규칙 4줄)
- 출동 시각이 지나는 순간 출동 배너와 팀별 진동 1회
- 앱바 ⓘ로 같은 장면에서 규칙 다시 보기, 첫 게임에 한 번만 ⓘ 위치 안내

### ✅ 구현 내용

#### 시작 흐름 계산과 단계 진행
- **파일**: `lib/features/game/domain/start_flow.dart`, `lib/features/game/domain/recede.dart`, `lib/features/game/presentation/helpers/start_intro_controller.dart`
- **변경 내용**: 서버 `gameStartTime` + `policeWaitMinutes`로 현재 단계를 계산하고, 단계 전환·출동 시각 통과를 컨트롤러가 진행
- **이유**: 앱을 다시 열어도 같은 시각 기준으로 같은 장면이 이어지도록 서버 시각만 사용

#### 배너·장면 위젯
- **파일**: `lib/features/game/presentation/widgets/start/` (`stripe_banner.dart`, `band_transition.dart`, `start_banners.dart`, `chase_scene.dart`, `chase_scene_rules.dart`, `run_cycle.dart`)
- **변경 내용**: 사선 줄무늬 띠, 띠에서 펼쳐지고 접히는 전환, 역할·출동 배너, 경찰 대기·도둑 설명 장면, 달리기 애니메이션 추가
- **이유**: 대기·설명·규칙 다시 보기를 같은 장면 구성으로 재사용

#### 게임 화면 연결
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 장면을 지도·앱바 위, 공지 배너·플로팅 버튼 아래에 끼움. 일반 게임에서는 기존 경찰 대기 팝업 대신 대기 장면 표시. 장면이 떠 있는 동안 좌측 하단 내 위치 버튼 숨김
- **이유**: 대기·설명 장면이 지도를 덮고 규칙 줄과 겹치므로

#### 공지 배너 정리
- **파일**: `lib/features/game/presentation/providers/game_event_provider.dart`
- **변경 내용**: 일반 게임에서 START·`POLICE_MOVE_START` 공지 배너를 띄우지 않음. 채팅 기록은 유지
- **이유**: 역할 배너·출동 배너와 같은 정보가 겹침

### 🔧 주요 변경사항 상세

#### 시작 흐름 단계
- 시작 후 20초 안에 진입한 경우에만 역할 배너를 표시. 그 이후 진입은 현재 단계 장면으로 바로 진입
- 경찰은 출동 전까지 대기 장면, 대기 중에는 기존처럼 나갈 수 없음
- 도둑은 역할 배너 다음 설명 장면

**특이사항**:
- 소리 패키지가 없어 소리 없이 진동만 사용
- 이벤트 게임은 기존 동작 유지
- `gameId`가 방 id와 같아 같은 방에서 다시 하는 게임은 배경이 같을 수 있음. BE 재대결 동작 확인 필요
