# 맵 롱프레스 핑 기능 (발견/의심) 구현 보고서 #405

### 📌 작업 개요

게임 화면에서 맵을 길게 누르면 발견/의심 핑을 찍어 **같은 팀원에게 실시간 공유**하는 기능 구현. 로컬 표시 단계부터 STOMP echo 기반 실시간 송수신까지 완성.

핑은 팀별로만 공유되며(전체 공유 없음), 찍힌 핑은 2.5초 후 자동 소멸. 백엔드 방어 로직이 없어 프론트에서 전송 rate-limit으로 스팸을 차단.

---

### 🎯 구현 목표

- 맵 롱프레스 → 발견/의심 선택 카드 → 좌표에 핑 마커 표시
- STOMP로 같은 팀에 실시간 송수신 (서버 echo 기반)
- 핑 자동 소멸(2.5초) + 전송 rate-limit(5초 8회 초과 시 쿨다운)
- 팀 테마(경찰=라이트 / 도둑=다크) 대응

---

### ✅ 구현 내용

#### 1. 도메인 모델 (Ping 엔티티 / 수신 DTO)
- **파일**: `lib/features/game/domain/entities/ping.dart`, `lib/features/game/data/models/ping_message_dto.dart`
- **변경 내용**: `PingType { found, suspect }` enum + 순수 Dart `Ping` 엔티티(좌표는 double). 서버 수신용 `PingMessageDto`(`pingType`을 String으로 받아 HELP 등 미지원 타입 파싱 실패 방지)
- **이유**: 도메인은 `LatLng`(google_maps) 의존 없이 유지, 변환은 presentation 경계에서 처리

#### 2. 핑 상태 관리 (PingNotifier — echo 기반)
- **파일**: `lib/features/game/presentation/providers/ping_provider.dart`
- **변경 내용**: `addPing`은 화면에 즉시 추가하지 않고 **전송 요청만** 수행. 서버가 팀 채널로 돌려준 핑을 `_onPingReceived`에서 수신해 표시(서버 UUID 기준 upsert + 소멸 타이머)
- **이유**: 서버 Drop("조용히 무시")과 화면을 일치시키기 위함. 낙관적 즉시 표시는 서버 판정과 어긋날 수 있음

#### 3. STOMP 송수신 (기존 게임 이벤트 채널에 통합)
- **파일**: `lib/features/game/data/datasources/game_event_stomp_datasource.dart`
- **변경 내용**: 기존 `GameEventStompDatasource`에 핑 발행(`publishPing`)·팀 채널 구독(`onPing`) 추가. 새 WebSocket 연결 없이 기존 게임 이벤트 연결 재사용
- **이유**: 별도 연결을 만들면 재연결 정책을 중복 구현해야 하므로, 이미 발행/수신을 모두 하는 게임 이벤트 채널에 합침

#### 4. 팀 채널 재구독 보장
- **파일**: `lib/features/game/presentation/providers/game_event_provider.dart`
- **변경 내용**: `connectAndSubscribe(gameId, team)`로 시그니처 변경 + `_team` 저장. 재연결/토큰 갱신 경로 3곳 모두 팀 채널 재구독
- **이유**: 재연결 시 팀 핑 채널 구독이 누락되면 핑 수신이 끊김. `team`을 필수 인자로 만들어 누락을 컴파일 단계에서 차단

#### 5. 선택 카드 UI + 맵 마커
- **파일**: `ping_selection_card.dart`, `ping_marker_factory.dart`, `google_map_view.dart`, `game_page.dart`
- **변경 내용**:
  - 선택 카드: 발견/의심 셀 + 가운데 divider + 아래 핀 꼬리. 팀 테마 대응
  - 맵 마커: 종류 심볼 SVG를 `BitmapDescriptor`로 합성(핀 꼬리는 선택 카드 전용)
  - 롱프레스 좌표를 화면 좌표로 변환해 카드 오버레이 표시
- **이유**: 카드는 발견/의심 개별 탭이 필요해 Flutter 오버레이로, 마커는 GoogleMap 마커로 분리

### 🔧 주요 변경사항 상세

#### 전송 rate-limit (슬라이딩 윈도우)
`addPing`이 "최근 5초간 내가 보낸 핑 시각"을 리스트로 관리. 새 핑 시도 시 5초 밖 기록을 버리고, 남은 게 8개 이상이면 거부 + 3초 쿨다운. **전송이 성공해야만 카운트 소모**(연결 끊김 시 미소모).

**특이사항**:
- rate-limit은 **발신자 본인 기기**에만 적용. 팀원이 보낸 수신 핑에는 제한 없음 → 여러 명이 동시에 찍으면 모두 표시됨
- 시간 기준은 `clock.now()`라 테스트에서 가상 시간으로 검증 가능

#### Android 카드 위치 어긋남 수정 (DPR)
- **파일**: `google_map_view.dart`
- **문제**: 롱프레스 위치에 떠야 할 선택 카드가 Android에서만 하단으로 밀림
- **원인**: `getScreenCoordinate` 반환 좌표 단위가 플랫폼마다 다름 — Android는 physical(device) pixels, iOS는 logical pixels. DPR로 안 나눠서 Android 좌표가 dpr배 커졌고, 화면 clamp에 걸려 하단에 고정됨
- **해결**: `defaultTargetPlatform`으로 Android에서만 `devicePixelRatio`로 나눔. iOS 동작은 그대로 유지

#### 선택 카드 좌우 터치 영역 확장
- **파일**: `ping_selection_card.dart`
- **변경 내용**: 카드 padding과 divider margin을 각 셀의 `Padding`으로 이동. 아이콘/텍스트만이 아니라 **divider 기준 좌우 영역 전체**가 탭되도록 개선. 시각은 동일

#### HELP 타입 / 중복 수신 처리
- 수신 핑 변환 시 `FOUND`/`SUSPECT`만 매핑하고 `HELP`·미지정 값은 건너뜀(마커 없음)
- 같은 서버 UUID가 다시 오면 기존 항목·타이머를 교체(upsert)해 중복 표시 방지
- 타임스탬프는 KST ISO 8601 처리를 위해 프로젝트 공용 `IsoTimestampParser` 사용

### 📌 참고사항

**실기기 검증 권장** (단위 테스트로 못 잡는 부분):
- 같은 팀 2명 이상으로 핑 송수신 — 상대 핑이 내 화면에 뜨는지
- 구역 밖에서 핑 → 서버 Drop으로 안 뜨는지
- 재연결 후 팀 핑 채널 유지
- Android에서 롱프레스 위치에 카드가 정확히 뜨는지 (DPR 수정 검증)

**서버 명세 연계**:
- 전송: `/publish/game/{gameId}/ping`
- 수신: `/subscribe/game/{gameId}/ping/{police|robber}` (본인 팀 채널만)
- 서버 Drop 조건: 게임 미진행 / 구역 이탈 / 비참여자 — 별도 에러 없이 조용히 무시

**백엔드 확인 필요**:
- `api-docs.json`의 description은 v2.9.0인데 `info.version`은 2.8.0으로 불일치. 백엔드 자동 생성 정본이므로 생성 측에서 버전 동기화 필요
