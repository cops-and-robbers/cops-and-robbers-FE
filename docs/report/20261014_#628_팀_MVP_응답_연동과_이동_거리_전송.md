### 📌 작업 개요
게임 종료 시 서버가 팀마다 MVP를 1명씩 판정하도록(BE #212), 앱이 게임 중 내 누적 이동 거리를 30초마다 STOMP로 보내고 결과 API의 팀 MVP 필드를 받는다. 게임 종료 팝업은 진 팀 → 이긴 팀 순서로 MVP를 한 명씩 보여주는 공개 모달로 바꾸고, 결과 카드에는 내가 우리 팀 MVP일 때 거리 옆에 왕관을 표시한다(DEC-0093 ⑤). 서버가 새 필드를 주지 않으면 종료 팝업과 결과 화면은 기존과 같게 동작한다.

같은 브랜치에 iOS Live Activity 카드 수정 4건이 함께 들어 있다(아래 「Live Activity 카드 수정」).

**보고서 파일**: `docs/report/20261014_#628_팀_MVP_응답_연동과_이동_거리_전송.md`

### 🎯 구현 목표
- 경찰·도둑 모두 게임 중 누적 이동 거리를 서버로 전송 (MVP 동점 판정 재료)
- `GET /api/game-results/{id}`의 `policeMvp`·`robberMvp` 파싱
- `GET /api/game-results/{id}/me`의 `isMvp` 파싱과 결과 카드 왕관 표시
- 게임 종료 시 팀 MVP 공개 (진 팀 MVP 먼저, 이긴 팀 MVP 마지막)
- 서버가 아직 새 필드를 내려주지 않아도 종료 팝업·결과 화면이 그대로 동작

### ✅ 구현 내용

#### 이동 거리 전송 정책
- **파일**: `lib/features/game/domain/distance_send_policy.dart` (신규)
- **변경 내용**: `shouldSendDistance()` 순수 함수. 마지막 전송 후 30초 이상 지났고(처음이면 바로) 보낸 값보다 거리가 늘었을 때만 `true`
- **이유**: 안 움직인 플레이어(숨은 도둑, 수감 중인 도둑)가 같은 값을 반복 전송하지 않게 하고, 앱 재진입으로 거리가 복원된 경우(#629)에는 30초를 기다리지 않고 바로 서버 값을 따라잡게 함

#### STOMP 전송
- **파일**: `game_event_stomp_datasource.dart`
- **변경 내용**: `publishDistance(gameId, distanceMeters)` 추가. `/publish/game/{gameId}/distance`로 `{distanceMeters}` 전송
- **이유**: 누적값이라 중간 전송이 유실돼도 다음 전송이 덮어씀. 도둑 위치 전송(5초·10m)과 섞지 않은 별도 메시지

#### 게임 화면 연결
- **파일**: `game_page.dart`
- **변경 내용**: 위치 스트림에서 `addPoint` 직후 `_maybePublishDistance()` 호출. 이벤트 게임이거나 STOMP가 끊겨 있으면 건너뜀. 거리 값은 `playerGameRecordNotifierProvider.distanceMeters` 사용
- **이유**: 결과 카드에 쓰는 거리와 서버에 보내는 거리를 같은 값으로 유지. 이벤트 게임은 MVP 판정 대상이 아님

#### 결과 API 팀 MVP 필드
- **파일**: `game_result_response_model.dart`, `game_result_entity.dart`, `game_result_provider.dart`
- **변경 내용**: 응답에 `GameMvpModel? policeMvp`·`robberMvp`(`{nickname}`) 추가, Entity에는 `policeMvpNickname`·`robberMvpNickname`으로 전달. DTO → Entity 변환을 모델의 `toEntity()`로 옮김
- **이유**: MVP 공개 모달이 Entity만 보고 순서를 정할 수 있게 함. 변환 위치는 `myGameRecord`와 같은 방식으로 통일

#### 결과 카드 MVP 왕관
- **파일**: `my_game_record_response_model.dart`, `my_game_record_entity.dart`, `game_over_result_dialog.dart`, ARB 3종
- **변경 내용**: `isMvp`(기본값 `false`) 파싱. `true`일 때만 결과 카드의 날짜·거리 오른쪽에 왕관 아이콘(`AppIcons.crown`)과 「MVP」 라벨(`labelMvp`) 표시. 처음 넣었던 개인 탭 통계 위 배너(`_MvpBanner`)는 제거
- **이유**: 카드 안에 두어 저장 이미지에도 찍히게 함. 왕관은 대기실 방장 표시와 같은 아이콘. 개인 기록 로딩·실패 중에는 MVP 여부를 모르므로 표시하지 않음

#### 게임 종료 MVP 공개 모달
- **파일**: `game_over_intro_modal.dart` (신규), `mvp_reveal_order.dart` (신규), `game_page.dart`, `character_assets.dart`, ARB 3종
- **변경 내용**: 게임 종료 1단계의 `AppPopup`(3초 자동 닫힘)을 `GameOverIntroModal`로 교체
  - 「게임 종료!」 카드를 최소 1.4초 보여준 뒤, 결과에 팀 MVP가 있으면 카드를 흔들어 「MVP는 누굴까?!」로 바꿈
  - 이어서 진 팀 MVP → 이긴 팀 MVP 순서로 한 명씩 공개. 각 화면은 등장 연출이 끝난 뒤에만 탭·뒤로가기로 넘어감
  - MVP가 없으면(이전 서버·이벤트 게임·조회 실패·3초 안에 응답 없음) 예전 팝업처럼 3초 뒤 닫힘
  - 순서는 `mvpRevealOrder()`가 정함. 후보가 없던 팀(예: 도둑 전원 중도 퇴장)은 빠짐
- **이유**: DEC-0093 ⑤의 공개 순서. 연출이 끝나기 전 탭으로 넘어가면 MVP 이름을 못 보고 지나가므로 탭을 막고, 캡처할 시간을 줌

### 🔧 주요 변경사항 상세

#### 서버 판정 흐름과의 관계
서버는 게임 중 받은 최신 거리를 Redis에만 덮어쓰고, 게임 종료 처리에서 MVP를 즉시 판정한 뒤 GAME_OVER를 보낸다. 앱은 종료 순간에 따로 보낼 것이 없으므로 기존의 즉시 STOMP 해제와 결과 조회 흐름을 바꾸지 않았다. 모달에는 `game_page.dart`가 이미 사전 트리거한 `gameResultProvider` Future를 그대로 넘겨 결과 API를 한 번만 부른다.

#### GameOverIntroModal 타이밍 처리
- 단계가 바뀔 때마다 세대 번호(`_gen`)를 올려 이전 단계에서 예약한 타이머 콜백을 무효화
- 3초 직전에 결과가 오면 흔들림이 시작되어 타임아웃으로 닫히지 않음. 모달이 닫힌 뒤 도착한 결과는 무시
- 백그라운드에서 3초가 지난 채 돌아오면 카드 단계는 바로 닫음 (`AppPopup`과 같은 처리)
- 닫을 때 위에 다른 다이얼로그(복귀 시 위치 권한 안내 등)가 떠 있으면 `pop()` 대신 자기 라우트만 `removeRoute()`로 걷어냄

**특이사항**:
- MVP 캐릭터는 디자이너 MVP 에셋 전까지 홈 전신 그림(`mvpCharacterAssetPath()`)을 임시로 사용. 에셋이 오면 경로 한 줄과 `pubspec.yaml` 폴더 등록만 바꾸면 됨
- 서버가 새 필드를 주지 않으면 팀 MVP는 둘 다 `null`, `isMvp`는 `false` → 기존 종료 팝업·결과 화면과 동일
- 더미 게임은 위치 스트림을 시작하지 않으므로 거리 전송도 없음
- 위젯 테스트 화면(`test_widget_page.dart`)에 「게임 종료 MVP 공개」 미리보기 4종 추가 (경찰 승리·도둑 승리 다크·경찰 MVP만·MVP 없음)

#### Live Activity 카드 수정 (#628과 별개)
- **다이내믹 아일랜드 타이머** (`GameStatusLiveActivity.swift`): 타이머 `Text`의 `frame`을 제거해 로딩·흐림 상태로 멈추던 문제 방지
- **카드 서체** (`GameStatusCard.swift`, `GameStatusLiveActivity.swift`): 커스텀 폰트(Pretendard 2.6MB)가 렌더링 결과에 함께 실려 잠금 화면 카드가 약 2.9MB가 되고, 시스템이 `archiveTooLarge`로 거절해 스피너 후 카드가 사라졌다. 시스템 서체로 교체
- **폰트 파일 정리** (`ios/LiveActivity/Fonts/`, `Info.plist`, `project.pbxproj`): 확장 기능에서 쓰지 않게 된 Pretendard·Moneygraphy(약 4.2MB)와 등록 제거. 앱 본체 폰트(`assets/fonts`)는 유지
- **남은 시간 라벨** (`GameStatusCard.swift`): 타이머 `Text`가 최대 폭을 차지해 뒤에 둔 라벨이 가운데로 밀려 보였다. 라벨을 타이머 앞으로 옮김
