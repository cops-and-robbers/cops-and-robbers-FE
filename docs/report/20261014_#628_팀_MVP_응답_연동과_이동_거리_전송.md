### 📌 작업 개요
게임 종료 시 서버가 팀마다 MVP를 1명씩 판정하도록(BE #212), 앱이 게임 중 내 누적 이동 거리를 30초마다 STOMP로 보내고 결과 API의 팀 MVP 필드를 받아 둔다. 개인 탭에는 내가 우리 팀 MVP일 때만 「이번 판 팀 MVP」 배너를 띄운다. MVP 공개 화면과 애니메이션은 이번 범위에서 빠지고 후속 작업으로 진행한다.

**보고서 파일**: `docs/report/20261014_#628_팀_MVP_응답_연동과_이동_거리_전송.md`

### 🎯 구현 목표
- 경찰·도둑 모두 게임 중 누적 이동 거리를 서버로 전송 (MVP 동점 판정 재료)
- `GET /api/game-results/{id}`의 `policeMvp`·`robberMvp` 파싱
- `GET /api/game-results/{id}/me`의 `isMvp` 파싱과 개인 탭 배너 표시
- 서버가 아직 새 필드를 내려주지 않아도 결과 화면이 그대로 동작

### ✅ 구현 내용

#### 이동 거리 전송 정책
- **파일**: `lib/features/game/domain/distance_send_policy.dart` (신규)
- **변경 내용**: `shouldSendDistance()` 순수 함수. 마지막 전송 후 30초 이상 지났고(처음이면 바로) 보낸 값보다 거리가 늘었을 때만 `true`
- **이유**: 안 움직인 플레이어(숨은 도둑, 수감 중인 도둑)가 같은 값을 반복 전송하지 않게 하고, 앱 재진입으로 거리가 복원된 경우(#629)에는 30초를 기다리지 않고 바로 서버 값을 따라잡게 함

#### STOMP 전송
- **파일**: `game_event_stomp_datasource.dart`
- **변경 내용**: `publishDistance(gameId, distanceMeters)` 추가. `/publish/game/{gameId}/distance`로 `{distanceMeters}` 전송
- **이유**: 누적값이라 중간 전송이 유실돼도 다음 전송이 덮어씀. 도둑 위치 전송(5초·10m)과 섞지 않은 별도 메시지

#### 게임 화면 연결
- **파일**: `game_page.dart`
- **변경 내용**: 위치 스트림에서 `addPoint` 직후 `_maybePublishDistance()` 호출. 이벤트 게임이거나 STOMP가 끊겨 있으면 건너뜀. 거리 값은 `playerGameRecordNotifierProvider.distanceMeters` 사용
- **이유**: 결과 카드에 쓰는 거리와 서버에 보내는 거리를 같은 값으로 유지. 이벤트 게임은 MVP 판정 대상이 아님

#### 결과 API 팀 MVP 필드
- **파일**: `game_result_response_model.dart`, `game_result_entity.dart`, `game_result_provider.dart`
- **변경 내용**: 응답에 `GameMvpModel? policeMvp`·`robberMvp`(`{nickname}`) 추가, Entity에는 `policeMvpNickname`·`robberMvpNickname`으로 전달. DTO → Entity 변환을 모델의 `toEntity()`로 옮김
- **이유**: MVP 공개 화면이 바로 쓸 수 있게 준비. 변환 위치는 `myGameRecord`와 같은 방식으로 통일

#### 개인 탭 MVP 배너
- **파일**: `my_game_record_response_model.dart`, `my_game_record_entity.dart`, `game_over_result_dialog.dart`, ARB 3종
- **변경 내용**: `isMvp`(기본값 `false`) 파싱. `true`일 때만 개인 탭 통계 위에 팀 색 배너 표시. 문구는 `labelTeamMvpBanner`
- **이유**: 경찰·도둑 같은 모양으로 표시. 로딩·실패 중에는 MVP 여부를 모르므로 배너 없이 기존 3행만 표시

### 🔧 주요 변경사항 상세

#### 서버 판정 흐름과의 관계
서버는 게임 중 받은 최신 거리를 Redis에만 덮어쓰고, 게임 종료 처리에서 MVP를 즉시 판정한 뒤 GAME_OVER를 보낸다. 앱은 종료 순간에 따로 보낼 것이 없으므로 기존의 즉시 STOMP 해제와 결과 조회 흐름을 바꾸지 않았다.

**특이사항**:
- `_MvpBanner`는 시안 확정 전 임시 모양(팀 색 10% 배경 + 굵은 라벨). 디자인이 나오면 이 위젯만 교체
- 서버가 새 필드를 주지 않으면 팀 MVP는 둘 다 `null`, `isMvp`는 `false` → 기존 결과 화면과 동일
- 더미 게임은 위치 스트림을 시작하지 않으므로 전송도 없음
- 신규 의존성 없음

### 🧪 테스트 및 검증
- 전송 정책: 앱 재진입으로 복원된 거리는 즉시 전송 / 시작부터 제자리에 숨은 도둑은 전송 안 함 / 29초면 대기, 30초면 전송 / 1분째 안 움직인 수감 도둑은 전송 안 함
- 결과 응답: 양 팀 MVP 매핑 / 도둑 전원 중도 퇴장 시 도둑 MVP만 `null` / 새 필드가 없는 서버 응답도 파싱
- 개인 기록 응답: `isMvp` 전달 / 필드가 없는 서버 응답은 `false`
- 결과 다이얼로그: 경찰·도둑 MVP일 때 개인 탭 배너 표시 / MVP가 아니면 미표시 / 팀 탭에는 미표시
- `flutter test` 전체 통과(1410), `flutter analyze` 신규 이슈 없음
- 실서버(BE #212 반영 후) 연동 확인: **미확인**
