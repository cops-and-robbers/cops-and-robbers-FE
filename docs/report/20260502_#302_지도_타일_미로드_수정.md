# #302 게임 시작 시 지도 타일 미로드 수정

## 배경

### 증상
- 도둑(다크 테마) 팀에서 게임 시작 직후 Google Maps 타일이 회색으로만 표시
- 콜드 스타트 직후 첫 게임에서 주로 발생, 같은 인스턴스에선 회복 불가
- HUD/마커/경계선 등 Flutter 레이어는 정상

### 원인 가설
**Cloud Map ID 콜드 스타트 fetch 영구 실패**.

도둑 팀에서만 발생하는 점이 가설을 강하게 뒷받침한다:
- 도둑 팀: `cloudMapId: widget.mapId` 사용
- 경찰 팀: `cloudMapId: null`, JSON 폴백 → 회색 타일 보고 없음

`google_maps_flutter`는 `cloudMapId`가 지정되면 Google Cloud에서 스타일 메타데이터를 fetch한다. 콜드 스타트 직후 SDK/네트워크 워밍업이 끝나지 않은 상태에서 첫 fetch가 실패하면 SDK 내부가 영구 실패 상태로 고착된다(앱 재시작만 해소).

## 결정

**옵션 1 채택**: `cloudMapId` 코드 경로 자체를 제거하고, 도둑 팀 다크 스타일을 기존 JSON 폴백(`MapStyles.dark`)으로 통일.

### 검토 옵션
| 옵션 | 코드 변경량 | 효과 | 부작용 |
|---|---|---|---|
| **1. cloudMapId 폐기 → JSON 다크 통일** ✅ | **소** | 100% 제거 | 다크 스타일 시각 차이 |
| 2. 앱 시작 시 SDK 워밍업 (hidden map) | 중 | 빈도 감소 (확정 X) | 앱 시작 지연 |
| 3. 워밍업 + 회색 타일 폴백 | 대 | 가장 robust | 휴리스틱 필요 |

### 채택 근거
- **버그 0개 보장**: 회색 타일 코드 경로 자체가 사라짐 → 회귀 불가능
- **검증된 폴백**: `MapStyles.dark`는 cloudMapId 도입 전부터 준비된 폴백 코드 (`google_map_view.dart:339`)
- **유지보수 0**: 워밍업/감지/재시도 같은 우회 코드를 짊어지지 않음
- **시각 차이는 디자이너 검토 영역**: 채택 후 디자인 검토에서 수용 불가 시 옵션 2/3로 복귀

## 검증

자동 테스트 대상 없음(위젯 인자 변경). 수동 검증 항목:

1. **회귀 차단**: 경찰 팀 콜드 스타트 → 라이트 지도 정상 표시
2. **버그 차단**: 도둑 팀 콜드 스타트 5회 반복 → 회색 타일 미발생
3. **시각 검증**: 도둑 팀 다크 지도 시각 디자인 검토 (수용 불가 시 본 PR 롤백 후 옵션 2 재검토)
4. **정적 검증**: `flutter analyze` 통과

## 후속 조치

- Google Cloud Console의 Map ID 자체는 비용 0 → 즉시 삭제 불필요. 디자인 검토에서 옵션 1 수용되면 사후 정리.
- 디자인이 Cloud Map ID 다크 스타일을 다시 원할 경우 `git revert`로 복원 후 옵션 2(워밍업) 또는 옵션 3(폴백) 추가 도입.
