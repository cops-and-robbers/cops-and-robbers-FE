# 👤 방장 상세 시나리오

> 게임 방을 생성, 구역 설정, 팀 인원 비율을 지정
→ 초대 코드를 통해 참가자 초대

게임이 시작되면 방장 또한 일반 플레이어로서 동일하게 게임에 참여
> 

## 방 생성 단계

### 1. 게임 생성 진입

- 앱 홈 화면에서 `방 만들기` 버튼을 선택

### 2. 지도에서 플레이 그라운드 및 감옥 구역 설정

- 현재 위치 기반 지도에서 `구역 설정하기` 버튼을 눌러 플레이 그라운드 및 감옥 설정
- 중심 구역을 정한 후 드래그를 통해 원형 크기를 조절하는 방식으로 지정
- 설정 완료 후 `구역 설정 완료` 버튼을 누르면 경계 정보가 저장
→ 모든 플레이어 지도에 저장된 경계가 시각화되어 나타남

### 3. 기본 게임 설정 입력

- 새 게임 설정 화면이 표시되며 다음 항목을 입력

필수

- 라운드 시간 (default = 30 min) 
(최대 3시간)
- 위치 공유 주기 (default = 5 min) 
(최소 5분)
- ~~라운드 수 (default = 1)~~
- ~~경찰, 도둑 비율 지정 (default 4:6)~~

부가기능

- 경찰 대기 시간
→ 도둑 위치를 공유하면 안 되니까 세팅 필요
~~(양심에 맡기자)~~
- ~~위치 공개 지속시간~~
(위치 공유 주기 흔적(발자국)마다 업데이트)
- 총 참가 인원 수 (최대 30명)
    
    → 사용자 설정이 아니라 시스템 제한
    

### 4. 초대 코드 생성

- 모든 기본 정보와 구역 설정을 마치면 `초대 코드 생성하기` 버튼을 클릭
- 시스템은 **N자리 영문.숫자 조합의 초대 코드**를 자동 생성
- 초대 코드는 복사, QR 코드 공유, 메신저 전송 등 다양한 방식으로 공유 가능

### 5. 닉네임 설정

- 대기실을 입장하기 전에 플레이어는 본인의 닉네임을 설정
    - 닉네임 중복 막기(10자이내)

### 6. 방 생성 완료

- 방장이 생성한 방은 대기실 상태로 유지, 참가자들이 초대 코드를 입력하면 입장 가능
- **방장은 대기실 화면에서 참가자들의 닉네임과 팀 현황을 확인할 수 있으며, 
팀원들은 직접 팀을 선택할 수 있다. (방장은 관여 X)
→ 경찰, 도둑 버튼 선택**
- 모든 인원이 입장 후 `준비 완료`를 누르면 방장만 누를 수 있는 `게임 시작` 버튼이 활성화된다.

# 👮🏻 경찰 상세 시나리오

> 도둑을 추적하고 체포하는 역할을 수행
앱을 통해 도둑팀의 위치를 시간 주기마다 확인
도둑들의 위치가 잠시 공개되는 순간을 활용해 체포
> 

## 입장 및 팀 세팅

### 1. 초대 코드 입력

- `게임 참가` 버튼을 누르고, 방장이 공유한 초대 코드를 입력, 닉네임 설정

### 2. 팀 선택 및 입장

- `경찰팀으로 참가`를 선택
- 대기실 화면에서 팀원 목록을 확인 가능

### 3. 준비 완료

- 위치 권한, GPS 활성화, 네트워크 연결을 확인한 뒤 `준비 완료` 버튼
- 모든 참가자가 준비 완료 시 방장이 `게임 시작`을 누르면 게임이 시작됨

## 게임 시작 및 초기 위치 표시

### 1. 게임 시작

- ~~카운트다운 후 게임 시작~~
- 지도 화면이 열리며, 본인의 현재 위치가 게임 내내 실시간으로 표시
- 경기 구역은 경계선으로 표시되며, 벗어나면 즉시 경고 발생

### 2. 도둑 도망 단계

- 이 시간 동안 도둑팀은 자유롭게 이동할 수 있으며, 경찰은 대기해야 함

## 도둑 위치 공개 주기

### 1. 주기적 위치 공개 이벤트

- 설정된 주기가 지나면 화면 상단에 알림
    
    > “도둑들의 위치가 공개되었습니다!”
    > 
- 지도 위에 도둑들의 위치가 발자국으로 표시
- 다음 위치 공지가 있을 때 발자국 위치 최신화
- 이때 경찰의 위치도 동일한 타이밍에 볼 수 있음 (서버 부하 줄이기 위해 실시간 위치 공개는 X 추후업데이트 )

### 2. 위치 공개 종료

- 경찰은 잔상을 참고하여 도둑의 이동 방향을 추정
- 팀 채팅을 통해 전략을 공유한다
