# 크레딧 helpers 티어 시스템 도입 및 인원 보강

### 📌 작업 개요

크레딧 페이지 하단 Special Thanks 섹션에 5단계 기여도 티어 시스템 도입. 기존 8명이던 helpers를 16명으로 보강하고, 참여 횟수·기여 종류에 따라 텍스트 색상을 차별화. 마키 첫 등장 가독성도 함께 개선.

**보고서 파일**: `.report/20260505_#332_크레딧_인원_추가_및_기여도별_색상_차별화.md`

### 🎯 구현 목표

- 누락된 QA 기여자 7명 신규 등재
- 인프라 제공자(신지훈) 별도 등급으로 등재
- 기존·신규 명단에 중복 등장하는 핵심 기여자(송혜정·남해윤·이진) 시각적 강조
- tier가 올라갈수록 검은 배경 대비 가독성 단조 증가
- 마키 시작 시 첫 텍스트가 빨리 사라지는 문제 해결

### ✅ 구현 내용

#### 5단계 티어 시스템 도입
- **파일**: `lib/features/credits/domain/credit_member.dart`
- **변경 내용**: `ContributionTier` enum (tier1~tier5) 및 `ContributionTierColor` extension getter 추가
- **이유**: tier별 색상 매핑을 단일 진실(single source of truth)로 관리. 기존 `SocialType.tintColor` 패턴과 일관성 유지

#### CreditHelper 클래스 확장
- **파일**: `lib/features/credits/domain/credit_member.dart`
- **변경 내용**: `tier` (required), `participationCount` (default 1) 필드 추가
- **이유**: tier가 표시 결정의 단일 진실. participationCount는 메타데이터로 보존하여 미래 통계·정렬·툴팁 등에 활용 가능

#### 명단 보강 (8명 → 16명)
- **파일**: `lib/features/credits/domain/credit_member.dart`
- **변경 내용**: 신규 QA 7명 + 인프라 제공 신지훈 1명 추가, 중복 이름 unique union 처리
- **이유**: 누락 기여자 등재. 마키에서 같은 이름이 두 번 나오면 어색하므로 한 번만 표시하되 tier2로 강조

#### 마키 노출 우선순위 정렬
- **파일**: `lib/features/credits/domain/credit_member.dart`
- **변경 내용**: 명단을 tier 높은 순(tier4 → tier2 → tier1)으로 정렬, 같은 tier 안에서는 입력 순서 유지
- **이유**: 마키 시작 시 핵심 기여자가 먼저 등장하도록

#### tier 기반 텍스트 스타일 분기
- **파일**: `lib/features/credits/presentation/pages/credits_page.dart`
- **변경 내용**: helper.tier.color로 색상 적용, tier5에 한해 `paragraph14Semibold`로 굵기 강조
- **이유**: tier4(yellow)와 tier5(yellow900)의 색감 차이가 미세해서 색만으로는 구분 약함. 굵기로 보강. UI Design System 룰 준수 (`copyWith`는 color만 변경)

#### 마키 leading spacer 추가
- **파일**: `lib/features/credits/presentation/pages/credits_page.dart`
- **변경 내용**: Row의 첫 child로 `SizedBox(width: 0.7.sw)` 추가
- **이유**: 마키 위젯이 0 위치에서 시작하므로 첫 텍스트가 화면 왼쪽 끝에서 즉시 사라지는 문제 해결. 화면 너비 70%만큼 spacer를 두어 첫 항목이 화면 오른쪽 밖에서 진입하도록 개선

### 🔧 주요 변경사항 상세

#### tier 색상 매핑 (검은 배경 대비 명도 단조 증가)

| tier | AppColors 상수 | Hex | brightness | 인상 | 부여 기준 |
|---|---|---|---|---|---|
| tier1 | `black500` | `#76899E` | **134** | 회색 | 1회 참여 (수동 지정) |
| tier2 | `green` | `#38F55B` | **171** | 비비드 초록 | 2회 참여 (수동 지정) |
| tier3 | `green800` | `#7AF391` | **196** | 밝은 초록 | 3회+ 참여 (현재 0명) |
| tier4 | `yellow` | `#F5EF38` | **220** | 선명 노랑 | 인프라/지원 (수동) |
| tier5 | `yellow900` | `#F7F260` | **227** | 가장 밝은 노랑 | 후원/최고 공로 (현재 0명) |

검은 배경(`AppColors.black` `#080A0C`) 대비 perceived brightness(`0.299R + 0.587G + 0.114B`)가 134 → 171 → 196 → 220 → 227로 단조 증가. tier가 올라갈수록 가독성 향상. 흰색은 사용하지 않고 yellow900을 정점으로 클램핑.

#### 명단 구성 (16명)

| tier | 인원 | 명단 |
|---|---|---|
| tier4 | 1명 | 신지훈 (인프라 제공) |
| tier2 | 3명 | 남해윤·송혜정·이진 (QA 2회) |
| tier1 | 12명 | 안금서·손건우·신혜빈·정창우·허석준·서현진·오동현·최승훈·김민욱·정명준·강대현·심 혁 (QA 1회) |

**특이사항**:
- tier3, tier5는 현재 비어있는 슬롯. 미래 확장용으로 enum과 색상은 정의하되 인원은 없음
- 중복 이름(송혜정·남해윤·이진)은 unique union 처리. 한 번만 표시하되 `participationCount: 2`로 메타 보존
- 자동 카운트 로직 미도입 — tier4·5는 어차피 수동 지정이라 두 로직(자동/수동)이 섞이면 복잡. 데이터 입력 시 사람이 명시하는 방식으로 통일

#### 마키 leading spacer

`SizedBox(width: 0.7.sw)`로 화면 너비의 70% 길이 빈 공간을 Row의 첫 자리에 배치. `0.7.sw`는 `flutter_screenutil`의 단위로 *현재 화면 너비의 0.7배*를 의미.

마키 위젯은 child를 두 벌 복제(`[child, child]`)하여 0 → halfExtent → jumpTo(0)을 반복. spacer가 child의 일부로 포함되므로 한 사이클 끝과 다음 시작 사이에도 동일하게 spacer가 등장 → 자연스러운 호흡 효과.

**특이사항**:
- 초기 시안은 `1.sw`(전체 너비)였으나 사용자 조정으로 `0.7.sw`(70%)로 단축됨
- spacer 길이는 디바이스마다 실제 화면 너비에 비례
