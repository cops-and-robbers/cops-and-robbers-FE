# 백그라운드 위치 추적 도입에 따른 개인정보처리방침 및 이용약관 갱신 #315

### 📌 작업 개요

v1.8.5에서 도입된 백그라운드 위치 추적 기능(#305)이 약관에 반영되어 있지 않은 문제를 해결. 개인정보보호법·위치정보법 준수 및 App Store / Play Store 심사 메타데이터 정합성 확보를 위해 약관 본문 4종을 갱신하고, 앱 내 약관 페이지에 표시되는 JSON 데이터도 동일 본문으로 동기화. 함께 `assets/legal/` → `assets/legals/` 폴더명을 통일.

### 🎯 구현 목표

- Apple Privacy Policy 6요소(Section 5.1.1(i)) 충족
  - 수집 데이터, 수집 방법, 사용 목적, 제3자 동등 보호, 보유·삭제 정책, 동의 철회·삭제 방법
- 백그라운드 수집 메커니즘 명시 (Android Foreground Service, iOS UIBackgroundModes location)
- 미래 확장 단계(P1 결과 화면 동선, P2 단말 로컬 저장, P3 서버 보관)까지 한 번에 커버하여 약관 재갱신 작업 최소화
- 광고 식별자/사용자 추적(ATT) 비대상 사실 명시
- 앱 내 약관 페이지가 갱신된 본문을 즉시 반영하도록 데이터 동기화

#### 3. JSON 매핑 정책

마크다운 → JSON 변환 시 다음 정책 적용:

| 마크다운 요소 | JSON 매핑 |
|---|---|
| 첫 줄 `# 제목` | `title` |
| `시행일/적용일` | `effectiveDate` |
| `## N.` 헤더 | `sections[].heading` |
| 헤더 직후 첫 단락 또는 ① 항 | `sections[].content` |
| 번호 1./2./3. 또는 ②/③/④ 항 | `sections[].items[].text` |
| 중첩 1./2./3. | `sections[].items[].subItems[]` |
| `**굵게**` | 기호 제거 (텍스트 보존) |
| `---` 수평선 | 무시 (section 자연 분리) |

**원칙**: 텍스트 정보 손실 0%, 시각적 마크다운 기호만 제거.

### 🔧 주요 변경사항 상세

#### 개인정보처리방침 - ③ 위치 정보 항목 확장

**추가된 핵심 문구**:
- 수집 시점: 게임 세션이 진행(IN_PROGRESS) 중인 동안에 한하여, 포그라운드뿐만 아니라 화면이 꺼지거나 다른 앱이 실행된 백그라운드 상태에서도 수집. GAME_OVER 즉시 자동 중단
- 백그라운드 수집 방식 - Android: Foreground Service(`foregroundServiceType="location"`)를 통해 게임 진행 중임을 알리는 영구 알림 표시 상태에서만 수집
- 백그라운드 수집 방식 - iOS: UIBackgroundModes의 location 옵션 사용, 시스템 상단 파란색 위치 인디케이터로 사용자 시각적 인지

**5-3 향후 확장 기능 안내 신설**:
- 본인 게임 기록 단말 로컬 저장 (P2)
- 게임 기록 서버 보관 및 공유 (P3)
- 별도 동의 절차와 함께 도입 시점에 약관 구체화 시행

**제3자 제공 동등 보호 명시 (5-2)**:
- 동일 게임 세션 참가자에게 게임 진행 중에만 GPS 좌표 제공
- 위치정보를 제공받는 자에게 본 처리방침과 동등한 수준의 개인정보 보호 의무 부과

#### 위치정보 이용약관 - 제4조 신설

위치정보 수집의 시점 및 방식을 별도 조항으로 분리하여 명확히 규정:
- ① IN_PROGRESS 동안에만 수집, 게임 시작 전·종료 후 미수집
- ② Android FGS / iOS UIBackgroundModes 메커니즘 명시
- ③ GAME_OVER 즉시 메커니즘 자동 중단 + 시스템 자원 해제
- ④ 정당한 목적 범위 내 수집 한정
- ⑤ Android 배터리 최적화 정책에 따른 수집 제한 가능성 + 사용자 직접 설정 가능

#### 이용약관 - 제2조 ⑥ 백그라운드 위치 수집 정의

> "백그라운드 위치 수집"이란 앱이 화면에 표시되지 않는 상태(화면 꺼짐, 다른 앱 실행 중 등)에서 운영체제별 메커니즘(Android Foreground Service, iOS UIBackgroundModes location)을 통해 게임 진행 중 이용자의 위치 정보를 수집하는 것을 말합니다.

이용자가 약관을 읽고 백그라운드 수집의 범위·메커니즘을 명확히 인지할 수 있도록 정의 조항에 추가.

### 🔄 후속 정합성 보완 (코드래빗 리뷰 반영, 커밋 `bb7368a`)

PR #316에 자동으로 등록된 코드래빗 리뷰에서 약관 본문과 실제 구현 사이 정합성 이슈 3건이 지적되어 즉시 반영. 모두 `docs/legals/개인정보처리방침.md` 및 `assets/legals/privacy_policy.json` 양쪽 동기화.

#### 1. 발자국 보유·파기 기준 명시 (Major)

- **지적**: 2-1③ 수집 항목에 "위치 공개 기록(발자국)"이 명시되어 있으나 보유·파기 기준 누락. 위치정보이용약관(116행)에는 "게임 세션 종료 즉시 삭제" 명시되어 있어 약관 간 정합성 깨짐.
- **수정**:
  - 2-1③ 보유 기간 문구에 "위치 공개 기록(발자국)은 게임 세션 종료 즉시 삭제됩니다" 추가
  - 9조 보유 및 파기에 4번 항목 신설, 기존 4~6번을 5~7번으로 재정렬

#### 2. 2-2 수집 방법 ↔ 6장 SDK 정합성 (Minor)

- **지적**: 2-2 5번 항목은 `firebase_messaging, firebase_crashlytics`만 명시하지만 6장에는 Firebase Authentication, FCM, Crashlytics, **Firebase Remote Config, Google Maps SDK** 5종 모두 명시. 섹션 간 정합성 깨짐.
- **수정**: 2-2 5번을 6장 참조 포괄 표현으로 변경
  - `외부 SDK를 통한 수집 (Firebase Authentication, Firebase Cloud Messaging, Firebase Crashlytics, Firebase Remote Config, Google Maps SDK — 상세 항목은 제6조 참조)`

#### 3. 미구현 기능 명시 제거 (Major)

- **지적**: 10조 ③ 위치정보 이용 동의 철회의 세 번째 항목 "앱 내 설정에서 위치 정보 수집을 거부하는 방법 (이 경우 게임 참가가 제한됩니다)"은 v1.8.5 시점에 미구현. `lib/features/settings/presentation/pages/settings_page.dart:133-137`은 OS 설정 deeplink만 제공.
- **수정**:
  - 미구현 세 번째 항목 제거
  - 첫 번째 항목에 "(앱 내 설정 → 위치 권한 관리에서 OS 권한 화면으로 바로 이동 가능)" 보강
  - 두 번째 항목에 "(게임 진행 상태가 아닌 경우 위치 정보가 수집되지 않습니다)" 보강
- **결정 근거**: 미구현 기능을 약관에 명시하는 것은 잘못된 안내. 향후 앱 내 위치 토글 UI를 구현하는 시점에 약관 재개정으로 부활 가능.
