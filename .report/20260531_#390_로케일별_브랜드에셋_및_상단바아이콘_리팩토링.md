# 스플래시·인앱 로고 로케일 대응 및 상단바 아이콘 버튼 공통화

### 📌 작업 개요
스플래시·인앱 로고 이미지를 로케일별(ko/en/ja)로 분리 적용하고, 캐릭터·알림 SVG 에셋을 갱신. 더불어 여러 화면에 중복돼 있던 상단바 SVG 아이콘 버튼을 `FlatIconButton` 공통 컴포넌트로 추출하고, 홈 화면 공지 아이콘을 설정 버튼 옆으로 재배치.

총 4개 커밋으로 구성:
- `feat` 로케일별 워드마크 로고·스플래시 SVG 적용
- `chore` 캐릭터 SVG 에셋 및 알림 아이콘 업데이트
- `refactor` 상단바 아이콘 버튼 `FlatIconButton` 공통 컴포넌트 분리
- `style` 홈 화면 공지 아이콘 설정 버튼 옆으로 이동

### ✅ 구현 내용

#### 1. 로케일별 브랜드 에셋 해석 모듈 신설
- **파일**: `lib/core/i18n/locale_brand_assets.dart` (신규)
- **변경 내용**: 현재 로케일을 받아 워드마크 로고·스플래시 SVG 경로를 반환하는 함수 2개 추가
  - `localizedAppLogo(Locale)` → `assets/app_logos/app_logo_{code}.svg`
  - `localizedAppSplash(Locale)` → `assets/app_splashs/app_splash_{code}.svg`
- **이유**: 화면 내부에서 직접 렌더링하는 브랜드 일러스트를 한 곳에서 일관되게 해석. 네이티브 런처 아이콘(`locale_app_icon_mapper.dart`)과 책임 분리.

#### 2. 로케일별 SVG 에셋 추가
- **파일**: `assets/app_logos/app_logo_{ko,en,ja}.svg`, `assets/app_splashs/app_splash_{ko,en,ja}.svg` (신규 6종)
- **변경 내용**: 언어별 워드마크 로고 3종, 스플래시 일러스트 3종 추가. `pubspec.yaml`에 에셋 경로 등록.

#### 3. 5개 화면에 로케일 에셋 적용
- **파일**: `login_page.dart`, `splash_page.dart`, `force_update_page.dart`, `maintenance_page.dart`, `home_page.dart`
- **변경 내용**: 하드코딩된 단일 로고/스플래시 경로를 `localizedAppLogo` / `localizedAppSplash` 호출로 교체
  - 로고: `login_page`, `home_page`
  - 스플래시: `splash_page`, `force_update_page`, `maintenance_page`
- **관련 i18n**: `app_ko/en/ja.arb` 텍스트 추가 후 `app_localizations*.dart` 재생성

#### 4. 캐릭터·알림 SVG 에셋 갱신
- **파일**: `assets/characters/police/**`, `assets/characters/robber/**`, `assets/icons/icon_alert.svg`
- **변경 내용**: 경찰/도둑 캐릭터 SVG(home, ready, not_ready, jailed, result win/lose) 일괄 교체. 알림 아이콘 `icon_alert.svg` 신규 추가.

#### 5. 상단바 아이콘 버튼 공통 컴포넌트 분리
- **파일**: `lib/core/widgets/buttons/flat_icon_button.dart` (신규)
- **변경 내용**: 배경·그림자 없는 플랫 SVG 아이콘 버튼을 `FlatIconButton`으로 추출. `game_page`, `waiting_room_page`, `in_game_tutorial_page`의 중복 `GestureDetector + SvgPicture` 코드를 이 컴포넌트로 교체
- **이유**: 동일 패턴이 여러 화면에 반복돼 있어 단일 컴포넌트로 통일. (흰 배경+라운드+그림자가 필요한 경우는 기존 `SvgIconButton` 사용 — 역할 분리)

#### 6. 홈 화면 공지 아이콘 위치 이동
- **파일**: `home_page.dart`
- **변경 내용**: 공지 아이콘을 우측 아이콘 그룹(`Row`) 안에서 설정 버튼 좌측에 배치. 두 버튼 모두 `FlatIconButton`(`icon_alert.svg`, `icon_setting_1.svg`)로 통일.

### 🔧 주요 변경사항 상세

#### `FlatIconButton`
```
GestureDetector(behavior: HitTestBehavior.opaque)
  └ SizedBox(tapSize) → Align(alignment) → SvgPicture.asset
```
- `iconSize`(기본 24), `tapSize`(기본 42), `iconColor`, `alignment`를 파라미터화
- `HitTestBehavior.opaque` — 아이콘 주변 여백까지 탭 영역으로 잡아 터치 실패 방지
- `tapSize` 42 — 최소 터치 영역(권장 44 근처) 확보
- `iconColor`가 null이면 `ColorFilter` 미적용 → SVG 원본 색상 유지

**특이사항**:
- 배경/그림자가 필요한 버튼은 기존 `SvgIconButton`을 그대로 사용. 두 컴포넌트의 용도가 명확히 구분됨.

#### `locale_brand_assets.dart` — 폴백 전략
```dart
String _codeOrDefault(String code) =>
    kSupportedLocales.any((l) => l.languageCode == code)
    ? code
    : kDefaultLocale.languageCode;  // 미지원 로케일 → en
```
- 지원 목록(ko/en/ja)에 없는 언어 코드는 기본 로케일(en) 에셋으로 폴백 → 인앱 텍스트와 톤 일치

#### `home_page.dart` — 로고 높이 분기
```dart
height: (languageCode == 'en' ? 40 : 20).h
```
- 영문 워드마크는 세로 비중이 커서 height 40, ko/ja는 20으로 조정
