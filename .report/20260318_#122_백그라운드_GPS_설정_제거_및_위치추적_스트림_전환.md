### 📌 작업 개요

MVP 앱 스토어 심사 대응을 위해 불필요한 백그라운드 GPS 관련 네이티브 권한/설정을 제거하고, 위치 추적 방식을 Timer + 단발성 조회에서 지속적 스트림 구독으로 전환하여 OS 위치 인디케이터가 정상 표시되도록 개선

**보고서 파일**: `.report/20260318_#122_백그라운드_GPS_설정_제거_및_위치추적_스트림_전환.md`

### 🎯 구현 목표

- 앱 스토어 심사 리젝 방지를 위한 백그라운드 GPS 권한/설정 완전 제거
- OS 위치 인디케이터 표시를 위한 스트림 기반 위치 추적 전환
- 서버 부하 유지를 위한 throttle 적용
- 설정 페이지에 위치 권한 관리 메뉴 추가 (심사 대응)

### ✅ 구현 내용

#### 1. Android 네이티브 권한 제거
- **파일**: `android/app/src/main/AndroidManifest.xml`
- **변경 내용**: `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` 권한 및 관련 주석 제거
- **이유**: 백그라운드 위치 추적 미구현 상태에서 권한만 선언되어 있으면 심사 리젝 사유가 됨

#### 2. iOS 백그라운드 모드 및 권한 설명 정리
- **파일**: `ios/Runner/Info.plist`
- **변경 내용**:
  - `UIBackgroundModes`에서 `location` 제거 (`fetch`, `remote-notification` 유지)
  - `NSLocationAlwaysAndWhenInUseUsageDescription` 제거
  - `NSLocationWhenInUseUsageDescription` 문구를 구체적으로 변경 (목적/범위/종료조건 포함)
  - `NSUserNotificationsUsageDescription` 문구 구체화
- **이유**: 백그라운드 위치 권한 불필요, 심사 시 권한 사용 목적 명확화 필요

#### 3. 위치 추적 Timer → Stream 전환
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**:
  - `Timer? _locationTimer` → `StreamSubscription<Position>? _locationSubscription`으로 변경
  - `Timer.periodic` + `getCurrentPosition()` → `DeviceLocationService.getPositionStream(distanceFilter: 10)` 구독으로 전환
  - 5초 throttle 추가 (`_lastSentTime` 기반)하여 서버 부하 제한
  - `onError` 핸들러에서 `_locationSubscription = null` 처리로 재구독 가능하도록 방어 코드 추가
  - `onDone` 핸들러 추가
  - 백그라운드 관련 TODO 주석 및 안내 주석 제거
- **이유**: 지속적 스트림 구독으로 OS가 위치 사용을 인식하여 상태바 인디케이터(iOS 파란색 pill / Android 위치 아이콘) 정상 표시. distanceFilter를 OS 레벨로 이동하여 불필요한 Dart 측 거리 계산 제거

#### 4. 설정 페이지에 위치 권한 관리 메뉴 추가
- **파일**: `lib/features/settings/presentation/pages/settings_page.dart`
- **변경 내용**: 알림 섹션 아래에 "위치 권한 관리" 메뉴 항목 추가. 탭 시 `LocationPermissionService.openAppSettings()`로 OS 앱 설정 화면 이동
- **이유**: 앱 스토어 심사에서 사용자가 위치 권한을 직접 제어할 수 있는 경로 제공 요구

#### 5. 위치 권한 안내 문구 개선
- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: `_ensureLocationPermission` 다이얼로그 문구를 목적/범위/종료조건이 포함된 구체적 문구로 변경
- **이유**: 심사 대응 — 위치 정보 사용 목적을 사용자에게 명확히 고지

#### 6. 백그라운드 문서 제거
- **삭제 파일**: `docs/BACKGROUND_LOCATION_SERVICE.md` (691줄)
- **수정 파일**: `CLAUDE.md` — 백그라운드 위치 추적 섹션 제거
- **이유**: 미구현 기능의 문서가 남아있으면 혼란 유발

### 🔧 주요 변경사항 상세

#### game_page.dart — 스트림 기반 위치 추적

기존 `Timer.periodic(10초)` + `getCurrentPosition()` 방식에서 `getPositionStream(distanceFilter: 10)` 구독 방식으로 전환. 스트림 콜백에서 5초 미만 간격 전송은 스킵하여 서버 부하 제한. 스트림 에러/종료 시 `_locationSubscription = null` 처리하여 STOMP 재연결 시 `_startLocationSending()` 재호출 가능하도록 방어

**특이사항**:
- `distanceFilter: 10`으로 OS 레벨에서 10m 미만 이동 필터링 (기존 Dart 측 거리 계산 제거)
- 스트림 구독 유지로 인해 OS 위치 인디케이터가 자연스럽게 표시됨
- FCM 관련 설정(`remote-notification`, Firebase 백그라운드 핸들러)은 그대로 유지

#### settings_page.dart — CupertinoSwitch 적용

위치 권한 관리 메뉴 추가와 함께, 기존 Material Switch를 CupertinoSwitch로 변경하여 알림 토글의 높이 패딩 불일치 문제 해결
