- **파일**: `lib/main.dart`, `lib/core/services/fcm/firebase_messaging_service.dart`

- **파일**: `lib/core/i18n/error_message_mapper.dart`
- **변경 내용**: `errorByKey()`에 누락돼 있던 21개 messageKey를 로케일 메시지로 매핑.
- **이유**: 누락 키는 폴백으로 하드코딩 한국어를 사용해, 영어·일본어 사용자가 로그인·탈퇴·방생성·신고 등 21개 에러 상황에서 한국어를 보던 문제 해결.

#### P1 — Chat·Lobby Notifier dispose 가드
- **파일**: `lib/features/chat/presentation/providers/chat_provider.dart`, `lib/features/lobby/presentation/providers/lobby_provider.dart`
- **변경 내용**: `_isDisposed` 플래그 추가 + `onDispose`에서 설정 + `await` 직후 가드.
- **이유**: 토큰 갱신·재연결의 `await` 도중 화면 이탈로 Provider가 폐기되면, 이어지는 `state`/`ref` 접근이 죽은 Provider를 건드려 크래시할 수 있음. 이미 가드가 있던 `GameEventNotifier`와 일관화.

- **변경 내용**: 체포/탈옥 낙관적 업데이트·롤백·재진입 방어, `canPoliceArrest`, `syncFromParticipants` 검증 12개 테스트.
- **이유**: 데이터 일관성이 가장 민감한 로직이 직접 테스트 없이 운영되던 상태. 회귀 안전망 확보.

- **파일**: `lib/features/game/presentation/pages/game_page.dart`, `lib/features/game/domain/location_send_policy.dart` (신규), `test/features/game/domain/location_send_policy_test.dart` (신규)

### 🔧 주요 변경사항 상세

#### 위치 스트림 통합 (game_page.dart)
단일 스트림(`distanceFilter: 0`)이 모든 GPS 틱을 받아 **양 팀의 구역 이탈을 매 틱 즉시 감지**하고, **도둑은 STOMP 연결 상태에서만 전송 게이트를 통과할 때** 서버로 publish.

OS가 담당하던 10m 필터는 코드 레벨 거리 계산(`Geolocator.distanceBetween`)으로 대체. 전송 빈도는 기존과 동일 — "마지막 전송 후 10m 이상 이동 + 5초 이상 경과"를 모두 만족할 때(최대 5초에 1회).

**특이사항**:
- 경찰이 초기 위치를 잘못 전송하는 버그를 피하기 위해, 초기 1회 전송(`_sendInitialLocation`, 도둑 전용)과 상시 스트림(`_startLocationStream`, 양 팀)을 분리.
- 스트림 에러/종료 시 구독을 null로 리셋 → 포그라운드 복귀 시 재시작 가드가 정상 작동(구역 감지 영구 중단 방지).
- `distanceFilter: 0`은 새 부담이 아님 — 통합 전에도 구역 감지용 0 스트림이 이미 돌고 있었고, 별도 10m 스트림을 제거한 것.

#### dispose 가드 (chat_provider.dart, lobby_provider.dart)
`await` 전후로 `_isDisposed`를 확인해, 폐기된 Provider의 `state`/`ref` 접근을 조용히 건너뜀. `onDispose`가 이미 모든 구독을 취소하므로 대부분은 막혀 있었고, await가 진행 중인 좁은 경합 창을 추가로 닫음.

- Chat·Lobby Provider의 dispose 경합 크래시 창 차단 (드문 경합 하드닝).
- GPS 스트림 에러 후 구역 이탈 감지가 영구 중단되던 잠재 버그 방지(통합 스트림이 onError/onDone 보유).
