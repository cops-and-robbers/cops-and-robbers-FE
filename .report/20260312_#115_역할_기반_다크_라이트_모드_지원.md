### 📌 작업 개요

역할(경찰/도둑)에 따라 앱 테마를 자동 전환하는 다크/라이트 모드 지원 기능 구현.
경찰 팀은 라이트 모드, 도둑 팀은 다크 모드가 자동 적용되며, 대기방·인게임·채팅 등 주요 화면 전체에 걸쳐 isDarkMode 기반 UI 분기 처리 완료. 총 40개 파일 변경, +2,520 / -780 lines.

### 🎯 구현 목표

- 경찰 = 라이트 모드, 도둑 = 다크 모드 자동 전환
- 대기방, 인게임, 채팅, 다이얼로그 등 전 화면 다크모드 대응
- Moneygraphy 커스텀 폰트 기반 도둑 전용 타이포그래피 추가
- 향후 사용자 수동 선택 기능 확장 가능한 구조 설계

### 🔧 주요 변경사항 상세

#### 다크모드 전파 패턴
모든 위젯에 `isDarkMode` 파라미터를 top-down으로 전파하는 패턴 채택. game_page에서 `widget.team == 'ROBBER'`로 판단 후 하위 위젯에 전달. 대기방에서는 `RoleThemeProvider`를 통해 팀 변경 이벤트와 동기화.

#### Google Maps 다크 스타일
Google Maps Platform의 JSON 스타일링 API 사용. 도로, 건물, 수계 등 주요 요소를 어두운 톤으로 변경하는 스타일 JSON을 `_darkMapStyle` 상수로 정의.

#### Naver Map 야간 모드
`NMapType.navi` + `nightModeEnable: true` 조합으로 네이버 지도 야간 모드 활성화. 네이버 지도 SDK 기본 제공 기능 활용.

**특이사항**:
- 다크모드는 역할 기반 자동 전환만 구현 (1차 목표). 사용자 수동 선택은 향후 확장 예정
- `robber_` 접두사 텍스트 스타일은 lowerCamelCase(`robberHeading` 등)로 변환 완료 (CI lint 통과)
