## 🔒 보안 구현 원칙

### 3단계 보안 레이어

#### Layer 1: Heredoc with Single Quotes
```yaml
cat > ios/Flutter/Secrets.xcconfig << 'SECRETS_EOF'
GOOGLE_MAPS_API_KEY=${{ secrets.GOOGLE_MAPS_API_KEY }}
SECRETS_EOF
```
- **목적**: Shell 변수 확장 방지
- **효과**: `${{ secrets.GOOGLE_MAPS_API_KEY }}`가 문자 그대로 파일에 기록됨

#### Layer 2: env Block
```yaml
env:
  GOOGLE_MAPS_API_KEY: ${{ secrets.GOOGLE_MAPS_API_KEY }}
```
- **목적**: GitHub Actions 자동 마스킹 활성화
- **효과**: 로그에서 실제 값이 `***`로 표시됨

#### Layer 3: No-Output Verification
```yaml
if grep -q "GOOGLE_MAPS_API_KEY" ios/Flutter/Secrets.xcconfig; then
  echo "✅ GOOGLE_MAPS_API_KEY variable found"
fi
```
- **목적**: 값 출력 없이 존재 여부만 확인
- **금지**: `cat`, `echo $VARIABLE` 등 값 출력 명령 사용 안 함

## 📝 iOS 네이티브 설정 예시

### Secrets.xcconfig 파일 생성
```yaml
- name: Setup iOS Secrets (Google Maps)
  run: |
    mkdir -p ios/Flutter
    cat > ios/Flutter/Secrets.xcconfig << 'SECRETS_EOF'
    // Google Maps API Key
    // iOS Google Maps SDK에서 사용
    // Info.plist → AppDelegate를 통해 초기화
    GOOGLE_MAPS_API_KEY=${{ secrets.GOOGLE_MAPS_API_KEY }}
    SECRETS_EOF
    echo "✅ ios/Flutter/Secrets.xcconfig created"
  env:
    GOOGLE_MAPS_API_KEY: ${{ secrets.GOOGLE_MAPS_API_KEY }}
```

### 보안 검증 단계
```yaml
- name: Verify Secrets Not Exposed
  run: |
    echo "🔒 보안 검증: API 키가 노출되지 않았는지 확인"

    # iOS Secrets.xcconfig 확인
    if [ -f ios/Flutter/Secrets.xcconfig ]; then
      echo "✅ ios/Flutter/Secrets.xcconfig exists"
      if grep -q "GOOGLE_MAPS_API_KEY" ios/Flutter/Secrets.xcconfig; then
        echo "✅ GOOGLE_MAPS_API_KEY variable found in Secrets.xcconfig"
      else
        echo "⚠️ GOOGLE_MAPS_API_KEY not found in Secrets.xcconfig"
      fi
    else
      echo "❌ ios/Flutter/Secrets.xcconfig not created"
      exit 1
    fi

    echo "✅ 보안 검증 완료: 설정 파일 생성됨 (API 키 값은 마스킹됨)"
```

## 📝 Android 네이티브 설정 예시

### local.properties 파일 생성
```yaml
- name: Setup Android Secrets (Google Maps)
  run: |
    # 기존 local.properties가 있으면 백업
    if [ -f android/local.properties ]; then
      cp android/local.properties android/local.properties.backup
    fi

    # local.properties 생성/업데이트
    cat >> android/local.properties << 'SECRETS_EOF'

    # Google Maps API Key
    GOOGLE_MAPS_API_KEY=${{ secrets.GOOGLE_MAPS_API_KEY }}
    SECRETS_EOF
    echo "✅ android/local.properties updated with API key"
  env:
    GOOGLE_MAPS_API_KEY: ${{ secrets.GOOGLE_MAPS_API_KEY }}
```

### 보안 검증 단계
```yaml
# Android local.properties 확인
if [ -f android/local.properties ]; then
  echo "✅ android/local.properties exists"
  if grep -q "GOOGLE_MAPS_API_KEY" android/local.properties; then
    echo "✅ GOOGLE_MAPS_API_KEY variable found in local.properties"
  else
    echo "⚠️ GOOGLE_MAPS_API_KEY not found in local.properties"
  fi
else
  echo "❌ android/local.properties not created"
  exit 1
fi
```
