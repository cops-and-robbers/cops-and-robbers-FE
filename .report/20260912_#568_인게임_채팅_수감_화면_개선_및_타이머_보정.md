### 📌 작업 개요

인게임 채팅을 하단 시트에서 버튼으로 여는 전체 화면 패널로 전환. 체포 시 화면을 덮던 잠금 오버레이를 걷어내 수감 중에도 지도를 조작할 수 있게 하고, 타이머는 전달 값이 바뀌면 즉시 보정하며 60분 이상을 총 분으로 표시한다.

### 🎯 구현 목표

- 지도와 채팅을 오가도 채널별 미읽음·작성 중인 입력·스크롤 위치가 유지될 것
- 수감 중에도 감옥과 현재 위치를 지도에서 확인하고 이동·확대할 수 있을 것
- 타이머가 새 시간 값을 다음 tick까지 기다리지 않고 반영하고, 90분을 `90:00`으로 표시할 것

### ✅ 구현 내용

#### 인게임 채팅 전체 화면 패널

- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart`, `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `DraggableScrollableSheet` 제거. 우측 하단 채팅 버튼으로 앱바 아래 전체 화면 패널을 열고, 지도 보기 버튼이나 뒤로가기로 닫는다. 닫힌 패널은 `Offstage`로 살려 두어 구독·미읽음·입력 상태를 보존하고, 팀/전체는 `PageView` 탭으로 가른다
- **이유**: 시트 높이에 묶여 읽기 공간이 좁았고, 시트 상태와 지도 버튼 위치가 서로 얽혀 있었다

#### 공용 채팅 입력창 이동

- **파일**: `lib/core/widgets/chat/community_message_input.dart` (신규), `lib/features/community/presentation/widgets/community_message_input.dart`
- **변경 내용**: 커뮤니티 입력창을 `core/widgets/chat/`로 옮기고 기존 경로는 재내보내기로 유지. 게임 채팅이 같은 위젯을 쓴다
- **이유**: 게임 전용 `ChatInputBar`와 커뮤니티 입력창이 같은 모양을 따로 구현하고 있었다

#### 채팅 미리보기 말풍선

- **파일**: `lib/features/chat/presentation/widgets/chat_preview_card.dart`
- **변경 내용**: 상단 가로 배너를 채팅 버튼 옆 말풍선으로 교체. 채팅방 말풍선과 같은 모서리(위 12 / 좌하 12 / 우하 4)와 색을 쓰고, 우하 모서리가 채팅 버튼을 가리킨다. 본문 최대 2줄, 발신자 직업 아이콘·닉네임·채널을 함께 표시하며 3초 뒤 퇴장한다
- **이유**: 미읽음 수는 채팅 버튼 배지가 이미 표시하므로 중복을 없애고, 알림의 출처가 채팅 버튼임을 형태로 드러내기 위함

#### 수감 중 지도 조작 유지

- **파일**: `lib/features/game/presentation/widgets/arrest_lock_overlay.dart`, `lib/features/game/presentation/widgets/google_map_view.dart`, `lib/core/constants/map_styles.dart`, `lib/core/constants/app_colors.dart`
- **변경 내용**: 체포 시 안내를 자동으로 띄우지 않고, 좌측 하단 수감 버튼으로 열고 배경 탭·뒤로가기로 닫는다. 수감 중에는 `MapStyles.arrested`로 배경 지도만 어둡게 하고 감옥에 노란 채움(`yellowAlpha20`)과 맥동 경계를 적용한다. 수동 탈옥 버튼은 안내 안에 남는다
- **이유**: 잠금 오버레이가 지도와 조작 버튼을 모두 가려 감옥 위치와 복귀 경로를 확인할 수 없었다
- **특이사항**: 맥동 갱신은 200ms 간격이며 앱 백그라운드·모션 감소 설정·채팅/참가자 화면으로 지도가 가려진 동안 중지한다

#### 타이머 보정

- **파일**: `lib/features/game/presentation/widgets/game_timer_text.dart`
- **변경 내용**: `didUpdateWidget`에서 남은 시간을 재계산한다. 분 표시를 `inMinutes.remainder(60)`에서 `inMinutes`로 바꿔 90분을 `90:00`으로 표시한다. 시각은 `clock.now()`로 읽고, 서버 남은 시간과 수신 시각을 받는 `GameTimerText.remaining` 생성자를 추가했다
- **이유**: 시작 시각·전체 시간이 갱신돼도 다음 tick 전까지 옛 값이 보였고, 60분 이상에서 분 표시가 0부터 반복됐다

#### 문구·테스트

- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb`, `test/features/game/presentation/pages/game_page_auto_escape_test.dart`, `test/features/chat/presentation/widgets/chat_message_bubble_test.dart`, `test/features/game/presentation/widgets/game_timer_text_test.dart` (신규)
- **변경 내용**: 채팅 패널 문구 6개를 ko/en/ja에 추가. 미리보기 위치·채널 진입, 채널별 입력·스크롤 유지, 수감 지도·안내, 타이머 재보정·60분 이상 표시 회귀 테스트 추가

### 📌 참고사항

- `GameTimerText.remaining` 생성자는 추가만 했고 `GamePage`는 기존 시작 시각 + 전체 시간 생성자를 그대로 쓴다. 서버 남은 시간 연동은 후속 작업
- 인게임 FCM 알림은 이번 범위 밖
- 실기기에서 네이티브 지도·키보드·뒤로가기·백그라운드 전환·모션 감소 설정은 아직 확인하지 않음
- 공용 입력창 이동의 커뮤니티 호출부 호환성은 정적 분석과 기존 테스트 범위에서만 확인
