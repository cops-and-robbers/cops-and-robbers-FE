### 📌 작업 개요

App Store 심사 리젝(v1.3.4) 대응. Guideline 5.1.1(iv) 위치 권한 설정 앱 자동 리다이렉트 제거 및 대기실 UI 개선

### 🔍 문제 분석

App Store 심사에서 2건의 가이드라인 위반으로 리젝:

1. **Guideline 5.1.1(iv)**: 사용자가 위치 권한 "허용 안 함" 탭 후 설정 앱으로 자동 리다이렉트하여 권한 재부여 유도
2. **Guideline 2.1(a)**: 심사팀이 전체 기능을 확인할 수 있는 데모 계정 미제공

### ✅ 구현 내용

#### 1. 위치 권한 거부 시 설정 앱 자동 리다이렉트 제거

- **파일**: `lib/core/services/permission/location_permission_service.dart`
- **변경 내용**: `ensurePermission()` 내 `Geolocator.openLocationSettings()` (위치 서비스 OFF 시) 및 `Geolocator.openAppSettings()` (권한 영구 거부 시) 자동 호출 제거. 권한 미충족 시 `false`만 반환하도록 변경
- **이유**: Apple 정책상 사용자의 권한 거부 결정을 존중해야 하며, 거부 직후 설정 앱으로 보내는 행위 불허. 호출 측(home_page.dart)에서 안내 다이얼로그 → 사용자 직접 "설정으로 이동" 버튼 탭 방식은 가이드라인에 부합하므로 유지

**특이사항**:

- `openAppSettings()`, `openLocationSettings()` 메서드 자체는 삭제하지 않음 — home_page.dart 등 사용자 자발적 선택 경로에서 사용 중
- `ensurePermission()`의 DartDoc 주석도 변경된 흐름에 맞게 갱신

#### 2. 대기실 AppBar 뒤로가기 아이콘 변경

- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: AppBar leading 아이콘 `icon_previous.svg` → `icon_exit.svg`로 변경. 좌측 패딩 18.w 추가. 라이트 모드 아이콘 색상 `AppColors.black` → `AppColors.black800`으로 조정
- **이유**: 대기실에서의 뒤로가기가 "방 나가기" 동작이므로 exit 아이콘이 의미적으로 적합

#### 3. 대기실 팀 섹션 기본 펼침 상태 변경

- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: `_isPoliceExpanded`, `_isRobberExpanded` 초기값 `false` → `true`로 변경
- **이유**: 대기실 진입 시 팀 구성원을 바로 확인할 수 있도록 개선

#### 4. 대기실 나가기 버튼 터치 영역 44x44 최소 크기 보장

- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: AppBar leading에 `leadingWidth: 62.w` 추가, `SizedBox(width: 44.w, height: 44.w)`로 GestureDetector를 감싸 터치 타겟 최소 크기 보장
- **이유**: 좌측 패딩(18.w)으로 인해 기본 leadingWidth(56) 안에서 실질 탭 영역이 약 38dp로 줄어드는 문제. App Store 심사 대응 맥락상 터치 타겟 최소 44x44 보장 필요

### 🧪 테스트 및 검증

- 위치 권한 "허용 안 함" 탭 후 설정 앱으로 자동 이동하지 않는지 확인
- 위치 권한 영구 거부 상태에서도 설정 앱 자동 이동 없이 false 반환 확인
- home_page.dart의 안내 다이얼로그 → "설정으로 이동" 버튼은 정상 동작 확인 (사용자 자발적 선택이므로 가이드라인 준수)
- 대기실 AppBar exit 아이콘 및 좌측 패딩 정상 표시 확인
- 대기실 진입 시 팀 섹션 펼침 상태 확인
- 대기실 나가기 버튼 터치 영역이 44x44 이상인지 확인
