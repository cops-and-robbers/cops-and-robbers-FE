# 원격 배너 추가 및 빈 상태 아이콘 적용

### 📌 작업 개요

Firebase Remote Config로 켜고 끄는 홈 화면 이미지 배너 신규 추가. 앱 배포 없이 콘솔에서 노출 여부·이미지·이동 링크를 제어한다.
함께 신규 에셋 `icon_not_found.svg`를 공지사항 빈 목록과 404 페이지의 빈 상태 아이콘으로 적용해 두 화면의 표현을 통일했다.

**보고서 파일**: `.report/20260813_#474_원격_배너_추가_및_빈_상태_아이콘_적용.md`

---

### 🎯 구현 목표

- Remote Config 파라미터 3개(`banner_enabled` / `banner_image_url` / `banner_link_url`)로 홈 배너를 원격 제어
- 콘솔에서 값 게시 시 앱 재시작 없이 즉시 반영
- 배너 로드 실패·설정 누락 시 화면에 빈 공간을 남기지 않는 fail-safe 동작
- 공지사항 빈 목록 / 404 페이지에 동일한 빈 상태 일러스트 적용

---

### ✅ 구현 내용

#### Remote Config 배너 파라미터 추가

- **파일**: `lib/core/services/remote_config/remote_config_keys.dart`
- **변경 내용**: `bannerEnabled`(bool), `bannerImageUrl`(String), `bannerLinkUrl`(String) 키 3개 추가. `RemoteConfigDefaults.values`에 각각 `false` / `''` / `''` 기본값 등록
- **이유**: 기존 파라미터(버전·점검·광고)와 같은 단일 정의 지점을 유지하고, fetch 실패 시에도 "안전한 꺼짐" 상태를 보장

#### Remote Config 서비스 접근자 및 실시간 갱신

- **파일**: `lib/core/services/remote_config/remote_config_service.dart`
- **변경 내용**: 배너 3개 값의 getter 추가. 미초기화 상태에서는 `bannerEnabled=false`, URL은 빈 문자열 반환. 게시된 설정을 즉시 활성화하는 `onConfigUpdated` 스트림 추가
- **이유**: Firebase 초기화 실패 시에도 배너가 뜨지 않아야 하고(광고 kill switch와 동일한 fail-safe 패턴), 콘솔에서 배너를 내리면 앱 재시작 없이 즉시 반영돼야 함

#### 홈 배너 위젯 신규 추가

- **파일**: `lib/features/session/presentation/widgets/home_banner.dart` (신규)
- **변경 내용**: 네트워크 이미지 배너 `HomeBanner` 위젯. 이미지 주소가 비었거나 로드 실패면 `SizedBox.shrink()`로 완전히 사라진다
- **이유**: 배너는 "있으면 좋은" 요소라, 실패 시 빈 박스나 깨진 이미지가 홈 레이아웃을 밀어내지 않도록 처리

#### 홈 화면 연동

- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: 게임 버튼 Row 아래에 `bannerEnabled`일 때만 `HomeBanner` 렌더. `initState`에서 Remote Config 갱신 스트림 구독 → `setState`로 재빌드, `dispose`에서 구독 해제
- **이유**: 원격 스위치 변경을 즉시 반영하면서, 화면 이탈 후 스트림이 남아 메모리 누수가 되지 않도록 정리

#### 빈 상태 아이콘 적용 (공지사항 / 404)

- **파일**: `lib/features/notice/presentation/pages/notices_page.dart`, `lib/router/app_router.dart`, `assets/icons/icon_not_found.svg` (신규)
- **변경 내용**: 공지 목록이 비었을 때 아이콘 + 안내 문구를 표시하고, 404 페이지의 `Icon(Icons.error_outline)`을 같은 SVG로 교체. 두 화면 모두 표시 폭 `110.w`
- **이유**: "결과 없음" 상황의 시각 표현을 한 에셋으로 통일. 머티리얼 기본 아이콘은 앱 디자인 톤과 맞지 않았음

#### 접근성 문구 다국어 추가

- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb` (+ `flutter gen-l10n` 재생성분)
- **변경 내용**: `homeBannerSemanticsLabel` 키 추가 — 한국어 "이벤트 배너", 영어 "Event banner", 일본어 "イベントバナー"
- **이유**: 배너는 이미지만으로 구성돼 스크린리더가 읽을 텍스트가 없음

### 🔧 주요 변경사항 상세

#### HomeBanner

`Image.network`를 `width: double.infinity` / `height: 68.h` / `BoxFit.cover`로 그리고, `frameBuilder` 안에서 상단 여백(`AppSpacing.vertical16`)과 `ClipRRect(AppRadius.large)`, 탭 처리를 감싼다.

**특이사항**:

- **빈 값 / 로드 실패 = 공간도 차지하지 않음**: `imageUrl.isEmpty`면 build 진입 즉시 `SizedBox.shrink()` 반환, 네트워크 실패는 `errorBuilder`에서 동일 처리. 배너 유무와 무관하게 홈 레이아웃이 흔들리지 않는다
- **장식을 `frameBuilder` 안에 둔 이유**: 패딩·라운드·제스처를 위젯 트리 바깥에 두면 이미지가 실패해도 여백과 터치 영역이 남는다. 이미지 프레임과 함께 생성·소멸시켜 실패 시 흔적이 남지 않게 했다
- **접근성**: `Semantics(label, button: onTap != null)`로 감싸고 내부는 `ExcludeSemantics` — 이미지의 기본 시맨틱과 중복 낭독을 막고, 링크가 없는 배너는 버튼으로 읽히지 않는다
- **탭 판정**: `HitTestBehavior.opaque`로 이미지 투명 영역에서도 탭이 먹는다

#### 홈 화면 배너 노출 조건

```dart
if (remoteConfig.bannerEnabled)
  HomeBanner(
    imageUrl: remoteConfig.bannerImageUrl,
    onTap: remoteConfig.bannerLinkUrl.isEmpty
        ? null
        : () => launchExternalUrl(remoteConfig.bannerLinkUrl),
  ),
```

`banner_link_url`이 비어 있으면 `onTap`이 `null`이 되어 이미지 전용 배너로 동작한다(링크 없는 공지성 배너 지원). 링크가 있으면 기존 `launchExternalUrl` 유틸로 외부 브라우저를 연다.

**특이사항**:

- 스트림 구독은 `onError`에서 로그만 남기고 화면은 그대로 둔다 — 실시간 채널이 끊겨도 앱 시작 시 fetch한 값으로 계속 동작
- 스크롤 영역(`SingleChildScrollView`) 안에 있어, 배너가 추가돼도 게임 버튼이 화면 밖으로 밀리지 않는다

#### Remote Config 디버그 로그

디버그 빌드 로그에 배너 URL 원문 대신 `banner_image_set: true/false` 형태로 설정 여부만 출력한다. 원격 설정값이 로그에 그대로 남지 않게 하기 위함.

#### 공지사항 빈 목록 정렬

```dart
Center(
  child: Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      SvgPicture.asset('assets/icons/icon_not_found.svg', width: 110.w),
      SizedBox(height: AppSpacing.vertical16),
      Text(l10n.pageNoticesEmpty, ...),
      // 위쪽 카테고리 필터만큼 아래를 채워, 화면 기준으로 가운데에 오게 한다
      SizedBox(height: AppSpacing.vertical64),
    ],
  ),
)
```

**특이사항**: 공지 화면은 상단에 카테고리 필터 칩이 고정돼 있어, 남은 영역 기준으로 가운데 정렬하면 눈에는 아래로 치우쳐 보인다. 텍스트 하단에 `AppSpacing.vertical64` 여백을 넣어 상단 필터 높이를 상쇄, **화면 기준** 가운데로 맞췄다.

#### SVG 에셋 최적화

`icon_not_found.svg`는 svgo로 204KB → 69.5KB (약 66% 감축).

**특이사항**:

- `floatPrecision 1` — 좌표 소수점 자릿수를 줄이는 것이 용량의 대부분을 차지. 110.w 표시 크기에서 육안 차이 없음
- **`viewBox` 제거 옵션은 반드시 꺼야 한다** — `flutter_svg`는 `viewBox`를 기준으로 스케일을 계산해서, 제거하면 아이콘이 원본 픽셀 크기로 그려지거나 깨진다
- `assets/icons/`는 pubspec에 디렉터리 단위로 등록돼 있어 개별 에셋 추가 선언은 불필요

### 📌 참고사항

- **Firebase 콘솔 파라미터 등록 필수**: `banner_enabled`(Boolean), `banner_image_url`(String), `banner_link_url`(String) 3개를 콘솔에 동일한 키로 생성해야 한다. 미등록 시 앱 기본값(꺼짐)으로만 동작
- **기본값이 꺼짐인 이유**: 배포 후 콘솔에서 켜는 안전한 롤아웃. 배너를 내려야 하는 상황(잘못된 이미지, 종료된 이벤트)에서 앱 배포 없이 즉시 차단 가능
- **릴리스 빌드 fetch 주기 1시간**: 콘솔 값 변경이 즉시 반영되는 것은 실시간 갱신 스트림이 연결된 경우이며, 스트림이 끊긴 클라이언트는 최대 1시간까지 지연될 수 있다
- **배너 이미지 규격**: 표시 영역이 `높이 68.h` / `BoxFit.cover`이므로, 좌우로 긴 비율의 이미지를 올려야 잘림이 자연스럽다
- 배너 노출/클릭 지표가 필요해지면 Analytics 이벤트 연동을 별도로 추가해야 한다 (이번 범위 제외)
