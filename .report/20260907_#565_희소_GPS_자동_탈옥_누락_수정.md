### 📌 작업 개요

감옥 내부 위치가 한 번만 수신된 뒤 도둑이 밖으로 이동하면 자동 탈옥이 실행되지 않는 문제 수정. 명확한 내부 위치는 단일 GPS 표본으로 진입을 인정하고, 이탈 표본 이후 위치 이벤트가 끊기면 캐시를 사용하지 않는 현재 위치 조회로 이탈을 한 번 더 확인한다.

### 🔍 문제 분석

`JailEscapeDetector`가 감옥 진입을 인정하려면 내부 GPS 표본 2개와 1초 경과를 모두 요구했다. 실제로 감옥에 들어왔어도 내부 표본이 한 번만 들어오면 다음 외부 표본에서 미완성 진입 후보가 지워져 탈옥 API 호출까지 도달하지 못했다.

### ✅ 구현 내용

#### 명확한 감옥 진입 단일 표본 인정
- **파일**: `lib/features/game/domain/jail_escape_detector.dart`
- **변경 내용**: 내부 위치에서 경계까지 거리가 GPS 정확도와 3m 안전 여유의 합보다 크면 한 번의 표본으로 진입 인정
- **이유**: 경계 오차 범위가 아닌 명확한 감옥 내부 위치를 GPS 수신 횟수만으로 누락하지 않기 위함

#### 희소 GPS 이탈 재확인
- **파일**: `lib/core/services/location/device_location_service.dart`, `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 첫 외부 표본 이후 2초 동안 추가 위치 이벤트가 없으면 현재 위치를 한 번 조회. 판정용 조회에서는 마지막 알려진 위치 폴백을 비활성화
- **이유**: 화면 잠금·다른 앱 사용 등 위치 스트림이 드문 상황에서도 새로운 좌표로 이탈을 확인하고, 캐시 좌표를 새 관측으로 잘못 세지 않기 위함

#### 비동기 판정 무효화
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 재체포, 게임 상태 재동기화, 연결 끊김, 게임 종료, 감옥 영역 변경, 화면 종료 시 대기 중인 위치 확인을 취소하거나 세대로 무효화
- **이유**: 이전 체포 주기의 늦은 위치 결과가 현재 수감 상태를 탈옥 처리하지 못하게 하기 위함

#### 회귀 테스트
- **파일**: `test/features/game/domain/jail_escape_detector_test.dart`, `test/features/game/presentation/pages/game_page_auto_escape_test.dart`
- **변경 내용**: 원형·폴리곤, 감옥 안/밖 체포, 단일 내부 표본, 새 위치 확인, 캐시 좌표 거부, 재체포·연결 끊김·화면 종료·조회 실패 후 복구, 백그라운드 프레임 비활성 상태 검증
