## 📋 작업 개요

세션 생성 플로우(4단계)의 페이지 전환 시 애니메이션이 없어 화면이 갑자기 바뀌는 문제를 해결하고, 중복된 UI 코드를 통합하여 유지보수성을 개선했습니다.

**주요 성과:**

- ✅ 부드러운 페이지 전환 애니메이션 구현 (150ms 페이드 효과)
- ✅ 중복 코드 ~240라인 제거 (24% 코드 감소)
- ✅ 재사용 가능한 공통 레이아웃 위젯 생성
- ✅ Null 안정성 및 상수 사용 개선

---

## 🎯 구현 목표

### 1. 페이지 전환 애니메이션 적용

**문제점:**

- 세션 생성 4단계 페이지 전환 시 애니메이션 없이 갑자기 바뀜
- 사용자 경험이 부자연스럽고 깜빡이는 느낌

**해결 방안:**

- `CustomTransitionPage`를 활용한 페이드 애니메이션 구현
- 150ms 전환 시간으로 자연스러운 전환 효과

### 2. 중복 코드 제거

**문제점:**

- 4개 페이지(구역 설정, 인원 설정, 게임 설정, 초대 코드)에서 동일한 UI 구조 반복
- AppBar, 헤더 섹션, 하단 버튼이 각 페이지마다 중복 구현
- 총 ~240라인의 중복 코드 존재

**해결 방안:**

- `SessionStepLayout` 공통 위젯 생성
- 각 페이지는 content만 제공하고 나머지는 재사용

### 3. 코드 품질 개선

- 하드코딩된 값을 상수로 변경
- Null 안정성 개선
- 불필요한 스크롤 제거

## 🛠️ 구현 내용

### 1. 페이지 전환 헬퍼 함수 생성

**파일**: [lib/core/utils/custom_page_transitions.dart](../lib/core/utils/custom_page_transitions.dart)

```dart
/// 부드러운 페이드 전환 (150ms)
CustomTransitionPage<T> buildSmoothFade<T>({
  required Widget child,
  required LocalKey key,
}) {
  return CustomTransitionPage<T>(
    key: key,
    child: child,
    transitionDuration: const Duration(milliseconds: 150),
    reverseTransitionDuration: const Duration(milliseconds: 150),
    transitionsBuilder: (context, animation, secondaryAnimation, child) {
      return FadeTransition(opacity: animation, child: child);
    },
  );
}
```

**기능:**

- `buildDirectionalSlide`: 방향성 슬라이드 전환 (우→좌, 좌→우)
- `buildInstantTransition`: 애니메이션 없는 즉각 전환
- `buildSmoothFade`: 150ms 부드러운 페이드 전환

### 2. 공통 레이아웃 위젯 생성

**파일**: [lib/features/session/presentation/widgets/session_step_layout.dart](../lib/features/session/presentation/widgets/session_step_layout.dart)

```dart
class SessionStepLayout extends StatelessWidget {
  const SessionStepLayout({
    super.key,
    required this.currentStep,      // 현재 단계 (0~3)
    required this.title,             // 헤더 제목
    required this.description,       // 헤더 설명
    required this.content,           // 페이지별 컨텐츠
    this.buttonText = '다음',        // 버튼 텍스트
    this.isButtonEnabled = true,     // 버튼 활성화 여부
    required this.onNext,            // 다음 버튼 콜백
    this.onPrevious,                 // 뒤로가기 콜백
    this.isLoading = false,          // 로딩 상태
  });

  @override
  Widget build(BuildContext context) {
    if (isLoading) {
      return Scaffold(
        appBar: _buildAppBar(context),
        body: const Center(child: CircularProgressIndicator()),
      );
    }

    return Scaffold(
      appBar: _buildAppBar(context),
      body: SafeArea(
        child: Padding(
          padding: AppPadding.all20,
          child: Column(
            children: [
              SizedBox(height: AppSpacing.vertical16),
              _buildHeader(),
              SizedBox(height: AppSpacing.vertical28),
              content,
              const Spacer(),
              _buildNextButton(),
            ],
          ),
        ),
      ),
    );
  }
}
```

**제공 기능:**

- ✅ AppBar + StepIndicator + PreviousButton
- ✅ 헤더 섹션 (제목 + 설명)
- ✅ 페이지별 컨텐츠 영역
- ✅ 하단 액션 버튼
- ✅ 로딩 상태 처리
