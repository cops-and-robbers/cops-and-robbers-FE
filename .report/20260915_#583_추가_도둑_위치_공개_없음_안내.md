# 추가 도둑 위치 공개 없음 안내

게임 종료 전에 발생할 수 없는 다음 위치 공개 카운트다운을 “추가 도둑 위치 공개는 없어요” 안내로 전환했다. 게임 잔여 2분·다음 공개 3분인 경우에도 공개를 기다리게 하던 문제를 수정한다. 관련 이슈: [#583](https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/583).

## 원인

`LocationRevealCountdown`은 공개 예정 시각이 지나면 다음 주기로 순환했지만 게임 종료 시각을 전달받지 않았다. 두 타이머에 이미 존재하던 시각 차이 계산·앱 복귀 시 갱신만으로는 종료 이후 공개 일정을 걸러낼 수 없었다.

## 구현

| 파일 | 변경 |
|---|---|
| `lib/features/game/presentation/pages/game_page.dart` | 게임 타이머와 같은 시작 시각·라운드 시간으로 종료 시각을 계산해 전달 |
| `lib/features/game/presentation/widgets/location_reveal_countdown.dart` | 다음 공개 시각이 종료 시각 이상이거나 게임 종료 시 안내 문구로 전환. 종료 시각·주기 변경 시 즉시 재계산 |
| `lib/l10n/app_*.arb` 및 생성된 로컬라이제이션 파일 | 한국어·영어·일본어 안내 추가, `flutter gen-l10n` 실행 |
| `test/features/game/presentation/widgets/location_reveal_countdown_test.dart` | 종료 경계·주기 순환·앱 복귀·설정 보정·종료 시각 미확인 테스트 추가 |
| `.issues/20260915_버그_게임_종료_이후_위치_공개_카운트다운_표시.md` | 재현 조건과 확정 안내 문구 기록 |

안내는 기존 카운트다운과 같은 위치·글꼴·팀별 색상을 사용한다. 공개 예정이 종료 이전이면 카운트다운을 유지한다. 종료 시각을 모르는 경우 기존 표시를 유지한다. 현재 시각은 기존 의존성 `clock`으로 한 번 읽어 주기 계산과 종료 판단에 함께 사용한다.

초기 숨김 처리에서 사용자 피드백에 따라 안내 문구로 변경했다. 실제 위치 공개 STOMP 이벤트 처리와 지도 마커 표시 로직은 변경하지 않았다.

## 검증

- 공개 카운트다운 4개 및 기존 게임 타이머 2개 테스트, 총 6개 통과.
- 종료 2분/공개 3분, 공개와 종료 동시, 종료 시각 보정, 마지막 공개 후 순환, 앱 복귀, 주기 변경, 종료 시각 미확인 검사.
- 안내 문구가 없는 구현에서 회귀 테스트 3개 실패, 안내 적용 후 통과.
- 변경 앱바·타이머·테스트 대상 정적 분석 문제 없음. Dart 포맷과 `git diff --check` 통과.

## 남은 확인

전체 테스트와 실제 기기·서버 연결 검증은 실행하지 않았다. 앱 생명주기 복귀는 위젯 테스트로 검증했다.
