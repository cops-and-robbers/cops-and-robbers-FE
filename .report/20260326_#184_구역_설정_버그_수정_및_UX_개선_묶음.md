### 📌 작업 개요

게임 설정에서 구역(플레이그라운드/감옥) 관련 타입 에러 수정, 비방장 구역 프리뷰 추가, 반경 최대값 조정, 키보드 직접 입력 UX 추가, 다크모드 전면 적용, 닉네임 입력 필터 추가 등 구역 설정 관련 버그와 UX를 일괄 개선

### 🔍 문제 분석

1. **타입 에러**: GoRouter `extra`를 통해 `LatLng` 객체를 직접 전달하면 상태 복원(딥링크/복원) 시 `type 'List<dynamic>' is not a subtype of type 'LatLng?'` 에러 발생
2. **비방장 구역 미표시**: 방장만 구역 설정 페이지에 접근 가능하여 일반 참여자는 설정된 구역을 확인할 수 없음
3. **과도한 반경 최대값**: 플레이그라운드·감옥 반경 max 값이 실제 게임에 비해 지나치게 큼
4. **반경 입력 UX**: 슬라이더로만 반경 조절이 가능하여 정밀한 값 입력이 어려움

### ✅ 구현 내용

#### 1. GoRouter extra 타입 에러 수정
- **파일**: `lib/router/app_router.dart`
- **변경 내용**: `LatLng` 객체 대신 `lat`, `lng` 원시 타입(double)을 `extra` Map으로 전달하고, 라우트 빌더에서 `LatLng`로 재조립
- **이유**: GoRouter의 상태 복원 과정에서 커스텀 객체가 직렬화/역직렬화 실패하는 문제 방지. 원시 타입 기반으로 변경하여 타입 안전성 확보

#### 2. 비방장 구역 읽기전용 프리뷰 페이지 추가
- **파일**: `lib/features/session/presentation/pages/zone_preview_page.dart` (신규)
- **변경 내용**: `ZonePreviewPage` — 플레이그라운드(파란색)와 감옥(빨간색) 구역을 Google Maps 위에 Circle 오버레이로 동시 표시하는 읽기전용 페이지
- **이유**: 비방장 참가자도 대기방에서 현재 설정된 구역 정보를 시각적으로 확인 가능

#### 3. 프리뷰 페이지 라우트 등록
- **파일**: `lib/router/app_router.dart`, `lib/router/route_paths.dart`
- **변경 내용**: `zone-preview` 경로 및 `gameSettingsZonePreviewName` 라우트명 추가. extra로 `playgroundLat/Lng`, `jailLat/Lng`, `playgroundRadius`, `jailRadius`를 원시 타입으로 전달
- **이유**: 비방장 접근용 구역 프리뷰 라우트 제공. 필수 좌표 누락 시 fallback 화면 표시

#### 4. 플레이그라운드·감옥 반경 최대값 축소
- **파일**: `lib/core/widgets/map/zone_setting_widget.dart`, `lib/features/session/presentation/pages/setup_playground_page.dart`, `lib/features/session/presentation/pages/setup_prison_page.dart`
- **변경 내용**: 플레이그라운드·감옥 반경 max 값을 적절한 수준으로 축소
- **이유**: 실제 게임 환경에 맞는 합리적 범위로 조정

#### 5. InfoRadiusChip 키보드 직접 입력 UX 추가
- **파일**: `lib/core/widgets/chips/info_radius_chip.dart`
- **변경 내용**: `editable` 프로퍼티 추가. 탭 시 TextField로 전환되어 숫자 키보드로 반경 값 직접 입력 가능. 100ms 디바운싱, min/max 클램핑, 포커스 해제 시 자동 편집 완료
- **이유**: 슬라이더만으로는 정밀한 값 입력이 어려운 문제 해결

#### 6. 다크모드 전면 적용
- **파일**: `lib/core/constants/map_styles.dart` (신규), `lib/core/widgets/map/zone_setting_widget.dart`, `lib/features/session/presentation/pages/zone_preview_page.dart`, 각종 위젯 파일
- **변경 내용**: `MapStyles.dark` 공통 상수로 다크맵 스타일 JSON 추출. 구역 설정·수정·프리뷰 페이지 전체에 다크모드 스타일 적용. 버튼·칩·카드 등 서브 위젯에 `isDarkMode` 파라미터 전파
- **이유**: 역할 기반 다크/라이트 모드 일관성 확보. 다크맵 스타일 중복 제거

#### 7. 닉네임 입력 한글·영문·숫자만 허용 필터 추가
- **파일**: `lib/features/auth/presentation/pages/nickname_setup_page.dart`
- **변경 내용**: `FilteringTextInputFormatter.allow(RegExp(r'[가-힣ㄱ-ㅎㅏ-ㅣa-zA-Z0-9]'))` 적용
- **이유**: 특수문자·공백 등 부적절한 닉네임 입력 사전 차단

#### 8. 코어 위젯 역할 전용 텍스트 스타일 의존 제거
- **파일**: `lib/core/widgets/buttons/my_location_button.dart`, `lib/core/widgets/buttons/previous_button.dart`, `lib/core/widgets/buttons/svg_icon_button.dart`
- **변경 내용**: 코어 위젯에서 역할(경찰/도둑) 전용 텍스트 스타일 참조를 제거하고 범용 스타일로 대체
- **이유**: 코어 레이어가 특정 도메인(역할) 스타일에 의존하는 아키텍처 위반 해소

### 🔧 주요 변경사항 상세

#### GoRouter extra 원시 타입 전달 패턴
기존: `extra`에 `LatLng` 객체를 직접 전달 → 상태 복원 시 타입 캐스팅 실패
변경: `{'lat': center.latitude, 'lng': center.longitude, 'radius': radius}` 형태로 원시 타입 전달 후 라우트 빌더에서 `LatLng(lat, lng)`로 재조립

**특이사항**:
- 감옥 수정 페이지는 플레이그라운드 좌표도 함께 전달 (`playgroundLat`, `playgroundLng`, `playgroundRadius`)
- 프리뷰 페이지는 플레이그라운드 + 감옥 좌표 4쌍 모두 필요

#### InfoRadiusChip 편집 모드
탭 → `_startEditing()` → TextField 표시 → 숫자 키보드 노출 → 100ms 디바운싱으로 실시간 반영 → 포커스 해제 or Submit 시 `_completeEditing()` → 읽기 모드 복귀

**특이사항**:
- `maxLength`는 `maxValue`의 자릿수 기반 동적 계산 (예: max 1000 → 4자리)
- 빈 입력 시 `minValue`로 자동 클램핑

#### ZonePreviewPage 구조
- `CircleZoneShape` 2개 (playground: blue, jail: red)를 Google Maps Circle 오버레이로 표시
- 반경 기반 자동 zoom 레벨 계산 (100m→17, 300m→16, 500m→15, 1000m→14)
- 플레이그라운드 중심 복귀 버튼 제공
- 다크모드 시 `MapStyles.dark` 스타일 자동 적용
