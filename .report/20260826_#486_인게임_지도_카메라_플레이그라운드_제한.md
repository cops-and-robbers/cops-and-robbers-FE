# 인게임 지도 카메라를 플레이그라운드 주변으로 제한

### 📌 작업 개요
인게임 지도에 줌아웃 제한만 있고 이동(pan) 제한이 없어 구역에서 무한히 멀리 지도를 끌고 나갈 수 있던 문제 개선.
카메라 이동을 플레이그라운드 주변(구역 반경의 30% 여유)으로 제한. 원형·다각형 구역 공통 적용, 구역 로드 전에는 무제한 유지.

**보고서 파일**: `.report/20260826_#486_인게임_지도_카메라_플레이그라운드_제한.md`

### 🎯 구현 목표
- 지도 카메라가 플레이그라운드 경계에서 크게 벗어나지 못하도록 이동 범위 제한
- 원형/다각형 구역 모두 도형 분기 없이 동일 로직으로 처리
- 구역 정보 로드 전에는 기존처럼 무제한 이동 유지 (초기 카메라 이동 방해 금지)

### ✅ 구현 내용

#### 도메인 - 구역 바운딩 박스 계산 메서드 추가
- **파일**: `lib/features/game/domain/entities/area_shape.dart`
- **변경 내용**: `AreaShape.boundingBox({marginRatio})` union 메서드 신설. centroid ± boundingRadius × (1 + marginRatio)를 평면 근사로 위경도 오프셋 환산 후 남서/북동 `GeoPoint` 레코드로 반환
- **이유**: circle/polygon 분기 없이 기존 union 게터(`centroid`, `boundingRadiusInMeters`)만 조합하여 도형 공통 처리. 도메인 계층은 google_maps 비의존 유지

#### 상수 - 카메라 이동 여유 비율 추가
- **파일**: `lib/core/constants/game_config.dart`
- **변경 내용**: `GameConfig.cameraPanMarginRatio = 0.3` 상수 추가
- **이유**: 구역 boundingRadius 대비 30% 여유를 매직 넘버 없이 한 곳에서 관리

#### 지도 위젯 - 카메라 이동 범위 상태 연결
- **파일**: `lib/features/game/presentation/widgets/google_map_view.dart`
- **변경 내용**: `_cameraTargetBounds` 상태(기본값 `CameraTargetBounds.unbounded`) 추가, `updateCameraBounds(LatLngBounds)` 공개 메서드 추가, `GoogleMap(cameraTargetBounds:)` 파라미터 연결
- **이유**: 구역 로드 전 무제한 → 로드 후 제한으로 전환되는 흐름을 기존 `updateMinZoom`·`updateAreaCircles`와 동일한 공개 메서드 패턴으로 구현

#### 게임 페이지 - 구역 로드 시 바운드 주입
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `gameAreaProvider` listen 블록(minZoom·구역 오버레이 주입하는 기존 자리)에서 `playground.boundingBox(marginRatio: GameConfig.cameraPanMarginRatio)` 계산 후 `LatLngBounds`로 변환해 `updateCameraBounds` 호출
- **이유**: 구역 로드 완료 시점에 줌 제한·오버레이와 함께 카메라 이동 제한을 한 곳에서 일괄 적용

### 🔧 주요 변경사항 상세

#### AreaShape.boundingBox
지구 반경 6,371km 기반 평면 근사로 미터 → 위경도 오프셋 변환. 경도 오프셋은 위도별 축소(`cos(latitude)`)를 보정하여 위도와 동일한 실거리 확보.
도메인 타입(`GeoPoint` 레코드)만 반환하므로 지도 SDK 교체나 테스트 시 google_maps 의존 없음.

**특이사항**:
- 길쭉한 폴리곤은 boundingRadius 기반이라 짧은 축 방향 여유가 실제보다 후해짐 — "구역에서 크게 못 벗어나게" 하는 목적에는 충분하며, 도형별 정밀 박스는 필요 시 확장
- 날짜변경선·극지방 미지원 (한국 서비스 전제, 기존 `contains` 판정과 동일한 근사 기준)

#### GoogleMapView
`_cameraTargetBounds` 초기값이 `CameraTargetBounds.unbounded`이므로 구역 로드 전(로비 진입 직후, 현재 위치로 카메라 이동 시점)에는 동작 변화 없음.
`updateCameraBounds`는 `mounted` 가드 후 `setState`로 반영 — 기존 공개 메서드들과 동일한 방어 패턴.

#### game_page.dart
도메인 `GeoPoint` → 지도 SDK `LatLng` 변환은 presentation 계층(listen 블록)에서만 수행. 계층 의존 방향 유지.

### 📌 참고사항
- 제한 기준은 감옥이 아닌 **플레이그라운드** 구역 — 감옥은 항상 플레이그라운드 내부이므로 별도 처리 불필요
- 여유 비율 조정이 필요하면 `GameConfig.cameraPanMarginRatio` 값만 변경하면 됨
- Google Maps `cameraTargetBounds`는 카메라 **중심점** 기준 제한 — 화면 가장자리는 박스 밖 영역이 일부 보일 수 있으나 30% 여유 설계에 이미 반영된 동작
