### 📌 작업 개요

PR #148 코드 리뷰에서 발견된 아키텍처, DRY, 런타임 안전성, 디자인 시스템 이슈를 반영하고, 추가로 채팅 바텀시트 UX 개선 및 앱 재설치 시 토큰 초기화 로직을 구현

**이슈**: [#154](https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/154)

---

### 🎯 구현 목표

1. chat feature → game feature 크로스 의존성 제거 (Feature-First 아키텍처 준수)
2. 하드코딩된 이벤트 메시지 문자열 상수화 (DRY 원칙)
3. 소켓 재연결 시 위치 전송 스트림 재시작 보강
4. 채팅 바텀시트 키보드 연동 및 스와이프 UX 개선
5. 앱 재설치 시 iOS Keychain 잔존 토큰 자동 초기화

---

### ✅ 구현 내용

#### 1. 게임 이벤트 시스템 메시지 아키텍처 개선

- **파일**: `chat_overlay.dart`, `game_page.dart`, `game_event_provider.dart`
- **변경 내용**: `chat_overlay.dart`에서 `game_event_provider.dart` import 및 4개의 `ref.listen`, `_lastHandled*` 필드를 완전히 제거. 해당 로직을 `game_page.dart`로 이동하여 두 feature 간 중재자(mediator) 역할 수행
- **이유**: chat feature가 game feature에 직접 의존하면 Feature-First 아키텍처 위반. `game_page.dart`는 이미 양 feature를 조합하는 화면이므로 이벤트 중재에 적합

#### 2. 게임 이벤트 메시지 상수 클래스 추출

- **파일**: `lib/core/constants/game_event_messages.dart` (신규)
- **변경 내용**: `GameEventMessages` 상수 클래스 추가 (gameStart, policeMove, locationReveal, gameOver 4개 메시지). `game_event_provider.dart`와 `game_page.dart` 양쪽에서 동일 상수 참조
- **이유**: 동일 한국어 메시지가 두 파일에 각각 하드코딩되어 있어 DRY 위반. 한쪽만 수정 시 불일치 위험 해소

#### 3. 소켓 재연결 시 위치 전송 스트림 재시작

- **파일**: `game_page.dart`
- **변경 내용**: `_reconnectSocketsIfNeeded()`에서 도둑 팀 `_locationSubscription`이 null(onError/onDone에서 해제)이면 `_startLocationSending()` 재호출
- **이유**: 기존에는 소켓 재연결만 하고 위치 전송 스트림은 재시작하지 않아 특정 타이밍에 도둑 팀 GPS 전송이 중단될 수 있었음

#### 4. `_initSettingsFromApiIfNeeded` mounted 체크 보강

- **파일**: `game_page.dart`
- **변경 내용**: `initFromLobby()` 호출 후 `setGameStartTime()` 직전에 `if (!mounted) return` 추가
- **이유**: async gap 이후 연속 호출 구간에서 dispose된 위젯에 접근하는 엣지 케이스 방지

#### 5. 위치 공개 카운트다운 재접속 시 동기화 수정

- **파일**: `game_page.dart`
- **변경 내용**: `nextRevealTime` 계산 시 `policeMoveStartTime`이 null(재접속으로 STOMP 미수신)이면 `gameStartTime + policeWaitMinutes`를 fallback으로 사용
- **이유**: 재접속 시 STOMP 이벤트를 받지 못해 카운트다운이 `--:--`로 표시되는 문제 해결

#### 6. 채팅 바텀시트 키보드/스와이프 UX 전면 개선

- **파일**: `chat_overlay.dart`, `chat_input_bar.dart`, `chat_message_list.dart`
- **변경 내용**:
  - `game_page.dart`에 `resizeToAvoidBottomInset: false` 적용 → 키보드 올라올 때 지도 리사이즈 방지
  - 키보드 열림 시 `minChildSize = 0.75`로 시트 자동 확장, 닫힘 시 `animateTo(0.5)` (키보드 닫힘 시작 감지로 동시 애니메이션)
  - 채팅 리스트 overscroll 감지(`NotificationListener<OverscrollNotification>`) → 끝까지 스크롤 후 계속 아래로 스와이프 시 시트 접기
  - 입력바/하단 여백 아래 스와이프로 시트 접기 (`GestureDetector`)
  - `Listener`로 포인터 추적 → 채팅 리스트에서 드래그하다 입력바 영역 도달 시 시트 접기
  - 빈 공간(지도) 탭 시 키보드 + 시트 동시 닫힘
  - `snapSizes` Flutter API 계약 위반 수정 (min/max 범위 밖 snap 값 필터링)
  - 키보드 닫히는 중 `bottomMargin` 즉시 `safeBottomMargin`으로 전환 → 입력바 튀는 현상 해결
- **이유**: 기존에 키보드 올라올 때 지도가 축소되고, 채팅 시트를 스와이프로 닫을 수 없어 UX가 불편했음

#### 7. 채팅 입력바 전송 후 키보드 유지

- **파일**: `chat_input_bar.dart`
- **변경 내용**: 메시지 전송 후 `_focusNode.requestFocus()`로 키보드 유지. 빈 텍스트로 전송 버튼 탭 시에만 `_focusNode.unfocus()`로 키보드 닫힘
- **이유**: 연속 메시지 전송 시 매번 키보드가 닫히면 불편

#### 8. 참가자 카드 본인 닉네임 스타일 개선

- **파일**: `participant_card.dart`, `text_styles.dart`
- **변경 내용**: `fontFamily: 'Pretendard-SemiBold'` 하드코딩 제거. `AppTextStyles.tag10Bold` (10px Pretendard-Bold) 신규 추가. 본인 닉네임에 `tag10Bold` + `AppColors.black600` 적용
- **이유**: fontFamily 문자열 직접 지정은 폰트 에셋 변경 시 silent failure 위험. 디자인 시스템 상수 사용

#### 9. 앱 재설치 시 Keychain 토큰 자동 초기화

- **파일**: `secure_token_storage.dart`, `main.dart`
- **변경 내용**: `clearTokensIfReinstalled()` 메서드 추가. `SharedPreferences`의 `has_run_before` 플래그로 재설치 감지. 앱 시작 시 `main.dart`에서 호출
- **이유**: iOS에서 앱 삭제 후에도 Keychain 데이터가 잔존하여 재설치 시 만료된 토큰으로 인증 시도 → 강제 로그아웃 발생 가능. Android는 앱 삭제 시 EncryptedSharedPreferences가 자동 삭제되므로 no-op

#### 10. 기타 UI 개선

- **대기실 앱바**: 초대코드 `copy.svg` 아이콘 제거, 텍스트에 underline 추가 (`decorationThickness: 2`, 간격 `2.h`)
- **공지사항 목록**: 마지막 아이템 하단 Divider 제거 (`isLast` 파라미터 추가)
- **설정 페이지**: 알림/위치 권한 → `AppSettings.openAppSettings()`로 OS 설정 직접 이동
- **StompConnectionState re-export**: `chat_provider.dart`에서 re-export 추가하여 `chat_overlay.dart`가 game feature 없이 해당 타입 사용 가능

### 📌 참고사항

- 채팅 바텀시트 키보드 연동은 `resizeToAvoidBottomInset: false` + `MediaQuery.viewInsets.bottom`으로 수동 제어하는 구조. 키보드 높이 변화를 `_prevKeyboardHeight`로 추적하여 닫힘 시작 감지
- `_isCollapsingFromKeyboard` 플래그로 키보드 닫히는 중 `effectiveMinSize`를 `_minSize`로 즉시 전환하여 `animateTo(0.5)` 허용
- `snapSizes`는 `effectiveMinSize`와 `effectiveSnap75` 사이 값만 포함하도록 필터링하여 Flutter API 계약 준수
