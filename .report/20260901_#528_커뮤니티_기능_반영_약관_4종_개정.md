### 📌 작업 개요

`docs/legals/` 아래 법적 문서 4종(이용약관·개인정보처리방침·위치정보이용약관·마케팅정보수신)을 개정 원고 수준으로 갱신했다. 기존 원고(최종 시행 2026-06-29)는 게임 기능만을 전제로 작성되어 있었으나, 이후 추가된 커뮤니티 기능(모집 게시판·게시글 채팅·댓글·알림·신고)이 전혀 반영되어 있지 않았고, 코드 실측과 어긋나는 서술 6곳도 함께 확인되어 이번 작업에서 정정했다.

### 🎯 구현 목표

- 커뮤니티 서비스 관련 신설 조항을 이용약관·개인정보처리방침·위치정보이용약관에 각각 반영한다.
- 실제 코드 동작과 문서 서술이 어긋나는 부분(닉네임 보유기간, 실시간 좌표 처리 방식, 위치 수집 주기, 설정 메뉴 존재 여부, FGS 알림 동작, 마케팅 철회 경로)을 실측 기준으로 정정한다.
- 시행 전 검수가 필요한 지점은 `<!-- 검수 -->` 주석으로 표시해 후속 절차(법무 확인, 웹 반영)에서 놓치지 않도록 한다.

### ✅ 구현 내용

#### 이용약관 (`docs/legals/이용약관.md`)

- **정의 추가(제2조)**: "커뮤니티 서비스"(⑦), "게시물"(⑧) 정의 신설.
- **제9조의2 신설**: 게시물 권리 귀속과 회사의 이용 허락 범위, 모집 게시판이 비로그인·웹 방문자에게도 공개될 수 있다는 고지, 탈퇴 후 게시물 잔존(작성자 익명 처리) 및 탈퇴 전 직접 삭제 가능, 게시물 삭제·노출 제한 사유, 신고 기능, 오프라인 모임 참여 시 이용자 본인 책임을 규정.
- **금지행위 추가(제8조)**: 영리 목적 광고·도배(11호), 커뮤니티를 통한 개인정보 무단 게시·유포(12호) 신설.
- **면책 확장(제15조)**: 커뮤니티 게시물·채팅·오프라인 모임에서 발생한 분쟁 및 제3자와의 관계 문제를 면책 범위에 포함.
- **면책 조항 정비(제10조⑤)**: 무료 서비스 면책이 제19조 제1항과 충돌하던 부분을 제19조 기준으로 일원화.
- **정의·제5조**: 서비스 목록에 "커뮤니티 서비스"(7호) 추가.

#### 개인정보처리방침 (`docs/legals/개인정보처리방침.md`)

- **⑨ 커뮤니티 활동 정보 신설(2-1)**: 모집 게시글·댓글·채팅·좋아요·스크랩·알림·신고 내용의 수집 항목·목적·보유기간을 명시. 게시글 삭제 시 연관 데이터 함께 삭제, 회원 탈퇴 시에는 삭제하지 않고 작성자 익명 처리, 알림 내역은 최근 60일 제공으로 정리.
- **5-2 커뮤니티 위치정보 이용 신설**: 모집 게시글 작성 시 좌표→주소 변환(국내: VWorld, 국외: Geoapify)과 거리순 정렬 시 현재 위치를 저장 없이 계산에만 사용하는 두 가지 이용 방식을 구분해 명시.
- **위탁·국외이전(7·8절)**: 국토교통부 VWorld(국내 좌표 변환)와 KEPTAGO LTD(Geoapify 운영사, 키프로스 — 국외 좌표 변환)를 위탁처·국외이전 대상에 추가.
- **실측 정정**: 닉네임 항목을 "2~10자"에서 "최대 20자"로 수정(회원 가입 정보 항목, ①).

#### 위치정보이용약관 (`docs/legals/위치정보이용약관.md`)

- **서비스 목록(제3조)**: "커뮤니티 모임 장소 표시 서비스"(6호), "커뮤니티 거리순 정렬 서비스"(7호) 추가.
- **제4조의2 신설**: 커뮤니티 기능에서의 위치정보 이용을 게임 중 실시간 수집과 분리해 규정 — 포그라운드 상태에서만 일시적으로 이용되며 백그라운드에서는 이루어지지 않음을 명시하고, 벤더 전송(VWorld/Geoapify) 사실과 거리순 정렬 시 미저장 원칙을 기술.
- **제4조④ 정정**: "게임 진행 중이 아니면 위치를 수집하지 않는다"는 기존 단정 표현을 "백그라운드에서는 수집하지 않는다"로 한정 — 커뮤니티 기능의 포그라운드 위치 이용과 모순되지 않도록 수정.
- **제11조 고지 기간**: 확장 기능 도입 시 사전 고지 기간을 이용약관 제3조 제3항(7일/30일)에 준용하도록 정비.

#### 마케팅정보수신 (`docs/legals/마케팅정보수신.md`)

- **제7조 철회 경로 정정**: 문서상 존재하지 않던 경로 서술을 실제 UI 경로인 "마이페이지 > 약관 설정"(`/mypage/agreements`)으로 정정.

### 🔧 주요 변경사항 상세

**실동작 대조로 정정한 거짓 서술 6곳**

| 항목 | 기존 서술 | 정정 내용 |
|---|---|---|
| 닉네임 보유기간 | 계정 속성인데 "세션 종료 시" | 회원 탈퇴 시까지로 정정 |
| 실시간 좌표 처리 | "즉시 전달 후 폐기" | 게임 진행 중 서버에 암호화 보관, 세션 종료 시 삭제로 정정 |
| 위치 수집 주기 | "3~5초" 고정 주기 | 거리 변화 기준 스트림 방식으로 정정 |
| 위치 권한 관리 메뉴 | "앱 내 설정 > 위치 권한 관리" | v3 앱에 존재하지 않는 메뉴 — 기기 설정 경로로 정정 |

**원고 상태**: 시행일(고지 게시 +7일)과 회사 주소는 확정 전이라 빈칸으로 남겨두었다. `<!-- 검수 -->` 주석 총 9곳은 법무·서버 실측 확인이 필요한 지점(예: 위치정보 확인자료 기록 미구현, VWorld/Geoapify의 법적 지위, Geoapify 이전 국가 표기 등)을 표시한 것으로, 시행 전 별도 확인이 필요하다.

### 🧪 테스트 및 검증

- 법적 문서 자체는 마크다운 콘텐츠 변경으로, 별도의 자동화 테스트 대상은 아니다.
- `lib/core/constants/app_urls.dart`의 `AppUrls.legalDocument`(ko/ja/en 언어별 웹뷰 경로 생성)와 이를 검증하는 `test/core/constants/app_urls_test.dart`는 문서 4종이 웹 정본(`dongsim-web`)에서 다국어로 제공되는 구조를 뒷받침하는 기존 코드로, 이번 문서 개정과 별개로 앱 쪽 라우팅 정합성을 담보한다.
- 코드 변경(`onboarding_page.dart`, `splash_page.dart`, `app_router.dart`, `lib/l10n/*`)은 이번 이슈의 작업 범위인 약관 원고 개정과 직접적인 관련이 확인되지 않았다 — 각 파일을 직접 읽어 확인한 결과 법적 문서 관련 서술이나 참조가 없었다. git 명령을 사용하지 않는 제약으로 정확한 diff 대조는 수행하지 못했으며, 별도 작업(온보딩 관련)의 워킹트리 잔여분일 가능성이 있다.

### 📌 참고사항

- 원고는 이 이슈 브랜치에서 커밋 후 웹 담당자에게 전달되어야 하며, 웹 정본(`dongsim-web/content/legal/{ko,ja,en}`)에 번역 반영(ja/en 신설 특칙 보존) 및 legal 폰트 서브셋 재생성이 필요하다.
- 시행 7일 전 인앱 공지 + 웹 고지 후, 시행일에 필수 3종 재동의 리셋(어드민 GraphQL `termsResetPreview` → `resetTermsAgreement`)이 필요하다.
- 리셋 실행 전 FE 전역 `REQUIRED_TERMS_NOT_AGREED` 400 처리 실기기 확인이 선행되어야 한다(#515 잔여 이슈).
- 위치정보 수집·이용·제공사실 확인자료 기록이 서버에 없는 상태(개인정보처리방침 ⑦·위치정보이용약관 8조 서술과 실제 구현 간 괴리)는 법무 확인과 별도 판단이 필요한 사항으로 남아 있다.
- 스토어 콘솔에 등록된 기존 개인정보처리방침 URL 교체가 후속 절차로 남아 있다.
