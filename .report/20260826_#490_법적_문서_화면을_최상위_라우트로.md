### 📌 작업 개요

법적 문서 화면을 `/legal/:doc` 최상위 라우트로 올렸다.

열한 곳이 `Navigator.push` 로 이 화면을 띄우고 있었다. 전환 연출이 앱의 다른 화면과 어긋나고, 화면이 제목을 인자로 받아 문서와 어긋난 조합이 나올 여지가 있었다.

- 커밋 3개 / 파일 10개 / +197 −111
- `flutter analyze` 에러 · 경고 0, 테스트 766개 통과

### 🎯 구현 목표

- 열한 곳의 진입을 라우트 이동 하나로 통일하고 전환을 앱 공용 슬라이드에 맞춘다
- 제목을 문서 종류에서 끌어와 어긋난 조합이 나올 수 없게 한다
- 오픈소스 라이선스만 마이페이지 하위에 있던 것을 같은 라우트로 흡수한다

### ✅ 구현 내용

#### 문서 종류에서 제목을 끌어오는 함수

- **파일**: `legal_doc.dart`, `legal_doc_test.dart` 신규
- **변경 내용**: `legalDocTitle(l10n, doc)` 과 경로 조각을 문서 종류로 되돌리는 `legalDocFromSlug(slug)` 를 추가했다
- **이유**: 제목은 문서가 정해지면 따라오는 값이다. 호출부가 따로 넘기면 이용약관 제목에 개인정보 문서를 띄우는 조합을 아무도 잡지 못한다

`legalDocFromSlug` 는 라우트가 임의의 문자열을 받을 수 있어 필요하다.

#### 최상위 라우트 신설

- **파일**: `app_router.dart`, `route_paths.dart`
- **변경 내용**: `/legal/:doc` 를 셸 라우트 바깥에 두고, 마이페이지 하위의 오픈소스 라이선스 라우트를 없앴다
- **이유**: 마이페이지 하위가 아니라 최상위인 것은 로그인과 가입 동의 화면에서도 같은 화면을 열기 때문이다

모르는 조각이 들어오면 라우트 `redirect` 가 홈으로 보낸다. `redirect` 가 `pageBuilder` 보다 먼저 돌아, 화면을 만드는 시점에는 문서가 반드시 정해져 있다.

#### 호출부 열한 곳 교체

- **파일**: `login_page.dart`, `agreement_page.dart`, `agreement_settings_page.dart`, `my_page.dart`
- **변경 내용**: 로그인 3, 가입 동의 4, 약관 설정 4, 마이페이지 라이선스 1을 `context.push(RoutePaths.legalDocumentOf(doc))` 로 바꿨다. 두 화면에 있던 `_openDetail` 헬퍼가 사라졌다
- **이유**: 경로 조립을 `RoutePaths` 한 곳에 모으면 호출부는 문서 종류만 고르면 된다

`RoutePaths.legalDocumentOf` 는 문자열이 아니라 `LegalDoc` 을 받는다. 문자열을 받으면 import 하나가 줄지만 오타를 잡지 못해, 이번 작업의 목적과 반대가 된다.

### 🔧 주요 변경사항 상세

#### 인증 가드에 걸리던 진입점 일곱 곳

`Navigator.push` 는 라우터를 거치지 않는다. 라우트로 올리면 인증 가드를 통과해야 하는데 `/legal/:doc` 이 허용 목록에 없었다.

| 진입점 | 상태 | 가드 판정 |
|---|---|---|
| 로그인 하단 약관 3개 | 미로그인 | 공개 경로가 아니라 `/login` 으로 되돌림 |
| 가입 동의 상세 4개 | 필수 약관 미동의 | `/agreement` 외 전부 차단 |
| 마이페이지 약관 4개 + 라이선스 | 정상 회원 | 통과 |

약관은 로그인 이전에도 읽을 수 있어야 하는 문서라, 인증 검사보다 앞에 통과 조건을 뒀다.

접두사가 어긋나면 다시 조용히 막히는 자리다. 호출부가 만드는 경로가 가드 조건과 맞는지 확인하는 테스트를 함께 넣었다.

#### 전환 연출

라우터는 커스텀 전환을 스물여덟 곳에서 쓰는데 법적 문서만 `MaterialPageRoute` 기본 전환이었다. 마이페이지에서 약관 설정까지는 슬라이드로 들어가는데 거기서 상세로 넘어갈 때만 플랫폼 기본이었다.

**특이사항**

- 라우트는 셸 라우트 바깥에 있다. 탭 스택에 남지 않는다
- `flutter_deeplinking_enabled` 가 꺼져 있고 딥링크는 초대 링크만 통과시키는 화이트리스트다. 경로가 생겨도 외부 진입점이 되지 않는다
- `legalDocFromSlug` 가 이동 한 번에 두 번 돈다. 값이 다섯 개인 선형 탐색이고, 없애려면 go_router 쪽이 더 복잡해진다

### 🧪 테스트 및 검증

- 마이페이지 약관 설정 상세 4종과 오픈소스 라이선스 진입 확인
