### 📌 작업 개요

게임 제한 시간과 다음 위치 공개 시간을 서로 다른 기준으로 갱신해 초가 어긋나던 문제를 수정했다.
경찰 재접속 시 대기 팝업이 중복 표시되거나 다른 팝업에 가려진 채 남는 문제도 함께 보완했다.

### 🔍 문제 분석

- 게임 타이머와 위치 공개 카운트다운이 각각 시간을 계산하고 갱신해 재빌드·주기 경계·앱 복귀 시 초 단위 차이가 발생했다.
- 서버의 남은 시간을 받은 시각을 고정하지 않으면 재빌드마다 타이머 기준점이 바뀔 수 있었다.
- 경찰 대기 팝업은 게임 설정을 불러오기 전에 표시를 시도하거나, 설정 보완 후 같은 경로에서 다시 열릴 수 있었다.
- 자동 닫힘 팝업 위에 다른 팝업이 표시되면 단순 `pop`으로는 만료된 팝업 자신의 라우트를 제거하지 못했다.

### ✅ 구현 내용

#### 게임·위치 공개 타이머 기준 통일

- **파일**: `lib/features/game/presentation/widgets/game_timer_text.dart`, `lib/features/game/presentation/widgets/location_reveal_countdown.dart`
- **변경 내용**: 게임 시작 시각과 현재 시각의 차이로 두 카운트다운을 함께 계산하고, 하나의 1초 갱신 타이머로 표시를 갱신
- **이유**: 두 표시가 재빌드와 주기 경계에서도 같은 초를 사용하도록 보장

서버가 남은 시간을 직접 반환하는 화면은 응답 수신 시각을 기준점으로 고정한다. 앱이 포그라운드로 돌아오거나 위젯 입력이 갱신되면 현재 시각을 즉시 다시 읽어 장시간 백그라운드 이후에도 실제 경과 시간을 반영한다.

다음 위치 공개 시각은 게임 시작 시각, 경찰 대기 시간, 위치 공개 간격으로 계산한다. 한 주기가 지난 경우 다음 주기까지 남은 시간으로 이동하며, 게임 제한 시간이 한 시간을 넘어도 전체 분을 유지한다.

#### 경찰 대기 팝업 표시 순서 보완

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: 재접속 시 게임 설정 보완을 마친 뒤 경찰 대기 팝업을 표시하고, 서버 시작 시각을 기준으로 실제 남은 시간만 전달
- **이유**: 설정 누락으로 팝업을 놓치거나 동일 진입에서 중복 생성되는 문제 방지

대기 시간이 이미 끝났거나 경찰 팀이 아니면 팝업을 열지 않는다. 아직 남아 있으면 전체 설정 시간이 아니라 현재 시각을 뺀 남은 시간만 표시하고 자동으로 닫는다.

#### 자동 닫힘 팝업 수명주기 수정

- **파일**: `lib/core/widgets/dialogs/app_popup.dart`
- **변경 내용**: 만료 시 현재 라우트면 닫고, 다른 팝업에 가려져 있으면 만료된 자신의 라우트만 제거. 앱 복귀 시 종료 시각을 기준으로 남은 시간을 다시 예약
- **이유**: 뒤에 가려진 경찰 대기 팝업이 남거나 위에 표시된 팝업을 잘못 닫는 문제 방지

화면 제거 시 타이머와 생명주기 옵저버를 정리하고, 자동 닫힘 팝업은 시스템 뒤로가기로 임의 종료되지 않도록 유지한다.

### 🧪 테스트 및 검증

- 서버 남은 시간의 응답 수신 시각 기준 갱신과 재수신 보정 확인
- 60분 초과 게임 시간 표시 확인
- 재빌드·위치 공개 주기 경계·앱 복귀 후 두 타이머의 초 일치 확인
- 설정이 늦게 도착한 경우 두 타이머 동시 시작 확인
- 경찰 재접속 시 대기 팝업 단일 표시와 만료 후 종료 확인
- 다른 팝업에 가려진 자동 닫힘 팝업만 제거되는 동작 확인
- 정적 분석 통과

### 📌 참고사항

- 타이머는 서버 시작 시각 또는 서버 응답 수신 시각을 기준으로 하며, 화면 재빌드 시각을 새로운 기준으로 사용하지 않는다.
- 위치 공개 카운트다운의 시간 계산과 주기 갱신은 게임 타이머가 소유한다.
