## 🐛 Critical Issue: 메모리 누수 수정

### 문제 발견 (코드 리뷰)

**심각도**: 🔴 CRITICAL
**카테고리**: Memory Leak

#### 원인 분석

[lifecycle_test_page.dart:109-124] 초기 구현:
```dart
// ❌ 문제: Stream 구독을 저장하지 않아 dispose 불가능
Geolocator.getPositionStream(
  locationSettings: locationSettings,
).listen(
  (Position position) {
    debugPrint('📍 위치 업데이트: ${position.latitude}, ${position.longitude}');
  },
  onError: (error) {
    debugPrint('❌ 위치 추적 에러: $error');
  },
);
```

#### 문제점
1. **메모리 누수**: Stream 구독이 위젯 dispose 후에도 계속 유지됨
2. **배터리 소모**: GPS가 페이지 종료 후에도 계속 실행됨
3. **중복 실행 가능**: 버튼을 여러 번 누르면 다중 Stream 생성
4. **리소스 낭비**: 사용하지 않는 위치 서비스가 계속 실행됨

### 수정 구현

### Stream 생명주기 관리

```
Widget initState
    ↓
Start Location Stream
    ↓
Save StreamSubscription Reference
    ↓
Widget Active (listening to position updates)
    ↓
Widget dispose
    ↓
Cancel StreamSubscription  ← 🔑 Memory Leak Prevention
    ↓
```

```
Start Location Tracking
    ↓
Permission Check
    ├─ Denied → Show SnackBar → Restore State

        ↓
    Platform Check
        ├─ iOS → AppleSettings (blue bar)
```

## 🎓 학습 포인트

### Flutter Stream 관리 베스트 프랙티스

1. **항상 StreamSubscription 참조 저장**
   ```dart
   StreamSubscription<T>? _subscription;
   _subscription = stream.listen(...);
   ```

2. **dispose에서 반드시 cancel 호출**
   ```dart
   @override
   void dispose() {
     _subscription?.cancel();
     super.dispose();
   }
   ```

3. **중복 구독 방지**
   ```dart
   await _subscription?.cancel();  // 기존 구독 취소
   _subscription = newStream.listen(...);  // 새 구독 시작
   ```

4. **에러 핸들러에서 상태 복원**
   ```dart
   onError: (error) {
     if (mounted) {
       setState(() { /* restore state */ });
     }
   }
   ```

### 플랫폼별 백그라운드 위치 추적

- **iOS**: `allowBackgroundLocationUpdates` + `showBackgroundLocationIndicator`
- **Android**: `ForegroundNotificationConfig` (필수, API 26+)
- **권한**: iOS는 Info.plist, Android는 AndroidManifest.xml 설정 필수
