### 📌 작업 개요

설정 > 앱 버전 5탭으로 진입하는 크레딧 화면을 네이티브 하드코딩 구현에서 웹 정본 임베드 웹뷰로 전환. 인원·기여가 바뀌면 이제 웹 저장소의 `content/credits/credits.json` 수정과 웹 배포만으로 끝나고, 앱 재배포·심사가 필요 없다. 법적 문서 전환(DEC-0036, #481)과 같은 패턴이다.

**보고서 파일**: `.report/20260901_#519_크레딧_화면을_웹_정본_웹뷰로_전환.md`

### 🎯 구현 목표

- 크레딧 정본을 웹으로 옮기고 앱은 웹뷰로 가져온다 (웹 쪽은 dongsim-web#82 / PR dongsim-web#83 으로 완료)
- 진입 경로(버전 5탭 이스터에그)·라우트·블러 페이드 전환은 그대로 유지한다
- 네이티브 크레딧 구현과 번들 사진을 제거해 앱 용량을 줄인다

### 🔍 문제 분석

- `CreditsPage` 가 멤버 7명의 이름·역할·사진(13장)·소셜 링크와 도와준 분들 16명의 기여 티어를 전부 코드와 에셋으로 들고 있었다. 사람이 바뀌면 심사를 다시 받아야 했다.
- 다국어 이름 키(`creditMember*`) 23종이 arb 세 벌에 걸쳐 있었고, 화면 전환 후에는 전부 미사용이 된다.
- 법적 문서가 이미 같은 문제를 웹 정본 + 임베드 웹뷰로 풀었으므로(`legal_document_page.dart`), 검증된 골격을 재사용하되 크레딧의 두 가지 차이(다크 화면, 소셜 외부 링크)만 다르게 처리하면 된다.

### ✅ 구현 내용

#### 크레딧 웹뷰 주소 추가

- **파일**: `lib/core/constants/app_urls.dart`
- **변경 내용**: `AppUrls.credits` 상수 추가 (`$site/credits/embed`)
- **이유**: 화면에 문장이 거의 없어(이름·역할) 언어 분기 없는 단일 주소로 둔다. 법적 문서와 달리 `LegalDoc` enum 을 확장하지 않는 이유이기도 하다 - 크레딧은 법적 문서가 아니고, 제목·언어 매핑 같은 enum 의 부가 계약이 필요 없다

#### CreditsPage 를 웹뷰 구현으로 교체

- **파일**: `lib/features/credits/presentation/pages/credits_page.dart`
- **변경 내용**: 네이티브 카드 목록 구현을 웹뷰 구현으로 전면 교체. JS off, 메인 프레임만 실패 처리, 로딩 스피너·재시도 화면은 `legal_document_page.dart` 골격 그대로
- **이유**: 웹 화면이 밤 지도(#22262B)라 배경·스피너·앱바를 같은 색으로 맞춰 전환에서 흰 화면이 번쩍이지 않게 했다. 앱바는 제목 없이 뒤로가기만 얹는다 - 제목은 웹이 로고로 그린다

#### 소셜 링크의 외부 브라우저 위임

- **파일**: `lib/features/credits/presentation/pages/credits_page.dart`
- **변경 내용**: 내비게이션 판정에서 같은 호스트는 내부 진행, 그 외 https 는 `launchExternalUrl` 로 외부 브라우저에 위임하고 웹뷰 이동은 막는다. 단 로딩 중의 타 호스트 이동은 실패로 처리한다
- **이유**: 멤버 카드의 GitHub·인스타그램 링크는 브라우저에서 열리는 게 맞다(legal 은 링크가 없어 전부 차단). 로딩 중의 이동만은 링크 탭이 아니라 공용 와이파이 포털 가로채기이므로 재시도 화면을 보여준다

#### 네이티브 크레딧 구현·에셋 제거

- **파일**: `lib/features/credits/` 5개 파일, `assets/credits/` 사진 13장, `pubspec.yaml`
- **변경 내용**: `credit_member.dart`(멤버 데이터), `credit_detail_page.dart`, `credit_card_widget.dart`, `flipping_profile_image.dart`, `marquee_widget.dart` 와 사진 에셋 삭제, pubspec 의 `assets/credits/` 항목 제거
- **이유**: 정본이 웹으로 옮겨져 전부 미사용이 됐다. 사진 13장이 번들에서 빠져 앱 용량이 줄어든다

#### 미사용 다국어 문자열 정리

- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb` 및 생성 파일 4개
- **변경 내용**: `creditMember*` 23종과 `pageCreditsTitle` 키 제거 후 로컬라이제이션 재생성
- **이유**: 이름 로컬라이즈는 이제 웹 정본의 몫이다. 미사용 키를 남기면 다음 정리 때 사용 여부를 다시 조사하게 된다

### 🔧 주요 변경사항 상세

#### 웹 정본과의 색 이음새

웹 크레딧 화면의 지도 타일 색(#22262B)을 페이지 로컬 상수로 두고 배경·스피너 오버레이·앱바에 동일하게 썼다. 값의 출처(dongsim-web `lib/credits/embed-html.ts`)를 주석으로 남겨, 웹 쪽 색이 바뀌면 함께 맞출 수 있게 했다.

#### 실패 문구 재사용

로드 실패 화면의 문구는 기존 `errorLegalDocumentLoadFailed`("문서를 불러오지 못했어요")를 재사용했다. 새 키를 3개 언어에 추가할 만큼 크레딧 전용 문구가 필요하지 않다.
