## 📌 작업 개요

구역 설정 페이지(플레이그라운드/감옥)에서 재진입 시 "setState called during build" 에러 발생 문제 해결. `ZoneSettingWidget`의 초기화 콜백이 부모 위젯 빌드 중에 `setState()`를 호출하여 Flutter 규칙 위반하던 문제를 PostFrameCallback으로 수정.

---

## 🔍 문제 분석

### 발생 상황

- 사용자가 구역(플레이그라운드/감옥)을 설정하고 저장
- 이전 페이지로 돌아감
- 다시 구역 설정 페이지로 진입
- **에러 발생**: `setState() or markNeedsBuild() called during build`

### 근본 원인

**호출 체인**:

```
1. SetupPlaygroundPage.build() 실행 중
2. └─ ZoneSettingWidget 생성 및 빌드
3.    └─ _initializeZone() 호출 (async)
4.       └─ widget.onZoneChanged() 콜백 호출 (동기적)
5.          └─ SetupPlaygroundPage._onZoneChanged() 실행
6.             └─ setState() 호출 ⚠️ BUILD 중에 부모 위젯의 setState!
```

**Flutter 규칙 위반**:

- 빌드 중에는 자신이나 조상 위젯의 `setState()` 호출 금지
- 첫 진입 시에는 발생하지 않았던 이유: `_currentCenter`가 null → async 지연 → 빌드 완료 후 콜백
- 재진입 시 발생하는 이유: `_currentCenter`가 이미 존재 → 즉시 완료 → 빌드 중에 콜백 → **에러!**

## ✅ 구현 내용

### 1. ZoneSettingWidget 수정

**파일**: `lib/core/widgets/map/zone_setting_widget.dart`

#### PostFrameCallback 적용

**위치**: Line 166-170

**변경 전**:

```dart
// 초기화 완료 시 부모 위젯에 초기 중심점과 반경 알림
widget.onZoneChanged(_currentCenter, _currentRadius);
```

**변경 후**:

```dart
// 초기화 완료 시 부모 위젯에 초기 중심점과 반경 알림
// ⚠️ 빌드 중 setState 방지: 다음 프레임에서 콜백 실행
WidgetsBinding.instance.addPostFrameCallback((_) {
  if (mounted) {
    widget.onZoneChanged(_currentCenter, _currentRadius);
  }
});
```

**해결 원리**:

- `addPostFrameCallback`은 현재 프레임의 빌드가 완전히 끝난 후 실행
- 이중 `mounted` 체크로 안전성 강화:
  1. 초기화 시점: 위젯이 마운트되어 있는지 확인
  2. 콜백 실행 시점: 다음 프레임에서도 여전히 마운트되어 있는지 확인

### 2. 부모 위젯 (변경 없음)

**파일**:

- `lib/features/session/presentation/pages/setup_playground_page.dart`
- `lib/features/session/presentation/pages/setup_prison_page.dart`

**변경 사항**: 없음

- `_onZoneChanged()` 콜백 그대로 유지
- `ZoneSettingWidget`이 콜백 호출 타이밍만 조정하므로 부모는 영향 없음

## 🔧 주요 변경사항 상세

### PostFrameCallback 패턴

Flutter 공식 권장 패턴으로, 빌드 중에 상태 변경이 필요한 경우 다음 프레임으로 연기:

```dart
WidgetsBinding.instance.addPostFrameCallback((_) {
  if (mounted) {
    // 상태 변경 로직
  }
});
```

**장점**:

- 빌드 완료 후 실행되어 Flutter 규칙 준수
- 1프레임(~16ms) 지연, 사용자 인지 불가
- 초기화 시 1회만 실행, 성능 영향 무시할 수준

**안전성**:

- `mounted` 체크로 위젯이 dispose된 후 실행되는 것 방지
- 빠른 화면 전환 시에도 안전하게 동작

### 플랫폼별 영향

- **iOS**: 정상 동작 유지 (기존과 동일)
- **Android**: 정상 동작 유지 (기존과 동일)
- 첫 진입과 재진입 모두 동일한 동작

## 🧪 테스트 및 검증

### 필수 테스트 시나리오

1. **플레이그라운드 첫 진입**
   - 세션 생성 → 플레이그라운드 설정 진입
   - 지도 로드 확인
   - 완료 버튼 활성화 확인
   - 완료 클릭 → 저장 성공

2. **플레이그라운드 재진입** (핵심 테스트)
   - 플레이그라운드 설정 재진입
   - ✅ **"setState called during build" 에러 없음** 확인
   - 지도 로드 및 기존 데이터 표시 확인
   - 반경 수정 → 저장 → 재진입 반복

3. **감옥 설정** (동일 패턴)
   - 감옥 설정 첫 진입 → 저장
   - 재진입 → 에러 없는지 확인

4. **빠른 화면 전환**
   - 플레이그라운드 설정 진입
   - 지도 로드 중 즉시 뒤로가기
   - 다시 진입 → 에러 없는지 확인
