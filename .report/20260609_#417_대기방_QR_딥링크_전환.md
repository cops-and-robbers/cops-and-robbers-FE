# 대기방 QR 코드를 딥링크 URL로 전환 #417

### 📌 작업 개요

대기방 QR 코드가 초대코드를 JSON으로 인코딩해 앱 내 스캐너로만 인식되던 문제를 해결.
공유 버튼과 동일한 딥링크 URL을 QR에 담아, 인앱 스캐너와 일반 카메라 양쪽에서 방 참가가 가능하도록 전환.
더불어 3곳에 흩어진 도메인 매직 상수를 단일 상수로 통일.

### 🎯 구현 목표

- 대기방 QR 데이터를 JSON → 딥링크 URL(`https://{host}/join/{code}`)로 변경
- 인앱 QR 스캐너로 스캔 시 방 참가 (기존 파싱 로직 재사용)
- 일반 카메라로 촬영 시 딥링크로 앱 실행 → 자동 참가 (기존 딥링크 인프라 활용)
- 도메인 host를 단일 상수로 중앙화

### ✅ 구현 내용

#### 딥링크 URL 생성 함수 추출
- **파일**: `lib/core/utils/share_util.dart`
- **변경 내용**: `buildInviteDeeplink(code)` 함수 추출, `shareInviteCode`가 이를 사용하도록 변경
- **이유**: 공유 메시지와 대기방 QR이 동일한 URL 형식을 단일 소스로 공유하도록 함

#### 대기방 QR 데이터 변경
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: `_showInviteCodeDialog`의 QR 데이터를 `jsonEncode({'inviteCode': code})` → `buildInviteDeeplink(code)`로 변경, 고아가 된 `dart:convert` import 제거
- **이유**: QR이 딥링크 URL을 담아야 일반 카메라 촬영 시에도 앱 실행/자동 참가로 연결됨

#### 도메인 host 상수 단일화
- **파일**: `lib/core/deeplink/deeplink_constants.dart` (신규)
- **변경 내용**: `DeeplinkConstants.host = 'copsnro66ers.site'` 상수 신설
- **이유**: 생성(share_util) / 파싱(deeplink_event) / 스캐너(home_page) 3곳에 중복된 도메인 문자열을 단일 소스로 통일

#### 파서·스캐너의 도메인 참조 교체
- **파일**: `lib/core/deeplink/deeplink_event.dart`, `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: `allowedHosts = {DeeplinkConstants.host}`, 스캐너 `uri.host == DeeplinkConstants.host`로 교체
- **이유**: 도메인 변경 시 Dart 코드 수정 지점을 1곳으로 축소

### 🔧 주요 변경사항 상세

#### 데이터 흐름 (인앱 스캐너)
QR(딥링크 URL) → 스캐너 `onParse`가 URL에서 6자리 코드 추출 → `Navigator.pop(추출된 코드)` → `_joinRoom(code)` 호출.
스캐너의 `onParse`가 "URL → 코드" 변환 경계 역할을 하므로, QR 포맷이 URL로 바뀌어도 `_joinRoom`은 변경 없이 6자리 코드를 그대로 수신.

#### 데이터 흐름 (일반 카메라)
QR(https URL) → 카메라가 링크로 인식 → App Links/Universal Links로 앱 실행 → 라우터 `/join/:code` → `DeepLinkJoinPage` 자동 참가.
딥링크 수신 인프라(`deeplink_event.dart`, 라우터, `DeepLinkJoinPage`)는 기존 구축분을 그대로 활용.

**특이사항**:
- 인앱 스캐너의 레거시 JSON fallback은 유지 — 구버전 앱이 생성한 JSON QR을 신버전 앱이 스캔하는 롤아웃 호환용
- 네이티브 설정 2곳(`AndroidManifest.xml`의 App Links host, `Runner.entitlements`의 applinks)은 빌드타임 설정이라 Dart 상수를 참조 불가 → 도메인 변경 시 수동 동기화 필요. `DeeplinkConstants` doc에 경고 명시
