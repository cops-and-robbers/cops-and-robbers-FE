### 📌 작업 개요

QR 코드 기반 방 입장 기능 추가 및 초대코드 UI 개선. 대기방에서 초대코드를 QR로 표시하고, 홈 화면에서 QR 스캔으로 방에 참가할 수 있도록 구현. 기존 텍스트 입력 방식과 QR 스캔 방식을 병행 지원.

### 🎯 구현 목표

- 대기방 초대코드 공유 다이얼로그에 QR 코드 이미지 표시
- 홈 화면 방 참여 다이얼로그에서 QR 스캔으로 자동 참가
- 기존 QR 스캐너(체포용)를 제네릭화하여 초대코드용으로 재사용
- 초대코드 언더라인 너비를 텍스트 실제 너비에 맞게 수정

### ✅ 구현 내용

#### 1. QrScannerPage 제네릭 콜백 방식으로 확장

- **파일**: `lib/features/game/presentation/widgets/qr_scanner_page.dart`
- **변경 내용**: 기존 체포 전용 스캐너를 `QrScannerPage<T>`로 제네릭화. `title`(안내 텍스트)과 `onParse`(QR 파싱 콜백) 파라미터를 받아 체포용/초대코드용 공용으로 사용. 기존 `_parseQrData` 하드코딩 메서드 제거.

#### 2. 초대코드 공유 다이얼로그에 QR 코드 이미지 추가

- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: `_showInviteCodeDialog`의 customContent에 `QrImageView` 추가. QR 데이터 형식은 `{"inviteCode": "A1B2C3"}`. QR 이미지에 `ClipRRect(borderRadius: AppRadius.xxlarge)` 적용. 초대코드 텍스트 스타일을 `label16Medium`/`robberLabel`로 변경하고 기존 외곽선 컨테이너 제거.

#### 3. 홈 화면 방 참여 다이얼로그에 QR 스캔 기능 추가

- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: `AppTextField`의 `suffixIcon`에 카메라 아이콘(`icon_camera.svg`) 추가. 탭 시 다이얼로그를 닫고 `QrScannerPage<String>`을 열어 QR 코드 스캔. 스캔 성공 시 `_joinRoom` 메서드로 자동 방 참가. 기존 `onConfirm` 내부의 방 참가 로직을 `_joinRoom` 메서드로 추출하여 텍스트 입력/QR 스캔 양쪽에서 공용 호출.

#### 4. 체포 스캐너 호출부 수정

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: `_openQrScanner`에서 `QrScannerPage<int>(title, onParse)` 새 API로 호출. 기존 `_parseQrData` 로직을 인라인 `onParse` 콜백으로 이동.

#### 5. 초대코드 언더라인 너비 수정

- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: 기존 `_inviteCode!.length * 12.w + 8.w` 고정 너비 계산을 `IntrinsicWidth` 위젯으로 대체. 텍스트 실제 렌더링 너비에 맞춰 언더라인이 자동 조정되어 가변폭 문자(M, W 등) 문제 해결.

#### 6. 방 참여 로딩 팝업 안정성 개선

- **파일**: `lib/features/session/presentation/pages/home_page.dart`
- **변경 내용**: `_joinRoom` 메서드의 API 호출 예외 처리를 `try-finally`로 변경. `DioException` 외 예상치 못한 예외 발생 시에도 로딩 팝업이 반드시 닫히도록 보장. CodeRabbit 리뷰 피드백 반영.

### 🔧 주요 변경사항 상세

#### QR 데이터 형식

- 초대코드 QR: `{"inviteCode": "A1B2C3"}` (6자 영숫자)
- 체포 QR: `{"pid": 505}` (기존 유지)
- 서로 다른 키(`inviteCode` vs `pid`)로 구분 가능

#### 방 참가 플로우 (QR 스캔)

1. 홈 화면 → "방 참여하기" 다이얼로그
2. AppTextField 우측 카메라 아이콘 탭
3. 다이얼로그 닫힘 → QR 스캐너 페이지 오픈
4. QR 스캔 → `{"inviteCode": "..."}` 파싱 → 6자 검증
5. `_joinRoom()` → 로딩 → API 호출 → 대기실 이동

### 📌 참고사항

- QR 생성에 `qr_flutter`, 스캔에 `mobile_scanner` 패키지 사용 (기존 의존성, 추가 설치 불필요)
- QR 스캔은 앱 내 전용 스캐너로만 동작 (딥링크/유니버설 링크 미지원)
- 서버 통신 불필요 — QR 데이터에 초대코드 텍스트만 포함, 기존 `joinGameProvider` API 그대로 사용
- 카메라 권한 거부 시 기존 체포 스캐너와 동일하게 설정 이동 다이얼로그 표시
