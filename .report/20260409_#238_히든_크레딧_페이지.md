### 📌 작업 개요

설정 페이지 앱 버전 영역을 2초 내 5회 연속 탭하면 진입하는 히든 크레딧 페이지 구현. 팀원 카드 가로 스크롤 + Hero 애니메이션 상세 페이지 + 소셜 링크 + Special Thanks 마키 텍스트 포함.

### 🎯 구현 목표

- 이스터에그 형태의 히든 크레딧 페이지 추가
- 팀원 6명의 프로필 카드 가로 스크롤 표시
- 카드 탭 시 상세 페이지 전환 (Hero 애니메이션)
- 상세 페이지에서 소셜 링크 (GitHub, Instagram, Discord 등) 연결
- 로딩 문구에 이스터에그 힌트 추가

### ✅ 구현 내용

#### 크레딧 멤버 데이터 모델
- **파일**: `lib/features/credits/domain/credit_member.dart`
- **변경 내용**: `SocialType` 열거형, `SocialLink`, `CreditMember`, `CreditHelper` 클래스 정의. 팀원 6명 + 도움을 준 분들의 하드코딩 데이터 포함
- **이유**: 백엔드 API 없이 앱 내에서 직접 관리하는 정적 데이터

#### 크레딧 페이지 (카드 목록)
- **파일**: `lib/features/credits/presentation/pages/credits_page.dart`
- **변경 내용**: 팀원 카드를 가로 스크롤로 표시하는 메인 크레딧 페이지. 하단에 Special Thanks 마키 텍스트 배치
- **이유**: 카드 형태로 팀원을 시각적으로 표현하여 이스터에그 발견의 재미 제공

#### 크레딧 상세 페이지
- **파일**: `lib/features/credits/presentation/pages/credit_detail_page.dart`
- **변경 내용**: 카드 탭 시 Hero 애니메이션으로 전환되는 상세 페이지. 프로필 사진, 이름, 역할, 소셜 링크 버튼 표시
- **이유**: `url_launcher`로 소셜 링크 직접 열기 지원

#### 크레딧 카드 위젯
- **파일**: `lib/features/credits/presentation/widgets/credit_card_widget.dart`
- **변경 내용**: 프로필 사진 + 이름 + 역할 카드 위젯. Hero 태그로 상세 페이지 전환 애니메이션 연동
- **이유**: 재사용 가능한 카드 컴포넌트로 분리

#### 마키 위젯 (Special Thanks)
- **파일**: `lib/features/credits/presentation/widgets/marquee_widget.dart`
- **변경 내용**: `ScrollController` 기반 무한 우→좌 스크롤 마키 위젯. 두 벌 복제로 이음새 없는 루프 구현
- **이유**: 크레딧 페이지 하단에 "특별히 감사한 분들" 텍스트를 자연스럽게 표시

#### 설정 페이지 이스터에그 트리거
- **파일**: `lib/features/settings/presentation/pages/settings_page.dart`
- **변경 내용**: 앱 버전 영역에 탭 카운터 추가. 마지막 탭으로부터 2초 초과 시 리셋, 5회 달성 시 크레딧 페이지 진입. `elasticOut` 스케일 애니메이션으로 전환
- **이유**: Android 개발자 옵션과 유사한 숨겨진 진입 방식

#### 로딩 문구 확장 + 이스터에그 힌트
- **파일**: `assets/messages/loading_messages.json`
- **변경 내용**: 전 카테고리(delete_account 제외)에 이스터에그 힌트 문구 3종 추가 ("설정 어딘가를 계속 누르면 비밀이 열린다던데...", "앱 버전을 자꾸 누르면 뭔가 나올지도...?", "누군가 버전 번호에 비밀을 숨겨뒀다는 소문이..."). 각 카테고리별 세계관 몰입형 일반 문구 2개씩도 추가
- **이유**: 이스터에그 발견 확률을 높이면서 로딩 경험 다양화

#### 라우터 등록
- **파일**: `lib/router/app_router.dart`, `lib/router/route_paths.dart`
- **변경 내용**: `/credits` 경로에 크레딧 페이지 등록
- **이유**: GoRouter 기반 네비게이션 통합

### 🔧 주요 변경사항 상세

#### 이스터에그 진입 로직
`_versionTapCount`와 `_lastVersionTap`으로 탭 간격 2초 기준 카운팅. 5회 달성 시 `PageRouteBuilder`로 `elasticOut` 스케일 애니메이션 적용.

#### 소셜 링크 타입
`SocialType` 열거형으로 7종 지원: github, instagram, discord, linkedin, youtube, email, website. SVG 아이콘 에셋 또는 FontAwesome 아이콘으로 표시.

**특이사항**:
- 소셜 링크 URL이 플레이스홀더 상태인 멤버 존재 → 릴리즈 전 실제 URL로 교체 필요
- 마키 위젯의 `halfExtent` 계산이 `maxScrollExtent / 2`로 근사치 사용 → 넓은 화면에서 약간의 점프가 발생할 수 있음
