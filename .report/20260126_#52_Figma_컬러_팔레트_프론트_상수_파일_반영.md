## 🔧 구현 세부사항

### 파일 경로

- **수정된 파일**: [lib/core/constants/app_colors.dart](../lib/core/constants/app_colors.dart)

### 네이밍 컨벤션

- **Figma 스네이크 케이스** → **Dart 카멜 케이스** 변환
  - 예: `black_900` → `black900`
  - 예: `deep_green` → `deepGreen`
  - 예: `green_200` → `green200`

### 코드 구조

```dart
/// Figma 디자인 시스템 컬러 팔레트
///
/// 2026-01-26 업데이트: 전체 색상 시스템 교체
abstract class AppColors {
  // 기본 색상 (Base Colors)
  static const Color white = Color(0xFFFFFFFF);
  static const Color black = Color(0xFF080A0C);

  // Black Scale (흑백 그라디언트)
  static const Color black900 = Color(0xFF1E232A);
  // ... (12단계 그라디언트)

  // Green Scale (초록색 계열)
  static const Color green = Color(0xFF38F55B);
  // ... (3단계)

  // 그 외 색상 계열들...
}
```

## 📝 사용 예시

### 기본 사용법

```dart
// 흰색/검은색
Container(color: AppColors.white)
Container(color: AppColors.black)

// Black Scale (그라디언트)
Text('진하게', style: TextStyle(color: AppColors.black900))
Text('중간', style: TextStyle(color: AppColors.black500))
Text('옅게', style: TextStyle(color: AppColors.black100))

// 색상 계열 사용
Container(color: AppColors.green)      // 기본 초록
Container(color: AppColors.green200)   // 밝은 초록
Container(color: AppColors.green100)   // 매우 밝은 초록
```

### Theme 연동

```dart
ThemeData(
  primaryColor: AppColors.green,
  scaffoldBackgroundColor: AppColors.black10,
  colorScheme: ColorScheme(
    primary: AppColors.green,
    secondary: AppColors.blue,
    error: AppColors.red,
    // ...
  ),
)
```
