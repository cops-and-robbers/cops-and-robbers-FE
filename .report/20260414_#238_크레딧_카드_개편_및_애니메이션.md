# 히든 크레딧 페이지 — 카드 레이아웃 개편 & 인터랙션 보강 #238

### 📌 작업 개요

기존 히든 크레딧 페이지의 카드 UI와 인터랙션을 개편. 프로필 사진을 여러 장 제공할 수 있도록 확장하고 동전 뒤집기 애니메이션 추가, 카드 레이아웃을 크게 재구성, 소셜 아이콘을 카드에 노출, website 아이콘 교체, README/LICENSE 문서 정리까지 포함.

### 🎯 구현 목표

- 멤버별 프로필 사진 다중 등록 및 n초 주기 동전 뒤집기
- 크레딧 카드의 사진 영역 확대 (원형 110 → 둥근 사각형 168×180)
- 카드에 소셜 링크를 아이콘 전용으로 노출
- 상세 페이지 프로필 이미지 확대 (150 → 220)
- website 소셜 아이콘을 블로그 상징으로 교체
- README 라이센스 표기를 ELv2 기반 Source-Available 로 최신화

### ✅ 구현 내용

#### 크레딧 멤버 데이터 모델 확장

- **파일**: `lib/features/credits/domain/credit_member.dart`
- **변경 내용**: `profileAsset: String` 단수 필드를 `profileAssets: List<String>` 로 교체. 박찬빈은 `FE-Park1~4.jpeg` 4장, 이창희는 `member3.png + BE-Lee.jpeg` 2장, 홍의민은 `FE-Hong1.jpeg + FE-Hong2.JPG` 2장으로 배정.
- **이유**: 여러 사진을 돌려 가며 보여주는 동전 뒤집기 애니메이션의 입력을 지원하기 위해 컬렉션 형태로 일반화.

#### FlippingProfileImage 위젯 신규 작성

- **파일**: `lib/features/credits/presentation/widgets/flipping_profile_image.dart` (신규)
- **변경 내용**:
  - `width / height` 별도 파라미터 + `borderRadius` 지원 (null 이면 `ClipOval`, 값이 있으면 `ClipRRect`).
  - `AnimationController` 로 Y축 0°→180° 회전. 90°(진행률 0.5)를 통과하는 순간 다음 이미지로 교체, 90°~180° 구간은 `angle - π` 로 미러링해 뒷면 방지.
  - 회전 완료 후 `interval`(기본 3초) 대기 → 다음 회전 스케줄.
  - 사진이 1장 이하면 정적 이미지로 표시, 애니메이션 비활성화.
  - `gaplessPlayback: true` 로 이미지 교체 깜빡임 방지, 로드 실패 시 `Icons.person` fallback.
- **이유**: 카드/상세 양쪽에서 재사용 가능한 단일 표시 컴포넌트로 분리. 원근감(`setEntry(3, 2, 0.001)`)을 적용해 자연스러운 플립 효과 구현.

#### 크레딧 카드 레이아웃 개편 (E2 시안)

- **파일**: `lib/features/credits/presentation/widgets/credit_card_widget.dart`
- **변경 내용**:
  - 프로필 이미지: 원형 `110.w` → 둥근 사각형 `168.w × 180.h`, `AppRadius.xlarge` 적용.
  - 이름/역할 아래에 **소셜 아이콘 전용 Row** 추가 (`_SocialIconRow`). SVG 아이콘은 `SvgPicture.asset`, 나머지는 `Icon` 으로 16.w 크기, `AppSpacing.horizontal6` 간격. 개별 탭 동작 없이 카드 전체 탭으로 상세 이동.
  - 기존 컨테이너(어두운 배경 + 테두리 + 패딩)는 유지, 하단 그라디언트는 적용하지 않음.
- **이유**: 사용자가 선택한 E2 시안(168×180) 기준으로 카드 내부를 사진이 지배하면서도 컨테이너 정체성을 유지. 카드 폭 200 - 패딩 32 = 168 내부에 7개 아이콘(112 + 간격 36 = 148)이 여유 있게 들어가도록 치수 계산.

### 🔧 주요 변경사항 상세

#### FlippingProfileImage — 동전 뒤집기 알고리즘

```
angle     = controller.value * π
displayAngle = angle > π/2 ? angle - π : angle
Matrix4.rotationY(displayAngle)  // setEntry(3,2,0.001) 로 원근감
```

- `controller.value < 0.5` : 0° → 90° 로 회전하며 현재 이미지가 접힘.
- `controller.value == 0.5` : 리스너에서 `_currentIndex = (_currentIndex+1) % length` 로 교체.
- `controller.value > 0.5` : `angle - π` 로 180°→0° 로 복귀하며 새 이미지 노출(뒷면 미러링 방지).
- `AnimationStatus.completed` 수신 시 컨트롤러 reset + `Future.delayed(interval)` 로 다음 플립 예약.

**특이사항**:

- 카드마다 독립 타이머로 움직임. "다 같이 맞추면 더 좋을까" 논의 결과, 시선 분산/번잡함 완화를 위해 **독립 실행 유지** 결정.
- Hero 전환 중에는 플립 애니메이션이 진행되어도 시각적 문제 없음. 둥근 사각형(카드) ↔ 원형(상세) 모양 전이는 Flutter Hero 기본 크로스페이드로 처리.

#### CreditCardWidget `_SocialIconRow`

7개 소셜 타입(`github, instagram, discord, linkedin, youtube, email, website`) 을 한 줄에 나열. SVG 아이콘 보유 타입은 `SvgPicture.asset`, email/website 는 FontAwesome `IconData` 로 그림. 각 아이콘에 별도 `GestureDetector` 를 두지 않고 카드 루트 탭으로만 상세 이동 → 오탭/중복 탭 이슈 차단.

#### 카드 ↔ 상세 Hero 태그

`tag: 'credit_${member.name}'` 로 이름 기준 매칭 유지. 모양(사각형↔원형)과 크기(168×180 ↔ 220×220) 가 달라도 Hero 는 동작.
