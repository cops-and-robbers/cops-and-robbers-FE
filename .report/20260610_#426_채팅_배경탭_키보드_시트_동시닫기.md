# 채팅 배경 탭 한 번으로 키보드+시트 동시 닫기

### 📌 작업 개요
인게임 채팅에서 키보드가 열려있을 때 채팅을 내리려면 ①키보드 닫기 → ②배경 탭 2단계가 필요했던 불편을 개선. 배경 탭 한 번으로 키보드와 채팅 시트가 함께 닫히도록 구현

**보고서 파일**: `.report/20260610_#426_채팅_배경탭_키보드_시트_동시닫기.md`

### 🔍 문제 분석
- 기존 배경 탭 가드 조건이 `_isExpanded && !isKeyboardOpen` — 키보드가 열려있는 동안엔 배경 탭이 아예 비활성화되어 2단계 조작 필요
- 과거 동일 기능 시도(#166, #177)에서 키보드 닫기 상태가 다이얼로그까지 전파되거나, 복합 상태 플래그 간 상호작용으로 드래그 핸들 버그가 발생해 롤백한 이력 존재
- 추가 제약: 키보드가 닫히는 동안 `effectiveMinSize`가 75%로 고정되어, 키보드 닫힘과 동시에 시트를 내리면 애니메이션 경합 발생 (#166 실패 경로)

### ✅ 구현 내용

#### 배경 탭 가드 확장 + 닫기 시퀀스 분리
- **파일**: `lib/features/chat/presentation/widgets/chat_overlay.dart` (단일 파일)
- **변경 내용**:
  - 배경 탭 가드 조건 `_isExpanded && !isKeyboardOpen` → `_isExpanded`로 확장 (키보드 열림 중에도 탭 가능)
  - `_onBackgroundTap()` 핸들러 추가 — 키보드 열림 시 `unfocus()` + 접기 예약, 닫힘 시 기존 `_collapseSheet()` 그대로
  - `_pendingCollapse` 로컬 플래그 추가 — build에서 키보드 닫힘 완료 시점(`!isKeyboardOpen`)에 post-frame으로 한 번만 collapse 실행
  - `_onInputFocused()`에서 플래그 리셋 — 배경 탭 직후 입력창 재탭 시 뒤늦은 collapse 방지
- **이유**: 키보드 닫힘 애니메이션과 시트 애니메이션의 경합을 피하기 위해 "unfocus 먼저 → 키보드 닫힘 완료 후 시트 접기" 시퀀스로 분리

### 🔧 주요 변경사항 상세

#### 과거 실패 원인 회피 설계
- **상태 전파 차단**: `_pendingCollapse`는 ChatOverlay State 로컬 필드로만 관리. Provider나 부모 위젯으로 전파하지 않음. 다이얼로그 등 외부 요인의 unfocus로 키보드가 닫혀도 플래그가 꺼져있어 시트는 움직이지 않음
- **플래그 최소화**: #177은 `_collapseScheduled`, `onVerticalDragUpdate`, `onFocusLost` 등 복합 플래그 상호작용이 문제였음. 이번엔 단방향 플래그 1개로만 구성

**특이사항**:
- 안드로이드 시스템 뒤로가기는 IME가 시스템 레벨에서 소비 → 키보드만 닫히고 시트는 유지 (플래그가 꺼져있어 격리 설계가 그대로 작동, 변경 전과 동일 동작)
- 별개 발견: `game_page.dart`에 PopScope가 없어 키보드 닫힌 상태에서 뒤로가기 시 게임 화면이 pop되어 이탈 가능 — 별도 이슈 검토 필요
