### 📌 작업 개요

게임 화면에서 플레이그라운드 밖에 있는 상태로 웹소켓이 끊겨 재연결 모달이 올라왔다가 닫힐 때, 여전히 구역 밖인데도 "플레이그라운드를 벗어났어요!" 팝업이 복구되지 않던 버그 수정. 재연결 모달 진입 시점에 보류 플래그(`_pendingZoneExit`)를 세팅하는 조건을 추가해, 기존 복구 경로(`_processPendingZoneExit`)가 모달 종료 후 팝업과 진동을 다시 실행하도록 처리.

---

### 🔍 문제 분석

#### 근본 원인: `ZoneExitDetector` 의 상태 전환 한정 콜백

`ZoneExitDetector` 는 구역 안↔밖 **전환 시점**에만 `onExitZone`/`onEnterZone` 콜백을 발화. 이미 밖인 상태에서 위치 업데이트가 반복돼도 동일 콜백이 재호출되지 않음.

#### 버그 시나리오

```
① 구역 밖 → 이탈 팝업 표시 (detector._isOutside = true, _isZoneExitPopupShown = true)
② 웹소켓 끊김 → _showReconnectModalIfNeeded() 실행
   ├─ 스택 충돌 방지 위해 _dismissZoneExitPopup() 으로 이탈 팝업 강제 종료
   │  └─ _pendingZoneExit 를 세팅하지 않고 지나감 ← 🐛 구멍
   └─ ReconnectModal 표시
③ 재연결 성공 → ReconnectModal .then() 실행
   └─ _processPendingZoneExit() 호출
      └─ _pendingZoneExit == false 이므로 아무 동작 안 함
④ 유저는 여전히 구역 밖이지만 팝업이 복구되지 않음
```

기존 로직은 **"재연결 모달 중 새로 이탈한 경우"** 만 `_pendingZoneExit = true` 를 세팅했고, **"이미 이탈 중인 상태에서 모달이 올라온 경우"** 는 누락되어 있었음.

### 🔧 주요 변경사항 상세

#### `_showReconnectModalIfNeeded()` 순서 보장

```dart
// 이탈 팝업이 떠 있거나 현재 구역 밖이라면, 재연결 모달이 닫힌 뒤
// 팝업을 복구해야 함을 보류 플래그로 기록한다.
// (ZoneExitDetector 는 상태 전환에만 콜백이 발화하므로 모달 종료 후
//  위치 업데이트만으로는 자동 복구되지 않음)
if (shouldMarkZoneExitAsPendingOnReconnect(
  isPopupShown: _isZoneExitPopupShown,
  isDetectorOutside: _zoneExitDetector.isOutside,
)) {
  _pendingZoneExit = true;
}

// 구역 이탈 팝업이 떠 있으면 먼저 닫음
_dismissZoneExitPopup();
```

**특이사항**:
- 플래그 세팅이 반드시 `_dismissZoneExitPopup()` 보다 먼저 실행되어야 함. `whenComplete` 가 `_isZoneExitPopupShown = false` 로 만들기 때문
- `_processPendingZoneExit()` 내부의 `_zoneExitDetector.isOutside` 재확인으로 이중 방어 — 모달 종료 시점에 구역으로 복귀했다면 복구하지 않음

#### `_pendingZoneExit` 의미 확장
- 기존: "재연결 모달 중 새 이탈 발생"
- 변경 후: "재연결 모달 종료 후 팝업 복구 필요" (두 경로 포괄)
  - 경로 1: 재연결 모달 표시 중 새 이탈 (기존 `onExitZone` 콜백)
  - 경로 2: 모달 진입 시점에 이미 이탈 중 (신규 추가)

#### 계층 배치 결정
첫 구현 시 `lib/features/game/domain/zone_exit_detector.dart` 에 판정 함수를 뒀다가, 코드 리뷰에서 "Domain 파일에 UI 상태 파라미터가 들어와 계층 경계가 흐려진다" 는 지적이 있어 `lib/features/game/presentation/helpers/` 로 이동. Domain 파일은 변경 없이 원상복구.

| D. 구역 밖 → 모달 중 구역 복귀 → 재연결 | 팝업 뜨지 않음 (`onEnterZone` 에서 플래그 리셋) | ✅ 기존 로직 재사용 |
