### 📌 작업 개요

체포 방식을 기존 UI 버튼 탭 방식에서 QR 코드 기반으로 변경. 도둑이 QR 코드를 보여주고 경찰이 스캔하여 체포하는 플로우로 전환하여 물리적 대면을 유도한다. 백엔드 변경 없이 기존 체포 API를 그대로 활용.

### 🎯 구현 목표

- 도둑: 게임 중 자신의 QR 코드(participantId 인코딩)를 화면에 표시
- 경찰: QR 코드를 스캔하여 즉시 체포 (확인 모달 없이 바로 API 호출)
- 참가자 카드 탭 시 기존 체포 모달은 유지 (QR과 병행)
- 카메라 권한 거부 시 설정 안내 다이얼로그

### ✅ 구현 내용

#### 1. 도둑 QR 표시 다이얼로그
- **파일**: `lib/features/game/presentation/widgets/qr_display_dialog.dart` (신규)
- **변경 내용**: `QrDisplayDialog.show()`로 호출. `participantId`를 JSON `{"pid": <id>}` 형태로 QR 인코딩. 다크모드(도둑팀) 지원

#### 2. 경찰 QR 스캐너 페이지
- **파일**: `lib/features/game/presentation/widgets/qr_scanner_page.dart` (신규)
- **변경 내용**: `MobileScanner`로 카메라 뷰파인더 구현. QR 감지 시 JSON 파싱 → `pid` 추출 → `Navigator.pop(participantId)` 반환. 첫 번째 유효 스캔 후 자동 중지하여 중복 pop 방지
- **특이사항**: 카메라 권한 거부 시 기기 설정으로 이동하는 안내 다이얼로그 표시. 다이얼로그 중복 표시 방지 로직 포함

#### 3. 게임 페이지에 QR 버튼 추가
- **파일**: `lib/features/game/presentation/pages/game_page.dart` (수정)
- **변경 내용**:
  - 경찰: QR 스캔 버튼 → `_openQrScanner()` 호출
  - 도둑: QR 표시 버튼 → `_showMyQrCode()` 호출
  - 참가자 오버레이에서 지도 버튼(위) + QR 버튼(아래) 순서로 배치

#### 4. QR 스캔 즉시 체포 (확인 모달 제거)
- **파일**: `lib/features/game/presentation/pages/game_page.dart` (수정)
- **변경 내용**: `_openQrScanner()`에서 QR 인식 후 GameActionModal 없이 즉시 `arrestRobber()` 호출. QR 스캔 자체가 대면 확인이므로 추가 확인 불필요
- **정리**: 미사용된 `_findRobberNickname()` 메서드 및 `GameActionModal` import 제거

#### 5. canPoliceArrest 헬퍼 추출
- **파일**: `lib/features/game/presentation/providers/game_event_provider.dart` (수정)
- **변경 내용**: 경찰 대기시간 체크 로직을 `GameEventState.canPoliceArrest()` 헬퍼 메서드로 추출. `game_page.dart`와 `participant_overlay.dart`에서 공통 사용

#### 6. 기존 카드 탭 체포 유지
- **파일**: `lib/features/game/presentation/widgets/participant_overlay.dart`
- **변경 내용**: 참가자 카드 탭 시 체포 모달(GameActionModal)은 기존대로 유지. QR 방식과 병행

### 📦 의존성 변경

- `qr_flutter: ^4.1.0` 추가 (QR 코드 생성)
- `mobile_scanner: ^7.2.0` 추가 (QR 코드 스캔)

### 🔧 플랫폼 설정

- **Android**: `AndroidManifest.xml`에 `CAMERA` 권한 추가
- **iOS**: `Info.plist`에 `NSCameraUsageDescription` 추가 ("도둑을 체포하기 위해 QR코드를 스캔합니다")

### 🔧 주요 변경사항 상세

#### QR 데이터 포맷
`{"pid": 505}` — participantId는 게임 세션 스코프이므로 게임 종료 시 자동 무효화. 아너시스템 기반으로 별도 보안 토큰 없음

#### 체포 플로우 변경

**변경 전 (UI 버튼 방식)**:
```
참가자 카드 탭 → 체포 확인 모달 → "네" 탭 → 체포 API 호출
```

**변경 후 (QR 코드 방식)**:
```
QR 스캔 버튼 탭 → 카메라로 QR 스캔 → 즉시 체포 API 호출
```

#### 참가자 오버레이 버튼 배치
참가자 목록 화면 우측 하단에 지도 버튼(위) + QR 버튼(아래) 순서로 배치

### 🧪 테스트 및 검증

- 도둑 QR 표시: 게임 진입 → 도둑 역할 → QR 버튼 탭 → QR 다이얼로그 표시 확인
- 경찰 QR 스캔: 게임 진입 → 경찰 역할 → QR 스캔 버튼 → 카메라 뷰파인더 → 도둑 QR 스캔 → 즉시 체포 확인
- 경찰 대기 시간 가드: 대기 시간 중 스캔 버튼 탭 → 스낵바 표시
- 이미 체포된 도둑: JAILED 도둑 QR 스캔 → 스낵바 표시
- 카메라 권한 거부: 스캐너 진입 시 권한 거부 → 설정 안내 다이얼로그
- 기존 카드 탭 체포: 참가자 목록에서 도둑 탭 → 기존 체포 모달 정상 동작 확인

### 📌 참고사항

- 백엔드 변경 없음 — 기존 `POST /api/games/{gameId}/system/arrest` API 그대로 사용
- QR 데이터는 게임 내 participantId 기반이므로 해당 게임 세션에서만 유효
- Stack children 개수 유지 (if/else 구조) — ChatOverlay index 7 고정으로 State 보존
