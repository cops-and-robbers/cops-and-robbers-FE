### 📌 작업 개요

피그마 시안과 불일치하는 게임 설정 UI 수정, 이용약관·개인정보처리방침 앱 내 열람 페이지 구현, 로그인 시 만 14세 연령 확인 다이얼로그 및 홈 진입 시 안전 안내 다이얼로그 추가

**보고서 파일**: `.report/20260319_#132_디자인_시안_반영_및_이용약관_개인정보처리방침_앱내_열람.md`

### 🎯 구현 목표

- 게임 설정 카드 UI를 피그마 시안에 맞게 수정
- 이용약관·개인정보처리방침을 외부 브라우저가 아닌 앱 내에서 열람할 수 있도록 변경
- 앱 스토어 심사 대응 (만 14세 연령 확인, 안전 안내)
- 게임 종료 다이얼로그 문구 시안 반영

### ✅ 구현 내용

#### 1. 게임 설정 카드 화살표 아이콘 추가 (피그마 시안 반영)
- **파일**: `lib/core/widgets/cards/info_card.dart`, `lib/features/session/presentation/widgets/zone_list_card.dart`, `lib/features/session/presentation/widgets/setting_list_card.dart`
- **변경 내용**: InfoCard에 `titleTrailing` 옵셔널 파라미터 추가. 구역/설정 카드에 `icon_previous.svg` 180도 회전 화살표 아이콘(16x16, black300) 표시
- **이유**: 피그마 시안에서 호스트에게 수정 가능 여부를 시각적으로 안내하는 화살표가 있었으나 미구현 상태였음. `onTap`이 있을 때만 표시하여 비호스트에게는 숨김

#### 2. 이용약관·개인정보처리방침 앱 내 열람 페이지
- **파일**: `lib/features/settings/presentation/pages/legal_document_page.dart` (신규), `assets/legal/terms_of_service.json` (신규), `assets/legal/privacy_policy.json` (신규)
- **변경 내용**: JSON 기반 법적 문서 렌더링 페이지 구현. 조항 제목(paragraph14Semibold, black), 본문(tag_12, black800), 하위 항목(+16px 좌측 패딩) 스타일 적용. 앱바 우측에 외부 링크 이동 버튼 배치
- **이유**: 외부 브라우저로 이동하면 앱 이탈이 발생하고 심사에서 부정적 평가 가능. 앱 내에서 직접 열람하되, 외부 링크도 제공하여 사용자 선택권 보장

#### 3. 설정 페이지 및 로그인 페이지 연동
- **파일**: `lib/features/settings/presentation/pages/settings_page.dart`, `lib/features/auth/presentation/pages/login_page.dart`
- **변경 내용**: 이용약관/개인정보처리방침 탭 시 외부 URL 대신 `LegalDocumentPage`로 이동하도록 변경. 설정 페이지와 로그인 페이지 모두 앱바 우측에 외부 링크 버튼 제공
- **이유**: 두 진입점 모두에서 일관된 열람 경험 제공

#### 4. 로그인 페이지 만 14세 연령 확인 다이얼로그
- **파일**: `lib/features/auth/presentation/pages/login_page.dart`
- **변경 내용**: 로그인 화면 진입 시 AppDialog로 연령 확인. "네" 선택 시 다이얼로그 닫힘, "아니요" 선택 시 `exit(0)`으로 앱 종료. `barrierDismissible: false`로 바깥 탭 닫기 방지
- **이유**: 이용약관 제4조 및 만 14세 미만 가입 제한 정책 준수. 앱 스토어 심사 시 연령 확인 절차 필요

#### 5. 홈 화면 안전 안내 다이얼로그
- **파일**: `lib/features/session/presentation/pages/home_page.dart`, `lib/features/auth/presentation/providers/auth_provider.dart`
- **변경 내용**: 홈 진입 시 "주변을 확인하며 이용해 주세요" 안전 안내 다이얼로그 표시. "오늘은 다시 보지 않기" 체크 기능(SharedPreferences 날짜 기반). 로그아웃/강제 로그아웃 시 static flag + SharedPreferences 모두 초기화하여 재로그인 시 다시 표시
- **이유**: 위치 기반 야외 게임 특성상 안전 안내 필수. 앱 스토어 심사 시 안전 관련 고지 요구

#### 6. 게임 종료 다이얼로그 문구 변경
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**: "다시하기" → "한 번 더"로 버튼 텍스트 변경
- **이유**: 피그마 시안 문구 반영

### 🔧 주요 변경사항 상세

#### LegalDocumentPage — JSON 기반 법적 문서 렌더링
`rootBundle.loadString()`으로 JSON 로드 후 섹션별 파싱. heading/content/items/subItems 4단계 구조. `externalUrl` 옵셔널 파라미터로 앱바 우측 외부 링크 버튼 제어

#### 안전 안내 다이얼로그 — ConsumerWidget 내 상태 관리
`StatefulBuilder`로 "오늘은 다시 보지 않기" 체크박스 상태를 로컬 관리. `ConsumerWidget`의 `build` 내에서 `addPostFrameCallback` + static flag로 1회만 콜백 등록. `check_circle_true/false.svg` 토글 아이콘 사용

**특이사항**:
- 안전 안내의 "오늘은 다시 보지 않기"는 자정 기준 리셋 (24시간 아님)
- 로그아웃 시 `HomePage.resetSafetyNotice()`로 SharedPreferences 날짜 키도 함께 삭제하여 재로그인 시 다시 표시

#### iOS Info.plist 문구 수정
`NSLocationAlwaysAndWhenInUseUsageDescription` 키는 geolocator 패키지가 내부적으로 Always 권한 API를 참조하여 Apple이 요구하므로 유지. 다만 "백그라운드에서도" 문구를 제거하여 실제 동작(포그라운드 전용)과 일치시킴. `NSLocationWhenInUseUsageDescription`과 동일한 문구로 통일

### 📦 의존성 변경

- 새로운 패키지 추가 없음 (`shared_preferences`는 기존 사용 중)

### 📌 참고사항
- JSON 법적 문서 내용은 `docs/이용약관.md`, `docs/개인정보처리방침.md` 원본과 동일. 내용 변경 시 JSON도 함께 업데이트 필요
- `InfoCard`의 `titleTrailing` 파라미터는 다른 카드에서도 재사용 가능 (범용 설계)
- 연령 확인에서 `exit(0)` 대신 로그인 비활성화 방식 사용 (Apple HIG 준수, iOS 심사 리젝 방지)
- 연령 확인 static flag(`_ageVerified`)는 로그아웃 시 `LoginPage.resetAgeVerification()`으로 리셋
