# QR 체포 액션 버튼 인게임 이동 및 지도 UI 개선 #377

### 📌 작업 개요

기존에 참가자 오버레이 안에 숨어 있던 QR 체포 액션 버튼을 인게임 지도 화면으로 노출하여 1-tap 접근성 확보. 내 위치 버튼은 좌측 하단으로, 디버그 버튼은 우측 상단으로 재배치하여 버튼 충돌 방지. 인게임 튜토리얼도 동일한 레이아웃·미션 순서로 동기화.

**보고서 파일**: `.report/20260527_#377_QR_체포_액션_버튼_지도_UI개선.md`

---

### 🎯 구현 목표

- QR 버튼을 지도 모드 우측 하단(`[참가자, QR]`)에서도 접근 가능하도록 노출
- 내 위치 버튼은 좌측 하단으로 분리
- 디버그 버튼(kDebugMode 한정)은 우측 상단으로 이동하여 좌측 하단과 충돌 방지
- 튜토리얼 페이지를 실 게임 화면과 동일 레이아웃으로 미러링
- 튜토리얼 미션 순서를 `QR → 참가자 → 지도복귀`로 재정렬
- 좌측 하단 내 위치 버튼의 모서리 반경을 외부에서 조절 가능하도록 API 확장

### ✅ 구현 내용

#### 1. 게임 화면 레이아웃 재배치
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**:
  - 지도 모드 우측 하단: 기존 `[참가자, 내 위치]` → `[참가자, QR]`로 변경, 둘 다 `_isZoneExitWarningActive` 가드 안에 포함
  - 좌측 하단(`index 5b`): 내 위치 버튼 신규 Positioned 추가, 이탈 중에도 활성화 유지(복귀 경로 파악 필수)
  - 디버그 버튼(`index 8`): 좌측 하단 → 우측 상단(타이머 HUD 64.h 아래)으로 이동
- **이유**: QR 체포는 핵심 게임 액션이라 항상 1-tap 접근 가능해야 함. 우측 하단을 QR이 차지하면서 내 위치는 좌측으로 분리. 디버그는 kDebugMode 한정이라 릴리즈에선 dead-code 제거되지만 개발 중 시인성을 위해 우측 상단으로

#### 2. 인게임 튜토리얼 미러링 및 미션 순서 재정렬
- **파일**: `lib/features/tutorial/presentation/pages/in_game_tutorial_page.dart`
- **변경 내용**:
  - `_missionStep` 매핑 변경: 기존 `0=참가자, 1=QR, 2=지도복귀` → `0=QR, 1=참가자, 2=지도복귀`
  - `_buildMapMode` 우측 Column: 내 위치 제거하고 `_buildQrButton()` 추가, 좌측 하단 내 위치 Positioned 신규
  - `_buildMissionBanner` `descriptions` 배열 순서 swap (ARB 키는 그대로 재사용)
- **이유**: QR이 인게임에 노출되었으니 학습 순서도 QR을 첫 번째로. 실 화면과 동일한 버튼 배치를 튜토리얼에 미러링하여 학습 일치성 확보

#### 3. 펄스 ring z-order 문제 해결
- **파일**: `lib/features/tutorial/presentation/pages/in_game_tutorial_page.dart`
- **변경 내용**:
  - `_pulseIfActive`를 `_pulseButtonScale`(버튼 본체 sin 곡선 scale)과 `_pulseRing`(외곽 ring 1.0→1.8 확장) 두 메서드로 분리
  - 우측 액션 Column을 `Stack(clipBehavior: Clip.none)`으로 감싸고 ring을 Stack 마지막 자식(`Positioned(top:0)` 또는 `Positioned(bottom:0)`)으로 배치
  - ring 외곽 박스를 56.w × 56.w(`SvgIconButton.containerSize` 기본값)로 맞추고 안의 ring 48.w × 48.w는 `Center`로 정중앙 정렬
- **이유**: Column children은 리스트 순서대로 페인트되어 위 형제의 ring 확장 영역이 아래 형제 버튼에 가려졌음. ring을 Stack 마지막 자식으로 분리하면 항상 최상위에 페인트됨. 또한 최근 PR에서 `containerSize: 48` override를 제거하면서 버튼이 56×56이 된 상태였는데, ring이 여전히 48×48이라 중심이 4px 어긋났던 정렬 버그도 함께 해결

#### 4. MyLocationButton borderRadius 파라미터 추가
- **파일**: `lib/core/widgets/buttons/my_location_button.dart`, `lib/core/widgets/map/zone_setting_widget.dart`
- **변경 내용**:
  - `MyLocationButton`에 `borderRadius` 파라미터 노출(기본값 16) → 내부 `SvgIconButton.borderRadius`로 전달
  - `ZoneSettingWidget`에서 `borderRadius: 12` 적용
- **이유**: 구역 설정 화면의 내 위치 버튼은 일반 화면과 다른 라운드 값이 필요했음. API 확장으로 호출 시점에서 자유롭게 조절 가능

#### 5. QR 아이콘 교체 및 버튼 크기 통일
- **파일**: `assets/icons/icon_qr_code.svg`, `assets/icons/icon_qr_scan.svg`
- **변경 내용**: QR 아이콘 디자인 교체, 인게임 버튼 컨테이너 크기를 56×56 기본값으로 통일(`containerSize: 48`, `iconSize: 24` override 제거)
- **이유**: 디자인 가이드 통일 및 다른 인게임 액션 버튼과 시각적 일관성 확보

### 🔧 주요 변경사항 상세

#### Stack children 인덱스 안정성 보존

`game_page.dart`의 메인 `Stack`은 `ChatOverlay`가 특정 인덱스(7번)에 고정되어야 State가 dispose되지 않는 구조. 신규 노드 추가 시 `if/else` 양분기 패턴을 따라 항상 동일한 children 개수를 유지함.

```dart
// index 5b: 좌측 하단 내 위치 (지도 모드 한정)
if (!_showParticipants)
  Positioned(left: 20.w, bottom: actionButtonBottom, child: MyLocationButton(...))
else
  const SizedBox.shrink(),
```

기존 `index 6/7/8/9` 주석 번호는 그대로 유지하고 신규 노드만 `index 5b`로 표기.

#### 이탈 경고 중 가시성 규칙

| 버튼 | `_isZoneExitWarningActive == true` 시 |
|---|---|
| 참가자 (우측 상단) | 숨김 |
| QR (우측 하단) | 숨김 (신규 정책) |
| 내 위치 (좌측 하단) | 유지 — 복귀 경로 파악 필수 |
| 디버그 (우측 상단, kDebugMode) | 유지 |

#### 펄스 ring 오버레이 패턴

```dart
Positioned(
  right: 20.w,
  bottom: actionButtonBottom,
  child: Stack(
    clipBehavior: Clip.none,
    children: [
      Column(children: [
        _pulseButtonScale(step: 1, child: SvgIconButton(/* 참가자 */)),
        SizedBox(height: AppSpacing.vertical8),
        _buildQrButton(),
      ]),
      // Stack 마지막 자식이라 항상 최상위 페인트
      if (_missionStep == 1)
        Positioned(top: 0, child: _pulseRing())
      else if (_missionStep == 0)
        Positioned(bottom: 0, child: _pulseRing()),
    ],
  ),
)
```

`_pulseRing` 내부는 외곽 56×56 박스에 48×48 ring을 `Center`로 정렬하여 56×56 버튼과 정중앙이 일치하도록 구성.

**특이사항**:
- `IgnorePointer`로 ring을 감싸 하단 버튼의 터치를 막지 않음
- ring 외곽 박스 크기는 `SvgIconButton.containerSize` 기본값(56)과 동일하게 맞춤
- ARB 파일 변경 없음 — `descriptions` 배열 순서만 swap (`tutorialMissionQrButton` → step 0, `tutorialMissionParticipantsButton` → step 1)
