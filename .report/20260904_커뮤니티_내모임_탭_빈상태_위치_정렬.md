### 📌 작업 개요
커뮤니티 「전체」·「우리 동네」 탭은 모집글이 없을 때 화면 기준 가운데에 안내 문구가 뜨는데, 「내 모임」 탭만 위쪽으로 치우쳐 보이던 문제 수정

**보고서 파일**: `.report/20260904_커뮤니티_내모임_탭_빈상태_위치_정렬.md`

### 🔍 문제 분석
세 탭 다 위에 스코프 토글(전체/우리 동네/내 모임)이 있어, 빈 상태 문구를 단순히 `Center`로만 두면 화면 전체 기준 가운데가 아니라 그만큼 위로 밀린 자리가 된다.

「전체」·「우리 동네」(`community_feed_list.dart`)는 이미 이걸 보정했다 — `SliverFillRemaining`으로 남은 높이를 채우고, `EmptyState` 아래에 `AppSpacing.vertical64`짜리 빈 `SizedBox`를 더해 토글 높이만큼 아래로 내려 화면 기준 가운데로 맞췄다.

「내 모임」(`community_chat_room_list.dart`)은 같은 화면에서 이틀 뒤(#480) 별도로 구현되면서 이 보정 없이 `ListView` 맨 위에 `SizedBox(height: vertical64 * 2)` 고정 스페이서 + `EmptyState`만 뒀다. 화면 상단에서 고정 거리만큼 내려온 자리라, 화면 높이가 큰 기기일수록 실제 가운데와 어긋나 위로 치우쳐 보였다. 로그인 안내·에러 상태도 같은 이유로 다른 두 탭보다 낮게 그려지고 있었다.

### ✅ 구현 내용

#### 빈 상태를 다른 탭과 같은 트리로 교체
- **파일**: `lib/features/community/presentation/widgets/community_chat_room_list.dart`
- **변경 내용**: 목록이 비었을 때의 `ListView` + 고정 스페이서를 `CustomScrollView` + `SliverFillRemaining` + `Center(Column[EmptyState, SizedBox(vertical64)])`로 교체. 로그인 안내·에러 상태도 같은 `_centered` 헬퍼로 묶어 동일하게 보정
- **이유**: 「전체」·「우리 동네」와 같은 배치 방식으로 맞추면 세 탭의 빈 상태가 같은 높이에 뜬다. 당겨서 새로고침은 `SliverFillRemaining`이 뷰포트를 안 채워도 스크롤 가능하게 유지해줘 그대로 보존된다

### 🔧 주요 변경사항 상세

#### `_centered` 헬퍼
빈 상태 위젯 하나를 받아 `Center(Column[child, SizedBox(vertical64)])`로 감싸는 작은 헬퍼를 추가해, 빈 목록·로그인 안내·에러 상태 세 곳에서 재사용했다.

**특이사항**:
- 이 배치를 규정한 결정 문서는 따로 없음 — 순수 UI 정렬 수정
- 기존 위젯 테스트(`shows_empty_message_when_no_rooms` 등)는 텍스트 노출만 확인해 위치 변경과 무관하게 그대로 통과
