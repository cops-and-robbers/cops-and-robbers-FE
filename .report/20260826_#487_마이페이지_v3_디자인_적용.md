### 📌 작업 개요

마이페이지에 v3 시안을 적용하고, 하위 화면 다섯 개를 GoRoute 로 올렸다.

시안 적용은 아이콘 · 항목 순서 · 행 치수가 대상이고, 오픈소스 라이선스 항목이 새로 생겼다. 라우팅 정리는 화면이 탭 스택에 남는 문제와 전환 애니메이션이 다른 화면과 어긋나는 문제를 함께 없앤다.

- 커밋 5개 / 파일 22개 / +388 −128
- `flutter analyze` 에러 · 경고 0, 테스트 통과

### 🎯 구현 목표

- 시안대로 아이콘, 항목 순서, 행 치수를 맞춘다
- 오픈소스 라이선스 항목을 만들고 웹이 제공하는 문서를 연다
- 하위 화면이 탭 스택에 남지 않고, 전환이 앱의 다른 화면과 같아지게 한다

### ✅ 구현 내용

#### 설정 항목에 아이콘 추가

- **파일**: `assets/icons/` 5종 신규, `my_page.dart`
- **변경 내용**: 메뉴 아이템과 스위치 메뉴 아이템에 `leadingAsset` 인자를 옵셔널로 추가했다. 아이콘 24x24, 좌측 여백 24, 텍스트와의 간격 18
- **이유**: 아이콘 유무와 보조 텍스트 유무가 서로 독립이라 위젯을 나누지 않았다. 닉네임 변경은 아이콘이 있고 보조 텍스트가 없다. 둘을 묶어 나누면 양쪽이 보조 텍스트 분기와 여백 · 구분선을 각자 갖게 되어 중복이 생긴다

행 높이는 상하 여백 16 하나로 세 경우가 모두 나온다.

```
텍스트만            16 + 16 + 16 = 48
아이콘 + 주          16 + 24 + 16 = 56
아이콘 + 주 + 보조    16 + (16+8+12) + 16 = 68
```

아이콘(24)이 주 + 보조 묶음(36)보다 작아 마지막 경우의 높이는 텍스트가 정한다. 조건 분기가 없다.

#### 화살표를 전용 에셋으로 교체

- **파일**: `assets/icons/icon_next.svg` 신규, `my_page.dart`
- **변경 내용**: `icon_previous.svg` 를 180도 회전해 쓰던 것을 전용 에셋으로 바꿨다. `dart:math` 의존도 사라졌다
- **이유**: 받은 에셋이 20x20 에 색도 `black300` 과 같아 그대로 쓸 수 있다

화살표는 시안대로 닉네임 변경 행에만 둔다. 언어 행에서는 뺐다.

#### 항목 순서와 버전 표시

- **파일**: `my_page.dart`
- **변경 내용**: 앱 설정은 게임 알림 · 알림 · 언어 · 위치 권한 관리 순, 이용 안내는 앱 버전 · 튜토리얼 다시 보기 · 튜토리얼 초기화 · 버그 제보 · 오픈소스 라이선스 · 이용약관 및 정책 순으로 바꿨다. 버전 표시 텍스트 색을 `black300` 에서 `black600` 으로 올렸다

#### 오픈소스 라이선스 항목

- **파일**: `legal_doc.dart`, `l10n` 3종, `my_page.dart`, `app_router.dart`
- **변경 내용**: 법적 문서 종류에 `licenses` 를 더하고 이용 안내에 항목을 추가했다
- **이유**: 본문은 웹이 이미 제공한다. 앱은 문서 종류에 값 하나를 더하면 기존 화면이 그대로 연다

#### 하위 화면을 GoRoute 로 승격

- **파일**: `app_router.dart`, `route_paths.dart`, `my_page.dart`
- **변경 내용**: 언어 설정 · 약관 설정 · 버그 제보 · 오픈소스 라이선스 · 크레딧을 라우트로 만들고 전부 루트 네비게이터를 부모로 지정했다
- **이유**: `StatefulShellRoute.indexedStack` 은 탭마다 스택을 유지한다. 마이페이지에서 화면을 열고 홈 탭에 갔다 돌아오면 그 화면이 그대로 떠 있었다

전환 애니메이션도 함께 정리됐다. 라우터는 커스텀 전환을 28곳에서 쓰는데 마이페이지 하위만 `MaterialPageRoute` 기본 전환이었다. 마이페이지는 페이드로 들어오는데 그 안에서는 플랫폼 기본 슬라이드로 나갔다.

#### 버그 제보를 전용 화면으로 분리

- **파일**: `bug_report_page.dart` 신규, `my_page.dart`
- **변경 내용**: 범용 입력 화면에 문구와 `onSubmit` 콜백을 넘기던 것을 전용 화면으로 뺐다. 전송 로직도 함께 옮겼다
- **이유**: 라우트는 URL 로부터 화면을 복원해야 하는데 콜백은 URL 에 담기지 않는다. `state.extra` 로 넘기면 타입이 잡히지 않고, 앱이 죽었다 살아나면 라우트만 복원되고 인자가 비어 화면이 깨진다

### 🔧 주요 변경사항 상세

#### 크레딧 전환 보존

크레딧은 버전을 다섯 번 눌러야 닿는 이스터에그이고 페이드 + 블러 500ms 로 등장한다. 라우트로 옮기면서 이 연출이 사라지지 않도록 `buildBlurFade` 를 전환 헬퍼에 추가했다. 다른 화면과 같은 방식으로 등장하면 숨겨진 화면이라는 느낌이 사라진다.

#### go_router 경로는 외부 진입점이 아니다

경로가 생기면 이스터에그가 노출되는지 확인했다. 딥링크는 초대 링크만 통과시키는 화이트리스트이고 `flutter_deeplinking_enabled` 가 꺼져 있어, 앱이 직접 파싱하지 않는 경로로는 밖에서 들어올 수 없다. 인증 리다이렉트도 `/login` 과 `/agreement` 에만 걸려 새 경로는 통과한다.

**특이사항**

- 아이콘은 다색이라 색 필터를 걸지 않는다. 앱의 다른 아이콘 대부분이 단색 + 색 필터 방식이라 여기서 갈라진다
- 공식 SNS 채널 줄은 시안에 없지만 하단에 그대로 둔다. 뺀 것이 아니라 유지가 의도다
- 약관 4종의 상세 화면은 라우트로 올리지 않았다. 목록 안의 항목이라 성격이 다르다
- 마이페이지에서 죽은 import 7개를 정리했다. 화면들이 라우터로 옮겨가며 안 쓰게 됐다
