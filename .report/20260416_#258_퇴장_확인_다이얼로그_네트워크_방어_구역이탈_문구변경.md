### 📌 작업 개요

대기방 UX 개선 및 네트워크 오프라인 방어 로직 보강. 퇴장 확인 다이얼로그 추가, 방 나가기 시 API 실패 방어, 구역 이탈 규칙 문구 변경, 스플래시 hot restart 오탐 수정을 포함한다.

### 🎯 구현 목표

- 대기방 나가기 시 확인 다이얼로그 표시하여 실수 방지
- 네트워크 오프라인 상태에서 방 나가기 시 UI만 나가지는 문제 해결
- 구역 이탈 패널티 변경에 맞춰 안내 문구 수정
- 스플래시 화면 hot restart 후 오프라인 오탐 방지

### ✅ 구현 내용

#### 1. 대기방 퇴장 확인 다이얼로그 추가
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: `_confirmLeaveRoom()` 메서드 추가. AppBar 뒤로가기 버튼이 `_leaveRoom()` 직접 호출 대신 `_confirmLeaveRoom()`을 호출하도록 변경
- **다이얼로그 내용**: "방을 나가시겠어요?" / "나가면 다시 초대코드를 입력해야 해요" / 나가기(빨간색) 버튼

#### 2. 방 나가기 네트워크 오프라인 방어
- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**: `_leaveRoom()` 실행 순서를 변경하여 REST API 퇴장을 먼저 시도하고, 성공한 경우에만 STOMP 끊기 + 상태 초기화 + 홈 이동을 수행
- **이유**: 기존에는 STOMP를 먼저 끊고 API를 호출했는데, API 실패 시에도 상태 초기화 + 홈 이동이 실행되어 서버에는 방에 남아있지만 클라이언트만 나가는 문제가 있었음

#### 3. 구역 이탈 규칙 문구 변경
- **파일**: `lib/features/game/presentation/pages/game_page.dart`, `lib/features/session/presentation/widgets/game_rules_content.dart`
- **변경 내용**: "구역 안으로 돌아와서 진행해 주세요" → "구역 밖으로 나가면 화면이 잠겨요"로 변경
- **이유**: 실제 패널티가 위치 노출에서 화면 잠금으로 변경됨에 따라 문구 동기화

#### 4. 스플래시 hot restart 오프라인 오탐 방지
- **파일**: `lib/features/auth/presentation/pages/splash_page.dart`
- **변경 내용**: `connectivity_plus`의 `isConnected()` 첫 호출이 `false`일 때 500ms 대기 후 한 번 더 체크하는 로직 추가
- **이유**: hot restart 직후 플랫폼 채널이 stale 값을 반환하여, 실제로는 네트워크가 연결되어 있음에도 오프라인 화면이 표시되는 문제 해결

### 🔧 주요 변경사항 상세

#### waiting_room_page.dart — 방 나가기 플로우 변경

**기존 플로우**:
1. STOMP 끊기 (EXIT 이벤트 자기 수신 방지)
2. REST API 퇴장 호출
3. API 성공/실패 무관하게 상태 초기화 + 홈 이동

**변경 후 플로우**:
1. REST API 퇴장 호출
2. API 실패 → 에러 스낵바 + `return` (방에 남아있음)
3. API 성공 → STOMP 끊기 + 상태 초기화 + 홈 이동

**특이사항**:
- 기존에 STOMP를 먼저 끊던 이유(자기 EXIT 이벤트 수신 방지)는, API 성공 후 즉시 홈으로 이동하므로 실질적 영향 없음
- 네트워크 오프라인 시 STOMP 재연결 팝업이 이미 표시되고 있으므로, 별도 재연결 로직 불필요

#### splash_page.dart — 재체크 로직

`connectivity_plus` 패키지가 hot restart 직후 플랫폼 채널 캐시를 사용하는 특성상, 첫 체크가 stale할 수 있음. 500ms 대기 후 재체크하여 실제 오프라인인지 확인. 실제 오프라인이면 두 번째도 `false`라 기존 동작 유지.

### 🧪 테스트 및 검증

- 네트워크 연결 상태에서 방 나가기 → 확인 다이얼로그 표시 → 정상 퇴장
- 네트워크 오프라인 상태에서 방 나가기 → API 실패 → 에러 스낵바 + 방에 남아있음
- 팀 변경 네트워크 오프라인 → API 실패 → UI 변경 없음 (기존 정상 동작)
- hot restart 후 스플래시 → 오프라인 화면 미표시 확인

### 📌 참고사항

- 이슈에서 요청된 팀 변경 페이드 애니메이션은 적용 후 UX 검토 결과 제거. 애니메이션이 팀 변경 후에 재생되어 효과가 미미했으며, AnimatedContainer + Scaffold 투명 배경 조합의 복잡도 대비 체감 개선이 부족
- AppBar 배경색을 `Colors.transparent`로 변경하여 Scaffold 배경색이 직접 보이도록 처리
