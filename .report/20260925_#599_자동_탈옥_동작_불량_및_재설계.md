### 📌 작업 개요
자동 탈옥이 제대로 동작하지 않는다는 제보에 따라 기존 로직을 걷어내고 다시 구현했다. 규칙은 "이번 체포 이후 감옥 안에 있었던 것이 확인되고, 그 뒤 감옥 밖에 확실히 나가 있으면 탈옥"이며, 밖에서 체포→진입→이탈과 안에서 체포→이탈 두 동선을 모두 지원한다. 수감 중에는 QR 버튼 자리에 수감 버튼을 둬 수동 탈옥을 찾기 쉽게 했다.

**보고서 파일**: `.report/20260925_#599_자동_탈옥_동작_불량_및_재설계.md`

### 🔍 문제 분석
실패 재현 로그는 확보하지 못했다. 기존 코드에서 확인한 구멍은 다음과 같다.
- 판정이 소켓 연결·상태 동기화 완료일 때만 실행됨 — 구역 이탈 진동과 같은 위치 콜백인데도 백그라운드에서 소켓이 끊기면 판정이 멈춤
- 연결 끊김·재연결·동기화·요청 실패 때마다 "감옥 안에 있었다" 기록을 지움 — 끊긴 사이 감옥을 나가면 다시 들어갔다 나오기 전까지 탈옥 불가
- 정확도 10m를 넘는 위치를 모두 버림 — 주머니 속·건물 옆에서 대부분 버려질 수 있음
- 위치 측정 시각을 기기 시계와 비교 — Android 위치 시각은 기기 시계와 다를 수 있어 시계가 틀린 폰에서는 위치가 전부 버려질 수 있음

### ✅ 구현 내용

#### 감옥 경계 거리 계산 복원
- **파일**: `lib/features/game/domain/entities/area_shape.dart`
- **변경 내용**: `distanceToBoundaryInMeters` 복원. 원형은 중심 거리 − 반경, 폴리곤은 가장 가까운 변까지의 실제 거리
- **이유**: GPS 오차 완충을 실제 경계 기준으로 적용하기 위해

#### 자동 탈옥 판정기
- **파일**: `lib/features/game/domain/jail_escape_detector.dart` (신규)
- **변경 내용**: 위치 하나를 넣으면 탈옥 요청 여부를 돌려주는 순수 클래스
  - 들어감: 감옥 안이면서 경계에서 (정확도 + 3m)보다 안쪽, 또는 안쪽 위치가 1초 넘게 연속 2번
  - 탈옥 요청: 들어감 이후 경계 밖 max(정확도, 3m)보다 먼 위치가 3초 유지
  - 요청 뒤 계속 밖이면 5초 간격으로 재요청
  - 앱이 위치를 받은 시각만 사용, 정확도가 0 이하인 위치는 무시
- **이유**: 판정 규칙을 화면에서 분리해 원형·폴리곤과 GPS 흔들림을 단위 테스트로 고정

#### 게임 화면 연결
- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**
  - 위치 콜백에서 구역 이탈 감지 옆에 자동 탈옥 판정 추가. 소켓 연결 조건 없음 — 백그라운드에서도 동작
  - 판정 기록은 본인이 수감되거나 풀릴 때만 새로 시작 (`localArrestRevision`은 연결 끊김에도 올라 기준으로 쓰지 않음)
  - 요청 실패 시 기존 상태 동기화를 부르고, 계속 밖이면 5초 뒤 재요청
  - 수감 중에는 QR 버튼 자리에 수감 버튼 표시 (왼쪽 아래에서 이동, 아이콘·동작 동일)
  - 체포 중에는 재연결 뒤 보류된 구역 이탈 경고를 켜지 않음 — 켜지면 오른쪽 버튼 줄과 함께 수감 버튼이 사라짐
- **이유**: 구역 이탈 진동과 같은 조건으로 판정하고, 수동 탈옥 진입점이 항상 보이게 하기 위해

#### 수동 탈옥 확인창
- **파일**: `lib/features/game/presentation/widgets/arrest_lock_overlay.dart`
- **변경 내용**: 확인창을 띄우기 전에 notifier를 잡아 두고 확인 시 그것을 사용
- **이유**: 확인창이 열린 사이 자동 탈옥되면 오버레이가 사라져, 확인을 누를 때 해제된 `ref` 사용 예외가 났음

#### 안내 문구
- **파일**: `lib/l10n/app_{ko,en,ja}.arb` (+ `flutter gen-l10n`)
- **변경 내용**: "감옥에 들어갔다가 벗어나면 자동으로 탈옥해요 / 자동 탈옥이 안 되면 아래 버튼을 눌러 주세요"로 복원

### 🔧 주요 변경사항 상세

**특이사항**:
- 탈옥 API와 `GameEventNotifier.escape()`는 바꾸지 않음. 서버가 수감·진행 여부를 검증
- 앱을 완전히 종료한 뒤 감옥 밖에서 다시 켜면 들어감 기록이 없어 수동 버튼으로 풂
- 작은 감옥·좁은 폴리곤·GPS 불량 지역에서는 들어감이 인정되지 않을 수 있음 — 수동 버튼으로 풂
- 체포 요청 경합 등 서버 동시성은 백엔드 범위로 제외
- 탈옥 진동은 기존 그대로 (소켓이 끊긴 채 HTTP로 풀리면 본인 폰은 울리지 않음)
