### 📌 작업 개요

게임 종료 후 개인 활동 기록(이동 거리·이동 경로·역할별 카운트·플레이타임·승패)을 별도 다이얼로그로 제공하고, 카드를 PNG로 캡처해 공유하거나 갤러리에 저장하는 기능을 추가했다. 경로 영역은 실제 구글 지도 스냅샷 우선, 오프라인·실패·타임아웃 시 `CustomPainter` 기반 스타일라이즈드 경로로 폴백한다. 모든 기록은 메모리에만 유지되며 다음 게임 시작 시 초기화된다.

---

### 🎯 구현 목표

- 역할별 개인 통계를 공유 가능한 카드 형태로 시각화
- 구글 지도 스냅샷 + CustomPainter 이중 폴백으로 오프라인 환경 대응
- 카드 캡처 → 공유(share_plus) / 갤러리 저장(gal) 원스텝 지원
- STOMP 확정 이벤트 기준 실시간 누적 (체포·탈옥·잡힘 위치 포함)

#### 상태 누적 Provider — `PlayerGameRecordNotifier` (신규)
- **파일**: `lib/features/game/presentation/providers/player_game_record_provider.dart`
- `@Riverpod(keepAlive: true)` — 게임 종료 정리 시 위치 스트림이 먼저 cancel되더라도 다이얼로그가 안전하게 읽도록 생명주기 보장
- `addPoint(p)`: 직전 점과 2m 미만 이동은 GPS 노이즈로 간주해 경로·거리에서 제외
- `incrementArrest()`: 경찰이 도둑을 잡았을 때 카운트 + 현재 위치 마커 기록
- `recordCaught()`: 도둑이 잡혔을 때 위치만 기록(카운트는 경찰 통계이므로 미증가)
- `incrementEscape()`: 도둑 탈옥 확정 시 횟수 증가(감옥 고정 위치이므로 위치 미기록)
- `markEnd(t)`: 위치 스트림 cancel 직전 호출해 종료 시각 확정
- `reset()`: 다음 게임 진입(`GamePage.initState`) 시 전체 초기화

#### 지도 스냅샷 위젯 — `RouteMapSnapshot` (신규)
- **파일**: `lib/features/game/presentation/widgets/route_map_snapshot.dart`
- 연결 확인 3초 타임아웃(이후 폴백) → 온라인 시 `GoogleMap` 렌더 → `_onMapCreated`에서 `animateCamera(CameraUpdate.newLatLngBounds(routeBounds(...), 36))` → `onCameraIdle`에서 700ms 안정화 대기 후 `takeSnapshot()`
- 4초 타임아웃 타이머: 타일 미로드 등 무한 대기 방지 → 기간 초과 시 자동 폴백
- `_notifyResolved()`: 중복 호출 방지 플래그(`_resolvedNotified`) + `addPostFrameCallback`으로 실제 정적 렌더 이후 부모에 통지
- 스냅샷 성공 시 `Image.memory`로 교체(라이브 플랫폼 뷰 → 정적 이미지). 실패·오프라인 시 `fallback` 반환
- 지도 인터랙션 전부 비활성화(`zoomGesturesEnabled` 등) — 정적 표시 전용
- `routeBounds()`: 단일/동일 좌표면 `CameraUpdate.newLatLngBounds`가 동작하도록 약 11m(0.0001도) 패딩 확장

#### 스타일라이즈드 경로 폴백 — `RoutePainter` (신규)
- **파일**: `lib/features/game/presentation/widgets/route_painter.dart`
- `projectRoute(route, size)` 결과로 얻은 캔버스 좌표에 Polyline 그리기
- 시작점(회색/흰색 원) · 끝점(팀 컬러 원) · 마커(흰 헤일로 + 컬러 링 + 컬러 중심)
- `RouteMarker(points, color)` 구조체로 복수 마커 그룹 지원

#### Web Mercator 투영 — `RouteGeometry` (신규)
- **파일**: `lib/features/game/presentation/widgets/route_geometry.dart`
- `_mercatorX(lon)`: 경도(도) → 라디안. 그대로 두면 x가 y보다 ~57배 커져 경로가 납작해지는 문제 방지
- `_mercatorY(lat)`: `ln(tan(π/4 + lat/2))` Web Mercator y축
- `projectRoute(route, size, {padding})`: 경로 바운딩 박스를 패딩 제외 영역에 uniform scale + 중앙 정렬. 화면 y축 반전(북→상) 처리
- `RouteProjection`: 투영된 경로점 목록 + 마커 등 임의 좌표를 동일 변환으로 투영하는 `project(p)` 함수 동봉 → 체포/잡힌 위치가 경로와 정확히 같은 좌표계에 올라감

#### 위젯 캡처 유틸 — `WidgetCaptureUtil` (신규)
- **파일**: `lib/core/utils/widget_capture_util.dart`
- `captureBoundaryToPng(GlobalKey, {pixelRatio=3.0})`: `RenderRepaintBoundary.toImage` → PNG 바이트. `image.dispose()` finally 보장, 실패 시 null 반환

#### 공유 유틸 확장 — `share_util.dart` (수정)
- **파일**: `lib/core/utils/share_util.dart`
- `shareImageBytes(bytes)`: 임시 디렉터리에 `cops_record.png` 저장 후 `SharePlus`로 파일 공유
- `saveImageBytesToGallery(bytes)`: `Gal.putImageBytes`로 갤러리 저장, 성공 여부 반환

#### 포맷 유틸 — `RecordFormat` (신규)
- **파일**: `lib/features/game/presentation/widgets/record_format.dart`
- `formatDistance(m)`: 1km 미만 → 정수 `m`, 이상 → 소수 2자리 `km`
- `formatDuration(sec)`: `"분:초"` 포맷 (60분 이상 cap 없음, 초 2자리 0 패딩)
- `formatRecordDate(dt)`: 로케일 독립 `"yyyy.MM.dd HH:mm"`

### 🔧 주요 변경사항 상세

#### 지도 스냅샷 vs 캡처 타이밍 문제
라이브 `GoogleMap`(플랫폼 뷰)는 `RepaintBoundary.toImage()` 캡처 시 빈 이미지로 찍힌다. 이를 방지하기 위해 스냅샷(`takeSnapshot()`) 완료 후 `Image.memory`로 정적 교체 → `addPostFrameCallback`으로 정적 렌더 확인 → 부모의 `_mapReady = true` 흐름으로 캡처 버튼이 활성화된다. 경로가 없으면 이 대기 없이 즉시 활성화.

#### keepAlive 이유
`PlayerGameRecordNotifier`는 `@Riverpod(keepAlive: true)`로 선언했다. `_prepareGameOverPresentation()`에서 위치 스트림을 cancel한 뒤 `MyRecordDialog`를 여는 순서이므로, autoDispose이면 다이얼로그가 provider를 watch하는 순간 이미 dispose된 상태일 수 있다. keepAlive로 선언해 게임 전체 생명주기를 보장하고, 다음 게임 `initState`에서 `reset()`으로 명시적 초기화.

#### GPS 노이즈 필터
`addPoint(p)`: `Geolocator.distanceBetween`으로 직전 점과 2m 미만 이동을 제외한다. 이동 없이 고정된 상태에서 GPS 진동이 거리를 부풀리는 것을 방지.

#### 경도 라디안 보정 (route_geometry.dart 회귀 방지)
경도를 도(degree) 그대로 x로 쓰면 π/180 ≈ 57배 차이가 생겨 경로가 세로로 납작해진다. `_mercatorX`에서 `lon * π / 180`으로 변환해 y축(`ln(tan(...))`)과 같은 라디안 단위로 맞춘다. 관련 회귀 테스트(`does_not_flatten_square_route_into_a_line`)로 검증.

### 📌 참고사항

- **기록은 휘발성**: 백엔드에 저장하지 않는다. 앱 강제 종료 시 현재 게임의 기록은 유실된다
- **더미 모드 제외**: `widget.isDummy`가 true이면 `reset()`과 `markEnd()` 호출이 생략된다
- `RouteMapSnapshot`은 경로가 1점 이상일 때만 사용하도록 `assert`로 보호됨. 빈 경로에는 "이동 기록 없음" 텍스트 표시
- i18n 키(`labelMyRecord`, `labelTravelDistance`, `labelMyArrestCount`, `labelMyEscapeCount`, `labelResult`, `messageSaveComplete`, `messageSaveFailed`, `labelNoRoute`, `legendArrestSpot`, `legendCaughtSpot`, `buttonViewMyRecord`)를 ko/en/ja ARB 파일에 추가하고 `flutter gen-l10n`으로 자동 생성 파일 갱신
- `game_localizations*.dart`(자동 생성) 파일은 ARB에서 재생성한 결과이며 직접 편집하지 않음
