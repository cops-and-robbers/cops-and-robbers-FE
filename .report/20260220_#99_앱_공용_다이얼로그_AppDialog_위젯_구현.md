### 📌 작업 개요

앱 전체에서 재사용 가능한 공용 다이얼로그 위젯 시스템 구현. 초대코드 입력, 게임규칙 안내, 회원 탈퇴 확인, 타이머 표시 등 다양한 사용 케이스를 하나의 통일된 컴포넌트로 지원. 디자인 시스템(AppColors, AppTextStyles, AppSpacing)과 완전 통합. 유효성 검증(validator) + shake 애니메이션, 키보드 인셋 대응, 외부 링크 연결, 초대코드 공유, SnackBar 통일, CodeRabbit 리뷰 2차 반영까지 완료.

### 🎯 구현 목표

- 버튼 모드 3가지(2버튼, 1버튼, 무버튼) 지원하는 유연한 다이얼로그 구조
- 버튼 없는 정보 표시용 팝업(타이머, 게임 종료 등) 별도 위젯 분리
- 애니메이션 공용화(스케일 + 페이드, 250ms)
- 기존 사용처(방 참여, 로그아웃 등) 마이그레이션
- validator 실패 시 shake 애니메이션으로 사용자 피드백
- 소프트 키보드가 다이얼로그를 가리지 않도록 인셋 대응
- 개인정보 처리방침/이용약관 외부 링크 연결
- 초대코드 네이티브 공유 시트 연결 (share_plus)
- SnackBar UI 통일 및 중복 표시 방지
- 로그아웃 성공/실패 사용자 피드백

### ✅ 구현 내용

#### 1. AppDialog — 공용 다이얼로그 위젯
- **파일**: `lib/core/widgets/dialogs/app_dialog.dart`
- **변경 내용**: 앱 전역 공용 다이얼로그 StatefulWidget 구현
- **주요 기능**:
  - `AppDialog.show()` — 범용 다이얼로그 표시 (제목, 메시지, 커스텀 콘텐츠)
  - `AppDialog.confirm()` — `bool` 반환 간편 확인 다이얼로그
  - 버튼 모드 3가지: `cancelText` 지정 시 2버튼, 미지정 시 1버튼, `showButtons: false` 시 무버튼
  - `isDestructive: true` 시 확인 버튼 빨간색 자동 적용
  - `showAvatar` / `avatarWidget` / `nickname` — 체포 로직용 아바타 표시
  - `confirmColor`, `cancelColor`, `titleStyle` 등 세부 커스터마이징 지원
  - `validator` — 확인 버튼 탭 시 유효성 검증, 실패 시 shake 애니메이션 (다이얼로그 닫지 않음)

#### 2. Validator + Shake 애니메이션
- **파일**: `lib/core/widgets/dialogs/app_dialog.dart`
- **변경 내용**: `bool Function()? validator` 파라미터 추가, StatefulWidget 변환
- **동작 방식**:
  - `AppDialog.show(validator: () => ctrl.text.length == 6)` 형태로 사용
  - validator가 `false` 반환 시 `Navigator.pop()` 호출하지 않고 수평 흔들림 애니메이션 실행
  - `TweenSequence`로 감쇠 진동 구현 (±8.w → ±6.w → ±4.w → 0, 400ms)
  - `GlobalKey<_AppDialogState>`를 통해 외부에서 `shake()` 메서드 호출
  - Shake 오프셋에 ScreenUtil `.w` 스케일링 적용하여 다양한 화면 크기에서 일관된 효과 보장

#### 3. 키보드 인셋 대응
- **파일**: `lib/core/widgets/dialogs/app_dialog.dart`
- **문제**: `showGeneralDialog`의 Overlay에서 `Center` 위젯이 `MediaQuery.viewInsets`를 소비하지 않아, customContent에 TextField가 있을 때 소프트 키보드가 다이얼로그를 가림
- **해결**:

  - `SingleChildScrollView` — 키보드 + 다이얼로그 높이가 화면을 초과할 경우 스크롤 허용, 오버플로우 방지
  - 애니메이션 100ms, `Curves.decelerate` — 키보드 올라올 때 부드러운 전환
- **파일**: `lib/features/session/presentation/pages/home_page.dart`

### 🔧 주요 설계 결정

#### AppDialog vs AppPopup 분리
버튼이 있는 인터랙티브 다이얼로그(`AppDialog`)와 정보만 표시하는 팝업(`AppPopup`)을 별도 위젯으로 분리. `AppDialog`의 `showButtons: false` 모드보다 `AppPopup`이 더 명확한 의도 표현 가능.

#### 버튼 색상 자동 결정 로직
`isDestructive` 플래그 기반으로 확인 버튼 색상 자동 결정 (true → red, false → black). `confirmColor`로 수동 오버라이드도 가능하여 체포 로직 등에서 blue 버튼 사용 지원.

#### Navigator 자동 pop + validator 차단
`AppDialog.show()`의 `onConfirm` 콜백은 내부에서 자동으로 `Navigator.pop()` 호출 후 사용자 콜백 실행. `validator`가 설정된 경우 `false` 반환 시 pop을 차단하고 shake 애니메이션으로 피드백. 호출부에서 별도로 닫기/검증 처리 불필요.

#### 키보드 인셋 대응 패턴
Flutter 내장 `Dialog` 위젯과 동일한 `AnimatedPadding(MediaQuery.viewInsetsOf)` 패턴 적용. `showGeneralDialog`를 사용하는 커스텀 다이얼로그에서도 키보드에 안전하게 대응.

#### shareText fire-and-forget 허용
`AppDialog`의 `onConfirm`이 `VoidCallback?` 타입이라 async 콜백 전달 불가. `shareText` 내부에서 `try-catch`로 플랫폼 예외를 처리하므로 fire-and-forget이 안전함.

#### SnackBar 중복 방지 패턴
`messenger.clearSnackBars()` → `messenger.showSnackBar()` 순서로 호출하여 연속 탭 시 SnackBar가 쌓이지 않도록 처리. 디바운싱보다 단순하고 효과적.
