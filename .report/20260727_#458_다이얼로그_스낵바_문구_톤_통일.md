### 📌 작업 개요
앱 내 다이얼로그·스낵바·에러·게임 안내 문구를 토스 UX 라이팅 기준(해요체)으로 통일하고, 회귀를 자동 검출하는 톤 린터를 추가했어요.

### 🎯 구현 목표
- 하십시오체(`~습니다`, `~니다`)로 섞여 있던 문구를 해요체로 전면 통일
- 과도한 경어(`~하시겠어요`, `~시나요`, `~께서` 등) 제거
- ARB(ko/en/ja) 3개 로케일 톤·마침표 규칙을 자동 검출하는 린터 스크립트 추가
- 다이얼로그 부정 버튼 문구를 취소 → 닫기로 통일

### ✅ 구현 내용

#### 톤 린터 스크립트 추가
- **파일**: `docs/i18n/_lint_tone.py`
- **변경 내용**: ARB 문구에서 하십시오체(`니다|니까`), 과도한 경어(`하시겠|시겠어요|시나요|하십|께서|님께`), 로케일별 끝 마침표(ko/en `.`, ja `。`) 위반을 정규식으로 검출
- **이유**: 품질 게이트가 아닌 회귀 알람 목적. 능동형/긍정형/명사+명사 같은 문맥 판단은 검출 대상에서 제외하고, 정규식으로 확실히 잡히는 어미·마침표만 검사

#### UX 라이팅 기준 문서 추가
- **파일**: `docs/i18n/UX_WRITING.md`
- **변경 내용**: 토스 보이스톤 가이드(해요체, 능동적 말하기, 긍정적 말하기, 캐주얼한 경어, 명사+명사 지양) 원문 추적
- **이유**: 린터 규칙과 문구 수정의 근거 문서로 참조

#### ARB 문구 톤 통일 (ko/en/ja)
- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb` (및 생성 파일 `app_localizations*.dart`)
- **변경 내용**:
  - 에러 안내 문구(`errorNetworkTimeout`, `errorServerInternal`, `errorBadRequest` 등) `~했습니다/~입니다` → `~했어요/~예요` 전환
  - 백엔드 에러코드 안내 문구 해요체 통일
  - 다이얼로그·스낵바·게임 이벤트 문구(`dialogUpdateOptionalMessage`, `chatSystemGameStartTime`, `chatSystemPoliceMoveWarning` 등) 해요체 전환
  - 린터가 새로 검출한 하십시오체 22건(`-ㅂ니다` 계열: 합니다·됩니다·갑니다 등) 추가 전환
  - `errorAuthTooManyRequests` 등 어색한 조합 문구 재수정
  - en/ja 문구 끝 마침표 제거(`gameEventStartReportTip`, `gameEventStartTime`, `gameOverFallbackMessage`), `errorCodeInvalidInputValue`의 개발자 용어(validation/検証) 순화
- **이유**: 상황·맥락 불문 모든 문구에 해요체를 일관 적용하기 위함(UX_WRITING.md 기준)

#### gameLeaveConfirmMessage 원문 의미 복원
- **파일**: `lib/l10n/app_ko.arb`
- **변경 내용**: `"나가면 다시 게임에 참여할 수 없어요"` → `"진행 중인 게임에서 나가게 돼요"`
- **이유**: 이전 톤 전환 과정에서 원문 의미가 왜곡되어 인게임 중도 퇴장 확인 다이얼로그 본문의 의미를 복원

#### 다이얼로그 취소 버튼 문구 통일
- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb`, `test/.../app_dialog_cancel_l10n_test.dart`
- **변경 내용**: `buttonCancel` 값을 취소/Cancel/キャンセル → 닫기/Close/閉じる로 변경
- **이유**: "취소"는 진행 중인 작업이 취소된다고 오해할 수 있어, 다이얼로그 왼쪽(부정) 버튼은 "닫기"로 통일한다는 UX_WRITING.md 지침을 따름

#### 린터 정규식 보강 (하십시오체 미검출 회귀 수정)
- **파일**: `docs/i18n/_lint_tone.py`
- **변경 내용**: 해요체 검출 정규식을 `(습니다|입니다|십시오)` → `(니다|니까)`로 확장, 끝 마침표 검사를 ko 전용에서 ko/en/ja 3개 로케일로 확장
- **이유**: 기존 정규식이 `-ㅂ니다` 계열(합니다·됩니다·갑니다 등)을 놓치는 회귀가 있어 검출 범위 확장

#### 용어집·문서 갱신
- **파일**: `docs/i18n/glossary.md`, `CLAUDE.md`
- **변경 내용**: `buttonCancel`/`buttonClose`가 별칭 관계임을 비고에 명시. `CLAUDE.md`에 "ARB 문구 추가/수정 후 `python3 docs/i18n/_lint_tone.py` 실행" 안내 추가
- **이유**: 향후 문구 추가 시 톤 회귀를 놓치지 않도록 워크플로우에 린터 실행을 고정

### 🔧 주요 변경사항 상세

**특이사항**:
- 톤 린터는 품질 게이트가 아니라 회귀 알람이다. 능동형/긍정형/명사+명사 지양 같은 문맥 판단 규칙은 정규식으로 잡을 수 없어 검출 대상에서 제외했다.
- `buttonCancel`은 실질적으로 `buttonClose`의 레거시 별칭으로 유지 — 진행 중 작업을 되돌리는 새 버튼이 필요해지면 그때 별도 키를 신규 추가하기로 함(glossary.md 비고).
- `flutter gen-l10n`으로 `app_localizations*.dart` 생성 파일 재생성 반영, 직접 수정하지 않음.
