### 📌 작업 개요

재로그인 시 기존 참여 중이던 방(대기실/게임)으로 복귀하지 않고 홈으로 이동되는 버그 수정.
추가로 대기실/게임 진입 시 위치 권한 체크 및 설정 안내 다이얼로그 기능 구현, AppDialog 다크모드 지원.

### 🔍 문제 분석

- 앱 콜드스타트(Splash 경유) 시에는 활성 세션 복원이 정상 동작
- 로그아웃 → 재로그인 시 Splash를 경유하지 않아 활성 게임 체크 로직이 실행되지 않음
- 결과적으로 기존 회원이 재로그인해도 항상 홈으로 이동됨

### ✅ 구현 내용

#### 1. 로그인 성공 시 활성 게임 상태 체크 및 목적지 결정

- **파일**: `lib/features/auth/presentation/providers/auth_provider.dart`
- **변경 내용**:
  - `postLoginDestinationProvider` (StateProvider) 추가 — 로그인 후 이동할 목적지를 1회성으로 저장
  - `_resolvePostLoginDestination()` 메서드 추가 — `getMyActiveGameUsecase`로 활성 게임 조회 후 상태별 경로 결정
    - `WAITING` → 대기실 경로
    - `IN_PROGRESS` → 게임 경로 (team, pid 쿼리 파라미터 포함)
    - 참여 게임 없음 / API 실패 → null (홈 fallback)
  - `signInWithGoogle()`, `signInWithApple()` 모두에서 기존 회원(`!result.isNewUser`)인 경우 `_resolvePostLoginDestination()` 호출

#### 2. GoRouter redirect에서 로그인 후 목적지 분기 처리

- **파일**: `lib/router/app_router.dart`
- **변경 내용**:
  - 기존 회원이 로그인 페이지에서 인증 완료 시 `postLoginDestinationProvider` 값을 확인
  - 값이 있으면 해당 목적지로 리다이렉트 후 provider를 null로 초기화 (1회 소비)
  - 값이 없으면 기존 로직대로 홈으로 이동

#### 3. 대기실 진입 시 위치 권한 체크 및 안내 다이얼로그

- **파일**: `lib/features/session/presentation/pages/waiting_room_page.dart`
- **변경 내용**:
  - `WidgetsBindingObserver` 믹스인 추가하여 앱 resume 시 권한 재확인
  - `_ensureLocationAndInit()` — 위치 권한 확인 후 로비 초기화 또는 권한 요청 다이얼로그 표시
  - `_showLocationPermissionDialog()` — 위치 서비스 OFF/권한 미허용 구분하여 안내 메시지 표시
  - `_checkLocationPermissionOnResume()` — 설정에서 권한 해제 후 복귀 시 재확인
  - 나가기 버튼 → 방 나가기, 설정으로 이동 버튼 → 앱 설정 화면으로 이동

#### 4. 게임 페이지 진입 시 위치 권한 체크

- **파일**: `lib/features/game/presentation/pages/game_page.dart`
- **변경 내용**:
  - `WidgetsBindingObserver` 믹스인 추가 (기존 `LifecycleProvider` 방식에서 변경)
  - `_ensureLocationAndInit()` — 위치 권한 확보 후 게임 연결 초기화
  - 게임 중에는 나갈 수 없으므로 설정 이동 버튼만 제공 (나가기 버튼 없음)
  - 설정에서 권한 허용 후 복귀 시 앱 재시작 안내

#### 5. 위치 권한 다이얼로그 메시지 공통화

- **파일**: `lib/core/services/permission/location_permission_messages.dart` (신규)
- **파일**: `assets/messages/location_permission_messages.json` (신규)
- **변경 내용**:
  - 위치 서비스 꺼짐 / 권한 미허용 두 가지 상황별 메시지를 JSON으로 외부화
  - `LocationPermissionContext` enum으로 home/game/waitingRoom 컨텍스트별 메시지 구분
  - `LocationPermissionMessages.getText()` — 최초 호출 시 JSON 로드 후 메모리 캐싱

#### 6. 위치 권한 서비스 신규 추가

- **파일**: `lib/core/services/permission/location_permission_service.dart` (신규)
- **변경 내용**:
  - `ensurePermission()` — 게임 진입 전 위치 권한 확보 플로우 (서비스 확인 → 권한 요청 → 결과 반환)
  - `canAccessLocation()` — 위치 접근 가능 여부 종합 판단 (상태 체크용)
  - `openAppSettings()`, `openLocationSettings()` — 설정 화면 이동

#### 7. AppDialog 다크모드 지원

- **파일**: `lib/core/widgets/dialogs/app_dialog.dart`
- **변경 내용**:
  - `isDarkMode` 파라미터 추가
  - 다크모드 시 배경색(black), 제목 스타일(robberHeading + white), 메시지 색상(black400) 자동 적용
  - 버튼 색상 기본값: confirm(green 배경, black 텍스트), cancel(black900 배경, black400 텍스트)

### 🔧 주요 변경사항 상세

#### 세션 복원 흐름 (재로그인 경로)

```
로그인 성공 → _resolvePostLoginDestination() 호출
  → getMyActiveGameUsecase.execute()로 활성 게임 조회
  → WAITING/IN_PROGRESS 상태면 postLoginDestinationProvider에 경로 저장
  → state = AsyncValue.data(result) → GoRouter redirect 트리거
  → redirect에서 postLoginDestination 확인 → 대기실/게임 화면으로 이동
```

**특이사항**:
- `_resolvePostLoginDestination()`은 `state` 설정 전에 호출하여 GoRouter redirect 시점에 목적지가 이미 준비되어 있도록 보장
- API 실패 시 홈 fallback으로 안전하게 처리
- Splash의 기존 세션 복원 로직은 그대로 유지 (앱 콜드스타트 담당)

#### 위치 권한 체크 흐름

```
페이지 진입 → _ensureLocationAndInit()
  → canAccessLocation() 확인
  → 허용: 정상 초기화 진행
  → 미허용: _showLocationPermissionDialog() 표시
    → "설정으로 이동" → 앱/위치 설정 화면 이동 → 복귀 후 재확인
    → "나가기" (대기실만) → 방 퇴장
```

### 📦 의존성 변경

- 없음 (기존 `geolocator` 패키지 활용)

### 🧪 테스트 및 검증

- 대기실/게임 참여 중 로그아웃 → 재로그인 시 해당 방으로 복귀되는지 확인
- 활성 게임 없는 상태에서 재로그인 시 홈으로 이동되는지 확인
- 앱 콜드스타트(Splash 경유) 시 기존 세션 복원 정상 동작 확인
- 위치 권한 미허용 상태에서 대기실/게임 진입 시 다이얼로그 표시 확인
- 설정에서 위치 권한 해제 후 앱 복귀 시 권한 재확인 동작 확인
- 다크모드(ROBBER 팀) 상태에서 위치 권한 다이얼로그 스타일 확인

### 📌 참고사항

- 위치 권한 복구 후에는 앱 재시작 필요 (Geolocator 스트림이 한번 실패하면 재생성 필요)
- 게임 페이지에서는 "나가기" 버튼 없이 "설정으로 이동"만 제공 (게임 중 이탈 방지)
- `postLoginDestinationProvider`는 1회성으로 소비 후 null 초기화 — redirect 무한 루프 방지
