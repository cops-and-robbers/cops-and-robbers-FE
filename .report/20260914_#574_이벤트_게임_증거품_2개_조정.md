# 이벤트 게임 증거품 2개 조정

회의에서 결정한 증거품 2개 구성을 진행·결과 보드와 체포 성공 알림에 반영했다. 두 명을 검거하면 두 증거품이 모두 공개된다. 관련 이슈: [#574](https://github.com/cops-and-robbers/cops-and-robbers-FE/issues/574).

## 구현 내용

- `lib/features/game/presentation/widgets/event_result_board.dart`: 세 칸의 고정 좌표 배치를 두 칸의 가로 배치로 변경했다. 두 `Expanded`가 가용 너비를 나누고, 이미지 비율과 간격을 유지한다. 검거 수가 0이면 두 칸을 잠그고, 1이면 첫 증거만, 2 이상이면 두 증거를 공개한다.
- `lib/features/game/presentation/widgets/event_arrest_success_dialog.dart`: 증거 인덱스를 1~2로 제한하고 세 번째 증거 전용 확대 처리를 제거했다. 범위를 벗어난 값도 첫 번째 또는 두 번째 이미지로 표시한다.
- `test/features/game/presentation/widgets/event_result_board_test.dart`, `event_arrest_success_dialog_test.dart`: 수집 단계별 이미지·잠금 상태, 화면 크기별 배치, 인덱스 범위 밖 입력을 검증하도록 수정했다.
- `.issues/20260913_기능개선_이벤트_게임_증거품_2개로_축소_및_배치_조정.md`: 문제와 변경 범위, 검증 항목을 정리했다.

증거품은 기존 `evidence1.png`와 `evidence2.png`를 사용한다. 실제 검거 인원은 2명을 초과해도 그대로 표시하며, 집계·중복 방지·재접속 복원 로직은 변경하지 않았다. `evidence3.png` 파일은 보존했다.

## 검증 결과

- 결과 보드·체포 알림·이벤트 집계·저장소 관련 테스트 **43개 통과**.
- `flutter analyze --no-pub` 오류 없음. 변경한 Dart 파일 4개 포맷 확인 및 `git diff --check` 통과.
- 0·1·2·3회 검거에 따른 공개 상태와 인덱스 0·5 입력을 확인했다. 320×568 및 768×1024 화면에서 두 이미지가 겹치지 않고 화면 안에 배치되는지 검증했다.
- 별도 위젯 렌더링 6개 시나리오 통과. 미수집·일부 수집·수집 완료, 작은 화면·태블릿·큰 글자, 체포 알림 이미지를 확인했다.
- 전체 테스트는 **1,217개 통과, 6개 실패**했다. 실패는 `community_sort_sheet.dart:92`의 하단 37px 오버플로이며, 기준 `main` 커밋 `cd2a05d1`의 격리 환경에서도 동일한 6개 실패를 재현했다.

## 남은 확인 사항

실기기 및 서버와 연결한 실제 이벤트 게임 진행은 검증하지 않았다. 전체 테스트의 기존 커뮤니티 정렬창 오버플로는 별도 수정이 필요하다.
