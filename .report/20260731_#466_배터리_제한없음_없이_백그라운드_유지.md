# [#466] 배터리 "제한없음" 설정 없이 백그라운드 게임 유지

### 📌 작업 개요
Android에서 배터리 설정을 "제한없음"으로 바꾸지 않아도 게임 세션 동안 위치 추적과 실시간(STOMP) 연결이 유지되도록 개선. 게임 진입을 막던 배터리 최적화 안내 다이얼로그를 완전히 제거하고, 포그라운드 서비스에 PARTIAL_WAKE_LOCK을 적용해 화면이 꺼져도 하트비트가 끊기지 않게 함

**보고서 파일**: `.report/20260731_#466_배터리_제한없음_없이_백그라운드_유지.md`

### 🔍 문제 분석
- 게임 중 홈 이동/화면 꺼짐 시 CPU가 절전 상태로 들어가면서 main isolate의 Dart 타이머가 정지 → STOMP 하트비트(10초 주기) 누락 → 서버가 연결을 끊어 게임 진행 중단
- 기존에는 이를 우회하려고 방 만들기/참여하기 진입 시 배터리 "제한없음" 설정을 요구하는 차단 다이얼로그를 띄웠고, 이것이 큰 진입 장벽이었음
- 포그라운드 서비스(FGS)는 프로세스를 살려두지만 CPU까지 깨워두지는 않으므로, FGS만으로는 해결되지 않음 (iOS는 UIBackgroundModes=location으로 이미 정상 동작)

### ✅ 구현 내용

#### 1. FGS에 PARTIAL_WAKE_LOCK 적용 (핵심)
- **파일**: `android/app/src/main/kotlin/com/elipair/copsandrobbers/GameSessionForegroundService.kt`
- **변경 내용**: `onStartCommand`에서 `PowerManager.PARTIAL_WAKE_LOCK` 획득, `onDestroy`에서 해제. 내비/음악 앱과 동일한 FGS(location) + partial wakelock 레시피
- **이유**: 화면이 꺼져도 CPU를 깨워둬야 Dart 타이머가 계속 돌아 하트비트가 유지됨
- **안전 장치**:
  - 타임아웃 4시간(`WAKELOCK_TIMEOUT_MS`) — release 누락(프로세스 비정상 종료 등) 시에도 OS가 자동 해제하는 누수 가드
  - `setReferenceCounted(false)` — start가 중복 호출돼도 release 1회로 확실히 해제
  - `isHeld` 체크로 중복 획득 방지

#### 2. onTaskRemoved 처리 — 고아 FGS/wakelock 방지
- **파일**: `GameSessionForegroundService.kt`
- **변경 내용**: 최근 앱 목록에서 태스크를 스와이프하면 `onTaskRemoved`에서 `stopSelf()` 호출 → `onDestroy`에서 wakelock 해제
- **이유**: 태스크 제거 시 Flutter 엔진이 죽어 MethodChannel로 stop을 호출할 주체가 없음. 방치하면 "게임 진행 중" 알림과 wakelock이 고아로 남아 배터리를 소모
- **같은 맥락**: `START_NOT_STICKY` 명시 — FGS만 부활해도 Flutter 측이 죽어 있어 기능적으로 무의미하므로 재시작하지 않음

#### 3. WAKE_LOCK 권한 추가
- **파일**: `android/app/src/main/AndroidManifest.xml`
- **변경 내용**: `android.permission.WAKE_LOCK` 권한 추가 (일반 권한 — 사용자 동의 불필요)

#### 4. 게임 진입 게이트에서 배터리 최적화 체크 제거
- **파일**: `lib/core/services/permission/game_entry_gate.dart` (+ `game_entry_gate.g.dart` 재생성)
- **변경 내용**: `ensure()`가 위치 권한만 판정하도록 단순화. 배터리 최적화 상태 확인과 차단 다이얼로그 로직 제거
- **이유**: wakelock으로 근본 원인이 해결되어 배터리 설정 요구가 불필요해짐. 진입 장벽 제거
- **호출부 영향 없음**: 인터페이스(`ensure`)가 유지되어 home_page/deeplink_join_page 호출 코드는 변경 불필요
- **정리**: 배터리 안내 관련 l10n 문구도 ARB(ko/en/ja)에서 제거 — 현재 ARB/코드 어디에도 배터리 관련 키·로직 잔존 없음

#### 5. BackgroundService Dart 레이어 정비
- **파일**: `lib/core/services/background/background_service.dart`, `background_service_android.dart`, `background_service_ios.dart`
- **변경 내용**: start/stop에 멱등 + 동시성 가드 적용. 상태 플래그를 native 호출 `await` 이전에 선반영(optimistic)하고 실패 시 롤백
- **이유**: 게임 화면 진입 직후 즉시 dispose되는 등 start/stop이 교차 호출될 때, stop 쪽 멱등 가드가 잘못 통과되는 race 방지. native stop이 실패해도 Dart 상태는 종료로 정리(FGS는 OS가 정리하거나 다음 start에서 재초기화)

### 📌 참고사항
- wakelock 특성상 게임 세션 동안 CPU가 깨어 있어 배터리 소모가 있음. FGS 알림(영구 알림)으로 사용자에게 동작 중임이 표시되고, 세션 종료/태스크 제거/4시간 타임아웃 어느 경로로든 반드시 해제되도록 설계됨
- `home_page.dart`, `deeplink_join_page.dart`의 게이트 호출부 주석에 "배터리 게이트" 표현이 남아 있음 (동작 무관, 추후 주석 정리 대상)
- FGS 알림 문구는 네이티브 리소스(`strings.xml`) 현지화를 그대로 사용 — 이번 변경 범위 아님
