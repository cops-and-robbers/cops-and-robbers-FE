### 📌 작업 개요

새 캐릭터 디자인을 default 스킨으로 적용하고, 기존 캐릭터는 classic 스킨으로 보존해 이스터에그로 전환할 수 있도록 구현. 캐릭터 에셋 폴더 구조를 `{team}/{skinId}/{state}.svg` 규칙으로 재정비하고, 홈 화면·대기실 카드·게임 결과 다이얼로그·체포 락 오버레이 등 캐릭터가 노출되는 모든 위치에 글로벌 스킨 Provider를 연결.

### 🎯 구현 목표

- 신규 캐릭터(default) + 기존 캐릭터(classic) 듀얼 스킨 시스템 구축
- 홈 화면 캐릭터 5번 탭으로 스킨 토글 이스터에그
- 600ms 페이드 트랜지션으로 스킨 전환 시 시각적 부드러움 확보
- 게임 결과 다이얼로그의 신규 캐릭터 수치(위치/크기) 재조정
- 수감(JAILED) 도둑은 라이트 0.5 / 다크 0.7 opacity로 흐릿하게 처리해 활성 참가자와 구분
- 홈 환영 메시지를 치즈 컨셉(`누가 내 치즈 훔쳐갔어!!!!🧀`)으로 변경, 클래식 스킨은 기존 문구 유지

### ✅ 구현 내용

#### 1. 캐릭터 에셋 폴더 구조 재정비
- **경로 규칙**: `assets/characters/{team}/{skinId}/{state}.svg`
- 기존 단일 구조(`assets/characters/police/ready.svg`)를 `default`/`classic` 두 스킨으로 분리
- 게임 결과 캐릭터도 `assets/characters/{team}/result/{skinId}/{result}_{part}.svg` 규칙으로 통일
- 기존 result 에셋 6개(`win_body`, `lose_body`, `win/lose_arm_left/right`)를 `classic/`으로 이동 → 신규 default 에셋 추가
- `pubspec.yaml`에 default/classic 폴더 4개 등록

#### 2. 글로벌 캐릭터 스킨 Provider
- **파일**: `lib/core/theme/character_skin_provider.dart`
- `@Riverpod(keepAlive: true)` — 앱 프로세스 생애주기 동안 유지, 영속 저장은 하지 않아 재시작 시 자연스럽게 default로 복귀
- `String` 상태(`'default'` / `'classic'`), `toggle()` 메서드 제공

#### 3. 캐릭터 에셋 경로 생성 헬퍼
- **파일**: `lib/core/constants/character_assets.dart`
- `characterAssetPath({team, skinId, state})` — 일반 상태 SVG 경로
- `resultCharacterAssetPath({team, skinId, result, part})` — 결과 화면 분할 SVG 경로
- 호출부에서 문자열 조합 없이 일관된 경로 생성 가능

#### 4. 홈 화면 캐릭터 Stack + 이스터에그
- **파일**: `lib/features/session/presentation/widgets/home_character_stack.dart`
- 경찰(180×200, 앞) + 도둑(160×145, 뒤)을 좌우 살짝 겹치게 배치
- 두 캐릭터 어느 쪽이든 5탭 합산 시 스킨 토글 (2초 초과 시 카운터 리셋)
- `settings_page.dart`의 버전 5탭 이스터에그와 동일 패턴 차용

#### 5. 스킨 전환 페이드 트랜지션
- **파일**: `lib/core/widgets/fade_skin_transition.dart`
- 600ms 시퀀스: 0~200ms 어두워짐 → 200~300ms 검정 유지(스킨 swap) → 300~600ms 밝아짐
- `Overlay` + `AbsorbPointer`로 진행 중 모든 입력 차단
- 중간 시점(완전히 검정 구간 시작)에 `onMidpoint` 콜백 호출 → Provider 토글 타이밍 맞춤

#### 6. 홈 환영 메시지 i18n 변경
- **파일**: `lib/l10n/app_ko.arb`, `app_en.arb`, `app_ja.arb`
- `homePageWelcomeMessage` (default): `누가 내 치즈 훔쳐갔어!!!!🧀`
- `homePageWelcomeMessageClassic` (classic): `너무 기대 돼 이번에는 어떤 역할을 할까?`
- 홈 페이지에서 `ref.watch(characterSkinProvider)` 결과로 분기

#### 7. 게임 결과 다이얼로그 수치 재조정
- **파일**: `lib/features/game/presentation/widgets/game_over_result_dialog.dart`
- 신규 캐릭터 SVG의 시각 비율에 맞춰 위치/크기 상수 조정:
  - 경찰 몸통: 높이 136→140, 다이얼로그 겹침 40→14
  - 도둑 몸통: 높이 120→100, 겹침 36→5, 가로 오프셋 8→0
  - 도둑 팔: 크기 47×26→40×22, 좌우 inset 100→126
  - 공통 팔 top offset: -10→-12
- `resolveBodyAsset`/`resolveLeftArmAsset`/`resolveRightArmAsset` 함수에 `skinId` 파라미터 추가, `resultCharacterAssetPath` 사용으로 일원화

#### 8. 체포 락 오버레이 스킨 연동
- **파일**: `lib/features/game/presentation/widgets/arrest_lock_overlay.dart`
- 본인 수감 시 표시되는 도둑 캐릭터에 글로벌 스킨 적용 (기존: default 고정 → 변경: 글로벌 Provider 반영)

#### 9. 수감 도둑 흐리게 처리
- **파일**: `lib/features/session/presentation/widgets/participant_card.dart`
- `gameStatus == 'JAILED' && team == 'robber'` 조건에서 opacity 분기
  - 라이트 모드: 0.5 (디자이너 명세)
  - 다크 모드: 0.7 (어두운 배경에서 너무 사라지지 않게 보정)

#### 10. 이스터에그 카운터 Duration 비교 정확화
- **파일**: `lib/features/session/presentation/widgets/home_character_stack.dart`
- CodeRabbit 리뷰 반영: `inSeconds > 2` → `> Duration(seconds: 2)`
- `inSeconds`는 분수초를 버려 2.1~2.9초 간격도 2로 계산되어 의도한 “2초 초과 리셋”이 느슨해지는 문제 수정

### 🔧 주요 변경사항 상세

#### 캐릭터 폴더 구조 (Before → After)

**Before**:
```
assets/characters/
├── police/
│   ├── ready.svg
│   ├── not_ready.svg
│   └── result/
│       ├── win_body.svg
│       └── ... (6개)
└── robber/
    ├── ready.svg
    ├── not_ready.svg
    ├── jailed.svg
    └── result/
        └── ... (6개)
```

**After**:
```
assets/characters/
├── police/
│   ├── default/   ← 신규 캐릭터
│   │   ├── home.svg, ready.svg, not_ready.svg
│   ├── classic/   ← 기존 캐릭터 보존
│   │   ├── home.svg, ready.svg, not_ready.svg
│   └── result/
│       ├── default/  (6개)
│       └── classic/  (기존 6개 이동)
└── robber/
    ├── default/   (home + ready + not_ready + jailed)
    ├── classic/   (home + ready + not_ready + jailed)
    └── result/{default,classic}/
```

신규 `home.svg`는 홈 화면 캐릭터 Stack 전용 에셋이며, `ready/not_ready/jailed`는 참가자 카드용.

#### 페이드 트랜지션 시퀀스 (600ms)

`TweenSequence`로 3구간 분리:
- 0.0~0.333 (0~200ms): opacity 0→1, 가중치 200
- 0.333~0.5 (200~300ms): opacity 1 유지, 가중치 100 (스킨 swap 안전 구간)
- 0.5~1.0 (300~600ms): opacity 1→0, 가중치 300

중간 시점 콜백은 `addListener`에서 `value >= 200/600` 도달 시 한 번만 발화. `AnimationStatus.completed`에서 OverlayEntry 자동 제거.

#### 이스터에그 카운터 로직

```dart
void _onCharacterTap() {
  final now = DateTime.now();
  if (_lastTap != null &&
      now.difference(_lastTap!) > const Duration(seconds: 2)) {
    _tapCount = 0;
  }
  _lastTap = now;
  _tapCount++;

  if (_tapCount >= 5) {
    _tapCount = 0;
    showFadeSkinTransition(context, onMidpoint: () {
      ref.read(characterSkinProvider.notifier).toggle();
    });
  }
}
```

`Duration` 객체 비교를 사용해 2.1초도 정확히 “2초 초과”로 판정.

**특이사항**:
- `keepAlive: true`라서 스킨 변경은 앱 재시작 전까지 유지
- 영속 저장 없음 → 재시작 시 자동으로 default 복귀 (이스터에그 성격에 맞음)
- 게임 진행 중에 스킨 변경되어도 결과 다이얼로그까지 일관되게 반영

#### 수감 도둑 opacity 다크모드 분기

```dart
final isJailed =
    gameStatus == 'JAILED' && participant.team.toLowerCase() == 'robber';
final characterOpacity = isJailed ? (isDarkMode ? 0.7 : 0.5) : 1.0;
```

다크모드(도둑팀)에서는 어두운 배경 대비 0.5는 너무 흐려져 0.7로 보정. 라이트(경찰팀)는 디자이너 명세대로 0.5 유지.
