## 📋 개요

앱이 백그라운드로 전환될 때 iOS에서는 파란 바(blue bar), Android에서는 알림(notification)이 표시되는지 테스트하기 위한 기능을 구현했습니다. 기존 생명주기 테스트 페이지에 통합하여 앱의 백그라운드 동작을 시각적으로 확인할 수 있습니다.

```dart
/// 백그라운드 위치 추적 테스트 시작
Future<void> _startBackgroundLocationTest() async {
  try {
    // 권한 확인 및 요청
    LocationPermission permission = await Geolocator.checkPermission();
    if (permission == LocationPermission.denied) {
      permission = await Geolocator.requestPermission();
      if (permission == LocationPermission.denied) {
        if (mounted) {
          ScaffoldMessenger.of(context).showSnackBar(
            const SnackBar(content: Text('위치 권한이 거부되었습니다')),
          );
        }
        return;
      }
    }

    if (permission == LocationPermission.deniedForever) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(content: Text('설정에서 위치 권한을 허용해주세요')),
        );
      }
      return;
    }

    // 플랫폼별 백그라운드 설정
    late LocationSettings locationSettings;

    if (Platform.isIOS) {
      locationSettings = AppleSettings(
        accuracy: LocationAccuracy.high,
        distanceFilter: 10,
        allowBackgroundLocationUpdates: true, // 🔑 백그라운드 허용
        showBackgroundLocationIndicator: true, // 🔑 파란 바 표시
      );
    } else if (Platform.isAndroid) {
      locationSettings = AndroidSettings(
        accuracy: LocationAccuracy.high,
        distanceFilter: 10,
        foregroundNotificationConfig: const ForegroundNotificationConfig(
          notificationTitle: '경찰과 도둑',
          notificationText: '게임 위치 추적 중...', // 🔑 알림 표시
          notificationIcon: AndroidResource(name: 'ic_launcher'),
        ),
      );
    } else {
      locationSettings = const LocationSettings(
        accuracy: LocationAccuracy.high,
        distanceFilter: 10,
      );
    }

    // 위치 스트림 시작 (실제 위치 업데이트는 무시, 백그라운드 표시만 확인)
    Geolocator.getPositionStream(locationSettings: locationSettings).listen(
      (Position position) {
        debugPrint('📍 위치 업데이트: ${position.latitude}, ${position.longitude}');
      },
      onError: (error) {
        debugPrint('❌ 위치 추적 에러: $error');
      },
    );

    setState(() {
      _isTrackingLocation = true;
    });

    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(
            Platform.isIOS
                ? '백그라운드 위치 추적 시작\n상단 파란 바를 확인하세요'
                : '백그라운드 위치 추적 시작\n알림을 확인하세요',
          ),
          duration: const Duration(seconds: 3),
        ),
      );
    }
  } catch (e) {
    debugPrint('❌ 백그라운드 위치 추적 시작 실패: $e');
    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('위치 추적 시작 실패: $e')),
      );
    }
  }
}
```

### iOS 백그라운드 표시

**권한 설정만으로는 부족합니다!**

```dart
// ❌ 잘못된 생각: Info.plist 권한만 설정하면 끝
// ✅ 올바른 접근: 권한 + 코드 옵션 필요

AppleSettings(
  allowBackgroundLocationUpdates: true,  // 백그라운드에서 위치 업데이트 허용
```

| 옵션 | 역할 | 효과 |
|------|------|------|
| `allowBackgroundLocationUpdates` | 백그라운드 위치 추적 허용 | 앱이 백그라운드에 있어도 위치 업데이트 수신 |
| `showBackgroundLocationIndicator` | 파란 바 표시 | 상단 상태 바에 파란색 배경 표시 (사용자에게 백그라운드 추적 알림) |

### Android 백그라운드 표시

```dart
AndroidSettings(
  foregroundNotificationConfig: const ForegroundNotificationConfig(
    notificationTitle: '경찰과 도둑',
    notificationText: '게임 위치 추적 중...',
    notificationIcon: AndroidResource(name: 'ic_launcher'),

```

| 속성 | 역할 | 효과 |
|------|------|------|
| `notificationTitle` | 알림 제목 | 알림 바에 표시될 제목 |
| `notificationText` | 알림 내용 | 알림 바에 표시될 설명 텍스트 |
| `notificationIcon` | 알림 아이콘 | 알림에 표시될 앱 아이콘 |

**중요**: Android는 포그라운드 서비스를 사용하여 백그라운드 위치 추적을 수행하며, 이는 **지속적인 알림**으로 사용자에게 표시됩니다.

## 🎓 학습 포인트

### 1. 권한 설정 vs 코드 설정

**핵심 개념**: 모바일 플랫폼에서 백그라운드 기능을 활성화하려면 **두 가지 설정이 모두 필요**합니다.

| 설정 유형 | iOS | Android |
|----------|-----|---------|
| **권한 설정** | Info.plist에 권한 설명 추가 | AndroidManifest.xml에 권한 선언 |
| **코드 설정** | `AppleSettings`에 백그라운드 옵션 활성화 | `AndroidSettings`에 포그라운드 서비스 설정 |

**잘못된 접근**:
```dart
// ❌ Info.plist나 AndroidManifest.xml만 설정하고 코드는 작성 안 함
// → 권한은 있지만 백그라운드 표시가 안 됨
```

**올바른 접근**:
```dart
// ✅ 권한 설정 + 코드에서 백그라운드 옵션 명시적으로 활성화
if (Platform.isIOS) {
  AppleSettings(allowBackgroundLocationUpdates: true, showBackgroundLocationIndicator: true)
} else if (Platform.isAndroid) {
  AndroidSettings(foregroundNotificationConfig: ...)
}
```

### 2. iOS 파란 바의 의미

Apple은 사용자 프라이버시를 중시하여, 앱이 백그라운드에서 위치를 추적할 때 **시각적 표시**를 강제합니다.

```dart
showBackgroundLocationIndicator: true
```

- **파란 바**: 상단 상태 바가 파란색으로 변경
- **목적**: 사용자가 백그라운드 위치 추적을 인지하도록 함
- **제어**: 개발자가 끌 수 없음 (Apple의 프라이버시 정책)

### 3. Android 포그라운드 서비스의 필수성

Android 8.0 (API 26) 이상에서는 백그라운드에서 위치를 추적하려면 **포그라운드 서비스**를 사용해야 합니다.

```dart
foregroundNotificationConfig: const ForegroundNotificationConfig(
  notificationTitle: '경찰과 도둑',
  notificationText: '게임 위치 추적 중...',
)
```

- **포그라운드 서비스**: 사용자가 볼 수 있는 알림을 통해 서비스가 실행 중임을 알림
- **제거 불가**: 사용자는 알림을 스와이프해서 지울 수 없음 (서비스가 종료되기 전까지)
- **배터리 관리**: 시스템이 서비스를 강제 종료하지 않음

### 4. geolocator 패키지의 편리함

```dart
Geolocator.getPositionStream(locationSettings: locationSettings)
```

- **크로스 플랫폼**: iOS와 Android를 단일 API로 제어
- **권한 관리**: `checkPermission()`, `requestPermission()` 제공
- **플랫폼별 설정**: `AppleSettings`, `AndroidSettings`로 세밀한 제어

### 실제 게임에서 위치 추적 적용

이번 테스트 구현을 바탕으로 실제 게임 화면에서 위치 추적을 적용할 수 있습니다.

```dart
// 게임 시작 시 (features/game/)
final locationSettings = Platform.isIOS
    ? AppleSettings(
        allowBackgroundLocationUpdates: true,
        showBackgroundLocationIndicator: true,
      )
    : AndroidSettings(
        foregroundNotificationConfig: ForegroundNotificationConfig(
          notificationTitle: '경찰과 도둑',
          notificationText: '게임 진행 중... 위치 추적 활성화',
        ),
      );

// 위치 스트림으로 실시간 좌표 전송
Geolocator.getPositionStream(locationSettings: locationSettings).listen((position) {
  // WebSocket으로 서버에 위치 전송
  webSocketClient.send({
    'latitude': position.latitude,
    'longitude': position.longitude,
  });
});
```

### 생명주기 기반 배터리 최적화

```dart
// AppLifecycleService와 연동
service.stateStream.listen((state) {
  if (state == AppLifecycleState.paused) {

    Geolocator.changeSettings(
      accuracy: LocationAccuracy.high,
      distanceFilter: 10,
    );
  }
});
```
