# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 다국어 지원 (한국어/일본어/영어)

- 앱 전체 텍스트를 외부화하고 한국어, 일본어, 영어 3개 언어를 지원합니다.
- 처음 실행 시 기기 언어를 자동으로 인식해 표시합니다.

2. 언어 설정 페이지 추가

- 설정에서 시스템 따름 / 한국어 / English / 日本語 중 하나를 선택할 수 있습니다.
- 변경 즉시 앱 전체에 반영됩니다.

3. 법적 문서 다국어 안내

- 한국어 외 언어로 앱을 사용하는 분이 약관, 개인정보처리방침, 위치정보 이용약관을 열람할 때 한국어 원본임을 알리는 안내 배너가 표시됩니다.

4. 회원 탈퇴 키워드 통일

- 기존: 한국어에서는 '탈퇴하기' 또는 'delete' 입력, 다른 언어에서는 안내 문구가 일치하지 않았습니다.
- 변경: 모든 언어에서 'delete'로 통일해 일관되게 동작합니다.

5. 안정성 개선 및 버그 수정

- 다국어 환경에서 체포 잠금 화면 안내 문구가 잘려 보이던 문제를 수정했습니다.
- 일부 서버 오류 상황에서 사용자에게 부정확한 안내가 노출되던 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. Multi-language Support (Korean / Japanese / English)

- The entire app text has been externalized to support Korean, Japanese, and English.
- The app automatically detects and displays your device language on first launch.

2. Language Settings Page Added

- You can choose System / 한국어 / English / 日本語 from Settings.
- Changes apply across the app immediately.

3. Multilingual Notice for Legal Documents

- When non-Korean users open the Terms of Service, Privacy Policy, or Location Terms, a banner now indicates that the original document is in Korean.

4. Account Deletion Keyword Unified

- Before: Korean accepted both '탈퇴하기' and 'delete', and other languages had inconsistent guidance.
- After: All languages now use 'delete' as the single confirmation keyword.

5. Stability Improvements & Bug Fixes

- Fixed a text overflow issue on the arrest lock screen in non-Korean languages.
- Fixed an issue where inaccurate messages were shown for certain server error responses.
