# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 채팅 닫기 조작 간소화
- 기존: 게임 중 채팅을 내리려면 키보드를 먼저 닫고 빈 공간을 다시 눌러야 했습니다.
- 변경: 채팅 화면 바깥을 한 번 누르면 키보드와 채팅창이 함께 닫힙니다.

2. 지도 핑 표시 성능 개선
- 핑 마커 이미지를 재사용하도록 개선하여 지도 화면이 더 부드럽게 동작합니다.

3. 오류 안내 보강
- 일부 상황에서 일반적인 오류 문구만 표시되던 문제를 보강하여, 상황에 맞는 안내가 표시됩니다.

4. 위치 공유 동작 일관화
- 체포 상태에 따른 위치 공유 기준을 통일하여 탈옥 전후 동작이 일관되게 처리됩니다.

5. 안정성 개선 및 버그 수정
- 화면 종료 직후 발생할 수 있던 내부 오류를 방지했습니다.
- 출시 빌드에서 불필요한 내부 기록을 비활성화했습니다.

==========

[English]

Key changes in this version:

1. Simplified Chat Dismissal
- Before: Closing the chat during a game required dismissing the keyboard first, then tapping the empty area again.
- After: A single tap outside the chat closes both the keyboard and the chat panel.

2. Map Ping Performance Improvement
- Ping marker images are now reused, making the map screen run more smoothly.

3. Improved Error Messages
- Situations that previously showed only a generic error message now display guidance appropriate to the situation.

4. Consistent Location Sharing
- Location sharing rules based on arrest status are now unified, so behavior before and after a jailbreak is handled consistently.

5. Stability Improvements & Bug Fixes
- Prevented internal errors that could occur right after leaving a screen.
- Disabled unnecessary internal logging in release builds.
