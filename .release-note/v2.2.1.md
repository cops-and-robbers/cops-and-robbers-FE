# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 공식 SNS 채널 바로가기 추가

- 설정 화면에서 공식 SNS 채널로 바로 이동할 수 있습니다.

2. 대기방 QR 코드 개선

- 대기방 QR 코드를 통해 더 간편하게 방에 참여할 수 있습니다.

3. 진동 피드백 추가

- 버튼을 누르거나 지도를 길게 눌러 핀을 찍을 때 진동 피드백이 제공됩니다.

4. 핀 찍기 튜토리얼 안내 추가

- 인게임 튜토리얼에서 지도에 핀 찍는 방법을 안내합니다.

==========

[English]

Key changes in this version:

1. Official SNS Channel Shortcuts

- You can now jump to official SNS channels from the Settings screen.

2. Improved Waiting Room QR Code

- Joining a room via the waiting room QR code is now simpler.

3. Haptic Feedback Added

- Haptic feedback is now provided when tapping buttons or long-pressing the map to drop a pin.

4. Pin Drop Tutorial Guide

- The in-game tutorial now explains how to drop pins on the map.
