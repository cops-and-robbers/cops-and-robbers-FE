# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 로딩 화면 개편

- 대기실과 게임 화면의 로딩 화면을 파동 링과 팀 캐릭터가 등장하는 새로운 비주얼로 교체했습니다.
- 로딩 중 화면이 사라지지 않던 문제를 수정했습니다.

2. 폴리곤 게임 구역 기능 추가

- 원형뿐 아니라 여러 지점을 찍어 자유로운 형태로 게임 구역을 설정할 수 있습니다.
- 구역 반경 표시 오류와 유효성 검증 관련 문제를 수정했습니다.

3. 게임 종료 화면 개편

- 게임 종료 시 표시되는 화면에 내 기록을 함께 확인할 수 있도록 통합했습니다.

4. 배터리 제한없음 설정 없이 백그라운드 게임 유지

- 화면이 꺼지거나 다른 화면으로 이동해도 위치 추적과 실시간 연결이 끊기지 않습니다.
- 게임 진입 시 배터리 설정을 요구하던 안내를 제거했습니다.

5. 게임 결과 이미지 저장 기능 추가

- 게임 종료 화면에서 결과 이미지를 갤러리에 저장하거나 공유할 수 있습니다.

6. 구역 설정 지도 축소 제한

- 구역을 설정하는 지도에서 과도하게 축소해 핀이 화면 밖으로 사라지는 문제를 방지했습니다.

7. 안정성 개선 및 버그 수정

- 다크 테마에서 구역 방식 선택 화면의 가독성을 개선했습니다.
- 지도 로딩 관련 오류로 게임이 중단되던 문제를 수정했습니다.
- 안내 문구를 자연스럽게 다듬었습니다.
- 이미지 저장·공유 중 연속 탭으로 인한 중복 처리 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. Loading Screen Redesign

- Replaced the loading screen in the waiting room and game with a new visual featuring pulse rings and team characters.
- Fixed an issue where the loading screen would not dismiss properly.

2. Polygon Game Area Support

- Game areas can now be set in a free-form shape by placing multiple points, in addition to the existing circular shape.
- Fixed issues with area radius display and validation.

3. Game-Over Screen Redesign

- Integrated personal records into the game-over screen.

4. Background Game Continuity Without Disabling Battery Optimization

- Location tracking and the live connection no longer drop when the screen turns off or you switch to another screen.
- Removed the prompt that previously required changing battery settings to start a game.

5. Result Image Save Added

- You can now save or share the result image from the game-over screen.

6. Area Setup Map Zoom Limit

- Prevented pins from disappearing off-screen when zooming out too far on the area setup map.

7. Stability Improvements & Bug Fixes

- Improved readability of the area type selector in dark theme.
- Fixed an issue where a map loading error could interrupt the game.
- Refined guidance messages for clarity.
- Fixed a duplicate-processing issue caused by rapidly tapping during image save or share.
