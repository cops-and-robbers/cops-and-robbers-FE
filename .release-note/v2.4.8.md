# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 로딩 화면 개편

- 대기실과 게임 화면의 로딩 화면을 파동 링과 팀 캐릭터가 등장하는 새로운 비주얼로 교체했습니다.
- 로딩 중 화면이 사라지지 않던 문제를 수정했습니다.

2. 폴리곤 게임 구역 기능 추가

- 원형뿐 아니라 여러 지점을 찍어 자유로운 형태로 게임 구역을 설정할 수 있습니다.
- 구역 반경 표시 오류와 유효성 검증 관련 문제를 수정했습니다.

3. 게임 종료 화면 개편

- 게임 종료 시 표시되는 화면에 내 기록을 함께 확인할 수 있도록 통합했습니다.

4. 배터리 제한없음 설정 없이 백그라운드 게임 유지

- 화면이 꺼지거나 다른 화면으로 이동해도 위치 추적과 실시간 연결이 끊기지 않습니다.
- 게임 진입 시 배터리 설정을 요구하던 안내를 제거했습니다.

5. 게임 결과 이미지 저장 기능 추가

- 게임 종료 화면에서 결과 이미지를 갤러리에 저장하거나 공유할 수 있습니다.

6. 구역 설정 지도 축소 제한

- 구역을 설정하는 지도에서 과도하게 축소해 핀이 화면 밖으로 사라지는 문제를 방지했습니다.

7. 안정성 개선 및 버그 수정

- 다크 테마에서 구역 방식 선택 화면의 가독성을 개선했습니다.
- 지도 로딩 관련 오류로 게임이 중단되던 문제를 수정했습니다.
- 안내 문구를 자연스럽게 다듬었습니다.
- 이미지 저장·공유 중 연속 탭으로 인한 중복 처리 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. Loading Screen Redesign

- Replaced the loading screen in the waiting room and game with a new visual featuring pulse rings and team characters.
- Fixed an issue where the loading screen would not dismiss properly.

2. Polygon Game Area Support

- Game areas can now be set in a free-form shape by placing multiple points, in addition to the existing circular shape.
- Fixed issues with area radius display and validation.

3. Game-Over Screen Redesign

- Integrated personal records into the game-over screen.

4. Background Game Continuity Without Disabling Battery Optimization

- Location tracking and the live connection no longer drop when the screen turns off or you switch to another screen.
- Removed the prompt that previously required changing battery settings to start a game.

5. Result Image Save Added

- You can now save or share the result image from the game-over screen.

6. Area Setup Map Zoom Limit

- Prevented pins from disappearing off-screen when zooming out too far on the area setup map.

7. Stability Improvements & Bug Fixes

- Improved readability of the area type selector in dark theme.
- Fixed an issue where a map loading error could interrupt the game.
- Refined guidance messages for clarity.
- Fixed a duplicate-processing issue caused by rapidly tapping during image save or share.

# [심사 노트 — App Review Information]

[한국어]

초대 코드는 앱 안에서 방을 만들면 자동으로 발급됩니다. 저희가 미리 전달드릴 수 있는 고정 코드는 없습니다.

초대 코드 확인 방법

1. 앱을 실행하고 Apple로 로그인합니다. 별도의 데모 계정은 필요하지 않습니다.
2. 닉네임을 입력하고 위치 권한을 허용합니다.
3. 홈 화면에서 방 만들기를 선택합니다.
4. 지도에서 게임 구역과 감옥 위치를 지정하고, 인원과 시간을 설정한 뒤 방 생성하기를 누릅니다.
5. 대기실로 이동하면 초대 코드가 화면에 바로 표시됩니다. 이 값이 초대 코드입니다.
6. 다른 기기에서 홈 화면의 참여하기를 선택하고 이 코드를 입력하면 같은 방에 입장합니다. 코드 직접 입력과 QR 코드 스캔 모두 지원합니다.

심사 시 참고 사항

- 실시간 위치 기반 멀티플레이 게임입니다. 방장은 다른 참가자가 입장해 준비를 완료한 뒤에 게임 시작 버튼을 사용할 수 있으므로, 게임 진행까지 확인하시려면 기기 2대가 필요합니다.
- 기기 1대만 사용 가능하시면 App Store Connect로 회신해 주세요. 심사용 방을 즉시 개설하고 초대 코드를 전달드리겠습니다.
- 게임 구역은 방을 만든 위치를 기준으로 설정됩니다. 심사 담당자님 위치에서 방을 직접 만드시면 구역 안에서 정상적으로 진행됩니다.

==========

[English]

The invite code is generated inside the app when you create a room. There is no fixed code we can provide in advance.

How to obtain an invite code

1. Launch the app and sign in with Apple. No separate demo account is required.
2. Enter a nickname and allow the location permission.
3. On the home screen, select Create Room.
4. Set the game area and the jail location on the map, adjust the player count and duration, then tap Create Room.
5. You are taken to the waiting room, where the invite code is shown on screen. That value is the invite code.
6. On another device, select Join on the home screen and enter that code to enter the same room. Both manual entry and QR code scanning are supported.

Notes for review

- This is a real-time location-based multiplayer game. The host can only use the Start Game button after another participant has joined and marked themselves ready, so two devices are needed to reach actual gameplay.
- If only one device is available, please reply through App Store Connect. We will open a room for review and send you the invite code right away.
- The game area is created around the location where the room is made. Creating the room at your own location keeps you inside the play area.
