==========

[한국어]

이번 버전의 주요 변경사항입니다.

1. 앱 아이콘 변경
- 앱 아이콘이 새로운 디자인으로 변경되었습니다.

2. 크레딧 멤버 목록 업데이트
- 크레딧 페이지의 멤버 정보가 업데이트되었습니다.

3. 대기방 퇴장 확인 창 추가
- 대기방에서 뒤로가기 시 실수 방지를 위한 확인 다이얼로그가 표시됩니다.

4. 구역 이탈 안내 문구 수정
- 패널티가 위치 노출에서 화면 잠금으로 변경됨에 따라 안내 문구를 동기화했습니다.
- 기존: "구역 안으로 들어갈 때까지 위치가 드러나요"
- 변경: "구역 밖으로 나가면 화면이 잠겨요"

5. 네트워크 오프라인 방어 로직 보강
- 네트워크가 끊긴 상태에서 방 나가기 시도 시, 서버 퇴장 처리가 실패하면 클라이언트도 방에 그대로 남도록 수정했습니다 (기존에는 UI만 나가지는 문제가 있었습니다).
- 스플래시 화면에서 hot restart 직후 오프라인으로 잘못 인식되던 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. App Icon Update
- The app icon has been updated with a new design.

2. Credits Member List Update
- The member information on the credits page has been updated.

3. Waiting Room Exit Confirmation
- A confirmation dialog now appears when leaving the waiting room to prevent accidental exits.

4. Zone Exit Warning Text Update
- The penalty has changed from location exposure to screen lock, and the warning text has been updated accordingly.
- Before: "Your location will be revealed until you return to the zone."
- After: "Your screen will be locked if you leave the zone."

5. Offline Network Handling Improvements
- Fixed an issue where leaving a room while offline would exit the UI locally even though the server-side exit failed. The client now stays in the room if the server request fails.
- Fixed a false offline detection on the splash screen after a hot restart.
