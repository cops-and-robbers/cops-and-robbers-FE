# [주요 변경사항 — 애플 제출용]

[한국어]
```text
이번 버전의 주요 변경사항입니다.

1. 게임 시간 표시 개선
- 기존: 게임 제한 시간과 다음 위치 공개 시간이 서로 다른 기준으로 갱신되어 초가 어긋날 수 있었습니다.
- 변경: 두 시간을 같은 기준으로 계산하고, 앱에 다시 들어왔을 때 실제 경과 시간을 즉시 반영합니다.

2. 경찰 대기 안내 개선
- 기존: 재접속 시 경찰 대기 안내가 중복되거나 다른 안내 뒤에 남을 수 있었습니다.
- 변경: 남은 대기 시간에 맞춰 한 번만 표시하고 시간이 끝나면 정확히 닫힙니다.

3. 커뮤니티 광고 추가
- 전체, 우리 동네, 내 모임 목록의 상단과 게시글 사이에 광고를 표시합니다.
- 게시글의 댓글이 없어도 댓글 영역에 광고가 표시됩니다.

4. 광고 로딩 화면 개선
- 광고를 불러오는 동안 미리 같은 크기의 공간을 표시해 목록이 갑자기 밀리지 않습니다.
- 광고를 불러오지 못하면 같은 공간에서 모집글 작성 안내를 제공합니다.
```

[English]
```text
Key changes in this version:

1. Improved Game Time Display
- Before: The game timer and next location reveal timer could update from different reference points and become out of sync.
- After: Both timers use the same reference point and immediately reflect elapsed time when returning to the app.

2. Improved Police Waiting Notice
- Before: The police waiting notice could appear more than once after reconnecting or remain behind another notice.
- After: It appears once for the remaining wait time and closes correctly when the wait ends.

3. Community Ads Added
- Ads now appear at the top of All, Our Neighborhood, and My Groups lists and between posts.
- An ad also appears in the comment section when a post has no comments.

4. Improved Ad Loading Display
- Space is reserved while an ad loads so the list does not suddenly shift.
- If an ad cannot be loaded, the same space provides a shortcut for creating a community post.
```
