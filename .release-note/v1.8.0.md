- 게임 진입 시 이전 발자국이 잠깐 보이던 문제를 수정했습니다
- 마지막 도둑 체포 시 참가자 목록에서 도둑 표시가 원래대로 되돌아가던 문제를 수정했습니다

==========

[한국어]

이번 버전의 주요 변경사항입니다.

1. 초대 QR 코드 유효 시간 적용

- 초대 QR 코드에 유효 시간이 적용되어, 일정 시간이 지나면 새로 발급받아야 합니다.
- 만료된 코드로는 게임에 참여할 수 없으며, 대기방에서 언제든 새 코드를 발급받을 수 있습니다.

2. 대기방 UI 개선

- 대기방 화면의 레이아웃과 구성 요소를 정리하여 가독성을 개선했습니다.
- 대기 중 슬롯 카드를 제거하고 참가자 표시 방식을 단순화했습니다.

3. 대기방 초대 다이얼로그와 튜토리얼 겹침 수정

- 대기방에서 초대 다이얼로그와 튜토리얼 안내가 동시에 표시되어 화면이 어색해 보이던 문제를 수정했습니다.

4. 게임 진입 시 이전 발자국 노출 수정

- 도둑 팀으로 게임에 다시 접속할 때 이전 라운드의 발자국이 잠깐 표시되던 문제를 수정했습니다.

5. 마지막 도둑 체포 시 참가자 목록 표시 수정

- 경찰이 마지막 도둑을 체포하여 게임이 종료될 때, 참가자 목록에서 해당 도둑이 감옥 상태로 표시됐다가 활동 중 상태로 되돌아가던 문제를 수정했습니다.
- 이제 체포된 도둑은 결과 화면이 닫힐 때까지 감옥 상태로 유지됩니다.

==========

[English]

Key changes in this version:

1. Invite QR Code Expiration

- Invite QR codes now expire after a set time and must be reissued.
- Expired codes cannot be used to join a game. A new code can be issued from the waiting room at any time.

2. Waiting Room UI Improvements

- The waiting room layout and components have been refined for better readability.
- Removed the pending slot cards and simplified how participants are displayed.

3. Fixed Invite Dialog and Tutorial Overlap in Waiting Room

- Fixed an issue where the invite dialog and tutorial guide appeared at the same time in the waiting room, causing a confusing layout.

4. Fixed Previous Footprints Showing on Game Entry

- Fixed an issue where footprints from a previous round were briefly shown when rejoining the game as a robber.

5. Fixed Arrested Robber Display in Participant List

- Fixed an issue where the last arrested robber appeared as jailed and then reverted to active in the participant list when the game ended.
- Arrested robbers now remain in the jailed state until the result screen closes.
