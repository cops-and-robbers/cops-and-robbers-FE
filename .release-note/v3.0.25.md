# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 인게임 채팅 개선
- 채팅 버튼으로 팀 채팅과 전체 채팅을 오가는 전체 화면 채팅을 열 수 있습니다.
- 지도로 돌아가도 읽지 않은 메시지 수, 작성 중인 내용, 채널별 위치가 유지됩니다.
- 새 메시지는 채팅 버튼을 가리키는 말풍선으로 미리 보여줍니다.

2. 수감 및 탈옥 흐름 개선
- 수감 중 화면 전체에 철창을 표시하면서도 지도 이동과 확대는 계속 사용할 수 있습니다.
- 감옥 영역을 강조해 현재 위치와 돌아갈 방향을 쉽게 확인할 수 있습니다.
- 감옥 밖으로 확실히 이동하면 자동으로 탈옥하며, 위치 정보가 드문 상황에서도 다시 확인합니다.
- 자동 탈옥이 어려운 경우에는 기존 수동 탈옥 기능을 계속 사용할 수 있습니다.

3. 이벤트 게임 증거품 간소화
- 기존: 검거 결과에 증거품 3개를 표시했습니다.
- 변경: 증거품을 2개로 줄이고, 두 명을 검거하면 모두 공개되도록 배치를 조정했습니다.

4. 게임 시간 표시 개선
- 게임 시간이 변경되면 다음 초를 기다리지 않고 즉시 반영합니다.
- 60분을 넘는 시간도 분이 다시 0부터 시작하지 않고 전체 분으로 표시됩니다.

5. 커뮤니티와 주요 화면 사용성 개선
- 커뮤니티 모집글을 인기순으로 정렬할 수 있습니다.
- 주요 버튼과 공유, 채팅방 진입 등의 동작에 진동 반응을 보완했습니다.
- 닉네임 수정 화면의 이동 방식과 버튼 글자 크기, 숫자 입력 화면의 하단 여백을 개선했습니다.

6. 앱 시작과 링크 이동 안정화
- 앱을 새로 시작하면서 모집글 링크를 열 때 목적지 대신 홈으로 이동하거나 링크가 사라지던 문제를 수정했습니다.
- 연결 장애가 발생했을 때 시작 화면에 계속 머무르던 문제를 개선했습니다.

7. 안정성 개선 및 버그 수정
- 방 참여 화면에서 카메라를 열 때 검은 화면이 나타나던 문제를 수정했습니다.
- 채팅 화면의 메시지 간격과 입력창 높이, 아이폰 키보드 뒤 배경 표시를 개선했습니다.
- 게임 화면의 상단 정보와 공지 아이콘 배치를 정리했습니다.

==========

[English]

Key changes in this version:

1. Improved In-Game Chat
- Open a full-screen chat from the chat button and switch between team and all-player channels.
- Unread counts, drafts, and channel positions remain intact after returning to the map.
- New messages appear in a speech bubble pointing to the chat button.

2. Improved Jail and Escape Flow
- Full-screen jail bars now appear during confinement while map movement and zoom remain available.
- The jail area is highlighted to make the current position and return direction easier to see.
- Leaving the jail area clearly triggers automatic escape, with an additional check when location updates are infrequent.
- Manual escape remains available when automatic escape cannot be completed.

3. Simplified Event Game Evidence
- Before: Three evidence items appeared in arrest results.
- After: Evidence was reduced to two items, and both are revealed after two arrests.

4. Improved Game Time Display
- Changes to the game time are reflected immediately without waiting for the next second.
- Durations over 60 minutes now show total minutes instead of restarting from zero.

5. Improved Community and Screen Usability
- Recruiting posts can now be sorted by popularity.
- Vibration feedback was added to more key actions, including sharing and entering chat rooms.
- Improved navigation on the nickname edit screen, button text size, and bottom spacing on number entry screens.

6. More Reliable Launch and Link Navigation
- Fixed recruiting links opening the Home screen or being lost when launching the app from a closed state.
- Improved startup behavior when a connection failure occurs.

7. Stability Improvements and Bug Fixes
- Fixed a black screen that could appear when opening the camera from the join game screen.
- Improved chat message spacing, input height, and the background behind the iPhone keyboard.
- Refined the placement of game status information and the notice icon.
