# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 권한 안내 문구 다국어 지원
- 위치, 카메라, 알림 권한을 요청할 때 표시되는 안내 문구가 기기 설정 언어(한국어, 영어, 일본어)에 맞게 표시됩니다.

2. 로그인 버튼 문구 정리
- 로그인 버튼 문구를 다듬었습니다.
- 기존: Apple로 시작하기 / Google로 시작하기
- 변경: Apple로 계속하기 / Google로 계속하기

3. 안정성 개선 및 버그 수정
- 일부 기기 언어에서 권한 안내 문구가 다른 언어로 표시되던 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. Localized Permission Descriptions
- Permission descriptions shown when requesting location, camera, and notification access now match the device language (Korean, English, Japanese).

2. Stability Improvements and Bug Fixes
- Fixed an issue where permission descriptions could appear in a different language than the device setting.
