# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. QR 체포 버튼을 게임 화면에 노출
- 기존: 참가자 목록 화면을 열어야 QR 체포·인증 버튼에 접근할 수 있었습니다.
- 변경: 게임 화면 우측 하단에서 바로 QR 버튼을 사용할 수 있습니다.

2. 내 위치 버튼 위치 이동
- 기존: 우측 하단에서 참가자 버튼과 함께 표시되었습니다.
- 변경: 좌측 하단으로 옮겨 시야가 더 넓어지고 양손 조작이 편해졌습니다.

3. 튜토리얼 미션 순서 조정
- 기존: 참가자 보기 → QR → 지도 복귀 순서로 진행했습니다.
- 변경: QR → 참가자 보기 → 지도 복귀 순서로 자연스럽게 학습합니다.

4. 디자인 정돈
- QR 아이콘 디자인을 새로 적용했습니다.
- 인게임 액션 버튼 크기를 통일했습니다.

==========

[English]

Key changes in this version:

1. QR Arrest Button Surfaced on the Game Screen
- Before: The QR arrest/verification button was only accessible from the participants list screen.
- After: The QR button is now directly available at the bottom-right of the game screen.

2. My Location Button Repositioned
- Before: Displayed alongside the participants button at the bottom-right.
- After: Moved to the bottom-left for a wider field of view and easier two-handed control.

3. Tutorial Mission Order Updated
- Before: Participants → QR → Return to Map.
- After: QR → Participants → Return to Map for a more natural learning flow.

4. Design Polish
- Applied a new QR icon design.
- Unified the size of in-game action buttons.
