🚀 [기능개선][캐릭터] 신규 캐릭터 적용 및 폴더 구조 재정비

## 본문

## 📝 현재 문제점

- 캐릭터 디자인이 신규 시안으로 변경되었으나 앱에는 기존 에셋이 적용되어 있음
- 홈 화면에서 임시로 `assets/app_icon.png`가 캐릭터 자리에 노출되고 있음
- 추후 아바타/스킨 시스템 도입을 고려해 폴더 구조에 확장 포인트가 필요함
- 기존 캐릭터를 단순 삭제하지 않고 추후 이스터에그 용도로 보존해야 함

## 🛠️ 해결 방안 / 제안 기능

- 신규 캐릭터 SVG를 `default` 스킨으로 일괄 적용 (대기실/인게임 자동 반영)
- 기존 캐릭터를 `classic` 스킨으로 백업하여 이스터에그 활용 여지 확보
- 홈 화면에 경찰+도둑 Stack 위젯 신규 도입 (`HomeCharacterStack`)
- 캐릭터 SVG 경로 헬퍼의 `skinId` 파라미터로 default/classic 분기 가능하도록 폴더 구조 통일

## ⚙️ 작업 내용

- 폴더 구조 재정비
  - `assets/characters/{team}/default/` — 신규 캐릭터 (현재 활용 스킨)
  - `assets/characters/{team}/classic/` — 기존 캐릭터 백업 (이스터에그용)
  - `assets/characters/{team}/result/default/` — 신규 결과 화면 캐릭터
  - `assets/characters/{team}/result/classic/` — 기존 결과 화면 백업
- 신규 캐릭터 SVG 적용 (경찰/도둑 default — ready, not_ready, jailed, home)
- 신규 결과 화면 SVG 적용 (result/default — win/lose × body, arm_left, arm_right)
- 홈 화면 전용 신규 포즈 `home.svg` 추가 (경찰/도둑)
- 홈 화면 캐릭터 위젯 `HomeCharacterStack` 신규 작성
  - 경찰 180x200(앞·좌측), 도둑 160x145(뒤·우측)
  - 반응형(.w/.h) + `Clip.none`으로 SizedBox 영역 외 노출 허용
- 홈 화면 `app_icon.png` → `HomeCharacterStack` 위젯 교체 및 레이아웃 spacing 재조정
- 게임 종료 결과 다이얼로그(`game_over_result_dialog.dart`) 경로 매핑 `result/` → `result/default/` 갱신
- `pubspec.yaml` 에셋 등록 갱신 (classic 2개 + result/{default,classic} 4개 신규 등록)
- `AppSpacing.vertical58` 상수 추가
