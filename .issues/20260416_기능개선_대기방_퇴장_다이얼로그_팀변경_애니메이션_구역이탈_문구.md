## 제목

🚀 [기능개선][대기방] 퇴장 확인 다이얼로그, 팀 변경 페이드 애니메이션, 구역 이탈 규칙 문구 변경

## 본문

## 📝 현재 문제점

- 대기방에서 나가기 버튼을 누르면 확인 절차 없이 바로 퇴장된다
- 팀 변경 시 화면 전환이 즉각적으로 이루어져 어색하다
- 구역 이탈 규칙 문구가 "구역 안으로 돌아갈 때까지 위치가 드러나요"로 되어 있으나, 실제 패널티는 화면 잠금으로 변경 예정

## 🛠️ 해결 방안 / 제안 기능

- 대기방에서 나가기를 누르면 확인 다이얼로그를 표시한다
- 팀 변경 시 앱 크레딧 화면에서 사용하는 것과 동일한 페이드 애니메이션을 적용한다
- 구역 이탈 규칙 문구를 "구역 밖으로 나가면 화면이 잠겨요"로 변경한다

## ⚙️ 작업 내용

- 대기방 퇴장 확인 다이얼로그 추가
- 팀 변경(경찰 ↔ 도둑) 시 페이드 애니메이션 적용
- 구역 이탈 규칙 텍스트 변경 (기능은 이미 구현됨, 문구만 수정)
