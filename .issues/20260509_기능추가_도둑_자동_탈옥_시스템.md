## 제목

⚙️ [기능추가][게임] 도둑 자동 탈옥 시스템 (감옥 이탈 감지)

## 본문

## 📝 현재 문제점

- 현재 수감된 도둑은 화면을 덮는 체포 잠금 오버레이의 "탈옥 완료" 버튼을 직접 눌러야만 탈옥 처리가 된다.
- 감옥 위치까지 실제로 이동하지 않아도 버튼만 누르면 탈옥이 가능해, "감옥에 갇혔다가 직접 빠져나온다"는 게임 룰의 본질과 어긋난다.
- 도둑 입장에서 조작(부정행위 or 실수)의 여지가 있고, 경찰 입장에서는 체포 직후 도둑이 곧장 탈옥하는 상황을 막을 방법이 없다.

## 🛠️ 해결 방안 / 제안 기능

- 이미 적용 중인 플레이그라운드 구역 이탈 감지 시스템을 감옥 영역에도 동일하게 응용한다.
- 도둑이 체포된 상태에서 감옥 영역에 한 번 들어왔다가 다시 벗어나는 순간을 감지하여 자동으로 탈옥을 처리한다.
- "탈옥 완료" 수동 버튼은 제거하고, 안내 문구를 자동 탈옥 안내로 교체한다.

## 🧩 자동 탈옥 발동 규칙

- 도둑이 체포되어 수감 상태일 때만 감지가 동작한다.
- 이번 체포 사이클 동안 감옥 영역에 한 번이라도 들어온 적이 있어야 자동 탈옥이 발동된다.
  - 한 게임에서 잡히고 탈옥하고 다시 잡히는 사이클이 반복되면, 매 체포마다 새로 시작한다.
  - 게임 시작 시점에 우연히 감옥 영역 안에 위치하더라도, 그 이력은 영향을 주지 않는다.
- 감옥 안에서 밖으로 벗어나는 그 순간에만 발동하며, 감옥 밖에서 안으로 들어오는 동작은 무시한다.

## 🚫 자동 탈옥 스킵 조건

- 게임 종료 다이얼로그가 표시된 이후
- 연결이 끊겨 재연결 모달이 떠 있는 동안
- 이미 탈옥 처리가 완료된 상태
- 탈옥 API 호출이 진행 중인 상태 (중복 호출 방지)
- 게임 영역 정보가 아직 로드되지 않은 상태

## ⚙️ 작업 내용

- 감옥 영역 이탈 감지 로직 추가 (기존 플레이그라운드 이탈 감지 패턴 재사용)
- 이번 체포 사이클 기준 "감옥 첫 진입 여부" 추적 상태 추가
- 체포 이벤트 수신 시 위 추적 상태 초기화
- 자동 탈옥 발동 가드 정책 분리 (재연결 모달, 게임 종료, 이미 탈옥, API 진행 중 등)
- 체포 잠금 오버레이에서 "탈옥 완료" 수동 버튼 및 확인 모달 제거
- 안내 문구를 "감옥 밖으로 나가면 자동으로 탈옥됩니다" 류로 교체
