# 🚀 [기능개선][Flutter][마이페이지] 닉네임 수정 화면에 뒤로가기 앱바 추가

## 🗒️ 설명

닉네임 수정 화면에 뒤로가기가 없다.

- 닉네임 화면(`nickname_setup_page.dart`)은 Scaffold에 앱바가 아예 없는 구조다.
- 첫 로그인 온보딩(뒤로 갈 곳이 없음)과 마이페이지의 닉네임 수정이 **같은 화면을 공유**해서, 수정으로 들어와도 앱바가 없다.
- 수정 진입 시 되돌아갈 방법이 iOS 엣지 스와이프 / Android 시스템 백뿐이라, 화면 안에서 나가는 길이 보이지 않는다.

## 🔄 재현 방법

1. 마이페이지 → 닉네임 변경 진입
2. 상단에 뒤로가기 버튼이 없어 화면 안에서 되돌아갈 수 없다

## ✅ 예상 동작

- 닉네임 수정 진입 시 상단에 뒤로가기가 있는 앱바가 보이고, 누르면 마이페이지로 복귀한다
- 첫 로그인 닉네임 설정에서는 앱바가 보이지 않아야 한다 (기존 동작 유지)

## 🛠️ 작업 내용

- `context.canPop()`이 true일 때(설정에서 push 진입)만 공용 `AppTopBar`를 붙여 뒤로가기 제공
- 첫 로그인(redirect 진입, canPop false)에서는 지금처럼 앱바 없이 유지
- 앱바가 있을 때 상단 여백을 조정해 "상단 바에서 제목까지 28" 시안 관례에 맞춤
