⚙️ [기능추가][API연동][커뮤니티] 모집글 댓글·신고·프로필 아이콘 서버 연동

## 본문

## 📝 현재 문제점

- 게시글 상세의 댓글이 앱 메모리에만 저장된다. 앱을 껐다 켜면 사라지고 다른 사람에게는 보이지 않는다
- 게시글 신고 메뉴가 준비 중 안내만 띄운다. 백엔드는 신고 접수를 이미 열어둔 상태다
- 프로필 아이콘이 기기에만 저장된다. 기기를 바꾸면 초기화되고, 내가 쓴 글과 댓글에는 다른 사람에게 늘 기본 아이콘으로 보인다
- 사용자가 신고할 수단이 없는 상태로 스토어 심사에 들어가면 반복 지적 대상이 된다

## 🛠️ 해결 방안 / 제안 기능

- 댓글 작성·조회·삭제를 서버 연동으로 전환
- 게시글 신고를 인게임 신고와 같은 흐름으로 연결
- 프로필 아이콘 선택을 서버에 저장하고, 글과 댓글의 작성자 아이콘을 서버 값으로 표시

## ⚙️ 작업 내용

댓글

- 댓글 목록 조회·작성·삭제 서버 연동, 목록은 이어 보기 방식
- 답글은 한 단계까지만 달 수 있다. 답글에는 답글을 달 수 없다
- 답글이 남은 댓글을 지우면 자리는 남기고 삭제된 댓글입니다로 표시한다
- 탈퇴한 작성자의 댓글은 알수없음으로 표시한다
- 예시 데이터로 채워둔 댓글 저장소를 제거한다

신고

- 게시글 상세와 목록 카드의 신고 메뉴를 실제 신고 접수로 연결한다
- 인게임 신고 시트에서 유형 선택과 기타 사유 입력만 공용으로 뽑아 커뮤니티에서 재사용한다. 말풍선을 길게 눌러 여는 오버레이는 인게임 전용이라 그대로 둔다
- 신고 유형은 인게임과 같은 목록을 그대로 쓰고, 기타를 고르면 사유 입력을 받는다
- 신고 완료·중복 신고 안내를 붙인다

프로필 아이콘

- 아이콘을 고르면 서버에 저장하고, 내 정보 조회 결과를 기준값으로 삼는다
- 게시글과 댓글의 작성자 아이콘을 서버가 준 값으로 표시한다
- 탈퇴한 작성자는 기본 아이콘으로 표시한다

공통

- 처리된 자리의 준비 중 안내 문구를 제거한다
- 화면 문구와 실패 안내를 다국어 처리한다 (ko/en/ja)

## 📌 참고

- 댓글 신고는 접수 경로가 아직 없다. 댓글 신고 메뉴는 준비 중 안내를 그대로 둔다
- 채팅 메시지 신고는 모집글 채팅 이슈로 넘겼다. 신고 접수에 서버가 발급한 메시지 번호가 필요한데 지금 채팅은 예시 데이터라 번호가 앱이 만든 가짜다. 채팅 화면에 신고 진입점 자체도 아직 없어, 채팅을 서버에 붙이는 작업과 한 번에 하는 편이 낫다
- 프로필 아이콘을 이 이슈에 함께 넣는 이유는 댓글 목록이 작성자 아이콘을 그려야 하기 때문이다. 따로 하면 댓글을 기본 아이콘으로 그려두고 다시 고치게 된다
- 좋아요·스크랩은 서버 응답 보강이 필요해 별도 이슈로 분리했다. 같은 화면을 건드리므로 이 이슈를 먼저 끝낸다
