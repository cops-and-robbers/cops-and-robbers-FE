## 제목

⚙️ [기능추가][게임][결과화면] 게임 종료 후 동선/이동거리 결과 페이지 (런닝 앱 스타일)

## 본문

## 📝 현재 문제점

- 게임이 끝난 뒤 사용자가 게임 중 얼마나 움직였는지(총 이동 거리, 동선)를 확인할 방법이 없음
- 현재 게임 결과 API(`GameResultResponseModel`)는 `winnerTeam / durationSeconds / totalArrestCount / remainingRobberCount`만 제공 — 거리/경로 데이터 없음
- 도둑은 이미 5초 throttle로 서버에 위치를 전송 중이지만 누적 데이터로 활용되지 않음
- 경찰은 헤딩 스트림(`distanceFilter:0`)에서 위치를 받아 구역 이탈 감지에만 쓰고, 어디에도 누적되지 않음
- 결과 화면이 다이얼로그(`GameOverResultDialog`)로 작아서 동선·통계 같은 풍부한 데이터를 보여줄 공간이 부족함

## 🛠️ 해결 방안 / 제안 기능

게임 종료 직후 풀스크린 결과 페이지(`GameResultPage`)에서 본인 동선과 통계를 한 번에 보여준다. 기존 다이얼로그(`GameOverResultDialog`)는 폐기하고 페이지로 대체한다.

### v1 범위 (이번 작업)

- 본인의 동선만 표시 (다른 참가자 동선 X)
- 정적 한 장 화면 + **동선 재생 애니메이션 토글**
- **결과 이미지 공유/캡처** 지원
- 백엔드 변경 없음 — 전부 클라이언트에서 처리하고 메모리에서만 유지
- 결과 페이지 닫으면 데이터 사라짐 (다시보기/히스토리 없음)

### 표시 항목

- 상단 헤더: 승/패 배지, 게임 진행 시간
- 지도 영역(화면 50% 안팎): 본인 동선 polyline (단순화된 최대 300포인트), 시작/끝 마커, 카메라는 polyline 전체가 보이게 자동 fit
- 통계 카드: 총 이동 거리(km/m), 평균 속도, 최고 속도
- 액션 버튼: 동선 재생 / 이미지 공유 / 다시 시작 / 홈으로
- 뒤로가기는 차단(게임 페이지로 못 돌아감) — "홈으로"만 사용

### 카운트 정책 (단일)

`GAME_START` 이벤트 수신부터 `GAME_OVER` 이벤트 수신까지의 모든 본인 위치를 누적한다. **도둑/경찰 구분 없음**, 체포·감옥·대기시간에 따른 별도 처리 없음. GPS 노이즈는 아래 필터로 제거되므로 갇혀 있을 때의 1~2m 흔들림이나 정적 노이즈는 자연스럽게 흡수된다.

> 정책을 단순 boolean 한 개로 둔 이유: 이벤트별 ON/OFF 토글은 시계 동기화·이벤트 누락 복구 등 엣지 케이스가 많고, v1은 본인만 보는 화면이라 공정성 이슈가 없으며, P3에서 백엔드로 옮길 때도 "게임 진행 상태"만 알면 됨.

### GPS 노이즈 처리 정책

단순 누적은 가만히 서있어도 거리가 부풀려지는 문제가 있어 기본 필터링을 적용:

- `position.accuracy > 30m` 인 점은 버림 (정확도 너무 낮음)
- 직전 점과의 거리가 3m 미만이면 노이즈로 간주, 카운트 안 함
- 직전 점과의 시간 간격 1초 미만이면 스킵

### Polyline 단순화

- 누적 포인트가 300개를 초과하면 **균등 다운샘플링**(stride로 N개 추출)으로 표시용 포인트만 300개로 축약
- 거리·속도 계산은 단순화 전 원본 포인트로 수행해 정확도 유지

### 빈 상태 처리

누적 포인트가 2개 미만이면 지도 영역을 숨기고 **"이동 기록 없음 — GPS 신호가 충분하지 않아 동선을 그릴 수 없어요"** 플레이스홀더 카드로 대체. 게임 결과 수치(승패·시간 등)는 정상 표시.

### 향후 확장 (이번 작업 범위 X)

- P2: 로컬 DB(sqflite/drift) 저장 → 본인 과거 게임 기록 다시 보기
- P3: 백엔드 API 연동 → 다른 참가자 동선·MVP 동선 공유, 기기 변경에도 유지
- 데이터 모델은 처음부터 P3 호환되게 설계해서, 나중에 확장할 때 업로드/조회 코드만 추가하면 되도록 함

## ⚙️ 작업 내용

### 도메인 (순수 Dart, Riverpod 의존성 없음)

- `lib/features/game/domain/movement_tracker.dart` 신규
  - 입력: `Position` (geolocator)
  - 처리: GPS 노이즈 필터(accuracy>30m / 거리<3m / 간격<1s) 적용
  - 보유 상태: `List<TrackPoint>`, 거리·속도 통계 캐시
  - getter: `totalDistanceMeters`, `averageSpeedMps`, `maxSpeedMps`, `points`, `pointCount`
  - 메서드: `start()` / `stop()` / `addPoint(Position)`
- `TrackPoint` 모델 — `{latitude, longitude, timestamp, accuracy?}` (Freezed)
- `MovementSnapshot` — 결과 페이지에 전달하는 immutable 스냅샷 (Freezed)
- `lib/features/game/domain/polyline_simplifier.dart` 신규
  - `simplify(List<LatLng> points, {int maxPoints = 300})` 균등 다운샘플링
  - 단위 테스트 동봉

### Provider (Riverpod)

- `lib/features/game/presentation/providers/movement_tracker_provider.dart` 신규
  - `MovementTrackerNotifier` — `gameId` family 사용
  - `keepAlive` 미사용 (game_page → result page dispose까지만 살아있으면 됨)
  - 액션: `addPoint(Position)` / `start()` / `stop()`
  - state: `MovementSnapshot`

### `game_page.dart` 통합

- 기존 `_headingSubscription`(`distanceFilter:0`) 콜백 안에 `_checkZoneExit(pos)` 다음 줄로 누적 호출 추가
  - 새 위치 스트림 추가 X (스트림 fan-out으로 콜백 한 곳에서 처리)
- `GAME_START` 이벤트 핸들러에서 `MovementTrackerNotifier.start()` 호출
- `GAME_OVER` 이벤트 핸들러에서 `stop()` 호출 후 결과 페이지로 전환
- `GameOverResultDialog.show(...)` 호출 제거 → `context.go('/game/$_gameId/result', extra: ...)` 로 교체
- `_locationSubscription`(서버 발행용 10m+5s throttle)은 그대로 유지

### 결과 페이지

- `lib/features/game/presentation/pages/game_result_page.dart` 신규
- go_router에 `/game/:gameId/result` 라우트 추가
- 기존 `GameOverResultDialog` 삭제
- 위젯 구성:
  - `MapResultView` — GoogleMap + 단순화된 polyline + 시작/끝 마커, `LatLngBounds`로 카메라 fit, 빈 상태 플레이스홀더
  - `StatsCardRow` — 거리/평균/최고 카드
  - `PlaybackButton` — `AnimationController`로 polyline 진행률 0→1 (5초 고정), `AnimatedBuilder` + `Polyline.copyWith`로 매 프레임 갱신
  - `ShareButton` — 이미지 공유 트리거
  - `BottomActionBar` — "다시 시작" / "홈으로"
- `PopScope(canPop: false)`로 뒤로가기 차단

### 이미지 공유 구현

구글맵은 네이티브 텍스처라 일반 `RepaintBoundary` 캡처가 안 됨. 두 단계로 합성:

1. `GoogleMapController.takeSnapshot()` → 지도 영역 PNG `Uint8List`
2. 통계 카드 부분만 별도 `RepaintBoundary` 키로 캡처 → PNG `Uint8List`
3. `dart:ui` Canvas에 두 이미지를 위아래로 그려 최종 PNG 생성
4. `path_provider` 임시 디렉터리에 저장 후 `share_plus`로 외부 공유

### 패키지

- `path_provider` 추가 필요 (현재 pubspec에 없음)
- `share_plus` 이미 사용 중 (`^12.0.1`)
- `geolocator`, `google_maps_flutter` 이미 사용 중

### 테스트

- `MovementTracker` 단위 테스트
  - 노이즈 필터(거리<3m, accuracy>30m, 간격<1s)별 케이스
  - 거리·평균·최고 속도 계산 검증
  - `start()`/`stop()` 라이프사이클
- `PolylineSimplifier.simplify` 단위 테스트
  - 포인트 수 ≤ N → 그대로 반환
  - 포인트 수 > N → stride 기반 N개 균등 추출
  - 시작·끝점 보존
