# ❗ [버그][인게임] 게임 종료 이후 위치 공개 카운트다운 표시

## 🗒️ 설명

게임 잔여 시간이 2분이고 다음 도둑 위치 공개까지 3분이면 게임 안에서 추가 공개가 없는데도 공개 카운트다운이 계속 표시된다.

`LocationRevealCountdown`은 다음 공개 시각과 공개 주기만 받아 과거 시각을 다음 주기로 순환한다. 게임 종료 시각을 전달받지 않으므로 종료 이후 공개 예정도 표시한다. 현재 게임 타이머와 공개 타이머 모두 시각 차이 기반 계산 및 앱 resumed 시 재계산을 사용한다.

<br>

## 🔄 재현 방법

1. 위치 공개 주기가 설정된 게임에 진입한다.
2. 마지막 공개 이후 게임 잔여 시간이 다음 공개까지의 시간보다 짧아질 때 확인한다.
3. 종료 전에는 도달할 수 없는 다음 공개 카운트다운이 앱바에 계속 표시된다.

<br>

## ✅ 예상 동작

게임 타이머와 같은 시작 시각·라운드 시간으로 종료 시각을 계산하고, 다음 공개 시각이 종료 시각 이상이면 같은 위치·글꼴·색상으로 “추가 도둑 위치 공개는 없어요”를 안내한다. 종료 전 공개는 기존대로 표시한다. 앱 복귀·공개 주기 순환·종료 시각 보정 시에도 같은 기준을 적용한다. 종료 시각 정보가 없을 때는 기존 표시를 유지한다.

<br>
