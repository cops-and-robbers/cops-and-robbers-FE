# 🚀 [기능개선][Android] 배터리 제한없음 설정 없이 백그라운드 게임 유지

## 📝 현재 문제점

- Android에서 게임 중 홈으로 나가거나 화면을 끄면 웹소켓 연결이 끊겨 게임 진행이 중단됨
- 배터리 설정을 "제한없음"으로 직접 변경해야만 백그라운드 유지가 가능함
- 이 때문에 방만들기/참여하기 진입 시 배터리 설정 안내 다이얼로그로 사용자를 차단하고 있어 진입 장벽이 큼
- 네이버지도, 음악앱처럼 별도 설정 없이 백그라운드에서 동작해야 함 (iOS는 이미 정상 동작)

## 🛠️ 해결 방안 / 제안 기능

- 배터리 "제한없음" 설정 없이도 게임 세션 동안 위치 추적과 실시간 연결이 유지되도록 개선
- 배터리 설정 안내(차단) 다이얼로그 완전 제거

## ⚙️ 작업 내용

- 게임 세션 포그라운드 서비스가 절전 상태에서도 동작을 유지하도록 개선
- 게임 진입 게이트에서 배터리 최적화 체크 제거
- 사용하지 않게 된 배터리 관련 코드와 안내 문구 정리
- 삼성 실기기에서 배터리 "최적화" 상태로 백그라운드 유지 검증
