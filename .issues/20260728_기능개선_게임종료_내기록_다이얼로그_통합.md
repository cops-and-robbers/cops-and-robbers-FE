# 🚀 [기능개선][Flutter][게임종료] 게임 종료 다이얼로그와 내 기록 다이얼로그 통합

## 📝 현재 문제점

- 게임이 끝나면 결과 다이얼로그가 먼저 뜨고, 내 이동 기록은 하단의 내 기록 보기 버튼을 눌러야만 별도 다이얼로그로 열린다. 2단 구조라 대부분의 사용자가 자기 기록을 보지 못한 채 홈으로 나간다
- 두 다이얼로그가 승패, 플레이 시간 같은 정보를 각자 다시 보여주고 있어 화면이 중복된다
- 내 기록 다이얼로그의 이동 경로는 실제 지도 없이 궤적 선만 그려서, 어디를 돌아다녔는지 알아보기 어렵다
- 공유하기가 두 번째 다이얼로그 안에 숨어 있어 도달률이 낮다

## 🛠️ 해결 방안 / 제안 기능

- 내 기록 다이얼로그를 없애고 그 내용을 게임 종료 다이얼로그 하나로 합친다. 게임이 끝나면 승패, 종료 일시, 이동 거리, 이동 경로, 게임 통계가 한 화면에 바로 보인다
- 이동 경로를 실제 지도 위에 표시한다. 지도는 모바일 지도 SDK를 그대로 쓰므로 추가 API 비용이 발생하지 않는다
- 공유하기를 다이얼로그 우측 상단 아이콘으로 올려 한 번에 닿게 한다. 공유 이미지에는 버튼이 찍히지 않는다
- 합치면서 겹치거나 시안에 없는 요소는 정리한다. 승패 배지, 개인 통계 두 칸, 경로 범례, 앱 로고 워터마크가 대상이다
- 버튼, 라운드, 문구 등 기존 결과 다이얼로그의 시각 요소는 그대로 유지한다

## ⚙️ 작업 내용

- 이동 거리 표기를 숫자와 단위로 분리 (시안에서 두 폰트 크기가 다름)
- 결과 카드 전용 읽기 전용 경로 지도 위젯 신규 작성 (경로 폴리라인, 강조 지점, 카메라 자동 맞춤, 다크 모드 지도 스타일)
- 게임 종료 다이얼로그 카드 본문 재구성 (타이틀과 공유 아이콘 한 줄, 종료 일시, 이동 거리, 경로 지도)
- 통계 세 행 정렬과 글자 스타일을 시안에 맞게 조정
- 공유 캡처 기능 이식 및 캡처 시 버튼과 공유 아이콘 숨김 처리
- 내 기록 보기 버튼 제거
- 내 기록 다이얼로그 파일과 테스트 삭제, 개발용 위젯 화면의 관련 섹션 정리
- 사용하지 않게 된 다국어 문구 키 정리
