## 제목

🚀 [기능개선][Flutter][API] 백엔드 API v2.7.0 변경사항 Flutter 클라이언트 반영

## 본문

## 📝 현재 문제점

- 백엔드 API가 v2.7.0으로 업데이트되면서 Flutter 클라이언트와 불일치 발생
- 게임 푸시 알림 동의 조회/업데이트 엔드포인트가 클라이언트에 없음
- 소켓 재연결 시 게임 화면 복원에 사용하는 게임 상태 조회 엔드포인트가 클라이언트에 없음
- 도둑 위치 조회 엔드포인트가 v2.6.0부터 deprecated 처리되었으나 클라이언트에 반영 미흡

## 🛠️ 해결 방안 / 제안 기능

- 게임 푸시 알림 동의 조회 및 업데이트 API 연동
- 게임 상태 조회 API 연동 (소켓 재연결 시 화면 복원용)
- 기존 도둑 위치 조회 API를 게임 상태 조회 API로 교체
- API 명세 문서(API_SPEC.md) v2.7.0 기준으로 업데이트

## ⚙️ 작업 내용
