## 제목

⚙️ [기능추가][인게임][WebSocket] 게임 진행 중 중도 퇴장 기능 프론트엔드 연동

## 본문

## 📝 현재 문제점

- 게임이 시작되면 종료될 때까지 계속 진행되어, 중간에 나가거나 종료가 필요한 상황에서도 게임이 끝날 때까지 기다려야 하는 불편이 있었다.
- 백엔드에서 인게임 중도 퇴장 기능(`DELETE /api/games/{gameId}/leave`)과 관련 이벤트(`PLAYER_LEFT`, forfeit `GAME_OVER`)가 구현되었으나, 프론트엔드에는 아직 퇴장 동작 및 이벤트 수신 처리가 없다.

## 🛠️ 해결 방안 / 제안 기능

- 인게임 화면에 중도 퇴장 동작을 추가하여, 게임 진행 중에도 사용자가 자유롭게 퇴장할 수 있도록 한다.
- 퇴장 시 백엔드 퇴장 엔드포인트를 호출하고, 본인 퇴장 처리 후 게임 화면을 정상적으로 빠져나가도록 한다.
- 남은 참가자에게 전파되는 시스템 이벤트(`PLAYER_LEFT`, forfeit `GAME_OVER`)를 수신하여 화면과 알림에 반영한다.
- 퇴장으로 인한 강제 종료(몰수승/몰수패) 상황에서도 기존 게임 종료 결과 화면 흐름과 동일하게 동작하도록 연동한다.

## ⚙️ 작업 내용

- 인게임 퇴장 API(`DELETE /api/games/{gameId}/leave`) 연동
- 인게임 화면에 퇴장 진입점(버튼/메뉴) 및 퇴장 확인 흐름 추가
- 시스템 채널(`/subscribe/game/{gameId}/system`) `PLAYER_LEFT` 이벤트 수신 및 처리 (퇴장자 정보 반영, 알림 표시)
- forfeit `GAME_OVER` 이벤트(`POLICE_FORFEITED`, `ROBBER_FORFEITED`) 수신 및 게임 종료 결과 화면 연동
- 방장 퇴장 시 로비 채널(`/subscribe/game/{gameId}/lobby`) `HOST_CHANGED` 이벤트 처리 확인
- 퇴장/종료 FCM 푸시 알림 동작 확인
