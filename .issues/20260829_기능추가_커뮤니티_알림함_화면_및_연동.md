⚙️ [기능추가][Flutter][커뮤니티] 커뮤니티 알림함 화면 신설 및 알림 목록·미읽음 배지 연동

🔥 구현 기능
---

커뮤니티 상단 종 아이콘을 눌러 들어가는 **알림함 화면을 새로 만들고** 서버와 연결합니다.

| 표면 | 내용 |
|---|---|
| 종 아이콘 | 안 읽은 알림이 있으면 `icon_noti_on.svg`, 없으면 `icon_noti_off.svg` |
| 알림함 화면 | 내 글에 달린 댓글(`COMMENT`)·답글(`REPLY`) 목록, 최신순, 커서 페이징 |
| 알림 항목 | 게시글 제목 · 댓글 내용 · 발생 시각 · 읽음 여부. 누르면 해당 게시글로 이동 |
| 읽음 처리 | 화면에서 나갈 때 한 번, 커서를 현재 시각으로 이동 |

📝 현재 문제점
---

> [!WARNING]
> 종 아이콘이 아무 동작도 하지 않는 자리표로 박혀 있습니다.

```dart
// lib/features/community/presentation/pages/community_page.dart
// 알림은 기능 자체가 없다. 후속 연결 전까지 탭 여부만 로그로 확인한다.
_buildAppBarIcon('assets/icons/icon_noti_off.svg');
```

서버가 없어서 미뤄둔 자리인데, 백엔드 #182(Swagger v2.26.0)로 **API 3종이 열렸습니다.**
`icon_noti_on.svg`도 이미 에셋에 있어 켜짐/꺼짐 상태를 그릴 준비는 돼 있습니다.

🛠️ 해결 방안 / 제안 기능
---

| 엔드포인트 | 쓰임 |
|---|---|
| `GET /api/community-posts/notifications` | 알림 목록 (`cursor`·`size` 커서 페이징) |
| `GET /api/community-posts/notifications/unread-count` | 종 아이콘 배지 개수 |
| `POST /api/community-posts/notifications/read` | 읽음 커서를 현재 시각으로 이동 |

응답 `CommunityNotificationResponse` 필드: `id` · `type`(`COMMENT`\|`REPLY`) · `communityPostId` · `postTitle` · `content` · `read` · `createdAt`

> [!IMPORTANT]
> **목록을 여는 것만으로는 읽음 처리가 되지 않습니다.** `GET`은 무부작용이라 `POST .../read`를 앱이 따로 불러야 배지가 내려갑니다. 안 부르면 다시 들어와도 숫자가 그대로입니다.

> [!IMPORTANT]
> `read`는 알림마다 저장된 값이 아니라 **유저당 커서 하나로 판정한 결과**입니다. 개별 알림만 읽음 처리할 수는 없습니다.

> [!TIP]
> 목록·배지 모두 **최근 60일**만 내려옵니다. 그 이전 알림이 안 보이는 것은 버그가 아닙니다.

⚙️ 작업 내용
---

- `features/community`에 알림함 데이터·도메인·프레젠테이션 계층 추가 (`notice` 피처 구조를 따름)
- 알림함 화면 UI 제작 — 목록·빈 상태·로딩·에러·당겨서 새로고침·무한 스크롤
- 종 아이콘 상태 전환(`icon_noti_off` ↔ `icon_noti_on`)과 배지 개수 연동
- 알림 → 게시글 상세 이동 라우팅
- 읽음 처리 호출 시점 결정 및 배지 갱신

❓ 확인 필요
---

- **알림함 화면 시안이 있는지** — 커뮤니티 페이지 우측 상단 종에서 진입하는 화면입니다. 없으면 기존 목록 화면(공지사항) 스타일을 따라 만들겠습니다.
- **읽음 처리 시점** — 화면 진입 시 / 이탈 시 중 어느 쪽이 좋을지. 진입 시 처리하면 스크롤하지 않은 알림도 읽음이 됩니다.
