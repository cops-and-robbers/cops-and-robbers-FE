## 제목

⚙️ [기능추가][Flutter][앱아이콘] Remote Config 기반 동적 앱 아이콘 변경

## 본문

## 📝 현재 문제점

- 현재 앱 아이콘은 빌드 시점에 고정되어 있어, 변경하려면 앱 재배포가 필요함
- 이벤트/시즌/프로모션 등 시기적 요인에 따라 아이콘을 빠르게 교체할 수 있는 수단이 없음
- 사용자에게 앱 업데이트를 강제하지 않고도 시각적 변화를 줄 수 있는 채널 부재

## 🛠️ 해결 방안 / 제안 기능

- Firebase Remote Config에서 “현재 사용할 앱 아이콘 식별자” 값을 내려받음
- `flutter_dynamic_icon: 2.1.0` 패키지를 통해 미리 등록해둔 아이콘 세트 중 해당 식별자에 매핑된 아이콘으로 런타임 전환
- 앱 부팅 시 / 포그라운드 복귀 시 Remote Config 값을 확인하여 현재 적용된 아이콘과 다르면 자동 교체
- 운영자가 Remote Config 값만 변경하면 앱 재배포 없이 전 사용자에게 아이콘 변경 적용 가능

## ⚙️ 작업 내용

- iOS `Info.plist`에 alternate icon 세트 등록 (기본 아이콘 + 추가 아이콘들)
- Android에 alternate launcher activity 및 아이콘 리소스 등록
- Remote Config 키 정의 및 기본값/조건부 값 셋업 (예: `app_icon_variant`)
- Remote Config 값과 등록된 아이콘 식별자 매핑 테이블 정의
- 앱 진입 시점/포그라운드 복귀 시점에 Remote Config fetch → 아이콘 교체 로직 호출
- iOS에서 아이콘 변경 시 노출되는 시스템 알럿 처리 정책 결정 (표시 허용/억제)
- 변경 실패/미지원 단말에 대한 폴백 정책 정의
- 운영자용 Remote Config 값 가이드 문서화 (지원되는 아이콘 식별자 목록, 기본값, 적용 시점)
