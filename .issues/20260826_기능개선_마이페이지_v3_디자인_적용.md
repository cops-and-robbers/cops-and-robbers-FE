# 🚀 [기능개선][마이페이지] v3 디자인 적용 및 하위 화면 라우팅 정리

## 📝 현재 문제점

- 마이페이지가 v3 시안 이전 상태다. 계정과 앱 설정 항목에 아이콘이 없고, 항목 순서와 행 높이가 시안과 다르다
- 오픈소스 라이선스 항목이 없다. 커뮤니티 모집글에 표시되는 주소는 OpenStreetMap 기반 데이터를 변환한 결과라 출처 표기가 필요한데 앱에 그 자리가 없다
- 마이페이지 하위 화면(언어 설정, 버그 제보, 크레딧)은 Navigator.push 로 띄워서 탭 스택에 남는다. 홈 탭에 갔다가 마이페이지로 돌아오면 그 화면이 그대로 떠 있다
- 같은 이유로 전환 애니메이션도 다르다. 앱의 다른 화면은 라우터의 공용 전환을 쓰는데 마이페이지 하위 화면만 플랫폼 기본 전환이다

## 🛠️ 해결 방안 / 제안 기능

- 시안대로 아이콘, 항목 순서, 행 치수를 맞춘다
- 오픈소스 라이선스 항목을 만든다. 본문은 웹이 이미 제공하고 있어 앱은 문서 종류만 하나 늘리면 된다
- 하위 화면을 GoRoute 로 올리고 루트 네비게이터에 붙인다. 탭 스택에 남지 않고 전환도 다른 화면과 같아진다

## ⚙️ 작업 내용

아이콘

- assets/icons 에 5개 추가 (알림, 게임 알림, 언어, 위치 권한, 닉네임 변경)
- 메뉴 아이템에 아이콘 인자를 옵셔널로 추가한다. 아이콘 24x24, 좌측 여백 24, 텍스트와의 간격 18
- 받은 아이콘이 다색이라 색 필터를 적용하지 않는다

치수

- 행 높이는 텍스트만 48, 아이콘과 주 텍스트 56, 아이콘과 주 보조 텍스트 68
- 세 경우 모두 상하 여백 16, 좌우 여백 24로 같다
- 주 텍스트 16px 블랙, 보조 텍스트 12px 블랙600
- 버전 표시 텍스트는 14px 세미볼드, 색을 블랙300에서 블랙600으로 올린다

항목

- 앱 설정 순서: 게임 알림, 알림, 언어, 위치 권한 관리
- 이용 안내 순서: 앱 버전, 튜토리얼 다시 보기, 튜토리얼 초기화, 버그 제보, 오픈소스 라이선스, 이용약관 및 정책
- 화살표는 닉네임 변경에만 둔다
- 게임 알림은 토글을 유지한다
- 프로필 아이콘 선택기는 그대로 둔다
- 공식 SNS 채널 줄은 시안에 없지만 지금처럼 하단에 유지한다

라우팅

- 언어 설정, 이용약관 및 정책, 버그 제보, 오픈소스 라이선스, 크레딧을 GoRoute 로 올린다
- 전부 루트 네비게이터를 부모로 지정해 바텀 네비게이션을 덮게 한다
- 버그 제보는 범용 입력 화면에 인자를 넘겨 쓰고 있어, 라우트가 화면을 온전히 갖도록 전용 래퍼를 만든다

## 📌 참고

- 오픈소스 라이선스 본문은 웹에 이미 배포되어 있다. 앱은 법적 문서 종류에 값을 하나 추가하면 기존 화면이 그대로 연다
- 화살표는 전용 에셋으로 교체한다. 예전에는 이전 화살표를 180도 돌려 쓰고 있었다
- go_router 경로는 앱 내부 식별자다. 딥링크는 초대 링크 경로만 통과시키는 화이트리스트이고 Flutter 자동 딥링크가 꺼져 있어, 새 경로가 외부 진입점이 되지는 않는다
- 아이콘과 보조 텍스트는 서로 독립이다. 닉네임 변경은 아이콘이 있고 보조 텍스트가 없다. 그래서 메뉴 아이템 위젯을 나누지 않고 인자를 하나 더 받는다
