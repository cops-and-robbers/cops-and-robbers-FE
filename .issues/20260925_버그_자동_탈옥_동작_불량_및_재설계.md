## ✅ 예상 동작

확정된 탈옥 조건을 만족하면 자동 탈옥 요청과 서버 수감 상태, 화면 표시가 일관되게 반영되어야 한다. 새 판정 기준과 예외 처리 방식은 재설계 과정에서 정한다.

<br>

## 🚧 작업목록

- [ ] 실패 상황의 기기·앱 버전·게임 모드·GPS 및 상태 전이 로그를 확보해 재현한다.
- [ ] 위치 수신 → 감옥 진입·이탈 판정 → 탈옥 요청 → 서버·화면 상태 반영 흐름을 점검한다.
- [ ] 자동 탈옥 조건, 재체포·재연결·요청 실패 처리와 수동 탈옥의 관계를 재설계한다.
- [ ] 확정된 설계를 구현하고 재현 테스트 및 실제 기기에서 검증한다.

## ❓ 확인 필요

실패 시의 재현 순서·기기·앱 버전·게임 모드는 미확인이다. 기존 GPS 기준이 원인인지, 상태 동기화나 요청 처리 문제인지는 조사 후 판단한다. 새 판정 기준과 서버 변경 필요 여부도 아직 정하지 않았다.
