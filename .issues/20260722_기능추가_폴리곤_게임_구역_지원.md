## 본문

## 📝 현재 문제점

- 백엔드 v2.13.0에서 게임 구역에 폴리곤 타입이 추가됨 (areaType: CIRCLE | POLYGON, 플레이그라운드·감옥 둘 다 폴리곤 가능)
- GET /api/games/{gameId}/area 응답이 기존 플랫 구조에서 areaType + circle/polygon 중첩 구조로 변경되어, 현재 앱은 신규 응답을 파싱하지 못함 (breaking change)
- 앱의 구역 이탈 감지가 중심점-반경 거리 비교 방식이라 폴리곤 구역에서는 판정 불가
- 인게임 지도 구역 표시(경계선, 외부 딤 오버레이)와 로비 구역 미리보기가 원형 전제로만 구현되어 있음
- 참고: 저장된 docs/api-docs.json이 100KB 지점에서 잘려 있어 폴리곤 스키마 상세 확인 불가 → 전체 스펙 재확보 필요

## 🛠️ 해결 방안 / 제안 기능

- 신규 구역 응답 구조(areaType + circle/polygon)를 파싱하고, 원형/폴리곤을 공통으로 다루는 구역 도메인 모델로 대응
- 구역 이탈 감지와 감옥 판정을 원형(거리 비교)/폴리곤(내부 포함 판정)으로 분기 처리
- 인게임 지도와 로비 미리보기에 폴리곤 경계선·외부 딤 오버레이 렌더링 추가
- 방장 구역 설정 UI는 기존 원형 방식 유지 (폴리곤은 서버/이벤트 게임에서 내려주는 구역을 수신·표시·판정만)
- 구역 이탈 시 경고 동작(진동·배너·비네트)은 기존 정책 유지, 판정 경계만 폴리곤 대응
