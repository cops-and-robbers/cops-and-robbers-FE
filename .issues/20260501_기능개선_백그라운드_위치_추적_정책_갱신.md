## 본문

## 📝 현재 문제점

- v1.8.5에서 게임 진행 중 백그라운드 위치 추적 기능이 도입됨 (#305)
- 화면이 꺼져 있거나 앱이 백그라운드 상태일 때도 사용자 위치를 수집하여 게임 참가자에게 실시간 공유함
- 그러나 현재 개인정보처리방침과 위치정보 이용약관에는 백그라운드 위치 수집에 대한 내용이 명시되어 있지 않음
- 약관에 명시되지 않은 데이터 수집은 개인정보보호법 및 위치정보법 위반 소지가 있음
- App Store / Play Store 심사 시 백그라운드 위치 사용 정당성에 대한 메타데이터도 갱신 필요

## 🔧 기술 구현 참고 (정책 문구 작성 시 정확성 확보용)

약관 담당자 또는 법무팀이 정확한 표현을 쓸 수 있도록 현재 구현 방식을 명시.

Android
- Foreground Service (foregroundServiceType="location") 사용
- 게임 진행 중 영구 알림 표시 ("경찰과 도둑 게임이 진행 중입니다")
- ACCESS_FINE_LOCATION 권한 ("앱 사용 중에만" 수준 — 별도 "항상 허용" 권한 요청 안 함)
- 일부 단말은 사용자가 직접 "배터리 최적화 제외" 설정해야 안정적 동작

iOS
- UIBackgroundModes에 location 추가
- NSLocationWhenInUseUsageDescription 권한 문구에 백그라운드 사용 명시
- geolocator allowBackgroundLocationUpdates = true
- 화면 상단 파란 위치 인디케이터로 사용자가 백그라운드 위치 사용을 시각적으로 인지

공통
- 게임이 IN_PROGRESS 상태인 동안에만 활성
- 게임 종료(GAME_OVER) 즉시 자동 중단 및 자원 정리
- 위치 정보는 같은 게임 참가자에게 실시간 공유될 뿐, 서버에 영구 저장하지 않음 (현재 v1.8.5 기준)

## 📊 위치 정보 데이터 라이프사이클 (현재 + 향후 확장 가능성)

약관은 미래 확장 단계까지 한 번에 커버하도록 작성하여 향후 약관 재갱신 작업을 최소화한다.

현재 (v1.8.5)
- 게임 진행 중 실시간 위치 수집
- STOMP를 통해 같은 게임 참가자에게 즉시 전달
- 마지막 위치만 덮어씀 (누적 저장 X)
- 게임 종료 시 즉시 폐기
- 서버 영구 저장 없음

향후 P1 — 게임 동선 결과화면 (관련 이슈: 20260429_기능추가_게임_이동거리_동선_결과화면.md)
- 게임 진행 중 본인 동선·이동 거리·속도를 본 기기 메모리에 임시 누적
- 게임 종료 후 결과 화면에서 본인에게만 표시
- 결과 화면 종료 시 메모리에서 폐기 (영구 저장 X)
- 백엔드 변경 없음

향후 P2 — 본인 게임 기록 보관
- 본인 게임 기록을 본 기기 로컬 저장소(sqflite/drift 등)에 일정 기간 보관
- "내 과거 게임 다시보기" 기능 제공
- 사용자가 별도 동의 시에만 활성화

향후 P3 — 서버 동선 공유
- 백엔드 API 연동
- 다른 참가자 동선·MVP 동선 공유, 기기 변경에도 데이터 유지
- 사용자가 별도 동의 시에만 활성화

## 🛠️ 해결 방안 / 제안 기능

다음 정책 문서를 백그라운드 위치 추적 기능 도입 사실 + 미래 확장 가능성을 고려하여 갱신한다.

개인정보처리방침
- 수집 항목 (확장성 표현)
  - 게임 진행 중 도둑/경찰의 실시간 GPS 위치
  - (향후 단계에서) 게임 중 누적된 동선·이동 거리·속도 등 통계
- 수집 방법
  - Android: Foreground Service 통한 백그라운드 위치 콜백 수신
  - iOS: UIBackgroundModes location 통한 백그라운드 위치 콜백 수신
- 수집 목적 (확장성 표현)
  - 게임 진행 중 도둑 위치 공유 및 구역 이탈 감지
  - (향후 단계에서) 결과 화면의 동선/이동 거리 표시, 본인 게임 기록 보관, 다른 참가자와 동선 공유
- 보유·삭제 정책 (확장성 표현)
  - 실시간 전달 후 폐기: 보관하지 않음 (현재 v1.8.5 기본 동작)
  - (향후) 게임 진행 중 임시 누적: 결과 화면 종료 즉시 폐기
  - (향후) 본인 게임 기록 보관: 사용자 동의 받은 기간 또는 사용자가 삭제 요청할 때까지
  - (향후) 서버 보관: 사용자 동의 받은 기간 또는 회원 탈퇴 시
- 제3자 제공 범위 (Apple 가이드라인 5.1.1(i) 4번 항목)
  - 같은 게임 참가자: 게임 진행 중에만 공유, 게임 종료 시 공유 중단
  - 서비스 운영자 서버: 게임 진행 중계 및 결과 처리 목적
  - 위 모든 대상은 서비스 운영자가 적용하는 개인정보 보호 수준과 동등한 수준의 보호를 적용함을 명시
- 동의 철회·삭제 요청 방법 (Apple 가이드라인 5.1.1(i) 6번 항목)
  - 위치 정보 수집 동의 철회: 기기 설정 → 권한 → 위치 → 수집 거부
  - 게임 중 처리되는 임시 위치 정보: 게임 종료 시 자동 폐기되므로 별도 절차 없음
  - (향후) 본인 게임 기록 삭제: 앱 내 설정 → 게임 기록 → 삭제
  - (향후) 서버 보관 데이터 삭제: 회원 탈퇴 또는 고객센터 요청

위치정보 이용약관
- 백그라운드 위치 사용 목적 및 범위 추가
- 위치 정보 수집 시점 명확화 (게임 시작 ~ 종료 구간)
- 위치 정보 보관 정책 (현재 + 향후 확장 단계 모두 커버하는 표현)

이용약관
- 게임 이용 시 백그라운드 위치 사용에 동의한다는 조항 추가 검토
- 사용자가 백그라운드 위치 사용을 거부할 경우 게임 진행이 제한될 수 있음을 명시

App Store Connect 메타데이터
- App Privacy 섹션의 "Location" 사용 목적 갱신 (Foreground + Background)
- App Privacy Nutrition Label에 "데이터를 사용자 추적에 사용하지 않음" 명시 (App Tracking Transparency 비해당 사실)
- App Review Information의 Notes 필드에 백그라운드 위치 사용 정당성 설명 추가

Play Console 메타데이터
- 데이터 보안(Data safety) 섹션의 위치 데이터 수집 항목 갱신
- 백그라운드 위치 접근 권한 사용 사유 갱신

## ⚙️ 작업 내용

문서 갱신
- 개인정보처리방침 본문 수정 (위 6요소 모두 반영, 미래 확장 단계까지 커버)
- 위치정보 이용약관 본문 수정 (현재 + 향후 보관 정책 모두 커버)
- 이용약관 본문 수정 (필요 시)

앱 내 표시 문구 검토
- 게임 시작 시 안내 문구가 백그라운드 사용을 명확히 알리는지 재검토
- 위치 권한 요청 다이얼로그 문구가 변경된 정책과 일치하는지 확인
- 약관 페이지에 갱신된 본문이 반영되어 표시되는지 확인

스토어 메타데이터 갱신
- App Store Connect — App Privacy 섹션 갱신 (Location: Foreground + Background)
- App Store Connect — App Privacy Nutrition Label에 "Tracking 비사용" 명시
- App Store Connect — App Review Information의 Notes에 백그라운드 위치 사용 정당성 설명
- Play Console — Data safety 섹션 갱신

기존 사용자 대응 검토
- 약관 변경 사항을 기존 사용자에게 어떻게 고지할지 결정 (앱 내 공지, 재동의 요청 등)
- 신규 사용자에게는 갱신된 약관으로 동의 받음
