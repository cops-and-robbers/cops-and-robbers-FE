## 📝 현재 문제점

**아이콘 경로가 컴파일러의 사각지대에 있다.** 오타를 내도 빌드는 통과하고, 그 화면을 열어야 아이콘이 사라진 걸 알게 된다. 파일명 하나 바꾸면 57개 파일을 전수 검색해야 한다.

이미 아래 신호들이 쌓여 있다.

**1. 잘못된 파일명이 코드 곳곳에 그대로 박혀 있다**

| 에셋 | 문제 |
|---|---|
| `assets/icons/icon_wrong mark.svg` | 파일명에 **공백** |
| `assets/icons/icon_check mark.svg` | 파일명에 **공백** |
| `assets/icons/icon_settiing_2.svg` | 오타 (`setting` → `settiing`) |
| `Loudspeaker.svg` · `Top_hat.svg` · `youtube.svg` | `icon_` 접두어 규칙 이탈 · 대소문자 혼재 |

지금 고치려면 이름을 바꾼 뒤 코드 쪽 리터럴을 전부 찾아 맞춰야 한다. 한 곳에 모여 있으면 상수 이름은 그대로 두고 값만 바꾸면 끝난다.

**2. 같은 경로를 세 군데서 서로 다른 방법으로 만든다**

핑 마커 경로 `icon_ping_{type}_marker_{theme}.svg` 하나가 이렇게 흩어져 있다.

| 위치 | 만드는 방식 |
|---|---|
| `lib/features/game/presentation/widgets/ping_marker_factory.dart:52` | 보간 |
| `lib/test_widget_page.dart:635` | 보간 (변수명만 다름) |
| `lib/features/tutorial/presentation/pages/in_game_tutorial_page.dart:409` | **문자열 3줄 연결** |

<details><summary>세 번째 사례 — 경로가 세 조각으로 쪼개져 있어 grep으로 찾히지 않는다</summary>

```dart
// in_game_tutorial_page.dart:409
'assets/icons/icon_ping_'
'${_placedPingType == PingType.found ? 'found' : 'suspect'}'
'_marker_${_isDarkMode ? 'darkmode' : 'lightmode'}.svg',
```

`icon_ping_found_marker_darkmode.svg`로 검색하면 **세 곳 다 안 나온다.**
</details>

**3. 그래서 에셋 사용 여부를 정적으로 판정할 수 없다**

`assets/icons/` 파일 109개 중 21개가 단순 검색으로는 미참조로 나오지만, 그중 10개는 위 보간 경로로 실제 사용 중이다. 미사용 에셋 정리(#460 같은 작업)를 할 때마다 이 판정을 손으로 다시 해야 한다.

## 🛠️ 해결 방안

**다국어(l10n)에서 문구를 키로 뽑아 쓰듯, 아이콘 경로도 키로 뽑는다.**
`AppLocalizations.of(context).xxx`가 문구 리터럴을 없앤 것과 같은 방식이다.

```dart
// lib/core/constants/app_icons.dart (신설)
abstract final class AppIcons {
  static const String previous  = 'assets/icons/icon_previous.svg';
  static const String likeOn    = 'assets/icons/icon_like_on.svg';
  static const String likeOff   = 'assets/icons/icon_like_off.svg';
  static const String wrongMark = 'assets/icons/icon_wrong mark.svg';
  // ...
}
```

| | Before | After |
|---|---|---|
| 호출부 | `SvgPicture.asset('assets/icons/icon_previous.svg')` | `SvgPicture.asset(AppIcons.previous)` |
| 오타 | 빌드 통과 → 화면 열어야 발견 | **컴파일 에러** |
| 파일명 변경 | 57개 파일 전수 검색 | `app_icons.dart` 값 한 줄 |

**이 저장소에 이미 같은 선례가 있다** — 아이콘만 빠져 있을 뿐이다.

| 기존 파일 | 담당 에셋 |
|---|---|
| `lib/core/constants/character_assets.dart` | 캐릭터 (`characterAssetPath` · `resultCharacterAssetPath`) |
| `lib/core/i18n/locale_brand_assets.dart` | 로케일별 로고 · 스플래시 |

클래스 형태는 `MapStyles` · `VibrationPatterns`와 같은 `abstract final class`를 따른다.
보간으로 만들던 핑 마커 경로는 상수 대신 **경로 생성 함수**로 통일해 `character_assets.dart` 방식을 그대로 쓴다 — 위 세 곳이 이 함수 하나를 부르게 된다.

> [!IMPORTANT]
> 이번 범위는 **코드 쪽 참조**까지다. 깨진 에셋 **파일명 자체를 바꾸는 건 별도 작업**으로 둔다 — 상수화가 끝나면 그때는 `app_icons.dart` 한 줄만 고치면 되므로 훨씬 싸진다. (위 `wrongMark`가 그 예 — 상수 이름은 이미 정상이고 값만 깨져 있다.)
