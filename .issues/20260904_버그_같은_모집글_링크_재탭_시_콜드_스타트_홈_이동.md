# ❗ [버그][Flutter][딥링크] 같은 모집글 링크를 다시 누르면 콜드 스타트에서 홈으로 이동함

## 🗒️ 설명

앱이 켜져 있을 때 모집글 링크(`https://copsandrobbers.app/g/12`)를 누르면 상세로 잘 들어가는데, **앱을 종료한 뒤 같은 링크를 누르면** 앱은 실행되지만 상세 대신 홈에 도착한다. 초대 링크(`/join/{code}`)는 같은 인프라를 쓰는데도 이 증상이 없다.

**원인**

딥링크 서비스의 콜드 스타트 중복 방지(dedup)가 모집글 링크의 정상 재탭을 "OS의 launch intent 재전달"로 오판한다.

| 지점 | 동작 |
|---|---|
| `deeplink_service.dart:88` `markHandled` | 웜 처리한 URI를 `last_handled_deeplink_uri`에 기록 |
| `deeplink_service.dart:56` `coldStartDeeplink` | `getInitialLink()` 결과가 그 값과 같으면 null 반환 → 스플래시가 홈으로 이동 |

이 규칙은 초대 링크의 성질(코드가 방마다 새로 발급돼 같은 URI를 두 번 탭할 일이 없음, join API 부작용이 있어 recents 재실행의 재참가를 막아야 함)에 맞춰 설계됐다. 모집글 링크는 글 하나에 URI가 고정이라 같은 링크를 다시 여는 것이 정상 사용인데, 같은 규칙이 두 번째 탭부터 전부 버린다. 초대도 같은 URI를 다시 누르면 똑같이 스킵되지만, 이미 그 방에 참가한 상태라 스플래시의 활성 게임 복구가 대기방으로 보내 증상이 가려진다.

> [!WARNING]
> 웜에서 한 번 열어본 링크는 이후 콜드에서 매번 스킵된다. 재현이 100%다.

<br>

## 🔄 재현 방법

1. 앱 실행 상태에서 `https://copsandrobbers.app/g/12` 탭 → 상세 진입 (정상)
2. 앱 완전 종료
3. 같은 링크 탭 → 스플래시 후 홈 도착. 로그에 `[DeepLink] cold start 중복 스킵:` 출력
4. 아직 안 눌러본 글(`/g/13`)로 콜드 탭하면 첫 번째만 들어가고 두 번째부터 홈

<br>

## ✅ 예상 동작

같은 모집글 링크를 몇 번을 누르든 콜드 스타트에서 상세로 들어가야 한다.

**수정 방향**

- `coldStartDeeplink`에서 URI를 먼저 이벤트로 파싱하고, last-handled 비교·기록은 `InviteJoinEvent`일 때만 적용한다. 글 열람은 두 번 열려도 무해하므로 dedup이 필요 없다.
- 웜 `markHandled`, 스플래시의 콜드 프로브 회수 로직(#558), 웹은 건드리지 않는다.
- 트레이드오프: 프로세스가 죽은 뒤 recents로 재실행하면 모집글 상세가 한 번 더 열린다. 글 열람은 멱등이라 감수한다.
