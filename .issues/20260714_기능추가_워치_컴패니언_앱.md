⚙️ [기능추가][워치] 갤럭시워치·애플워치 컴패니언 앱 지원

## 본문

## 📝 현재 문제점

- 게임 특성상 실제로 뛰어다니는 중에 폰을 꺼내 타이머·게임 상황을 확인해야 해서 불편함
- 도둑은 체포당할 때마다 폰을 꺼내 체포 QR을 띄워야 해서 게임 몰입이 깨짐
- 게임 이벤트(체포, 위치 공개, 게임 종료 등)를 폰 화면을 봐야만 알 수 있음

## 🛠️ 해결 방안 / 제안 기능

- 갤럭시워치(Wear OS)와 애플워치(watchOS) 컴패니언 앱을 제공한다 (폰의 리모컨/디스플레이 역할, 게임 로직·네트워크·인증은 폰 유지)
- 라운드 타이머, 내 팀/상태, 남은 도둑 수를 손목에서 바로 확인
- 게임 이벤트(체포/탈옥/위치 공개/경찰 이동 시작/게임 종료) 수신 시 워치 배너 + 햅틱 알림
- 도둑 체포 QR을 워치 화면에 표시 — 기존 QR 체포 시스템의 확장, 만료 대비 자동 갱신 (경찰은 기존처럼 폰 카메라로 스캔)
- 심박수 측정 후 워치·폰 게임 화면에 표시 (서버 전송 없음)
- 백엔드 무변경, 신규 스토어 등록 없이 기존 앱 등록에 함께 배포

## ⚙️ 작업 내용

- 폰(Flutter) ↔ 워치 브리지 신설 및 게임 상태/이벤트 push 연동

- CI/CD 보강 — Wear AAB 빌드·업로드 스텝, watchOS 서명·임베드 배포
