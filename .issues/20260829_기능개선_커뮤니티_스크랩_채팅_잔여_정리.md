🚀 [기능개선][Flutter][커뮤니티] 스크랩·채팅 잔여 정리 — 새로고침·강퇴 errorCode·문서 정합

🔥 구현 기능
---

#493·#494에서 범위 밖으로 미뤄둔 잔여 4건을 닫습니다.

| 항목 | 내용 |
|---|---|
| 스크랩 화면 새로고침 | 피드에는 있는 `AppRefreshControl`이 내 스크랩 목록에는 없음 |
| 강퇴 errorCode 3종 | 매핑이 없어 공통 폴백 문구로 떨어짐 |
| 클래스 문서 | `community_scrap_page.dart` doc이 개명 전 이름을 서술 |
| 경합 테스트 | 역순 시나리오 전용 테스트 부재 |

📝 현재 문제점
---

**① 스크랩 목록에 새로고침·재시도가 없다**

커뮤니티 피드는 당겨서 새로고침과 실패 재시도를 갖고 있는데, 같은 모양의 내 스크랩 목록에는 없습니다. 목록이 낡거나 로딩에 실패하면 화면을 나갔다 들어오는 수밖에 없습니다.

**② 강퇴 errorCode 3종이 매핑되지 않아 테스트가 빨간불**

> [!WARNING]
> `api-docs errorCode coverage` 테스트가 지금 실패 상태입니다. 이 저장소의 상시 실패 1건이 이것입니다.

```
Expected: empty
  Actual: ['CANNOT_KICK_SELF', 'CHAT_MEMBER_NOT_FOUND', 'FORBIDDEN_NOT_CHAT_HOST']
error_message_mapper에 매핑이 없어 공통 폴백으로 떨어지는 코드
```

**③ 클래스 문서가 낡음**

`community_scrap_page.dart`의 클래스 doc이 `syncAfterDetail` 개명 전 서술을 그대로 갖고 있습니다.

**④ 경합 테스트가 한 방향만 덮음**

`loadMore`가 먼저 오는 순서만 테스트하고 역순은 코드상 정합이라는 판단으로 넘어갔습니다. 전용 테스트가 없습니다.

🛠️ 해결 방안 / 제안 기능
---

- 스크랩 화면에 `AppRefreshControl` 적용 — 피드와 같은 방식
- 강퇴 errorCode 3종을 `error_message_mapper`에 매핑하고 ko/en/ja 문구 추가
- `community_scrap_page.dart` 클래스 doc을 현재 이름·동작에 맞게 수정
- 경합 역순 시나리오 테스트 추가

> [!TIP]
> ②를 닫으면 이 저장소의 상시 실패 1건이 사라져 `flutter test`가 전부 초록이 됩니다.
