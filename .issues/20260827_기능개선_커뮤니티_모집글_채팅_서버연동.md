## 제목

🚀 [기능개선][API연동][커뮤니티] 모집글 채팅을 예시 데이터에서 서버 연동으로 전환

## 본문

## 📝 현재 문제점

- 모집글 채팅 화면과 내 모임 목록은 만들어져 있으나 대화가 앱 메모리에만 남는다. 앱을 껐다 켜면 사라지고 다른 사람과 이어지지 않는다
- 지금 내 모임에 보이는 채팅방 두 개는 시안 확인용 예시 데이터다
- 백엔드는 채팅방 참여·나가기·이전 대화 조회·내 채팅방 목록과 실시간 채널을 모두 열어둔 상태다

## 🛠️ 해결 방안 / 제안 기능

- 채팅 저장소를 서버 연동 구현으로 교체
- 실시간 채널을 구독해 메시지를 주고받도록 연결

## ⚙️ 작업 내용

- 채팅방 참여·나가기·이전 대화 조회·내 채팅방 목록을 서버 연동으로 전환한다
- 실시간 채널을 구독한다. 게임과 같은 연결 하나를 쓰고, 지금 보고 있는 방만 구독한다
- 방을 나가면 구독을 해제한다
- 보낸 메시지를 먼저 그린 뒤 서버 응답으로 확정하는 방식은 지금 구현을 그대로 유지한다
- 이전 대화는 위로 올려 이어 보기로 가져온다
- 참여 중인 방 개수 상한을 넘기면 안내한다
- 예시 데이터 저장소를 제거한다
- 읽음 표시와 안 읽은 개수는 서버가 만들지 않으므로 앱에서 유지한다
- 채팅 메시지 신고를 붙인다. 말풍선을 길게 눌러 신고 유형을 고르는 진입점이 아직 없어 함께 만든다
- 실패 안내를 다국어 처리한다 (ko/en/ja)

## 📌 참고

- 화면과 상태 흐름은 모집글 채팅 이슈에서 이미 완성했다. 이번 작업은 데이터 출처 교체다
- 모임 날짜가 지난 글은 새로 참여만 막고, 이미 있는 대화는 그대로 유지한다
- 작성자는 채팅방을 나갈 수 없다
- 채팅 메시지 신고가 이 이슈로 넘어왔다. 신고 접수에 서버가 발급한 메시지 번호가 필요한데, 예시 데이터의 번호는 앱이 만든 가짜라 그대로 보내면 서버가 찾지 못한다
- 신고 유형 선택과 기타 사유 입력은 게시글 신고 작업에서 공용으로 뽑아 둔다. 여기서는 가져다 쓰면 된다
- 세 이슈 중 가장 크다. 나머지 둘과 겹치는 파일이 없어 동시에 진행할 수 있다
