## 제목

❗ [버그][Flutter][지도] 게임 시작 시 지도 타일이 간헐적으로 로드되지 않음

## 본문

## 🗒️ 설명

- 게임 시작 직후 지도 화면에서 Google Maps 타일이 렌더링되지 않고 회색 배경만 표시되는 현상
- HUD(타이머, 공지 배너, 채팅 입력), 내 위치 마커, playground 경계선 원 등 Flutter 레이어에서 그리는 요소는 모두 정상 표시됨
- 도둑(다크 테마, Cloud Map ID 기반 다크 스타일) 진행 시 관찰되었으며, 경찰(라이트)에서는 확인되지 않음
- 앱 콜드 스타트 직후 첫 게임에서 주로 발생하고, 두 번째 게임부터는 잘 뜸
- 같은 앱 인스턴스 안에서는 회복되지 않음 (화면 전환, 백그라운드 복귀, 위젯 rebuild로도 복구 불가). 앱 프로세스를 종료 후 재실행해야만 정상화됨
- Cloud Map ID 콜드 스타트 경쟁 이슈는 iOS/Android 양 플랫폼에서 모두 보고된 패턴이므로, 현재 관찰 기기와 무관하게 양 플랫폼 모두를 대상으로 검토 필요

## 🔄 재현 방법

1. 앱을 완전히 종료 (iOS: 앱 스와이프로 종료 / Android: 최근 앱에서 제거)
2. 앱을 새로 실행하고 로그인
3. 게임을 생성 또는 참가하여 도둑 팀으로 배정
4. 대기방에서 모든 인원 준비 완료 후 게임 시작
5. 게임 화면 진입 시 간헐적으로 지도 타일이 로드되지 않고 회색 배경만 표시되는 것을 확인

## 📸 참고 자료

- 첨부 스크린샷 (2026-04-23 확인)
  - 상단 HUD(타이머 29:23, "다음 도둑 위치 공개까지 01:23") 정상
  - 공지 배너 정상
  - 중앙 내 위치 마커 정상
  - playground 경계선 원 정상
  - 지도 타일 영역만 단색 회색으로 표시됨

## ✅ 예상 동작

- 게임 시작 후 지도 화면 진입 시 지도 타일이 정상적으로 로드되어 지도 배경, 마커, 경계선이 모두 표시되어야 함
- 앱 재시작 없이도 첫 게임부터 지도 타일이 안정적으로 표시되어야 함
- 특정 팀(도둑, 다크 테마)에서 편향되지 않아야 함
