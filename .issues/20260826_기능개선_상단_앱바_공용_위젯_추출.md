# 🚀 [기능개선][Flutter][공용컴포넌트] 화면마다 중복된 상단 앱바를 공용 위젯으로 추출

## 📝 현재 문제점

- 화면 상단 앱바를 26곳에서 각자 조립하고 있다 — 배경색, 표면 틴트, 그림자 제거, 뒤로가기 버튼, 가운데 정렬, 타이틀 글자 스타일이 화면마다 그대로 반복된다
- 같은 모양인데도 화면마다 조금씩 어긋나 있다. 일부 화면은 표면 틴트 설정이 빠져 있고, 타이틀 여백 설정도 제각각이며, 아무 아이콘도 읽지 않는 죽은 설정값이 남아 있는 화면도 있다
- 디자인이 앱바 규격을 한 번 바꾸면 26곳을 전부 찾아 고쳐야 하고, 빠뜨린 화면이 생겨도 눈에 잘 띄지 않는다

## 🛠️ 해결 방안 / 제안 기능

- 반복되는 앱바 구성을 공용 위젯 하나로 모으고, 화면마다 다른 부분만 넘기도록 한다 — 제목, 뒤로가기 동작, 우측 버튼, 팀 테마 여부
- 팀 테마(경찰 라이트 / 도둑 다크)는 기존 원칙대로 상위 화면이 값으로 내려준다
- 도둑 모드 타이틀 글꼴은 기본값을 두되, 의도적으로 다른 글꼴을 쓰는 화면(게임 설정, 구역 미리보기)은 분기 옵션으로 그대로 유지한다
- 화면에 보이는 결과는 바꾸지 않는 것을 원칙으로 한다 — 색·간격·글꼴 변경 없음
- 구조가 다른 화면은 대상에서 제외한다 — 인게임 화면(앱바가 아니라 지도 위에 겹쳐 그리는 구조), 대기방(투명 배경·초대 코드 타이틀), 개발용 테스트 화면, 라우터 오류 화면

## ⚙️ 작업 내용

- 상단 앱바 공용 위젯 신규 작성
- 대상 26곳 전환
- 앱바에서만 쓰이던 죽은 설정값·지역 변수 정리
- 공용 위젯 동작 검증 테스트 작성 (팀 테마 색상, 글꼴 분기, 뒤로가기 없는 경우, 제목 슬롯 우선순위)
